# 一、基础层：ESI-MS 是什么？

## 1.1 质谱仪的基本工作原理

质谱仪（Mass Spectrometer）的本质是一台**超精密的分子体重秤**。它通过以下三步工作：

1. **电离（Ionization）**：让分子带上电荷，变为可被电场操控的「离子」

1. **分离（Separation）**：利用电场或磁场，按质荷比（m/z）将不同离子分开

1. **检测（Detection）**：记录每种离子的信号强度，画出谱图

> 💡 **关键约束**：质谱仪只能检测**带电的离子**，不能直接检测中性分子。因此，电离方式的选择至关重要。

## 1.2 ESI 的核心优势：软电离

历史上，质谱常用高能量电子束来电离样品（称为「硬电离」），会把大分子直接打碎成碎片，根本无法分析蛋白质、DNA 等生物大分子。

**1989 年，John Fenn 发明了电喷雾电离（ESI）**，这是一种「软电离」技术：

|特性|硬电离（EI）|软电离（ESI）|
|---|---|---|
|施加能量|高|极低|
|分子碎裂|严重|几乎无|
|适用分子量|< 1,000 Da|> 1,000,000 Da|
|典型应用|小分子有机物|蛋白质、核酸、多肽|

> 🏆 **诺贝尔奖背书**：John Fenn 因发明 ESI-MS 于 2002 年获得诺贝尔化学奖。

## 1.3 ESI 电离过程详解

想象用喷雾瓶喷水，但喷嘴接了几千伏高压电：

**① 高压喷雾 → 带电液滴**

溶液从金属针头（毛细管）喷出，高电压把液体撕裂成**无数极细的带电液滴**，形如「带电的毛毛雨」。

**② 溶剂蒸发 → 液滴缩小**

液滴在飞行中不断蒸发，体积越来越小，但电荷数不变——就像气球越缩越小，但上面的磁贴数量不变。

**③ 库仑爆炸 → 离子「裸奔」**

当液滴小到极限，内部电荷排斥力撑爆液滴（**库仑爆炸，Coulomb Explosion**），将分子一个一个「抖出来」，成为携带电荷的气态离子。

**④ 飞行分析 → 画出谱图**

带电离子进入真空管，被加速后飞行。**轻的跑得快，重的跑得慢**。探测器记录到达时间，换算成 m/z，最终画出质谱图。

```jsx
溶液注入
  ↓
[高压毛细管喷嘴] → 带电液滴云
  ↓ 溶剂蒸发
液滴不断缩小 → 库仑爆炸
  ↓
气态离子 → [真空飞行管] → 质量分析器 → 检测器
  ↓
质谱图（m/z vs 相对丰度）
```

# 二、坐标层：如何读懂谱图？

## 2.1 横坐标：m/z（质荷比）

$m/z = \frac{\text{离子质量（Da）}}{\text{所带电荷数（z）}}$

⚠️ **重要陷阱**：横坐标的数值**不等于分子量**！它是质量除以电荷数之后的值。

- 小分子通常带 1 个电荷（z=1），所以 m/z ≈ 分子量

- 大蛋白质可以带几十个电荷，所以 m/z 远小于真实分子量

## 2.2 纵坐标：相对丰度（Relative Abundance, %）

- 以**最高峰（基峰，Base Peak）**为 100%

- 其他峰按比例折算为百分比

- 峰越高 = 该质荷比的离子数量越多

## 2.3 加合离子与分子量校正

中性分子 M 本身无法被检测，必须「抱上」带电的离子才能飞进质谱仪。最常见的加合方式：

|加合形式|带电来源|加合质量（Da）|校正公式|
|---|---|---|---|
|[M+H]⁺|结合一个 H⁺|+1.0078|M = (m/z) × 1 − 1.0078|
|[M+Na]⁺|结合一个 Na⁺|+22.9898|M = (m/z) × 1 − 22.9898|
|[M+NH₄]⁺|结合铵根|+18.034|M = (m/z) × 1 − 18.034|
|[M+nH]ⁿ⁺|结合 n 个 H⁺|+n×1.0078|M = (m/z) × n − n×1.0078|
|[M−H]⁻|失去一个 H⁺（负模式）|−1.0078|M = (m/z) × 1 + 1.0078|

> 💡 **识别技巧**：如果谱图中两个强峰相差 21.98 Da，通常一个是 [M+H]⁺，另一个是 [M+Na]⁺，代表同一个分子。

# 三、小分子层：简单谱图分析

## 3.1 小分子谱图的外观

小分子（如药物、代谢物，通常 < 1000 Da）的 ESI-MS 谱图很简洁：

- 通常只有**1-3 个主要峰**

- 最高峰（基峰）对应最稳定的加合离子形式

- 峰型细而尖锐

**典型图谱示意（以葡萄糖 M=180 Da 为例）：**

```jsx
相对丰度 (%)
100 |         ██  ← [M+H]⁺ at m/z = 181.07
    |         ██
 50 |         ██    ██  ← [M+Na]⁺ at m/z = 203.05
    |    ██   ██    ██
  0 |____██___██____██_____________→ m/z
      100  181  203  300
```

## 3.2 同位素峰簇：利用间距判断电荷数 z

自然界中碳元素存在两种同位素：¹²C（98.9%）和 ¹³C（1.1%）。含有一个 ¹³C 的分子比全 ¹²C 的分子重约 **1.00335 Da**。

当分子带 z 个电荷时，相邻同位素峰的 m/z 差值为：

$\Delta(m/z) = \frac{1}{z}$

|同位素峰间距 Δ(m/z)|电荷数 z|常见场景|
|---|---|---|
|1.0|z = 1|小分子药物、有机物|
|0.5|z = 2|二肽、小多肽|
|0.33|z = 3|中等多肽|
|0.25|z = 4|较大多肽|
|1/n|z = n|通用公式|

**实例计算：**

- 某峰在 m/z = 601.32，相邻同位素峰在 601.82，间距 = 0.50 → z = 2

- 真实分子量 M = 601.32 × 2 − 2 × 1.008 = **1200.6 Da**

> ⚠️ **仪器要求**：需要高分辨质谱（如 TOF、Orbitrap）才能分辨 0.33 或 0.25 的精细间距。

# 四、大分子层：蛋白质的奇妙谱图

## 4.1 多电荷包络线（Multi-charge Envelope）

蛋白质拥有大量可质子化位点（如氨基、组氨酸侧链），在电喷雾过程中会同时携带许多个 H⁺。**同一个蛋白质分子会以不同的电荷状态出现**，在谱图上形成一系列峰，这就是「多电荷包络线」。

**典型示意图（以 Ubiquitin，MW ≈ 8565 Da 为例）：**

```jsx
相对丰度 (%)
100 |                ▐███▌  ← z=+10, m/z≈857
    |           ▐████████████▌
 50 |      ▐██████████████████████▌
    |   ▐████████████████████████████▌
  0 |__▐████████████████████████████████▌__ m/z
        600  700  800  900  1000 1100
             ↑z=13      ↑z=8
         (高电荷,低m/z)  (低电荷,高m/z)
```

**关键规律：**

- 电荷数越高（z 大）→ m/z 越小 → 峰在图谱左侧

- 电荷数越低（z 小）→ m/z 越大 → 峰在图谱右侧

- 整组峰合在一起，形如一个「拱桥」或「山脉」

> 📌 **文献参考**：Ubiquitin（泛素）是 ESI-MS 领域最经典的研究对象，分子量 8565 Da，在正离子模式下典型带有 +8 至 +13 电荷（来源：LibreTexts Analytical Chemistry，Biological Mass Spectrometry 课程材料）。

[![](https://cdn.ncbi.nlm.nih.gov/pmc/blobs/dcb8/6003721/a80390b05cd0/nihms915687f2.jpg)](https://cdn.ncbi.nlm.nih.gov/pmc/blobs/dcb8/6003721/a80390b05cd0/nihms915687f2.jpg)

图1：三种模型蛋白（Ubiquitin、Cytochrome c、Myoglobin）的 ESI-MS 多电荷包络线。红色：酸性有机溶剂（pH ~3，蛋白质展开，高电荷态）；蓝色：水性缓冲液（pH ~6.6，蛋白质折叠，低电荷态）。可清晰看到，折叠状态下峰群整体右移（低电荷、高 m/z），展开状态下峰群左移（高电荷、低 m/z）。

> 📖 **图片来源**：May JC et al. (2018). _Conformational Landscapes of Ubiquitin, Cytochrome c, and Myoglobin: Uniform Field Ion Mobility Measurements in Helium and Nitrogen Drift Gas._ **Int J Mass Spectrom**, 427:79–90. [PMC6003721](https://pmc.ncbi.nlm.nih.gov/articles/PMC6003721/) — 开放获取，CC BY 授权。

**图片解读要点：**

- **（A）Ubiquitin（8,566 Da）**：红色（pH 3，展开）的峰群集中在 m/z 600–800，对应 +9 至 +13 电荷；蓝色（pH 6.6，折叠）峰群集中在 m/z 900–1100，对应 +8 至 +9 电荷。

- **（B）Cytochrome c（12,359 Da）**：展开时最高电荷可达 +17 以上（m/z < 800），折叠时集中在 +9 至 +10（m/z ~1200–1400）。

- **（C）Myoglobin（apo 16,951 Da / holo 17,567 Da）**：holo 形式（保留血红素）仅在缓冲液条件下出现，可通过质量差（616 Da）与 apo 形式区分。

## 4.2 ¹³C 混杂的「胖峰」现象（微观尺度）

**为什么大蛋白质谱图上的每个峰都是「胖的」？**

因为蛋白质含有几千个碳原子，这些碳原子中，¹³C 会随机混入。不同数量 ¹³C 组成的「同一个蛋白质」，质量略有不同，在 m/z 轴上紧紧相邻——仪器无法一一分辨时，这些小峰融合成一个**宽而圆弧的「胖峰」**。

## 4.3 二项分布与「概率悖论」

🤔 **问题**：既然 ¹²C 占 98.9%，为什么大蛋白质图谱里「纯 ¹²C 峰」反而消失了？

**答案来自概率论（二项分布）：**

把每个碳原子想象成一次抛硬币：

- 正面（¹²C）概率 = 98.9%

- 反面（¹³C）概率 = 1.1%

|分子碳原子数|「全是 ¹²C」的概率|图谱表现|最可能混入的 ¹³C 数量|
|---|---|---|---|
|10 个（小药物）|(0.989)¹⁰ ≈ **89.5%**|纯 ¹²C 峰最高|≈ 0 个|
|100 个（小肽）|(0.989)¹⁰⁰ ≈ **32%**|第 1、2 峰差不多|≈ 1 个|
|1000 个（中等蛋白）|(0.989)¹⁰⁰⁰ ≈ **0.0015%**|¹²C 峰几乎不见|≈ 11 个|
|3000 个（大蛋白）|(0.989)³⁰⁰⁰ ≈ **≈ 0**|纯 ¹²C 峰完全消失|≈ **33 个**|

**期望值公式：**

$\text{最可能的} \;^{13}\text{C} \text{ 数量} = N_{carbon} \times 1.1\%$

因此对于含 3000 个碳的蛋白质，**含有约 33 个 ¹³C 的分子数量最多**，其对应的峰才是最高的基峰。整体同位素峰簇呈现**高斯分布（正态分布）的山丘形态**。

> 🎯 **关键洞察**：这并没有违反自然界中 ¹²C 占多数的规律。如果将蛋白质拆成单个碳原子去测，¹²C 依然占 98.9%。但作为「整体分子」，概率论放大了¹³C 混入的必然性。

## 4.4 平均质量 vs 单同位素质量

这两个概念在文献中频繁出现，含义不同：

|概念|定义|对应谱图位置|适用场景|
|---|---|---|---|
|**单同位素质量**（Monoisotopic Mass）|假设全由丰度最高的同位素（¹²C, ¹H...）组成时的质量|最左边的第一根细峰 M₀|小分子、高分辨谱图|
|**平均质量**（Average Mass）|按自然界同位素丰度加权平均的质量（即元素周期表中的原子量）|胖峰的几何重心位置|大蛋白质、低分辨谱图|

# 五、解析层：从谱图还原真实分子量

## 5.1 多电荷解卷积（Deconvolution）

对于蛋白质谱图（多电荷包络线），如何从一系列 m/z 峰算出真实分子量？

**数学原理：**

设某蛋白质真实质量为 M，若观察到相邻两个峰：

- 峰 1 在 m₁，对应电荷数 z₁

- 峰 2 在 m₂，对应电荷数 z₁+1

则：

$M = m_1 \cdot z_1 - z_1 \times 1.008$

$z_1 = \frac{m_2 - 1.008}{m_2 - m_1}$

**实例：** 相邻两峰在 m/z = 779.83 和 714.92（ubiquitin）

$MW = \frac{(779.83-1.01)(714.92-1.01)}{779.83-714.92} = \frac{778.82 \times 713.91}{64.91} \approx 8566 \; Da$

理论值 8560 Da，误差仅 0.07%！

> 📌 **计算来源**：LibreTexts Analytical Chemistry，Section 2B ESI-MS Data，Trinity College 实验数据。

[![](https://cdn.ncbi.nlm.nih.gov/pmc/blobs/dcb8/6003721/a80390b05cd0/nihms915687f2.jpg)](https://cdn.ncbi.nlm.nih.gov/pmc/blobs/dcb8/6003721/a80390b05cd0/nihms915687f2.jpg)

图2：ESI-MS 多电荷包络线的解卷积示意。上图（a）为原始质谱图，显示一系列多电荷态峰（m/z 轴）；下图（b）为解卷积后的结果，横轴转换为真实质量（Da），单一峰对应蛋白质的真实分子量，极大简化了解析。

> 📖 **图片来源**：同上，May JC et al. (2018)，PMC6003721。

**从原始谱图到分子量的解析逻辑（对照图示）：**

- 图中每一个"山峰"对应一个电荷状态（z），每个峰的 m/z 值 = (M + z×1.008) / z

- 取任意两个相邻峰 m₁（对应 z₁）与 m₂（对应 z₁+1），代入公式即可解出 M

- 软件（MaxEnt、Bruker DataAnalysis 等）会同时拟合所有峰，给出唯一最优解

## 5.2 双维度嵌套：宏观 vs 微观尺度

ESI-MS 谱图同时包含两个完全不同尺度的信息：

|维度|现象|物理机制|m/z 尺度差|
|---|---|---|---|
|**宏观**|多电荷包络线（连绵山脉）|带电量（质子数）不同|**几十到几百 Da**|
|**微观**|¹³C 导致的胖峰（单座山头）|质量（中子数）不同|**零点几 Da**|

**定量示例（30,000 Da 蛋白质，带 20 或 21 个电荷）：**

- 宏观：z=20 峰在 m/z=1500.0，z=21 峰在 m/z=1428.6，**相差 71.4 m/z**

- 微观：同一个峰内，含 33 个 ¹³C 与含 34 个 ¹³C 的分子，**相差仅 0.05 m/z**

## 5.3 质量校准与系统误差排除

如何确保「胖峰的右移」是 ¹³C 导致的，而非机器误差？

**三重保障机制：**

1. **质量校准（Mass Calibration）**：实验前用分子量绝对已知的标准物校准仪器，将系统误差压制在 < 5 ppm（即对于 30,000 Da 蛋白质，误差 < 0.15 Da）

1. **峰宽验证**：胖峰的宽度（半高宽 FWHM）必须严格符合含有几千个碳原子的**二项分布数学预测宽度**，不可伪造

1. **多峰联动（解卷积算法）**：宏观包络线上几十个山头的位置、间距必须同时满足同一个分子量的解，任何机器误差无法产生如此「完美协调」的多峰联动规律

> 📌 **软件工具**：现代质谱软件（如 MaxEnt、Averagine 模型）通过对同位素包络的全局拟合，可精确还原大蛋白质的真实分子量，准确度可达 Da 量级以内。

# 六、应用层：ESI-MS 能做什么？

## 6.1 蛋白质组学（Proteomics）

- **蛋白质鉴定**：确认蛋白质分子量，与数据库比对

- **翻译后修饰（PTM）**：磷酸化（+80 Da）、糖基化、泛素化等

- **蛋白质构象研究**：pH 变化会改变蛋白质折叠状态，进而改变多电荷包络线的分布（高 pH → 低电荷态 → 包络线右移）

- **原生质谱（Native MS）**：在接近生理条件的缓冲液中电喷雾，保留蛋白质的非共价相互作用，研究蛋白质复合物

> 📌 **文献实例**：细胞色素 C（Cytochrome C，MW≈12,360 Da）在 pH 2.6 时蛋白质展开，ESI 谱图中心偏移至 z≈+16；在 pH 5.6 时蛋白质折叠，中心在 z≈+10（Konermann & Douglas, _Biochemistry_, 1997）。

## 6.2 药物研发

- **合成确认**：验证合成产物的精确分子量，确认反应是否成功

- **纯度检测**：通过峰面积比例判断产物纯度

- **代谢物鉴定**：追踪药物在体内的代谢转化产物

## 6.3 代谢组学与食品安全

- **代谢组学**：血液、尿液中代谢物的高通量鉴定

- **农药残留**：精确质量确认农药分子

- **非法添加物**：食品掺假成分的检测

## 6.4 ESI 与不同质量分析器的组合

|质量分析器|分辨率|典型应用|
|---|---|---|
|四极杆（Quadrupole）|低（~1 Da）|快速定量、药代动力学|
|飞行时间（TOF）|高（~10,000）|精确分子量、肽段鉴定|
|轨道阱（Orbitrap）|极高（~100,000+）|翻译后修饰、同位素峰精细分析|
|FT-ICR|最高（>1,000,000）|超高精度基础研究|

# 七、图谱速查：看图识谱

## 7.1 小分子药物谱图特征

```jsx
相对丰度
100% |        ████  ← 基峰 [M+H]⁺
     |        ████
 50% |   ██   ████   ██  ← [M+Na]⁺, [M+K]⁺
     |   ██   ████   ██
   0 |___██___████___██__→ m/z
         ↑   ↑   ↑
         钠峰  H峰  钾峰
（同一分子，不同加合形式）
```

**识别要点：**

- [M+H]⁺ 和 [M+Na]⁺ 相差约 21.98 Da

- [M+Na]⁺ 和 [M+K]⁺ 相差约 15.97 Da

- 高分辨下可见同位素簇（¹³C 小峰），间距 ≈ 1.0（单电荷）

## 7.2 中等多肽谱图特征

```jsx
相对丰度
100% |       ▐█████▌  ← [M+2H]²⁺ 最强
     |   ▐███████████▌
 50% |   ▐███████████▌  ▐████▌ ← [M+3H]³⁺
   0 |___▐███████████████████▌_→ m/z
         同位素间距≈0.5       ≈0.33
```

**识别要点：**

- 出现 2-3 个电荷态的峰群

- 同位素峰间距 0.5 → 双电荷；0.33 → 三电荷

- 利用相邻电荷态峰的 m/z 差值，可列方程反算分子量

## 7.3 蛋白质谱图特征（宏观 + 微观双层结构）

```jsx
宏观视角（全图）：
相对丰度                  连绵山脉（多电荷包络线）
100% |              ▐██████▌
     |         ▐███████████████▌
 50% |    ▐█████████████████████████▌
   0 |__▐█████████████████████████████████▌_ m/z
       ←← 高电荷（小m/z）      低电荷（大m/z）→→

微观视角（单峰放大）：
      ▐████▌  ← 这个「单峰」其实是胖圆弧
     ▐██████▌    由混有不同数量¹³C的分子
    ▐████████▌   叠加融合而成
```

**蛋白质谱图的「解读三步走」：**

1. 🔭 **全局看**：多电荷包络线的整体形状 → 估计电荷状态范围

1. 🔬 **局部算**：选两个相邻峰，用公式计算 z 和 M

1. 🖥️ **软件验**：用解卷积算法（如 MaxEnt）拟合整个包络线，得到精确分子量

多电荷包络线 = **多个独立分开的尖峰**，不是一个胖包

**以 Ubiquitin（MW ≈ 8565 Da）为例：**

```jsx
相对丰度 (%)                    ← 每个峰 = 一个独立电荷态
                                   各峰之间有明显空隙！

100%|               |
    |           |   |
 80%|           |   |
    |       |   |   |
 60%|       |   |   |   |
    |   |   |   |   |   |
 40%|   |   |   |   |   |   |
    |   |   |   |   |   |   |
 20%|   |   |   |   |   |   |
    |   |   |   |   |   |   |
  0%|___|___|___|___|___|___|___▶ m/z
      660 720 780 857 952 1072
      +13 +12 +11 +10  +9  +8
      ◀ 高电荷态            低电荷态 ▶
        (低m/z)             (高m/z)

相邻峰间距 ≈ 60 ~ 95 m/z（宏观尺度）
```

**再把 z=+10（m/z≈857）那个峰单独放大 ×100：**

```jsx
相对丰度 (%)       ← 这才是"微观胖峰"的内部结构

100%|         |
    |       | | |
 80%|     | | | | |
    |   | | | | | | |
 50%| | | | | | | | | |
    | | | | | | | | | |
  0%|_|_|_|_|_|_|_|_|_|_▶ m/z（放大后的尺度）
    M₀         M+4    M+9
        Δ = 0.1 m/z = 1/z（z=10）

高分辨仪器（Orbitrap/FT-ICR）可以分辨出这些0.1间距的细线
低分辨仪器：0.1太近，所有细线融合 → 宏观上看起来是一个"胖包"
```

**两个尺度的关键区别：**

|特征|宏观：多电荷包络线|微观：¹³C导致的胖峰|
|---|---|---|
|**成因**|分子带了不同数量的 H⁺|分子含有不同数量的 ¹³C|
|**峰间距**|60~100 m/z（肉眼可见）|1/z ≈ 0.1 m/z（需高分辨）|
|**峰的数量**|每种蛋白质出现6~15个独立峰|每个电荷态峰内含数十条细线|
|**看起来像**|🏔️ 连绵的独立山峰群|🏔️ 单座山峰的内部地形|
|**用途**|联立方程算分子量|确认电荷数，确认¹³C统计特性|

# 八、关键公式速查卡

> 📋 汇总所有核心计算公式

**质量校正（正离子模式）：**

- [M+H]⁺：$M = (m/z) - 1.0078$

- [M+Na]⁺：$M = (m/z) - 22.9898$

- [M+nH]ⁿ⁺：$M = (m/z) times n - n times 1.0078$

**质量校正（负离子模式）：**

- [M−H]⁻：$M = (m/z) + 1.0078$

**电荷数判断（同位素间距法）：**

$z = \frac{1}{\Delta(m/z)}$

**双峰法反算分子量（蛋白质）：**

$M = \frac{(m_1 - A)(m_2 - A)}{m_1 - m_2}$

（其中 A = 1.008，m₁ > m₂ 为相邻两峰的 m/z 值）

**¹³C 混杂期望值：**

$\bar{N}_{^{13}C} = N_{carbon} \times 1.1\%$

## 图2｜小分子同位素簇分布随分子质量的变化规律

同位素峰簇随分子量变化（三种情形对比）

**规律：分子越大，纯 ¹²C 峰（M₀）越矮，甚至消失**

```jsx
【小分子 ~150 Da，约10个碳】         【大蛋白质 ~13,000 Da，约1000个碳】
相对丰度                              相对丰度
100%|█                               100%|        █
    |█                                   |      █ █ █
 12%|  █                              50%|    █ █ █ █ █
  1%|    █ ▂                              |  ▂ █ █ █ █ █ █ ▂
    |________▶ m/z                      0%|▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▶ m/z
    M₀  M+1 M+2                          M₀ ← 几乎为零  M+11 ← 最高峰

间距 Δ(m/z) = 1.0 → z=1               间距 Δ(m/z) = 0.1 → z=10（若高分辨）
```

**关键规律对比表：**

|分子大小|碳原子数|M₀峰高度|最高峰位置|含义|
|---|---|---|---|---|
|小分子药物 (~150 Da)|~10|**最高 ~89%**|M₀|纯¹²C分子占绝大多数|
|中等多肽 (~1300 Da)|~100|~32%|M₀ 或 M+1|两峰高度相近|
|中等蛋白 (~13,000 Da)|~1000|**<1%，几乎消失**|M+11|必然混入约11个¹³C|
|大蛋白 (~30,000 Da)|~2500|**完全为0**|M+27|纯¹²C概率趋近于0|

> 💡 **这不违反自然规律**：每个碳原子单独看，¹²C 依然占 98.9%。但整个蛋白质作为一个"群体"，几千个碳原子中必然有几十个混入¹³C，这是概率论（二项分布）的必然结果。
