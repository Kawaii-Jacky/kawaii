# 酚类：可逆的氧化——石炭酸、单宁与黑色素共享的一只羟基

> **根节点**：为什么「苯环上挂一只羟基」这一处小小的改动，能同时造出最古老的消毒剂、最大宗的塑料原料、植物界最庞大的抗氧化与显色系统，以及人体里的神经递质与黑色素？换句话说——酚这个结构类型，究竟靠哪一两个化学性质，被自然界与工业反复征用？
>
> **叙事逻辑**：定义与边界 → 三副面孔（弱酸 / 富电子 / 易氧化） → 分类主干（酚类·芳香醇·多酚·酚醚酚酯酚苷·酚酸） → 天然酚的生合成 → 工业 → 人体 → 药与毒 → 分析方法 → 收束
>
> **立场说明**：结构式、pKa、电位与产量数据取自公开教材、综述与工业百科；凡是「机理假说」「流行病学关联」而非既有共识的内容，正文会显式写成「假说」「相关而非因果」；数量级估计统一标「约」，不同统计口径会注明。
>

## 一、定义与边界：酚到底是不是「醇」

### 1.1 定义

**酚（phenol / hydroxyarene）**：羟基直接连在芳香环 sp² 碳上的一类化合物，通式 Ar–OH。这个「直接」二字是全部性质的源头：氧的孤对电子可以进入芳环的 π 体系，于是环变富电子、O–H 变酸、C–O 键变短（苯酚约 1.36 Å，比甲醇的 1.43 Å 短），分子整体趋于平面。

> 📌 **酚（phenol）**：羟基与芳环碳直接成键的化合物；苯酚（C₆H₅OH）是母体，也是 IUPAC 唯一保留的俗名。它与醇的差别不是「挂了个环」，而是**羟基的氧参与了这个环的共轭**——这一条决定了酸性、显色、抗氧化与聚合四条性质。

一个常被忽略的细节：苯酚的「酮式互变异构体」（环己二烯酮）几乎不存在，平衡常数约 10⁻¹³。也就是说，**酚宁愿放弃酮式的 C=O，也要保住芳香性**。这条「芳香性优先」的原则，正是它与醌互相转换时的底层账本。

### 1.2 五条边界

初学酚类最容易犯的错，是把「带苯环的含氧物」统统叫酚。下面这张表是本文后面所有分类的地基。

| 常见误解 | 为什么不对 | 正确的说法 |
|---|---|---|
| 酚就是醇 | 醇羟基连 sp³ 碳，酚羟基连 sp² 芳环碳 | pKa 差约 10⁶ 倍；酚显 FeCl₃ 色、易氧化，醇不会 |
| 芳香醇就是酚 | 芳香醇的羟基在侧链（Ar–CH₂OH） | 苯甲醇 pKa 约 15，性质接近脂肪醇，可氧化成醛/酸 |
| 酚醚 / 酚酯 / 酚苷是「另一类酚」 | 它们是酚羟基被取代后的衍生物 | 酸性消失、亲电性下降，但常是植物的储存形式或药物的前药 |
| 酚就是苯酚 | 苯酚只是母体 | 酚是类名；甲酚、儿茶酚、双酚 A、壬基酚都算 |
| 带苯环和羧基就是酚酸 | 苯甲酸的羟基在羧基上，不在环上 | 酚酸必须**环上另有酚羟基**，如没食子酸、阿魏酸 |

还有一条软边界值得单独说：**「多酚」不是一个严格的结构类名**。它通常指含两个以上酚羟基的天然产物，分子量从几百到几千不等；糖苷化的、酯化的、聚合的都能被叫「多酚」。这个模糊性正是后面分析化学争议的根源。

### 1.3 命名谱系：六个必须认识的母体

酚类的命名比醌类整齐，因为母体少。下面六个母体覆盖了绝大多数日常遇到的酚。

| 结构 | 系统名 | 俗名 | 代表用途 |
|---|---|---|---|
| 单羟基 | 苯酚 | phenol / carbolic acid | 消毒、酚醛树脂、双酚 A |
| 1,2-二羟基 | 苯-1,2-二醇 | 儿茶酚（catechol） | 显影剂、香兰素与肾上腺素骨架 |
| 1,3-二羟基 | 苯-1,3-二醇 | 间苯二酚（resorcinol） | 轮胎粘合、间苯二酚-甲醛树脂、化妆品 |
| 1,4-二羟基 | 苯-1,4-二醇 | 氢醌（hydroquinone） | 黑白显影剂、美白成分、抗氧化单体 |
| 1,2,3-三羟基 | 苯-1,2,3-三醇 | 连苯三酚（pyrogallol） | 除氧剂、显影剂、合成砌块 |
| 1,3,5-三羟基 | 苯-1,3,5-三醇 | 均苯三酚（phloroglucinol） | 解痉药、合成砌块 |

> 📌 **酚盐（phenoxide / phenolate）**：酚失去 O–H 质子后形成的负离子。它的负电荷能离域到邻、对位，因此比醇盐稳定得多——这正是酚能溶于 NaOH 的原因，也是后面 Kolbe–Schmitt 反应与 Williamson 醚化的入口。

### 1.4 与醌的关系：同一本账的两页

酚与醌不是两类「相邻的化合物」，而是同一对氧化还原共轭体的两端：**酚是「已赎回」的状态，醌是「已花掉」的状态**。酚氧化成醌要交出两个电子和两个质子；醌还原成酚就把这笔账赎回来。呼吸链里的泛醌/泛醇、光合链里的质体醌/质体酚、维生素 K 的醌式与氢醌式，走的都是这条通道。

> 🔗 **横向关联**：本节「酚↔醌是一对 2e⁻/2H⁺ 共轭体」与 [醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头](醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头.md) 的 §2.3「还原＝赎回」形成**互证关系**——那篇从「醌失去芳香性」的方向讲代价，这篇从「酚交出电子」的方向讲同一笔账；两篇合起来才是完整的循环。

## 二、第一副面孔：弱酸——pKa 10 从哪里来

### 2.1 为什么醇是 16，酚是 10

把几个 pKa 排在一起，差距一眼可见：

| 化合物 | pKa | 备注 |
|---|---|---|
| 乙醇 | 约 16 | 脂肪醇的典型值 |
| 水 | 15.7 | 参照溶剂 |
| 苯酚 | 9.95 | 弱酸，但比醇强百万倍 |
| 碳酸（H₂CO₃） | 6.35 | 酚比碳酸弱 |
| 乙酸 | 4.76 | 羧酸的门槛 |
| 苦味酸 | 0.38 | 酚的酸性上限 |

差别来自共轭碱：酚氧负离子的负电荷通过 π 体系离域到邻、对位，而且**电离之后芳香性仍然完好**；醇盐水解则没有任何「额外稳定化」可拿。还有一条常被引用的旁证：丙酮烯醇的 pKa 是 10.9，与苯酚几乎同量级——说明「氧负离子旁边有一个 sp² 体系」本身就是主要贡献，而不只是「共振式的数量」。

> 📌 **pKa**：酸给出质子的能力指标，越小越酸。每差 1 个单位，酸性差 10 倍；酚与醇差 6 个单位，就是 10⁶ 倍。这个尺度在后面的药物设计里非常实用：pKa 10 意味着酚在生理 pH 7.4 下几乎不电离。

### 2.2 取代基怎么调这只旋钮

酚的 pKa 对取代基极其敏感，而且方向可预测：**吸电子基稳定酚氧负离子 → 酸性增强；给电子基相反**。

| 取代基 | pKa | 相对苯酚的变化 |
|---|---|---|
| 无 | 9.95 | 基准 |
| 4-CH₃ | 约 10.1 | 给电子，酸性略降 |
| 4-Cl | 9.38 | 弱吸电子，酸性略升 |
| 4-NO₂ | 7.15 | 强吸电子，降约 2.8 |
| 3-NO₂ | 8.35 | 间位作用弱于对位，符合预期 |
| 2-NO₂ | 7.23 | 与对位接近，但分子内氢键会拉住未电离的 O–H |
| 2,4-二硝基 | 4.10 | 与乙酸同量级 |
| 2,4,6-三硝基（苦味酸） | 0.38 | 与强酸同量级 |
| 五氯苯酚 | 约 4.7 | 氯代越多越酸，也是它易被吸收的原因之一 |

这张表最实用的一行不是苦味酸，而是**邻硝基苯酚（7.23）与对硝基苯酚（7.15）几乎持平**：如果只算诱导效应，邻位应该更强；实际被分子内氢键抵消了一部分。这类「理论预测 + 一个例外」的格子，是理解取代基效应的最好练习。

### 2.3 三条工业后果

**第一，碱溶酸析。** 酚能溶于 NaOH 但不溶于 NaHCO₃，而羧酸两者都溶——这是有机实验里区分酚与羧酸的标准操作：酚 + NaHCO₃ 不冒气泡。煤焦油提酚、含酚废水的回收，用的都是「加碱成盐→分层→加酸析出」这套动作。

**第二，酚盐是强亲核体。** 苯酚钠与 CO₂ 在高温高压下反应，羧基进入邻位，得到水杨酸——这就是 1860 年的 Kolbe–Schmitt 反应，阿司匹林的工业前身。酚盐与卤代烃反应则是 Williamson 醚化，酚醚的工业制法。

**第三，药物里酚羟基通常不是成盐位点。** pKa 10 太高，生理 pH 下基本不电离，做成钠盐没有意义。所以酚类药物的水溶性靠三条替代路线解决：糖苷化（熊果苷）、酯化（阿司匹林、雌二醇戊酸酯）、或做成磷酸酯前药（磷丙泊酚）。这条「不能成盐 → 只好修饰」的逻辑，会在第五节反复出现。

## 三、第二副面孔：富电子环——亲电取代快到失控

### 3.1 速率与定位

羟基是**最强的活化基之一**：苯酚的亲电取代速率比苯快 10³–10⁵ 倍（不同反应差异很大），定位几乎只走邻、对位。后果是「反应太容易」：苯酚与溴水直接生成 2,4,6-三溴苯酚的白色沉淀，不需要催化剂、不需要加热——这也是酚的经典检验之一。稀硝酸在室温下就能硝化，浓硝酸则一路硝到苦味酸。

这种「失控」在工业上是双刃剑：它让酚成为极好的原料（一步就能上取代基），也让酚在环境里极易被氯化、被氧化、被微生物攻击。

### 3.2 卤代、亚硝化与偶联

三条最常见的下游反应，各自对应一个产业：

| 反应 | 产物 | 对应产业 / 现象 |
|---|---|---|
| 氯代 | 2,4-二氯苯酚、2,4,6-三氯苯酚、五氯苯酚 | 木材防腐、杀菌剂；饮水氯化副产物带来「氯酚味」 |
| 亚硝化 | 对亚硝基苯酚 | 与酚再偶联生成偶氮染料；也是酚类显色反应的化学基础 |
| 重氮偶联 | 对羟基偶氮染料 | 纺织与指示剂；碱性条件下酚氧负离子亲核性更强，偶联更快 |

**酚酞**是这一节最好的教具：内酯环闭合时无色，遇碱开环生成**醌型**的共轭阴离子，溶液变粉红。也就是说，一个最普通的酸碱指示剂，其变色本质就是「酚 → 醌型」的一次结构切换。同一逻辑还解释了两件日常小事：苯酚久置会变粉红（氧化产物显色），切开的苹果会变褐（见第四节）。

> 🔗 **横向关联**：本节「酚酞变色＝开环成醌型」与 [醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头](醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头.md) 的 §6.4「蒽醌染料」形成**上下游关系**——那篇讲醌型发色团如何被设计成染料，这篇讲最简单的酚酞如何借同一个发色团当指示剂。

### 3.3 氧化偶联＝聚合：一条反应，四条产线

这是酚化学最漂亮的一处统一。机理只有三步：

1. 酚失去一个电子（酶、碱、氧气或过氧化物都可以当氧化剂），生成**酚氧自由基**；
2. 自由基的未配对电子通过共振分布到环的邻、对位；
3. 两个自由基偶联，形成 C–C 键或 C–O 键，聚合物链就这样长起来。

| 产线 | 引发方式 | 产物 | 用途 |
|---|---|---|---|
| 酚醛树脂 | 酸或碱催化 + 甲醛 | 交联酚醛网络 | 胶合板胶、摩擦材料、绝缘件、砂轮 |
| 木质素 | 过氧化物酶 / 漆酶 + H₂O₂ | G/S/H 三种单体的无规聚合物 | 植物细胞壁、造纸副产物、生物基材料 |
| 黑色素 | 酪氨酸酶 | 吲哚醌聚合物 | 防晒、肤色、头发颜色 |
| 腐殖质 | 微生物与金属氧化物 | 类酚聚合物 | 土壤有机质、碳封存 |

**这张表的收束句**：四条产线的化学是同一套，差别只在「谁提供氧化剂、在什么介质里、聚合到什么程度停下」。工业用酸碱，植物用酶，人体用酪氨酸酶——这就是「同一只羟基在不同场合被征用」的第一层含义。

## 四、第三副面孔：易氧化——抗氧化剂、褐变与促氧化

### 4.1 三步电子账

酚的氧化不是一步到位的「坏掉」，而是一条可以停在中间的分步路线：

| 步骤 | 物种 | 电子/质子变化 | 特征 |
|---|---|---|---|
| 第一步 | 酚氧自由基（PhO•） | −e⁻、−H⁺ | 靠芳环共振稳定，寿命可达秒级 |
| 中间态 | 半醌自由基 | 再 −e⁻ | 既亲电又亲核，最不稳定 |
| 终点 | 醌（quinone） | 累计 −2e⁻、−2H⁺ | 有色、亲电，可被还原回酚 |

用电位来说，苯酚/苯醌在 pH 0 是 +0.699 V，按 −59 mV/pH 换算到 pH 7 约为 +0.28 V。这个数值正好落在呼吸链的「中继区」：比 NADH（−0.32 V）高得多，比氧气（+0.82 V）低得多，所以泛醌才能在两者之间当二传手。

> 📌 **酚氧自由基（phenoxyl radical）**：酚失去一个电子和一个质子后的物种。它既是抗氧化剂「牺牲自己」的产物，也是木质素与黑色素聚合的起点——同一个物种，在食品工业里是链终止剂，在植物体内是建筑材料。

### 4.2 抗氧化剂：链终止与再生网络

抗氧化剂的定义可以写得很朴素：**它比被保护物更容易被氧化**。脂质过氧化产生的过氧自由基（ROO•）会去抢别人的氢，酚抢先把自己的氢交出去，生成的酚氧自由基因为共振与位阻而不再引发新链——反应链就在这里断掉。

| 抗氧化剂 | 类型 | 食品编号 | 备注 |
|---|---|---|---|
| BHA（丁基羟基茴香醚） | 酚醚 | E320 | 两种异构体混合物，脂溶性好 |
| BHT（二丁基羟基甲苯） | 受阻酚 | E321 | 位阻保护自由基，稳定性高 |
| TBHQ（特丁基对苯二酚） | 二元酚 | E319 | 效果好但争议较多 |
| 没食子酸丙酯（PG） | 酚酯 | E310 | 与油脂相容性好 |
| α-生育酚 | 天然酚 | E307 | 体内抗氧化网络的核心节点 |

体内还有一层「再生网络」，这是很多人忽略的：生育酚交出氢后变成生育酚自由基，维生素 C 把它还原回生育酚，自己变成半脱氢抗坏血酸，再靠 GSH 与 NADPH 还原。电位顺序大致是：抗坏血酸/脱氢抗坏血酸 +0.28 V、生育酚自由基/生育酚约 +0.5 V、GSH/GSSG −0.24 V、NAD⁺/NADH −0.32 V。**上游的还原剂把下游的抗氧化剂不断「充值」**，这就是为什么单独补一种抗氧化剂效果有限。

不过这里必须打一个折扣：体外试管里 10–100 µM 的多酚能清除自由基，膳食后血浆里的总多酚通常不到 1 µM，而且大部分是葡糖醛酸化/硫酸化的代谢物。**「试管里抗氧化」与「体内起作用」之间隔着吸收、代谢与浓度三道墙**，这条批评在第九节还会展开。

### 4.3 酶促褐变与黑色素：酚→醌→聚合的教科书

苹果、土豆、牛油果、莲藕切开后变褐，是**多酚氧化酶（PPO）**把酚氧化成邻醌，邻醌再自行聚合的结果。PPO 是双铜酶，同时具有两种活性：单酚酶活性（把单酚羟化成邻二酚）与双酚酶活性（把邻二酚氧化成邻醌）。茶发酵、红茶的颜色、虾的黑变，走的都是同一类反应。

抑制褐变有四条路，正好对应反应的四个环节：

| 手段 | 作用点 | 日常例子 |
|---|---|---|
| 加热（焯水） | 让酶变性 | 土豆切块先焯水 |
| 加酸（柠檬汁） | 降低 pH，抑制酶活 | 苹果片淋柠檬汁 |
| 加抗坏血酸 | 把醌还原回酚 | 果汁护色、切果盘 |
| 隔氧 / 螯合铜 | 断掉氧化剂或辅基 | 真空包装、EDTA |

黑色素是同一反应的「人体版」：酪氨酸 →（酪氨酸酶）多巴 → 多巴醌 → 环化 → 吲哚醌 → 聚合。中途如果被半胱氨酸截获，就转向黄红色的褐黑色素（pheomelanin）；不带硫的路线则生成黑褐色的真黑色素（eumelanin）。白化病是酪氨酸酶缺失，白癜风是黑素细胞被免疫攻击，而「美黑」本质上是让这条反应多跑几轮。

### 4.4 反转：金属离子与高剂量下的促氧化

酚并不总是抗氧化。**在有游离铁或铜时，酚会把 Fe³⁺ 还原成 Fe²⁺，后者参加 Fenton 反应生成羟自由基**——抗氧化剂瞬间变成促氧化剂。这也是「大剂量多酚补充剂」风险的化学基础之一。

三条具体后果：

- **茶与铁**：单宁与多酚会螯合非血红素铁，随餐喝浓茶可显著降低铁吸收（常引约一半），缺铁人群应错开时间。
- **单宁与蛋白**：单宁的多点氢键把蛋白质沉淀出来，这是「涩味」的分子解释，也是制革的原理。
- **醌的硫醇耗竭**：对乙酰氨基酚过量时，醌亚胺（NAPQI）把 GSH 池掏空，阈值一旦跌破就是肝坏死——这条链的完整版本在醌类笔记里。

> 🔗 **横向关联**：本节「GSH 池被醌类掏空」与 [醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头](醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头.md) 的 §5.2「两条解毒路线」与 §9.1「越少越好」形成**因果关系**——那篇讲醌作为亲电弹头如何消耗 GSH，这篇讲酚作为还原剂如何把 GSH 网络「充值」；同一种化学在两个方向上分别是解药与毒药。

## 五、分类主干：五条支流与四步判定

这一节是全文的骨架，也是把「酚」这个词拆开看的地方。先给一个可以随身带的判定顺序：

> 📌 **四步判定**：①羟基挂在哪？挂芳环＝酚，挂侧链＝芳香醇。②一共有几个酚羟基？≥2 且来自天然＝通常归入多酚。③羟基有没有被占？被甲基/酰基/糖基占住＝酚醚/酚酯/酚苷。④环上有没有羧基？有＝酚酸。

### 5.1 酚类：简单酚与取代酚

**范围**：以苯环（或少数稠环）为骨架、羟基直接连在环上，不再带长侧链的「简单酚」。它们大多有明确的工业来源，毒性也更直接。

| 代表物 | 结构特征 | 主要用途 / 意义 |
|---|---|---|
| 苯酚 | 单羟基 | 消毒剂、酚醛树脂、双酚 A、己内酰胺 |
| 甲酚（o/m/p） | 甲基苯酚 | 来苏水、消毒剂、树脂改性 |
| 百里香酚 / 香芹酚 | 异丙基甲基酚 | 抗菌、香料、漱口水 |
| 丙泊酚 | 2,6-二异丙基苯酚 | 静脉麻醉药 |
| 儿茶酚 | 邻二羟基 | 显影剂、香兰素与儿茶酚胺骨架 |
| 间苯二酚 | 间二羟基 | 轮胎粘合体系、化妆品、树脂 |
| 氢醌 | 对二羟基 | 显影剂、美白、聚合阻聚剂 |
| 连苯三酚 | 1,2,3-三羟基 | 除氧剂、显影剂 |
| 氯酚（2,4-DCP、PCP） | 氯代 | 防腐、杀菌；环境污染物 |
| 硝基酚（苦味酸、2,4-DNP） | 硝基取代 | 炸药、染料、防霉 |
| 烷基酚（壬基酚、辛基酚） | 长链烷基 | 表面活性剂前体；内分泌干扰物 |
| 双酚 A | 两个酚环 + 异丙基桥 | 聚碳酸酯、环氧树脂单体 |

**这一节的要点**：简单酚是「工业酚」的主体，它们的功能几乎都来自第二、三节讲的两件事——**易被氧化**（所以能当还原剂、阻聚剂、显影剂）与**环富电子**（所以能缩合、能卤代、能当单体）。

### 5.2 芳香醇：羟基在侧链上

**定义**：羟基连在侧链碳上（Ar–CH₂OH 或 Ar–CH=CH–CH₂OH），而不是环上。它们与酚的关系，像「表亲」而不是「同一个人」。

| 代表物 | 结构 | 主要来源 / 用途 |
|---|---|---|
| 苯甲醇 | Ar–CH₂OH | 安息香胶；防腐剂、香料溶剂 |
| 2-苯乙醇 | Ar–CH₂CH₂OH | 玫瑰香气，香水与食品香精 |
| 肉桂醇 | Ar–CH=CH–CH₂OH | 肉桂；香料，也是木质素单体的近亲 |
| 水杨醇 | 邻羟基苄醇 | 柳树；其葡萄糖苷就是水杨苷 |
| 酪醇 | 对羟基苯乙醇 | 橄榄油、红酒；抗氧化与信号分子 |
| 松柏醇 | 4-羟基-3-甲氧基肉桂醇 | 木质素 G 单元的单体 |

最容易混的对照是苯酚、苯甲醇、苯乙醇三兄弟，列成表就清楚了：

| 维度 | 苯酚 | 苯甲醇 | 2-苯乙醇 |
|---|---|---|---|
| 羟基位置 | 芳环碳 | 侧链 CH₂ | 侧链 CH₂CH₂ |
| pKa | 9.95 | 约 15 | 约 15 |
| FeCl₃ 显色 | 显色 | 不显色 | 不显色 |
| 主要氧化产物 | 醌 / 聚合物 | 苯甲醛 → 苯甲酸 | 苯乙醛 → 苯乙酸 |
| 主要代谢 | 葡糖醛酸化、硫酸化 | 氧化 + 结合 | 氧化 + 结合 |
| 典型角色 | 消毒剂、单体 | 防腐剂、香料 | 花香信号 |

**收束句**：芳香醇是「把酚的麻烦去掉、把香味留下」的版本——酸性没了、易氧化没了，但脂溶性与香气保留。植物常把活性酚做成醇或苷来储存，原因就在这里。

### 5.3 多酚 / 天然酚

**定义**：含两个以上酚羟基的天然产物。这个定义是操作性的，不是 IUPAC 的：它既包括分子量 290 的儿茶素，也包括分子量几千的单宁，还包括带糖的花青素。按骨架大致分五族：

| 家族 | 骨架 | 代表物 | 主要来源 |
|---|---|---|---|
| 黄酮类 | C6–C3–C6 | 槲皮素、芦丁、儿茶素、EGCG、矢车菊素、染料木素、柚皮素 | 茶、蓝莓、洋葱、大豆、柑橘 |
| 芪类 | C6–C2–C6 | 白藜芦醇、紫檀芪 | 葡萄皮、红酒、花生 |
| 木脂素 | C6–C3 二聚 | 芝麻素、亚麻木脂素、肠内酯 | 芝麻、亚麻籽 |
| 单宁 | 多酚酯或多聚黄烷 | 没食子单宁、鞣花单宁、原花青素 | 树皮、石榴、红酒、柿子 |
| 其他 | 混合 | 姜黄素、鞣花酸、绿原酸 | 姜黄、莓果、咖啡 |

黄酮这一族内部差异很大，再拆一层：

| 亚类 | 结构特征 | 代表物 | 备注 |
|---|---|---|---|
| 黄酮醇 | 3 位有羟基 | 槲皮素、芦丁 | 芦丁是槲皮素的芸香糖苷 |
| 黄烷-3-醇 | 饱和 C 环 | 儿茶素、EGCG | 茶叶的主体，EGCG 带没食子酰基 |
| 花青素 | 阳离子型 C 环 | 矢车菊素、飞燕草素 | 颜色随 pH 变：黄烊盐→醌型→查尔酮 |
| 异黄酮 | B 环接在 3 位 | 染料木素、大豆苷元 | 弱雌激素活性，大豆异黄酮 |
| 黄烷酮 | 饱和 C 环 + 无 3-OH | 柚皮素、橙皮素 | 柑橘苦味 |
| 查尔酮 | C 环开环 | 根皮素 | 苹果、梨；也是黄酮生合成的第一个产物 |

单宁按结构分两类，用途差别很大：

| 维度 | 可水解单宁 | 缩合单宁 |
|---|---|---|
| 结构 | 没食子酸/鞣花酸与糖的酯 | 黄烷-3-醇的聚合物 |
| 水解性 | 酸/碱可水解 | 不易水解，强酸下缩合成花青素 |
| 代表 | 鞣花单宁、没食子单宁 | 原花青素 |
| 主要来源 | 石榴、橡木、五倍子 | 葡萄籽、树皮、柿子 |
| 工业用途 | 鞣革、食品抗氧化 | 鞣革、葡萄酒结构感 |

必须单独提一句**木质素**：它不是「多酚」这个天然产物类名下的成员，但在化学上是酚聚合物的极端形态，占木材干重的 20–30%，是地球上最大的芳香族碳库。把它放在这里，是为了提醒读者：**酚的聚合不是实验室里的特例，而是植物界的主流建筑方式**。

### 5.4 酚醚、酚酯、酚苷：O-取代的三条路

三条路线共享同一个目的：**把酚羟基「封住」**。封住之后，酸性消失、亲电性下降、抗氧化性大幅下降，但稳定性、脂溶性或水溶性可以被单独调节。自然界与药厂都用这一招。

#### 5.4.1 酚醚（Ar–O–R）

| 代表物 | 结构 | 来源 / 用途 |
|---|---|---|
| 苯甲醚 | 苯–O–CH₃ | 香料、合成中间体 |
| 愈创木酚 | 2-甲氧基苯酚 | 烟熏风味、香兰素前体、药物中间体 |
| 丁香酚 | 4-烯丙基-2-甲氧基苯酚 | 丁香；牙科安抚剂、香料 |
| 异丁香酚 | 丁香酚的丙烯基异构体 | 香料 |
| 黄樟素 | 3,4-亚甲二氧基烯丙苯 | 黄樟油；啮齿类肝致癌，已限用 |
| 芝麻酚 | 3,4-亚甲二氧基苯酚 | 芝麻；抗氧化 |
| BHA | 叔丁基羟基茴香醚 | 食品抗氧化剂 |
| 可待因 | 吗啡的 3-O-甲基醚 | 镇咳/镇痛前药 |
| 甲状腺素（T4） | 两个酪氨酸环以醚键相连 | 甲状腺激素 |

三条值得记住的生物学事实：

1. **COMT 是人体内的「酚醚制造机」**：儿茶酚-O-甲基转移酶用 SAM 把儿茶酚的羟基甲基化，产物正是愈创木酚型结构。多巴胺、肾上腺素、去甲肾上腺素的灭活都走这条路。
2. **木质素单体的甲基化是同一反应**：松柏醇（G 单元）与芥子醇（S 单元）都是 O-甲基化的酚。
3. **醚可以是前药掩蔽**：可待因本身对阿片受体的亲和力很低，靠 CYP2D6 脱甲基变成吗啡才起效；这也是「可待因在超快代谢者身上风险更高」的原因。

> 🔗 **横向关联**：本节「COMT 用 SAM 把儿茶酚甲基化成酚醚」与 [辅因子：金属离子、维生素衍生物与酶的化学外挂](../生物学/辅因子：金属离子、维生素衍生物与酶的化学外挂.md) 的「甲基化与 SAM」一节形成**上下游关系**——那篇讲 SAM 作为甲基供体的辅因子逻辑，这篇讲它具体把酚变成了什么。

#### 5.4.2 酚酯（Ar–O–C(=O)–R）

| 代表物 | 结构 | 用途 / 意义 |
|---|---|---|
| 阿司匹林 | 水杨酸的乙酰酯 | 不可逆乙酰化 COX，抗血小板 |
| 没食子酸丙酯（PG） | 没食子酸的丙酯 | 食品抗氧化剂 E310 |
| EGCG | 儿茶素的 3-没食子酸酯 | 绿茶主体成分 |
| 乙酸丁香酚酯 | 丁香酚的乙酸酯 | 香料、牙科材料 |
| 单宁中的酯键 | 没食子酰基与糖的酯 | 可水解单宁的结构基础 |
| 雌二醇戊酸酯 | 雌二醇 3-OH 的酯 | 长效雌激素前药 |

这里有一个必须划清的边界：**水杨酸甲酯、苯甲酸甲酯不是酚酯**。它们的酰基连在羧酸的氧上，属于「芳香酸酯」；酚酯要求酰基连在**酚氧**上。阿司匹林同时是酚酯（乙酰在酚氧上）和羧酸，所以它既能水解出 salicylate，又能把乙酰基交给酶。

酚酯在药理学上的价值，阿司匹林是最好的例子：乙酰基从酚氧转移到 COX-1 的 Ser529（COX-2 是 Ser516），酶被共价封闭，血小板整个生命周期都无法再合成前列腺素。**一个酚酯键，既是「保护酚羟基不被氧化」的手段，也是「把酚变成弹头」的手段**。

#### 5.4.3 酚苷（Ar–O–糖）

| 代表物 | 苷元 | 来源 / 用途 |
|---|---|---|
| 熊果苷 | 氢醌 | 熊果叶；美白（释放氢醌抑制酪氨酸酶） |
| 水杨苷 | 水杨醇 | 柳树皮；体内释放水杨酸 |
| 松柏苷 | 松柏醇 | 形成层；木质素单体的储存形式 |
| 天麻素 | 对羟基苯甲醇 | 天麻；镇静、头痛 |
| 红景天苷 | 酪醇 | 红景天；抗疲劳 |
| 虎杖苷 | 白藜芦醇 | 虎杖；抗氧化 |
| 七叶苷 | 七叶亭 | 欧洲七叶树；血管与抗炎研究 |

糖基化的四重作用可以一次记全：**增溶、稳定、解毒、储存**。植物把有活性的酚做成苷放在液泡里，等需要时再用 β-葡萄糖苷酶把糖拆掉；人体与肠菌也会拆糖——所以很多「天然酚药」的真正活性形式是苷元，而吸收位置常常在结肠。

> 🔗 **横向关联**：本节「酚苷 = 可水解的储存形式」与 [糖基与糖基化：从糖苷键到糖密码——生命为什么给蛋白质和脂质贴糖](糖基与糖基化：从糖苷键到糖密码——生命为什么给蛋白质和脂质贴糖.md) 的 §2.4「O/N/S/C 四条键」形成**上下游关系**——那篇给出键型稳定性的一般规律（O-糖苷可水解、C-糖苷抗酶），这篇给出它在酚上的具体后果：正因为 O-糖苷能被拆，熊果苷才能当「氢醌的糖衣」、水杨苷才能在体内释放水杨酸。

这里顺手排掉一个常见混淆：苦杏仁苷（amygdalin）不是酚苷，它是**氰醇苷**，水解后释放氢氰酸；但它的「糖基化掩蔽毒性」逻辑与酚苷完全一致。

三条 O-取代路线的总对照如下：

| 维度 | 酚醚 | 酚酯 | 酚苷 |
|---|---|---|---|
| 取代基 | 烷基/芳基 | 酰基 | 糖基 |
| 酸性 | 消失 | 消失 | 消失 |
| 抗氧化性 | 大幅下降 | 下降 | 下降 |
| 水溶性 | 下降（脂溶性↑） | 下降 | **上升** |
| 稳定性 | 高（耐氧化） | 中（可水解） | 高（耐氧化） |
| 生物学角色 | 灭活、储存、前药 | 前药、抗氧化剂 | 储存、运输、解毒 |
| 药物例子 | 可待因 | 阿司匹林 | 熊果苷 |

**收束句**：三条路的差别只在「封条的材料」，共同点是把活泼的酚羟基变成可控的库存——这也是天然酚在植物体内能存到几千种而不互相打架的原因。

### 5.5 酚酸：环上同时有羟基与羧基

酚酸分两型，骨架差一个 C2 单元：

| 类型 | 骨架 | 代表物 | 主要来源 |
|---|---|---|---|
| 羟基苯甲酸型 | C6–C1 | 没食子酸、原儿茶酸、香草酸、丁香酸、水杨酸、龙胆酸、鞣花酸 | 茶、莓果、香草、柳树 |
| 羟基肉桂酸型 | C6–C3 | 对香豆酸、咖啡酸、阿魏酸、芥子酸 | 咖啡、谷物麸皮、果蔬 |

几个必须认识的名字：

- **没食子酸**：3,4,5-三羟基苯甲酸，单宁的构件，也是 Folin 法的标准品。
- **原儿茶酸**：3,4-二羟基苯甲酸，花青素与肠菌代谢的常见产物。
- **香草酸**：4-羟基-3-甲氧基苯甲酸，木质素降解产物，香兰素的前体。
- **阿魏酸**：4-羟基-3-甲氧基肉桂酸，谷物麸皮里最多，可经微生物转化变成香兰素。
- **咖啡酸**：3,4-二羟基肉桂酸，与奎宁酸酯化就是绿原酸。
- **绿原酸**：咖啡酸 + 奎宁酸的酯——注意，这是**芳香酸与醇的酯**，不是酚酯，别和 5.4.2 混。

生合成上，C6–C3 型是苯丙烷路径的直接产物，C6–C1 型则由 C6–C3 经 β-氧化缩短碳链得到；木质素单体则是 C6–C3 型被还原成醇（松柏醇、芥子醇、对香豆醇）。**同一条主干，三个出口：酸、醛、醇**。

### 5.6 五类总对照

| 维度 | 酚类 | 芳香醇 | 多酚 | 酚醚/酚酯/酚苷 | 酚酸 |
|---|---|---|---|---|---|
| 羟基位置 | 芳环 | 侧链 | 芳环，多个 | 芳环，但被封住 | 芳环 |
| 是否含羧基 | 否 | 否 | 少数含 | 否 | **是** |
| 酸性 | pKa≈10 | pKa≈15 | 多变 | 基本无 | 羧酸 pKa≈4–5 |
| 抗氧化性 | 强 | 弱 | 强（聚合后下降） | 弱 | 中—强 |
| 典型代表 | 苯酚、双酚 A | 苯甲醇、酪醇 | 槲皮素、单宁 | 丁香酚、阿司匹林、熊果苷 | 没食子酸、阿魏酸 |
| 典型应用 | 树脂、消毒 | 香料、防腐 | 食品、药物、材料 | 前药、香精、护肤 | 抗氧化、鞣革、香料 |

**收束句**：五类的分界不是「谁更高级」，而是「羟基有没有被占、占了几个、旁边有没有羧基」——三个问题决定了一类物质在生物体内是当建筑材料、当信号、当库存，还是当药物。

## 六、天然酚的来路：四条生合成主线

植物每年造出天文数字的酚，靠的是两条主干加一次拼接。

### 6.1 莽草酸 → 苯丙烷（C6–C3）

磷酸烯醇式丙酮酸（PEP）+ 赤藓糖-4-磷酸 → 分支酸 → 预苯酸 → **苯丙氨酸**。接下来的一步是全篇的枢纽：**PAL（苯丙氨酸解氨酶）**把苯丙氨酸脱氨变成肉桂酸——这是植物从「氨基酸代谢」切换到「苯丙烷代谢」的总闸。肉桂酸经 C4H 羟化成对香豆酸，再由 4CL 活化成就对香豆酰-CoA。

从这个节点往下分四岔：

| 下游 | 关键酶 | 产物 |
|---|---|---|
| 黄酮 | CHS（查尔酮合酶） | 查尔酮 → 各类黄酮 |
| 木质素 | CCR / CAD | 松柏醇、芥子醇、对香豆醇 |
| 芪类 | STS（芪合酶） | 白藜芦醇 |
| 酚酸 | β-氧化 / 还原 | 香草酸、阿魏酸等 |

### 6.2 乙酸–丙二酸 → 聚酮（C6–C1、蒽醌、黄酮 A 环）

第二条主干是聚酮途径：乙酰-CoA 与丙二酰-CoA 反复缩合，长出多酮链，再环化成酚。没食子酸、部分蒽醌、黄酮的 A 环都来自这里。它的特点是「碳链自己长」，不需要苯丙氨酸参与。

### 6.3 拼接：黄酮 = C6–C3–C6

黄酮的骨架是两条路线拼出来的：**B 环 + 中间三碳来自苯丙烷（C6–C3），A 环来自聚酮（C6）**。查尔酮合酶把三个丙二酰-CoA 与一个对香豆酰-CoA 缩合，得到第一个黄酮——查尔酮；之后的异构化、羟化、甲基化、糖基化，才有了槲皮素、花青素、儿茶素这一大家子。

这条「拼接」逻辑解释了一个常被问的问题：为什么黄酮类有那么多种？因为两条上游路线各自可以修饰，拼接之后又能继续修饰，组合数就是乘法。

### 6.4 植物为什么造这么多酚

四个理由，按证据强度排序：

| 功能 | 机制 | 例子 |
|---|---|---|
| 结构 | 木质素交联细胞壁 | 木材 20–30% 干重 |
| 防御 | 单宁沉淀蛋白、酚氧化产物抑菌 | 树皮、未成熟果实 |
| 防晒 | 黄酮吸收 UV-B | 高山植物、叶片表皮 |
| 信号 | 水杨酸参与系统获得性抗性 | 病原侵染后的 SAR |

还有一条「化感」：胡桃醌、紫草素这类醌（酚的氧化产物）会被植物释放到土壤里抑制竞争者——这正是酚与醌两篇笔记在生态层面的接口。

> 🔗 **横向关联**：本节「酚氧化成醌可当化感武器」与 [醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头](醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头.md) 的 §6.3「萘醌：维生素与植物色素的主场」形成**对照关系**——那篇讲醌在植物里的色素与药毒双重身份，这篇讲它的前体酚如何被植物当作防御投资。

## 七、工业中的酚：从煤焦油到双酚 A

### 7.1 异丙苯法与全球规模

今天的苯酚几乎全部来自**异丙苯法（Hock 法）**：苯 + 丙烯 → 异丙苯 → 空气氧化成异丙苯过氧化氢 → 酸催化重排 → 苯酚 + 丙酮。它占全球产量的约 95%，工艺成熟、原料便宜，唯一的结构性约束是**副产丙酮必须有销路**（约 0.6 吨丙酮/吨苯酚）。

全球苯酚产量约 700 万吨/年，产能统计更高；中国是最大的生产与消费国。下游结构大致是：双酚 A 约四到五成、酚醛树脂约三成、己内酰胺与尼龙链一成多，其余是烷基酚、抗氧剂、医药中间体。

> 🔗 **横向关联**：本节「苯酚-丙酮链」与 [钢铁与化工的全球产业格局：从欧洲钢铁业复兴、碳关税到七大基础化工原料](钢铁与化工的全球产业格局：从欧洲钢铁业复兴、碳关税到七大基础化工原料.md) 的「七大基础化工原料」一节形成**上下游关系**——那篇把苯、丙烯放在基础原料层，这篇展示它们如何合成苯酚并继续流向双酚 A 与尼龙。

### 7.2 酚醛树脂：第一种全合成塑料

1907 年 Baekeland 把苯酚与甲醛的缩合做成了可控的工业材料，商品名 Bakelite。它的两条工艺路线必须分清：

| 维度 | Novolac（酸催化） | Resole（碱催化） |
|---|---|---|
| 催化剂 | 酸 | 碱 |
| 配比 | 苯酚过量 | 甲醛过量 |
| 预聚物 | 热塑性线型 | 热固性、可自交联 |
| 固化方式 | 需外加六亚甲基四胺 | 加热即可 |
| 典型用途 | 模塑料、摩擦材料、砂轮 | 胶合板胶、层压板、绝缘件 |

酚醛树脂的意义不只是「第一种塑料」，更在于它证明了**酚的氧化偶联/缩合可以做成结构材料**——这与木质素在植物体内的角色是同一件事，只是工业版把时间压缩到了几分钟。

### 7.3 双酚 A：聚碳酸酯、环氧与热敏纸

双酚 A（BPA）由苯酚与丙酮在酸催化下缩合而成，1891 年就被 Dianin 报道。它的两个酚环是聚合的把手：

| 用途 | 占比（约） | 说明 |
|---|---|---|
| 聚碳酸酯（PC） | 65–70% | 透明、耐冲击、耐热；水瓶、电器外壳、光学件 |
| 环氧树脂 | 25–30% | 涂料、覆铜板、风电叶片、胶粘剂 |
| 其他 | 5% | 热敏纸显色剂、阻燃剂原料、牙科材料 |

监管时间线值得单独记：

| 时间 | 事件 |
|---|---|
| 1930s | Dodds 测试 BPA 的雌激素活性，后来转向 DES |
| 1990s 末 | 低剂量效应研究引发争议 |
| 2011 | 欧盟禁止 BPA 用于婴儿奶瓶 |
| 2012 | 美国 FDA 修订法规，不再允许 BPA 用于奶瓶与吸管杯 |
| 2023 | EFSA 重评估，把每日耐受摄入量下调到 0.2 ng/kg 体重/天 |
| 2024-12 | 欧盟通过 Regulation (EU) 2024/3190，禁止 BPA 用于食品接触材料 |
| 2025-01-20 | 该法规生效；多数食品接触制品可销售至 2026-07-20，部分一次性/重复使用制品过渡到 2028–2029 |

化学上值得注意的一点：BPA 与雌激素受体的结合其实很弱（常引弱几个数量级），但它对**雌激素相关受体 γ（ERRγ）**的结合可达纳摩尔级（常引 Kd ≈ 5.5 nM）。所以「BPA 是弱雌激素」这个说法只描述了它的一半；另一半是它走的是非经典受体的路径。

替代品也不干净：BPS、BPF 的结构与 BPA 同源，已有研究提示类似的内分泌活性。这是典型的「regrettable substitution」——换了一个名字，没有换掉机制。

### 7.4 烷基酚与受阻酚抗氧剂

**烷基酚**是另一条大宗支线：壬基酚聚氧乙烯醚（NPE）曾是洗涤剂与工业表面活性剂的主力，降解后释放**壬基酚**——在水生生物中表现出明确的雌激素效应（鱼类雌性化），欧盟已通过 REACH 限制。

**受阻酚抗氧剂**则是塑料工业的「保险丝」：BHT、BHA、TBHQ 是食品级的小分子版本；高分子材料里用的是分子量更大的受阻酚（如 Irganox 1010/1076 类结构），原理相同——**用位阻保护酚氧自由基，让它稳定到不再引发新链**。

## 八、人体里的酚：儿茶酚胺、黑色素与碘化酪氨酸

### 8.1 儿茶酚胺：一条从酪氨酸出发的四步链

| 步骤 | 酶 | 辅因子 | 产物 |
|---|---|---|---|
| 1 | 酪氨酸羟化酶（TH，限速） | 四氢生物蝶呤 BH4、Fe²⁺ | L-DOPA |
| 2 | 芳香族氨基酸脱羧酶（AADC） | PLP | 多巴胺 |
| 3 | 多巴胺 β-羟化酶（DBH） | 铜、抗坏血酸 | 去甲肾上腺素 |
| 4 | 苯乙醇胺 N-甲基转移酶（PNMT） | SAM | 肾上腺素 |

灭活靠两条酶：MAO 氧化脱氨，COMT 把酚羟基甲基化（又是酚醚）。5-羟色胺严格说也是酚——它的羟基在吲哚环上，化学行为与酚同族。

临床上左旋多巴就是「补前体」：它穿过血脑屏障后被 AADC 变成多巴胺；卡比多巴只在外周抑制 AADC，减少副作用。帕金森病里多巴胺能神经元的死亡、以及多巴胺自氧化生成醌的毒性，是酚化学与神经化学的交叉点。

> 🔗 **横向关联**：本节「酪氨酸→多巴→多巴胺」与 [ADHD神经递质机制](../心理学/ADHD神经递质机制.md) 的「多巴胺通路与浓度—功能关系」形成**互证关系**——那篇讲行为与注意层面的多巴胺功能，这篇补上它的化学前体链与辅因子需求；两篇合起来才能解释「为什么缺铁、缺 BH4 会影响注意」。

> 🔗 **横向关联**：本节「TH 需要 BH4、AADC 需要 PLP、DBH 需要铜与抗坏血酸」与 [辅因子：金属离子、维生素衍生物与酶的化学外挂](../生物学/辅因子：金属离子、维生素衍生物与酶的化学外挂.md) 的「四系统解剖」形成**上下游关系**——那篇讲辅因子的分类与再生，这篇讲它们在一条具体通路上的四个卡点。

### 8.2 黑色素：酚→醌→聚合的教科书

路径很短：酪氨酸 →（酪氨酸酶，双铜）多巴 → 多巴醌 → 分子内环化 → 白多巴色素 → 吲哚-5,6-醌 → 聚合。中途若被半胱氨酸加成，就转向褐黑色素（红黄）；不加成则走真黑色素（黑褐）。

三个临床接口：

- **白化病**：酪氨酸酶功能缺失，黑色素合成中断。
- **白癜风**：黑素细胞被自身免疫清除，酶还在但细胞没了。
- **神经黑色素**：脑内儿茶酚胺自氧化与聚合的产物，帕金森病中黑质多巴胺神经元内的积累与氧化应激相关（相关性明确，因果仍有争议）。

### 8.3 甲状腺激素：碘化酪氨酸与二芳基醚

甲状腺球蛋白（Tg）里的酪氨酸残基被甲状腺过氧化物酶（TPO）碘化，生成 MIT 与 DIT；两个 DIT 偶联成 T4，一个 MIT + 一个 DIT 偶联成 T3。**T4 的两个酪氨酸环之间是一个醚键**——所以甲状腺素本身就是一个「二芳基醚」，这是酚醚在人体里最重要的实例。

两个药理学后果：硫脲类（丙硫氧嘧啶、甲巯咪唑）抑制 TPO；高碘会短暂抑制激素合成（Wolff–Chaikoff 效应），这是「碘过量也能致甲状腺肿」的化学解释。

### 8.4 生育酚与泛醇：抗氧化网络的两个节点

α-生育酚的色满环上有一只酚羟基，这是它唯一的「工作位点」：交出氢、终止脂质过氧化链，然后靠维生素 C 再生。泛醌/泛醇则是「醌↔酚」开关在呼吸链里的版本，与醌类笔记的 §7.1 完全对应。

一个常被忽略的细节：维生素 E 的「抗氧化」不是它自己有多强，而是它**在脂相里位置正确**——它溶在膜里，正好拦截脂质自由基；水相的维生素 C 再把它还原。**抗氧化是一个网络，不是一张排行榜**。

### 8.5 肠菌代谢：尿石素 A 与雌马酚

膳食多酚的真相在结肠。鞣花单宁被菌群水解、脱羟基，生成**尿石素 A**（urolithin A）——它在动物与早期人体试验中显示促进线粒体自噬的作用，是「多酚代谢物比母体更有活性」的代表。大豆苷元则被菌群转化为**雌马酚**（equol），其雌激素活性高于母体；但只有部分人（东亚人群比例较高，西方常引 25–30%）是「雌马酚生产者」。

这条线索的意义：**同一份食物，不同人的代谢产物不同，效果就可能不同**。这是「多酚有益健康」难以做成统一建议的根本原因之一。

## 九、药与毒：同一只羟基的两支部队

### 9.1 药：五类结构，五种用法

| 药物 | 结构类型 | 机制 | 关键点 |
|---|---|---|---|
| 阿司匹林 | 酚酯 + 羧酸 | 不可逆乙酰化 COX-1/COX-2 | 抗血小板；水解产物水杨酸仍有解热镇痛作用 |
| 对乙酰氨基酚 | 酰胺 + 酚 | 中枢 COX 抑制（机制仍有争议） | 过量经 CYP2E1 生成 NAPQI |
| 丙泊酚 | 2,6-二异丙基苯酚 | 增强 GABA_A | 脂乳剂制剂；注射痛；丙泊酚输注综合征 |
| 左旋多巴 | 儿茶酚 + 氨基酸 | 补充多巴胺前体 | 与卡比多巴合用；酚羟基是 COMT 底物 |
| 熊果苷 | 酚苷 | 释放氢醌抑制酪氨酸酶 | 美白；「氢醌的糖衣」 |
| 水杨苷 | 酚苷 | 体内释放水杨酸 | 柳树皮；阿司匹林的前史 |
| 雌二醇酯类 | 酚酯 | 雌激素替代 | 3-OH 酯化延长作用时间 |

**收束句**：这些药的共同点是「酚羟基必须被修饰或必须被保留」——阿司匹林靠修饰它获得选择性，左旋多巴靠保留它才能被转运体识别，熊果苷靠糖基把它送到皮肤里再释放。

### 9.2 毒：四条经典线索

| 毒物 | 结构 | 毒性机制 | 关键事实 |
|---|---|---|---|
| 苯酚 / 甲酚 | 简单酚 | 蛋白变性、膜破坏、经皮吸收 | 腐蚀性；皮肤去污可用聚乙二醇（脂溶性，水冲效果有限） |
| 五氯苯酚（PCP） | 氯代酚 | 解偶联氧化磷酸化、慢性肝/肾/神经损伤 | IARC 1 类；斯德哥尔摩公约 2015 年投票禁止 |
| 双酚 A | 双酚 | 弱 ER 激动、ERRγ 结合、发育毒性证据 | 欧盟 2024/3190 禁食品接触 |
| 壬基酚 | 烷基酚 | 水生雌激素效应 | REACH 限制；鱼类雌性化 |
| 2,3,7,8-TCDD | 二噁英（氯酚副产物） | 芳香烃受体激动 | IARC 1 类；氯酚生产的伴生污染物 |

### 9.3 膳食多酚的生物利用度困境

把前面的线索拼起来，就是一条不太浪漫的结论：

| 环节 | 事实 | 后果 |
|---|---|---|
| 小肠吸收 | 常引 5–10% | 大部分多酚根本没进血液 |
| II 相代谢 | 葡糖醛酸化、硫酸化、甲基化 | 血浆里的形式与试管里的形式不同 |
| 血浆浓度 | 总多酚常 < 1 µM | 远低于体外有效浓度（10–100 µM） |
| 结肠菌群 | 水解、脱羟基、开环 | 生成酚酸、尿石素等新代谢物 |
| 个体差异 | 菌群组成、雌马酚生产者比例 | 同一剂量，效果可能差几倍 |

所以更稳妥的表述是：**多酚的健康效应可能主要来自结肠代谢物与信号通路调节（如 Nrf2），而不是「直接清除自由基」**。高剂量补充剂也不是无风险：高剂量绿茶提取物（EGCG 每日 800 mg 量级）与肝损伤个案相关，EFSA 曾据此给出安全边界提示。

## 十、怎么「看见」酚：显色、Folin 与 LC-MS

### 10.1 FeCl₃ 显色及其边界

酚与三氯化铁生成有色配合物，颜色随取代模式从紫到绿不等（苯酚偏紫，儿茶酚偏绿，间苯二酚偏紫）。这条反应快、便宜，是最经典的酚检验。但它的边界也很清楚：**烯醇、异羟肟酸、部分羧酸也能显色**，所以阳性不等于酚，阴性也不排除酚。

另外两条经典显色：溴水生成 2,4,6-三溴苯酚白色沉淀；Millon 反应对酪氨酸（酚羟基）显红色，是蛋白质化学里的老方法。

### 10.2 Folin–Ciocalteu 与 GAE

Folin–Ciocalteu 试剂是磷钼酸/磷钨酸的混合物，酚把它们还原成蓝色（Mo⁶⁺ → Mo⁵⁺），在 765 nm 比色，结果用**没食子酸当量（GAE）**表示。

这条方法的问题必须写清楚：

- **不是专一的**：抗坏血酸、还原糖、硫醇、芳香胺、Fe²⁺ 都能还原试剂；
- **不是等摩尔响应**：不同酚的显色强度不同，所以「总酚」是一个相对值；
- **必须做空白与标准曲线**，否则跨实验室不可比。

### 10.3 现代方法：LC-MS/MS 为主

| 方法 | 适用 | 要点 |
|---|---|---|
| LC-MS/MS（ESI 负离子） | 绝大多数酚与酚酸 | 酚羟基易去质子化，[M−H]⁻ 信号强；MRM 定量 |
| GC-MS | 挥发性酚（愈创木酚、4-乙基苯酚） | 需衍生化；葡萄酒 Brett 污染的常规检测 |
| NMR | 结构鉴定 | 与 MS 互补，定异构体 |
| HPLC-UV | 常规定量 | 苯甲酸型看 280 nm，肉桂酸型看 320 nm |
| 体外抗氧化 assay | ORAC / DPPH / ABTS / FRAP | 各自测「清除某类自由基」或「还原能力」，不能互相替代 |

> 🔗 **横向关联**：本节「ESI 负离子模式适合酚类」与 [⚗️ 电喷雾电离质谱（ESI-MS）完整学习笔记](⚗️%20电喷雾电离质谱（ESI-MS）完整学习笔记.md) 的「软电离与负离子模式」形成**上下游关系**——那篇讲 ESI 的离子化原理，这篇讲它为什么特别适合测酚。

### 10.4 三种常见误判

1. **把「总酚」当成「多酚含量」**：Folin 值里混着抗坏血酸与糖，数字会系统性偏高。
2. **把「总酚高」当成「抗氧化强」**：不同酚的响应不同，聚合程度越高显色越弱，单宁多的样品反而可能被低估。
3. **把「体外抗氧化」当成「体内有效」**：浓度差一到两个数量级，代谢物结构也变了。

## 十一、收束：先拆误读，再归因 / 延伸 / 个体坐标

### 11.1 七条误读

| 误读 | 纠正 |
|---|---|
| 酚就是苯酚 | 酚是类名，苯酚只是母体 |
| 酚和醇差不多 | pKa 差 10⁶ 倍，氧化性完全不同 |
| 芳香醇就是酚 | 羟基位置决定一切：酸性、显色、氧化产物全变 |
| 多酚 = 抗氧化剂 | 多酚更多是信号分子与菌群底物，直接抗氧化贡献有限 |
| 天然酚一定安全 | 黄樟素、棉酚、高剂量 EGCG、氢醌都有明确风险 |
| 酚醚/酚酯/酚苷只是「衍生物」 | 它们是储存形式与前药，活性常取决于水解释放 |
| 无酚就无毒 | BPS/BPF 同样有内分泌活性，「无 BPA」不等于安全 |

### 11.2 归因：一只羟基与一个环

把全文收束成一句话：**酚的全部用途，都是「一只羟基 + 一个芳环」这四个动作的组合**。

| 动作 | 化学本质 | 被谁征用 |
|---|---|---|
| 交质子 | 弱酸，pKa≈10 | 碱溶酸析、Kolbe–Schmitt、药物成盐策略 |
| 给电子 | 环富电子，亲电取代快 10³–10⁵ | 卤代消毒、偶联染料、酚醛缩合 |
| 交电子 | 酚→酚氧自由基→醌，可逆 | 抗氧化剂、呼吸链、黑色素、褐变 |
| 被取代 | O-甲基化/酰化/糖基化 | 植物储存、COMT 灭活、前药设计 |

这就是「可逆的氧化」四个字的全部含义：**酚之所以能当抗氧化剂、能当电子载体、能当染料前体、能当建筑材料，不是因为它稳定，而是因为它氧化之后还能被还原回来**。

### 11.3 延伸：酚 → 醌 → 聚合的三级台阶

酚化学的下一步永远指向两个方向：

- **向氧化方向走**：酚 → 醌 → 聚合，通向木质素、黑色素、腐殖质、染料与电极材料；
- **向修饰方向走**：酚 → 醚/酯/苷，通向植物储存、药物前药与食品添加剂。

两条路在「设计」层面汇合：想稳定就封住羟基（修饰），想反应就打开羟基（氧化）。液流电池里的 AQDS、生物基酚醛树脂、木质素解聚做香兰素，都是这两条路的不同组合。

> 🔗 **横向关联**：本节「酚→醌→聚合」与 [醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头](醌类：芳香性的赎金——呼吸链的心脏、染料母体与药毒同源的弹头.md) 的 §10「新战场」形成**上下游关系**——那篇讲醌类液流电池与醌基电极，这篇讲它们的原料酚如何从生物质里来；两篇合起来是「生物基芳香化学」的完整链条。

### 11.4 个体坐标：药盒、厨房与护肤品

1. **厨房**：褐变不是「坏了」，是酚被氧化。控制它只需四选一——加热、加酸、加抗坏血酸、隔氧；想让它发生（红茶发酵、黑蒜、陈酿）就反过来做。
2. **药盒**：阿司匹林是酚酯，对乙酰氨基酚是酚，两者都走「酚→醌」的毒性路线但阈值不同；吃退烧药时别同时喝酒（诱导 CYP2E1，把 NAPQI 生成推高）。
3. **护肤品**：熊果苷是酚苷，氢醌是酚；前者是「缓释版」，后者是「直接版」。看到「对苯二酚 / hydroquinone」要当成药，不是普通护肤成分。
4. **饮食**：茶与咖啡里的多酚会拦铁，缺铁人群把饮用时间与正餐错开；多酚补充剂不是「越多越好」，剂量边界真实存在。
