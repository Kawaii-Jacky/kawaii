## 开篇：雷曼兄弟的最后一夜（2008年9月14日）

纽约，曼哈顿，雷曼兄弟总部。

下午5点，CEO Richard Fuld走出办公室，面对等候的高管团队。

"美联储拒绝救助。美国银行和巴克莱的收购谈判都崩了。我们没有选择了。"

**雷曼兄弟，成立于1850年，存活了158年，资产6390亿美元——申请破产保护。**

这是美国历史上最大的企业破产。

**但真正的问题不是雷曼破产，而是雷曼背后的债务网络。**

雷曼持有的债务：6390亿美元。
但雷曼参与的衍生品合约：**35万亿美元**（名义价值）。

什么是衍生品？**赌注。**

**信用违约掉期**（CDS）：我向你买保险，赌某个公司/国家会违约。如果违约，你赔我钱。

**抵押贷款支持证券**（MBS）：把10,000笔房贷打包，切成1,000份"证券"卖给投资者。

**担保债务凭证**（CDO）：把100份MBS再打包，切成10份"超级证券"。

**CDO平方**（CDO²）：把CDO再打包......

**雷曼破产后，这35万亿美元的赌注怎么办？**

谁欠雷曼钱？谁欠了钱给持有雷曼债券的人？这些人又欠谁？

**金融系统是一张巨大的债务网。当一个节点崩溃，整个网可能撕裂。**

9月15日（周一），全球股市暴跌：
- 道琼斯指数：-504点（-4.4%）
- 伦敦富时100：-3.9%
- 日经225：-4.9%

9月16日，美国货币市场基金Reserve Primary Fund（资产650亿美元）宣布"跌破面值"——投资者每1美元只能拿回0.97美元。

**挤兑开始。**

投资者疯狂从货币市场基金撤资：

| 日期 | 货币市场基金总资产（万亿美元） | 单日流出 |
|------|---------------------------|---------|
| 9月10日 | 3.5 | - |
| 9月17日 | 3.3 | -1690亿 |
| 9月18日 | 3.1 | -1440亿 |

**两天流出3130亿美元——相当于总资产的9%。**

货币市场基金是企业短期融资的命脉。它们崩溃意味着：

```
企业无法借到钱付工资 → 裁员 → 消费下降 → 企业倒闭 → 更多裁员 → 经济崩溃
```

9月19日，美国财政部宣布：**政府担保所有货币市场基金**，规模5000亿美元。

9月20日，布什政府向国会提交7000亿美元救助计划（TARP）。

**金融系统没有崩溃——因为政府用纳税人的钱兜底。**

**这一夜，暴露了金融资本主义的本质**：

**风险社会化，利润私人化。**

雷曼赚钱时，利润归股东和高管（Fuld 2000-2007年薪酬：4.84亿美元）。

雷曼破产时，政府用纳税人的钱救整个系统。

**但这不是偶然。这是70年金融化进程的必然结果。**

## 第一章：黄金时代——凯恩斯主义与福利国家（1945-1973）

### 1.1 布雷顿森林体系：美元霸权的建立

新罕布什尔州，布雷顿森林，1944年7月。

44个国家的代表在Mount Washington Hotel开会，设计战后国际货币体系。

**核心协议**：

```
1. 美元与黄金挂钩：35美元 = 1盎司黄金
2. 其他货币与美元挂钩（固定汇率，可调整）
3. 国际货币基金组织（IMF）：提供短期流动性
4. 世界银行（IBRD）：提供长期发展贷款
```

**这是一个以美元为中心的体系。**

为什么其他国家接受？

**因为1944年，美国拥有世界70%的黄金储备。**

| 国家 | 黄金储备（吨，1945年） | 占比 |
|------|---------------------|------|
| 美国 | 17,848 | 70% |
| 英国 | 1,450 | 5.7% |
| 法国 | 540 | 2.1% |
| 其他 | 5,662 | 22.2% |

**布雷顿森林体系的逻辑**：

美元可以兑换黄金 → 各国愿意持有美元 → 美元成为国际储备货币和贸易结算货币 → 美国可以印美元向全世界购买商品 → "嚣张的特权"（exorbitant privilege）

**但这个体系有一个内在矛盾**（"特里芬悖论"，Robert Triffin, 1960）：

```
世界经济增长 → 需要更多美元作为流动性
   ↓
美国必须持续输出美元（贸易逆差）
   ↓
美元越来越多，黄金储备不变
   ↓
美元-黄金比例失衡
   ↓
其他国家怀疑美国能否兑现承诺
   ↓
挤兑美元换黄金
   ↓
体系崩溃
```

**这个预言在1971年应验了。**

### 1.2 黄金三十年：资本主义的黄金时代

1945-1973年，西方资本主义国家经历了史无前例的高速增长。

**年均GDP增长率**：

| 国家/地区 | 1950-1973年均增长 |
|----------|----------------|
| 日本 | 9.3% |
| 西德 | 5.9% |
| 意大利 | 5.6% |
| 法国 | 5.1% |
| 美国 | 3.9% |
| 英国 | 2.9% |
| **OECD平均** | **4.9%** |

**这是什么概念？**

按照72法则（翻倍年数 ≈ 72/年增长率），4.9%的年增长率意味着GDP每15年翻倍。

23年（1950-1973），经济规模增长约3倍。

**为什么增长这么快？**

**原因1：战后重建需求**
- 欧洲、日本的工业在战争中被摧毁
- 重建创造巨大需求
- 马歇尔计划（1948-1952）：美国援助欧洲130亿美元

**原因2：技术扩散**
- 美国的技术（电气化、化工、汽车）扩散到欧洲、日本
- 生产率快速提升

**原因3：廉价能源**
- 石油价格极低

**石油价格**（美元/桶，名义价格）：

| 年份 | 价格 |
|------|------|
| 1950 | 2.57 |
| 1960 | 1.80 |
| 1970 | 1.80 |
| 1973 | 3.29（石油危机前）|

**20年几乎没涨！（扣除通胀，实际价格还在下降）**

廉价石油→廉价能源→廉价运输→廉价生产→高增长。

**原因4：凯恩斯主义政策**
- 政府积极干预经济
- 逆周期调节：衰退时增加支出，繁荣时减少
- 充分就业政策

**失业率**（主要OECD国家平均）：

| 时期 | 失业率 |
|------|--------|
| 1950-1973 | 2-3% |
| 1974-1990 | 6-8% |
| 1991-2007 | 7-9% |

**1950-1973年，失业率长期维持在3%以下——这在资本主义历史上是奇迹。**

**原因5：福利国家**
- 全民医保（英国NHS 1948年建立）
- 养老金
- 失业保险
- 免费教育

**社会支出占GDP比例**（西欧平均）：

| 年份 | 占比 |
|------|------|
| 1950 | 10% |
| 1960 | 13% |
| 1973 | 19% |
| 1980 | 24% |

**原因6：劳资平衡**
- 工会强大
- 工资与生产率同步增长

**美国工资份额**（劳动报酬占GDP比例）：

| 年份 | 工资份额 |
|------|---------|
| 1950 | 64% |
| 1960 | 66% |
| 1970 | 67% |
| 1973 | **68%（峰值）** |

**工人拿走了68%的GDP——这是工业资本主义历史上的最高点。**

**黄金三十年的权力方程**：

$$
GDP = C + I + G
$$

消费（C）增长（工资上涨）→ 投资（I）增长（需求扩大）→ 政府支出（G）托底（福利+基建）→ GDP持续增长 → 利润增长 → 工资上涨 → 正循环

**这是资本主义历史上唯一一次，工人和资本家都满意的时代。**

**但它依赖两个条件：高增长+廉价能源。**

**1973年，两个条件同时消失。**

### 1.3 石油危机：能源的反击

1973年10月6日，赎罪日战争爆发（以色列 vs 埃及+叙利亚）。

10月17日，**阿拉伯石油输出国组织（OAPEC）宣布石油禁运**——禁止向支持以色列的国家出口石油。

**石油价格暴涨**：

| 日期 | 价格（美元/桶） | 涨幅 |
|------|---------------|------|
| 1973年10月 | 3 | - |
| 1973年12月 | 12 | +300% |
| 1974年3月 | 12 | 稳定在高位 |

**3个月涨4倍。**

**第二次石油危机**（1979-1980，伊朗革命+两伊战争）：

| 年份 | 价格 | 涨幅 |
|------|------|------|
| 1978 | 14 | - |
| 1980 | 37 | +164% |
| 1981 | 36 | 高位 |

**石油危机的冲击**：

**GDP增长率**（OECD平均）：

| 时期 | 年均增长 |
|------|---------|
| 1960-1973 | 5.1% |
| 1973-1979 | 2.7% |
| 1980-1982 | 0.3% |

**通货膨胀率**（OECD平均）：

| 时期 | 年均通胀 |
|------|---------|
| 1960-1972 | 3.9% |
| 1973-1979 | 9.6% |
| 1980-1981 | 12.5% |

**滞胀**（stagflation）：经济停滞+通货膨胀——凯恩斯主义无法解释也无法解决。

**凯恩斯主义的逻辑**：
- 通胀高→紧缩政策（加息、减少支出）→经济降温→通胀下降
- 失业高→扩张政策（降息、增加支出）→经济升温→失业下降

**但滞胀是**：通胀高+失业高——两个药方互相矛盾。

**紧缩政策**→失业更高。
**扩张政策**→通胀更高。

**凯恩斯主义失灵了。**

**新自由主义的机会来了。**

## 第二章：新自由主义革命——从福利国家到市场原教旨（1979-2000）

### 2.1 沃尔克冲击：用衰退治疗通胀

华盛顿，1979年8月6日。

Paul Volcker被任命为美联储主席。

**Volcker的使命：不惜一切代价降低通胀。**

**策略：大幅加息，收紧货币供应。**

**联邦基金利率**（美联储的政策利率）：

| 时期 | 利率 |
|------|------|
| 1979年8月 | 11% |
| 1980年12月 | 19% |
| 1981年7月 | **20%（峰值）** |
| 1982年12月 | 8.5% |

**20%的利率——这意味着什么？**

企业贷款成本暴涨→投资停止→裁员→消费下降→经济衰退。

**美国经济数据**：

| 指标 | 1980 | 1981 | 1982 |
|------|------|------|------|
| GDP增长 | -0.3% | 2.5% | -1.8% |
| 失业率 | 7.2% | 8.5% | **10.8%** |
| 通胀率 | 12.5% | 8.9% | 3.8% |

**1982年失业率10.8%——二战后最高。**

**但通胀被压下来了：从12.5%降到3.8%。**

**Volcker用衰退换来了价格稳定。**

**但代价是**：
- 数百万人失业
- 企业大量倒闭
- 工会力量被削弱（失业的人没有谈判筹码）

**这是资本对劳工的反攻**。

**里根总统1981年对空管工会（PATCO）罢工的处理**：

```
空管工人罢工（要求加薪）
   ↓
里根：48小时内返岗，否则全部解雇
   ↓
工人拒绝
   ↓
里根解雇11,345名空管工人，动用军队接管空管
   ↓
工会失败，被永久取缔
```

**这发出了信号：政府站在资本一边，不再保护工会。**

**工会成员率**（美国）：

| 年份 | 工会成员占工人比例 |
|------|------------------|
| 1973 | 26.7% |
| 1983 | 20.1% |
| 2000 | 13.5% |
| 2020 | 10.8% |

**从1973到2020，工会成员率下降60%。**

### 2.2 里根-撒切尔革命：私有化与去监管

**里根（美国，1981-1989）和撒切尔（英国，1979-1990）推行的新自由主义政策**：

**核心理念**（Milton Friedman、Friedrich Hayek）：

```
"政府不是解决问题的方法，政府本身就是问题。"
"市场是最有效的资源配置机制。"
"减税→刺激投资→经济增长（涓滴经济学，trickle-down economics）"
```

**政策措施**：

| 领域 | 措施 |
|------|------|
| **减税** | 削减富人和企业税率 |
| **私有化** | 出售国有企业（电信、航空、能源）|
| **去监管** | 放松金融、航空、电信监管 |
| **削减福利** | 减少社会支出 |
| **反工会** | 削弱工会力量 |
| **自由贸易** | 降低关税，推动全球化 |

**美国最高边际税率**（对富人征税）：

| 年份 | 税率 |
|------|------|
| 1960 | 91% |
| 1970 | 71.75% |
| 1980 | 70% |
| 1988（里根改革后）| **28%** |
| 2024 | 37% |

**从70%降到28%——富人税负暴跌60%。**

**企业所得税率**（美国）：

| 年份 | 税率 |
|------|------|
| 1980 | 46% |
| 1988 | 34% |
| 2018（特朗普税改后）| 21% |

**英国的私有化**（撒切尔政府，1979-1990）：

| 企业 | 私有化年份 | 出售收入（亿英镑） |
|------|-----------|------------------|
| 英国电信 | 1984 | 39 |
| 英国天然气 | 1986 | 54 |
| 英国航空 | 1987 | 9 |
| 英国钢铁 | 1988 | 25 |
| 供水公司 | 1989 | 53 |
| 供电公司 | 1990-1991 | 228 |

**总计私有化收入：超过500亿英镑。**

**撒切尔的逻辑**：
- 国有企业效率低、亏损
- 私有化→引入竞争→提高效率→价格下降→消费者受益

**实际结果**（以供水为例）：

| 指标 | 私有化前（1989） | 私有化后（2019） | 变化 |
|------|---------------|---------------|------|
| 水价（实际） | 100（基准） | 156 | +56% |
| CEO平均薪酬 | £60,000 | £250万 | +41倍 |
| 股东分红（累计）| 0 | 720亿英镑 | - |
| 投资（年均） | 25亿 | 32亿 | +28%（但债务大增）|
| 漏水率 | 25% | 23% | -8%（改善微弱）|

**价格上涨56%，CEO薪酬涨41倍，股东拿走720亿英镑。**

**新自由主义的本质：将公共资产转移给私人资本，将利润私有化、风险社会化。**

### 2.3 金融去监管：潘多拉的盒子

1999年11月12日，美国国会通过《金融服务现代化法案》（Gramm-Leach-Bliley Act）。

**这个法案废除了1933年《格拉斯-斯蒂格尔法》——罗斯福新政建立的、分离商业银行和投资银行的防火墙。**

**《格拉斯-斯蒂格尔法》的逻辑**（1933-1999）：

```
商业银行：吸收存款、发放贷款（低风险，政府担保存款）
投资银行：证券承销、交易、投资（高风险，政府不担保）

两者分离 → 商业银行不能用储户的钱去赌博
```

**1999年废除后**：

```
银行可以同时做商业+投资业务
   ↓
用储户的存款去投资高风险资产
   ↓
赚钱时，银行拿利润
   ↓
亏钱时，政府救助（因为商业银行倒闭会引发系统性风险）
```

**金融去监管的里程碑**：

| 年份 | 政策 | 内容 |
|------|------|------|
| 1980 | 《存款机构放松管制法》 | 取消存款利率上限 |
| 1982 | 《加恩-圣杰曼法》 | 允许储贷机构投资商业地产 |
| 1999 | 废除格拉斯-斯蒂格尔法 | 银行可同时做商业+投资 |
| 2000 | 《商品期货现代化法》 | 衍生品不受监管 |

**2000年法案规定：场外衍生品（OTC derivatives）不受监管——包括后来引爆2008危机的信用违约掉期（CDS）。**

**金融资产占GDP比例**（美国）：

| 年份 | 金融资产/GDP |
|------|-------------|
| 1980 | 400% |
| 1990 | 500% |
| 2000 | 700% |
| 2007 | **1,100%** |

**金融资产膨胀到GDP的11倍——这不是实体经济增长，而是金融资产的自我膨胀（泡沫）。**

**金融业利润占企业总利润比例**（美国）：

| 年份 | 占比 |
|------|------|
| 1950 | 10% |
| 1980 | 15% |
| 2000 | 25% |
| 2007 | **40%** |

**金融业不生产商品，不提供（太多）实体服务，但拿走了40%的企业利润。**

**这就是"金融化"（financialization）。**

## 第三章：互联网泡沫与全球化——虚拟经济的膨胀（1995-2008）

### 3.1 互联网泡沫：网景到宠物网的疯狂

纽约，纳斯达克交易所，1995年8月9日上午9:30。

**网景通信公司（Netscape）首次公开募股（IPO）。**

发行价：28美元。
开盘价：71美元（+154%）。
收盘价：58美元。
**首日涨幅：107%。**

市值：29亿美元——一家成立仅16个月、从未盈利的公司。

**这一天，互联网泡沫开始了。**

**逻辑很简单**：

```
互联网将改变世界
   ↓
任何与互联网有关的公司都有巨大前景
   ↓
不管是否盈利，股价都会涨
   ↓
买入就能赚钱
```

**纳斯达克指数**（科技股为主）：

| 日期 | 指数 | 涨幅 |
|------|------|------|
| 1995年1月 | 755 | - |
| 1998年1月 | 1,619 | +114% |
| 1999年1月 | 2,505 | +55% |
| 2000年3月10日 | **5,048（峰值）** | +102% |

**从1995到2000年峰值：涨6.7倍，年均涨幅47%。**

**疯狂的估值**：

| 公司 | IPO年份 | 市值（峰值，亿美元） | 市盈率（P/E） | 是否盈利 |
|------|--------|------------------|------------|---------|
| 亚马逊 | 1997 | 330 | 无（亏损） | 否 |

### 3.2 中国加入WTO：全球供应链的大重组

**中国得到的**：


**全球供应链重组：从"日本制造"到"中国制造"**

$$
\text{全球利润最大化} = \min(\text{各国工资}) + \min(\text{各国环境成本}) + \min(\text{各国税率})
$$

**资本在全球寻找最低成本：**
- 工资最低的地方生产（中国、越南、孟加拉）
- 税率最低的地方注册（爱尔兰、开曼群岛）

**劳工无法跨国流动，资本可以。**

**这为后来的民粹反弹（特朗普、Brexit）埋下伏笔。**

### 3.3 房地产泡沫：次级贷款到CDO的死亡链条

凤凰城，2005年春天。

**Maria，单身母亲，年收入2.4万美元，在超市做收银员。**

她想买房——美国梦。

房价：32万美元。
传统贷款：需要首付20%（6.4万美元）+ 证明稳定收入。
Maria没有。

**但2005年，她不需要。**

贷款经纪人说："我们有次级贷款（subprime mortgage）。"

```
零首付。
前两年利率2%（"诱惑利率"，teaser rate）。
两年后跳到11%。
不需要收入证明（"忍者贷款"，NINJA：No Income, No Job, no Assets）。
```

Maria签了字。

月供（前两年）：533美元——她能付得起。
月供（两年后）：2,940美元——她的全部收入。

**贷款经纪人为什么不在乎？**

```
经纪人发放贷款
   ↓
24小时内，把贷款卖给投资银行
   ↓
经纪人拿到佣金（贷款额的1-2%）
   ↓
违约风险转移给投资银行（和最终买家）
```

**经纪人的激励：发放越多贷款，赚越多钱——质量不重要。**

**次级贷款发放量**：

| 年份 | 次级贷款（亿美元） | 占住房贷款比例 |
|------|-----------------|--------------|
| 2001 | 1,900 | 8% |
| 2004 | 5,400 | 17% |
| 2006 | **6,000（峰值）** | **20%** |
| 2007 | 2,300 | 10% |

**投资银行买到贷款后做什么？**

**第一步：证券化（MBS，Mortgage-Backed Securities）**

```
买入10,000笔房贷（每笔30万美元）
   ↓
总价值：30亿美元
   ↓
打包成"抵押贷款支持证券"
   ↓
切成1,000份，每份300万美元
   ↓
卖给投资者（养老基金、保险公司、外国央行）
```

**第二步：CDO（Collateralized Debt Obligation，担保债务凭证）**

```
买入100份不同的MBS
   ↓
再次打包
   ↓
切成三层：
- 优先级（Senior）：80%，AAA评级，年收益5%
- 中间级（Mezzanine）：15%，BBB评级，年收益8%
- 股权级（Equity）：5%，无评级，年收益20%（或全亏）
```

**逻辑**：就算底层有些贷款违约，优先级仍然安全（"分散风险"）。

**第三步：CDO²（CDO平方）**

```
把中间级和股权级的CDO再打包
   ↓
再切成优先级、中间级、股权级
   ↓
"垃圾"变成了"AAA"
```

**评级机构（穆迪、标准普尔、惠誉）为什么给AAA？**

```
投资银行付费给评级机构（"谁付费，谁是客户"）
   ↓
评级机构之间竞争（评级太严，客户找别家）
   ↓
评级虚高
```

**影子银行系统**：

| 机构类型 | 功能 | 监管 |
|---------|------|------|
| 商业银行 | 吸收存款、发放贷款 | 严格监管 |
| 投资银行 | 证券承销、交易 | 监管较松 |
| 对冲基金 | 高风险投资 | 几乎不监管 |
| 货币市场基金 | 短期融资 | 不监管 |
| 特殊目的实体（SPV） | 持有证券化资产 | **完全不监管** |

**影子银行系统资产规模**（美国）：

| 年份 | 影子银行资产（万亿美元） | 传统银行资产 |
|------|----------------------|------------|
| 2000 | 10 | 7 |
| 2007 | **20** | 11 |

**影子银行比传统银行更大，但几乎不受监管。**

**房价疯涨**：

**美国房价指数**（Case-Shiller，2000年=100）：

| 年份 | 指数 | 年涨幅 |
|------|------|--------|
| 2000 | 100 | - |
| 2002 | 120 | +10% |
| 2004 | 150 | +12.5% |
| 2006 | **189（峰值）** | +13% |

**6年涨89%——远超工资增长（同期15%）。**

**2006年，泡沫见顶。**

**房价开始下跌→Maria的房子贬值→她的贷款"水下"（房价<贷款额）→利率跳升→月供3000美元→她付不起→违约。**

**次级贷款违约率**：

| 年份 | 违约率 |
|------|--------|
| 2005 | 5.5% |
| 2006 | 7.5% |
| 2007 | **14.4%** |
| 2008 | 19.9% |

**持有MBS和CDO的投资者开始亏损→恐慌抛售→价格暴跌→更多亏损→金融危机。**

## 第四章：次贷危机与大衰退——金融系统的濒死体验（2007-2012）

### 4.1 危机爆发：从贝尔斯登到雷曼崩溃

纽约，贝尔斯登总部，2008年3月14日。

### 4.4 欧债危机：从希腊到欧元区边缘

**为什么危机传染？**

```
希腊债务违约风险上升
   ↓
持有希腊债券的银行（德、法银行）面临亏损
   ↓
投资者担心其他高债务国家（葡萄牙、爱尔兰、西班牙、意大利）
   ↓

   ↓

```

**37%的利率——意味着市场认为希腊随时可能违约。**

**救助与紧缩**：

| 国家 | 救助金额（亿欧元） | 条件 |

**金融资本主义的三大矛盾**：

**1. 债务螺旋**

```
增长放缓→借债刺激→债务增加→利息负担加重→增长更慢→更多借债
```

```

```

**逃生出口**：财富税、大规模再分配或社会动荡

**3. 泡沫-崩溃循环**

```
低利率→资产泡沫→崩溃→政府救助→更低利率→更大泡沫→更大崩溃
```

**逃生出口**：?

**下一次危机的种子已经种下**：

- **主权债务危机**：美国、日本、欧洲债务不可持续
- **金融泡沫**：股市、房地产、加密货币估值极端
- **地缘政治**：中美对抗、俄乌战争、中东冲突
- **气候危机**：极端天气、资源枯竭、强制转型成本

**金融资本主义用70年建立了一个债务驱动、泡沫依赖、不平等加剧的体系。**

**它创造了史无前例的纸面财富（2024年全球亿万富翁财富：14万亿美元，=非洲+拉美全年GDP），也创造了史无前例的脆弱性。**

**每次危机，都用更大规模的救助和更低的利率暂时延缓崩溃——但下一次危机会更猛烈。**

**当央行弹药耗尽（利率已接近零，资产负债表已膨胀10倍），当政府债务高到无法再借（利息吃掉财政收入），当社会不平等引发政治崩溃——**

**系统会如何收场？**

**历史给出三种答案**：

1. **大通胀**（1970年代）：用通胀稀释债务，但撕裂社会
2. **大萧条**（1930年代）：债务通缩，经济崩溃，法西斯主义崛起，世界大战
3. **大重组**（战后）：布雷顿森林体系、债务减免、福利国家重建

**2024年，我们站在哪个路口？**

**这个问题的答案，将在未来10-20年揭晓。**
