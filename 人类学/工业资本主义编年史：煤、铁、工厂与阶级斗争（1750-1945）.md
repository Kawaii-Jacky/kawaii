## 开篇：曼彻斯特的烟囱（1842年）

英格兰，曼彻斯特，清晨5点。

工厂汽笛响起。

8岁的Sarah从床上爬起来——准确说是从地板上爬起来，她和另外5个孩子挤在一间10平米的阁楼里。没有床，稻草铺在地上。

她抓起一块面包（昨天剩下的，已经发霉），塞进嘴里，跑向工厂。

迟到会被扣工资——1便士/小时的工资，迟到1分钟扣1便士。

**工厂的数字**：

| 指标 | 数据 |
|------|------|
| 名称 | Quarry Bank Mill（棉纺厂） |
| 工人数量 | 450人 |
| 童工比例 | 40%（180人，年龄6-16岁）|
| 工作时间 | 14小时/天（夏季），12小时/天（冬季）|
| 工资（成人） | 10-15先令/周 |
| 工资（童工） | 2-4先令/周 |
| 事故率 | 约5%/年（断指、碾压、机器绞伤）|

Sarah的工作：在纺纱机下面爬行，捡掉落的棉絮，清理机器下的棉屑。

**工作流程**：

```
5:30 AM：进厂，开始工作
8:00 AM：早餐（15分钟），稀粥
12:00 PM：午餐（30分钟），面包+奶酪
3:00 PM：继续工作
7:30 PM：下班（夏季）或 5:30 PM（冬季）
```

14小时的工作。在低矮的机器下爬行，呼吸着棉尘弥漫的空气，忍受机器的震耳噪音。

Sarah的父亲是农民，3年前失去土地（圈地运动），举家搬到曼彻斯特。他在码头做搬运工，母亲在另一家纺织厂工作。

一家5口，每周总收入约25先令。

**生活成本**（曼彻斯特，1840年代）：

| 项目 | 周花费（先令） |
|------|--------------|
| 房租 | 3 |
| 面包 | 8 |
| 牛奶 | 1.5 |
| 肉（偶尔） | 2 |
| 煤（取暖/做饭） | 1.5 |
| 衣物（分摊） | 1 |
| 其他 | 2 |
| **总计** | **19** |

收入25先令，开销19先令，剩余6先令——看起来还行。

但这没算：
- 失业（码头搬运工不是每天都有活）
- 疾病（工厂工人肺病、伤残常见，没有医保）
- 冬天煤炭涨价
- 面包价格波动

**一旦任何意外发生，这个家庭就会跌入赤贫**。

曼彻斯特，1842年，有30万人口。其中20万是工人阶级。

城市的天空终年灰暗，300多座工厂的烟囱日夜喷出黑烟。恩格斯在《英国工人阶级状况》（1845）中写道：

```
"空气中弥漫着煤烟和棉尘，太阳透过烟雾只能看到一个暗淡的红点。
街道狭窄、肮脏，污水沟散发恶臭。工人住宅拥挤不堪，一间房住10-12人是常态。
霍乱、伤寒、肺病肆虐。工人的平均寿命——17岁。"
```

**17岁——这不是婴儿死亡率拉低的平均值，而是活到成年的工人，平均活不过35岁。**

但工厂还在扩张。曼彻斯特的棉纺织产量：

| 年份 | 棉布产量（百万码） |
|------|------------------|
| 1780 | 2 |
| 1800 | 15 |
| 1820 | 50 |
| 1840 | 150 |

**60年增长75倍。**

**这是人类历史上第一次，产量的增长速度远远超过人口增长。**

但这个增长，是用Sarah这样的童工、她父母这样的工人，用14小时工作日、用黑烟笼罩的城市、用17岁的平均寿命换来的。

**工业资本主义的权力方程，正在这些烟囱里成形。**

## 第一章：蒸汽机与煤——能源革命的权力转移（1750-1830）

### 1.1 瓦特的改进：从8%到20%的效率跃迁

苏格兰，格拉斯哥，1763年。

仪器修理工James Watt接到一个任务：修理一台纽科门蒸汽机（Newcomen engine）的模型。

纽科门机是1712年发明的，用于煤矿抽水。原理：

```
锅炉烧水 → 蒸汽进入汽缸 → 推动活塞上升 → 冷水喷入汽缸 → 蒸汽冷凝成水 → 汽缸内形成真空 → 大气压把活塞压下 → 活塞带动泵抽水
```

**纽科门机的致命缺陷**：

每个冲程，汽缸都要先加热（蒸汽进入）再冷却（喷冷水）。大量热量浪费在反复加热冷却汽缸上。

**热效率：约1%**。烧100份煤，只有1份转化为机械功，99份浪费。

Watt意识到问题：冷凝和做功不应该在同一个汽缸里。

**瓦特的改进**（1765年专利）：

```
汽缸始终保持高温（蒸汽始终充满）
    ↓
蒸汽做功后，不是在汽缸里冷凝，而是导入一个单独的"冷凝器"
    ↓
冷凝器保持低温，汽缸保持高温，不再反复加热冷却
    ↓
热效率提升到 8-12%
```

**但这只是第一步**。

1781-1784年，Watt又做了三个关键改进：

1. **双动式**：蒸汽推动活塞上升和下降都做功（原来只有下降做功）——功率翻倍
2. **旋转运动**：活塞的往复运动转化为轮轴的旋转运动——可以驱动机器，不只是抽水
3. **调速器**：自动调节蒸汽流量，保持转速稳定

**到1800年，瓦特蒸汽机的热效率达到20%**——是纽科门机的20倍。

**能源效率的经济学**：

| 机型 | 热效率 | 每马力每小时耗煤（磅） | 每马力每年煤成本（先令，工作300天）|
|------|--------|---------------------|--------------------------|
| 纽科门机（1712） | 1% | 50 | 300 |
| 瓦特机（1775） | 8% | 6 | 36 |
| 瓦特机（1800） | 20% | 2.5 | 15 |

**瓦特机每马力每年节省285先令煤成本**。

一个100马力的瓦特机，每年节省28,500先令 = 1,425英镑。

**瓦特机的价格**（1800年代）：约1,000-2,000英镑（取决于马力）。

**投资回报期：1-2年**。

**瓦特与博尔顿的商业模式**：

Watt与工厂主Matthew Boulton合作，成立Boulton & Watt公司。他们不是卖蒸汽机，而是**租赁**：

```
客户购买纽科门机（便宜，技术公开）
    ↓
Boulton & Watt免费改造成瓦特机
    ↓
客户每年支付"节省燃料成本的1/3"作为专利费
    ↓
支付25年（专利保护期）
```

**这是人类历史上第一个基于"效率提升"的商业模式**——不是卖产品，而是卖节约。

**瓦特蒸汽机的扩散**：

| 年份 | 英国运行的瓦特机（台） | 总马力 |
|------|---------------------|--------|
| 1775 | 2 | 20 |
| 1800 | 500 | 10,000 |
| 1815 | 1,500 | 30,000 |
| 1830 | 3,000+ | 60,000+ |

**30,000马力意味着什么？**

一匹马的功率约0.75马力（持续工作）。30,000马力 = 40,000匹马的持续工作能力。

但马要吃草、休息、生病。蒸汽机不吃不睡，24小时工作。

**30,000马力蒸汽机 = 约100,000-150,000匹马的实际生产能力**。

英国在1800年有约100万匹役马。到1830年，蒸汽机相当于增加了15%的"马力"。

**但关键不是数量，而是灵活性**：蒸汽机可以建在任何有煤的地方，不需要草地和马厩。

**这解放了工业选址，为工厂集中化创造了条件。**

### 1.2 煤：地下的阳光

英国，1700年。

木材短缺。森林被砍伐用于造船、建筑、冶铁。木炭价格飙升。

**煤炭成为救星**——但煤炭有个问题：越挖越深，地下水渗入矿井，必须抽水。

**纽科门蒸汽机就是为此发明的**——用煤烧蒸汽机抽水，挖出更多煤。

这是一个自我强化的循环：

```
煤 → 蒸汽机 → 抽水 → 更多煤 → 更多蒸汽机 → 更深矿井 → 更多煤
```

**英国煤炭产量**：

| 年份 | 产量（百万吨） | 人均（公斤/年） |
|------|--------------|---------------|
| 1700 | 3 | 500 |
| 1750 | 5 | 800 |
| 1800 | 15 | 1,500 |
| 1830 | 30 | 2,000 |
| 1850 | 50 | 2,500 |

**从1700到1850年，煤炭产量增长17倍。**

**煤的能量密度**：

| 燃料 | 热值（MJ/kg） | 相对于木材 |
|------|-------------|-----------|
| 木材（干） | 15 | 1倍 |
| 木炭 | 30 | 2倍 |
| 煤炭 | 25-35 | 2-2.3倍 |

煤的能量密度是木材的2倍，但**关键优势是储量**。

英国的森林在17世纪几乎被砍光。但英国有煤——数十亿吨，足够烧几百年。

**煤是"地下的阳光"**（古代植物通过光合作用储存的太阳能）。

工业革命本质上是：**人类学会了开采地下储存的数亿年的太阳能，而不是依赖每年从太阳获得的流量**。

**能源跃迁的对比**：

| 社会 | 主要能源 | 年人均能源（GJ） | 能源类型 |
|------|---------|----------------|---------|
| 农业社会 | 人力+畜力+木材 | 10-15 | 流量（每年太阳能） |
| 工业社会（1850） | 煤炭+蒸汽机 | 50-80 | 存量（地下古代太阳能）|
| 现代社会（2000） | 石油+天然气+煤+核+电 | 150-300 | 存量+部分流量 |

**工业革命是人类第一次突破每年太阳能流量的限制。**

### 1.3 铁路：运输革命

英格兰，1825年9月27日。

Stockton到Darlington的铁路正式通车——世界上第一条客运铁路。

机车：*Locomotion No. 1*，设计师George Stephenson。

**第一次运行**：
- 速度：15英里/小时（24公里/小时）
- 载客：450人（远超设计容量，人们挤在煤车上）
- 距离：25英里（40公里）

**这看起来不快**——马车也能达到10-12英里/小时。

但关键不是速度，而是**运载能力**和**成本**。

**运输成本对比**（1830年代，英国）：

| 运输方式 | 成本（便士/吨·英里） | 相对于运河 |
|---------|---------------------|-----------|
| 马车（陆路） | 24 | 12倍 |
| 运河 | 2 | 1倍 |
| 铁路（早期） | 1.5 | 0.75倍 |
| 铁路（1850年代）| 0.5 | 0.25倍 |

**铁路比马车便宜20-50倍**。

**利物浦-曼彻斯特铁路**（1830年开通）的经济影响：

| 指标 | 开通前（运河） | 开通后（铁路） |
|------|--------------|--------------|
| 运输时间 | 3天 | 2小时 |
| 货运成本（煤炭，先令/吨） | 15 | 5 |
| 客运价格（2等，先令） | 10（马车） | 4 |
| 年货运量（万吨） | 10 | 30（1835年）|

**铁路把曼彻斯特的煤炭成本降低了67%**。

这直接降低了工厂运营成本，提高了利润率，刺激了更多投资。

**英国铁路里程**：

| 年份 | 铁路里程（英里） | 累计投资（百万英镑） |
|------|----------------|-------------------|
| 1830 | 100 | 3 |
| 1840 | 1,500 | 50 |
| 1850 | 6,600 | 240 |
| 1860 | 10,400 | 400 |

**30年投资400百万英镑**——相当于英国GDP的20-25%。

**铁路狂热**（Railway Mania, 1840s）：投机泡沫，数百家铁路公司成立，大部分破产，但基础设施留下了。

**铁路的系统性影响**：

1. **降低运输成本** → 扩大市场半径 → 工厂可以服务更大区域
2. **加速原材料流动** → 煤炭、铁矿、棉花更快到达工厂
3. **促进钢铁需求** → 铁轨、机车、桥梁 → 钢铁工业爆发
4. **标准化时间** → 铁路需要统一时刻表 → 全国统一时间（Greenwich Mean Time）

**铁路对经济的乘数效应**：

铁路不只是运输工具，它拉动了整个工业体系：

| 直接需求 | 1英里铁路所需物资（1850年代） |
|---------|--------------------------|
| 铁轨 | 60吨铁 |
| 枕木 | 2,640根木材 |
| 道钉 | 14,000根 |
| 土方工程 | 20,000立方码 |
| 机车（每50英里） | 1台（40吨铁+钢） |

**间接拉动**：

```
铁路建设 → 铁轨需求 → 钢铁厂扩张 → 煤炭需求 → 煤矿扩张 → 蒸汽机需求 → 机械厂扩张
         → 机车需求 → 机械工业发展
         → 桥梁隧道 → 土木工程技术进步
         → 资本需求 → 金融市场发展（铁路债券、股票）
```

**英国1840-1850年代，铁路投资占固定资本形成的30-50%——成为经济增长的主引擎。**

**第一次工业革命的区域扩散时间线**：

| 国家/地区 | 启动时间 | 标志事件 | 追赶策略 |
|----------|---------|---------|---------|
| **英国** | 1760s | 瓦特蒸汽机 | 原创 |
| **比利时** | 1820s | 列日机械工业 | 引进英国技术+政府支持 |
| **法国** | 1830s | 北部煤矿+纺织 | 缓慢渐进，保护主义 |
| **德国** | 1840s | 鲁尔工业区 | 后发优势：直接建最新工厂 |
| **美国** | 1850s | 北方工业带 | 劳动力短缺→机械化更激进 |
| **俄国** | 1890s | 圣彼得堡+莫斯科 | 国家主导，外资涌入 |
| **日本** | 1870s | 明治维新 | 政府强制现代化 |

**扩散的权力结构**：

先工业化国家通过**技术垄断**（专利、熟练工禁止出境）维持优势20-30年，后发国家通过**工业间谍**+**政府保护**+**低工资优势**追赶。

**工业资本主义的三位一体：蒸汽机、煤炭、铁路**。

它们相互强化：
- 煤驱动蒸汽机
- 蒸汽机挖煤、炼铁、驱动机车
- 铁路运煤、运铁、运产品

**这是一个自我加速的正反馈循环。**

## 第二章：工厂制度与劳动异化——马克思的诊断（1830-1880）

### 2.1 分工的极致：流水线的前身

伯明翰，1835年。

一家别针工厂。Adam Smith在《国富论》（1776）中用别针工厂举例，描述分工的效率。

**别针制造的分工**（18道工序）：

| 工序 | 操作 | 工人技能 |
|------|------|---------|
| 1 | 拉铁丝 | 半熟练 |
| 2 | 拉直 | 非熟练 |
| 3 | 切断 | 非熟练 |
| 4 | 削尖一端 | 半熟练 |
| 5 | 磨尖 | 非熟练 |
| 6-10 | 制作针头（5道工序）| 熟练 |
| 11 | 装针头 | 半熟练 |
| 12 | 磨白针头 | 非熟练 |
| 13-18 | 包装（6道工序） | 非熟练 |

**Smith的计算**：

- 1个熟练工人，独立完成全部18道工序：每天最多20根别针
- 10个工人分工合作：每天48,000根别针 = 人均4,800根
- **生产率提升240倍**

但Smith没有看到的是：**分工的另一面**。

**工人的视角**：

*工匠时代*（分工前）：
- 我制作整个别针
- 我掌握完整技艺
- 我的劳动有完整意义

*工厂时代*（分工后）：
- 我只做第3道工序：切断铁丝
- 每天重复同一动作8,000-10,000次
- 我不知道我在做什么，只知道切断铁丝

**Marx的"异化"理论**（《1844年经济学哲学手稿》、《资本论》）：

工人在资本主义生产中经历四重异化：

| 异化维度 | 表现 |
|---------|------|
| **产品异化** | 工人生产的别针不属于自己，属于资本家 |
| **过程异化** | 劳动过程由资本家控制，工人只是机器的附件 |
| **类本质异化** | 人的创造性被剥夺，劳动变成机械重复 |
| **人际异化** | 工人之间竞争（被迫压低工资），而非合作 |

**"工人生产的财富越多，他自己越贫穷。"**

### 2.2 剩余价值：资本主义的数学

Marx在《资本论》（1867）中给出了资本主义的核心方程：

**剩余价值率**：

$$
m' = \frac{s}{v}
$$

其中：
- $m'$：剩余价值率（剥削率）
- $s$：剩余价值（资本家拿走的）
- $v$：可变资本（工资）

**Marx的例子**（英国棉纺厂，1860年代）：

| 项目 | 金额（英镑） |
|------|------------|
| 原料（棉花） | 372 |
| 机器折旧 | 54 |
| 工资 | 100 |
| **总成本** | **526** |
| | |
| 产品售价 | 600 |
| **利润** | **74** |

**剩余价值率** = 74 / 100 = **74%**

翻译：工人创造的价值是174（工资100 + 剩余价值74），但只拿回100。资本家拿走74。

**工人每工作8小时，约3.4小时是为自己劳动，4.6小时是为资本家劳动。**

**但Marx的洞察不止于此**。他追问：**为什么工人创造的价值超过工资？**

答案：**劳动力商品的特殊性**。

```
劳动力的价值 = 维持工人及其家庭生存、繁衍的成本
    ≈ 食物 + 住房 + 衣物 + 子女抚养
    ≈ 100英镑/年（1860年代英国工人）

但劳动力的"使用价值"（创造的价值） > 劳动力的价值（工资）
```

**资本家购买劳动力，就像购买一台机器**——支付其"价值"（工资），但获得其"使用价值"（产出）。

差额就是剩余价值。

**工业资本主义的权力方程**（Marx版本）：

$$
\Pi = (P - C) \cdot Q = s \cdot Q
$$

其中：
- $\Pi$：总利润
- $s$：单位商品的剩余价值
- $Q$：产量

**要增加利润，两条路**：

1. **提高剩余价值率**：延长工作时间、降低工资、提高劳动强度
2. **增加产量**：机器化、扩大规模

**19世纪资本家两条路都走**。

### 2.3 童工与工作时间：极限压榨

英国，1833年，议会调查童工问题。

**证词**（纺织厂童工，14岁女孩）：

```
问：你几岁开始工作？
答：7岁。

问：每天工作多久？
答：从早上5点到晚上9点。

问：中间休息吗？
答：早餐15分钟，午餐30分钟。

问：累吗？
答：非常累。经常因为疲劳被机器打伤。

问：打伤过吗？
答：是的，我的手指被纺纱机卷进去，断了两根。

问：得到赔偿吗？
答：没有。工头说是我自己不小心。
```

**英国工厂工作时间**（1830年代，纺织业）：

| 年龄 | 每天工作时间 | 每周 | 每年（52周） |
|------|------------|------|-------------|
| 成人 | 14-16小时 | 84-96小时 | 4,368-4,992小时 |
| 少年（12-18）| 12-14小时 | 72-84小时 | 3,744-4,368小时 |
| 儿童（6-12） | 10-12小时 | 60-72小时 | 3,120-3,744小时 |

**对比**：
- 现代标准：每周40小时，每年约2,000小时（含假期）
- 1830年代工人：每年4,000-5,000小时
- **工作量是现代的2-2.5倍**

**为什么雇佣童工？**

| 维度 | 童工 | 成人 |
|------|------|------|
| 工资 | 成人的1/3-1/4 | 10-15先令/周 |
| 服从性 | 高（易于管教） | 低（可能反抗） |
| 体型 | 小，能在机器下爬行 | 大，某些工作不便 |
| 替代性 | 高（随时可替换） | 中 |

**工厂纪律的暴力执行**：

工厂主如何确保工人服从14小时工作制？**罚款、体罚、黑名单。**

**曼彻斯特某纺织厂罚款表**（1830年代）：

| 违规行为 | 罚款（先令） | 相当于工资 |
|---------|------------|----------|
| 迟到5分钟 | 0.5 | 半小时工资 |
| 唱歌、吹口哨 | 1 | 1小时工资 |
| 开窗通风（违反规定）| 1 | 1小时工资 |
| 与同事说话 | 0.5 | 半小时工资 |
| 损坏工具 | 2-5 | 半天工资 |
| 缺勤1天 | 扣3天工资 | - |

**一周罚款可能高达工资的10-20%。**

**体罚（童工）**：

```
用皮带抽打手掌或背部
长时间罚站（12小时连续工作后再罚站2小时）
"重物惩罚"：背负重物绕工厂行走
```

**1833年议会调查，一名工头承认："我每天平均打5-6个孩子，用皮带或棍子。他们累得动作慢，不打就跟不上机器节奏。"**

**黑名单制度**：

被开除的"麻烦工人"（抱怨待遇、试图组织工会）会被列入黑名单，传阅给其他工厂主，**在整个地区失去就业机会**。

**童工不是特例，而是系统性的**。

**英国童工比例**（1830年代）：

| 行业 | 童工占比 |
|------|---------|
| 纺织 | 30-40% |
| 煤矿 | 25-35% |
| 陶瓷 | 40-50% |
| 火柴厂 | 50-60% |

**议会不得不干预**。

**《工厂法》（Factory Acts）的演进**：

| 年份 | 法案内容 | 执行 |
|------|---------|------|
| 1802 | 学徒工不得超过12小时/天 | 几乎不执行 |
| 1819 | 9岁以下禁止在棉纺厂工作 | 执行不力 |
| 1833 | 9岁以下禁止；9-13岁每天8小时 | 开始有监察员 |
| 1844 | 8岁以下禁止；13-18岁每天12小时；女工同等待遇 | 逐步执行 |
| 1847 | 10小时工作日（女工和少年）| 执行 |

**资本家的抵抗**：每次立法都遭到强烈反对，理由是"会摧毁英国工业的竞争力"。

**但工厂法通过后，工业并未崩溃**——反而因劳动力质量提高、技术改进而继续增长。

**这证明：极限压榨不是工业化的必要条件，而是资本家的选择。**

### 2.4 曼彻斯特的贫民窟：城市化的暗面

恩格斯在《英国工人阶级状况》（1845）中描述曼彻斯特工人区：

**住房**：
```
一栋房子，3层，每层2间房。
每间房住2-3个家庭，共10-15人。
房间面积：10-15平方米。
无窗户（或很小），无通风。
地面潮湿，墙壁发霉。
```

**卫生**：
```
无自来水。
水源：街角的公共水泵，1个水泵服务200-300人。
厕所：1个户外旱厕服务50-100人。
垃圾：堆在街上，几周才清理一次。
污水：街道中央的明沟。
```

**曼彻斯特贫民窟详细卫生统计**（1840年代，恩格斯调查）：

| 指标 | 数据 | 对比（中产区） |
|------|------|-------------|
| 人均居住面积 | 3-5平方米 | 15-25平方米 |
| 人均水泵数量 | 1/250人 | 1/30人 |
| 厕所数量 | 1/60人 | 1户1厕 |
| 排泄物处理 | 粪坑，每月清空1次 | 下水道 |
| 街道宽度 | 2-4米（极窄） | 8-12米 |
| 通风采光 | 背靠背房屋，无后窗 | 独立房屋，四面采光 |
| 地面 | 泥土地或破损石板，积水 | 木地板或完整石板 |

**疾病率对比**（每千人/年，曼彻斯特1840年代）：

| 疾病 | 工人区 | 中产区 | 比率 |
|------|-------|-------|------|
| 伤寒 | 8.5 | 1.2 | 7倍 |
| 肺结核 | 12.0 | 3.5 | 3.4倍 |
| 霍乱（疫情年） | 25.0 | 5.0 | 5倍 |
| 婴儿死亡率（‰） | 280 | 120 | 2.3倍 |

**工人区28%的婴儿活不到1岁。**

**人口密度**（曼彻斯特，1840年代）：

| 区域 | 人/英亩 | 对比 |
|------|---------|------|
| 工人区 | 300-400 | - |
| 中产区 | 50-80 | 工人区的1/5 |
| 郊区 | 20-30 | 工人区的1/10 |

**疾病死亡率**（曼彻斯特，1840年代，每千人）：

| 阶级 | 死亡率 | 平均寿命 |
|------|--------|---------|
| 上层阶级 | 10 | 55岁 |
| 中产阶级 | 20 | 38岁 |
| 工人阶级 | 40 | 17岁 |

**工人阶级的平均寿命是上层的1/3**。

**霍乱疫情**（1832, 1849, 1854）：每次杀死数万人，主要是工人区。

**为什么不改善？**

**资本家的逻辑**：
```
改善住房 → 提高租金或建设成本 → 工人要求涨工资 → 利润下降
```

**市政府的财政**：
- 主要收入来自财产税（property tax）
- 富人区财产价值高，但富人有政治影响力，能压低税率
- 工人区财产价值低，税收少
- 结果：工人区得不到公共服务投资（下水道、自来水、街道清洁）

**19世纪工业城市的权力方程**：

$$
\text{工人生活质量} \propto \frac{1}{\text{资本积累速度}}
$$

资本积累越快，工人被压榨越狠。

**但压榨有极限——当工人开始组织起来反抗时。**

## 第三章：工人阶级的觉醒——从自发斗争到有组织运动（1800-1914）

### 3.1 卢德运动：砸机器的工人

英格兰，1811年3月。

诺丁汉郡的针织工人夜里闯入工厂，用大锤砸毁织袜机。

领头者自称"Ned Ludd将军"的追随者（Luddites）——Ned Ludd可能是虚构的英雄人物。

**为什么砸机器？**

**织袜业的机器化**：

| 年份 | 手工织机 | 机械织机 | 手工工人工资（先令/周） |
|------|---------|---------|---------------------|
| 1800 | 20,000 | 500 | 15 |
| 1810 | 15,000 | 3,000 | 10 |
| 1815 | 10,000 | 8,000 | 6 |

机器不仅替代了工人，还压低了剩余手工工人的工资。

**卢德派的诉求**：
- 销毁广幅织机（wide frames）和剪毛机（shearing frames）
- 恢复手工织工的工资
- 限制学徒数量（防止劳动力过剩）

**卢德运动的规模**（1811-1816）：

| 年份 | 机器被毁（台） | 参与人数（估计） | 逮捕人数 |
|------|--------------|----------------|---------|
| 1811 | ~200 | 数千 | 60 |
| 1812 | ~300 | 数千 | 140 |
| 1813-16 | ~100 | 数百 | 30 |

**卢德运动的地理分布与时间线**：

| 时期 | 地区 | 主要行业 | 典型事件 |
|------|------|---------|---------|
| **1811年3-11月** | 诺丁汉郡 | 针织业 | 砸毁200台宽幅织袜机 |
| **1812年1-4月** | 约克郡西区 | 毛纺业 | 攻击剪毛机工厂，4月Rawfolds Mill袭击：2名卢德派被打死 |
| **1812年4-5月** | 兰开夏郡 | 棉纺业 | 烧毁Westhoughton工厂，12人后被绞死 |
| **1812年5月** | 柴郡 | 丝织业 | 砸毁力织机 |
| **1816年** | 莱斯特郡 | 针织业 | 小规模复燃后彻底镇压 |

**地理核心**：英格兰中部-北部工业带（诺丁汉-约克-兰开夏三角区）。

**卢德运动失败了——但它标志着工人意识觉醒的开始。**

工人意识到：
1. 他们有共同利益
2. 他们的敌人不是机器本身，而是**控制机器的资本家**
3. 需要有组织的集体行动

### 3.2 宪章运动：第一个工人政治运动

英国，1838年。

**《人民宪章》（People's Charter）发布，提出六大诉求**：

1. **普选权**（所有成年男性，无财产限制）
2. **秘密投票**（防止地主、雇主威胁）
3. **议员无财产资格限制**（工人也能当议员）
4. **议员领薪**（否则只有富人能当全职议员）
5. **选区平等**（每个选区人口相等）
6. **年度议会选举**（增强问责）

**现状**（1830年代英国）：

| 指标 | 数据 |
|------|------|
| 英国人口 | 1600万 |
| 有投票权的人 | 65万（仅4%）|
| 投票资格 | 年收入10英镑以上的财产所有者 |
| 工人有投票权吗？ | 极少（绝大多数达不到财产门槛）|

**宪章运动的组织**：

- 1839年：第一次请愿，125万签名 → 议会拒绝（235票反对，46票赞成）
- 1842年：第二次请愿，330万签名 → 议会拒绝（287票反对，49票赞成）
- 1848年：第三次请愿，声称580万签名（实际约200万，有伪造） → 议会拒绝

**三次议会辩论的核心分歧**：

**1839年第一次请愿辩论**（7月12日）：

| 阵营 | 代表发言 | 核心论点 |
|------|---------|---------|
| 支持者（激进派）| Thomas Attwood议员 | "125万人请愿，代表数百万无声者。拒绝将导致革命。" |
| 反对者（保守派）| Robert Peel（前首相）| "普选权将导致无产者多数，摧毁财产权。" |
| 反对者（辉格党）| Lord John Russell | "宪法改革必须渐进，1832年改革已足够。" |

**表决结果：235:46惨败。**

**1842年第二次请愿辩论**（5月3日）：

| 阵营 | 代表发言 | 核心论点 |
|------|---------|---------|
| 支持者 | Thomas Duncombe议员 | "330万签名，是1839年的2.6倍。工人在饥饿边缘，议会必须回应。" |
| 反对者 | Thomas Macaulay（历史学家/议员）| "工人阶级无教育，给他们投票权=给暴民治国权。" |
| 反对者 | Benjamin Disraeli（保守党）| "宪章运动是煽动者操纵无知群众的工具。" |

**表决结果：287:49再次惨败。**

工人意识到：**议会路线在现有权力结构下无法成功。**

**三次都失败了。**

**但宪章运动的意义**：

1. **第一个全国性的工人政治组织**——此前工人斗争都是地方性、行业性的
2. **政治意识**——工人意识到经济斗争（涨工资）必须结合政治斗争（争取投票权）
3. **长期影响**——宪章的六大诉求，除了"年度选举"，其余五条到20世纪初全部实现

**英国选举权的扩大**：

| 年份 | 改革法案 | 有投票权的人（万） | 占成年男性比例 |
|------|---------|------------------|---------------|
| 1832 | 第一次改革法案 | 65 | 7% |
| 1867 | 第二次改革法案 | 200 | 16% |
| 1884 | 第三次改革法案 | 500 | 40% |
| 1918 | 第四次改革法案 | 2100（含女性）| 100%（男性）+30%（女性）|
| 1928 | 第五次改革法案 | 2900 | 100%（男性+女性）|

**宪章运动虽然在1840年代失败，但它推动的民主化进程，在后50-80年逐步实现。**

### 3.3 工会的兴起：集体谈判的力量

英国，1850年代。

**新模式工会**（New Model Unions）出现——不同于早期的激进工会，它们采取温和、务实策略。

**代表：全国机械工人联合会**（Amalgamated Society of Engineers, ASE，1851年成立）

**新模式工会的特点**：

| 维度 | 旧工会（1800-1840s） | 新模式工会（1850s-1900s） |
|------|-------------------|----------------------|
| 策略 | 激进（罢工、砸机器） | 温和（集体谈判） |
| 成员 | 单一行业、地方性 | 跨地区、全国性 |
| 资金 | 少，难以持续 | 高会费，建立罢工基金 |
| 合法性 | 被镇压 | 逐步获得法律承认 |
| 目标 | 政治革命 | 改善工资、工时、工作条件 |

**工会会费与福利**（ASE，1860年代）：

| 项目 | 金额 |
|------|------|
| 周会费 | 1先令 |
| 罢工津贴 | 10先令/周（罢工期间） |
| 失业救济 | 6先令/周（失业时） |
| 疾病津贴 | 10先令/周（生病时） |
| 丧葬费 | 12英镑 |

**ASE财务报表**（1867年度）：

| 收入项目 | 金额（英镑） | 支出项目 | 金额（英镑） |
|---------|-----------|---------|-----------|
| 会费收入 | 85,420 | 失业救济 | 28,650 |
| 入会费 | 3,240 | 疾病津贴 | 22,180 |
| 罚款收入 | 850 | 罢工津贴 | 4,520 |
| 投资收益 | 2,100 | 丧葬费 | 5,670 |
| | | 行政开支 | 8,940 |
| | | 法律费用 | 1,820 |
| **总收入** | **91,610** | **总支出** | **71,780** |
| | | **年末余额** | **19,830** |

**会员数**（1867）：33,560人。

**人均年会费**：52先令（相当于熟练工人2.5周工资）。

**罢工津贴仅占支出6.3%**——大部分钱用于失业、疾病等社会保障，这是工会能持续吸引会员的关键。

**工会的经济学**：

```
工会收集会费 → 建立罢工基金 → 工人罢工时有收入支持 → 可以坚持更久 → 资本家被迫谈判
```

**没有罢工基金，罢工往往3-7天就瓦解（工人饿肚子）。有了基金，可以坚持几周甚至几个月。**

**工会成员数**（英国）：

| 年份 | 工会成员（万） | 占工人比例 |
|------|--------------|-----------|
| 1850 | 10 | 2% |
| 1870 | 50 | 8% |
| 1900 | 200 | 15% |
| 1914 | 400 | 25% |

**工会合法化的里程碑**：

- **1871年《工会法》（Trade Union Act）**：承认工会的合法地位，允许注册、拥有财产
- **1875年《雇主与工人法》（Employers and Workmen Act）**：废除"违反雇佣合同"的刑事处罚，工人罢工不再是犯罪

**工会的成就**（1850-1914）：

| 指标 | 1850年 | 1914年 |
|------|--------|--------|
| 平均周工时 | 60-70 | 50-55 |
| 实际工资（1850=100） | 100 | 180 |
| 童工（10岁以下） | 普遍 | 几乎消失 |

**工会通过集体谈判，把部分生产力提升的收益转移给工人。**

但这只限于**有组织的、熟练的工人**。

大量非熟练工人、女工、移民工人仍然处于工会之外，继续被压榨。

### 3.4 马克思与第一国际：国际工人运动

伦敦，1864年9月28日。

**国际工人协会**（International Workingmen's Association，即第一国际）成立。

Marx起草《成立宣言》：

```
"过去的一切运动都是少数人的或者为少数人谋利益的运动。
无产阶级的运动是绝大多数人的、为绝大多数人谋利益的独立运动。"

"全世界无产者，联合起来！"
```

**第一国际的目标**：

1. 协调各国工人运动
2. 支持罢工（跨国募捐）
3. 阻止资本家用外国工人做罢工破坏者（strike breakers）
4. 推动立法改革（工时、工资）

**成员组织**（高峰期，1870年代初）：

| 国家 | 成员数（估计） |
|------|--------------|
| 英国 | 50,000-80,000 |
| 法国 | 30,000-50,000 |
| 德国 | 20,000-30,000 |
| 意大利 | 15,000-20,000 |
| 其他 | 10,000 |
| **总计** | **125,000-190,000** |

**第一国际的内部冲突**：

- **Marx派**：主张通过政治斗争（争取政权）实现社会主义
- **巴枯宁派**（无政府主义）：反对一切政权，主张直接行动、破坏国家机器

**1872年海牙大会**：Marx派驱逐巴枯宁派。

**1876年**：第一国际解散（内部分裂+各国政府镇压）。

**但它的遗产延续**：

- **1889年：第二国际成立**（社会主义政党的国际组织）
- **1917年：俄国革命**（列宁领导的布尔什维克）
- **1919年：第三国际（共产国际）成立**

**工人运动从经济斗争（工会）进化到政治斗争（政党+国际组织）。**

## 第四章：帝国主义与世界大战——资本的全球扩张与自我毁灭（1880-1945）

### 4.1 新帝国主义：瓜分非洲

柏林，1884年11月15日。

**柏林会议**召开，14个欧洲国家+美国讨论如何瓜分非洲。

**会议规则**（柏林总议定书）：

1. "有效占领原则"：声称拥有非洲领土，必须实际控制
2. 刚果河、尼日尔河自由通航
3. 禁止奴隶贸易（但允许强制劳动）

**没有一个非洲国家被邀请参加。**

**非洲被瓜分的速度**（欧洲控制的非洲面积占比）：

| 年份 | 欧洲控制面积占比 |
|------|----------------|
| 1880 | 10% |
| 1900 | 90% |
| 1914 | 95% |

**20年，90%的非洲被瓜分**。

**瓜分结果**（1914年）：

| 殖民国 | 控制面积（万平方公里） | 主要殖民地 |
|--------|---------------------|-----------|
| 英国 | 1,000 | 埃及、苏丹、肯尼亚、南非、罗得西亚、尼日利亚 |
| 法国 | 1,000 | 阿尔及利亚、摩洛哥、法属西非、法属赤道非洲 |
| 德国 | 250 | 喀麦隆、坦噶尼喀、西南非洲 |
| 比利时 | 230 | 刚果自由邦 |
| 葡萄牙 | 210 | 安哥拉、莫桑比克 |
| 意大利 | 160 | 利比亚、厄立特里亚、索马里 |

**为什么突然瓜分非洲？**

**列宁的《帝国主义论》（1916）的解释**：

资本主义发展到**垄断资本主义阶段**：

```
国内市场饱和 → 资本过剩 → 寻找海外投资机会 → 殖民地
国内原料不足 → 寻找原料来源 → 殖民地
国内劳动力成本上升 → 寻找廉价劳动力 → 殖民地
```

**殖民地的经济角色**：

1. **原料供应地**：橡胶（刚果）、棕榈油（西非）、铜（罗得西亚）、钻石（南非）
2. **商品倾销地**：欧洲工业品的市场
3. **资本输出地**：铁路、矿山、种植园投资

**刚果的恐怖统治**（比利时国王利奥波德二世的私人领地，1885-1908）：

**橡胶提取制度**：

```
每个村庄分配橡胶配额
    ↓
未完成配额 → 人质（女性、儿童）被扣押
    ↓
村民必须进入雨林采集野生橡胶
    ↓
采集不足 → 鞭打、砍手、杀戮
```

**刚果砍手恐怖的详细证据**：

**传教士报告**（瑞典传教士E.V. Sjöblom，1896年）：

```
"我亲眼见到Force Publique（殖民地武装）士兵带着一篮子人手回营——那是他们杀死的村民的手。
军官要求他们每打出一发子弹，必须带回一只人手作为证明（防止士兵浪费子弹或私藏）。
有时士兵为了保存子弹打猎，会砍下活人的手交差。
我见到一个7岁男孩，双手被砍，因为他父亲未完成橡胶配额。"
```

**英国领事报告**（Roger Casement，1903年）：

Casement走访刚果河流域16周，记录了大量暴行：

| 村庄 | 人口（1891） | 人口（1903） | 典型案例 |
|------|------------|------------|---------|
| Bongandanga | 5,000 | 300 | 橡胶配额未完成，士兵屠村，幸存者逃散 |
| Ikoko | 1,200 | 150 | 首领Molili因抗议被鞭打致死，村民被迫提供40倍平时的橡胶 |
| Bolengi | 8,000 | 600 | 1900年"惩罚性远征"，烧毁房屋、作物，强奸妇女 |

**人口普查数据**：

| 地区 | 1880年估计人口 | 1924年人口普查 | 死亡率 |
|------|--------------|--------------|--------|
| 赤道省 | 250万 | 35万 | 86% |

**砍手照片**（Alice Seeley Harris摄影，1904年）：

英国传教士夫妇Harris拍摄的照片传到欧洲，引发公愤：
- Nsala坐在门廊，盯着一块布包裹的小手和小脚——那是他5岁女儿的遗骸（被士兵杀死、肢解，因为他未完成橡胶配额）
- 多名儿童和成人展示被砍断的手腕残肢

**国际舆论压力**：1904年，英国成立"刚果改革协会"（Congo Reform Association），Casement、Arthur Conan Doyle（《福尔摩斯》作者）、Mark Twain等加入，发起国际抗议。

| 年份 | 人口（百万） |
|------|------------|
| 1880 | 20-30 |

**1908年，国际舆论压力下，比利时议会接管刚果（从国王私人领地变为殖民地），暴行稍有收敛——但强制劳动继续。**

### 4.3 俄国革命：工人夺取政权

彼得格勒（圣彼得堡），1917年11月7日（俄历10月25日）。

**十月革命**：布尔什维克党在列宁领导下武装起义，推翻临时政府，建立苏维埃政权。

**为什么革命发生在俄国？**

**俄国的特殊性**（1917年）：

1. **工业化不均衡**：少数大城市（彼得格勒、莫斯科）工业集中，工人阶级集中
2. **战争压力**：一战中俄国损失惨重（死亡170万军人），经济崩溃
3. **政治危机**：沙皇专制+二月革命后临时政府软弱无能
4. **农民不满**：土地问题未解决（85%人口是农民）
5. **布尔什维克组织**：列宁的集中制政党，纪律严明

**革命的纲领**（布尔什维克口号）：

```
"和平、土地、面包"
"一切权力归苏维埃"
"工人监督生产"
```

**革命后的政策**：

| 政策 | 内容 |
|------|------|
| 《和平法令》 | 立即停战，退出一战 |
| 《土地法令》 | 废除地主土地所有制，土地归农民 |
| 工厂控制 | 工人委员会监督生产 |
| 银行国有化 | 银行、铁路、重工业收归国有 |

**世界震动**：**工人阶级第一次夺取国家政权。**

**但接下来是内战**（1918-1922）：

- 红军（布尔什维克） vs 白军（反革命+外国干涉军）
- 死亡约800万-1000万（战争+饥荒+疾病）
- 红军胜利，苏维埃政权巩固

**关键观察**：
- **依赖出口的小国**（澳大利亚、加拿大）**GDP跌幅最大**
- **金融中心**（美国、德国）**失业率最高**
- **殖民帝国**（英、法）**依靠殖民地市场缓冲**
- **苏联因退出世界资本主义体系而免疫**

**为什么崩溃？**

**三大原因**：

**原因1：生产过剩**

工业生产能力远超消费能力：

```
工厂高效生产 → 产量暴增 → 但工人工资增长缓慢 → 购买力不足 → 产品卖不出去 → 工厂倒闭 → 工人失业 → 购买力进一步下降 → 恶性循环
```

**原因2：金融投机**

1920年代股市泡沫：

- 股票可以用10-20%保证金购买（杠杆5-10倍）
- 人人炒股（连鞋童都在给人推荐股票）
- 股价脱离实体经济

**原因3：国际金本位制的僵化**

金本位要求货币与黄金挂钩，限制了货币政策灵活性：

```
经济衰退 → 需要增加货币供应刺激经济 → 但金本位限制货币发行 → 无法刺激 → 衰退加剧
```

### 5.2 罗斯福新政：国家干预的转向

华盛顿，1933年3月4日。

富兰克林·罗斯福就任美国总统。就职演说：

```
"我们唯一值得恐惧的，就是恐惧本身。"
```

**新政的核心理念**：**国家必须干预经济，不能放任市场自发调节。**

这是对自由放任资本主义的根本挑战。

**新政的历史意义**：

**资本主义的修正**：从自由放任转向国家干预、福利国家。

凯恩斯主义诞生：政府通过财政政策（赤字支出）和货币政策调节经济。

**新权力方程**：

$$
Y = C + I + G
$$

GDP = 消费 + 投资 + **政府支出**

政府支出成为调节经济的重要工具。

### 5.3 法西斯主义的崛起：资本主义的极端化

德国，1933年1月30日。

阿道夫·希特勒被任命为总理。

**纳粹党的崛起背景**：

| 年份 | 事件 | 纳粹党得票率 |
|------|------|------------|
| 1928 | 经济繁荣 | 2.6% |
| 1930 | 大萧条开始 | 18.3% |
| 1932年7月 | 失业率30% | 37.3%（第一大党）|
| 1932年11月 | 略有恢复 | 33.1% |
| 1933年3月 | 希特勒已掌权 | 43.9% |

**纳粹的支持基础**：

| 阶层 | 支持率（1932） | 原因 |
|------|--------------|------|
| 失业工人 | 中 | 承诺就业 |
| 小资产阶级（店主、手工业者）| 高 | 恐惧破产、被大资本吞并 |
| 农民 | 高 | 债务危机、粮价暴跌 |
| 大资本家 | 部分支持 | 恐惧共产主义、希望镇压工会 |

**法西斯主义的经济政策**：

1. **国家控制但不废除私有制**：私企继续运作，但服从国家指令
2. **大规模军备**：重建军队、生产武器
3. **公共工程**：修建高速公路（Autobahn）、体育场
4. **压制工会**：禁止罢工，强制劳动组织

**德国失业率**：

| 年份 | 失业人数（百万） | 失业率 |
|------|----------------|--------|
| 1933 | 6.0 | 30% |
| 1935 | 2.2 | 11% |
| 1937 | 0.9 | 4.5% |
| 1939 | 0.1 | 0.5% |

**纳粹"解决"了失业问题——通过军备和准备战争。**

**法西斯主义的本质**（根据Paxton《法西斯主义剖析》）：

```
资本主义危机 → 中下层恐慌（失业、破产） → 寻找替罪羊（犹太人、共产主义者）→ 极端民族主义 → 独裁者承诺恢复秩序、伟大 → 对外扩张转移矛盾
```

**法西斯主义是资本主义在危机中的极端化，而不是对资本主义的否定。**

## 尾声：1945年，资本主义的转型关口

1945年5月8日，德国投降。
1945年9月2日，日本投降。

第二次世界大战结束。

**世界满目疮痍**：

| 国家 | 死亡人数（百万） | GDP损失 |
|------|----------------|---------|
| 苏联 | 27 | 25% |
| 中国 | 20 | 20% |
| 德国 | 7 | 城市90%被毁 |
| 波兰 | 6 | 38% |
| 日本 | 3 | 工业70%被毁 |

**但工业资本主义没有崩溃——它转型了。**

**1945年后的新体系**：

1. **布雷顿森林体系**（1944）：美元-黄金挂钩，其他货币-美元挂钩，国际货币稳定
2. **马歇尔计划**（1948）：美国援助欧洲130亿美元，重建工业、扩大市场
3. **福利国家**：欧洲各国建立全民医保、养老、失业保险
4. **凯恩斯主义**：政府积极干预经济，熨平周期
5. **冷战**：资本主义阵营 vs 社会主义阵营

**工业资本主义的权力方程，在1945年发生了第二次转型**：

**从**：

$$
\Pi = (P - C) \cdot Q, \quad \text{压低} \; C \text{（工资）、提高} \; Q \text{（产量）}
$$

**到**：

$$
\Pi = (P - C) \cdot Q, \quad \text{但} \; C \uparrow, Q \uparrow, \text{通过扩大总需求实现}
$$

**给工人涨工资（扩大消费）→ 刺激需求 → 工厂扩大生产 → 利润上升**

这是凯恩斯主义+福利国家的逻辑。

**但这个体系依赖两个条件**：

1. **高速增长**：GDP每年增长4-6%，足够分给工人和资本家
2. **廉价能源**：石油价格低，支撑大规模生产

**当这两个条件在1970年代消失时，工业资本主义将再次转型——进入金融资本主义时代。**

---

**工业资本主义的历史遗产**（1750-1945）：

**创造**：
- 生产力爆炸：GDP增长50-100倍
- 人均寿命翻倍（从35岁到70岁）
- 科技革命：电力、化学、内燃机、无线电、原子能

**破坏**：
- 两次世界大战：1.1亿人死亡
- 殖民掠夺：数千万人死于强制劳动、饥荒
- 环境破坏：煤烟、工业污染

**斗争**：
- 工人阶级从无组织到有组织
- 从每天14小时到每天8小时
- 从无投票权到普选权
- 从无社会保障到福利国家

**工业资本主义用煤和铁重塑了世界——既创造了前所未有的财富，也制造了前所未有的不平等和暴力。**

**它的核心矛盾——生产社会化与占有私人化——通过国家干预和福利国家得到部分缓解，但并未解决。**

**1945年后，资本主义将进入新的阶段：金融化、全球化、数字化。**

**但工业资本主义时代的斗争经验和制度遗产（工会、社保、劳动法），仍然是今天工人阶级的防线。**
