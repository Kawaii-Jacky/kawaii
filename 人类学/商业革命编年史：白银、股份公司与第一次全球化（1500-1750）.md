## 开篇：波托西的死亡矿井（1545年）

安第斯山脉，海拔4090米。

印第安矿工Diego Gualpa在Cerro Rico（富饶之山）山腰生火取暖。风太大，火苗摇晃，他用石头围住火堆。石头在高温下开裂，裂缝里流出银白色的液体。

Diego捡起一块冷却的金属。很重，很软，在阳光下闪闪发光。

他不知道，他刚发现了人类历史上最大的银矿——在接下来的300年里，这座山将产出全世界45%的白银，总计约6万吨。

1545年，西班牙人听说了这个发现。总督下令建城：Villa Imperial de Potosí（波托西皇家城）。

1560年，波托西人口达到4.5万。
1580年，12万。
1650年，16万——超过伦敦、巴黎、罗马，成为西半球最大的城市。

但没有人想住在这里。

海拔4090米，氧气稀薄，每走几步就要停下喘气。冬天气温降到-20°C，夏天暴雨把街道变成泥沼。没有树木，燃料要从200公里外运来。食物全靠进口，一只鸡的价格等于马德里的10倍。

人们来这里只有一个原因：银子。

**Cerro Rico的剖面**：整座山是一个巨大的银矿床，银含量高达200-500克/吨（现代银矿平均3-5克/吨）。银以辉银矿（Ag₂S）和角银矿（AgCl）形式存在，与石英、黄铁矿混合。

西班牙人开挖竖井，最深的达到800米。矿工从地表爬下木梯，梯子之间的垂直距离超过100米。下到底部要2-3小时。

每个矿工背一个皮袋，装满矿石后往上爬。一袋矿石重25公斤，加上工具和灯，总重30-35公斤。从井底爬到地表要4-5小时。

**一天的工作**：

```
凌晨4点：下井（2-3小时）
上午7点：到达工作面
上午7点-下午3点：挖矿、装袋（8小时）
下午3点：开始往上爬（4-5小时）
晚上8点：回到地表
```

16小时的工作，在氧气稀薄、粉尘弥漫、随时可能塌方的地下。

矿工是印第安人，来自秘鲁总督区的mita制度——一种强制劳役系统，要求每个村庄每年派出1/7的成年男性去波托西挖矿。

**Mita的死亡率**（根据Cole 1985的估算）：

| 时期 | 年均mita人数 | 死亡率 | 年死亡人数 |
|------|-------------|--------|----------|
| 1570-1600 | 13,500 | 15-20% | 2,000-2,700 |
| 1600-1650 | 10,000 | 20-25% | 2,000-2,500 |
| 1650-1700 | 4,500 | 25-30% | 1,100-1,350 |

在最高峰时期（1600-1650），每年有约2500名印第安人死在波托西。50年总计12.5万人——相当于当时整个秘鲁印第安人口的2-3%。

他们死于：
- 矿井塌方
- 水银中毒（提炼银用的汞蒸气）
- 矽肺病（粉尘）
- 寒冷、疲劳、营养不良

Cerro Rico山下，有数不清的坟墓。当地人说：这座山可以用印第安人的骨头搭一座桥，从波托西一直连到西班牙。

但白银还在流出。每年3000-4000吨，装上骡队，运到利马，装船，穿越太平洋到马尼拉，或者横渡大西洋到塞维利亚。

**这些白银将重新定义人类的权力方程。**

## 第一章：白银洪流——货币化的全球冲击（1500-1650）

### 1.1 价格革命：欧洲的通货膨胀

西班牙，1550年。

塞维利亚港口，卸货工人从"珍宝船队"（Flota de Indias）上搬下一箱箱银锭。每箱重约50公斤，印着秘鲁总督的印记。

**西班牙美洲白银进口量**（根据Hamilton 1934的数据）：

| 时期 | 年均进口量（吨） | 累计（吨） |
|------|----------------|-----------|
| 1503-1520 | 0.3 | 5 |
| 1521-1540 | 5 | 100 |
| 1541-1560 | 42 | 840 |
| 1561-1580 | 94 | 1,880 |
| 1581-1600 | 272 | 5,440 |
| 1601-1620 | 281 | 5,620 |
| **总计1503-1650** | - | **16,600** |

16,600吨白银，在150年内涌入欧洲。这相当于欧洲原有白银存量的5-6倍。

结果？价格爆炸。

**欧洲物价上涨**（1500=100）：

| 年份 | 西班牙 | 法国 | 英国 | 波兰 |
|------|--------|------|------|------|
| 1500 | 100 | 100 | 100 | 100 |
| 1550 | 160 | 145 | 145 | 120 |
| 1600 | 315 | 260 | 275 | 180 |
| 1650 | 425 | 355 | 380 | 240 |

150年内，西班牙物价上涨425%，英国380%，法国355%。

这在一个几百年物价基本稳定的农业社会，是灾难性的。

**谁受益？谁受损？**

*受益者*：
- **债务人**：固定债务的实际价值下降。贵族、君主欠的债，用贬值的货币还。
- **商人**：货物价格上涨快于成本上涨，利润膨胀。
- **地主（有适应能力的）**：能提高地租的地主，收入随物价上涨。

*受损者*：
- **固定收入者**：工资、养老金、固定地租的实际购买力暴跌。
- **债权人**：借出的钱，还回来时购买力大减。
- **农民（佃农）**：地租往往滞后于物价上涨，但生活成本飞涨。

**工资-物价剪刀差**（英国，1500=100）：

| 年份 | 物价指数 | 工资指数 | 实际工资 |
|------|---------|---------|---------|
| 1500 | 100 | 100 | 100 |
| 1550 | 145 | 120 | 83 |
| 1600 | 275 | 150 | 55 |
| 1650 | 380 | 180 | 47 |

实际工资下降了53%！

16世纪的欧洲工人，购买力几乎减半。一个石匠在1500年一天的工资可以买12公斤面包，到1650年只能买5.6公斤。

**这是人类历史上第一次全球性的货币冲击**——不是因为战争或饥荒，而是因为白银从地球的一端流向另一端。

### 1.2 中国：白银的终点站

另一端，中国。

明朝，1570年代。

张居正推行"一条鞭法"：把各种赋税、徭役，统一折算成白银缴纳。

**一条鞭法的逻辑**：

*旧制度*（明初）：
- 田赋：谷物
- 徭役：劳动
- 杂税：实物（布、铁、木材等）

*新制度*（一条鞭法后）：
- 所有税赋折银
- 农民缴纳白银
- 国家用银雇人做原本徭役的工作

这简化了征税，但有一个前提：**农民必须能获得白银**。

问题是：中国不产银。

明朝的银矿产量极低，年产不到10吨。而一条鞭法实施后，每年需要约1000-1500吨白银才能满足税收和经济运行。

白银从哪里来？

**从波托西来。**

**白银的环球流动**（1600年代）：

```
波托西矿山
    ↓
利马（秘鲁）
    ↓
阿卡普尔科（墨西哥）→ 太平洋 → 马尼拉（菲律宾）→ 福建月港 → 中国
    或
    ↓
塞维利亚（西班牙）→ 大西洋 → 里斯本/阿姆斯特丹 → 印度洋 → 澳门 → 中国
```

#### 1.2.1 马尼拉大帆船：太平洋上的白银高速公路

阿卡普尔科，1620年5月。

*Nuestra Señora de la Concepción*号（圣母无染原罪号）准备启航，目的地：马尼拉。航程6500海里，预计3-4个月。

**大帆船的规格**（典型17世纪马尼拉大帆船）：

| 指标 | 数据 |
|------|------|
| 长度 | 45-50米 |
| 排水量 | 1,200-2,000吨 |
| 船员 | 200-350人 |
| 士兵/乘客 | 50-100人 |
| 货舱容量 | 700-1,000吨 |
| 航速 | 2-4节（顺风） |

**货物清单**（1620年阿卡普尔科→马尼拉）：

| 货物 | 数量 | 价值（比索） |
|------|------|-----------|
| 银锭 | 1,200箱（60吨） | 3,000,000 |
| 银币（8里亚尔币） | 400万枚（60吨） | 4,000,000 |
| 可可 | 50吨 | 30,000 |
| 烟草 | 20吨 | 15,000 |
| **总计白银** | **120吨** | **7,000,000** |

**700万比索相当于**：
- 西班牙王室年收入的20-25%
- 可购买350万磅中国丝绸
- 或100万件瓷器
- 或800吨胡椒

**马尼拉→阿卡普尔科回程货物**（1621年）：

| 货物 | 数量 | 进货价（比索） | 墨西哥售价 | 利润率 |
|------|------|-------------|----------|--------|
| 生丝 | 60吨 | 2,400,000 | 5,000,000 | 108% |
| 绸缎 | 12万匹 | 1,200,000 | 2,800,000 | 133% |
| 瓷器 | 80万件 | 400,000 | 1,000,000 | 150% |
| 香料 | 15吨 | 300,000 | 600,000 | 100% |
| 象牙、珠宝 | - | 700,000 | 1,600,000 | 129% |
| **总计** | - | **5,000,000** | **11,000,000** | **120%** |

**马尼拉大帆船贸易的经济学**（单次航程）：

```
阿卡普尔科出发：
  白银：700万比索
  
马尼拉采购：
  中国商品：500万比索
  菲律宾本地商品：50万比索
  贸易税、行贿、损耗：150万比索
  
回程到达阿卡普尔科：
  货物在墨西哥售价：1100万比索
  
运输成本：
  船只折旧：30万比索
  船员工资、食物：40万比索
  保险、维护：30万比索
  
净利润：1100万 - 700万 - 100万 = 300万比索
利润率：43%（按白银投入计算）
```

**但风险巨大**：

**马尼拉大帆船的死亡率**（1565-1815年，250年间）：

| 风险类型 | 船只损失 | 占比 |
|---------|---------|------|
| 沉没（风暴） | 26艘 | 43% |
| 触礁 | 15艘 | 25% |
| 海盗/敌舰劫掠 | 10艘 | 17% |
| 火灾 | 6艘 | 10% |
| 其他 | 3艘 | 5% |
| **总计损失** | **60艘** | **每4.2年损失1艘** |

**船员死亡率更加惊人**：

| 航程 | 出发人数 | 到达人数 | 死亡率 | 主要死因 |
|------|---------|---------|-------|---------|
| 阿卡普尔科→马尼拉 | 300 | 270 | 10% | 痢疾、坏血病 |
| 马尼拉→阿卡普尔科 | 280 | 180 | 36% | 坏血病、饥饿 |

**回程为什么死亡率飙升？**

回程路线必须向北绕行到北纬35-40度（接近日本），利用黑潮洋流和西风带，然后向东横渡太平洋。航程长达4-6个月，淡水和食物经常耗尽。

**1638年*San Francisco Javier*号的航海日志**（摘录）：

```
7月15日：离开马尼拉，船员308人
8月23日：发现坏血病，12人病倒
9月17日：死亡15人，病倒63人
10月8日：淡水配给减半，每人每天1品脱（0.5升）
10月30日：累计死亡48人，食物仅剩玉米和咸鱼
11月15日：发现陆地（加利福尼亚），累计死亡103人
11月22日：到达阿卡普尔科，幸存205人，其中80人病危
```

**死亡率：33%**

**马尼拉白银流向中国的机制**：

马尼拉不产白银，也不产商品。它是一个**转口港**——西班牙白银的中继站。

**1620年马尼拉的白银流动**：

```
阿卡普尔科运来：120吨白银
    ↓
流向分配：
  ├─ 福建商人（运走丝绸、瓷器）：80吨（67%）
  ├─ 西班牙在菲律宾的开支（军队、教会）：20吨（17%）
  ├─ 日本商人：10吨（8%）
  └─ 其他（印度、东南亚）：10吨（8%）
    ↓
福建商人运到月港/厦门 → 缴纳关税 → 进入中国内地
```

**中国对白银的吸纳规模**（太平洋路线，1580-1640）：

| 时期 | 年均流量（吨） | 60年累计（吨） |
|------|--------------|--------------|
| 1580-1600 | 30-40 | 700 |
| 1600-1620 | 60-80 | 1,400 |
| 1620-1640 | 80-120 | 2,000 |
| **总计** | - | **4,100** |

**太平洋路线运送了约4000吨白银到中国**——占中国同期白银进口总量的30-40%。

**这条航线将波托西银山与中国江南连接起来，创造了人类历史上第一条真正的环球贸易路线。**

**中国白银进口量估算**（根据von Glahn 1996）：

| 时期 | 年均进口（吨） | 来源 |
|------|--------------|------|
| 1550-1600 | 50-100 | 日本(80%) + 美洲(20%) |
| 1600-1640 | 200-300 | 美洲(60%) + 日本(40%) |
| 1640-1680 | 100-150 | 美洲(70%) + 日本(30%) |
| 1680-1750 | 50-100 | 美洲(90%) |

从1550到1750年，中国累计进口白银约3-4万吨——占同期世界白银产量的25-30%。

**中国成了全球白银的终点站。**

为什么？

**中国的白银需求机制**：

1. **税收货币化**：一条鞭法后，1亿人口每年要缴纳1000-1500吨白银
2. **白银-铜钱比价**：中国用铜钱作为日常货币，白银作为大额结算。但铜钱贬值快，人们更愿意持有白银。
3. **储蓄偏好**：中国家庭习惯储蓄白银，白银流入后很少流出（不像欧洲，白银会继续流动）

**白银-铜钱汇率的变化**（1两白银兑换铜钱数）：

| 年份 | 汇率（文） | 变化 |
|------|----------|------|
| 1500 | 500-600 | - |
| 1580 | 700-800 | 白银升值 |
| 1640 | 1000-1200 | 白银继续升值 |
| 1650 | 2000+ | 白银短缺危机 |

1640年代，明朝崩溃的前夜，白银汇率暴涨——从1两兑800文涨到2000文。

原因？美洲白银供应中断。

### 1.3 白银断流：明朝的货币危机

1639-1644年，明朝最后的五年。

**美洲白银进口量断崖下跌**：

| 年份 | 进口量（吨/年） |
|------|---------------|
| 1630-1639 | 250-300 |
| 1640 | 150 |
| 1641 | 100 |
| 1642-1644 | 50-80 |

**为什么白银突然断流？**

1. **西班牙衰落**：三十年战争（1618-1648）耗尽了西班牙财政，美洲白银越来越多被截留在欧洲
2. **荷兰封锁**：荷兰海军控制东南亚航线，切断了马尼拉-福建的白银走私
3. **日本锁国**：1639年日本禁止与欧洲贸易，日本白银出口骤减

**对中国的冲击**：

白银短缺 → 银-铜汇率暴涨 → 农民用铜钱买银纳税，成本翻倍 → 税负实际加倍

**明末税负的实际变化**（陕西农民的案例）：

| 项目 | 1630年 | 1644年 |
|------|--------|--------|
| 名义税额 | 0.5两白银/年 | 0.5两白银/年（未变）|
| 需用铜钱 | 400文 | 1000文 |
| 一个农民年收入 | 10,000文 | 10,000文 |
| 税负占比 | 4% | 10% |

税率没变，但实际税负涨了2.5倍。

陕西农民起义，1628年开始。领袖：李自成。

1644年，李自成攻入北京，崇祯帝在煤山自缢。明朝灭亡。

**一个货币学的视角**：明朝不是亡于腐败、不是亡于女真入侵，而是亡于白银断流导致的通缩危机。

*货币-财政-崩溃的链条*：

```
美洲白银减少 → 中国银价暴涨 → 实际税负翻倍 → 农民破产 → 起义 → 军费飙升 → 加税 → 更多破产 → 崩溃
```

**这是人类历史上第一次，一个帝国的命运被地球另一端的银矿产量决定。**

## 第二章：股份公司的诞生——资本的组织革命（1600-1720）

### 2.1 VOC：第一家真正的公司

阿姆斯特丹，1602年3月20日。

荷兰东印度公司（Verenigde Oostindische Compagnie, VOC）成立。

这不是第一家贸易公司——英国东印度公司(EIC)早了两年（1600）。但VOC有三个革命性的创新：

**创新1：永续存在**

*旧模式*（英国EIC 1600-1657）：
- 每次航行单独募资
- 航行结束后清算、分配利润
- 公司只是一系列独立航行的法律外壳

*VOC模式*（1602-1799）：
- 一次性募资，公司永续存在
- 利润再投资，不是每次都分光
- 股东想退出？卖股票，不是清算公司

**创新2：可转让股份**

VOC发行股票，股东可以自由买卖。1602年首次发行后，阿姆斯特丹很快就出现了**股票交易市场**。

**VOC股价**（荷兰盾，面值100）：

| 年份 | 股价 | 变化 |
|------|------|------|
| 1602 | 100 | 发行 |
| 1607 | 130 | +30% |
| 1610 | 150 | +50% |
| 1620 | 240 | +140% |
| 1630 | 360 | +260% |
| 1640 | 420 | +320% |

买了VOC股票的投资者，40年收益420%。

**创新3：有限责任**

股东只对公司债务承担**股本范围内的责任**。公司破产，股东最多损失投资的钱，不会连累家产。

这三个创新合起来，创造了现代公司的基本形态：
- 永续存在（不因股东变更而解散）
- 所有权可转让（股票市场）
- 有限责任（风险隔离）

650万盾是什么概念？相当于荷兰共和国一年GDP的2-3%。用今天的比例，相当于集资6000-9000亿美元成立一家公司。

但关键不是规模，而是**权力的重新分配**。

董事会批准了。

**旧权力方程**（农业帝国）：

$$
\text{剩余} = \text{提取率} \times \text{农业产出}
$$

**新权力方程**（商业资本主义）：

$$
\text{利润} = (\text{卖价} - \text{买价}) \times \text{贸易量} - \text{暴力成本}
$$

关键变化：利润来源不是**提取农民的剩余**，而是**控制贸易路线、垄断商品、操纵价差**。

运输成本约占10-15%，暴力成本（军队、炮舰）约占5-10%。净利润率：400-800%。

**但这种利润只有在垄断的情况下才能维持。**

VOC的策略：
1. 军事占领产地（班达、摩鹿加）
2. 强制当地人只能卖给VOC
3. 摧毁"野生"香料树，集中种植到可控区域
4. 用海军封锁，阻止其他欧洲商人进入

这不是自由贸易，这是**武装垄断**。

### 2.3 阿姆斯特丹交易所：投机的诞生

阿姆斯特丹，1630年代。

VOC股票每天在交易所交易，价格波动，有人赚、有人亏。很快，新的玩法出现了：

**期权交易**。

**看涨期权**（opsie）：我今天付给你10盾，获得3个月后以400盾价格从你这里买入VOC股票的权利（不是义务）。

- 如果3个月后VOC股价涨到450，我行权，花400买入，立即卖出450，赚40（扣除期权费10，净赚30）
- 如果股价跌到350，我放弃行权，损失10盾期权费

**看跌期权**：我今天付10盾，获得以400盾价格卖给你股票的权利。

**期货合约**：我今天和你约定，3个月后以400盾价格买你的股票（必须执行，不是期权）。

**卖空**（blanco verkoop，空白出售）：我今天以400盾价格卖给你股票，但我手里没有股票。我承诺1个月后交割。我赌股价会跌，到时候我能以更低价格买入，交给你，赚差价。

**Isaac Le Maire的做空传奇**（1609）：

Le Maire是VOC创始股东之一，后来与董事会闹翻，被踢出公司。他心怀怨恨，策划了人类历史上第一次**有组织的做空攻击**。

**Le Maire的计划**：

```
第1步：散布VOC的负面消息
  - 船只沉没
  - 香料仓库失火
  - 与葡萄牙的战争失利

第2步：大量卖空VOC股票
  - 承诺3个月后交割
  - 卖空价：500盾/股
  - 卖空数量：相当于VOC总股本的5-10%

第3步：股价下跌
  - 恐慌情绪蔓延
  - 其他投资者跟风抛售
  - 股价跌到300

第4步：低价买入，交割，获利
  - 以300买入
  - 以500交割
  - 每股赚200
```

VOC董事会发现后，向政府游说。1610年，荷兰政府颁布**欧洲第一部证券监管法**：**禁止卖空VOC股票**。

Le Maire的做空计划失败，但他开创了一个新时代：**金融市场上的猎食者与猎物**。

**17世纪阿姆斯特丹的金融创新**：

| 工具 | 出现时间 | 功能 |
|------|---------|------|
| 股票 | 1602 | 所有权分割 |
| 股票交易所 | 1602 | 二级市场 |
| 期权 | 1620s | 对冲/投机 |
| 期货 | 1630s | 锁定价格 |
| 卖空 | 1609 | 做空/价格发现 |
| 杠杆交易 | 1630s | 放大收益/风险 |

**这些工具在2020年代仍然是金融市场的基础。它们全部诞生于1600-1650年的阿姆斯特丹。**

### 2.4 郁金香狂热：第一次金融泡沫（1636-1637）

哈勒姆（Haarlem），1637年2月3日。

郁金香球茎拍卖会。今天的明星：一颗Semper Augustus（永远的奥古斯都）品种。

竞价：
- 3,000荷兰盾
- 4,000
- 5,000
- 5,200（成交！）

5,200盾买一颗郁金香球茎——这是一个熟练工匠8年的工资，够买一栋阿姆斯特丹运河边的豪宅。

一周后，2月10日。同一个拍卖行。

今天没人来。

Semper Augustus流拍。底价3,000盾，无人应价。

郁金香市场崩溃了。一夜之间，球茎价格暴跌90-95%。

**郁金香价格的疯狂**（1636-1637）：

| 时期 | 普通品种（盾/磅） | 稀有品种（盾/株） |
|------|-----------------|----------------|
| 1634年11月 | 20 | 500-1,000 |
| 1635年11月 | 60 | 1,500-3,000 |
| 1636年11月 | 200 | 3,000-5,000 |
| 1637年1月 | 1,000 | 4,000-6,000 |
| 1637年2月 | **50** | **200-500** |

**为什么郁金香这么贵？**

*表面原因*：稀有性。某些郁金香品种（如Semper Augustus）是病毒感染的变异品种，花瓣有独特的条纹图案，极难繁殖。

*深层原因*：**期货市场**。

郁金香球茎只能在秋天种植，夏天挖出。但交易全年进行。冬天买卖的是**期货合约**——承诺夏天交割球茎。

**期货市场的杠杆效应**：

```
我花100盾买一份期货合约
   ↓
合约承诺夏天交割价值1,000盾的球茎
   ↓
如果现货价格涨到2,000，我赚1,900（20倍杠杆！）
   ↓
如果跌到500，我亏400（但初始投入只有100，实际亏4倍）
```

**博傻理论**（Greater Fool Theory）：

我知道这颗球茎不值5,000盾，但我相信明天有人会以6,000盾买走。只要能找到更大的傻瓜，我就能赚钱。

1637年2月，没有更大的傻瓜了。价格崩溃。

**郁金香泡沫的社会学**：

参与者不是贵族或大商人，而是**小工匠、店主、织工**——中产阶级。

为什么他们敢拿8年工资去赌一颗球茎？

因为周围的人都在赚钱。邻居买了球茎，3个月翻倍。酒馆里的人炫耀他的收益。连女仆都在讨论该买哪个品种。

**当所有人都在赚钱时，不参与就是损失。**

经济学家Kindleberger的泡沫五阶段模型（基于郁金香等历史案例）：

```
1. 置换（Displacement）：新机会出现（郁金香期货市场）
2. 繁荣（Boom）：价格上涨，早期参与者获利
3. 亢奋（Euphoria）：价格失控，散户涌入
4. 获利回吐（Profit Taking）：内部人开始撤退
5. 恐慌（Panic）：崩溃
```

**郁金香泡沫是人类历史上第一次完整记录的金融泡沫周期**——但绝不是最后一次。

#### 2.4.1 南海泡沫与密西西比泡沫：两场大型灾难的对比（1719-1720）

1720年，伦敦和巴黎几乎同时爆发了两场更大规模的金融危机，郁金香泡沫相比之下只是一次预演。

**时间线对比**：

| 时间 | 南海公司（英国） | 密西西比公司（法国） |
|------|----------------|-------------------|
| 1719年1月 | 股价128（面值100） | 股价500（面值500） |
| 1719年8月 | 180 | 2,750 (+450%) |
| 1719年12月 | 400 | 10,000 (+1,900%) |
| 1720年1月 | 950 (+850%) | 18,000 (+3,500%) |
| 1720年6月 | **1,050 (峰值)** | 崩盘开始 |
| 1720年9月 | 崩盘开始 | - |
| 1720年12月 | 150（回落86%） | 500（回到原点） |
| 1721年 | 公司重组，部分偿付 | 劳逃离，纸币废除 |

**两家公司的底层资产对比**：

| 维度 | 南海公司 | 密西西比公司 |
|------|---------|-------------|
| **法定垄断** | 南海（南美）贸易权 | 路易斯安那全部贸易+税收权 |
| **实际资产** | 几乎没有（仅奴隶贸易权） | 法国所有海外殖民地特许权 |
| **承接债务** | 英国国债3000万英镑 | 法国国债30亿里弗尔 |
| **真实盈利** | 年亏损（无贸易） | 微薄利润（路易斯安那未开发） |
| **股本发行** | 4轮增发，总计1.14亿英镑 | 60万股，总计3亿里弗尔 |

**南海公司的骗局机制**：

南海公司由财政大臣Robert Harley于1711年创建，名义上垄断南美洲贸易，实际目的是**承接政府债务**。

**债务-股权置换的魔术**：

```
1. 政府欠债权人3000万英镑国债（年息5%，每年付150万）
      ↓
2. 南海公司对政府说：我发股票，让债权人用国债换股票
      ↓
3. 债权人换股后，国债消失，政府只需付南海公司较低利息（4%）
      ↓
4. 南海公司股价越高，债权人越愿意换（1英镑国债能换更多股票）
      ↓
5. 南海公司疯狂推高股价（贿赂议员、散布谣言、操纵市场）
      ↓
6. 股价崩盘，债权人血本无归，但政府债务已经转移
```

**南海公司股价操纵手段**：

| 手段 | 细节 |
|------|------|
| **贿赂** | 向128名议员、贵族赠送总计120万英镑的股票（无需付钱，只享收益） |
| **虚假新闻** | 宣称在南美发现金矿、获得西班牙贸易特许 |
| **杠杆贷款** | 允许投资者只付10-20%首付，其余公司贷款（推高需求） |
| **泡沫公司法** | 1720年6月，南海公司游说通过法案，禁止其他股票公司（消灭竞争） |

**密西西比公司的纸币灾难**：

约翰·劳的系统更加激进：他同时控制了**银行（Banque Royale）**和**垄断贸易公司（密西西比公司）**，将货币发行权与资产泡沫捆绑。

**劳的货币-股票双泡沫**：

```
1. 通用银行发行纸币，承诺兑换金银
      ↓
2. 密西西比公司股价上涨，财富效应
      ↓
3. 人们用纸币购买股票，纸币需求增加
      ↓
4. 银行印更多纸币来满足需求
      ↓
5. 股价继续涨，纸币继续印（正反馈循环）
      ↓
6. 有人兑现：要求用纸币换金银
      ↓
7. 银行储备不足，兑现挤兑
      ↓
8. 恐慌，股价崩盘，纸币变废纸
```

**纸币发行量的失控**（里弗尔，百万）：

| 时间 | 纸币流通量 | 金银储备 | 储备率 |
|------|----------|---------|--------|
| 1719年1月 | 60 | 40 | 67% |
| 1719年9月 | 400 | 45 | 11% |
| 1720年2月 | 2,200 | 50 | 2.3% |
| 1720年5月 | 3,000 | 20（外流） | 0.7% |

**劳的绝望措施**（1720年5-6月）：

```
5月21日：强制贬值，纸币面值减半
   ↓（大恐慌）
5月27日：撤回贬值令（但信心已崩溃）
   ↓
6月1日：禁止持有超过500里弗尔的金银（强制用纸币）
   ↓
6月10日：银行门口踩踏，15人死亡
   ↓
7月17日：劳被解除财政总监职务
   ↓
11月：劳逃离法国，纸币作废
```

**两场泡沫的社会代价对比**：

| 指标 | 南海泡沫（英国） | 密西西比泡沫（法国） |
|------|----------------|-------------------|
| **直接损失** | 约5000万英镑（GDP的50%） | 无法估算（整个货币体系崩溃） |
| **破产人数** | 数万中产阶级 | 数十万，包括贵族 |
| **自杀案例** | 数十起记录在案 | 数百起 |
| **政治后果** | 财政大臣Aislabie入狱，政府重组 | 摄政王声誉扫地，强化反纸币情绪 |
| **制度后果** | 《泡沫法案》（Bubble Act），限制股份公司100年 | 法国抵制纸币长达一个世纪 |
| **长期影响** | 资本市场成熟化，英格兰银行信誉提升（对比） | 法国金融落后英国50年 |

**泡沫崩溃的触发点对比**：

**密西西比**：
- 1720年1月，Philippe II, Duke of Bourbon（孔德亲王）用3辆马车运走大量金币兑现
- 宫廷内部人带头抛售→恐慌传染

**南海**：
- 1720年8月，Bank of England拒绝继续贷款给南海公司
- 流动性枯竭→股价失去支撑

**为什么英国恢复得比法国快？**

| 制度差异 | 英国 | 法国 |
|---------|------|------|
| **中央银行** | 英格兰银行独立于南海公司，信誉完好 | 劳同时控制银行和公司，全体系崩溃 |
| **纸币** | 南海公司未发行货币，只是股票泡沫 | 纸币与股票双重泡沫，货币信用摧毁 |
| **议会监督** | 议会调查、问责（虽然有腐败） | 王权专断，无有效监督 |
| **债务清理** | 政府强制重组，部分债务得到偿付 | 债务事实上作废，债权人血本无归 |

**牛顿的损失**：

物理学家艾萨克·牛顿（时任英国皇家铸币厂厂长）在南海泡沫中亏损2万英镑（约今天1000万英镑）。他的名言：

> "我能计算天体的运动，却无法计算人类的疯狂。"

**这两场泡沫证明了**：金融市场的群体疯狂是跨国的、重复的，当贪婪与投机遇到杠杆与货币扩张，灾难规模可以超越任何一株郁金香。

## 第三章：国家与资本的纠缠——主权债务的诞生（1650-1720）

### 3.1 英国：光荣革命与国债

伦敦，1688年。

詹姆斯二世逃往法国。荷兰执政威廉三世（William of Orange）和妻子玛丽（詹姆斯的女儿）被邀请入主英国。

这就是"光荣革命"——没有流血，国王换了。

但真正革命性的变化不在王位，而在**财政权力的转移**。

**《权利法案》（1689）的财政条款**：

```
第4条：国王未经议会同意，不得征税
第12条：国王未经议会同意,不得建立常备军
```

翻译成白话：**国王不能自己决定从哪里拿钱、拿多少钱。**

**旧体制**（斯图亚特王朝）：
- 国王依靠王室领地收入、关税、零散税收
- 议会偶尔批准临时税
- 战争需要钱？国王向银行家私人借贷，利率20-30%

**新体制**（1688后）：
- 议会控制税收立法
- 国王要钱必须说服议会
- 税收收入用于偿还**国家债务**（不是国王个人债务）

**为什么这很重要？**

因为它创造了**主权信用**。

### 3.2 英格兰银行的诞生（1694）

1694年，英国与法国交战（九年战争），需要120万英镑军费。议会没钱。

苏格兰商人William Paterson提出一个方案：

```
我组织一群商人，凑120万英镑借给政府
   ↓
政府每年付8%利息（96,000英镑/年）
   ↓
作为回报，我们获得成立银行的特许权
   ↓
这家银行可以：
  - 发行纸币
  - 吸收存款
  - 发放贷款
  - 管理政府账户
```

议会同意了。英格兰银行（Bank of England）成立。

**这是一笔交易**：

| 政府获得 | 银行获得 |
|---------|---------|
| 120万英镑现金 | 政府每年付8%利息 |
| 解决军费危机 | 发行纸币的垄断权 |
| | 管理政府财政的地位 |

**英格兰银行的资本结构**：

- 初始资本：120万英镑
- 股东人数：1,268人
- 最大股东：国王威廉三世（10,000英镑）
- 股份可转让、可交易

**关键创新**：政府债务**证券化**。

120万英镑的国债被分成1,200股，每股1,000英镑。这些股份可以在市场上买卖。

**英格兰银行股价**（英镑，面值1000）：

| 年份 | 股价 | 年息 |
|------|------|------|
| 1694 | 1,000 | 80（8%）|
| 1697 | 1,200 | 96（8%）|
| 1700 | 1,450 | 116（8%）|
| 1710 | 1,600 | 128（8%）|

股价上涨意味着什么？**市场相信英国政府会还钱。**

#### 3.2.1 英格兰银行 vs 法国体系：制度对比的关键

英格兰银行（1694）和劳的通用银行/皇家银行（1716/1718）几乎同时期创建，但制度设计的差异决定了截然不同的命运。

**完整对比表**：

| 维度 | 英格兰银行（英国） | 劳的银行体系（法国） |
|------|-----------------|-------------------|
| **创始时间** | 1694年 | 通用银行1716年，改组为皇家银行1718年 |
| **资本结构** | 股份制，1268个股东 | 先股份制，后国有化（1718年王室接管） |
| **治理结构** | 24人董事会，股东大会选举 | 劳一人独裁，受摄政王指挥 |
| **发行纸币** | 有，但**谨慎**，承诺兑换金银 | 有，**过度发行**，1720年强制使用 |
| **储备金率** | 维持30-50% | 1719年后低于5%，最低时0.7% |
| **政府债务** | 承接，但限额（初始120万镑） | 承接全部30亿里弗尔（无上限） |
| **监督机制** | 议会监督、定期审计 | 无有效监督，王权决定一切 |
| **商业银行业务** | 存款、贷款、汇兑，独立经营 | 与密西西比公司捆绑，利益冲突 |
| **危机应对** | 1720年南海泡沫时，拒绝继续贷款（止损） | 1720年挤兑时，强制贬值、禁止持有金银（加剧恐慌） |
| **结果** | 存续至今（1946年国有化） | 1720年崩溃，纸币废除 |

**关键制度差异1：独立性**

**英格兰银行**：
```
议会授权 → 银行章程（法定） → 董事会（股东选举） → 业务决策
    ↑                                              ↓
    └────────────── 定期报告、审计 ←──────────────┘
```

银行可以拒绝政府的不合理要求。1720年南海泡沫时，银行拒绝继续贷款给南海公司，这保护了自身信誉。

**劳的银行**：
```
王权（摄政王） → 劳（财政总监+银行行长+公司总裁） → 印钞、炒股、承接债务
    ↑                                                      ↓
    └───────────────── 全部听命 ←──────────────────────┘
```

**关键制度差异2：纸币发行纪律**

**英格兰银行纸币发行量**（1694-1720）：

| 年份 | 纸币流通量（万英镑） | 金银储备（万英镑） | 储备率 |
|------|------------------|-----------------|--------|
| 1695 | 75 | 40 | 53% |
| 1700 | 180 | 80 | 44% |
| 1710 | 320 | 140 | 44% |
| 1720 | 510 | 200 | 39% |

**增长平稳，储备率维持在40%左右。**

**劳的纸币发行量**（见上一节表格）：

1719-1720年增长50倍，储备率从67%跌到0.7%。

**关键制度差异3：利益冲突隔离**

**英格兰银行**：
- 只管银行业务
- 不参与南海公司（虽然董事个人有投资）
- 南海泡沫崩溃时，银行的信誉反而提升（对比效应）

**劳的体系**：
- 同一人控制：银行、密西西比公司、税务总局
- 利益完全捆绑：印钞→买股票→股价涨→印更多钞
- 任何一环崩溃，全体系瓦解

**英国国债市场的成熟运作机制**（1720年代形成）：

**一级市场**（政府发行）：
```
政府需要100万英镑 → 财政部公告发债计划 → 认购（银行、商人、贵族）
   ↓
债券发行：面值100英镑，年息4%，期限永续或长期（20-99年）
   ↓
认购价格由竞价决定（可能高于或低于面值，形成即时收益率）
```

**二级市场**（交易）：

伦敦交易所（Exchange Alley）形成活跃的国债交易市场：
- 每日报价
- 券商做市
- 价格公开透明

**收益率曲线**（1720年代英国国债，年息%）：

| 期限 | 收益率 |
|------|--------|
| 短期债券（1-3年） | 3.5-4.0% |
| 中期债券（5-10年） | 4.0-4.5% |
| 长期债券（20年+） | 4.5-5.0% |
| 永续债券（Consols） | 4.0-5.5%（视信心而定） |

**永续债券的诞生**：

1751年，英国政府将各种短期债券合并重组为**统一公债**（Consolidated Annuities, Consols），年息3-4%，**永不到期**。

投资者获得永久的利息收入流，政府永远不需要偿还本金（只需付息）。

**Consols的逻辑**：

```
面值100英镑，年息3.5英镑（3.5%）
   ↓
投资者A以100英镑买入 → 每年收3.5英镑
   ↓
如果市场利率下降（政府信誉好），Consols价格上涨
   ↓
假设价格涨到120英镑 → 投资者A卖出，赚20英镑资本利得
   ↓
投资者B以120英镑买入 → 每年收3.5英镑（收益率2.9%）
```

**为什么Consols是制度胜利的标志？**

| 指标 | 含义 |
|------|------|
| **永续债可交易** | 说明市场相信英国**永远不会违约** |
| **收益率低** | 信用好，投资者愿意接受低回报 |
| **价格稳定** | 金融系统成熟，不易恐慌 |

**法国的对比**：

法国大革命前（1789），政府债务利率8-10%，是英国的2-3倍。原因：
- 没有议会监督
- 王室可以随意违约（历史上多次赖账）
- 没有成熟的二级市场

**借钱成本的差异决定了国力的差异**：

**七年战争（1756-1763）的融资对比**：

| 项目 | 英国 | 法国 |
|------|------|------|
| 战争总开支 | 8000万英镑 | 13亿里弗尔（约5000万英镑） |
| 通过借债融资比例 | 75% | 40% |
| 借款利率 | 4-5% | 8-10% |
| 战后债务负担（年息占收入） | 40% | 60% |
| 财政状况 | 可持续 | 破产（导致1789革命） |

**低利率让英国能以更低成本打更长的战争，最终赢得全球霸权。**

### 3.3 法国：约翰·劳的货币实验（1716-1720）

巴黎，1715年。

路易十四死了，留下一个烂摊子：30亿里弗尔的国债（相当于政府10-15年的收入），利率4-7%，每年光利息就要2亿里弗尔。

政府年收入才1.45亿里弗尔。入不敷出。

新摄政王奥尔良公爵（Philippe d'Orléans）找到一个苏格兰冒险家：约翰·劳（John Law）。

**劳的理论**：

```
经济增长受限于货币不足
   ↓
增加货币供应→刺激贸易→产出增加→财富增长
   ↓
纸币比金银更灵活，可以根据需要印刷
   ↓
建立一家银行,发行纸币,刺激经济
```

听起来很现代？但在1716年,这是异端邪说。主流观点是：货币必须是金银，纸币是骗局。

摄政王同意让劳试试。1716年，劳成立**通用银行**（Banque Générale），获准发行纸币。

**第一年很成功**：

- 纸币可以兑换金银，汇率固定
- 政府接受纸币缴税
- 商人逐渐接受纸币
- 经济开始回暖

1717年，劳更进一步：成立**密西西比公司**（Compagnie du Mississippi），获得法属路易斯安那（今美国南部大片土地）的贸易垄断权。

**劳的宏大计划**：

```
密西西比公司开发路易斯安那
   ↓
种植烟草、棉花、糖
   ↓
产品卖到欧洲，赚取巨额利润
   ↓
公司股价上涨
   ↓
股东财富增加→消费增加→经济繁荣
```

1719年，劳说服摄政王，让密西西比公司**承接政府全部债务**：

```
政府欠30亿里弗尔
   ↓
密西西比公司发行30亿里弗尔的股票
   ↓
债权人用国债换公司股票
   ↓
政府债务消失，变成公司股权
```

**密西西比公司股价**（里弗尔，面值500）：

| 时期 | 股价 | 涨幅 |
|------|------|------|
| 1719年1月 | 500 | - |
| 1719年8月 | 2,750 | +450% |
| 1719年12月 | 10,000 | +1,900% |
| 1720年1月 | **18,000** | **+3,500%** |

疯了。

**巴黎的街景**（1719年底）：

Rue Quincampoix（金康波街）——密西西比公司股票的交易中心。街道挤满了人，贵族、商人、仆人、妓女,都在买卖股票。

一个驼背人把背出租当书桌，每次收1里弗尔。

一个鞋匠靠炒股赚了几十万里弗尔，买了豪宅。

"百万富翁"（millionnaire）这个词在此时诞生。

但路易斯安那没有黄金，没有繁荣的种植园，只有沼泽、蚊子和敌对的印第安人。

1720年1月，有人开始兑现：把纸币换成金银。

劳的应对：**印更多钞票**，维持兑换。

2月，兑换加速。

5月，劳宣布贬值：纸币面值减半。

恐慌。

6月，挤兑。通用银行门口挤满了人，要求兑换金银。踩踏事件，15人死亡。

11月，系统崩溃。纸币变成废纸。密西西比公司股价跌到500（回到原点）。

劳逃离法国。

**法国的教训**：纸币不被信任长达一个世纪。法国大革命后发行的assignats（指券）再次失败，引发恶性通胀。

**英国的对比**：

| 指标 | 英国 | 法国 |
|------|------|------|
| 国债管理 | 议会监督、英格兰银行独立 | 国王独断、银行听命于王权 |
| 纸币 | 谨慎发行、可兑换金银 | 过度发行、强制使用 |
| 市场 | 相对自由 | 政府操纵 |
| 结果 | 国债市场繁荣,政府信用好 | 崩溃,纸币声名狼藉 |

**制度差异决定了货币实验的成败。**

## 第四章：贸易网络的暴力基础——奴隶贸易与种植园（1650-1800）

### 4.1 三角贸易的血腥几何

### 4.1 三角贸易的血腥几何

利物浦，1730年。

Slave ship *Brookes*号准备启航。船长检查货舱的布局图：

**货舱设计**（根据1788年废奴协会的测量图）：

```
长度：30米
宽度：7.6米
高度（下层）：1.5米
高度（上层）：1.2米

设计容量：
  - 男性：292人（下层）
  - 女性：130人（上层）
  - 儿童：90人（下层，男性区域之间）
总计：**482人**

实际每人空间：
  - 男性：183cm × 40cm（比棺材略宽）
  - 女性：同上
  - 儿童：140cm × 35cm
```

482个人，在1.2-1.5米高的空间里，侧身躺着，锁链连在一起，横渡大西洋。航程：6-8周。

**三角贸易的路线**：

```
第1段：利物浦→西非海岸（6周）
  - 货物：枪支、火药、酒、布匹、铜器
  - 目的：换取奴隶

第2段：西非→西印度群岛（中段航程，6-10周）
  - 货物：482名奴隶
  - 死亡率：15-20%（到达时剩410人左右）

第3段：西印度→利物浦（8周）

### 4.2 中段航程的恐怖

*Brookes*号，大西洋中段，1730年8月。

出发第3周。货舱里的温度超过40°C。没有窗户，唯一的通风来自甲板上的几个小舱口。

482人挤在一起，排泄物、呕吐物、汗水混成一片。气味令人窒息。

每天上午，船员打开舱口，把"货物"拉上甲板，分批"透气"1小时。然后赶回货舱，重新上锁。

**死因统计**（根据1790年代英国议会调查）：

| 死因 | 占比 |
|------|------|
| 痢疾（flux） | 40% |
| 天花 | 20% |
| 麻疹 | 15% |
| 坏血病 | 10% |
| 忧郁症（refusing to eat） | 10% |
| 其他（窒息、自杀、暴动） | 5% |

**"忧郁症"**：奴隶拒绝进食，选择饿死。船员的应对：用器具撬开嘴，强制灌食。如果还是拒绝，就放弃——扔到海里。

**自杀**：跳海。船员的应对：在甲板周围拉起高网。

**暴动**：1730年，10%的奴隶船发生暴动。船员用枪、刀镇压，杀死领头者，吊在桅杆上示众。

**死亡率随时间的变化**：

| 时期 | 死亡率 |
|------|--------|
| 1680-1700 | 25-30% |
| 1700-1750 | 18-25% |
| 1750-1800 | 12-18% |
| 1800-1807（废奴前）| 10-15% |

死亡率下降不是因为人道，而是因为**经济学**：死掉的奴隶不能卖钱。船长开始改进通风、增加食物、减少货舱密度。

**但即使10%的死亡率，在400万跨大西洋的奴隶贸易中，意味着40万人死在海上。**

**但为什么还有人投资？**

**投资回报率**（ROI）：

```

年利润：690英镑
ROI：4.1%
```

这和伦敦的国债收益率（4-5%）差不多！

**种植园的真正吸引力在于**：

| 优势 | 解释 |
|------|------|
| **资本增值** | 土地和奴隶价格上涨（1720-1770年牙买加地价涨3倍） |
| **社会地位** | 庄园主是殖民地精英阶层 |
| **政治权力** | 控制牙买加议会 |
| **税收优惠** | 殖民地税率低于英国本土 |

**最关键的收益：奴隶繁殖与转卖**：

```

### 4.4 糖的权力方程

为什么糖？

**糖的特殊性**：

1. **高价值**：1700年，糖在伦敦的价格是小麦的20-30倍/重量
2. **成瘾性**：糖与茶、咖啡结合，成为欧洲工人阶级的日常消费
3. **劳动密集**：甘蔗必须在砍下24小时内榨汁，否则糖分流失，需要大量集中劳动力
4. **规模经济**：大种植园（300+奴隶）成本远低于小农

**英国糖消费量**：

| 年份 | 总消费量（吨） | 人均（公斤/年） |
|------|--------------|---------------|
| 1700 | 10,000 | 1.8 |
| 1750 | 60,000 | 9.3 |
| 1800 | 150,000 | 15.6 |
| 1850 | 290,000 | 16.3 |

**从1700到1800年，人均消费增长8.7倍**。

糖从奢侈品变成日常品。工人阶级的早餐：面包+茶+糖。午餐：面包+啤酒。晚餐：粥+糖。

**糖提供了廉价的卡路里**，支撑了工业革命时期的劳动力再生产。

**商业革命的权力方程**（糖-奴隶-资本循环）：

```
非洲奴隶 → 加勒比种植园 → 糖 → 英国消费 → 利润 → 再投资到奴隶贸易
     ↑                                                    ↓
     └─────────────────────────────────────────────────┘
```

**这个循环的数量级**（1750年）：

| 环节 | 规模 |
|------|------|
| 奴隶贸易投资 | 200万英镑/年 |
| 奴隶运输 | 5-6万人/年 |
| 糖产量 | 15万吨/年 |
| 糖销售额 | 300万英镑/年 |
| 净利润 | 150万英镑/年 |
| 利润率 | 50-75% |

**英国GDP（1750）约1.5亿英镑。糖贸易占GDP的2%，但占利润资本的10-15%。**

#### 4.4.1 非洲内陆：捕获奴隶的战争经济

奴隶不是在海岸上凭空出现的。他们来自非洲内陆，通过一套由战争、劫掠、债务奴役组成的供应链。

**西非奴隶捕获的三大中心**（1650-1800）：

| 王国 | 地理位置 | 活跃时期 | 主要策略 |
|------|---------|---------|---------|
| **达荷美王国** | 今贝宁 | 1720-1850 | 年度战争、突袭邻邦 |
| **阿散蒂帝国** | 今加纳内陆 | 1701-1900 | 征服战争、债务奴役 |
| **奥约帝国** | 今尼日利亚西南 | 1600-1835 | 劫掠战争、贡纳奴隶 |

**达荷美王国：制度化的奴隶狩猎**

达荷美国王Agaja（1718-1740在位）创建了一套**年度战争制度**：

**达荷美的战争周期**（每年）：

```
1月-3月（旱季）：
  国王集结军队（常备军8,000人+民兵5,000人）
     ↓
  目标：邻近村庄、敌对部落
     ↓
  战术：夜间突袭、包围、焚烧村庄
     ↓
  俘虏：青壮年（奴隶）、妇女儿童（留用或卖掉）、杀死抵抗者
     ↓
4月：战役结束，押送俘虏到海岸（200-300公里）
     ↓
5月-6月：在威达（Ouidah）港口卖给欧洲商人
     ↓
7月-12月（雨季）：农业生产，准备下一年战争
```

**达荷美奴隶出口量**（人/年）：

| 时期 | 年均出口 | 国王分成 |
|------|---------|---------|
| 1720-1740 | 9,000-10,000 | 30%（国王垄断） |
| 1740-1780 | 10,000-12,000 | 40% |
| 1780-1810 | 8,000-10,000 | 50% |

**国王收入来源**：

```
奴隶交易收入：
  每个奴隶售价：15-25英镑（欧洲货物计价）
  国王抽成：每个奴隶约8英镑
  年出口10,000人 × 8英镑 = 80,000英镑/年
  
加上：
  - 向欧洲商人收取的港口税
  - 强制购买国王的"皇家奴隶"（质量更好，价格更高）
  
国王总收入：约100,000英镑/年
```

**达荷美的军事投入**：

| 项目 | 成本（英镑/年） |
|------|--------------|
| 常备军薪水 | 20,000 |
| 火器购买（火枪、火药） | 30,000 |
| 战争补给 | 10,000 |
| **总计** | **60,000** |

**净利润：40,000英镑/年**

**奴隶战争的工业化**：达荷美建立了**女兵军团**（Mino，亚马逊战士），约3,000-4,000人，专门训练捕获奴隶而非杀死敌人。

**阿散蒂帝国：黄金与奴隶的双重经济**

阿散蒂位于黄金海岸内陆，同时出口黄金和奴隶。

**阿散蒂的征服战争**（1701-1750）：

| 年份 | 目标 | 结果 | 获得奴隶（估计） |
|------|------|------|---------------|
| 1701 | 丹克亚王国 | 征服 | 5,000 |
| 1711-1720 | 邦曼人部落 | 年贡制度 | 2,000/年 |
| 1724 | 泰奇曼 | 屠杀+掳掠 | 8,000 |
| 1730-1750 | 北方诸部落 | 劫掠 | 3,000-5,000/年 |

**阿散蒂奴隶供应机制**：

| 类型 | 占比 | 来源 |
|------|------|------|
| **战争俘虏** | 50% | 年度征服战争 |
| **贡纳制度** | 30% | 附属部落每年缴纳奴隶作为贡品 |
| **债务奴役** | 15% | 欠债者自卖或被卖 |
| **刑罚奴役** | 5% | 犯罪者被判为奴隶 |

| 时期 | 年均出口 | 目的地 |
|------|---------|--------|

| 1780-1807 | 10,000-15,000 | 主要海岸 |

**奴隶价格的演变**（在非洲海岸，用欧洲货物计价）：

| 时期 | 价格（等值英镑） | 货物篮子 |
|------|--------------|---------|
| 1700 | 8-12 | 火枪2支+火药+布匹+铜器 |
| 1750 | 15-20 | 火枪3支+火药+酒+烟草+纺织品 |
| 1800 | 20-30 | 火枪5支+大量火药+酒+纺织品 |

**价格上涨的原因**：
1. 海岸附近人口枯竭，必须深入内陆
2. 欧洲需求增加
3. 火器成为必需品，非洲王国陷入军备竞赛

**火器-奴隶的恶性循环**：

```
欧洲商人进口火枪 → 非洲王国购买火枪 → 用奴隶支付
     ↓                                         ↑
     └→ 火枪用于战争 → 捕获更多奴隶 ──────────┘
     
结果：
  - 军备竞赛：没有火枪的部落被征服
  - 人口劫掠加剧：每个王国都需要更多奴隶换取火枪
  - 战争常态化：和平意味着军事落后，落后意味着被征服
```

**非洲内陆的人口损失**（1650-1850年，200年累计）：

| 地区 | 出口奴隶 | 战争死亡 | 间接死亡（逃难、饥荒） | 总损失 |
|------|---------|---------|---------------------|--------|
| 西非 | 550万 | 200万 | 300万 | **1050万** |
| 中非 | 400万 | 150万 | 200万 | **750万** |
| 东非 | 150万 | 50万 | 100万 | **300万** |
| **总计** | **1100万** | **400万** | **600万** | **2100万** |

**每出口1个奴隶，非洲内陆有2人死亡。**

**1750年的非洲西海岸**：

```
欧洲商船停泊 → 海岸堡垒（等待奴隶）
     ↑                    ↑
     └─ 等待时间：2-6个月 ─┘
     
奴隶从内陆行军到海岸：
  距离：200-500公里
  时间：2-4周
  锁链连接，颈枷固定
  死亡率：10-20%
  
到达海岸时：
  健康检查 → 不合格者被抛弃（饿死或病死）
  合格者烙印 → 装船 → 中段航程
```

**商业革命的奴隶贸易，在非洲建立了一套战争-捕获-出口的工业化系统，将数百万人变成了商品，将无数部落推入灭绝。**

## 第五章：商业革命的极限——权力方程的第一次转型（1720-1800）

### 5.1 增长的天花板

1750年，商业资本主义达到了它的巅峰——也是它的极限。

**商业革命的权力方程**：

$$
\Pi = (P_{sell} - P_{buy}) \cdot Q - C_{violence}
$$

其中：
- $\Pi$：利润
- $P_{sell}$：售价
- $P_{buy}$：收购价
- $Q$：贸易量
- $C_{violence}$：暴力成本（军队、海军、殖民管理）

**要增加$\Pi$，只有四个途径**：

1. **提高$P_{sell}$**：垄断市场，抬高售价
2. **降低$P_{buy}$**：压榨生产者（奴隶、殖民地农民）
3. **增加$Q$**：扩大贸易量
4. **降低$C_{violence}$**：更高效的暴力机器

**到1750年，这四条路都遇到了瓶颈**：

**瓶颈1：垄断的瓦解**

VOC的香料垄断被打破：
- 英国、法国东印度公司进入
- 香料树被走私到其他地区（法属模里西斯、英属锡兰）
- 价格下降：1650年肉豆蔻3盾/磅，1750年0.8盾/磅

**瓶颈2：压榨的极限**

奴隶死亡率已经降到10-15%，再降低需要大幅增加成本（更好的食物、医疗），抵消利润。

种植园工作时间已经达到每天11-13小时，一周7天，无法再延长。

**瓶颈3：市场饱和**

欧洲糖消费增长放缓：
- 1700-1750：年均增长4.5%
- 1750-1800：年均增长2.1%

香料市场饱和：欧洲胡椒消费1750年后几乎不增长。

**瓶颈4：暴力成本上升**

殖民地管理成本飙升：
- 英国在北美13个殖民地的行政+军事成本：1750年40万英镑/年，1775年200万英镑/年
- VOC的军事开支占总成本的比例：1650年10%，1750年30%

**商业资本主义无法突破这些瓶颈，因为它的本质是零和博弈**：

```
我的利润 = 我买得够便宜（压榨生产者）+ 我卖得够贵（垄断市场）
```

**要实现非零和增长，需要新的方程**：

$$
\Pi = (P - C) \cdot Q, \quad \text{where} \quad P \text{ and } C \text{ both decrease, but } P - C \text{ constant or increasing}
$$

翻译：降低售价、降低成本，但通过**产量的爆炸性增长**来增加利润。

**这需要工业革命。**

### 5.2 棉花：工业革命的预兆

印度，1750年。

孟加拉纺织工人用手摇纺车，把棉花纺成线。一个熟练工人一天能纺约100克线。

然后用手工织机，把线织成布。一个熟练工人一天能织约1米布。

**印度棉布的成本结构**（1750）：

| 项目 | 占比 |
|------|------|
| 原料（棉花） | 30% |
| 劳动（纺纱） | 40% |
| 劳动（织布） | 25% |
| 其他 | 5% |

印度棉布在18世纪是世界上最好的纺织品：
- 轻薄、透气
- 色彩鲜艳（印花技术）
- 价格比欧洲羊毛布便宜30-50%

**英国从印度进口的棉布**（百万码）：

| 年份 | 进口量 |
|------|--------|
| 1700 | 1.0 |
| 1720 | 2.5 |
| 1750 | 6.0 |
| 1770 | 8.5 |

英国本土纺织工人愤怒了：印度棉布抢走了他们的生意。

1700年，**《印花布法案》**（Calico Act）：禁止进口印度印花布。

1721年，进一步禁令：禁止在英国穿印度棉布。

**但禁令挡不住需求**。英国商人想：如果我们能在本土生产棉布，用英国的劳动力（工资比印度高3-4倍），还能赚钱吗？

答案：**只有用机器降低劳动成本**。

**纺纱技术的突破**：

| 年份 | 发明 | 效率提升 |
|------|------|---------|
| 1764 | 珍妮纺纱机（Spinning Jenny） | 1人操作8轴，产量8倍 |
| 1769 | 水力纺纱机（Water Frame） | 用水力驱动，产量10-20倍 |
| 1779 | 骡机（Mule） | 结合两者优点，产量200倍 |

**一个操作骡机的工人，产量相当于200个印度手工纺纱工**。

**英国棉布产量**（百万磅）：

| 年份 | 产量 |
|------|------|
| 1760 | 2.5 |
| 1780 | 5.0 |
| 1800 | 56 |
| 1820 | 135 |

40年增长27倍。

**价格**（便士/码）：

| 年份 | 英国棉布 | 印度棉布 |
|------|---------|---------|
| 1780 | 38 | 25 |
| 1800 | 20 | 25 |
| 1820 | 9 | 20 |

到1820年，英国机器生产的棉布，比印度手工布便宜50%以上。

**工业革命的权力方程诞生了**：

$$
\Pi = (P - C) \cdot Q
$$

**关键**：$C$（成本）暴跌，$P$（价格）下降，但$Q$（产量）爆炸，利润反而增加。

**商业资本主义 vs 工业资本主义**：

| 维度 | 商业革命 | 工业革命 |
|------|---------|---------|
| 利润来源 | 垄断、价差 | 大规模生产 |
| 竞争策略 | 暴力垄断 | 技术降成本 |
| 市场 | 奢侈品（小众） | 大众消费品 |
| 产量增长 | 受限于劳动力 | 几乎无限 |
| 权力基础 | 武装商船 | 工厂+机器 |

**1750-1800年，权力方程正在转型，从贸易利润转向工业利润。**

#### 5.2.1 英国vs印度：成本对比与机器化的必然性

**1780年，一匹棉布的完整成本对比**（英国 vs 印度）：

**印度手工生产**（孟加拉）：

| 环节 | 劳动时间 | 工资（便士） | 备注 |
|------|---------|-----------|------|
| 纺纱（100克线） | 10小时 | 15 | 手摇纺车 |
| 织布（5码） | 8小时 | 12 | 手工织机 |
| 漂白、染色 | 2小时 | 3 | 传统工艺 |
| **总劳动** | **20小时** | **30便士** | - |
| 原料（棉花） | - | 10 | - |
| **总成本** | - | **40便士** | - |

**英国机器生产**（1780年，珍妮纺纱机+水力织机）：

| 环节 | 劳动时间 | 工资（便士） | 备注 |
|------|---------|-----------|------|
| 纺纱（珍妮纺纱机） | 1.25小时 | 20 | 1人操作8轴，但英国工资高 |
| 织布（水力织机） | 0.5小时 | 10 | 机器驱动 |
| 漂白、染色（化学法） | 0.3小时 | 6 | 硫酸、氯气 |
| **总劳动** | **2.05小时** | **36便士** | - |
| 原料（美国棉花） | - | 12 | 进口，比印度棉贵 |
| 机器折旧+动力 | - | 8 | 水车、机械维护 |
| **总成本** | - | **56便士** | - |

**1780年，英国机器棉布比印度手工棉布还贵40%！**

**但到了1800年**：

**英国机器生产**（1800年，骡机+改进水力织机）：

| 环节 | 劳动时间 | 工资（便士） | 备注 |
|------|---------|-----------|------|
| 纺纱（骡机） | 0.1小时 | 5 | 产量200倍 |
| 织布（动力织机） | 0.15小时 | 4 | 完全机械化 |
| 漂白染色 | 0.2小时 | 4 | 规模化化学处理 |
| **总劳动** | **0.45小时** | **13便士** | - |
| 原料（美国棉花） | - | 8 | 产量增加，价格下降 |
| 机器折旧+动力（煤） | - | 6 | 蒸汽机出现 |
| **总成本** | - | **27便士** | - |

**印度手工生产**（1800年，基本无变化）：

| 总成本 | 40便士 |
|--------|--------|

**英国成本降到印度的67%，而且产量是印度的100倍。**

**这就是工业革命的本质**：
- 不是手工vs机器的一次性跃迁
- 而是**机器不断改进 → 成本持续下降 → 市场扩大 → 更多投资 → 更好的机器**的正反馈循环

**印度vs英国棉纺织业的命运**（1780-1850）：

| 指标 | 印度 | 英国 |
|------|------|------|
| 1780年产量 | 200万磅 | 5万磅 |
| 1820年产量 | 150万磅（萎缩） | 135万磅（增长27倍） |
| 1850年产量 | 50万磅（崩溃） | 580万磅（增长116倍） |
| 就业人数变化 | 200万手工纺织工失业 | 50万工厂工人就业 |

**英国用机器摧毁了印度的纺织业，然后把印度变成原棉产地和工业品市场。**

## 尾声：1750年的世界——第一次全球化的遗产

1750年，一个印度农民种植的棉花，可以：
- 被运到伦敦
- 用英国机器纺成线
- 织成布
- 卖到非洲

**这是人类历史上第一次，商品、人口、资本在全球范围内循环流动。**

**这个体系的三大支柱**：

1. **白银**：货币化了全球贸易
2. **股份公司**：组织了资本与暴力
3. **奴隶制**：提供了廉价劳动力

**这个体系的两大遗产**：

**遗产1：全球不平等**

1500年，世界各地区的人均收入差距约1.5-2倍（欧洲vs中国vs印度）。

1750年，差距扩大到3-4倍。

1900年，差距达到10-15倍。

**商业革命开启了大分流（Great Divergence）**。

**遗产2：资本主义的制度基础**

- 股份公司→现代公司制度
- 股票交易所→资本市场
- 国债市场→主权信用
- 中央银行→货币管理

**这些制度全部诞生于1600-1750年。**

**但商业革命无法再自我扩张。它的增长依赖于垄断、暴力、压榨。这些都有极限。**

**1750-1800年，权力方程正在转型：**

从

$$
\Pi = (P_{sell} - P_{buy}) \cdot Q - C_{violence}
$$

到

$$
\Pi = (P - MC) \cdot Q, \quad \text{where} \quad MC \to 0 \text{ as } Q \to \infty
$$

**从贸易利润到生产利润，从武装商船到蒸汽机，从垄断香料到大规模制造棉布。**

**工业革命的方程，正在英国的纺织厂里悄然成形。**
