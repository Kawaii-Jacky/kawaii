02 — Distributed roles

每个节点只管自己的任务

平移顶、能源和光学校准分开运行。主控出现问题时，能源节点仍可继续采样和上传数据，单个任务也更容易单独排查。

Node 01 / Orchestration

中央调度

读取雨水、温湿度与总负载；控制平移顶、电源、风扇；通过蓝牙 SPP 向 OnStep 发送 HOME、PARK、UNPARK 与 SET PARK 指令。

  • DHT11
  • Rain Sensor
  • INA226
  • Bluetooth SPP
Node 02 / Energy autonomy

能源自治

该节点基于开源硬件设计和开源算法，经参数适配后完成同步 Buck 调制、P&O MPPT、CC-CV 充电、动态散热、异常保护和独立遥测。

  • Open-source base
  • P&O
  • CC-CV
  • System integration
Node 03 / Optical calibration

拍摄联动

以有限状态机协调舵机、平场光源与防结露加热，让 Flat / Dark Flat 校准结束后自动恢复观测光路。

  • Servo
  • 5 kHz PWM
  • EEPROM
  • ESP-NOW
03 — System behavior

三条关键闭环

每条控制流程均包含感知、决策、动作和状态回传。

  1. FLOW 01 / Weather safety

    天气避险

    雨水或异常环境触发 → 拍摄设备处理 → 赤道仪归位 → 平移顶关闭 → 状态回传。

  2. FLOW 02 / Imaging

    远程拍摄

    Blynk 供电调度 → OnStep 解除归位 → 平移顶开启 → ZWO 拍摄 → 定时安全收束。

  3. FLOW 03 / Energy

    能源自循环

    光伏输入采样 → MPPT 跟踪 → 4S LiFePO4 充电 → SOC / 能耗遥测 → 负载持续供电。
