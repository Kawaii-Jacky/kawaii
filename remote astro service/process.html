01 — Development path

五次逐步确认

先确认空间和机械关系，再验证电路、接口与完整流程。前一步有结果后，我才进入下一步制作。

Phase 01 / CAD design

结构与空间预演

用透明线框同时观察外壳、平移顶传动、望远镜运动包络与控制箱位置，在制造前发现空间冲突。

Phase 02 / Circuit proof

洞洞板联合验证

以模块化方式连接 ESP32、功率计、传感器、驱动板与负载，先验证采样、控制、保护和通信，再进入紧凑装配。

Phase 03 / Integration

控制箱集成

把验证电路迁移到定制外壳，组织电源、天线、接口、散热与前面板标识，同时保留检修能力。

Phase 04 / Assembly

整机装配

太阳能板既承担供电，也成为箱体外部结构的一部分；望远镜、赤道仪和拍摄设备安装在平移顶覆盖的箱体内部。

Phase 05 / Scenario test

流程闭环实测

分别验证平移顶远程开合、雨水触发避险、拍摄设备供电与调度，以及平场板展开、发光、加热和归位流程。

验证目标是证明完整动作链条可执行；当前系统未部署为持续运行站点。
02 — Targeted optimization

针对现场使用做的优化

结构、供电、防水、移动和监控都围绕实际使用调整。目标是缩短搭建时间，并让设备在户外环境中更容易维护和收纳。

01

快速搭建框架

主体使用铝合金型材和铝塑板，框架便于切割、连接和拆装，后续增加接口或调整内部布局时也更方便。

02

可收纳太阳能平移顶

三块太阳能板单块 100W。顶板保留小角度倾斜，便于雨水排出；左右两块可调角度，也能折叠收纳。

03

整机可移动

底部安装四个带刹车万向轮。移动时可调整天文台位置，观测时锁止轮组，减少意外滑动。

04

大容量电池与密封防护

使用 50Ah 磷酸铁锂电池。泡沫箱负责隔热与缓冲，电池舱按防火、防水需求加强密封，降低温度变化和进水带来的风险。

05

雨水触发关顶

雨水传感器检测到水后，系统自动执行关顶动作，并把雨水状态和关顶结果上报到远程端。

06

内外双监控

外部摄像头用于查看云量、降水和现场天气，内部摄像头用于确认望远镜姿态、赤道仪位置和舱内状态。

这些优化已经落实到实物结构和控制流程中；长期户外耐候性、防火等级与密封寿命仍需要继续测试。
