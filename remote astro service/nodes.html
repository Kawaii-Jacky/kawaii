01 Master IoT Gateway

环境、机械与设备调度中枢

主控网关读取雨水和温湿度，直接控制平移顶、电源分路与风扇，并通过蓝牙 SPP 向 OnStep 赤道仪发送指令。

  • 环境避险DHT11、雨淋传感器及专属 PTC/PWM 防结露加热
  • 平移顶驱动12V 减速电机、齿轮齿条、机械上下限位与到位检测
  • 赤道仪网关HOME、PARK、UNPARK、SET PARK 等 OnStep 指令
  • 电源调度监控、ASIAIR、赤道仪与路由器的独立供电管理
  • 负载监测INA226 采集总电压、电流与实时功耗
02 MPPT Buck Charger

独立运行的光伏与电池管理

这一节点采用开源硬件设计和开源充电算法。我根据天文台使用的光伏组件、4S LiFePO4 电池和遥测需求完成参数适配与系统接入。同步 Buck 将最高 36V 光伏输入转换为充电输出，控制循环协调 P&O MPPT 与 CC-CV 策略。

  • 方案来源开源硬件设计与开源 MPPT / 充电算法
  • 功率拓扑同步 Buck，高压光伏输入至 4S LiFePO4 电池
  • 跟踪算法P&O 最大功率点跟踪与 predictivePWM 限制
  • 充电管理恒流 / 恒压多阶段控制，可配置满电限制
  • 保护恢复输入/输出过压过流、反接与 IUV 欠压恢复
  • 独立遥测板载 Wi‑Fi 直接连接私有 Blynk 服务器
  • 项目工作参数适配、遥测接入、整机集成与样机验证
03 Motorized Flat Panel

与拍摄序列联动的光学校准

平场节点以有限状态机完成展开、恒流发光、加热和安全归位。角度、亮度与湿度阈值保存于 EEPROM；5 kHz、8-bit PWM 用于减少相机滚动快门条纹。

  • 机械展开16 位硬件 PWM 驱动舵机平滑到达记忆角度
  • 平场发光5 kHz、8-bit PWM 亮度调节，范围 0–100%
  • 环境联动ESP-NOW 接收主控湿度并自动启动防结露加热
  • 参数保持EEPROM 保存角度、亮度、加热功率与湿度阈值
  • 安全收束曝光完成后先关闭光源，再撤离并释放观测光路
STATE 01 / DEPLOY

机械定点展开

舵机由安全位平滑移动至 EEPROM 预设角度，覆盖镜筒前端。

STATE 02 / EXPOSE

发光与曝光

读取记忆亮度，开启平场光源；根据湿度阈值联动加热。

STATE 03 / PARK

关闭与归位

光源缓灭，舵机返回 0° 安全位，保存状态并回到待机。

Engineering note

每个节点都能单独观察和调试

节点拆分便于功能组织和验证。能源节点可独立观察输入输出与保护状态；主控可单独执行避险和 OnStep 指令；平场节点可直接校准角度与亮度。
