# 知识笔记整理 Skill

## 触发条件

当用户要求：
- 将文章/视频/播客/讨论整理成笔记
- 创建新笔记并写入指定文件夹
- 对已有笔记进行结构化重写
- 用具体例子串联名词解释
- 精简/深入/重写已有笔记

## 前置步骤

1. **必读规则文件**：先用 Read 工具读取 `知识笔记写作规则.md`（项目根目录），获取全部格式规则。每次整理笔记都必须重新读取，不得凭记忆跳过。
2. **扫描现有笔记**：用 Glob 列出目标文件夹下的 `.md` 文件，了解已有笔记的主题和关联结构，为横向关联做准备。
3. **确认用户意图**：
   - 目标文件夹（如 `世界经济政治/`、`心理学/`）
   - 笔记标题（用户提供或从素材提炼）
   - 是否需要扩展已有笔记而非创建新笔记

## 核心工作流

### Step 1: 素材预处理

- 如用户提供的是文章/视频转写文本，直接使用
- 如用户指向已有笔记文件，用 Read 读取全文
- 如用户指向 `<current_note>` 标签，用 Read 读取该路径的文件
- 提取：核心论点、关键数据、专业概念、论证结构

### Step 2: 生成知识树

用 ```txt 代码块绘制树形结构：

```
根节点：[核心问题]
│
├── 一、[维度一]（[功能说明]）
│   ├── [要点1]
│   └── [要点2]
│
└── N、[维度N]（[收束]）
    └── [要点]
```

规则：
- 树的层级不超过三层（根 → 维度 → 要点）
- 叶节点用一句话概括，不写完整长段
- 知识树与正文章节严格对应

### Step 3: 前置声明（四要素必填）

在正文前用引用块（`>`）写：

| 声明项 | 说明 |
|--------|------|
| **根节点** | 核心问题，必须是有争议性或反常识的"为什么/怎么" |
| **叙事逻辑** | 推进路径，用"→"连接 |
| **立场说明** | 区分材料来源、整理者分析与公开事实 |
| **来源标注** | 信息来源及发布时间 |

### Step 4: 正文撰写

按知识树的维度逐章展开，同时执行以下子规则：

#### 4a. 概念定义（📌 引用块）

每个专业概念首次出现时立即定义：

```markdown
> 📌 **概念名（English Name）**：[一句话定义] + [与本文的关联说明]
```

- 定义紧跟首次出现段落之后
- 中英文名称并列
- 结尾说明"这个概念在本文中的作用"

#### 4b. 对比表格

凡涉及"A 与 B 的区别"或多维度比较，必须用表格：

```markdown
| 维度 | 选项A | 选项B |
|------|-------|-------|
| 维度1 | 描述 | 描述 |
```

- 表格前有引导句
- 表格后有收束句

#### 4c. 横向关联（嵌入正文，不得集中放结尾）

当论点与已有笔记形成镜像/因果/对照/上下游/互证关系时：

```markdown
> 🔗 **横向关联**：[本文要点] 与 [[关联笔记名]] 中的 [关联概念] 形成 [关系类型]——
> [一到两句话说明共同底层逻辑或对照点]。
```

关联类型：镜像关系、因果关系、对照关系、上下游关系、互证关系。

#### 4d. 关键统计数据保留

- 百分比、比例、金额、年份等支撑论证的数据必须完整保留
- 标注"作者用这个数字要证明什么"
- 如有较多数字，增加"关键统计数据与数字锚点"章节

### Step 5: 收束章节

最后一章完成三个动作：
1. **归因**：归结到制度/结构层面的根本原因
2. **延伸**：指出下一步可能发生什么
3. **个体坐标**：对普通人意味着什么

### Step 6: 索引表

每篇笔记末尾附索引表：

```markdown
| # | 概念/事件 | 时间 | 类型 | 所属维度 | 横向关联笔记 | 重要性 |
|---|---------|------|------|---------|------------|--------|
```

重要性评级：⭐⭐⭐⭐⭐ / ⭐⭐⭐⭐ / ⭐⭐⭐ / ⚠️

### Step 7: 参考来源

```markdown
## 参考来源

1. 作者/机构：《标题》，发布时间，链接或出处。
```

### Step 8: Frontmatter 更新

如笔记需要横向关联，在 YAML frontmatter 的 `关联` 字段中添加双向链接：

```yaml
关联:
  - "[[世界经济政治/相关笔记.md]]"
```

## 叙述视角

默认从材料/文章本身出发：
- ✅ "文章认为……"、"材料将这一点解释为……"
- ❌ "我认为作者这里说得对/不对……"、"这显然是……"

除非用户明确要求"评论、反驳、批判"，否则正文不夹杂整理者个人判断。

## 禁止事项

| 禁止行为 | 原因 |
|---------|------|
| 直接引用大段原文 | 笔记的价值在于再加工 |
| 仅用连续段落描述比较关系 | 表格比散文更清晰 |
| 把分析、推测写成确定事实 | 混淆会误导读者 |
| 专业概念只写中文名不写英文名 | 阻断检索路径 |
| 横向关联只写"详见××笔记" | 没有说明理由等于没有关联 |
| 把所有横向关联统一堆在结尾 | 切断关联与具体论点的语境 |
| 知识树与正文章节不对应 | 知识树失去导航功能 |

## 输出位置

默认写入项目根目录下的对应学科文件夹：
- `世界经济政治/` — 经济、政治、哲学、社会学
- `心理学/` — 心理学、个人观察
- `中国历史/` — 中国历史
- `哲学/` — 哲学
- `生物学/` — 生物学
- `电子、计算机和通信/` — 电子/计算机
- `艺术学习/` — 艺术

文件名应为中文，能概括笔记核心主题。
