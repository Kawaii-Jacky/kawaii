

|对比维度|npm|npx|pnpm|
|---|---|---|---|
|**定位**|Node 官方包管理器|npm 内置的命令执行工具|高性能包管理器（npm 替代品）|
|**核心作用**|安装、管理、卸载项目依赖包|临时执行某个包的命令，无需全局安装|高效安装管理依赖，节省磁盘空间|
|**是否自带**|安装 Node.js 后自动自带|npm 5.2+ 内置，随 npm 一起安装|需要单独安装|
|**全局安装命令**|`npm install -g 包名`|—|`pnpm add -g 包名`|
|**项目安装依赖**|`npm install 包名`|—|`pnpm add 包名`|
|**开发依赖安装**|`npm install 包名 -D`|—|`pnpm add -D 包名`|
|**执行项目脚本**|`npm run dev`|—|`pnpm dev`（可省略 run）|
|**临时运行工具**|—|`npx 包名`|`pnpm dlx 包名`|
|**清理缓存**|`npm cache clean --force`|—|`pnpm store prune`|
|**锁文件**|`package-lock.json`|—|`pnpm-lock.yaml`|
|**磁盘占用**|高，每个项目独立复制一份依赖|无本地存储，临时下载用完即删|极低，全局硬链接共享同一份依赖|
|**下载速度**|较慢|单次临时下载|快（并行下载 + 缓存复用）|
|**依赖隔离性**|扁平化结构，容易幽灵依赖|—|严格隔离，结构清晰|
|**典型使用场景**|基础项目依赖管理|偶尔用一次的脚手架、CLI 工具|中大型项目、多项目并行开发、节省磁盘|
