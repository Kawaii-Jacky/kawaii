# 系统性研究引擎原型

## 核心思想

**不是推理更长，是搜索更全面**

传统方法：
- 人类专家：基于直觉选择3-5个"最可能"的机制
- 大语言模型：模拟专家，同样基于"直觉"

系统性方法：
- 结构化遍历所有生物学层次
- Template-based生成 + LLM创造性补充
- 系统性检查约束条件
- 识别被忽视的机制

## 工作流程

```
问题输入
    ↓
┌─────────────────────────────────────┐
│ Phase 1: 系统性生成机制空间           │
│                                     │
│ 方法：                              │
│ - 遍历7个生物学层次                  │
│ - 每层次3-5个机制类型                │
│ - LLM创造性补充                     │
│                                     │
│ 输出：40-60个候选机制                │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ Phase 2: 约束条件提取                │
│                                     │
│ 对每个机制提取：                     │
│ - 必要条件（如果不满足就不成立）      │
│ - 可检验预测                        │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ Phase 3: 约束满足检查                │
│                                     │
│ 检查每个必要条件是否：                │
│ - 物理上可行                        │
│ - 生物学上合理                      │
│ - 逻辑上consistent                  │
│                                     │
│ 剪枝不可行的机制                     │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ Phase 4: 生成人类baseline            │
│                                     │
│ 让LLM模拟人类专家的典型分析           │
│ （3-5个最obvious的机制）             │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ Phase 5: 对比分析                   │
│                                     │
│ 识别：                              │
│ - 系统性方法发现了多少机制            │
│ - 哪些是人类可能忽视的               │
│ - 覆盖了哪些层次                     │
└─────────────────────────────────────┘
    ↓
  报告输出
```

## 人类专家的典型分析（baseline）
1. 前肢骨骼延长形成翼骨架
   为什么obvious：这是最直观的形态差异

2. 飞膜（翼膜）的演化
   为什么obvious：飞行的必需结构

3. 高代谢率支持飞行能量需求
   为什么obvious：飞行是高能耗活动

4. 体型小化降低飞行成本

  - 生殖策略的改变（飞行vs繁殖的权衡）

## 系统性分析发现的机制（按层次）

### MOLECULAR 层次 (5个)

1. Prx1基因表达域扩展导致前肢延长
   必要条件：
     - Prx1必须在前肢发育早期上调
     - 下游靶基因（如Fgf10）必须响应
   可检验预测：
     - 蝙蝠胚胎Prx1表达域比其他哺乳动物更宽
     - 实验性扩展Prx1在小鼠中应导致前肢延长

2. BMP信号通路抑制允许指间膜保留
   必要条件：
     - 正常哺乳动物发育中BMP4诱导指间凋亡
     - 蝙蝠必须下调BMP4或上调其抑制剂
   可检验预测：
     - 蝙蝠胚胎指间区域BMP4表达低于小鼠
     - 抑制小鼠BMP4应保留指间膜

### DEVELOPMENTAL 层次 (6个)

1. 异时发育（Heterochrony）：前肢生长期延长
   必要条件：
     - 前肢生长板关闭时间必须延迟
     - 不能影响其他肢体（否则全身比例失调）
   可检验预测：
     - 蝙蝠前肢骨骺板闭合时间晚于后肢
     - 生长激素在前肢表达时间更长

2. 指间凋亡程序抑制（heterochrony + 细胞死亡调控）
   ...

### PHYSIOLOGICAL 层次 (4个)

1. 心肺系统大幅增强以供氧
   必要条件：
     - 飞行肌需要高氧供应（~10x静息代谢）
     - 心脏必须增大 OR 心率必须提高
   可检验预测：
     - 蝙蝠相对心脏质量 > 非飞行哺乳动物
     - 最大心率 > 200 bpm

2. 肠道长度减少以降低体重
   ...

### ECOLOGICAL 层次 (5个)

1. 夜行性昆虫资源的空生态位
   必要条件：
     - 必须存在丰富的夜行性飞行昆虫
     - 竞争者（鸟类）在夜间不活跃
   可检验预测：
     - 蝙蝠辐射时间与夜行昆虫辐射重叠
     - 蝙蝠多样性与夜行昆虫密度正相关

2. 逃避地面捕食者压力
   ...

### EVOLUTIONARY 层次 (4个)

1. 从滑翔到飞行的exaptation路径
   必要条件：
     - 祖先必须有树栖习性
     - 滑翔膜必须能渐进演化为动力飞行翼
   可检验预测：
     - 最早的蝙蝠化石应显示中间形态
     - 现存滑翔哺乳动物的飞膜结构应与蝙蝠部分同源

2. 发育约束突破：指骨独立延长的能力
   ...

2. [physiological] 褪黑素代谢改变使能夜行性与飞行协同

## 验证价值的实验

### 实验设计

1. **招募5-10位演化生物学博士**
2. **给他们同一个问题**（如上例）
3. **要求他们列出会考虑的机制**（限时30分钟）
4. **运行这个系统**
5. **对比**：
   - 系统发现了多少人类遗漏的机制？
   - 这些"遗漏的机制"是否有科学价值？
   - 系统是否产生了nonsense？

### 成功标准

如果：
- ✅ 系统发现的机制数量 > 3x 人类平均
- ✅ 至少20%的"新发现"被专家认为"有意思，我确实没想到"
- ✅ False positive rate < 30%（系统生成的机制中，合理的占70%+）

→ 则证明了"系统性穷尽"的价值

## 当前限制（原型版本）

1. **约束检查还很简单**
   - 现在只是让LLM判断"可行/不可行"
   - 应该：构建真正的约束传播网络

2. **没有文献整合**
   - 现在纯靠LLM知识
   - 应该：实时检索PubMed

3. **没有定量模型生成**
   - 现在只生成文字描述
   - 应该：自动生成R/Python代码

4. **新颖性检测很粗糙**
   - 现在只是简单的关键词匹配
   - 应该：语义相似度 + 因果图同构检测

## 关键insight

**这个系统不是"推理更深"，是"搜索更全"**

类比：
- 人类专家 = 国际象棋大师（深度+直觉）
- 这个系统 = AlphaZero（系统性搜索+评估）

人类专家很强，但会被认知偏见限制：
- Confirmation bias（只找支持的证据）
- Availability heuristic（只想到容易想起的）
- Anchoring effect（被第一个想到的锚定）

系统性搜索没有这些偏见：
- 遍历所有层次
- 检查所有因果类型
- 不漏掉"不直观"的机制

## 与"多专家"架构的区别

**之前的设计（错误）**：
```
生态学专家 ──┐
基因组学专家 ├─→ 综合
生理学专家 ──┘

问题：这只是"3个人各说各的"，不是深度
```

**现在的设计（正确）**：
```
系统性遍历算法 → 生成50+机制 → 约束剪枝 → 发现遗漏

价值：不是"多视角"，是"无盲区"
```
