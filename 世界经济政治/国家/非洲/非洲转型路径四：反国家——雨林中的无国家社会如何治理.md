## 一、路径定义：反国家不是「未建国」

> 📌 **反国家路径（Anti-State Path）**：在土地相对充裕、人口可随时迁移的环境中，人们通过**分散居住、跨世系组织、仪式性权威与市场仲裁**来维持秩序，而**拒绝**建立常设中央权力。**本文中的作用**：它把「无国家」从「发展失败」重新定义为**一种与环境的匹配策略**——它的成本是「无法组织大规模防御」，收益是「没有人能对你征重税」。

用 Hirschman 的三选项框架（exit / voice / loyalty）看：

| 选项 | 在无国家社会中的形式 | 成本 |
|------|---------------------|------|
| **Exit（退出）** | 搬走：开新地、迁往另一世系、加入另一村群 | 低（土地充裕） |
| **Voice（发声）** | 在村群会议、年龄组、社团中施压 | 中 |
| **Loyalty（忠诚）** | 接受长者仲裁与神谕裁决 | 低 |

当一个社会里 **exit 的成本低于 voice 的成本**时，任何试图集中权力的努力都会失败：**被统治者不需要反抗，只需要搬走。**

> 🔗 **横向关联**：本节「exit 低于 voice」与 [非洲转型路径三：集约农业——大湖区的香蕉、牛群与强酋邦](非洲转型路径三：集约农业——大湖区的香蕉、牛群与强酋邦.md) 形成**镜像关系**——大湖区因为香蕉园不可搬走，exit 成本极高，于是 voice 被压制、王权得以建立；雨林因为可以随时开新地，exit 成本极低，于是王权无法建立。**两条路径的分岔点不是文化，而是一块地能不能被搬走。**

## 二、雨林的物质基础：四把锁与一个容量上限

要把「雨林为什么没长成国家」讲成一条链，先得说清国家需要什么。从路径一（埃及）、路径二（桑海）、路径三（布干达）反推，国家形成需要四项供给，任一项长期为零，政体就退化成别的形态：

| 必要条件 | 具体含义 | 为零时会怎样 |
|---------|---------|-------------|
| **可计量的剩余** | 产出集中、可储存、可按单位折算 | 无法编预算，养不起脱产者 |
| **可固定的人口** | 人口无法低成本迁走 | 征税成本高于税额 |
| **可垄断的暴力** | 存在「统治者有、被统治者没有」的武力代差 | 只能协商，不能强制 |
| **可扩张的信息** | 能把义务记录到「面对面」之外 | 组织规模卡在熟人社会 |

下面五节逐一交代：雨林在每一条上分别缺什么，以及为什么这四项缺失会互相加强，而不是各管一段。

### 2.1 第一把锁：土壤——养分不在土里，在树里

热带雨林的养分主要储存在**生物量**（植被与枯枝落叶层）中，而不在土壤里。原因是一旦有机物分解，暴雨会在几天内把可溶养分淋溶到根系以下。这带来一个反直觉的结论：**雨林土壤往往比温带草原更贫瘠**。

更具体的物理化学障碍有三条：

| 障碍 | 机制 | 后果 |
|------|------|------|
| **强酸性** | 高度风化土壤 pH 常在 4—5 | 多数作物根系受铝离子毒害 |
| **磷被固定** | 铁铝氧化物强烈吸附磷酸根 | 施磷肥也大多无效，产量无法靠投入拉高 |
| **有机质快速分解** | 高温高湿下分解速度极快 | 肥力只存在于地表薄薄一层枯枝落叶 |

| 特征 | 后果 |
|------|------|
| 养分在植被层 | 砍烧后肥力只能维持 2—3 年 |
| 需要长期休耕（15—20 年） | 必须占用大面积土地轮换，人口密度被压低 |
| 采采蝇与湿度 | 无法养马、无法用犁，畜力受限 |
| 木材丰富但运输困难 | 可建屋、可造舟，但难形成规模市场 |

**收束**：三者的合成效果是——**土地不能靠「投入」提高产出，只能靠「换一块地」维持产出**。这是它与路径三（香蕉园可以越管越高产）最根本的区别。

### 2.2 第二把锁：作物——薯蓣为什么做不成国库

这一节是全篇最关键的一环，因为它把「农业」直接连到了「国家能力」。

> 📌 **税基的可计量性（Taxable Measurability）**：指产出能否按统一单位快速折算、长期储存、并在运输后仍可核验。**本文中的作用**：它决定了「剩余」能否从实物变成预算——**没有可计量性，就没有国库；没有国库，就没有常备军与官僚。**

| 维度 | 谷物（高粱/粟/小麦） | 薯蓣（yams） |
|------|--------------------|-------------|
| 含水率 | 约 12—14%，可干燥至安全水分 | 约 70—80%，含水量高 |
| 储存期 | 干燥后可存 1—3 年 | 常温下数周至数月，易腐烂 |
| 计量方式 | 按体积（斗、篮）或重量，个体差异小 | 个体差异大，需逐个清点 |
| 运输 | 可袋装、可堆叠，损耗低 | 易碰伤腐烂，运输半径小 |
| 留种比例 | 5—15% | 约 20—30%（下一季的「种子」就是上一季的产量） |
| 征收成本 | 低（一次清点入库） | 高（需现场逐堆估算，且腐烂责任难界定） |

三条推论直接把国家挡在门外：

1. **没有国库**：剩余无法在地点累积，只能随人群移动。国家不能建粮仓，就不能养脱产的书吏与士兵。
2. **征税不划算**：征收需要现场清点 + 承担腐烂风险，**行政成本接近甚至超过税额**。
3. **剩余只能以「人」的形式积累**：既然存不住粮，就存人——亲属、依附民、奴隶。这就是 **wealth in people** 的物质起点。

> 📌 **土地的已改造价值（Capital Improvement on Land）**：指过去投入的劳动中沉积在土地上、能跨季留存、并随土地一起被转让的那部分价值；判据为持续性、可转移性、可识别性三条。**本文中的作用**：雨林薯蓣地的已改造价值接近零（土垄与支架当年报废），因此土地无法成为可继承的资产——完整定义见 [非洲转型路径三：集约农业——大湖区的香蕉、牛群与强酋邦](非洲转型路径三：集约农业——大湖区的香蕉、牛群与强酋邦.md) §2.1.1。

当土地的价值差很小时，三件事随之发生：

- 争夺土地无利可图 → 战争的主要目标变成**抢人**（俘虏、依附民、奴隶）。
- 人口是稀缺资源 → 权力体现为「能支配多少人」。
- 谁都可以离开 → 统治者必须**宽待**下属，否则人走楼空。

> 🔗 **横向关联**：本节「薯蓣做不成国库」与 [农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）](../../../人类学/农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）.md) 的「可储存谷物是国家的前提」这一论证形成**互证关系**——那篇从底格里斯-幼发拉底与黄河流域提炼出「储存技术→提取率→官僚」的链条，本文则给出这条链在雨林**断在哪一环**：不是储存技术不足，而是**作物本身不可储存**。

### 2.3 第三把锁：疾病与迁徙——税基是液体

| 疾病/约束 | 传播机制 | 人口学后果 |
|-----------|---------|-----------|
| **恶性疟疾** | 按蚊，低地高传播 | 婴幼儿死亡率高，人口增长被压制 |
| **锥虫病** | 采采蝇 | 人畜共患，限制畜力与定居点选址 |
| **河盲症** | 黑蝇（沿急流繁殖） | 河谷被弃耕，沿河定居点稀疏 |
| **黄热病** | 伊蚊 | 周期性暴发，城市化受限 |

非洲热带雨林的历史人口密度长期在**每平方公里 1—5 人**量级（估算），而大湖区高地可达**数十至上百人**。这个量级差决定了一件事：**在雨林里「收税」需要先「找人」**，而找人的成本被地形与分散居住推得极高。

同时，**exit 的成本接近于零**：一把斧头、一把火，任何成年人都能在几天内清出一块新地。当搬走的成本低于被统治的成本时：

- 统治者的**威胁不可信**（你征税，我就走）；
- 任何集中权力的尝试都会以「人口流失」告终；
- 领袖必须靠**给**而不是靠**取**来维持追随者。

**收束**：这一段的三条约束（疾病压低密度、地形抬高搜寻成本、迁徙成本近零）合成一个结果——**税基是液体，收不上来**。

### 2.4 第四把锁：军事技术——没有马，就没有「剪刀差」

> 📌 **武力剪刀差（Military Scissors Gap）**：统治者相对于被统治者拥有的、无法被后者自行复制的武力优势（如骑兵、城堡、火器）。**本文中的作用**：没有剪刀差，就没有「强制」；没有强制，就只剩「协商」——这正是无国家社会的政治常态。

雨林的军事技术结构有一个硬边界：**打不赢也跑不掉的东西不存在**。

| 要素 | 草原/萨赫勒 | 雨林 |
|------|-------------|------|
| 马匹 | 可养（无采采蝇），骑兵成为国家工具 | 采采蝇使马匹难以存活 |
| 畜力深耕 | 牛犁可提高单产 | 无法用犁，只能手锄 |
| 行军半径 | 骑兵日行 40—60 公里 | 步兵日行 20—30 公里，开路时更慢 |
| 运输 | 骆驼/牛车 | 只能靠人背与舟运 |
| 武器代差 | 马 + 铁甲 + 弓骑兵 | 弓、矛、盾、毒箭——**人人可自制** |

两条推论：

1. **武力无法被垄断**：当武器是「人人能造的弓矛」时，任何强人都无法建立持久的武力优势，只能靠**声望、年龄组与联盟**。
2. **控制半径极小**：以步兵为核心，一个政治中心的实际控制半径被压到「数日行军圈」，超过这个半径，命令就失效。

这也解释了为什么非洲的国家几乎全都贴着**无采采蝇带的边缘**出现——它们不是在雨林里建国，而是在雨林的**边界**上建国。

### 2.5 放大器：信息——口传记账的容量上限

前四把锁解释了「物质上做不到」，这一节解释「即使有人想做，也算不过来」。

国家规模的本质是**记账能力**：能记住多少人的义务，就能统治多少人。雨林社会没有本土文字系统（刚果 16 世纪后有限使用拉丁文是例外），义务靠口传、仪式与亲属关系记忆。

于是 **wealth in people 本身就是一种记账法**：

| 记账方式 | 载体 | 容量上限 | 失效方式 |
|---------|------|---------|---------|
| 文书 + 税籍 | 档案、地籍、户籍 | 理论上无上限 | 需要识字阶层与仓储 |
| 亲属关系 + 仪式 | 谱系记忆、入会等级、婚姻 | **数百人量级** | 超过容量就分裂 |

**收束**：这一点把「分裂性世系」从「落后」重新解释为**一种扩容策略的反面**——当单点信息负荷超载时，**分裂是降低负荷的手段**。所谓「部落越分越多」，不是混乱，而是**记账容量到了上限**。

### 2.6 四把锁如何锁死：一个自我维持的均衡

单看每一把锁都不致命（历史上无数社会缺其中一两项仍能建国）。真正的问题是**四项同时为零时会互相加强**：

```txt
土壤不能靠投入提高产出
      ↓
剩余无法在固定地点累积（无国库）
      ↓
养不起脱产的武力与官僚
      ↓
无法强制人口定居、无法阻止迁徙
      ↓
人口流动 → 无人可征 → 更无法集中剩余
      ↺（回到第一环，且更难打破）
```

| 如果只缺一项 | 历史上有哪些出路 |
|-------------|-----------------|
| 只缺剩余 | 靠掠夺建国（如 19 世纪 Mangbetu） |
| 只缺人口固定 | 筑城、设关卡、绑在土地上（如路径三的 mailo） |
| 只缺武力剪刀差 | 引进外部技术（如火枪，见路径二的阿卢马） |
| 只缺记账 | 借外来书吏（如路径二的外来者阶层） |
| **四项同时缺** | **均衡：不建国反而是低成本解** |

**收束**：所以「无国家」不是「还没有走到那一步」，而是**在一个特定参数组合下，建国是亏本生意**。这解释了它为什么能稳定存在上千年，而不是像「技术落后」那样自动被淘汰。

### 2.7 反证五例：哪些生态位把锁打开了

只讲「雨林为什么不能」容易陷入环境决定论。更有说服力的是反过来问：**在同样的农业工具箱下，哪里长出了国家，为什么？**

| 地点 | 生态位 | 被解开的那把锁 | 结果 |
|------|--------|---------------|------|
| **大湖区**（布干达/卢旺达） | 高原、火山土、无疟疾、可养牛 | 疾病与土壤 → 密度上升；香蕉园 → 土地成为资产 | 强酋邦→王国（路径三） |
| **刚果河口**（刚果王国） | 森林-草原过渡带 + 河运 | 剩余可沿河集中 | 有宫廷与省制的王国 |
| **津巴布韦高原**（大津巴布韦/穆塔帕） | 草原带、无采采蝇 | 牛 + 金 → 武力与剩余同时解锁 | 石构国家与黄金出口 |
| **森林-草原过渡带**（奥约/贝宁） | 可养马 | 武力剪刀差成立 | 骑兵帝国与森林王国 |
| **伊博地区**（反证的反证） | 高密度聚落、薯蓣 + 油棕 | 密度解锁了，但**土地仍非资产、仍无马** | 依然无国家 → 转向头衔协会与神谕 |

**收束**：五例最关键的信息是——决定性的不是「雨林」这个标签，而是**采采蝇带、谷仓、迁徙成本、土地资产化**这四个变量的具体取值。伊博这一行尤其重要：它证明**密度是必要不充分条件**，高密度可以在没有国家的情况下维持。

> 🔗 **横向关联**：本节「反证五例」与 [非洲区域划分方法论：环境带、互动圈与五条转型路径的三层坐标](非洲区域划分方法论：环境带、互动圈与五条转型路径的三层坐标.md) §三「9 个环境带」形成**验证关系**——方法论那张表给出的是**先验分区**，本节五例则是用「国家出没在哪」来**反向检验**那些边界是否有效。结论是：有效的不是气候带，而是采采蝇带与可储存作物的分界。

### 2.8 边界：环境设定成本函数，不是命运

必须承认两个反例，否则上面的论证会变成环境决定论：

**反例一：Mangbetu 与 Zande 的「人国」。** 18—19 世纪，刚果东北的 Mangbetu 在雨林中建立了有宫廷、有官职、有常备武装的王国。它的财政基础不是土地，而是**掠夺来的人口**——通过掠奴、象牙贸易与外部火器，把「以人为财富」的逻辑推到国家规模。

**反例二：河流网络。** 刚果河与乌班吉河上的商人网络（如 Bobangi）能组织跨越数百公里的贸易与信用，但形态始终是**网络**而不是**领土国家**——因为它不需要统治两岸的农民，只需要控制码头与航道。

**收束**：两例共同说明——**环境决定的不是「有没有国家」，而是「建国要花多少钱」**。当外部需求（象牙、奴隶、橡胶）把掠夺的收益抬高时，雨林里也会出现国家；但这种国家的财政建立在持续掠夺上，一旦外部需求消失或殖民军队到来，它就崩解。这正是它没能演化为「传统国家结构」的最后一块拼图。

## 三、五套治理装置与国家装置的功能对照

### 3.1 世系制与分裂性世系

> 📌 **分裂性世系（Segmentary Lineage）**：以共同祖先为纽带、可按层级不断分裂与合并的亲属组织。相邻的支系平时各自为政，遇到外部威胁时可以合并成更大的单位。**本文中的作用**：它提供了一种**无需中央政府的分层合作机制**——「我兄弟的敌人是我的敌人」这条规则，就是它的宪法。

### 3.2 年龄组：跨世系的横向组织

年龄组（age sets / age grades）把同龄人按批次组织起来，承担军事、劳役、仪式与治安职能。它最重要的功能是**切断世系与武力的独占关系**：如果一个世系想私自发动战争，它必须取得同龄组的同意。

### 3.3 秘密社团：跨村执法

> 📌 **秘密社团（Secret Society）**：如 Poro、Ekpe、Ogboni 等，以入会仪式、等级与保密规则组织跨村精英，承担司法、执法、仪式与政治协商功能。**本文中的作用**：它是无国家社会里的「超村政府」——**没有常设机构，但有可强制执行的裁决**。

### 3.4 头衔协会：用声望替代权力

伊博社会的 ozo 头衔体系是一个典型：通过宴请与馈赠购买头衔，获得议事权与声望，但**不获得对人身的强制权**。它的政治效果是：**权力被分散成许多可购买的「席位」**，任何人无法垄断。

### 3.5 市场-神庙共同体：跨区仲裁与信用

市场不只是交易场所，还是**司法场所**：市场日=开庭日，市场神=契约见证。跨村纠纷在市场上由长者或神谕裁决，裁决的执行靠**共同体的联合抵制**（谁不服从，谁就被排斥在所有市场之外）。

### 3.6 与国家治理装置的对照：九项功能、五组装置、三条原理

为什么要做这个对照：因为「无国家」最容易被误读成「无治理」。把两套装置按**功能**并排，会发现它们不是「有与无」，而是**同一功能的两种实现**——代价不同、上限不同、失效边界也不同。

#### 表 A：功能层对照（九项）

| 治理功能 | 国家装置 | 无国家装置 | 无国家装置的成本优势 | 它的失效边界 |
|---------|---------|-----------|---------------------|-------------|
| **立法**（规则生产） | 成文法、法典、敕令 | 祖训、禁忌、市场惯例、神谕判例 | 无需常设机构，规则随人群迁移 | 规则碎片化，跳区不一致 |
| **裁决**（纠纷处理） | 法院、法官、上诉审 | 长者会议、头衔持有者、神谕 | 无诉诉费与程序延迟 | 无强制管辖权，需双方自愿提交 |
| **执行**（裁决落地） | 警察、法警、监狱 | 社团执法、联合抵制、逐出 | 成本分摊到共同体，无监禁开支 | 对「不在乎共同体的人」无效 |
| **防御**（外部暴力） | 常备军、边墙、要塞 | 年龄组民兵、世系合并、地形 | 平时成本近零 | 无法应对跳区职业武装 |
| **资源动员** | 税收、徭役、国库 | 互惠馈赠、年龄组劳役、头衔宾请 | 无需计量与征收机构 | 规模上限极低，无法支撑常驻人口 |
| **身份认定** | 户籍、身份证、人口登记 | 世系谱系、入组仪式、入会仪式 | 无需文书，靠记忆与仪式 | 外来者难以归位，易被排斥 |
| **跳期合作**（信用） | 契约法、公证、货币、银行 | 婚姻联盟、牛与种子借贷、市场神见证 | 以关系作抵押，违约成本是社会性的 | 半径受通婚与市场网络限制 |
| **惩罚** | 刑罚、监禁、死刑 | 赔偿、逐出、巫术指控、社团制裁 | 无监狱成本 | 容易被滥用为「诬巫」 |
| **合法性生产** | 意识形态、宗教、教育、仪式 | 祖先崇拜、入会神话、神谕权威 | 无需官僚系统维护 | 易被商业或政治利益俘获 |

#### 表 B：装置级对照（机构对机构）

| 功能位置 | 国家里对应谁 | 无国家社会里对应谁 | 关键差别 |
|---------|-------------|-------------------|---------|
| 行政中枢 | 官僚制（科层、文书、任期） | 世系长者网络（辈分、谱系记忆） | 前者按**职位**继替，后者按**辈分**继替 |
| 暴力组织 | 常备军（脱产的专职者） | 年龄组（未脱产的同龄批次） | 前者可长期驻防，后者只在紧急时集结 |
| 司法／执法 | 法院 + 警察 | 秘密社团 + 神谕 | 前者有**地域**管辖权，后者有**人**的管辖权 |
| 地位授予 | 官阶、勋位、文凭 | 头衔协会（ozo 等） | 前者由上级授予，后者由宾请与声望**购买** |
| 公共空间 | 广场、议会、官署 | 市场—神庙复合体 | 前者与市场分离，后者**市场即法庭** |

#### 三条替换原理

1. **人身依附替代地域管辖**：国家按「你在哪块地」管人，无国家社会按「你是谁家的人」管人。两者都能确定「谁受约束」，但前者靠地图，后者靠谱系。
2. **仪式替代文书**：国家用档案记住义务（税籍、户籍、合同），无国家社会用入会、命名、献祭与婚姻记住义务。文书的优点是精确与可查验，仪式的优点是不需要识字阶层。
3. **社会性排斥替代暴力垄断**：国家能关人，无国家社会只能「不跟你来往」——但正因为如此，它对**内部人**极其有效（被逐出等于社会死亡），对**外部人**几乎无效。

**收束**：三组对照最关键的分野在**「谁能被强制」**——国家的强制是**地域性、普遍性**的（在这块土地上的人都受管辖），无国家社会的强制是**关系性、特定性**的（只对共同体成员有效）。这一条同时解释了它内部的高度有序与它在外部武装面前的脆弱。

> 🔗 **横向关联**：本节「功能层对照」与 [非洲编年史：多中心世界、掠奴体系与被外围化（1500—1900）](非洲编年史：多中心世界、掠奴体系与被外围化（1500—1900）.md) §2.7「四种国家形态对照」形成**宏观与微观的对应关系**——编年史那张表回答「1500 年的非洲有哪几种政体」，本节回答「每种政体靠什么装置干活」。前者是地图，后者是机器。

## 四、四项秩序指标检验

用四项指标检验「无国家社会是否有秩序」：

| 指标 | 无国家社会的装置 | 与国家社会的对比 |
|------|-----------------|----------------|
| **裁决** | 长者会议、头衔协会、神谕、市场法庭 | 法院与成文法 |
| **防守** | 年龄组民兵、分裂性世系的合并机制、地形与分散居住 | 常备军与边境 |
| **跨期合作** | 秘密社团、婚姻联盟、牛与种子借贷 | 税收与公共工程 |
| **惩罚** | 逐出、赔偿、巫术指控、社团制裁 | 警察与监狱 |

**收束**：四者最关键的是**惩罚的执行方式**——国家靠「暴力垄断」，无国家社会靠「社会性排斥」（逐出共同体）。后者的成本更低、更分散，但也**更难对付不介意被排斥的外来者**（例如掠奴武装）。

> 注：本节只做四项最低限度的检验；完整的**九项功能对照、五组装置对照与三条替换原理**见 §3.6。

### 4.1 伊博村群的运作

伊博地区（今尼日利亚东南部）有句谚语「Igbo enwe eze」（伊博无王）。其治理单元是**村群（village-group）**：若干村庄以共同市场、共同神祇与通婚网络联结，重大事务由**长老议事会 + 头衔持有者 + 年龄组 + 女性议事会**共同处理。

> 📌 **双性别治理（Dual-Sex Political System）**：伊博社会存在平行的女性政治组织（如 umuada，即同族女性联盟），在婚姻纠纷、市场规则与道德惩戒上有实际裁决权。**本文中的作用**：它证明「无国家」不等于「无政治参与」——恰恰相反，它的政治参与面可能比中央集权社会更宽。

## 五、Aro 神谕：无国家体系里的「跨区最高法院」

伊博腹地的 Arochukwu 有一处著名神谕（Ibini Ukpabi，欧洲人称为「长朱朱」Long Juju）。它在 18—19 世纪的功能是：

| 功能 | 机制 |
|------|------|
| **跨区仲裁** | 远方纠纷提交神谕裁决，裁决被广泛承认，因为神谕不属于任何一方 |
| **信用担保** | 商人以神谕为见证订立远距离契约 |
| **人身庇护** | 被追捕者可逃至神谕地寻求庇护 |
| **奴隶贸易通道** | Aro 网络利用神谕的权威与通行权，把内陆人口输送到海岸（这一面必须同时承认） |

**关键判断**：Aro 神谕说明无国家社会**能够生产跨区域的、可执行的秩序**——它的「司法权」覆盖范围甚至超过许多小王国。但它也说明这种秩序的**脆弱性**：一旦被商业利益俘获，同一套权威就会转化为掠奴的管道。

## 六、19 世纪：无国家成为致命弱点

| 机制 | 内容 |
|------|------|
| **目标选择** | 掠奴集团优先袭击无国家社会：没有常备军、没有城墙、没有统一指挥 |
| **报复不对称** | 分裂性世系的「以牙还牙」只在本地有效，面对跨区武装商队无法组织联合反击 |
| **火器不对称** | 沿海中间商国家用火器换俘虏，内陆无国家社会没有火器来源 |
| **人口抽离** | 青壮年被掠走 → 世系防卫能力进一步下降 → 更容易被掠（正反馈） |

**收束**：19 世纪的结构性悲剧在于——**无国家社会的「优势」（分散、灵活、可退出）在掠奴经济面前变成了「劣势」**：分散意味着没有可打击的中心，但也意味着没有可集结的力量；可退出意味着和平时期的安全阀，但也意味着战时的无人负责。

## 七、殖民时期：间接统治如何破坏原有秩序

### 7.1 warrant chiefs：凭空发明的「酋长」

英国在尼日利亚推行「间接统治」（indirect rule），前提假设是「每个社会都有酋长」。在伊博这种无国家社会里找不到酋长，殖民当局便**任命**一批人，发给「委任状」（warrant），赋予其征税与司法的权力。

后果是三重破坏：

1. **合法性错位**：被任命者往往是没有传统权威的边缘人，却获得了强制权。
2. **财政转型**：酋长的收入从「社区馈赠」变成「征税提成」，激励从服务转向榨取。
3. **权力集中**：原本分散在长老、头衔协会、女性组织手中的权力，被压缩到一个人身上。

### 7.2 1929 年阿巴妇女战争

1929 年，东南尼日利亚妇女大规模抗议，起因包括对女性征税的传闻与委任酋长的滥权。抗议采取传统形式（「坐在男人身上」，即用女性组织的仪式性施压），规模涉及数万人，殖民当局开枪镇压，死亡人数估计在数十人以上（数字有争议）。

**这场冲突的意义**：它证明无国家社会**有能力组织大规模集体行动**——只是用的不是国家的方式，而是**女性网络 + 市场网络 + 年龄组**的方式。殖民者把这种行动误读为「骚乱」，因为他们只认国家形式的政治。

## 八、收束

### 8.1 归因：低密度 + 可迁徙 = 无国家的理性选择

「反国家路径」不是「不知道自己该建国」，而是在给定环境下的成本最优解：

- **无国库**（薯蓣不可储、不可计量）→ 养不起脱产的武力与官僚 → 无法强制
- **土地充裕** → 争夺土地无利 → 战争目标是抢人 → 权力＝控制人
- **可随时迁走** → 重税不可行 → 只能轻税收或互惠再分配
- **无骑兵、无犁、无长途运输** → 没有武力剪刀差 → 无法控制大空间 → 分裂性组织更有效率

四条线连起来看（详见 §2.6 的锁死回路）：**不是缺一个零件，而是每个零件都让下一个更难获得**。

**在这个意义上，「无国家」与「帝国」是同一套理性在不同参数下的两个解。**

### 8.2 延伸：为什么「无国家」在 19 世纪突然变成灾难

因为外部环境变了：出现了**能跨越本地秩序边界的力量**（远洋资本、火器供应链、殖民军队）。本地秩序的所有装置——世系、年龄组、神谕、市场制裁——都以「参与者在意本地共同体」为前提。当对手不在意时，这些装置全部失效。

这是本文最重要的延伸判断：**任何以「社会性排斥」为基础的秩序，都挡不住不在乎被排斥的人。**

### 8.3 个体坐标：判断一个社会「有没有秩序」的四个提问

1. 纠纷由谁裁决？裁决能否执行？
2. 外部威胁由谁组织防御？
3. 跨期合作（借贷、共耕、婚姻）靠什么担保？
4. 违规者会受到什么惩罚，惩罚由谁执行？

四问都能答「有」，就是有秩序——**不管有没有国王**。
