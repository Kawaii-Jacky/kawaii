### 0.3 四种材料，四种偏差

这篇笔记至少叠了四层材料，每一层都有自己的「镜头畸变」。不先说明，后面就会把某一层的结论误当成全部。

| 材料层 | 主要来源 | 偏差 |
| :--- | :--- | :--- |
| 用户材料 A：帝国谱系 | 用户整理的历史脉络 | 为了叙事清晰，把「三大希腊化王国」当成全部，省略了帕加马、巴克特里亚、本都等；把「13 年」当成帝国全部寿命 |
| 用户材料 B：伊利里亚人 | 用户整理的民族史叙事 | 民族连续叙事偏强，把「阿尔巴尼亚语源于伊利里亚语」说成无争议；人物、出生地有几处错误 |
| 古典文献 | 希罗多德、修昔底德、阿里安、普鲁塔克、狄奥多罗斯、波利比乌斯、李维、卡西乌斯·狄奥 | 敌意、道德化、数字夸大；对「蛮族」和「东方君主」有固定套路 |
| 现代研究 | 铭文、纸草、考古、钱币、碑刻与学术综述 | 碎片化、断代争议、术语争议；「帝国」「希腊化」「伊利里亚人」都是现代分析词 |

四层材料叠在一起，才构成后面那条看似平滑的时间线；任何一层被单独使用，都会产生偏差。

> 📌 **「希腊化」（Hellenismus / Hellenistic）**：不是「变成希腊人」，而是 19 世纪史学家德罗伊森（Johann Gustav Droysen）用来概括亚历山大之后东地中海「希腊语言与城市文化成为上层通用语法」的时期。它在时间上通常指前 323—前 30 年，在空间上覆盖从希腊到印度河的广大地区。本文用这个词时，指的是**一套上层文化语法**，不是血统或民族。

## 一、分界线的形状：为什么是亚历山大

### 1.1 三种「帝国」：地图、机器与程序

「亚历山大帝国」和「阿契美尼德帝国」经常被放在同一张地图上比较，但它们不是同一种东西。至少要把「帝国」拆成三层：

| 层次 | 看什么 | 例子 | 死后能留下什么 |
| :--- | :--- | :--- | :--- |
| 领土帝国 | 地图颜色、边界、驻军 | 亚历山大死时的疆域 | 很容易被瓜分 |
| 制度帝国 | 税册、驿道、行省、铸币、文书 | 大流士一世的波斯 | 会被后继者借用 |
| 文化程序 | 语言、城市生活、教育、王权叙事 | 希腊化世界的 Koine 希腊语 | 可以脱离帝国存活 |

如果把三层混为一谈，就会得出两个相反的错觉：要么说「亚历山大帝国只是昙花一现」，要么说「希腊化三百年都是亚历山大帝国的延续」。更准确的说法是：**作为领土帝国，亚历山大是逗号；作为文化程序，他是冒号——后面还有一整句。**

> 🔗 **横向关联**：本节把「帝国」拆成地图、机器与程序三层，与 [国家的概念史与建制化程度](../../国家的概念史与建制化程度：现代国家、历史语汇与中间形态.md) §三「现代制度化国家的八个要件」形成**尺度对照**——那篇提醒我们，用「国家」去称呼前现代政治体要付概念代价；本节则把「帝国」再拆细，避免把疆域、行政与文化混成一个词。该笔记 §8.2 的评分矩阵给阿契美尼德波斯 7／16，正好说明「有帝国规模」不等于「有现代国家」。

### 1.2 四件遗产：帝国死后还活着的东西

亚历山大死后，真正被继承的不是「亚历山大本人」，而是四件可以被别人拿走的东西：

| 遗产 | 具体内容 | 谁接手 | 存活时间 |
| :--- | :--- | :--- | :--- |
| 疆域骨架 | 行省边界、道路、城市位置、港口网络 | 继业者三国、罗马 | 部分延续到拜占庭与奥斯曼 |
| 行政技术 | 税册、铸币、文书、驿传、宫廷礼仪 | 塞琉古、托勒密、罗马 | 以「帝国语法」的形式长期存在 |
| 文化语言 | Koine 希腊语、体育馆、剧场、城市自治 | 整个东地中海 | 一直到拜占庭与伊斯兰初期 |
| 合法性模板 | 胜利者叙事、王权神化、普世君主 | 罗马皇帝、拜占庭皇帝、奥斯曼苏丹 | 反复换壳，长期存活 |

这张表是全文的骨架。后面每一节，本质上都在问：**这四件东西，在这一段里由谁拿着？**

### 1.3 一个逗号，还是一个冒号

用户材料里有一句很漂亮的判断：「亚历山大自己只是波斯帝国和罗马帝国之间的一个闪光逗号。」这句话在军事史上是准确的：他的帝国没有活过一代人，也没有形成稳定的继承制度。但在文化史上，它不够准确：**希腊化不是亚历山大帝国的「余波」，而是亚历山大死后三百年里，由继业者、城市、商人和学者共同写出来的一整套世界语法。**

所以本文的写法是：既不把亚历山大吹成「统一世界的天才」，也不把他贬成「只会打仗的过客」。他真正的作用，是把波斯帝国的「帝国模板」和希腊城邦的「文化程序」强行焊在一起；焊点很脆，但焊上去之后，后来的人都能用。

> 🔗 **横向关联**：本节「焊点很脆，但后来的人都能用」与 [西欧四次大一统尝试](../../../经济理论/资本与政体比较/西欧四次大一统尝试：帝国标准化、失败机制与多中心秩序.md) §1.1「不能只看地图颜色」形成**方法互证**——那篇用罗马、查理曼、神圣罗马帝国、拿破仑四次尝试说明「统一失败不等于标准化失败」；本节把同一个判断提前到亚历山大：**帝国统一失败，但希腊化标准化成功了。**

## 二、他之前（一）：阿契美尼德——帝国模板的发明

### 2.1 从居鲁士到大流士：模板的三次升级

阿契美尼德波斯（前 550—前 330）不是突然冒出来的「东方专制帝国」。它有三个明显的升级阶段：

| 阶段 | 君主 | 关键动作 | 结构意义 |
| :--- | :--- | :--- | :--- |
| 创业 | 居鲁士二世（前 559—前 530） | 灭米底、吕底亚、巴比伦 | 把「征服」改写成「复位」 |
| 打包 | 大流士一世（前 522—前 486） | 行省、定额贡赋、驿道、铸币 | 把统治写成可复制的程序 |
| 维持 | 薛西斯到阿尔塔薛西斯 | 宫廷、地方神、希腊均势 | 用金钱与仪式维持一个多中心帝国 |

居鲁士的高明之处，不是「宽容」，而是**把地方精英的旧秩序保留下来，只换最上面的一层**。他进入巴比伦时，把自己写成马尔杜克神选中的王；他允许犹太人回乡；他保留地方神庙与法律。这不是现代意义上的宗教宽容，而是一种成本极低的统治技术：**只要你承认我是王，你的地方世界可以照旧运转。**

> 🔗 **横向关联**：本节「只换最上面一层」与 [阿契美尼德波斯](../../中东/伊朗/阿契美尼德波斯：第一个世界帝国的建制化实验（前 550—前 330）.md) §2.4「复位剧本的三条规则」形成**直接展开**——那篇把居鲁士的「复位」拆成三条可操作规则；本节只保留结论：**波斯的帝国模板，核心是「翻译」而不是「同化」。**

### 2.2 波斯的统治术：行省、驿道、贡赋与「翻译机器」

大流士一世的行政打包，可以概括为四件东西：

| 工具 | 做法 | 作用 |
| :--- | :--- | :--- |
| 行省（satrapy） | 约 20 多个行省，总督、驻军、书记三权并立 | 让地方有自治，但不敢独立 |
| 定额贡赋 | 按行省定额收税，部分用实物、部分用银 | 让中央能预算，也让地方可预期 |
| 驿道与驿传 | 以萨迪斯—苏萨的「王道」为代表，设驿站与信使 | 让命令与情报跑得比军队快 |
| 帝国阿拉米语 | 以阿拉米语作为跨地区行政语言 | 让不同语言的地方精英能进入同一套文书系统 |

这四件东西合起来，就是一台「翻译机器」：把地方差异翻译成帝国等级，把地方神翻译成「大王保护的神」，把地方精英翻译成「王的仆人」。**波斯的伟大不在于它消灭了差异，而在于它让差异变得可管理。**

### 2.3 为什么四年就被打穿

从格拉尼库斯（前 334）到波斯波利斯（前 330），亚历山大只用了四年。这不是因为波斯「腐朽不堪」，而是因为六个失效点同时发作：

| 失效点 | 具体表现 | 后果 |
| :--- | :--- | :--- |
| 没有统一指挥 | 总督各自为战，王室军与地方军协调差 | 被亚历山大各个击破 |
| 总督半独立 | 地方总督有自己的军队与财政 | 中央一旦失势，地方迅速观望 |
| 军队结构 | 征召兵、雇佣兵、贵族骑兵混合 | 持久战与野战协同不足 |
| 大流士三世的选择 | 两次大会战失败后连续撤退 | 王权合法性迅速流失 |
| 亚历山大的速度 | 不等补给线稳固就推进 | 波斯来不及组织第二道防线 |
| 合法性真空 | 大王一逃，地方精英立刻改换门庭 | 帝国从「被打败」变成「被接管」 |

这张表解释了一个常被误解的问题：**波斯不是被「更先进的文明」打败的，而是被一个更会打仗、更会收买地方精英的军事机器打败的。** 亚历山大进入巴比伦、苏萨、波斯波利斯时，很多地方精英并不是「抵抗到最后一刻」，而是迅速计算：换一个王，税照交、神照拜、城照管，为什么不换？

> 🔗 **横向关联**：本节「六个失效点」与 [阿契美尼德波斯](../../中东/伊朗/阿契美尼德波斯：第一个世界帝国的建制化实验（前 550—前 330）.md) §8.3「六个失效点」是同一组判断的压缩版；那篇还给了 §9.2 的「亚述—波斯—罗马—秦」四体对照，说明**波斯的弱点是「帝国规模 + 地方自治」的结构性代价，不是某个国王的个人愚蠢。**

### 2.4 波斯留下的不是疆域，是「帝国语法」

阿契美尼德亡了，但它的帝国语法没有亡。亚历山大保留了波斯的行省框架、驿道、贡赋和宫廷礼仪；塞琉古帝国继续使用波斯的行省与城市网络；罗马的东方行省也沿着波斯的旧路走。

> 📌 **帝国语法（imperial grammar）**：本文用它指一套「不需要帝国本身存在也能被后来者使用」的统治技术，包括行省划分、税册、驿道、跨地区语言、王权称号与宫廷仪式。它像语法：说这种语言的人可以换，但句子结构会留下来。

> 🔗 **横向关联**：本节「帝国语法」与 [阿契美尼德波斯](../../中东/伊朗/阿契美尼德波斯：第一个世界帝国的建制化实验（前 550—前 330）.md) §10.1「制度清单」形成**上下游关系**——那篇列的是波斯具体留下了哪些制度；本节把它抽象成「语法」，为后面解释罗马、拜占庭、奥斯曼为什么能反复使用同一套东西做铺垫。

## 三、他之前（二）：希腊城邦与马其顿——城邦世界如何被北方整合

### 3.1 城邦不是「小国家」

「希腊城邦时代」这个说法很容易让人以为希腊是一堆同质的小国家。实际上，古希腊世界是一个由数百个 **polis**（城邦）组成的网络，外加联邦（koinon）、王国、僭主政权和殖民地。它们共享语言、神话、竞技赛会和德尔斐/奥林匹亚这样的「泛希腊」场所，但政治上从未统一。

| 类型 | 例子 | 权力结构 | 说明 |
| :--- | :--- | :--- | :--- |
| 民主城邦 | 雅典 | 公民大会、陪审法庭、抽签官职 | 公民权范围有限，妇女、奴隶、外邦人排除 |
| 寡头/双王城邦 | 斯巴达 | 双王、长老会、公民大会 | 黑劳士制度支撑公民军事化 |
| 联邦城邦 | 彼奥提亚联盟、阿卡亚联盟 | 联邦大会 + 城市自治 | 不是「一个城邦」，而是「城邦的联盟」 |
| 王国 | 马其顿、伊庇鲁斯 | 世袭王权 + 贵族骑兵 | 被希腊人视为「半蛮族」的边缘 |
| 殖民地 | 西西里、黑海沿岸 | 母邦制度 + 本地适应 | 希腊世界的外环 |

> 📌 **城邦（polis）**：不是「城市国家」的简单同义词，而是「公民共同体 + 城市中心 + 周边农村 + 神庙与节庆」的组合。它的核心不是城墙，而是**谁有资格参加公民大会、谁有义务自备武器作战**。理解这一点，才能理解为什么希腊人宁可内战，也不愿意被一个王统一。

### 3.2 雅典、斯巴达、底比斯：三种霸权，同一个死结

前 5—前 4 世纪的希腊史，可以看成三种霸权轮流尝试「把希腊统一起来」，然后全部失败：

| 霸权 | 高峰期 | 基础 | 死结 |
| :--- | :--- | :--- | :--- |
| 雅典 | 前 478—前 404 | 提洛同盟、海军、商税 | 同盟变成帝国，盟邦反抗 |
| 斯巴达 | 前 404—前 371 | 重装步兵、伯罗奔尼撒同盟 | 人口少、黑劳士制度脆弱 |
| 底比斯 | 前 371—前 362 | 彼奥提亚联盟、圣队 | 资源有限，无法长期维持 |
| 马其顿 | 前 338 以后 | 军事改革、北方资源、联盟 | 被征服者不服，继承问题 |

雅典的提洛同盟最初是自愿联盟，后来变成「交钱换保护」的帝国；斯巴达赢了伯罗奔尼撒战争，却无法处理胜利后的希腊；底比斯在留克特拉（前 371）打碎斯巴达的神话，却在曼提尼亚（前 362）失去自己的灵魂人物伊巴密浓达。**三种霸权都证明了一件事：希腊世界的统一，靠一个城邦自己做不到。**

> 🔗 **横向关联**：本节「同盟变成帝国」与 [农业帝国编年史](../../../../人类学/农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）.md) §3.3「雅典提洛同盟：从自愿联盟到帝国提取」形成**同构关系**——那篇从提取率角度解释雅典如何把盟费变成帝国收入；本节从政治结构角度解释为什么这种帝国化会制造反抗。两篇合起来说明：**雅典的失败不是「民主失败」，而是「小规模公民共同体无法承载大规模帝国」。**

### 3.3 马其顿：边缘王国的军事升级

马其顿在希腊人眼里长期是「半蛮族」：讲一种希腊方言，王室自称源自阿尔戈斯的赫拉克勒斯后裔，但政治结构是部落王权。真正把它变成军事强权的是腓力二世（前 359—前 336）：

| 改革 | 内容 | 效果 |
| :--- | :--- | :--- |
| 萨里沙长矛 | 约 4—6 米的长矛，配合密集方阵 | 正面压制希腊重装步兵 |
| 伙伴骑兵 | 贵族骑兵，楔形冲击 | 打击敌军侧翼与指挥中枢 |
| 持盾兵 | 精锐步兵，连接方阵与骑兵 | 提高机动与协同 |
| 攻城技术 | 投石机、攻城塔、工程兵 | 不再只能野战 |
| 金矿与婚姻 | 控制潘盖翁金矿，广泛联姻 | 用钱与亲缘买忠诚 |

腓力二世的真正天才，不是发明了某一种武器，而是把**战术、后勤、金钱与婚姻**组合成一台可复制的扩张机器。前 338 年，他在喀罗尼亚击败雅典—底比斯联军；前 337 年，他成立科林斯同盟，自任「希腊统帅」，准备东征波斯。前 336 年，他被刺杀，亚历山大接手。

### 3.4 喀罗尼亚 338：希腊被「整合」，不是被「统一」

「腓力二世在喀罗尼亚降服希腊」这句话对，但需要两个限定：

1. **斯巴达没有加入科林斯同盟**。它拒绝承认马其顿的霸权，后来被亚历山大单独处理。
2. **底比斯在 335 年因反叛被亚历山大摧毁**，城市被夷平，居民被卖为奴。这不是「统一」，而是「震慑」。

所以更准确的说法是：**马其顿用军事胜利 + 联盟框架，把希腊「整合」进一个由自己主导的反波斯阵营；希腊城邦的内部制度被保留，但外交与战争权被拿走。** 这为亚历山大提供了两样东西：希腊的兵源与舰队，以及「为希腊复仇」的合法性叙事。

> 🔗 **横向关联**：本节「整合而不是统一」与 [中国与西欧历史社会结构差异](../../../经济理论/资本与政体比较/中国与西欧历史社会结构差异：官僚帝国、多中心秩序与阶级形成.md) §二.1「西欧：多中心不是自由，而是权利重叠」形成**尺度对照**——那篇解释西欧为什么长期是多中心；本节展示多中心世界被一个边缘王国短暂「压平」的时刻。压平不等于消失：亚历山大一死，希腊的多中心结构立刻回弹。

## 四、他之前（三）：埃及晚期与北方边缘——「开门迎王师」与「蛮族」的真相

### 4.1 埃及晚期：从萨伊到波斯再征服

「古埃及晚期王朝已经衰弱，几乎开门迎王师」这句话大方向没错，但时间线需要精确：

| 阶段 | 时间 | 说明 |
| :--- | :--- | :--- |
| 第 26 王朝（萨伊） | 前 664—前 525 | 最后一次本土复兴，随后被波斯征服 |
| 第 27 王朝（波斯） | 前 525—前 404 | 冈比西斯、大流士一世统治 |
| 第 28—30 王朝 | 前 404—前 343 | 本土王朝反复独立，最后一位本土法老涅克塔内布二世 |
| 第 31 王朝（波斯） | 前 343—前 332 | 阿尔塔薛西斯三世再征服 |
| 马其顿统治 | 前 332—前 305 | 亚历山大以法老身份进入孟菲斯 |
| 托勒密王朝 | 前 305—前 30 | 希腊化埃及 |

所以「开门迎王师」的准确版本是：**前 343 年波斯已经再次征服埃及，末代本土法老流亡；前 332 年，波斯驻埃及总督马扎凯斯（Mazaces）在几乎无抵抗的情况下向亚历山大投降。** 亚历山大不是打败了一个强大的埃及，而是接管了一个已经被波斯重新整合过的省。

### 4.2 亚历山大在埃及：法老、阿蒙与亚历山大里亚

亚历山大在埃及做了三件很有象征意义的事：

| 动作 | 内容 | 政治功能 |
| :--- | :--- | :--- |
| 孟菲斯加冕 | 以法老身份祭祀埃及神 | 继承埃及王权传统 |
| 锡瓦绿洲 | 向阿蒙神谕求问，被称作「阿蒙之子」 | 获得超越希腊城邦的神性合法性 |
| 建立亚历山大里亚 | 前 331 年建城，面向地中海 | 为希腊化世界造一个「文化首都」 |

这三件事说明：亚历山大并不是单纯的「征服者」，他很懂得**把不同地方的神圣语言接到自己身上**。波斯的「大王」、埃及的「法老」、希腊的「赫拉克勒斯后裔」——他同时使用多套合法性语法。

> 🔗 **横向关联**：本节「多套合法性语法」与 [阿契美尼德波斯](../../中东/伊朗/阿契美尼德波斯：第一个世界帝国的建制化实验（前 550—前 330）.md) §5.2「地方神的本土化」形成**镜像关系**——波斯让地方神继续存在，只要它们承认大王；亚历山大则进一步把自己写进地方神谱。前者是「翻译」，后者是「合体」。

### 4.3 北方边缘：伊利里亚、色雷斯、达契亚

马其顿的北方不是一个「统一的国家」，而是一条从亚得里亚海到黑海的**部落—山地—河谷**地带：

| 人群 | 大致位置 | 与马其顿的关系 |
| :--- | :--- | :--- |
| 伊利里亚人 | 亚得里亚海东岸，今阿尔巴尼亚、黑山、克罗地亚沿海 | 长期冲突，偶尔结盟，是马其顿最危险的西北邻居 |
| 色雷斯人 | 巴尔干山脉以南、黑海西岸 | 有奥德里西亚王国等政治体，既有对抗也有合作 |
| 特里巴利人 | 下多瑙河一带 | 前 335 年袭击亚历山大，被击退 |
| 盖塔人/达契亚人 | 多瑙河以北 | 不在马其顿直接控制下，后来成为罗马的长期对手 |

这里的「蛮族」是希腊—罗马视角的分类，不是这些人群自己的认同。他们中有王国、有联盟、有雇佣兵、有商人；与马其顿和希腊世界的关系，既有战争，也有贸易与婚姻。

### 4.4 伊利里亚人是谁：部落表与「国王」的真相

伊利里亚人属于印欧语系人群，约前 1000 年起在亚得里亚海东岸形成可辨识的考古文化。他们不是统一国家，而是一组语言—文化相近的部落：

| 部落 | 大致区域 | 备注 |
| :--- | :--- | :--- |
| 达尔达尼亚人（Dardani） | 科索沃、南塞尔维亚一带 | 后来的伊利里亚诸帝多出于达尔达尼亚—默西亚一带 |
| 阿尔迪安人（Ardiaei） | 今黑山、阿尔巴尼亚北部 | 前 3 世纪的海上强国，罗马第一次伊利里亚战争的对手 |
| 达尔马提亚人（Delmatae） | 今克罗地亚达尔马提亚 | 罗马征服中最顽强的一支 |
| 拉贝亚特人（Labeatae） | 今阿尔巴尼亚北部、斯库台湖一带 | 末代国王根提乌斯（Gentius） |
| 陶兰提人（Taulantii） | 今阿尔巴尼亚中部 | 与希腊殖民城市有长期互动 |
| 潘诺尼亚人（Pannonii） | 今匈牙利、克罗地亚内陆 | 后来成为潘诺尼亚行省 |
| 伊阿波德人（Iapodes） | 今克罗地亚西部山地 | 山地部落，长期抵抗罗马 |
| 利布尔尼人（Liburni） | 今克罗地亚沿海 | 以航海技术著称 |

他们的「国王」更接近**部落联盟的军事首领**：有个人权威，但没有常备官僚、没有统一税制、没有稳定继承制度。这样的结构在防御时很灵活，在长期占领时很吃力——这也解释了为什么伊利里亚人能让马其顿和罗马都头疼，却无法建立自己的大帝国。

### 4.5 三处需要校正的流行说法

用户材料里有三处说法需要校正，否则后面的「伊利里亚—阿尔巴尼亚」线索会被带偏：

| 流行说法 | 更准确的说法 | 为什么要校正 |
| :--- | :--- | :--- |
| 「伊利里亚人一度差点灭了马其顿」 | 前 359 年，伊利里亚人阵斩马其顿国王佩尔狄卡斯三世，马其顿王位动摇；前 358 年腓力二世击败巴迪利斯，收复失地 | 伊利里亚从未形成统一国家，无法长期占领马其顿核心；「差点灭国」是修辞，不是事实 |
| 「奥林匹亚丝有伊利里亚—伊庇鲁斯血统」 | 奥林匹亚丝是伊庇鲁斯摩罗西亚王族公主，家族自称源自阿喀琉斯；她不是伊利里亚人 | 伊庇鲁斯人与伊利里亚人是邻居，但不是同一人群；混淆会误导后面的族源讨论 |
| 「君士坦提乌斯出生在那不勒斯」 | 君士坦提乌斯一世（Constantius Chlorus）约 250 年生于内索斯（Naissus，今塞尔维亚尼什）；君士坦丁也生于内索斯 | 「那不勒斯」很可能是 Naissus 的误译；出生地错了，伊利里亚诸帝的地理基础就错了 |

> 🔗 **横向关联**：本节「部落联盟不是国家」与 [国家的概念史与建制化程度](../../国家的概念史与建制化程度：现代国家、历史语汇与中间形态.md) §5.6「城邦、帝国、联邦、酋邦：四种规模方案」形成**概念校准**——那篇提醒：不要因为一个政治体有「国王」就把它当成国家；本节用伊利里亚的例子说明，**「国王」可以只是联盟首领，而不是官僚国家的元首。**

| :--- | :--- | :--- |
| 336 | 腓力二世遇刺，亚历山大即位 | 20 岁，接手马其顿与科林斯同盟 |

把这条时间线压缩成一句：亚历山大用 11 年打完，用 7 年当波斯之主，然后用死亡把「怎么继承」变成了所有人的难题。

### 5.2 四场会战：亚历山大如何打穿波斯

| 会战 | 时间 | 亚历山大的兵力 | 波斯的应对 | 关键点 |
| :--- | :--- | :--- | :--- | :--- |
| 格拉尼库斯 | 前 334 | 约 3 万步兵、5 千骑兵 | 小亚细亚总督联军 | 亚历山大亲率骑兵冲击，险些丧命 |
| 伊苏斯 | 前 333 | 约 4 万 | 大流士三世亲征 | 波斯军在山地狭窄地形展开不利 |
| 高加米拉 | 前 331 | 约 4.7 万 | 大流士三世选开阔平原，配战车与战象 | 亚历山大斜线突击，直取大流士本人 |
| 希达斯皮斯河 | 前 326 | 约 4 万 | 印度王波罗斯的战象军 | 暴雨夜渡河，侧翼包抄 |

四场会战的共同点不是「亚历山大兵多」，而是**他总能在战场上找到对方的指挥中枢，并用自己的精锐骑兵去攻击它**。波斯的军队人数更多，但指挥链更长、协同更差；一旦大王本人逃跑，整支军队的合法性就崩了。

### 5.3 13 年、11 年、7 年：三个口径

用户材料说「他的帝国只活了 13 年」。这句话需要三个口径：

| 口径 | 起止 | 长度 | 说明 |
| :--- | :--- | :--- | :--- |
| 在位 | 前 336—前 323 | 13 年 | 从即位到死亡 |
| 东征 | 前 334—前 323 | 11 年 | 从渡海到死亡 |
| 作为「波斯之主」 | 前 330—前 323 | 7 年 | 从焚波斯波利斯到死亡 |

所以「13 年」是王朝口径，不是帝国制度的口径。**亚历山大从来没有足够时间把征服区整合成一个稳定的行政体**：他保留了波斯的行省，换上了自己的总督，但还没来得及建立统一的继承规则、财政体系和军队编制，就死了。

### 5.4 他真正留下的四样东西

| 遗产 | 具体表现 | 为什么能活下来 |
| :--- | :--- | :--- |
| 城市 | 亚历山大里亚及一系列「亚历山大城」 | 城市有商业与行政功能，不依赖某个国王 |
| 货币 | 阿提卡标准的银币在东方流通 | 交易需要通用尺度 |
| 语言 | Koine 希腊语成为东地中海通用语 | 城市精英、商人、军队都需要 |
| 王权叙事 | 神化国王、胜利者崇拜、普世君主 | 后继者可以照抄，不需要流亚历山大的血 |

> 🔗 **横向关联**：本节「城市与语言比帝国活得久」与 [希腊神话与荷马史诗](希腊神话与荷马史诗：金苹果、特洛伊与奥德赛的三个时代.md) §5.2「亚历山大里亚的编辑室：文本如何定型」形成**互证关系**——那篇讲亚历山大里亚如何把荷马文本标准化；本节讲这座城市如何成为希腊化文化的「总编辑部」。**帝国靠剑建立，文化靠城市复制。**

### 5.5 为什么帝国没有「制度化」

亚历山大帝国没有制度化的原因，不是「他不想」，而是四件事同时不允许：

1. **继承真空**：他没有指定明确继承人，罗克珊娜怀孕，部将各怀心思。
2. **军队疲劳**：希发西斯河哗变说明士兵已经不愿再向东。
3. **融合阻力**：苏萨集体婚礼、波斯宫廷礼仪、要求希腊人跪拜，都引起马其顿旧部不满。
4. **地方结构太厚**：波斯的行省、神庙、城市与地方精英不可能在十年内被重写。

所以他的帝国更像一次**超大规模的军事占领 + 上层换人**，而不是一次真正的国家建设。这也是为什么他一死，帝国立刻进入继业者战争。

> 🔗 **横向关联**：本节「军事占领不等于国家建设」与 [人类历史权力方程体系](../../../../人类学/人类历史权力方程体系：30万年文明演化的五大时代.md) 阶段二「农业帝国」的核心方程形成**尺度对照**——那篇把农业帝国的稳定条件归结为「提取能力 × 合法性 × 镇压能力」的平衡；本节说明亚历山大只完成了「镇压能力」的极致，还没来得及补上另外两项。

## 六、继业者战争：一个帝国如何拆成五个军阀

### 6.1 巴比伦分封 323：一份没有赢家的遗嘱

亚历山大死时，将领们在巴比伦开会。会议的结果不是「选出一个新王」，而是「先把能分的分掉」：

> 📌 **继业者（Diadochoi，单数 Diadochos）**：亚历山大死后争夺其遗产的将领与家族成员。他们最初以「摄政」「国王监护人」的名义行事，前 306／305 年相继称王，最终把帝国拆成托勒密、塞琉古、安提柯等王国。本文用「继业者战争」指前 323—前 281 年这一整段冲突。

| 人物 | 分到的东西 | 角色 |
| :--- | :--- | :--- |
| 帕迪卡斯（Perdiccas） | 帝国摄政、王室军队 | 试图维持帝国统一 |
| 安提帕特（Antipater） | 马其顿与希腊 | 后方稳定者 |
| 托勒密（Ptolemy） | 埃及 | 最会经营地盘的人 |
| 利西马科斯（Lysimachus） | 色雷斯 | 黑海—海峡方向 |
| 安提柯（Antigonus） | 弗里吉亚、吕基亚、潘菲利亚 | 小亚细亚最强的军阀 |
| 欧迈尼斯（Eumenes） | 卡帕多细亚 | 王室派，最后失败 |
| 塞琉古（Seleucus） | 近卫骑兵指挥；前 321 年才拿到巴比伦 | 后来最大的赢家 |

名义上的国王是腓力三世（亚历山大的同父异母兄弟，心智有缺陷）和亚历山大四世（罗克珊娜所生）。但实际上，**国王只是将军们用来合法化命令的图章**。

### 6.2 特里帕拉迪苏斯 321：第一次重排

帕迪卡斯在远征埃及途中被部下杀死；前 321 年，将领们在特里帕拉迪苏斯重新分配：

| 变化 | 内容 |
| :--- | :--- |
| 安提帕特 | 成为帝国摄政 |
| 塞琉古 | 获得巴比伦 |
| 安提柯 | 获得小亚细亚更多的指挥权 |
| 欧迈尼斯 | 被宣布为敌人 |
| 托勒密 | 保住埃及，继续独立经营 |

前 319 年安提帕特死，指定波利佩孔为摄政，引发卡山德不满；前 317 年腓力三世被杀；前 310／309 年亚历山大四世被杀。**至此，阿吉德王朝绝嗣，继业者不再需要「国王图章」，可以直接称王。**

### 6.3 伊普苏斯 301 与科鲁佩迪乌姆 281：两次定局

| 会战 | 时间 | 交战方 | 结果 |
| :--- | :--- | :--- | :--- |
| 伊普苏斯 | 前 301 | 安提柯一世 + 德米特里 vs 塞琉古、利西马科斯、卡山德、托勒密 | 安提柯战死；帝国不可能再统一 |
| 科鲁佩迪乌姆 | 前 281 | 塞琉古 vs 利西马科斯 | 利西马科斯战死；塞琉古短暂独大，随后被刺杀 |

伊普苏斯之后，三强格局基本定型：托勒密拿埃及，塞琉古拿叙利亚—两河—伊朗，利西马科斯拿小亚细亚与色雷斯，卡山德拿马其顿。科鲁佩迪乌姆之后，塞琉古几乎统一了亚历山大帝国在欧洲以外的部分，但他随即被托勒密·克劳诺斯刺杀，帝国再次分裂。

### 6.4 为什么没有人能重建帝国

继业者打了四十多年，为什么没有人能像亚历山大那样重建一个大帝国？原因可以归成四条：

| 原因 | 说明 |
| :--- | :--- |
| 没有合法继承人 | 阿吉德王朝绝嗣，任何自称「摄政」的人都缺乏长期合法性 |
| 军队忠诚碎片化 | 军队效忠的是给自己发饷的将军，不是「帝国」 |
| 地理与后勤 | 从埃及到伊朗的距离，超出任何单一中心的快速投送能力 |
| 相互均势 | 任何一个人试图独大，其他三方立刻结盟 |

> 🔗 **横向关联**：本节「相互均势阻止统一」与 [西欧四次大一统尝试](../../../经济理论/资本与政体比较/西欧四次大一统尝试：帝国标准化、失败机制与多中心秩序.md) §6.3「为什么外部均势持续阻止大陆霸权」形成**跨时空同构**——那篇讲近代欧洲的均势如何阻止拿破仑式统一；本节讲希腊化世界的均势如何阻止继业者重建亚历山大帝国。**均势不是和平，而是一种「谁都吃不掉谁」的稳定碎裂。**

## 七、三大希腊化王国：三种「帝国活法」

### 7.1 托勒密埃及：最长寿的希腊化王国

托勒密王朝（前 305—前 30）是三大王国里最长寿的，原因不是它最能打，而是它的**核心区最紧凑、最富、最容易被控制**：

| 支柱 | 内容 |
| :--- | :--- |
| 尼罗河农业 | 可预测的洪水与灌溉，提供稳定粮食剩余 |
| 亚历山大里亚 | 地中海最大港口之一，图书馆、缪斯宫、学术中心 |
| 纸草文书 | 高度发达的官僚登记与税收系统 |
| 宗教合流 | 塞拉皮斯、伊西斯等神祇，把希腊与埃及传统接在一起 |
| 希腊—马其顿精英 | 军事殖民者（cleruchs）与城市精英支撑王权 |

托勒密的弱点也很明显：王室内婚、宫廷阴谋、native 起义、以及最终对罗马的依赖。克利奥帕特拉七世（前 51—前 30）是最后一位积极使用「埃及—希腊—罗马」三重合法性资源的统治者；亚克兴海战（前 31）失败后，她和安东尼自杀，埃及在前 30 年成为罗马行省。

### 7.2 塞琉古帝国：最大、最不稳

塞琉古帝国（前 312—前 63）是三大王国里疆域最大的，从爱琴海东岸到印度河，但它也是最不稳的：

| 支柱 | 内容 |
| :--- | :--- |
| 城市殖民 | 大量希腊化城市（塞琉西亚、安条克等），作为统治节点 |
| 行省制 | 继承波斯行省框架，但总督权力很大 |
| 军队 | 马其顿方阵、银盾兵、伙伴骑兵、战象 |
| 货币 | 银币通行，连接地中海与东方贸易 |
| 合法性 | 以「胜利者」和「大王」叙事为主，缺乏埃及式的神性王权 |

塞琉古的麻烦是**多线作战**：西边要对付托勒密、帕加马、罗马；东边要对付巴克特里亚、帕提亚、印度。前 305 年，塞琉古与孔雀王朝的旃陀罗笈多缔约，放弃印度河以东的领地，换得 500 头战象。前 190 年马格尼西亚败于罗马，前 188 年《阿帕米亚和约》失去小亚细亚。前 148—前 141 年，帕提亚的米特里达梯一世夺取米底与巴比伦；前 63 年，庞培废黜末王，塞琉古灭亡。

### 7.3 安提柯马其顿：守老家的人

安提柯王朝（前 277—前 168）是三大王国里最「穷」的一个：它的核心是马其顿本土与希腊的霸权，而不是东方的富庶行省。

| 君主 | 时间 | 关键动作 |
| :--- | :--- | :--- |
| 安提柯二世·戈纳塔斯 | 前 277—前 239 | 击退加拉太人，稳住马其顿 |
| 安提柯三世·多松 | 前 229—前 221 | 前 222 年塞拉西亚战役，击败斯巴达 |
| 腓力五世 | 前 221—前 179 | 第一次、第二次马其顿战争；前 197 年库诺斯克法莱败于罗马 |
| 珀尔修斯 | 前 179—前 168 | 前 168 年彼得那战败，王朝灭亡 |

彼得那之后，罗马废除马其顿王制，把马其顿分成四个自治共和国；前 148 年安德里斯库斯起兵失败，前 146 年马其顿成为罗马行省，同年科林斯被毁。**安提柯王朝的结局，就是「守老家」策略的结局：老家守住了，但老家太小。**

### 7.4 三国总对照

| 维度 | 托勒密埃及 | 塞琉古帝国 | 安提柯马其顿 |
| :--- | :--- | :--- | :--- |
| 时间 | 前 305—前 30 | 前 312—前 63 | 前 277—前 168 |
| 核心区 | 尼罗河 | 叙利亚—两河—伊朗 | 马其顿与希腊 |
| 首都 | 亚历山大里亚 | 塞琉西亚、安条克 | 佩拉、德米特里阿斯 |
| 军队基础 | 尼罗河财政 + 军事殖民 | 行省税收 + 城市殖民 | 马其顿兵源 + 希腊盟军 |
| 合法性 | 法老 + 希腊神王 | 胜利者 + 大王 | 马其顿王权 + 希腊联盟 |
| 主要威胁 | 内部宫廷、native 起义、罗马 | 帕提亚、巴克特里亚、罗马、托勒密 | 希腊城邦、罗马、北方部落 |
| 终结 | 前 30，屋大维吞并 | 前 63，庞培废末王 | 前 168 彼得那；前 146 行省 |

最关键的区别不是「谁更大」，而是**谁的核心区更容易被一个中心控制**：托勒密的核心是一条河，塞琉古的核心是一条漫长的商路，安提柯的核心是一块人力有限的山地。**地理不是命运，但地理决定了治理成本。**

### 7.5 「希腊化」到底化在哪

「希腊化」经常被误解成「东方被希腊文化同化」。更准确的说法是：**希腊语和希腊城市制度成为东地中海的上层通用语法，地方文化在下面继续存在。**

| 渠道 | 具体表现 | 结果 |
| :--- | :--- | :--- |
| 语言 | Koine 希腊语成为行政、商业、文学语言 | 精英双语，普通人继续说地方语言 |
| 城市 | 希腊式城市（agora、gymnasium、theater） | 城市精英希腊化，农村变化慢 |
| 教育 | 荷马、修辞、哲学、体育 | 希腊 paideia 成为身份标志 |
| 宗教 | 神祇合流（塞拉皮斯、伊西斯） | 地方神保留，但披上希腊外衣 |
| 艺术 | 希腊化雕塑、肖像、马赛克 | 宫廷与城市艺术趋同 |

> 🔗 **横向关联**：本节「上层通用语法」与 [希腊神话与荷马史诗](希腊神话与荷马史诗：金苹果、特洛伊与奥德赛的三个时代.md) §5.2「亚历山大里亚的编辑室」形成**具体化关系**——那篇展示荷马如何被编辑成「标准文本」；本节说明这种标准化不只发生在文学，也发生在语言、城市与王权形象上。**希腊化不是「大家都变成希腊人」，而是「大家都学会用希腊语谈自己的事」。**

### 7.6 被「三大」遮住的其它希腊化王国

「三大希腊化王国」是教科书简化。实际上还有一批重要政治体：

| 王国 | 时间 | 位置 | 备注 |
| :--- | :--- | :--- | :--- |
| 帕加马 | 前 282—前 133 | 小亚细亚西部 | 阿塔罗斯王朝；前 133 年遗赠罗马 |
| 巴克特里亚 | 约前 250—约前 130 | 阿富汗、中亚 | 希腊—巴克特里亚王国；与印度、丝绸之路互动 |
| 印度—希腊王国 | 约前 180—约公元 10 | 巴基斯坦、印度西北 | 弥兰陀王（Menander）与佛教互动 |
| 本都 | 前 281—前 63 | 黑海南岸 | 米特里达梯六世与罗马长期战争 |
| 科马基尼 | 前 163—公元 72 | 叙利亚北部 | 希腊—波斯—亚美尼亚文化混合 |
| 哈斯蒙尼犹太 | 前 140—前 37 | 犹太地 | 马加比起义后独立，后被罗马吞并 |

这些王国说明：**希腊化世界不是一个「三足鼎立」的体系，而是一个多中心、多层级的城市—王国网络。** 三大王国只是最大的三个节点。

## 八、东方的另一条接力：帕提亚与萨珊

### 8.1 帕提亚：从塞琉古的东北边缘长出来

帕提亚（中国史书称「安息」，Arsacid Empire，前 247—公元 224）不是「塞琉古的对手」一开始就存在的。它原本是塞琉古帝国东北边缘的帕提亚地区，在塞琉古与巴克特里亚、游牧民族的拉扯中逐渐独立：

| 阶段 | 时间 | 事件 |
| :--- | :--- | :--- |
| 兴起 | 前 247 | 阿尔沙克一世在帕提亚建立政权 |
| 扩张 | 前 171—前 138 | 米特里达梯一世夺取米底、巴比伦，成为「万王之王」 |
| 均势 | 前 1 世纪—公元 2 世纪 | 与罗马争夺亚美尼亚、两河；前 53 年卡莱战役击败克拉苏 |
| 高峰 | 公元 2 世纪初 | 控制从幼发拉底河到中亚的商路 |
| 终结 | 224 | 萨珊的阿尔达希尔一世灭帕提亚 |

帕提亚的军队以弓骑兵与重装骑兵（cataphracts）为主，擅长在开阔地带消耗罗马军团。它的政治中心不止一个，后期以泰西封（Ctesiphon）为最重要都城之一；帝国本身是**多中心、半封建**的：大王之下有诸多地方王公，中央权力不强。这也是它能在罗马压力下长期存活、却难以彻底集中权力的原因。

> 🔗 **横向关联**：本节「帕提亚从塞琉古边缘独立」与 [阿契美尼德波斯](../../中东/伊朗/阿契美尼德波斯：第一个世界帝国的建制化实验（前 550—前 330）.md) §6.3「四世纪：核心稳定，边缘弹性」形成**长时段呼应**——那篇讲波斯帝国的边缘如何不断离心；本节讲塞琉古的边缘如何长出一个新的伊朗帝国。**帝国的边缘，往往是下一个帝国的起点。**

### 8.2 萨珊：波斯帝国的第三次开号

萨珊王朝（224—651）是波斯帝国的第三次「开号」（阿契美尼德—帕提亚—萨珊）。它的建立者阿尔达希尔一世来自法尔斯地区的祭司—贵族家族，推翻帕提亚后，刻意把自己写成阿契美尼德传统的继承者：

| 君主 | 时间 | 关键动作 |
| :--- | :--- | :--- |
| 阿尔达希尔一世 | 224—241 | 灭帕提亚，建立萨珊；强化中央集权 |
| 沙普尔一世 | 241—272 | 与罗马战争；260 年俘虏瓦莱里安 |
| 霍斯劳一世 | 531—579 | 税制、军制改革；击败白匈奴；文化繁荣 |
| 霍斯劳二世 | 590—628 | 最后一次大规模对拜占庭战争；614 年夺取耶路撒冷 |
| 伊嗣俟三世 | 632—651 | 阿拉伯征服；651 年死去，萨珊终结 |

萨珊的国家宗教是琐罗亚斯德教（Zoroastrianism），祭司阶层（magi）与国家紧密结合；同时存在犹太教、基督教（特别是东方教会）、摩尼教等少数群体。它的行政比帕提亚更集中，城市与税收系统更发达，军队以重骑兵（aswaran）与步兵为主。

### 8.3 罗马—波斯：七百年的均势

古代晚期的东地中海，真正的长期主线不是「希腊化王国的余波」，而是**罗马/拜占庭与帕提亚/萨珊的七百年均势**：

| 阶段 | 时间 | 特征 |
| :--- | :--- | :--- |
| 帕提亚 vs 罗马 | 前 1 世纪—公元 3 世纪 | 卡莱前 53、图拉真 116 年短暂占领泰西封、塞维鲁 197—198 |
| 萨珊 vs 罗马 | 224—395 | 沙普尔一世、瓦莱里安被俘；戴克里先—君士坦丁的重组 |
| 萨珊 vs 拜占庭 | 395—628 | 527—532、540—562、602—628 三次大战争 |
| 阿拉伯征服 | 636—651 | 卡迪西亚、尼哈万德；萨珊灭亡 |

> 🔗 **横向关联**：本节「七百年均势」与 [阿契美尼德波斯](../../中东/伊朗/阿契美尼德波斯：第一个世界帝国的建制化实验（前 550—前 330）.md) §6.2「希波战争：一场被后世放大的失败」形成**长时段对照**——那篇讲波斯在西线的第一次受挫；本节讲波斯与罗马/拜占庭在东线的长期拉锯。**「东西对峙」不是希腊—波斯的短暂插曲，而是持续千年的结构。**

### 8.4 两条时间线的错位

用户材料说「安息帝国 & 萨珊波斯——在东方顶住了塞琉古」，这里有一个**时代错位**：

| 说法 | 问题 | 修正 |
| :--- | :--- | :--- |
| 帕提亚「顶住塞琉古」 | 帕提亚是从塞琉古东北边缘独立出来的，不是与塞琉古正面均势的对手 | 帕提亚先独立，再反向蚕食塞琉古的伊朗核心 |
| 萨珊「顶住塞琉古」 | 萨珊 224 年建立时，塞琉古已经灭亡 287 年 | 萨珊的对手是罗马/拜占庭，不是塞琉古 |
| 帕提亚/萨珊「长期与罗马为敌」 | 基本正确，但要加上拜占庭 | 帕提亚—罗马、萨珊—罗马/拜占庭，前后约七百年 |

这个错位提醒我们：**「东方 vs 西方」的叙事很容易把不同时代的对手压缩成同一个「波斯」。** 实际上，阿契美尼德、帕提亚、萨珊是三个不同的王朝，面对的是不同的西方对手。

## 九、罗马：希腊化世界的终结者与继承者

### 9.1 罗马吞并希腊化世界的五步

罗马不是一天灭掉希腊化世界的，而是分五步：

| 步骤 | 时间 | 事件 | 结果 |
| :--- | :--- | :--- | :--- |
| 1 | 前 168 | 彼得那会战 | 安提柯王朝灭亡，马其顿王制被废 |
| 2 | 前 146 | 科林斯被毁 | 希腊本土被纳入罗马霸权 |
| 3 | 前 133 | 帕加马末王遗赠罗马 | 罗马接管小亚细亚西部 |
| 4 | 前 63 | 庞培废黜塞琉古末王 | 叙利亚成为罗马行省 |
| 5 | 前 30 | 屋大维吞并埃及 | 托勒密王朝终结，希腊化时代结束 |

这五步之间隔了 138 年。罗马的节奏不是「一口气征服」，而是**在每一个局部冲突中，逐步把希腊化王国变成附庸、再变成行省**。

### 9.2 「被征服的希腊征服了征服者」

贺拉斯有一句名言：「被俘的希腊俘获了她野蛮的征服者」（Graecia capta ferum victorem cepit）。这句话常被用来形容罗马对希腊文化的吸收，但它需要两个限定：

1. **罗马吸收的是希腊上层文化**：修辞、哲学、艺术、神话、建筑、教育。罗马的普通士兵、农民、奴隶并不因此「变成希腊人」。
2. **罗马同时保留了自己的制度优势**：公民权、军团、道路、法律、市政组织。希腊文化没有让罗马放弃这些。

| 领域 | 希腊对罗马的影响 | 罗马的改造 |
| :--- | :--- | :--- |
| 文学 | 史诗、悲剧、喜剧、修辞 | 拉丁语改写；维吉尔《埃涅阿斯纪》 |
| 哲学 | 斯多亚、伊壁鸠鲁、学园派 | 罗马法理学；西塞罗 |
| 艺术 | 雕塑、绘画、建筑柱式 | 罗马混凝土、拱券、公共建筑 |
| 宗教 | 神祇谱系、神话叙事 | 罗马神与希腊神对应；皇帝崇拜 |
| 教育 | paideia、修辞学校 | 罗马贵族子弟赴雅典学习 |

> 🔗 **横向关联**：本节「罗马吸收希腊上层文化」与 [西欧四次大一统尝试](../../../经济理论/资本与政体比较/西欧四次大一统尝试：帝国标准化、失败机制与多中心秩序.md) §2.2「罗马法、拉丁语与基督教为何比帝国更长寿」形成**直接呼应**——那篇讲罗马留下的三件长寿命遗产；本节补充第四件：**希腊文化**。罗马不是希腊的「敌人」，而是希腊文化的「放大器」和「保存器」。

### 9.3 罗马为什么能做成继业者做不到的事

| 原因 | 说明 |
| :--- | :--- |
| 公民权与同盟体系 | 把被征服精英逐步纳入罗马公民/同盟体系，提供上升通道 |
| 军团与道路 | 常备军 + 道路网，投送能力远超继业者 |
| 法律与市政 | 罗马法、市政自治、地方精英参与治理 |
| 税收与货币 | 行省税制、银币体系，降低交易成本 |
| 暴力与奴隶制 | 不可忽略：征服伴随屠杀、掠夺与大规模奴役 |

罗马的成功不是「文明优越」，而是**一整套把地方精英变成罗马精英的制度**。继业者没有一个能提供这种「向上流动的入口」；他们的王国是「希腊—马其顿精英压在本地人上面」，本地精英很难真正进入核心。

> 🔗 **横向关联**：本节「把地方精英变成罗马精英」与 [中国与西欧历史社会结构差异](../../../经济理论/资本与政体比较/中国与西欧历史社会结构差异：官僚帝国、多中心秩序与阶级形成.md) §四「精英形成与吸纳」形成**比较关系**——那篇讲中国通过科举把地方精英接合到中央；本节讲罗马通过公民权、军团与市政把地方精英接合到帝国。**两种「吸纳机器」，两种帝国寿命。**

### 9.4 罗马的边界与「地中海内湖」的真实含义

「把整个地中海变成内湖」是修辞，不是精确描述。罗马帝国在 117 年图拉真时期达到最大疆域，但：

- 它没有征服日耳曼尼亚全境、达契亚以北、美索不达米亚全境；
- 它的边界是「可防御的线」，不是「自然地理的终点」；
- 它的内部是「行省 + 城市 + 地方精英」的拼接，不是同质化的「罗马民族」。

> 🔗 **横向关联**：本节「地中海内湖是修辞」与 [政治统一的吸引力半径](../../../../人类学/政治统一的吸引力半径_量化模型与历史验证.md) §3.2「欧洲案例：罗马帝国的半径」形成**量化对照**——那篇用成本—收益模型估算罗马的统治半径；本节用制度语言解释为什么罗马能把这个半径撑到地中海尺度。**地图上的「内湖」，本质上是「税册 + 道路 + 军团 + 地方精英」四件东西的叠加。**

## 十、拜占庭与奥斯曼：东半部的两次换壳

### 10.1 拜占庭：罗马的希腊语基督教版本

「拜占庭帝国」是后世史家的叫法，当时的人自称「罗马人」（Rhomaioi）。它不是「希腊帝国」，而是**罗马帝国的东半部，在希腊语、基督教与君士坦丁堡的基础上重新长出来**：

| 维度 | 内容 |
| :--- | :--- |
| 政治 | 皇帝（basileus）是上帝在人间的代理人；宫廷礼仪繁复 |
| 法律 | 查士丁尼《民法大全》保存罗马法 |
| 宗教 | 东正教；皇帝与牧首相互依存又相互制约 |
| 行政 | 军区制（themes）、官僚机构、地方贵族 |
| 文化 | 希腊语、古典教育、圣像、修道院 |

拜占庭的时间线可以压成几个节点：330 年君士坦丁堡建成；395 年帝国分治；476 年西罗马灭亡；527—565 年查士丁尼扩张；7 世纪阿拉伯征服失去叙利亚、埃及、北非；1204 年第四次十字军攻陷都城；1261 年复国；1453 年奥斯曼攻陷。

### 10.2 巴尔干与伊利里亚：一千年并不是连续的一千年

用户材料说「巴尔干和伊利里亚地区归它管了一千年」。这句话需要分层：

| 时期 | 拜占庭对巴尔干西部的控制 |
| :--- | :--- |
| 4—6 世纪 | 罗马/拜占庭行省体系继续运转 |
| 6—7 世纪 | 斯拉夫、阿瓦尔人进入内地；拜占庭退守沿海城市 |
| 9—11 世纪 | 拜占庭逐步反攻；1018 年灭保加利亚第一帝国，控制巴尔干 |
| 12 世纪 | 塞尔维亚、匈牙利、威尼斯争夺；控制力下降 |
| 1204—1261 | 第四次十字军后，拜占庭失去君士坦丁堡 |
| 14—15 世纪 | 奥斯曼逐步征服；1453 年终结 |

所以「一千年」是**制度与文化的长时段影响**，不是「连续一千年的直接行政控制」。**拜占庭的遗产是宗教、法律、城市与帝国观念，而不是一条从未断过的边界线。**

### 10.3 奥斯曼：从边疆侯国到「罗马凯撒」

奥斯曼帝国（传统建国年 1299—1922）最初只是安纳托利亚西北部的一个边疆侯国，夹在拜占庭、塞尔柱余部与蒙古势力之间。它的崛起有几个关键节点：

| 时间 | 事件 | 意义 |
| :--- | :--- | :--- |
| 1299（传统） | 奥斯曼一世建国 | 边疆侯国的起点 |
| 1326 | 夺取布尔萨 | 建立第一个重要都城 |
| 1361／1369 | 夺取阿德里安堡（埃迪尔内） | 进入巴尔干 |
| 1389 | 科索沃战役 | 巴尔干权力格局逆转 |
| 1453 | 攻陷君士坦丁堡 | 终结拜占庭；穆罕默德二世自称「罗马凯撒」（Kayser-i Rum） |
| 1517 | 塞利姆一世击败马穆鲁克 | 取得哈里发头衔与圣地 |
| 1520—1566 | 苏莱曼一世 | 帝国极盛；1529 年第一次围维也纳 |
| 1683 | 第二次围维也纳失败 | 由攻转守 |
| 1699 | 《卡尔洛维茨和约》 | 失去匈牙利大部分 |
| 1839—1876 | 坦志麦特改革 | 试图以近代官僚制自救 |
| 1912—1913 | 巴尔干战争 | 失去巴尔干大部分 |
| 1914—1918 | 一战 | 帝国解体 |
| 1922／1923／1924 | 废苏丹制／共和国／废哈里发 | 帝国终结 |

奥斯曼不是「拜占庭的延续」，而是**拜占庭空间的伊斯兰帝国继承者**：它接管了君士坦丁堡、巴尔干、安纳托利亚与地中海东岸，保留了部分拜占庭的税收与教会结构，但它的合法性来自伊斯兰、 dynastic 家族与「加齐」（gazi）传统，而不是罗马法或东正教。

### 10.4 奥斯曼的制度：德夫希尔梅、蒂马尔与米勒特

| 制度 | 内容 | 功能 |
| :--- | :--- | :--- |
| 德夫希尔梅（devshirme） | 从基督教农村征召男孩，训练为禁卫军与官僚 | 建立对苏丹个人忠诚的精英阶层 |
| 蒂马尔（timar） | 以土地收入供养骑兵，换取军事服务 | 地方军事采邑制 |
| 米勒特（millet） | 按宗教群体自治，管理婚姻、教育、税收 | 降低多宗教帝国的管理成本 |
| 卡农（kanun） | 苏丹的世俗法令，与伊斯兰法并行 | 处理帝国行政与税收 |
| 卡迪（kadı） | 伊斯兰法官，兼管地方行政 | 把司法与地方治理结合 |

> 🔗 **横向关联**：本节「德夫希尔梅与蒂马尔」与 [农业帝国编年史](../../../../人类学/农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）.md) §5.1「奥斯曼帝国：Devshirme 儿童血税与 Timar 军事采邑」形成**直接展开**——那篇从提取率角度解释这两套制度如何把人力与土地转化为军事力量；本节从帝国接力角度解释它们为什么能让奥斯曼在 15—16 世纪成为东地中海最强政权。**制度不是「文化特色」，而是「提取与忠诚的交换装置」。**

### 10.5 1453 之后：拜占庭的「空间继承者」不是「血统继承者」

1453 年之后，奥斯曼苏丹自称「罗马凯撒」，保留了东正教牧首制，使用拜占庭的某些宫廷礼仪与税收技术。但这不意味着奥斯曼是拜占庭的「血统延续」：

| 维度 | 拜占庭 | 奥斯曼 |
| :--- | :--- | :--- |
| 合法性 | 基督教皇帝，上帝代理人 | 伊斯兰苏丹—哈里发，加齐传统 |
| 精英来源 | 希腊—罗马贵族、官僚、教会 | 德夫希尔梅、土耳其—巴尔干军事精英 |
| 法律 | 罗马法 + 东正教法 | 伊斯兰法 + 苏丹卡农 |
| 宗教 | 东正教 | 逊尼派伊斯兰教，米勒特制度 |
| 语言 | 希腊语 | 奥斯曼土耳其语（阿拉伯—波斯—土耳其混合） |

> 🔗 **横向关联**：本节「空间继承者不是血统继承者」与 [犹太教、基督教、东正教与新教的发展历史](../../../意识形态，宗教和文化运动/犹太教、基督教、东正教与新教的发展历史：三次分化与两千年谱系.md) §四「1054 年：第二次分化」及 §7.4「东正教线：俄国革命、冷战与国家认同」形成**长时段呼应**——那篇讲东正教如何在拜占庭之后继续存在；本节讲奥斯曼如何把东正教纳入米勒特制度。**宗教可以换一个帝国容器继续存活，但容器的合法性语法已经换了。**

## 十一、边缘的回报：伊利里亚人如何进入这条谱系

### 11.1 伊利里亚战争：海盗、银矿与罗马的耐心

罗马与伊利里亚人的冲突，表面上是「海盗问题」，底层是**亚得里亚海东岸的控制权**：

| 战争 | 时间 | 起因 | 结果 |
| :--- | :--- | :--- | :--- |
| 第一次伊利里亚战争 | 前 229—前 228 | 阿尔迪安女王特乌塔的海盗活动 | 罗马控制沿海据点，伊利里亚成为附庸 |
| 第二次伊利里亚战争 | 前 220—前 219 | 伊利里亚人再次扩张 | 罗马再次干预，削弱阿尔迪安 |
| 第三次伊利里亚战争 | 前 168 | 根提乌斯与马其顿结盟 | 根提乌斯战败，伊利里亚被罗马控制 |

罗马花了 61 年（前 229—前 168）才把这片海岸线纳入势力范围。这不是因为伊利里亚人「特别能打」，而是因为**山地地形 + 部落分散 + 海盗游击**让征服成本很高。罗马的解决办法不是「一次性灭国」，而是「沿海设点 + 扶植代理人 + 逐步蚕食」。

### 11.2 罗马化与语言分叉：沿海拉丁化，山地保住阿尔巴尼亚语

罗马统治之后，伊利里亚地区出现了明显的**语言分叉**：

| 区域 | 语言走向 | 结果 |
| :--- | :--- | :--- |
| 沿海城市（萨罗纳、纳罗纳、亚德尔、斯库台） | 拉丁语 → 达尔马提亚罗曼语 | 城市精英拉丁化；达尔马提亚语最后在 19 世纪消亡 |
| 内陆山地 | 本地伊利里亚语/巴尔干古语 | 逐渐演变为阿尔巴尼亚语 |
| 边境与商路 | 拉丁语 + 希腊语 + 本地语 | 多语并存 |

> 📌 **达尔马提亚罗曼语（Dalmatian Romance）**：罗马化的达尔马提亚沿海居民所说的罗曼语，与意大利语、罗马尼亚语有亲缘关系，最后一个使用者（Vegliot 方言）在 1898 年去世。它说明「罗马化」不是「所有人都变成意大利人」，而是**沿海城市说拉丁语，内地山地保留本地语言**。

### 11.3 阿尔巴尼亚语：孤岛、主流假说与争议

阿尔巴尼亚语是印欧语系中独立的一支，没有近亲。它不属于斯拉夫语族、希腊语族或罗曼语族，这一点没有争议。有争议的是它的**来源**：

| 假说 | 主张 | 支持证据 | 难点 |
| :--- | :--- | :--- | :--- |
| 伊利里亚说（主流） | 阿尔巴尼亚语直系源于伊利里亚语 | 古地名/族名的音变对应；罗马时期山地人口连续性；缺乏大规模替换记载 | 伊利里亚语语料太少，无法做严格谱系比对 |
| 达契亚—色雷斯说 | 阿尔巴尼亚语来自达契亚—色雷斯语 | 某些语音与词汇对应；巴尔干底层共同特征 | 达契亚语同样语料稀少；地理距离较远 |
| 混合/多重底层说 | 阿尔巴尼亚语是多种巴尔干古语叠加 | 词汇层复杂；与罗马尼亚语共享巴尔干特征 | 难以确定主次 |

更稳妥的表述是：**阿尔巴尼亚语通常被视为巴尔干古语（Paleo-Balkan）中唯一存活至今的独立分支（希腊语另属 Hellenic 语族），主流观点倾向于伊利里亚来源，但不是已被证明的定论。** 阿尔巴尼亚语最早的文献是 1462 年的《洗礼公式》（Formula e Pagëzimit）和 1555 年 Gjon Buzuku 的《弥撒书》（Meshari），这已经是奥斯曼时期，距离古典伊利里亚人很远。

> 🔗 **横向关联**：本节「起源叙事需要证据分级」与 [特洛伊](特洛伊：九层城、维鲁萨与一场被神话重写的战争（约前 3000—公元 500）.md) §7.4「中世纪的『特洛伊祖先』」形成**同构关系**——那篇讲中世纪欧洲人如何把特洛伊人认作祖先；本节讲现代巴尔干民族如何把伊利里亚人认作祖先。**「祖先叙事」从来不只是历史问题，它也是政治合法性问题。**

### 11.4 伊利里亚诸帝：一张名单与三处校正

三世纪危机（235—284）之后，罗马帝国出现了一批通常被称为「伊利里亚诸帝」（Illyrian emperors）的军人皇帝。他们大多出身巴尔干—多瑙河地区，靠军队上升，最终拯救了帝国：

| 皇帝 | 在位 | 出生地（通常说法） | 备注 |
| :--- | :--- | :--- | :--- |
| 克劳狄二世（Claudius II Gothicus） | 268—270 | 西尔米乌姆一带（一说达尔达尼亚） | 击败哥特人；病死瘟疫 |
| 奥勒良（Aurelian） | 270—275 | 西尔米乌姆/达契亚里彭西斯 | 「世界光复者」；修筑罗马城墙 |
| 普罗布斯（Probus） | 276—282 | 西尔米乌姆 | 军人皇帝；被士兵杀死 |
| 戴克里先（Diocletian） | 284—305 | 萨罗纳（Salona，今索林） | 四帝共治；退位于斯普利特宫殿 |
| 马克西米安（Maximian） | 286—305 | 西尔米乌姆附近 | 戴克里先的共治者 |
| 君士坦提乌斯一世（Constantius I） | 305—306 | 内索斯（Naissus，今尼什） | 君士坦丁之父 |
| 伽列里乌斯（Galerius） | 305—311 | 加姆济格拉德（Gamzigrad） | 戴克里先的女婿 |
| 君士坦丁一世（Constantine I） | 306—337 | 内索斯（Naissus） | 基督教合法化；建君士坦丁堡 |
| 瓦伦提尼安一世（Valentinian I） | 364—375 | 基巴莱（Cibalae，今温科夫齐） | 多瑙河防线 |
| 瓦伦斯（Valens） | 364—378 | 基巴莱 | 亚德里亚堡战死 |

这张名单说明「罗马是被伊利里亚人救活的」这句话有事实基础：**三世纪危机后的重建，主要靠巴尔干—多瑙河出身的军人皇帝。** 但也要注意三点校正：

| 流行说法 | 校正 |
| :--- | :--- |
| 「瓦莱里安是伊利里亚皇帝」 | 瓦莱里安（253—260）出身意大利元老贵族，不是伊利里亚人；他被沙普尔一世俘虏，是罗马的耻辱，不是伊利里亚军人的代表 |
| 「君士坦提乌斯出生在那不勒斯」 | 他生于内索斯（Naissus，今尼什），不是那不勒斯；君士坦丁也生于内索斯 |
| 「伊利里亚诸帝是一整个连续王朝」 | 他们不是同一个王朝，而是一批出身相近、靠军队上位的皇帝；「伊利里亚诸帝」是史家标签，不是血统家族 |

三处校正合起来说明：伊利里亚诸帝是一个「出身地域 + 军人上升通道」的群体，不是一个血统王朝；把他们说成「伊利里亚人的王朝」，会重复同样的血统叙事错误。

### 11.5 从斯坎德培到 1912：民族国家的诞生

伊利里亚人的后代在奥斯曼统治下，进入了另一条历史路径：

| 时间 | 事件 | 意义 |
| :--- | :--- | :--- |
| 1444 | 莱什联盟（League of Lezhë） | 阿尔巴尼亚贵族联合抵抗奥斯曼 |
| 1443—1468 | 斯坎德培（Skanderbeg）抵抗 | 约 25 年的山地战争 |
| 1468 | 斯坎德培病死 | 抵抗失去核心 |
| 1478—1479 | 克鲁亚、斯库台陷落 | 奥斯曼控制阿尔巴尼亚 |
| 1501 | 都拉斯陷落 | 沿海最后据点失守 |
| 17—18 世纪 | 伊斯兰化加速 | 社会精英与城市逐渐皈依 |

这张表说明：阿尔巴尼亚民族国家的诞生，不是「古老民族突然觉醒」，而是**帝国解体 + 巴尔干战争 + 列强划界**三件事同时作用的结果。

### 11.6 三条线如何拧成「阿尔巴尼亚人」

把前面的线索收拢，可以看到三条线：

| 线索 | 内容 | 对「阿尔巴尼亚人」的意义 |
| :--- | :--- | :--- |
| 语言线 | 伊利里亚语/巴尔干古语 → 阿尔巴尼亚语 | 提供「我们一直在这里」的连续性叙事 |
| 帝国线 | 罗马 → 拜占庭 → 奥斯曼 | 提供「我们被不同帝国统治过」的历史经验 |
| 民族线 | 部落 → 习惯法（Kanun）→ 民族国家 | 提供「山地自治 + 亲缘网络」的社会结构 |

关于「山民性格、部落抱团」的说法，需要避免本质主义。更可靠的解释是**结构性**的：山地地形、低国家渗透、亲缘网络、习惯法与移民链条，共同塑造了高信任、低中央权威的社会组织方式。现代犯罪组织中的亲缘网络，不能被解释为「民族天性」，而应被解释为**国家能力不足 + 边缘经济 + 移民网络**的组合。

> 🔗 **横向关联**：本节「山地自治 + 亲缘网络」与 [农业帝国编年史](../../../../人类学/农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）.md) §5.1「奥斯曼帝国」及 [国家的概念史](../../国家的概念史与建制化程度：现代国家、历史语汇与中间形态.md) §5.6「城邦、帝国、联邦、酋邦」形成**三层对照**——农业帝国篇讲奥斯曼如何提取山地人力；概念史篇讲「国家」如何在不同规模上变形；本节讲山地社会如何在帝国边缘保留自治，最终在 1912 年变成民族国家。

## 十二、结构解剖：帝国接力的四种「遗传物质」

### 12.1 四种「遗传物质」的传递表

下面这张表是全文的压缩版。符号是启发式阅读，不是精确测量：●＝强，◐＝中，○＝弱/断。

| 遗产 | 阿契美尼德 | 亚历山大 | 继业者三国 | 罗马 | 拜占庭 | 奥斯曼 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 疆域骨架 | ● | ◐ | ● | ● | ◐ | ● |
| 行政技术 | ● | ◐ | ● | ● | ● | ● |
| 文化语言 | ◐ | ● | ● | ● | ● | ◐ |
| 合法性模板 | ● | ● | ◐ | ● | ● | ● |

最关键的一行是「文化语言」：**波斯的行政技术很强，但它的文化语言没有成为东地中海的通用语；希腊化把希腊语变成通用语，因此它的文化寿命最长。** 这就是为什么亚历山大作为「领土帝国」很短，作为「文化程序」很长。

### 12.2 三种接力模式

| 模式 | 机制 | 例子 |
| :--- | :--- | :--- |
| 征服者被文化征服 | 军事胜利者吸收被征服者的上层文化 | 罗马吸收希腊文化 |
| 边缘反噬中心 | 帝国边缘的军事集团夺取中心 | 马其顿灭波斯；伊利里亚诸帝救罗马；奥斯曼灭拜占庭 |
| 宗教换壳 | 帝国崩溃后，宗教共同体成为新的容器 | 拜占庭东正教 → 奥斯曼米勒特；萨珊琐罗亚斯德教 → 伊斯兰 |

这三种模式经常叠加。比如奥斯曼灭拜占庭，既是「边缘反噬中心」，又是「宗教换壳」：安纳托利亚边疆的伊斯兰政权夺取君士坦丁堡，然后把东正教纳入米勒特制度。

### 12.3 帝国肉身与帝国基因

| 层 | 内容 | 寿命 | 例子 |
| :--- | :--- | :--- | :--- |
| 帝国肉身 | 王朝、首都、军队、疆域 | 短则十几年，长则几百年 | 亚历山大帝国 13 年；奥斯曼 623 年 |
| 帝国基因 | 道路、城市、语言、税册、王权叙事 | 可以跨王朝、跨宗教存活 | 波斯行省 → 塞琉古 → 罗马东方行省 |
| 帝国记忆 | 史诗、神话、祖先叙事 | 可以跨民族、跨语言存活 | 荷马 → 亚历山大 → 罗马 → 拜占庭 |

**帝国的「肉身」会死，「基因」会换宿主，「记忆」会被后来者重写。** 这就是为什么「亚历山大帝国只活了 13 年」和「希腊化延续了 300 年」并不矛盾：它们说的是两个不同的层。

### 12.4 「分数解释能力，冗余解释存活」

库内关于国家形成的一条经验判断是：**分数解释能力，冗余解释存活。** 建制化分数高的政治体，通常能力更强；但能否长期存活，往往取决于它有没有冗余——多个中心、多套合法性、多个税收来源、多条商路。

| 政治体 | 建制化（启发式） | 冗余 | 结果 |
| :--- | :--- | :--- | :--- |
| 阿契美尼德 | 7／16 | 行省 + 地方神 + 驿道 | 被亚历山大打穿，但制度被继承 |
| 塞琉古 | 中高 | 城市多，但中心太远 | 被帕提亚与罗马两头蚕食 |
| 托勒密 | 高 | 尼罗河 + 亚历山大里亚 | 最长寿，但最终被罗马吞并 |
| 罗马 | 高 | 公民权 + 行省 + 道路 + 法律 | 西部灭亡，东部延续 |
| 拜占庭 | 高 | 君士坦丁堡 + 希腊语 + 东正教 + 官僚 | 撑到 1453 |
| 奥斯曼 | 高 | 米勒特 + 蒂马尔 + 德夫希尔梅 + 多中心 | 撑到 1922 |

> 🔗 **横向关联**：本节「分数解释能力，冗余解释存活」与 [国家的概念史](../../国家的概念史与建制化程度：现代国家、历史语汇与中间形态.md) §8.2「八要件评分矩阵」及 [爱琴海文明](爱琴海文明：基克拉泽斯、米诺斯与迈锡尼的三个世界（约前 3200—前 1100）.md) §7.5「八要件打分：账本很强，国家很浅」形成**方法串联**——概念史篇给评分框架；爱琴海篇给「分数高但冗余低」的迈锡尼案例；本节把同一判断扩展到波斯、罗马、拜占庭与奥斯曼。

## 十三、收束：归因、延伸与个体坐标

### 13.1 归因：帝国接力传递的是「可复制的安排」

把三千年压成一句话：**帝国接力传递的不是血统，也不是某个民族的「天命」，而是一套可复制的安排。**

这套安排包括：

1. **怎么收税**：行省、定额、包税、蒂马尔、米勒特；
2. **怎么走路**：驿道、港口、运河、商路；
3. **怎么说话**：阿拉米语、希腊语、拉丁语、奥斯曼土耳其语；
4. **怎么合法**：大王、法老、神王、皇帝、苏丹—哈里发。

亚历山大之所以是「分界线」，不是因为他建立了最长寿的帝国，而是因为他把这四件事**同时推到了三个大洲**。他死后，继业者、罗马、拜占庭、奥斯曼各自拿走一部分，又重新组合。**帝国的肉身不断换，帝国的语法不断被重写，但「用一套安排去管理差异」这个动作，一直没有停。**

### 13.2 延伸：现代国家如何继承帝国

现代巴尔干、中东、东地中海的民族国家，几乎都是帝国解体后的「碎片」：

| 现代国家/地区 | 帝国遗产 |
| :--- | :--- |
| 希腊 | 拜占庭的东正教、古希腊的古典教育、奥斯曼的行政边界 |
| 土耳其 | 奥斯曼的官僚、军队、伊斯兰—世俗双重传统 |
| 阿尔巴尼亚 | 伊利里亚—罗马—拜占庭—奥斯曼的多层遗产 |
| 北马其顿 | 马其顿王国、拜占庭、奥斯曼、南斯拉夫 |
| 塞尔维亚/科索沃 | 拜占庭、奥斯曼、南斯拉夫；达尔达尼亚的记忆 |
| 埃及/叙利亚/伊拉克 | 波斯、希腊化、罗马、伊斯兰、奥斯曼 |
| 伊朗 | 阿契美尼德、帕提亚、萨珊、伊斯兰共和国 |

这些国家都在用「祖先叙事」把帝国遗产翻译成民族合法性：希腊用古典希腊，土耳其用奥斯曼，阿尔巴尼亚用伊利里亚，伊朗用波斯。**这不是「伪造历史」，而是「选择性地继承历史」——每个民族国家都会从多层遗产中挑一条线，把它讲成自己的主线。**

### 13.3 个体坐标：读帝国谱系的三问

如果你以后再看到「某帝国亡于某年」「某民族是某古族的直系后裔」这类说法，可以先问三个问题：

1. **谁在付税、谁在服役？** 帝国的地图很好看，但真正决定它能不能维持的，是税收与兵源。
2. **谁在翻译地方差异？** 帝国不是靠「所有人都一样」维持的，而是靠一套把差异分级、登记、征税的安排。
3. **帝国死后，什么东西还活着？** 王朝会死，道路、城市、语言、宗教、法律与祖先叙事会活得更久。

**亚历山大是逗号，但逗号后面那句话，由继业者、罗马、拜占庭、奥斯曼和无数地方精英一起写完。** 伊利里亚人从「海盗」到「罗马皇帝」到「山地民族」的这条线，就是这句话里的一个从句。
