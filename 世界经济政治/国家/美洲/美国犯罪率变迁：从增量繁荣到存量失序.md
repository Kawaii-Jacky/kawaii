# 美国犯罪率变迁：从增量繁荣到存量失序

> **核心命题**：美国犯罪率的百年波动不是"道德败坏"或"执法松紧"所能解释的——它是**增量→存量相变的社会温度计**。犯罪率的每一次大波动，背后都对应着经济结构、阶级流动性和制度合法性的根本性转换。

---

## 一、百年犯罪率全景：一张图看懂增量/存量

```

  1960：160  ──┐
  1965：200    │ 开始攀升
  1970：364    │ 去工业化启动
  1975：488    │ 越战+石油危机+城市暴动
  1980：597    ├── 快速恶化期
  1985：557    │ 里根时代"毒品战争"
  1990：732    │ 裂解可卡因(crack)危机高峰
  1991：758 ←─┘ 历史峰值
  1994：714    │ 《暴力犯罪控制法》
  2000：507    ├── 持续下降期
  2005：469    │
  2010：404    │
  2014：366 ←─┘ 低谷
  2016：397    │ 开始反弹
  2020：399    ├── 疫情+弗洛伊德抗议
  2022：381    │ 部分回落
  2024：~350   │ 继续下降但结构变化
```

### 关键分水岭

```
1973年 = 美国经济的"相变年"

1973年之前（增量时代）：
  ├── 实际工资年均增长2-3%
  ├── 犯罪率低且稳定
  ├── 社会流动性高
  ├── 中产阶级持续扩大
  └── "美国梦"有物质基础

1973年之后（存量时代启动）：
  ├── 实际工资停滞（底层50%的实际工资50年几乎没涨）
  ├── 犯罪率暴涨（1960→1991翻了近5倍）
  ├── 毒品泛滥（先是海洛因，然后是crack可卡因）
  ├── 城市空心化（白人逃离inner city）
  └── "美国梦"变成信用卡债务
```

## 二、为什么1973年是分水岭？

### 2.1 经济结构断裂

```
1945-1973（黄金时代/增量时代）：
  ├── 布雷顿森林体系 → 美元-黄金锚定 → 全球稳定
  ├── 战后重建红利 → 美国制造业无竞争对手
  ├── 工会覆盖率35% → 工人分享增长果实
  ├── 最高边际税率91% → 财富再分配有效
  ├── GI法案 → 退伍军人免费上大学+低息房贷
  └── 结果：最底层20%的收入增速 > 最顶层20%

1973年后（存量时代）：
  ├── 尼克松1971年关闭黄金窗口 → 布雷顿森林崩溃
  ├── 1973年石油危机 → 滞胀（高通胀+高失业）
  ├── 日本/德国制造业崛起 → 美国制造业竞争力下降
  ├── 工会覆盖率从35%降至6%（私营部门）
  ├── 里根革命（1981）→ 减税+去监管+打压工会
  └── 结果：最顶层1%的收入增速 >> 其他所有人
```

### 2.2 犯罪率与实际工资的镜像关系

```
  实际中位数工资（2020美元计）    暴力犯罪率
  1973: $54,000（峰值）          364
  1980: $50,000（下降）          597
  1990: $52,000（勉强恢复）       732
  1995: $52,500                  685
  2000: $55,000（终于超过1973）   507
  2020: $56,000                  399

  50年间：
  生产率增长了约160%
  实际工资增长了约4%
  → 增长果实被顶层拿走了
  → 底层的"美国梦"破产
  → 犯罪率上升 = 非正式经济的扩张（毒品贸易是底层的"创业"）
```

## 三、犯罪率变化的四个时代

### 3.1 增量时代（1945-1973）：低犯罪的黄金期

```
社会条件：
  ├── 就业充分 → 制造业提供大量蓝领中产工作
  ├── 社区稳定 → 邻里关系紧密，社会资本高
  ├── 上升通道 → 高中学历即可买房养家
  ├── 国家叙事 → "美国梦"有真实兑现
  └── 犯罪率低且稳定

犯罪类型：
  主要是传统犯罪（盗窃、抢劫）
  有组织犯罪（意大利黑手党）是主要威胁
  毒品问题有限（主要是爵士乐圈子的海洛因）
```

### 3.2 相变期（1973-1994）：犯罪率暴涨

```
驱动因素叠加：
  ① 去工业化 → 蓝领工作消失 → 底层青年失业
  ② 城市空心化 → 中产逃离 → 内城(inner city)资源枯竭
  ③ 家庭结构变化 → 单亲家庭比例飙升（黑人社区从20%→70%）
  ④ 毒品经济 → 底层青年的"替代就业"
  ⑤ 婴儿潮效应 → 大量年轻人进入犯罪高发年龄段（15-25岁）
  ⑥ 制度信任崩溃 → 越战+水门+种族冲突

犯罪地理学：
  犯罪集中于"去工业化走廊"：
  底特律、巴尔的摩、克利夫兰、圣路易斯、纽瓦克、弗林特
  → 这些城市恰恰是制造业流失最严重的城市
  → 犯罪率地图 ≈ 去工业化地图
```

### 3.3 存量时代的治标（1994-2014）：犯罪率下降

```
犯罪率为什么从1994年开始下降？学术界仍有争论，主要假说：

  ① 大规模监禁（Mass Incarceration）→ 贡献约25-30%
     1980年：约50万在押
     2009年：约230万在押（增长360%）
     → 将"高风险人口"物理性移出社区

  ② 警务策略变革 → 贡献约10-15%
     纽约"破窗理论"(Broken Windows)
     CompStat数据驱动警务
     社区警务(Community Policing)

  ③ 裂解可卡因(crack)市场饱和 → 贡献约10-15%
     crack市场在1990年代稳定 → 地盘战减少

  ④ 人口结构变化 → 贡献约10-15%
     婴儿潮一代走出犯罪高发年龄段
     移民涌入（移民犯罪率低于本土出生者）

  ⑤ 含铅汽油淘汰（Donohue-Levitt假说的变体）
     1970年代逐步淘汰含铅汽油
     → 铅暴露减少 → 20年后暴力行为下降

  ⑥ 经济改善 → 贡献约5-10%
     1990年代互联网泡沫经济繁荣
     失业率从7.5%降至4%

关键判断：
  犯罪率下降 ≠ 社会病因消失
  只是通过大规模监禁和警务升级"压制了症状"
  底层结构（去工业化、工资停滞、社区瓦解）完全没变
```

### 3.4 存量深化期（2014-至今）：犯罪形态变异

```
2014年后的新特征：

  ① 暴力犯罪反弹（2015-2020）
     → 弗格森效应（Ferguson Effect）：警察在BLM（Black Lives Matter）压力下减少主动执法
     → 疫情封锁 → 社会张力释放 → 2020年凶杀案激增30%

  ② 犯罪形态变异
     ├── 零元购/有组织零售盗窃(ORC) → 新型财产犯罪
     ├── 催化转化器盗窃 → 贵金属驱动的精准犯罪
     ├── 网络犯罪/身份盗窃 → 犯罪数字化
     └── 跟踪入室抢劫(follow-home robberies) → 社交媒体驱动

  ③ 毒品危机转型
     └── 从crack可卡因 → 处方阿片 → 海洛因 → 芬太尼
     └── 每年超10万人药物过量死亡（2021-2023）

  ④ 无家可归者危机
     └── 旧金山/洛杉矶/西雅图/波特兰街头帐篷城
     └── 与毒品+精神疾病+住房成本三重交叉
```

## 四、用图尔钦框架重新解读美国犯罪率

```
图尔钦三变量在美国的投射：

① 大众贫困化（popular immiseration）
   1973年后实际工资停滞 → 底层丧失合法上升通道
   → 非正式经济（毒品贸易）成为替代
   → 犯罪率上升是"非正式经济"的指标

② 精英过剩（elite overproduction）
   大学毕业生过剩 + 好工作不够
   → 精英内部竞争激化 → 政治极化
   → 检察官/法官也在极化（进步派检察官 vs 严刑峻法派）
   → 这直接影响犯罪政策的摇摆

③ 国家财政恶化
   大规模监禁年均成本约800亿美元
   → 财政可持续性受质疑
   → 左派要求减少监禁，右派要求更多警察
   → 政策在两极之间摇摆

波兰尼双向运动：
  市场脱嵌（去工业化/工资停滞）→ 社会反扑
  美国的反扑形式：
    底层：犯罪/毒品（非正式抵抗）
    中层：特朗普运动（政治抵抗）
    精英层：BLM/Defund Police（文化抵抗）
  → 三种反扑互相冲突，而非指向同一目标
```

## 六、犯罪率作为"相变温度计"的理论意义

> **犯罪率不是"坏人变多了"的指标——它是社会契约履行程度的负向指标。**
>
> 当社会契约被兑现（增量时代）：人们通过合法渠道获取资源 → 犯罪率低
> 当社会契约被违约（存量时代）：合法渠道失效 → 非正式/非法渠道扩张 → 犯罪率高
>
> 美国1973年后的犯罪率暴涨，本质上是"美国梦违约"的社会学后果。
> 1994年后的犯罪率下降，不是契约被修复，而是违约者被关进了监狱。
> 2014年后的犯罪形态变异（零元购/芬太尼/无家可归），是压制策略开始失效的信号。
