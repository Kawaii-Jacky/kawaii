# 十字军东征：四台机器如何把一场朝圣变成两百年的战争（1095—1291） (The Crusades: How Armed Pilgrimage, Feudal Succession, Papal Revolution, and Maritime Commerce Sustained Two Centuries of Holy War)

> **根节点**：为什么一场以"解放圣墓"为名的朝圣远征，最后既没有守住圣墓，也没有带来和平，却把一套"收税—借钱—发船—记账"的技术留在了欧洲？——十字军究竟是宗教狂热的爆发，还是四台制度机器在 1095 年恰好咬合的产品？

> **立场说明**：本文按十字军史、教会史与伊斯兰史的通行研究整理；凡"当时人的说法"与"后世史学判断"会分开写；军队规模、死亡人数、财政数字给区间并标注争议；既不把十字军写成"文明冲突"的单一主体，也不把宗教动机还原为纯粹的物质利益。

**先纠正一个用词。** 当时人并不说"十字军"。他们说的是 *iter*（行程）、*peregrinatio*（朝圣）、*passagium*（渡海远征）；参与者叫 *crucesignatus*——"被十字标记的人"。*cruciata* 这类"十字军"名词要到 13—15 世纪才流行。这不是文字游戏：**没有统一的名称，就没有统一的组织。** 十字军从来不是一支军队，而是一套由教皇授权、由誓愿者自愿参加、由商人承运、由领主买单的临时联合体。

> 📌 **十字军（Crusade）**：本文采取"广义—制度"定义：由教皇授权、以赦罪与誓愿为核心、以武装远征为形式的基督教战争；既包括 1095—1291 年以黎凡特为目的地的远征，也包括伊比利亚、波罗的海、法国南部与反奥斯曼的"复制品"。在本文中的作用：这个定义把"宗教动机"与"制度形式"分开——前者解释为什么有人去，后者解释为什么能反复组织起来。

## 一、坐标：为什么是 1095 年（四台机器与一个窗口）

### 1.1 十字军不是第一次"圣战"

把 1095 年当成"宗教狂热的突然爆发"，会漏掉此前的三次预演。

1063 年，教皇亚历山大二世鼓励基督徒在伊比利亚攻打巴瓦斯特罗；1087 年，比萨、热那亚与阿马尔菲的舰队远征北非马赫迪耶；1074 年，格里高利七世甚至在书信里提议亲自率 5 万骑士援助拜占庭。三件事都没有变成"十字军"，但三件事都包含了十字军的零件：**教皇授权、赦罪承诺、武装远征、对"异教徒"的暴力。**

差别在于，1095 年把这些零件装成了一台可以反复启动的机器。乌尔班二世的关键创新不是"号召战争"——这在中世纪并不稀奇——而是把**朝圣的法律形式**（誓愿、苦修、赦罪）与**封建的军事形式**（骑士、领主、采邑）焊接在一起，再由教皇充当"授权机构"。

> 📌 **圣战（Holy War）**：以宗教目的为正当性来源、由宗教权威授权或祝福的战争；它与"正义战争"（just war）不同：后者追问"战争是否符合正义条件"，前者追问"战争是否服务于神圣目的"。在本文中的作用：十字军同时借用了两套语言——对内有"正义战争"的法理，对外有"圣战"的动员。

### 1.2 机器一：朝圣——把"走路"变成"赎罪"

11 世纪的欧洲，朝圣从精英修行变成了大众运动。三条大路线——耶路撒冷、罗马、圣地亚哥-德孔波斯特拉——把道路、桥梁、客栈、医院与圣物经济连成网络。朝圣者带着罪、疾病、誓言与礼物上路；教会则把"走路"折算成"补赎"：走多远、走多久、受多少苦，都可以换算成罪罚的减免。

这套换算系统在 11 世纪变得越来越精细。修道院改革（克吕尼）、千禧年焦虑（1033 年前后的朝圣潮）、封建暴力造成的赎罪需求，共同把"朝圣"推成一种**可规模化的宗教产品**。1095 年，乌尔班二世做的，是把这条产品的终点从"圣墓前祈祷"改成"圣墓前战斗"。

> 📌 **朝圣（Pilgrimage）**：前往圣地、圣徒墓或圣物所在地的宗教旅行，兼具苦修、感恩、求医与司法补偿功能。在本文中的作用：它是十字军的"母体"——十字军不是"战争"，而是"武装朝圣"；这解释了誓愿、财产保护、债务延期与"朝圣者"身份为何是十字军制度的核心。

> 📌 **赦罪（Remission of Sins）**：教会以基督与圣徒的功德为根据，减免信徒在炼狱中的罪罚；11 世纪的十字军赦罪主要是"把苦修折算为远征"，还不是后来可以用钱购买的赎罪券。在本文中的作用：它是教皇能够提供的**唯一"货币"**——没有土地、没有军饷，教皇用赦罪支付了整场运动的"工资"。

**关键差别：** 1095 年的赦罪不是"卖"，而是"换"。骑士用命换赦罪，教皇用赦罪换兵。到 1213 年《Quia maior》允许"以钱代誓"，这台机器才开始接受现金；到 1517 年，路德看到的已经是一台彻底财政化的机器。

> 🔗 **横向关联**：本节"赦罪作为非货币激励"与 [马丁·路德与宗教改革](马丁·路德与宗教改革：从赎罪券到威斯特伐利亚（1517—1648）.md)（第二节"引爆"、3.1 节"因信称义"）形成**上下游关系**——本文交代赦罪如何从"苦修折算"变成"武装远征"，该笔记交代它如何在 1517 年变成一场关于"救赎能否被计价"的神学总爆发。

### 1.3 机器二：继承——长子拿走土地，幼子拿走刀剑

11—12 世纪，长子继承制（primogeniture）在西欧（尤其法国北部、诺曼底、佛兰德）逐步扩散。长子拿走全部或大部分地产，幼子得到的是骑士训练、一把剑与一段被延长的"青年期"（Duby 所说的 *juventus*）。比武大会、私战、雇佣兵与十字军，都是这批"有身份、无地产"的骑士的出口。

但这台机器不能解释"谁发起了十字军"。第一次十字军的核心领袖几乎都是有地的大贵族：

| 领袖 | 领地/身份 | 参战动机（史料可见） | 结局 |
| :--- | :--- | :--- | :--- |
| 布永的戈弗雷 | 下洛林公爵，洛林贵族 | 虔诚朝圣 + 家族竞争 | 1099 年当选"圣墓守护者"，1100 年死 |
| 布洛涅的鲍德温 | 戈弗雷之弟 | 土地与王位 | 埃德萨伯爵，1100 年成为耶路撒冷国王 |
| 塔兰托的博希蒙德 | 诺曼意大利贵族 | 领地与安条克 | 1098 年取安条克，1100 年被俘，后回意大利 |
| 坦克雷德 | 博希蒙德之侄，无地 | 地位与战利品 | 加利利领主、安条克摄政 |
| 图卢兹的雷蒙四世 | 普罗旺斯最富有的伯爵之一 | 虔诚 + 权力 | 的黎波里奠基者，1105 年死 |
| 诺曼底的罗贝尔二世 | 诺曼底公爵 | 赎罪 + 借钱 | 回欧洲后被亨利一世囚禁至死 |
| 布洛瓦的斯蒂芬 | 布洛瓦伯爵 | 虔诚 + 家族压力 | 1098 年临阵脱逃，1102 年战死 |
| 佛兰德的罗贝尔二世 | 佛兰德伯爵 | 虔诚 + 政治 | 1111 年死 |

表里最关键的一行是"无地"的坦克雷德：他确实是幼子逻辑的产物，但他追随的是有地的叔父博希蒙德。**无地骑士是十字军的"兵源"，有地贵族是十字军的"发起人"，教皇是十字军的"授权人"。** 三种人各有各的账本，不能用一个"贪婪"或一个"虔诚"解释全部。

> 📌 **长子继承制（Primogeniture）**：地产由长子一人继承，以保持家族领地的完整；幼子通常进入教会、骑士团或雇佣军。在本文中的作用：它解释了十字军的"供给端"——为什么 11 世纪末有大量受过军事训练、却没有地产可继承的骑士愿意远行。

> 📌 **封建（Feudalism）**：一种以土地封授（fief）换取军事服务（service）与忠诚（homage）的社会—政治关系；它不是一个统一的法律体系，而是各地差异极大的权利束。在本文中的作用：它既提供了十字军的兵源与组织方式，也制造了"私战"问题——教皇革命要做的事，就是把这种分散暴力收编为"公共战争"。

> 🔗 **横向关联**：本节"封建把暴力分散到领主手中"与 [农业帝国编年史](../../人类学/农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）.md)（4.1 节"封建制度：暴力的分散化"）形成**上下游关系**——该笔记把封建解释为"低提取均衡下的暴力分散化"，本文展示这套分散暴力如何在 1095 年被教皇"重新集中"为跨地域远征。

> 🔗 **横向关联**：本节"长子继承—幼子外溢"与 [中国与西欧历史社会结构差异](../经济理论/资本与政体比较/中国与西欧历史社会结构差异：官僚帝国、多中心秩序与阶级形成.md)（二.1 节"西欧：多中心不是自由"、四.1 节"西欧精英可以依托多个制度入口"）形成**对照关系**——西欧精英的"出口"是多元的（教会、骑士团、十字军、城市），中国精英的"出口"主要被科举—官僚制吸纳；两条路径塑造了不同的暴力供给曲线。

### 1.4 机器三：教皇革命——把暴力"授权"成公共事业

1075 年，格里高利七世发布《教皇训令》（Dictatus Papae），宣称教皇有权废黜皇帝、解除臣民效忠。由此爆发的"叙任权之争"（Investiture Contest）持续到 1122 年《沃尔姆斯宗教协定》。这场斗争的结果不是"教会赢了"或"皇帝赢了"，而是**教会变成了一个拥有自己的法律、法庭、税收与官僚系统的"准国家"**。

> 📌 **教皇革命（Papal Revolution）**：法律史家伯尔曼（Harold Berman）使用的概念，指 11—12 世纪教皇格列高利七世改革所引发的教会法、教会法庭与教会官僚制的建立；它使教会成为第一个"现代意义上的法人组织"。在本文中的作用：没有这场革命，教皇就没有能力"授权"一场跨王国的战争，也没有能力用教令、特使、绝罚与税收把命令传到英格兰、法兰西与意大利。

同一时期，教会推动"和平运动"（Peace of God）与"上帝休战"（Truce of God）：前者保护教士、农民、妇女、商人与朝圣者不受私战侵害，后者规定每周若干天、每年若干节期禁止作战。1095 年克莱蒙会议在号召十字军之前，先重申了上帝休战——这不是巧合：**把骑士的暴力从"内部"转向"外部"，是同一套治理术的两面。**

> 📌 **和平运动 / 上帝休战（Peace of God / Truce of God）**：10—11 世纪教会发起的限制私战运动；前者划定不可侵害的人群与场所，后者划定不可作战的时间。在本文中的作用：它解释了十字军的一个悖论——教会一边禁止基督徒互相杀戮，一边鼓励基督徒去远方杀戮；答案是把暴力"出口"到异教徒身上。

> 📌 **正义战争（Just War）**：奥古斯丁以来的一套战争伦理：正当权威、正当理由、正当意图、最后手段、相称性。12 世纪格拉提安《教令集》与 13 世纪托马斯·阿奎那把这套标准系统化。在本文中的作用：它给十字军提供了"对内可辩护"的法理语言——十字军不是"私战"，而是由教皇授权的"公共战争"。

**教皇没有军队，但他有"授权"。** 这是十字军最核心的制度创新：教皇不支付军饷，只发行"合法性"；领主不领取工资，只领取"赦罪"；商人不要土地，只要"特权"。三种人各自用自己的账本，完成了一次跨欧亚的"联合投资"。

### 1.5 机器四：海运——没有船，就没有十字军

从巴黎到耶路撒冷直线约 3,300 公里，走陆路要翻越阿尔卑斯、巴尔干与安纳托利亚，耗时数月，死亡率极高。第一次十字军之所以能走到底，靠的是拜占庭的补给与意大利舰队的沿海支援；此后的每一次大规模远征，都离不开威尼斯、热那亚、比萨与阿马尔菲的船。

这些"海上共和国"在 11 世纪已经积累了三种东西：**船队、信贷、殖民地经验**。威尼斯在 1082 年从拜占庭获得金玺诏书，商人在君士坦丁堡拥有特区与免税权；比萨与热那亚在 1087 年远征马赫迪耶；阿马尔菲在埃及与君士坦丁堡设有商馆。十字军到来时，它们已经是地中海东部的"物流巨头"。

> 📌 **海上共和国（Maritime Republics）**：以海上贸易与海军为经济基础、实行公社式自治的意大利城邦，主要有威尼斯、热那亚、比萨、阿马尔菲。在本文中的作用：它们是十字军的"运输部"与"财政部"——没有它们，十字军无法跨海；有了它们，十字军就不得不把战争目标与商业利益绑定。

> 📌 **康曼达（Commenda）**：一种海上合伙契约：一方出资、一方出航，利润按约定分配，风险有限。在本文中的作用：它让"远航"从贵族冒险变成可计算的商业投资；十字军的运输合同，正是这套契约技术的放大版。

> 📌 **特许权（Privilege）**：领主或教皇授予特定群体的法律例外，如免税、司法豁免、贸易垄断、港口特区。在本文中的作用：它是十字军"支付"意大利城邦的方式——城邦不收现金，收的是"在阿卡、提尔、君士坦丁堡的街区与免税权"。

**一句话：** 十字军首先是一场物流工程，其次才是一场神学运动。把 5,000 名骑士、数万步兵、马匹、粮食、武器与攻城器械运到 3,000 公里外，并在敌国维持驻军——这在 11 世纪是只有意大利城邦才能承接的"国家级项目"。

> 🔗 **横向关联**：本节"意大利城邦把陌生人交易做成跨海合同"与 [资本市场的形成](../资本与人/资本市场的形成：从债务、集市、商行到制度化资本主义的权力史.md)（三.3 节"意大利商人：靠合同与法庭的陌生人交易"、第四节"商行与银行的诞生"）形成**上下游关系**——该笔记讲这套合同技术如何在集市与商行中成熟，本文讲它如何被十字军放大为跨海远征的运输与信贷系统。

### 1.6 一个窗口：曼齐刻尔特之后的拜占庭与分裂的伊斯兰世界

四台机器决定了"欧洲能组织起远征"，但决定"远征能成功"的，是 1095 年东方的政治窗口。

1071 年曼齐刻尔特战役后，拜占庭失去安纳托利亚腹地；阿莱克修斯一世（1081—1118）面对诺曼人、佩切涅格人与塞尔柱人的多线压力，向西方求援。他要的是**雇佣兵与缓冲国**，不是一支独立于他的十字军。十字军要的是**圣墓与领地**，不是替拜占庭收复安纳托利亚。双方从一开始就在谈两笔不同的生意。

伊斯兰世界则处于三重分裂：巴格达的阿拔斯哈里发只是名义元首，真正的军事力量是塞尔柱苏丹；1092 年马利克沙死后，塞尔柱诸子内乱，叙利亚分裂为若干地方埃米尔；埃及的法蒂玛王朝（什叶派）与逊尼派塞尔柱互为死敌，1098 年刚从塞尔柱手中夺回耶路撒冷。**1099 年十字军攻打的，其实是法蒂玛王朝的耶路撒冷，而不是塞尔柱帝国的主力。**

| 力量 | 1095 年的状态 | 对十字军的策略 | 结果 |
| :--- | :--- | :--- | :--- |
| 拜占庭（阿莱克修斯一世） | 曼齐刻尔特后失去安纳托利亚腹地；需要雇佣兵与缓冲国 | 要求十字军宣誓效忠，收回失地 | 借十字军收复尼西亚与西部沿海，但与拉丁人互不信任 |
| 逊尼派塞尔柱（阿拔斯哈里发为名义元首） | 马利克沙死后诸子内乱；叙利亚分裂为地方埃米尔 | 先内斗，后零散抵抗 | 无法统一迎战，被各个击破 |
| 什叶派法蒂玛（埃及） | 1098 年刚从塞尔柱手中夺回耶路撒冷 | 先谈判，后出兵 | 1099 年阿斯卡隆战败，耶路撒冷未夺回 |

这张表说明：**第一次十字军的成功，不是因为十字军更强，而是因为对手更碎。** 一旦穆斯林世界出现一个能同时动员埃及与叙利亚的强人（萨拉丁），十字军的胜率就急转直下——这是第五节的主题。

> 🔗 **横向关联**：本节"三方各打各的算盘"与 [阿拉伯之春](../国家/中东/阿拉伯之春：从突尼斯小贩自焚到六国秩序崩塌.md)（8.2 节"四个决定性变量"、10.1 节"不是'文明冲突'，是制度与军队结构"）形成**对照关系**——两者都说明：外部干预能否成功，取决于本地国家性、军队结构与教派/部落分裂，而不是外部力量的"文明属性"。

### 1.7 乘积而不是加总：为什么偏偏是 1095 年

把五件事放在一起，1095 年的"唯一性"才显出来：

| 条件 | 1095 年的状态 | 缺了它会怎样 |
| :--- | :--- | :--- |
| 朝圣传统 | 大众朝圣 + 苦修量化 + 圣墓崇拜 | 没有"武装朝圣"的道德语法 |
| 继承压力 | 长子继承扩散，幼子外溢 | 缺少愿意冒险的骑士供给 |
| 教皇授权 | 教皇革命后的教会法 + 和平运动 | 没有跨地域的合法性与组织者 |
| 海运资本 | 意大利海上共和国 + 贸易特权 | 没有运力、贷款与补给 |
| 伊斯兰分裂 | 塞尔柱内乱 + 法蒂玛对立 | 十字军无法以少胜多 |
| 拜占庭求援 | 阿莱克修斯需要雇佣兵 | 没有"援助东方兄弟"的正当理由 |

**为什么不是 1000 年？** 因为那时没有教皇革命后的教会法、没有成型的誓愿制度、没有意大利海运的资本规模。**为什么不是 1200 年？** 因为那时穆斯林世界已经被萨拉丁重新统一，教皇的"授权"也已被第四次十字军透支。1095 年是一个**窗口**：四台机器第一次同时转动，而东方的裂缝刚好开到最大。

**一句话收束：** 十字军不是"宗教狂热的爆发"，而是**朝圣、继承、教皇革命、海运四台机器，在伊斯兰分裂与拜占庭求援的窗口里第一次同时咬合**。理解这一点，才能理解它为什么能开始；也才能理解它为什么会在两百年里不断变形，却始终没有变成一台稳定的"国家军队"。

## 二、扳机：从克莱蒙到耶路撒冷（1095—1099）

### 2.1 克莱蒙：一场改革会议上的"外部任务"

1095 年 11 月，乌尔班二世在法国中部的克莱蒙召开会议。到会者约 300 名主教与修道院长，议题本来全是教会改革：买卖圣职、教士婚姻、上帝休战、教会财产。十字军是在会议最后一天（11 月 27 日）被加进议程的"外部任务"。

这个细节很重要：**十字军不是一次独立的"战争动员"，而是教皇革命的一次外溢。** 乌尔班二世当时甚至不在罗马——他正与神圣罗马帝国支持的对立教皇争夺教廷，需要法国教会与法国贵族的支持。把法国骑士的暴力引向东方，既解决了"和平运动"管不住的私战问题，也给他自己造了一个跨阿尔卑斯的政治舞台。

乌尔班说了什么，没有逐字记录。现存四五个编年史版本，彼此差异很大；最著名的"Deus vult"（上帝所愿）出自罗伯特修士 1106—1107 年左右的版本，很可能是事后的文学加工。可以确认的核心承诺是：**凡因虔诚而非虚荣而参加远征者，罪得赦免。** 没有土地承诺，没有军饷承诺，也没有"封王"承诺。

> 📌 **"Deus vult"（上帝所愿）**：十字军最著名的口号，出自罗伯特修士对克莱蒙演说的追述；它不是现场速记，而是事后建构的"集体欢呼"。在本文中的作用：它提醒我们，十字军的"大众动员"从一开始就依赖**记忆与复述**，而不是文件与命令。

> 🔗 **横向关联**：本节"教皇革命外溢为十字军"与 [犹太教、基督教、东正教与新教的发展历史](犹太教、基督教、东正教与新教的发展历史：三次分化与两千年谱系.md)（第三节"大公教会"）形成**上下游关系**——该笔记讲 800 年加冕、1075—1122 年叙任权之争如何把教皇变成西方秩序的独立一极；本文讲这一极如何第一次把"精神权威"兑换成"军事动员"。

### 2.2 人民十字军：大众动员的第一次失败

克莱蒙的消息比教皇的教令跑得快。1096 年春天，隐修士彼得（Peter the Hermit）与"无钱骑士"瓦尔特（Walter Sans Avoir）率领数万平民从莱茵兰出发，史称"人民十字军"。他们中有农民、手工业者、妇女、儿童，也有破产骑士与地方小贵族；估计 2 万—4 万人，没有统一指挥，没有补给计划。

这支队伍在莱茵兰沿途屠杀犹太社区（详见第八节），在匈牙利与巴尔干与当地人冲突，1096 年 8 月到达君士坦丁堡。阿莱克修斯一世迅速把他们送过博斯普鲁斯海峡；10 月，塞尔柱苏丹基利杰·阿尔斯兰在奇维托特（Civetot）几乎全歼他们。

人民十字军的失败说明两件事：**第一，十字军的动员能力可以绕过教皇，靠布道、传言与地方网络自发扩散；第二，没有封建领主的组织与意大利人的海运，大众动员只能变成屠杀与溃败。** 此后的十字军，组织权重新回到教皇、君主与领主手中。

> 📌 **人民十字军（People's Crusade）**：1096 年由彼得隐修士等人领导的平民远征，先于诸侯十字军出发，以莱茵兰屠杀与奇维托特覆灭告终。在本文中的作用：它是十字军"大众动员"的极端样本——证明宗教热情可以迅速聚集人，却不能自动生成后勤与指挥。

> 🔗 **横向关联**：本节"大众动员中的替罪羊机制"与 [自我、羡慕与神圣](../../人类学/自我、羡慕与神圣：可达性动力学、通约与共同体的耗散维护.md)（第十节"巫术与猎巫"、10.3 节"猎巫：五个结构条件"）形成**对照关系**——两者都是"危机 + 神圣使命 + 内部异类"的三元结构：十字军把犹太人当作"内部敌人"，猎巫把邻里妇女当作"内部敌人"；暴力都披着净化共同体的语言。

### 2.3 诸侯十字军：四支军队、三条路线、一个巧合

1096 年秋，真正的诸侯十字军出发。四支主力从不同路线汇合于君士坦丁堡：

| 军队 | 领袖 | 路线 | 关键节点 |
| :--- | :--- | :--- | :--- |
| 洛林军 | 布永的戈弗雷、布洛涅的鲍德温 | 经匈牙利、巴尔干 | 1097 年春到君士坦丁堡 |
| 诺曼军 | 塔兰托的博希蒙德、坦克雷德 | 经南意大利、巴尔干 | 最先入安条克 |
| 普罗旺斯军 | 图卢兹的雷蒙四世 | 经达尔马提亚、巴尔干 | 最富有，与拜占庭关系最紧张 |
| 北法军 | 诺曼底的罗贝尔二世、布洛瓦的斯蒂芬、佛兰德的罗贝尔二世 | 经意大利、亚得里亚海 | 1097 年春到，随后同行 |

阿莱克修斯一世要求所有领袖向他宣誓效忠，并承诺把收复的原拜占庭领土交还帝国。大多数人照做了；博希蒙德要的是安条克，雷蒙四世要的是独立行动权，双方从一开始就同床异梦。

1097 年 6 月，十字军围攻尼西亚。城市在即将陷落时向拜占庭投降，十字军被禁止入城劫掠——这是拉丁人与拜占庭的第一道裂痕。7 月 1 日，多里莱乌姆战役，十字军击退基利杰·阿尔斯兰的伏击，穿越安纳托利亚。鲍德温脱离主力，南下夺取埃德萨，建立了第一个十字军国家。

**"一个巧合"** 指的是：如果尼西亚没有投降、如果多里莱乌姆的伏击更成功、如果鲍德温没有去埃德萨，第一次十字军的路线与结局都会不同。历史学家后来把这一连串"偶然"解释为"神意"，但当时的参与者更清楚：他们是在饥饿、缺水、内讧与不确定中一步步走过来的。

### 2.4 安条克：八个月围城与三天逆转

安条克是叙利亚北部的重镇，城墙绵延数公里，地势险要。1097 年 10 月，十字军开始围城；八个月里，饥饿、疾病、逃亡与内讧几乎瓦解了这支军队。彼得的追随者试图逃跑，布洛瓦的斯蒂芬以"病重"为由撤回欧洲，雷蒙与博希蒙德为"谁占有安条克"吵到几乎兵变。

1098 年 6 月 3 日，博希蒙德收买了一名守城军官，十字军夜袭入城。但几天后，摩苏尔总督克尔波加率援军赶到，把十字军反困在城里。饥饿、恐惧与"圣枪"的发现（一名修士声称在圣彼得教堂挖出了刺穿基督肋旁的枪头）把士气推到宗教狂热的高度。6 月 28 日，十字军出城决战，竟以少胜多击溃克尔波加。

> 📌 **圣枪（Holy Lance）**：传说中刺穿耶稣肋旁的枪头；1098 年在安条克被"发现"，成为十字军解围的精神支柱。在本文中的作用：它是"神圣物证"的典型——在极端不确定中，一个可触摸的圣物比一份战略计划更能维持军队。

安条克的归属问题没有解决：博希蒙德自称安条克亲王，拒绝把城市交给拜占庭；雷蒙四世愤而南下。**第一次十字军最大的军事胜利，同时也是拉丁人与拜占庭、拉丁人与拉丁人之间裂痕的放大镜。**

1098 年 12 月，十字军在马拉（Ma'arra）屠城，有编年史指控他们吃尸体。这类记载有恐怖修辞的成分，但它至少说明：**远征军在极端饥饿中已经失去了"朝圣者"的自我形象。**

### 2.5 耶路撒冷：1099 年 7 月 15 日

1099 年 6 月，十字军抵达耶路撒冷。此时城里是法蒂玛王朝的守军；埃及援军正在路上。十字军没有攻城器械，缺水，缺粮，人数不足；他们用木头搭塔、用船只残骸做梯子，7 月 15 日破城。

接下来发生的是中世纪最著名的大屠杀之一。拉丁编年史称血流到马嚼子深——这句话直接借自《启示录》14:20 的末日意象，是文学修辞，不一定是现场测量。死亡人数从 3,000 到 70,000 的说法都有；现代研究多倾向于"数千人"，但无法确定。可以确定的是：**城破之后，穆斯林与犹太人被大规模屠杀，幸存者被卖为奴，圣殿区（今阿克萨清真寺一带）成了尸堆。**

> 📌 **真十字架（True Cross）**：传说中钉死耶稣的十字架，被十字军视为最神圣的战利品；1187 年哈丁战役中被萨拉丁缴获。在本文中的作用：它把"战争"变成"圣物的争夺"，也让十字军的失败具有"神圣被夺走"的创伤意义。

> 📌 **法兰克人（Franks）**：穆斯林与拜占庭人对西欧十字军的统称（阿拉伯语 *Ifranj*）；它不是一个民族概念，而是"拉丁基督教侵略者"的集合标签。在本文中的作用：这个标签掩盖了十字军内部的地区、语言与利益差异，也埋下了"西方 vs 伊斯兰"简化叙事的种子。

戈弗雷没有称王，而是自称"圣墓守护者"（Advocate of the Holy Sepulchre）；1100 年他死后，其弟鲍德温一世加冕为耶路撒冷国王。**"王国"是事后补上的：第一次十字军的目标是朝圣，不是建国；国家是朝圣者留下来之后才长出来的。**

> 🔗 **横向关联**：本节"启示录修辞把屠杀写成神圣"与 [世界上的所有末世神学](../政治入门/世界上的所有末世神学.md)（第二节"末世神学转向"）形成**互证关系**——该笔记讲末世论如何把历史事件读成"末日剧本"；本文给出一个更早的样本：1099 年的十字军把攻城战读成《启示录》的应验，从而把屠杀合法化为"神圣净化"。

### 2.6 阿斯卡隆与 1101：成功为什么不可复制

1099 年 8 月 12 日，十字军在阿斯卡隆击败埃及援军，但没有攻城——戈弗雷与雷蒙为"谁当国王"争吵，错失时机。阿斯卡隆直到 1153 年才被耶路撒冷王国攻下。

1101 年，欧洲又派出三支十字军，试图复制 1096 年的成功。三支军队在安纳托利亚被塞尔柱人各个击破，几乎全军覆没。**这说明第一次十字军的成功是"窗口 + 运气 + 士气"的乘积，而不是一套已经成型的制度。** 制度要到 12 世纪才长出来：誓愿的法律化、军事修会、意大利海运合同、教皇的十字军税。

> 🔗 **横向关联**：本节"第一次十字军无法复制"与 [西欧四次大一统尝试](../经济理论/资本与政体比较/西欧四次大一统尝试：帝国标准化、失败机制与多中心秩序.md)（6.3 节"为什么外部均势持续阻止大陆霸权"）形成**对照关系**——欧洲的多中心秩序使十字军只能是"联盟式远征"，而不是"帝国工程"；联盟能赢一次，却很难连续赢，因为每一次胜利都会立刻引发分赃冲突。

## 三、机器：十字军如何被组织起来（誓愿、钱、船、法）

### 3.1 誓愿：一种可执行的法律身份

十字军最容易被忽略的制度，是"誓愿"（vow）。参加者不是"士兵"，而是"立誓者"（*crucesignatus*）：他在教会面前发誓前往圣地，教会则给他一套法律身份与保护。

这套身份至少有四种可执行的效果：

| 效果 | 内容 | 谁受益 |
| :--- | :--- | :--- |
| 财产保护 | 教会代管十字军参加者的地产，并保护其家属，禁止侵占 | 出征的领主、骑士 |
| 债务延期 | 十字军参加者的债务可以延期，利息暂停 | 负债的骑士、小贵族 |
| 司法特权 | 十字军参加者的案件归教会法庭管辖 | 想摆脱领主法庭的人 |
| 违约惩罚 | 不履行誓愿者可能被绝罚，或被强制补赎 | 教会（维持动员） |

**这把"宗教热情"变成了"可执行合同"。** 一个骑士可以因为"我已经立誓"而获得财产保护、债务喘息与司法豁免；教会可以因为"你已立誓"而对他施加惩罚。双方都有可执行的筹码——这就是十字军能反复组织起来的法律基础。

> 📌 **十字军誓愿（Crusade Vow）**：参加十字军者在教会面前作出的、具有法律约束力的誓言；它带来赦罪、保护与特权，也带来违约惩罚。在本文中的作用：它是十字军制度的"芯片"——没有誓愿，十字军就只是一次布道；有了誓愿，它才成为可执行、可继承、可替代（以钱代誓）的制度。

> 🔗 **横向关联**：本节"誓愿把宗教义务变成可执行合同"与 [早期近代欧洲的五重转型](../../人类学/早期近代欧洲的五重转型：文艺复兴、宗教改革、价格革命、圈地运动与科学革命（1450-1700）.md)（4.1 节"神学争论下面是三张账"）形成**上游—下游关系**——该笔记讲宗教改革背后的土地、现金流与解释权三张账；本文讲十字军如何第一次把"解释权"变成可兑现的"誓愿—赦罪"合约。

### 3.2 钱：谁付账，谁垫资

十字军不是由国家财政供养的军队。它是一群**自己筹钱的债务人**。

一个骑士的账单包括：战马（至少两匹，一匹战马、一匹坐骑）、盔甲、武器、随从、粮食、运输、过路费、赎金。赖利-史密斯估计，一名骑士参加十字军的开销约为其年收入的 4—5 倍；男爵与国王的规模更大。筹钱的方式主要有五种：

| 工具 | 谁用 | 成本/风险 |
| :--- | :--- | :--- |
| 卖地/抵押地产 | 领主、骑士 | 失去家族根基；利息高 |
| 向犹太人/伦巴第人借款 | 中小贵族、君主 | 高利贷禁令与政治风险 |
| 教会税（什一税、十字军税） | 教皇、君主 | 需要教会与世俗当局合作 |
| 以钱代誓（vow redemption） | 不能出征者 | 把"参战"变成"付费" |
| 意大利银行/圣殿骑士垫资 | 君主、大领主 | 以关税、领地收入作抵押 |

> 📌 **什一税（Tithe）**：教会按收入或土地产出征收的十分之一税；十字军时期被扩展为"十字军什一税"，用于资助远征。在本文中的作用：它是"战争财政"的雏形——把一次性的宗教热情，转化为可评估、可征收、可重复的税基。

> 📌 **盾牌钱（Scutage）**：封臣以现金代替军事服役的支付；君主用这笔钱雇佣军队。在本文中的作用：它标志着封建军事义务的货币化——十字军时代正是"以钱代役"迅速扩张的时期。

> 🔗 **横向关联**：本节"打仗要现金，税收来得慢"与 [资本市场的形成](../资本与人/资本市场的形成：从债务、集市、商行到制度化资本主义的权力史.md)（6.1 节"战争财政：打仗要现金，税收来得慢"）形成**互证关系**——该笔记把战争财政当作资本市场形成的长期动力；本文给出一个更早的样本：十字军是"战争财政"第一次跨欧亚的大规模实验。

### 3.3 船：意大利城邦的运输合同

把一支军队从西欧运到黎凡特，需要三种东西：船、钱、港口。意大利城邦三者都有。

威尼斯、热那亚、比萨与阿马尔菲在 11 世纪已经建立了地中海航运网络；它们用康曼达（commenda）与海上贷款分散风险，用领事馆与商馆（fondaco）管理异地贸易，用海军保护航线。十字军到来时，它们立刻发现了一门新生意：**运送十字军**。

第四次十字军把这条生意链推到了极端：

| 环节 | 内容 | 后果 |
| :--- | :--- | :--- |
| 1201 合同 | 威尼斯承诺运送 33,500 人与 4,500 马，费用 85,000 马克 | 威尼斯的全部商业运力被锁定一年 |
| 1202 到货 | 实际到场约 12,000 人，筹款约 51,000 马克 | 短缺约 34,000 马克 |
| 抵债 | 威尼斯要求十字军攻打扎拉（Zara）抵债 | 十字军第一次攻打天主教城市 |
| 加码 | 拜占庭流亡皇子阿莱克修斯四世承诺 20 万马克 | 十字军转向君士坦丁堡 |
| 1204 | 君士坦丁堡被洗劫，拉丁帝国建立 | 债务链彻底改写了战争目标 |

> 📌 **渡海远征（Passagium）**：中世纪拉丁语对"跨海远征"的称呼，通常指十字军前往黎凡特的航程；后来也指每年定期的运输船队。在本文中的作用：它把十字军从"一场战争"变成"一个航线"——有季节、有港口、有运费、有保险。

**债务链一旦形成，战争目标就被债权人改写。** 第四次十字军不是"意外偏离"，而是"合同违约 + 抵债 + 加码"的连锁反应。威尼斯不是"欺骗"了十字军；它只是按照合同收债，而十字军没有别的还债方式。

> 🔗 **横向关联**：本节"运输合同 + 特许权"与 [商业革命编年史](../../人类学/商业革命编年史：白银、股份公司与第一次全球化（1500-1750）.md)（2.1 节"VOC：第一家真正的公司"）形成**对照关系**——VOC 用"股份 + 特许状"组织远洋贸易，十字军东征用"誓愿 + 赦罪 + 运费合同"组织远洋战争；两者都是"把高风险事业拆成可投资份额"的技术，只是前者的回报是利润，后者的回报是赦罪与领地。

### 3.4 法：正义战争与"授权暴力"

十字军需要一套法理，把"基督徒杀人"变成"合法且神圣"的行为。这套法理由三层构成：

1. **奥古斯丁的正义战争**：正当权威、正当理由、正当意图、最后手段、相称性。
2. **格拉提安与教会法**：12 世纪的《教令集》把正义战争的条件系统化，并区分"私战"与"公战"。
3. **教皇的授权**：只有教皇（或皇帝）能宣布"公战"；十字军因此不是"私斗"，而是"为教会而战"。

> 📌 **两把剑（Two Swords）**：中世纪政治神学的核心比喻：教会掌握"精神之剑"，君主掌握"世俗之剑"；两把剑都来自上帝，但教会对世俗之剑有"指导权"。在本文中的作用：它解释了教皇为什么能"授权"战争而不必亲自统帅军队——教皇交出"剑"，但保留"授权剑"的权力。

> 📌 **教会法（Canon Law）**：教会自己的法律体系，12 世纪由格拉提安《教令集》系统化，涵盖婚姻、财产、誓愿、战争、异端与司法程序。在本文中的作用：它是十字军"制度化"的骨架——誓愿、赦罪、特权、绝罚、征税，全部需要教会法提供程序。

| 战争类型 | 授权者 | 参与者 | 目的 | 十字军的位置 |
| :--- | :--- | :--- | :--- | :--- |
| 私战（private war） | 领主自己 | 封臣、雇佣兵 | 领地、荣誉、复仇 | 被教会禁止 |
| 公战（public war） | 君主/皇帝 | 臣民 | 防御、收复失地 | 被教会认可 |
| 圣战（holy war） | 教皇 | 立誓者 | 解放圣地、赦罪 | 十字军的自我定位 |

**十字军最持久的发明不是战术，而是"把暴力包装成法律"的技术。** 它把"杀人"拆成"授权—理由—意图—程序"四个要件，只要四个要件齐全，暴力就可以被写成"正义"。

> 🔗 **横向关联**：本节"法律化暴力"与 [马克斯·韦伯的社会学理论](../社会学研究/马克斯·韦伯的社会学理论.md)（第四节"理性化与祛魅"）形成**对照关系**——韦伯讲现代国家如何垄断"合法暴力"；本文讲中世纪教会如何在没有国家的情况下，用教会法与赦罪"授权"暴力。两者都是"合法性的生产"，但一个靠官僚制，一个靠圣礼与誓愿。

### 3.5 组织：三大军事修会

十字军最成功的"组织创新"是军事修会：把修士的纪律、骑士的武力与商人的记账能力，装进同一个法人团体。

| 修会 | 成立 | 主要基地 | 军事角色 | 金融角色 | 结局 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 圣殿骑士团 | 约 1119 年，1129 年特鲁瓦会议认可 | 耶路撒冷、阿卡、巴黎 | 重装骑兵、城堡驻军 | 存款、异地支付、王室财政 | 1307 年被捕，1312 年解散 |
| 医院骑士团 | 约 1048/1080 年，1120 年代军事化 | 耶路撒冷、罗德岛、马耳他 | 城堡防御、海军 | 地产、募捐 | 1530 年迁马耳他，1798 年结束 |
| 条顿骑士团 | 1190 年阿卡，1198 年军事化 | 阿卡、普鲁士 | 北方十字军主力 | 地产、贸易 | 1525 年世俗化为普鲁士公国 |

> 📌 **军事修会（Military Order）**：以修道誓愿（贫穷、贞洁、服从）为基础、以武装战斗为使命的宗教团体；成员既是修士又是骑士，受教皇直接管辖。在本文中的作用：它是十字军制度最成功的"出口产品"——把"神圣暴力"组织成可复制、可募捐、可继承的法人。

圣殿骑士团的金融角色尤其值得注意：它为朝圣者提供存款与异地支付安排（常被比作"旅行支票"，但不要按现代银行制度想象），为法国王室管理财政，巴黎的圣殿总部实际上成了王国的金库。1307 年，法王腓力四世以"异端"罪名逮捕全法圣殿骑士；1312 年教皇克雷芒五世解散修会；1314 年最后一任大团长雅克·德·莫莱被烧死。**十字军财政的"银行家"，最后成了王权债务的替罪羊。**

> 🔗 **横向关联**：本节"圣殿骑士的异地支付"与 [资本市场的形成](../资本与人/资本市场的形成：从债务、集市、商行到制度化资本主义的权力史.md)（10.1 节"发明时间线"）形成**上下游关系**——该笔记把汇票、保险、合伙等工具列成一条"金融发明时间线"；本文指出十字军是这些工具的**第一个跨国大客户**：朝圣者要汇款，国王要借钱，修会要记账。

### 3.6 复制：从"目的地"到"模板"

12 世纪中叶以后，十字军开始脱离"耶路撒冷"这个目的地，变成一种**可复制的法律形式**。标志有三：

1. **以钱代誓**：1213 年英诺森三世《Quia maior》允许不能出征者以捐款替代誓愿；十字军从"人的远征"变成"钱的远征"。
2. **十字军税**：1188 年"萨拉丁什一税"、1215 年第四次拉特兰会议对教士收入征收 1/20、此后历任教皇的十字军税，把远征变成常规财政。
3. **政治十字军**：教皇把十字军授权用于西西里、阿拉贡、胡斯派等政治对手；"十字军"从"对异教徒的战争"扩展为"对教皇敌人的战争"。

| 模板要素 | 1095 年 | 1300 年 |
| :--- | :--- | :--- |
| 授权者 | 教皇 | 教皇（更频繁、更政治化） |
| 参与者 | 自愿立誓的骑士 | 立誓者、代誓者、职业军队 |
| 资金 | 自筹 + 战利品 | 教会税 + 借款 + 以钱代誓 |
| 运输 | 意大利城邦 | 意大利城邦 + 王室船队 |
| 目的 | 耶路撒冷 | 耶路撒冷、伊比利亚、波罗的海、法国南部、意大利 |

**十字军的成功在于可复制，失败也在于可复制。** 每复制一次，目标就模糊一分，教皇的信誉就透支一分；到 14—15 世纪，"十字军"已经变成一种可以卖给任何人的"赎罪产品"——这正是 1517 年路德要攻击的东西。

> 🔗 **横向关联**：本节"以钱代誓 → 十字军税 → 赎罪券"与 [马丁·路德与宗教改革](马丁·路德与宗教改革：从赎罪券到威斯特伐利亚（1517—1648）.md)（第二节"引爆"）形成**上下游关系**——本文交代赎罪券的"前世"：它原本是十字军誓愿的替代品；该笔记交代它的"今生"：当它被用来为圣彼得大教堂筹款时，终于引爆了宗教改革。

## 四、移植：拉丁东方及其制度（1099—1291）

### 4.1 四个国家：地图与名分

第一次十字军之后，拉丁人在黎凡特建立了四个国家：

| 国家 | 建立 | 统治者 | 结局 |
| :--- | :--- | :--- | :--- |
| 耶路撒冷王国 | 1099 | 戈弗雷（守护者）→ 鲍德温一世（国王） | 1291 年阿卡陷落 |
| 安条克公国 | 1098 | 博希蒙德一世 | 1268 年被马穆鲁克攻陷 |
| 埃德萨伯国 | 1098 | 鲍德温一世 | 1144 年被赞吉攻陷 |
| 的黎波里伯国 | 1102 | 雷蒙四世奠基 | 1289 年被马穆鲁克攻陷 |

> 📌 **拉丁东方（Outremer）**：法语"海外之地"，指十字军在黎凡特建立的四个国家及其社会；它不是统一的殖民帝国，而是四个各自为政、互相竞争、又共享"法兰克人"身份的封建政体。在本文中的作用：它是"西欧多中心秩序"的海外投影——王权弱、领主强、城市自治、教会独立。

> 🔗 **横向关联**：本节"四个国家各自为政"与 [西欧四次大一统尝试](../经济理论/资本与政体比较/西欧四次大一统尝试：帝国标准化、失败机制与多中心秩序.md)（第四节"神圣罗马帝国：名义统一的反例"）形成**对照关系**——神圣罗马帝国是"名义统一、实际多中心"；拉丁东方是"没有名义统一、只有多中心"。两者都证明：西欧的政治默认设置不是帝国，而是权利重叠。

### 4.2 封建移植：国王是"选举的"，不是"绝对的"

耶路撒冷王国的王权比西欧大多数王国都弱。国王由高等法院（Haute Cour）的领主们选举产生；没有高等法院同意，国王不能征税、不能宣战、不能没收封地。王国内部还有意大利城邦的自治街区、教会领地、军事修会的独立城堡，以及本地叙利亚基督徒与穆斯林社区的法律惯例。

| 权力主体 | 主要权限 | 制衡者 |
| :--- | :--- | :--- |
| 国王 | 军事指挥、外交、封授 | 高等法院、教会、军事修会 |
| 高等法院 | 立法、司法、选举国王 | 大领主 |
| 领主 | 领地司法、征税、服役 | 国王、教会 |
| 意大利公社 | 港口贸易、自治街区 | 国王（特许权） |
| 教会 | 宗教事务、地产、法庭 | 教皇使节 |

> 📌 **耶路撒冷法令（Assises de Jérusalem）**：13 世纪编纂的耶路撒冷王国法律汇编，混合了封建习惯法、教会法与城市惯例；它后来成为"拉丁东方"法律传统的象征。在本文中的作用：它证明十字军国家不是"无政府的掠夺者"，而是一个有法律、有法庭、有权利话语的封建社会。

> 📌 **公社（Commune）**：中世纪城市以誓约为基础形成的自治共同体，拥有自己的法庭、税收与民兵；在十字军国家，意大利商人的公社往往位于港口城市，享有特许权。在本文中的作用：它是"多中心秩序"的第三极——国王、领主、教会之外的商业自治力量。

> 🔗 **横向关联**：本节"权利重叠"与 [中国与西欧历史社会结构差异](../经济理论/资本与政体比较/中国与西欧历史社会结构差异：官僚帝国、多中心秩序与阶级形成.md)（三.1 节"西欧产权是'权利束'，城市自由来自政治交易"）形成**互证关系**——该笔记把西欧产权解释为"多主体权利束"；本文给出一个海外样本：在阿卡，同一块土地可能同时属于国王、领主、教会与威尼斯公社。

### 4.3 人口：少数统治多数

十字军国家的人口结构，是理解"拉丁东方"的关键：**法兰克人是少数，穆斯林与东方基督徒是多数。**

| 群体 | 估计比例 | 法律地位 | 实际处境 |
| :--- | :--- | :--- | :--- |
| 拉丁人（法兰克人） | 少数（估计数万至十余万） | 统治者、封臣、市民 | 沿海城市占比较高，内陆农村较少 |
| 东方基督徒（希腊、亚美尼亚、叙利亚、科普特） | 多数之一 | 被容忍的"异端"/纳税者 | 保留部分教堂与社区，部分被拉丁化 |
| 穆斯林 | 多数之一 | 被征服的农民/纳税者 | 农村主体，城市少数 |
| 犹太人 | 少数 | 受保护/受歧视 | 贸易、手工业、借贷 |
| 意大利商人 | 少数 | 特许权/自治 | 港口街区，政治影响力大 |

> 📌 **普兰人（Poulains）**：十字军国家出生的拉丁人后裔，常混有本地血统，说阿拉伯语、穿本地服装，被新来的欧洲人视为"软弱化"的东方人。在本文中的作用：它说明"法兰克人"不是一个纯粹的族群，而是一个在本地化的统治阶层——文化边界比宗教边界更模糊。

> 🔗 **横向关联**：本节"拉丁人依赖本地商人网络"与 [资本市场的形成](../资本与人/资本市场的形成：从债务、集市、商行到制度化资本主义的权力史.md)（三.2 节"阿拉伯与犹太商人：靠社群信誉的远程网络"）形成**对照关系**——十字军国家名义上由拉丁人统治，实际贸易却依赖穆斯林、犹太人与东方基督徒的社群网络；"统治"与"做生意"是两套不同的能力。

### 4.4 经济：糖、棉、玻璃与港口

十字军国家不是"纯粹的军事占领区"，而是地中海贸易的"转口站"。阿卡、提尔、贝鲁特、的黎波里都是繁忙的港口；蔗糖、棉花、玻璃、肥皂、橄榄油、香料与奴隶从这里流向欧洲，欧洲的羊毛、金属、武器与朝圣者从这里流向东方。

| 商品 | 产地/集散地 | 市场 | 制度支撑 |
| :--- | :--- | :--- | :--- |
| 蔗糖 | 黎凡特沿海庄园 | 欧洲、埃及 | 封建庄园 + 意大利资本 |
| 棉花 | 叙利亚内陆 | 意大利、佛兰德 | 本地农民 + 商人预付款 |
| 玻璃/肥皂 | 提尔、阿卡 | 地中海 | 手工业行会 |
| 香料 | 印度洋—红海—黎凡特 | 欧洲 | 穆斯林商人网络 |
| 奴隶 | 黑海、巴尔干、非洲 | 埃及、意大利 | 港口市场 + 教会禁令的漏洞 |

> 📌 **商馆（Fondaco）**：意大利商人在海外港口设立的仓储—住宿—交易综合体，享有自治与免税特权；它是"殖民据点"的商业版本。在本文中的作用：它把"十字军国家"变成意大利城邦的"海外开发区"——城邦不统治这里，却在这里赚钱。

**1256—1258 年的"圣萨巴战争"** 是这种结构的极端表现：威尼斯与热那亚为了阿卡的圣萨巴修道院控制权，爆发了一场城市内战，双方动用舰队、雇佣兵与本地领主，把十字军国家最后的首都变成了商业战场。**当宗教使命衰退时，商业竞争就接管了战争。**

> 🔗 **横向关联**：本节"港口 + 商馆 + 特许权"与 [商业革命编年史](../../人类学/商业革命编年史：白银、股份公司与第一次全球化（1500-1750）.md)（5.1 节"增长的天花板"）形成**上下游关系**——该笔记讲 18 世纪商业革命为何撞上增长天花板；本文讲它的"前史"：十字军国家已经演示了"贸易据点 + 特许权 + 武装护航"的模式，只是规模还不足以突破农业帝国的天花板。

### 4.5 宗教：粗糙的宽容

"十字军国家"听起来像宗教战争的前线，但日常生活比口号复杂。历史学家麦克维特（Christopher MacEvitt）用"粗糙的宽容"（rough tolerance）来描述拉丁人与东方基督徒的关系：没有系统的宗教宽容理论，却有大量实际的共存安排——共享教堂、共同纳税、互相雇佣、偶尔通婚。

> 📌 **粗糙的宽容（Rough Tolerance）**：麦克维特提出的概念，指十字军国家中拉丁人与东方基督徒之间缺乏理论依据、却在实践中形成的共存模式；它不是现代意义上的宽容，而是"懒得区分"与"需要合作"的混合物。在本文中的作用：它纠正了"十字军国家 = 宗教隔离"的刻板印象，同时不美化其压迫性。

> 🔗 **横向关联**：本节"拉丁人与东方基督徒的共存"与 [犹太教、基督教、东正教与新教的发展历史](犹太教、基督教、东正教与新教的发展历史：三次分化与两千年谱系.md)（第四节"1054 年：第二次分化"）形成**对照关系**——该笔记讲 1054 年与 1204 年如何把"分裂"变成"记忆"；本文讲在黎凡特的日常生活中，分裂的边界如何被利益与习惯磨钝。**制度上的分裂是硬的，生活里的边界是软的。**

### 4.6 军事：城堡链与驻军经济

十字军国家的军事体系，核心不是野战，而是**城堡**。从北方的克拉克骑士堡（Krak des Chevaliers）到南方的卡拉克（Kerak），从沿海的阿特利特（Atlit）到内陆的贝尔沃（Belvoir），拉丁人修建了一条"城堡链"，用驻军控制道路、水源与农业区。

| 城堡 | 建造者 | 功能 | 结局 |
| :--- | :--- | :--- | :--- |
| 克拉克骑士堡 | 医院骑士团 | 控制霍姆斯缺口 | 1271 年被拜巴尔斯攻陷 |
| 卡拉克 | 耶路撒冷王国/沙蒂永 | 控制约旦河以东商路 | 1188 年被萨拉丁攻陷 |
| 贝尔沃 | 医院骑士团 | 监视约旦河谷 | 1189 年陷落 |
| 阿特利特 | 圣殿骑士团 | 海防与朝圣者接待 | 1291 年撤离 |

> 📌 **城堡链（Castle Chain）**：十字军国家以一系列城堡控制交通线、水源与农业区的防御体系；城堡既是军事据点，也是行政中心、税收站与朝圣者客栈。在本文中的作用：它说明十字军的"军事"本质是**驻军经济**——城堡越多，财政越重；财政越重，越依赖意大利商人与西方捐助。

**城堡是"封建暴力的凝固形式"：它把机动战争变成驻军战争，也把财政变成无底洞。** 马穆鲁克后来对付城堡的办法很直接：不打野战，逐个围攻，拔掉一个就拆毁一个。1291 年之后，沿海城堡被系统性地拆除，以防十字军再次登陆。

### 4.7 脆弱性：为什么 1291 年守不住

拉丁东方的失败，常被写成"道德腐败"或"宗教热情衰退"。更准确的说法是：**它没有国家，只有一套权利重叠的封建网络；而它的对手，是一个正在国家化的马穆鲁克苏丹国。**

| 维度 | 十字军国家 | 马穆鲁克 |
| :--- | :--- | :--- |
| 军队 | 封建征召 + 朝圣者 + 雇佣兵 | 常备奴隶军 + 伊克塔 |
| 财政 | 关税 + 农业 + 西方捐助 | 土地税 + 贸易 + 战利品 |
| 指挥 | 国王/摄政/诸侯会议 | 苏丹集权 |
| 后勤 | 依赖意大利海运 | 依赖尼罗河与内陆 |
| 人力补充 | 依赖欧洲 | 依赖高加索奴隶贸易 |

> 📌 **伊克塔（Iqta）**：伊斯兰世界的军事采邑制度：苏丹把土地的收入权授予军官，以换取军事服务；它与西欧封地相似，但更强调税收权而非司法权。在本文中的作用：它让马穆鲁克拥有稳定的军官阶层与骑兵补给，是"国家军队"对"封建网络"的制度优势。

> 🔗 **横向关联**：本节"马穆鲁克的常备军 vs 十字军的封建网络"与 [农业帝国编年史](../../人类学/农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）.md)（5.1 节"奥斯曼帝国：Devshirme 儿童血税与 Timar 军事采邑"）形成**上下游关系**——该笔记讲奥斯曼如何用"儿童血税 + 军事采邑"建立中央军；本文讲它的前辈马穆鲁克如何用"奴隶军 + 伊克塔"拔掉十字军国家。**三个世纪的答案是一样的：能收税、能养常备军的一方，战胜了靠封建征召的一方。**

## 五、反攻：从赞吉到萨拉丁（1144—1193）

### 5.1 为什么 1099—1144 没有"圣战"

1099 年耶路撒冷陷落后，穆斯林世界并没有立刻发动"圣战"。原因不是"不关心"，而是**没有国家能组织起来**。

| 时间 | 政治格局 | 为什么没有统一回应 |
| :--- | :--- | :--- |
| 1099—1127 | 塞尔柱诸子内乱；叙利亚地方埃米尔 | 没有能同时动员伊拉克与叙利亚的强人 |
| 1127—1146 | 赞吉在摩苏尔崛起 | 先把资源用于巩固内部 |
| 1146—1174 | 努尔丁统一叙利亚 | 与法蒂玛埃及对抗，先取埃及 |
| 1174—1187 | 萨拉丁统一埃及与叙利亚 | 终于具备对十字军的总动员能力 |

> 📌 **埃米尔（Emir）**：阿拉伯语"指挥官/王子"，指地方军事首领或省区统治者；在塞尔柱与阿尤布体系中，埃米尔是实际的军政单位。在本文中的作用：它解释了伊斯兰世界为什么"碎片化"——每个埃米尔都有自己的税基、军队与外交，苏丹只是他们的盟主。

> 📌 **苏丹（Sultan）**：阿拉伯语"权威/统治者"，11 世纪后指掌握实际军政权力的统治者（如塞尔柱苏丹、阿尤布苏丹、马穆鲁克苏丹）；哈里发则保留名义上的宗教权威。在本文中的作用：它揭示了伊斯兰世界的"双头结构"——哈里发给合法性，苏丹给军队与税收；两者分离时，动员能力就弱。

> 📌 **哈里发（Caliph）**：先知穆罕默德的继承者，名义上的伊斯兰共同体领袖；阿拔斯哈里发在 1258 年蒙古陷巴格达后失去政治意义。在本文中的作用：它说明"圣战"的号召需要宗教权威，但执行需要世俗军队；两者不重合时，号召就落空。

> 📌 **逊尼/什叶（Sunni / Shia）**：伊斯兰教两大支派；逊尼派承认前四任哈里发，什叶派认为阿里及其后裔是合法继承者。在本文中的作用：11—12 世纪逊尼派塞尔柱与什叶派法蒂玛的对立，是十字军能够利用的"窗口"；萨拉丁废除法蒂玛、恢复逊尼派，是他"统一"的关键一步。

> 🔗 **横向关联**：本节"没有国家就没有圣战"与 [阿拉伯之春](../国家/中东/阿拉伯之春：从突尼斯小贩自焚到六国秩序崩塌.md)（9.2 节"教派化与极端主义"）形成**对照关系**——两者都说明：宗教动员不是"文化本能"，而是政治机会结构的产物；当国家崩溃、教派标签被政治企业家利用时，暴力就会以"信仰"的名义组织起来。

### 5.2 赞吉与努尔丁：把圣战做成国家工程

1144 年，摩苏尔总督赞吉（Zengi）攻陷埃德萨伯国——这是十字军国家第一次被拔除。赞吉不是"虔诚的圣战者"：他早年与十字军有过合作，也与其他穆斯林领主作战；但他在埃德萨的胜利，让他发现"圣战"是一种极好的合法性资源。

1146 年赞吉被刺杀，其子努尔丁（Nur al-Din）继承事业。努尔丁把"圣战"从一次性动员变成一套国家工程：

- **宗教合法性**：资助逊尼派学校（madrasa）、苏菲道堂、清真寺，把自己塑造成"圣战的守护者"。
- **行政统一**：用伊克塔制度整合叙利亚的埃米尔，建立可征税、可征兵的官僚体系。
- **宣传机器**：宫廷诗人与法学家把努尔丁写成"第二个欧麦尔"，把十字军写成"必须清除的污点"。
- **战略耐心**：先取大马士革，再取埃及，最后才与十字军决战。

> 📌 **圣战（Jihad）**：阿拉伯语"奋斗/努力"，在伊斯兰法中指为宗教事业而奋斗，包括内心的修行（"大圣战"）与武装斗争（"小圣战"）；武装圣战需要合法权威、正当理由与正确程序。在本文中的作用：它不是一个"天生暴力"的概念，而是一套可以被国家征用的法律—宗教资源；赞吉、努尔丁与萨拉丁做的，正是把它"国家化"。

| 统治者 | 基地 | 合法性来源 | 核心战略 | 结果 |
| :--- | :--- | :--- | :--- | :--- |
| 赞吉 | 摩苏尔 | 军事胜利 + 逊尼派支持 | 夺取埃德萨，震慑十字军 | 1144 年拔除埃德萨，1146 年被刺 |
| 努尔丁 | 阿勒颇/大马士革 | 圣战宣传 + 宗教赞助 | 统一叙利亚，介入埃及 | 为萨拉丁铺路 |
| 萨拉丁 | 埃及/大马士革 | 圣战 + 逊尼派复兴 | 统一埃及与叙利亚，决战哈丁 | 1187 年收复耶路撒冷 |

**圣战是被"国家建设"召唤出来的，不是反过来。** 努尔丁先有税基、军队与官僚，才有能力谈"圣战"；没有这些，圣战只是一次劫掠。

### 5.3 萨拉丁：一个库尔德人的"统一"

萨拉丁（Saladin，1137/38—1193）出生于提克里特，库尔德人家庭，早年在努尔丁麾下服役。他的崛起路径，是一部"统一税基"的历史：

| 时间 | 步骤 | 意义 |
| :--- | :--- | :--- |
| 1169 | 成为埃及维齐尔 | 取得埃及的税基与粮食 |
| 1171 | 废除法蒂玛哈里发 | 恢复逊尼派合法性 |
| 1174 | 进入大马士革 | 取得叙利亚基地 |
| 1183 | 取得阿勒颇 | 控制北部 |
| 1186 | 取得摩苏尔 | 几乎统一"新月地带" |
| 1187 | 哈丁战役 | 军事兑现 |

> 📌 **维齐尔（Vizier）**：伊斯兰国家的首相/行政长官，掌握财政与行政实权；在法蒂玛埃及，维齐尔往往是实际的统治者。在本文中的作用：萨拉丁从维齐尔起步，说明他的权力基础是**行政与财政**，而不是单纯的军事卡里斯玛。

萨拉丁的"圣战"有很强的政治计算：他先打穆斯林对手（埃及、叙利亚、摩苏尔），再打十字军；他用"圣战"合法性掩盖对同教的征服，又用对十字军的胜利巩固对同教的统治。**这不降低他的历史地位，反而说明他是一个成功的国家建造者。**

> 🔗 **横向关联**：本节"萨拉丁用行政与财政统一，再用圣战合法化"与 [马克斯·韦伯的社会学理论](../社会学研究/马克斯·韦伯的社会学理论.md)（第四节"理性化与祛魅"）形成**对照关系**——韦伯把现代国家解释为"垄断合法暴力 + 官僚制 + 税收"的组合；萨拉丁的国家还带着卡里斯玛与宗教光环，但它的底层逻辑已经是"税基—军队—合法性"的三件套。

### 5.4 哈丁：一场被水源决定的战役

1187 年 7 月，萨拉丁围攻太巴列，引诱耶路撒冷国王盖伊（Guy of Lusignan）率军救援。十字军从萨法里耶出发，在无水高地上行军；萨拉丁的轻骑兵不断骚扰，迫使他们离开道路，靠近太巴列湖却喝不到水。

| 变量 | 十字军 | 萨拉丁 |
| :--- | :--- | :--- |
| 水源 | 行军途中被切断 | 控制太巴列湖与泉水 |
| 阵型 | 步兵与骑兵脱节 | 轻骑兵骚扰，迫使对方离开道路 |
| 士气 | 真十字架与国王在场，但不能解渴 | 以逸待劳 |
| 指挥 | 盖伊缺乏威信，诸侯争吵 | 统一指挥 |
| 情报 | 对萨拉丁兵力估计不足 | 掌握十字军动向 |

7 月 4 日，十字军在哈丁角（Horns of Hattin）崩溃。国王盖伊被俘，真十字架被夺，沙蒂永的雷纳德被萨拉丁亲手处决（一说下令处决），大量骑士与步兵被杀或被卖为奴。**哈丁不是"勇气"的失败，是"后勤"的失败：一支没有水的军队，再虔诚也打不了仗。**

> 📌 **哈丁战役（Battle of Hattin）**：1187 年 7 月 4 日，萨拉丁在加利利击败耶路撒冷王国主力，随后收复耶路撒冷；它是十字军国家由盛转衰的转折点。在本文中的作用：它把"圣战"从宣传变成战果，也把"十字军不可战胜"的神话打破。

### 5.5 1187—1192：耶路撒冷、阿卡、阿苏夫与和约

哈丁之后，萨拉丁在三个月内横扫加利利、撒马利亚与沿海城市；10 月 2 日，耶路撒冷投降。萨拉丁没有重复 1099 年的屠杀：他允许居民赎买自由，留下大部分教堂，允许朝圣者通行。**这既是政治计算（稳定统治、争取国际承认），也是他"仁君"形象的材料。**

第三次十字军（1189—1192）由三位君主领衔：德意志的腓特烈一世、法兰西的腓力二世、英格兰的理查一世。腓特烈在奇里乞亚渡河时溺死，德意志军队溃散；腓力攻下阿卡后回国；理查独自支撑，攻下阿卡、在阿苏夫击败萨拉丁、两次逼近耶路撒冷，但始终没有攻城。

1192 年，双方签订《雅法和约》：耶路撒冷仍归穆斯林，但基督徒朝圣者可以自由进入；十字军保留从提尔到雅法的沿海地带。**理查没有夺回圣城，却保住了"朝圣权"——这正是十字军最初的目的。** 萨拉丁与理查互相欣赏的传说（互赠礼物、派医生），成了后世"骑士精神"叙事的素材；但两人都清楚，这是一场没有赢家的消耗战。

> 📌 **朝圣通行权（Right of Pilgrimage）**：1192 年《雅法和约》的核心条款之一：基督徒可以不受阻碍地前往耶路撒冷朝圣。在本文中的作用：它标志着十字军从"征服圣地"退回到"访问圣地"——目标降级，但制度延续。

| 君主 | 目标 | 行动 | 结局 |
| :--- | :--- | :--- | :--- |
| 腓特烈一世（德意志） | 经陆路直取耶路撒冷 | 穿越安纳托利亚 | 1190 年溺死，军队溃散 |
| 腓力二世（法兰西） | 收复阿卡，巩固王权 | 围攻阿卡 | 1191 年回国 |
| 理查一世（英格兰） | 收复耶路撒冷 | 阿卡、阿苏夫、雅法 | 1192 年和约，未取耶路撒冷 |

> 🔗 **横向关联**：本节"目标降级为朝圣权"与 [世界上的所有末世神学](../政治入门/世界上的所有末世神学.md)（第四节"外交与末世地图"）形成**对照关系**——末世论把耶路撒冷当作"末日剧本"的舞台；现实政治却把它降级为"朝圣目的地"。**同一座城市，在神学里是终点，在外交里是筹码。**

### 5.6 萨拉丁之后：马穆鲁克、蒙古与阿卡

1193 年萨拉丁去世，阿尤布王朝迅速分裂。此后的穆斯林反攻，主角换成了马穆鲁克：

- 1250 年，马穆鲁克推翻阿尤布王朝，建立苏丹国。
- 1258 年，蒙古攻陷巴格达，阿拔斯哈里发被杀。
- 1260 年，马穆鲁克在艾因贾鲁特击败蒙古，成为伊斯兰世界的军事核心。
- 1260—1277 年，拜巴尔斯（Baibars）系统性地拔除十字军城堡：1268 年安条克陷落。
- 1289 年，的黎波里陷落；1291 年，阿卡陷落。

> 📌 **马穆鲁克（Mamluk）**：阿拉伯语"被拥有者"，指从高加索、中亚等地购入的奴隶士兵；他们接受军事训练、皈依伊斯兰教，逐步成为埃及的统治精英，1250 年建立马穆鲁克苏丹国。在本文中的作用：它是"常备军国家"的典型——用奴隶贸易补充人力，用伊克塔供养军官，用苏丹集权统一指挥。

| 维度 | 十字军国家 | 马穆鲁克 |
| :--- | :--- | :--- |
| 军队 | 封建征召 + 朝圣者 + 雇佣兵 | 常备奴隶军 + 伊克塔 |
| 财政 | 关税 + 农业 + 西方捐助 | 土地税 + 贸易 + 战利品 |
| 指挥 | 国王/摄政/诸侯会议 | 苏丹集权 |
| 后勤 | 依赖意大利海运 | 依赖尼罗河与内陆 |
| 结果 | 1291 年被逐个拔除 | 1291 年后继续扩张 |

**1291 年不是"突然的灾难"，而是"国家军队战胜封建网络"的必然结果。** 阿卡陷落后，十字军国家在黎凡特的最后一个据点也消失了；圣殿骑士团退到塞浦路斯，医院骑士团退到罗德岛，条顿骑士团把重心转向普鲁士。十字军的"海外篇章"结束，但它的"模板"还在继续复制——这是下一节的主题。

> 🔗 **横向关联**：本节"马穆鲁克的国家军队"与 [农业帝国编年史](../../人类学/农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）.md)（5.1 节"奥斯曼帝国：Devshirme 儿童血税与 Timar 军事采邑"）形成**上游—下游关系**——马穆鲁克的"奴隶军 + 伊克塔"与奥斯曼的"儿童血税 + 提马尔"是同一套逻辑的两种版本：**用中央控制的军事精英，取代分散的封建领主。**

## 六、变形：十字军作为可复制模板（1204—1453）

### 6.1 第四次十字军：一次被债务改道的远征

第四次十字军（1201—1204）是十字军史上最臭名昭著的一次，也是制度分析价值最高的一次。它本来要去埃及——这是当时教皇与军事专家公认的"打蛇打七寸"路线；结果它去了扎拉，又去了君士坦丁堡，最后洗劫了同属基督教世界的拜占庭首都。

链条在第三节已经拆过：威尼斯合同 → 人数不足 → 筹款短缺 → 攻打扎拉抵债 → 拜占庭流亡皇子加码 → 转向君士坦丁堡。这里要补的是**后果**：

- 君士坦丁堡被洗劫三天，圣索菲亚大教堂的圣物、金银与艺术品被运回西欧；拜占庭帝国被分割为拉丁帝国、尼西亚帝国、伊庇鲁斯与特拉比松等碎片。
- 1261 年，尼西亚帝国收复君士坦丁堡，拜占庭复国，但再也恢复不了地中海霸权。
- 1204 年成为东正教记忆中最深的伤口；1054 年的"绝罚"是文件，1204 年的"洗劫"是血。

> 📌 **拉丁帝国（Latin Empire）**：1204 年十字军在君士坦丁堡建立的政权（1204—1261），由佛兰德的鲍德温一世为皇帝，威尼斯获得大量领土与商业特权；它是十字军"殖民化"最直接的一次尝试。在本文中的作用：它证明十字军模板可以推翻一个基督教帝国，却无法稳定统治它。

> 📌 **分土条约（Partitio terrarum imperii Romaniae）**：1204 年 3 月十字军与威尼斯签订的瓜分拜占庭领土的协议；威尼斯与十字军各得 3/8，余下 1/4 留给未来的拉丁皇帝。在本文中的作用：它把"圣战"变成了"分赃会议"，也让威尼斯从"承运人"变成"殖民宗主"。

关于第四次十字军，史学界有两派：一派（Queller、Madden）强调"意外"——债务、误判与个人野心把队伍一步步推偏；另一派强调"结构"——威尼斯的地中海利益、拜占庭的虚弱、西方对希腊人的长期敌意，早已把方向写好。**更稳妥的说法是：结构提供了可能性，债务提供了扳机，个人提供了执行。**

> 🔗 **横向关联**：本节"1204 年把分裂变成伤口"与 [犹太教、基督教、东正教与新教的发展历史](犹太教、基督教、东正教与新教的发展历史：三次分化与两千年谱系.md)（第四节"1054 年：第二次分化"）形成**互证关系**——该笔记指出 1054 年的绝罚当时并未被视为"大分裂"，1204 年才是真正的血案；本文补充它的组织史：这不是"宗教仇恨"的突然爆发，而是一支负债的军队在寻找还款方式。

### 6.2 伊比利亚：收复失地运动

伊比利亚是十字军模板最成功、也最持久的复制品。711 年穆斯林征服半岛后，北部基督教王国以"收复"为名逐步南推；1085 年卡斯蒂利亚攻占托莱多，1147 年里斯本被攻占，1212 年拉斯纳瓦斯·德·托洛萨战役成为转折，1236 年科尔多瓦、1248 年塞维利亚相继陷落，1249 年葡萄牙完成收复，1492 年格拉纳达投降。

| 时间 | 事件 | 意义 |
| :--- | :--- | :--- |
| 1085 | 托莱多陷落 | 收复失地运动的第一个大城 |
| 1147 | 里斯本陷落 | 十字军舰队参与，模板扩散 |
| 1212 | 拉斯纳瓦斯·德·托洛萨 | 基督教联军决定性胜利 |
| 1236 | 科尔多瓦陷落 | 伊斯兰西班牙的核心城市 |
| 1248 | 塞维利亚陷落 | 卡斯蒂利亚控制瓜达尔基维尔河 |
| 1492 | 格拉纳达投降 | 收复失地运动完成 |
| 1492 | 驱逐犹太人 | "内部净化"与"外部扩张"同步 |

> 📌 **收复失地运动（Reconquista）**：伊比利亚基督教王国对穆斯林政权的长期军事扩张（约 718—1492）；教皇把其中许多战役等同于十字军，给予参战者赦罪。在本文中的作用：它证明十字军模板可以脱离"耶路撒冷"这个目的地，变成一场持续数百年的"建国运动"。

**伊比利亚的特殊之处在于：它把"收复"变成了"建国"，再把"建国"变成了"出海"。** 1492 年格拉纳达陷落与哥伦布首航是同一年；此后的西班牙与葡萄牙把十字军的"特许 + 征服 + 传教"三件套带到了美洲、非洲与亚洲。这不是说"十字军导致了殖民主义"，而是说：**同一套合法性技术，可以从地中海搬到 Atlantic。**

> 🔗 **横向关联**：本节"伊比利亚的收复—建国—出海"与 [商业革命编年史](../../人类学/商业革命编年史：白银、股份公司与第一次全球化（1500-1750）.md)（1.1 节"价格革命：欧洲的通货膨胀"）形成**上下游关系**——该笔记讲美洲白银如何引发欧洲价格革命；本文讲白银到来之前的"合法性准备"：伊比利亚的十字军传统，为海外征服提供了现成的语言与制度。

### 6.3 北方十字军：条顿骑士团与普鲁士

1190 年，条顿骑士团在阿卡成立，1198 年军事化；1226 年，马佐维亚公爵康拉德邀请它到普鲁士对付异教徒；此后三百年，它把波罗的海的普鲁士变成了一个"骑士团国家"（Ordensstaat）。

| 时间 | 事件 | 意义 |
| :--- | :--- | :--- |
| 1147 | 文德十字军 | 北方十字军的开端 |
| 1198 | 条顿骑士团军事化 | 第三个大修会 |
| 1226 | 受邀进入普鲁士 | 骑士团国家的起点 |
| 1236 | 绍莱战役 | 立陶宛重创宝剑骑士团 |
| 1242 | 楚德湖战役 | 条顿骑士团东扩受挫 |
| 1386 | 立陶宛皈依基督教 | 北方十字军失去"异教徒"目标 |
| 1410 | 格伦瓦尔德战役 | 波兰—立陶宛重创条顿骑士团 |
| 1525 | 普鲁士世俗化 | 骑士团国家变成普鲁士公国 |

> 📌 **北方十字军（Northern Crusades）**：12—15 世纪在波罗的海地区对文德人、普鲁士人、立陶宛人等异教徒发动的十字军；参与者包括丹麦、瑞典、宝剑骑士团与条顿骑士团。在本文中的作用：它展示了十字军模板的"殖民化"一面——征服、传教、建城、移民、征税，形成一套可复制的"边疆国家"模式。

**条顿骑士团国是十字军模板最惊人的"国家化"：一个修会变成了一个公国，最后变成了普鲁士。** 1525 年，大团长阿尔布雷希特改宗路德宗，把骑士团国世俗化为普鲁士公国——这是十字军制度与宗教改革的直接交汇点。

> 🔗 **横向关联**：本节"1525 年普鲁士世俗化"与 [马丁·路德与宗教改革](马丁·路德与宗教改革：从赎罪券到威斯特伐利亚（1517—1648）.md)（第六节"政治结算"）形成**上下游关系**——该笔记讲路德宗如何被诸侯接管、成为领地教会的组织资源；本文讲一个十字军修会如何把自己改造成路德宗公国。**宗教改革的"教随国定"，在这里变成了"修会随国定"。**

### 6.4 阿尔比十字军：对内的十字军

1209 年，教皇英诺森三世发动阿尔比十字军，讨伐法国南部的卡特里派（Cathars）。这场战争持续二十年，贝济耶（Béziers）屠城、卡尔卡松投降、1213 年米雷战役、1229 年《巴黎条约》把朗格多克并入法国王室；1233 年宗教裁判所成立，1244 年蒙塞居尔（Montségur）陷落，卡特里派被彻底消灭。

> 📌 **卡特里派（Cathars）**：12—13 世纪法国南部与意大利北部的二元论异端，认为物质世界是恶的、精神世界是善的；他们拒绝教会财产与圣礼，被教会视为最大威胁之一。在本文中的作用：它让十字军从"对外收复圣地"转向"对内净化基督教世界"——这是十字军史上最重要的转向之一。

> 📌 **异端（Heresy）**：在教会法中被判定为偏离正统教义的主张；13 世纪以后，异端不仅是神学问题，也是"危害公共秩序"的法律问题。在本文中的作用：它解释了为什么十字军可以打击"名义上的基督徒"——只要对方被定义为异端，暴力就获得了合法性。

> 🔗 **横向关联**：本节"对内的十字军"与 [马丁·路德与宗教改革](马丁·路德与宗教改革：从赎罪券到威斯特伐利亚（1517—1648）.md)（4.2 节"激进派：被天主教与路德宗同时镇压"）形成**对照关系**——阿尔比十字军用十字军打击异端，宗教改革后的主流派也用世俗权力镇压激进派；**"正统"一旦与国家权力结合，就会把异端变成治安问题。**

### 6.5 政治十字军与民众十字军

13—15 世纪，"十字军"进一步泛化：

| 类型 | 时间 | 目标 | 结果 |
| :--- | :--- | :--- | :--- |
| 政治十字军 | 1240s—1280s | 教皇的霍亨斯陶芬对手、西西里、阿拉贡 | 把"十字军"变成教皇的政治工具 |
| 儿童十字军 | 1212 | 传说中由儿童领导的远征 | 多数人未离开欧洲，部分被卖为奴 |
| 牧羊人十字军 | 1251、1320 | 平民自发远征 | 被当局镇压或解散 |
| 胡斯十字军 | 1420—1431 | 镇压波希米亚胡斯派 | 五次十字军均失败 |

> 📌 **政治十字军（Political Crusade）**：教皇把十字军授权用于政治对手（如霍亨斯陶芬皇帝、西西里国王、阿拉贡国王）的战争；它使"十字军"从"对异教徒的战争"扩展为"对教皇敌人的战争"。在本文中的作用：它证明"十字军"本质上是一种**合法性形式**，内容可以被替换。

> 📌 **儿童十字军（Children's Crusade）**：1212 年传说中由法国与德意志儿童领导的远征；现代研究认为参与者多为贫困成年人，规模与结局被后世夸大。在本文中的作用：它是十字军"大众动员"的极端形态，也是"神圣使命"被商业与政治利用的样本。

**当"十字军"可以被卖给任何政治目标时，它就不再是一场运动，而是一种"合法性货币"。** 教皇印钞，君主与派系使用；印得越多，币值越低。到 15 世纪，"十字军"已经贬值到需要靠"胡斯战争"这样的地方冲突来维持。

### 6.6 反奥斯曼：从尼科波利斯到勒班陀

奥斯曼的崛起，让"十字军"找到了新的对手。1396 年尼科波利斯战役，欧洲联军惨败；1444 年瓦尔纳战役，波兰—匈牙利国王战死；1453 年君士坦丁堡陷落；1571 年勒班陀海战，神圣联盟击败奥斯曼舰队；1683 年维也纳之战，奥斯曼被挡在中欧之外。

| 时间 | 事件 | 结果 |
| :--- | :--- | :--- |
| 1396 | 尼科波利斯 | 欧洲联军惨败，奥斯曼巩固巴尔干 |
| 1444 | 瓦尔纳 | 十字军再次失败 |
| 1453 | 君士坦丁堡陷落 | 拜占庭终结，奥斯曼成为帝国 |
| 1571 | 勒班陀 | 神圣联盟海战大胜，但未改变陆上格局 |
| 1683 | 维也纳 | 奥斯曼扩张被逆转 |

> 📌 **神圣联盟（Holy League）**：16—17 世纪由教皇、西班牙、威尼斯等组织的反奥斯曼联盟；1571 年勒班陀海战是其最著名的胜利。在本文中的作用：它是"十字军"最后的制度化形态——仍然有教皇授权、赦罪与多国联军，但主导者已经是世俗君主。

**勒班陀是"十字军"的最后一次大胜，但它没有改变地缘政治：奥斯曼仍然是地中海东部的霸主；真正的转折是 1683 年维也纳，而那是王朝战争，不是十字军。** 十字军的时代结束了，但它的"合法性技术"没有结束——它被世俗化、被殖民化、被民族化，进入近代。

## 七、钱的账本：谁付账、谁获益

### 7.1 成本结构：一个骑士的账单

十字军首先是一笔家庭财务决策。一个骑士要准备：战马、坐骑、盔甲、武器、随从、粮食、运输、过路费、赎金；如果他是领主，还要负责随行人员的装备与家属的生活。赖利-史密斯估计，一名骑士的十字军开销约为其年收入的 4—5 倍；男爵与国王的规模更大。

| 项目 | 估算 | 谁承担 |
| :--- | :--- | :--- |
| 战马与坐骑 | 数倍于普通马 | 骑士本人 |
| 盔甲与武器 | 相当于数月收入 | 骑士本人 |
| 运输与过路费 | 按人头/货物 | 领主、意大利船主 |
| 粮食与补给 | 按军队规模 | 领主、随军商人 |
| 赎金 | 不可预测 | 家族、教会、修会 |
| 城堡与驻军 | 长期支出 | 国王、修会、意大利公社 |

**这意味着：能去十字军的人，不是"最穷的人"，而是"能筹到钱的人"。** 无地骑士愿意去，是因为他们有机会获得土地、地位与赦罪；有地贵族愿意去，是因为他们有财产可以抵押、有家族可以支援。**十字军的"群众基础"不是穷人，而是"有负债能力的人"。**

> 📌 **十字军预算（Crusade Budget）**：现代史学用来描述十字军远征的收支结构；它包括个人装备、运输、补给、赎金、城堡与外交费用。在本文中的作用：它把十字军从"信仰行为"还原为"财务行为"——没有预算，就没有远征。

### 7.2 融资：抵押、借款、卖地与教会税

十字军的融资工具，几乎就是一部"中世纪金融史"：

| 工具 | 谁用 | 成本/风险 |
| :--- | :--- | :--- |
| 卖地/抵押地产 | 领主、骑士 | 失去家族根基；利息高 |
| 向犹太人/伦巴第人借款 | 中小贵族、君主 | 高利贷禁令与政治风险 |
| 教会税（什一税、十字军税） | 教皇、君主 | 需要教会与世俗当局合作 |
| 以钱代誓 | 不能出征者 | 把"参战"变成"付费" |
| 意大利银行/圣殿骑士垫资 | 君主、大领主 | 以关税、领地收入作抵押 |

> 📌 **十字军税（Crusade Tax）**：教皇或君主为资助十字军而征收的税，包括教士收入税、动产税与"萨拉丁什一税"；它是中世纪晚期"常规税"的雏形。在本文中的作用：它把"一次性的宗教热情"转化为"可持续的财政制度"——十字军因此可以反复发动，而不必每次都等一个 charismatic 领袖。

> 📌 **高利贷（Usury）**：教会法禁止以利息放贷；但十字军融资通过"汇率差""风险补偿""抵押"等方式绕开禁令。在本文中的作用：它揭示了宗教禁令与商业实践之间的张力——**当战争需要钱时，禁令会被重新解释。**

> 🔗 **横向关联**：本节"高利贷禁令被战争融资绕开"与 [资本市场的形成](../资本与人/资本市场的形成：从债务、集市、商行到制度化资本主义的权力史.md)（14.1 节"从罪到利益"）形成**上下游关系**——该笔记讲"赚钱如何从中世纪的罪变成近代的体面"；本文给出一个更早的案例：十字军让"为战争借钱"变成一种可以被教会容忍的行为。

### 7.3 圣殿骑士：从护卫到银行

圣殿骑士团最初是朝圣者的武装护卫（约 1119 年），后来变成十字军世界最重要的金融机构之一：它为朝圣者提供存款与异地支付，为国王管理财政，为教皇代收税款。巴黎的圣殿总部实际上成了法国王室的国库。

| 资产/负债 | 内容 | 风险 |
| :--- | :--- | :--- |
| 地产 | 西欧各地的庄园与教堂 | 管理成本高 |
| 现金存款 | 朝圣者、国王、贵族的存款 | 挤兑与政治没收 |
| 债权 | 对国王与大领主的贷款 | 违约风险 |
| 特权 | 免税、教皇直属、司法豁免 | 引发嫉妒与攻击 |

1307 年，法王腓力四世以"异端"罪名逮捕全法圣殿骑士；1312 年教皇克雷芒五世解散修会；1314 年大团长雅克·德·莫莱被烧死。**圣殿骑士的灭亡不是"秘密"的胜利，而是"债务政治"的胜利：国王欠银行家的钱，最方便的还债方式就是消灭银行家。**

> 🔗 **横向关联**：本节"王室金库与主权债务"与 [资本市场的形成](../资本与人/资本市场的形成：从债务、集市、商行到制度化资本主义的权力史.md)（6.3 节"从'国王的信用'到'国家的信用'"）形成**上下游关系**——该笔记讲近代国家如何把君主的个人信用变成国家的公共信用；本文讲它的"前身"：圣殿骑士替国王管钱，最后被国王消灭。**主权债务的诞生，伴随着债权人的尸体。**

### 7.4 意大利城邦：运费、贷款与殖民地

十字军最大的"隐形赢家"是意大利海上共和国。它们不统治圣地，却控制了圣地的港口；它们不参加战斗，却决定谁能上岸、谁拿到补给、谁获得贸易特权。

| 城邦 | 主要据点 | 收益 | 结局 |
| :--- | :--- | :--- | :--- |
| 威尼斯 | 君士坦丁堡、克里特、阿卡、提尔 | 免税、街区、殖民地 | 1797 年被拿破仑终结 |
| 热那亚 | 阿卡、卡法、黑海 | 黑海贸易、银行 | 与威尼斯长期竞争 |
| 比萨 | 阿卡、提尔 | 贸易与航运 | 被热那亚击败 |
| 阿马尔菲 | 君士坦丁堡、埃及 | 早期贸易网络 | 被比萨与热那亚取代 |

> 📌 **巴伊洛（Bailo）**：威尼斯在海外殖民地或商馆设立的最高代表，兼具领事、法官与商人三重身份。在本文中的作用：它是"商业殖民"的行政形式——没有军队占领，却有司法权、税收权与外交权。

> 📌 **卡法（Caffa）**：热那亚在黑海的殖民地（今克里米亚费奥多西亚），是黑海奴隶与粮食贸易的中心；1347 年黑死病经此传入欧洲的叙事常被引用。在本文中的作用：它展示了十字军时代的"港口—殖民地"网络如何延伸为近代全球贸易的节点。

**意大利城邦是十字军最大的"隐形赢家"：它们不统治圣地，却控制了圣地的港口。** 威尼斯在 1204 年后获得克里特、优卑亚与爱琴海岛屿；热那亚在 1261 年后获得黑海贸易；两国的竞争一直延续到 1381 年的基奥贾战争。

### 7.5 长期后果：税收、代表制与国债

十字军的财政遗产，比它的军事遗产更持久：

| 机制 | 短期效果 | 长期后果 |
| :--- | :--- | :--- |
| 十字军税 | 为远征筹钱 | 常规税与教会财政体系的形成 |
| 以钱代役 | 封建军队货币化 | 雇佣军与常备军的兴起 |
| 王室借款 | 君主依赖银行家 | 主权债务与金融市场的形成 |
| 代表制 | 君主为征税召集议会 | "无代表不纳税"的政治传统 |

> 📌 **代表制（Representation）**：君主为征税而召集贵族、教士与城市代表，逐步形成议会制度；英国议会、法国三级会议、西班牙议会都有类似的财政起源。在本文中的作用：它说明十字军的财政需求，如何间接塑造了欧洲的政治代表制度——**战争逼出税收，税收逼出代表。**

**十字军没有创造资本主义，但它把"为战争借钱"变成了一门可持续的生意。** 意大利银行、圣殿骑士、王室财政、教会税，这些制度在十字军之后继续运转，成为近代国家与资本市场的基础设施。

> 🔗 **横向关联**：本节"战争—税收—代表制"与 [资本市场的形成](../资本与人/资本市场的形成：从债务、集市、商行到制度化资本主义的权力史.md)（6.4 节"国家财政与资本市场的长期绑定"）形成**互证关系**——该笔记把国家财政与资本市场的绑定追溯到近代早期；本文指出这条绑定在十字军时代已经出现了原型：**战争是最早的"刚性支出"，也是最早的"信用需求"。**

## 八、人的账本：受害者、参与者与沉默者

### 8.1 1096：莱茵兰的犹太人

人民十字军出发前，莱茵兰地区爆发了对犹太社区的大规模屠杀。施派尔、沃尔姆斯、美因茨、科隆的犹太社区被洗劫，许多人被强迫改宗，拒绝者被杀害；估计死者 2,000—12,000 人（各家差异大）。

| 时间 | 事件 | 机制 |
| :--- | :--- | :--- |
| 1096 | 莱茵兰屠杀 | 十字军以"异教徒同谋"为名攻击犹太人 |
| 1144 | 诺里奇血祭诽谤 | 犹太人被指控杀害基督徒儿童 |
| 1215 | 第四次拉特兰会议 | 要求犹太人佩戴识别标志 |
| 1290 | 英格兰驱逐犹太人 | 王权没收财产 |
| 1306 | 法国驱逐犹太人 | 王权没收财产 |
| 1492 | 西班牙驱逐犹太人 | 宗教统一与财产没收 |

> 📌 **血祭诽谤（Blood Libel）**：指控犹太人杀害基督徒儿童、用其血制作逾越节饼的谣言；1144 年诺里奇案是最早的著名案例。在本文中的作用：它是"内部敌人"叙事的典型——把宗教少数派描绘成威胁共同体的"污染源"，从而为暴力提供合法性。

> 📌 **隔都（Ghetto）**：16 世纪起欧洲城市中强制犹太人居住的隔离区；威尼斯 1516 年设立的 Ghetto 是最早的著名案例。在本文中的作用：它标志着"内部敌人"从"屠杀对象"变成"隔离对象"——暴力从肉体消灭转向空间管控。

> 🔗 **横向关联**：本节"血祭诽谤的纯洁—污染逻辑"与 [道德直觉进化起源_学术证据综述](../../人类学/道德直觉进化起源_学术证据综述.md)（第三节"Jonathan Haidt - 道德基础理论"）形成**互证关系**——海特把"神圣/纯洁"列为道德直觉的一个基础；本文展示这套直觉如何被政治企业家利用，把宗教少数派塑造成"污染源"。

### 8.2 1096：人民十字军

人民十字军的参与者，本身就是受害者：农民、手工业者、妇女、儿童，被布道动员上路，没有补给，没有指挥，在巴尔干与安纳托利亚被屠杀、饿死、卖为奴。奇维托特之战后，大部分人被杀或被俘；幸存者四散。

| 群体 | 遭遇 |
| :--- | :--- |
| 农民 | 饥饿、疾病、被当地居民攻击 |
| 妇女与儿童 | 随军、被俘、被卖为奴 |
| 破产骑士 | 战死或被俘 |
| 犹太人 | 被屠杀、被强迫改宗 |

**大众十字军是最容易被浪漫化、也最容易被牺牲的一群。** 他们相信自己在做神圣的事，却既没有资源，也没有组织；他们的热情被利用，他们的尸体被遗忘。

> 🔗 **横向关联**：本节"大众动员的规模错配"与 [自我、羡慕与神圣](../../人类学/自我、羡慕与神圣：可达性动力学、通约与共同体的耗散维护.md)（8.3 节"原始功能：150 人规模的黏合剂"）形成**互证关系**——该笔记指出，人类的道德直觉是为小规模共同体设计的；十字军把这种直觉放大到"基督教世界"的尺度，结果既产生了狂热的团结，也产生了失控的暴力。

### 8.3 1099：耶路撒冷

1099 年 7 月 15 日，耶路撒冷陷落。拉丁编年史称十字军"血流到马嚼子"，穆斯林与犹太人被大规模屠杀；幸存者被卖为奴。死亡人数的估计从 3,000 到 70,000 不等，现代研究多倾向于"数千人"。

| 史料 | 数字/表述 | 性质 |
| :--- | :--- | :--- |
| 拉丁编年史 | "血流到马嚼子" | 借用《启示录》的末日修辞 |
| 穆斯林史家（伊本·阿西尔） | 数万人 | 晚出，带有创伤记忆 |
| 现代研究（Kedar 等） | 数千人 | 人口基数与史料批判 |

> 📌 **伊本·阿西尔（Ibn al-Athir）**：13 世纪穆斯林史家，其《历史大全》记录了十字军的历史；他对 1099 年耶路撒冷大屠杀的记述，是后世穆斯林记忆的重要来源，但他并非目击者。在本文中的作用：它提醒我们，**记忆的传播者不一定是事件的见证者**。

**1099 年的记忆，比 1099 年的数字更持久。** 对穆斯林世界来说，耶路撒冷的陷落是"法兰克人"入侵的开端；对欧洲来说，它是"圣地解放"的象征；对犹太人来说，它是"1096 年迫害"的延续。同一事件，三种记忆，三种用途。

> 🔗 **横向关联**：本节"三种记忆"与 [自我、羡慕与神圣](../../人类学/自我、羡慕与神圣：可达性动力学、通约与共同体的耗散维护.md)（第八节"崇高的集体自我"）形成**互证关系**——该笔记讲集体如何通过"神圣叙事"把自我放大；本文给出一个极端案例：1099 年的屠杀同时被写成"神圣胜利"与"集体创伤"，取决于谁在叙述。

### 8.4 1204：君士坦丁堡

1204 年 4 月，十字军洗劫君士坦丁堡。圣索菲亚大教堂被掠夺，圣物、金银、艺术品被运回西欧；平民被屠杀、强奸、卖为奴；城市被焚毁。拜占庭史家尼基塔斯·霍尼亚提斯（Niketas Choniates）的记述，成为东正教记忆的核心文本。

| 损失 | 内容 | 记忆 |
| :--- | :--- | :--- |
| 圣物 | 圣索菲亚的圣像、圣髑 | 被运往威尼斯、法国 |
| 财富 | 金银、艺术品、书籍 | 部分进入欧洲教堂与博物馆 |
| 人口 | 平民死亡、逃亡、被卖 | 拜占庭人口与人才流失 |
| 政治 | 拉丁帝国建立 | 拜占庭分裂 57 年 |

**1204 年把"分裂"从文件变成了伤口。** 1054 年的绝罚可以被撤销（1965 年保罗六世与雅典纳哥拉互相撤销），但 1204 年的记忆不能被撤销。直到今天，东正教与天主教的关系仍然带着这道伤疤。

> 🔗 **横向关联**：本节"1204 年的记忆"与 [犹太教、基督教、东正教与新教的发展历史](犹太教、基督教、东正教与新教的发展历史：三次分化与两千年谱系.md)（第四节"1054 年：第二次分化"）形成**互证关系**——该笔记已经指出 1204 年才是"真正的伤口"；本文补充它的组织机制：这不是一次"宗教仇恨"的偶然爆发，而是一支负债的军队在威尼斯债权人引导下的"抵债行动"。

### 8.5 内部敌人：阿尔比派、胡斯派与政治对手

十字军的"对内转向"，比对外远征更深刻地塑造了欧洲。阿尔比十字军（1209—1229）消灭了卡特里派，把朗格多克并入法国王室；胡斯十字军（1420—1431）五次讨伐波希米亚，全部失败；政治十字军则把教皇的对手（霍亨斯陶芬、阿拉贡、西西里）打成"异端"。

| 目标 | 时间 | 结果 |
| :--- | :--- | :--- |
| 卡特里派 | 1209—1229 | 被消灭，朗格多克并入法国 |
| 胡斯派 | 1420—1431 | 五次十字军失败，胡斯派获得宗教妥协 |
| 霍亨斯陶芬 | 1240s—1260s | 教皇的政治十字军，削弱帝国 |
| 阿拉贡 | 1284—1285 | 法国十字军失败 |

> 🔗 **横向关联**：本节"把异端变成治安问题"与 [世界政治格局解释](世界政治格局解释.md)（"猎巫运动"一节）形成**对照关系**——猎巫与十字军对内镇压共享同一套逻辑：**把社会危机归咎于一个"内部异端"，用司法或军事暴力净化共同体。** 区别在于，十字军打击的是有组织的异端教派，猎巫打击的是被指控的个人。

### 8.6 女性：随军者、继承人与修女

十字军不是"男人的战争"。没有女性，就没有营地、家庭与继承；但她们的账本几乎没有被记录。

| 角色 | 例子 | 处境 |
| :--- | :--- | :--- |
| 随军妇女 | 洗衣妇、商贩、妓女、妻子 | 饥饿、疾病、暴力、被俘 |
| 贵族女性 | 阿基坦的埃莉诺（第二次十字军） | 随军、政治象征、被后世传奇化 |
| 十字军寡妇 | 留守领地的妻子 | 管理地产、等待、再婚 |
| 修女 | 医院修会、女修道院 | 护理、募捐、保存记忆 |

> 📌 **阿基坦的埃莉诺（Eleanor of Aquitaine）**：法国王后、后为英格兰王后，参加第二次十字军（1147—1149）；后世传说她与随行贵妇扮成"亚马逊女战士"，但这一说法缺乏可靠史料。在本文中的作用：它说明女性在十字军中的角色常被传奇化，真实的记录却极少。

**十字军的性别账本，最大的一栏是"缺席"：** 我们知道的女性名字，几乎都是贵族；农民、商贩、洗衣妇、被俘者的名字，几乎没有留下。**历史的沉默，不是因为没有发生，而是因为没有记录。**

### 8.7 被遗忘的人：东方基督徒、战俘与奴隶

十字军的人道账本，最大的一栏不是"死者"，而是"被卖掉的人"。

| 群体 | 遭遇 | 规模 |
| :--- | :--- | :--- |
| 东方基督徒 | 被拉丁人歧视、征税、 occasionally 屠杀 | 无法估计 |
| 战俘 | 被赎买、被卖为奴、被处决 | 数千至数万 |
| 奴隶 | 地中海奴隶贸易的"货物" | 数万至数十万（长期） |
| 农民 | 战争、饥荒、征税的承担者 | 绝大多数 |

> 📌 **战俘赎金（Ransom）**：中世纪战争中，俘虏可以用钱赎买；赎金的高低取决于身份与地位。在本文中的作用：它说明十字军的"人道"是有价格的——国王可以被赎，农民只能被卖。

> 📌 **奴隶贸易（Slave Trade）**：地中海世界长期存在奴隶贸易，来源包括黑海、巴尔干、非洲与战俘；意大利城邦、马穆鲁克埃及与奥斯曼都是重要参与者。在本文中的作用：它把十字军从"宗教战争"拉回"经济制度"——**圣战与奴隶贸易，常常是同一条供应链的两端。**

> 🔗 **横向关联**：本节"地中海奴隶贸易"与 [农业帝国编年史](../../人类学/农业帝国编年史：提取率的万年博弈（10000 BP - 1750 AD）.md)（5.1 节"奥斯曼帝国：Devshirme 儿童血税与 Timar 军事采邑"）形成**对照关系**——奥斯曼的"儿童血税"与马穆鲁克的"奴隶军"都是把人口转化为军事资本；十字军时代的奴隶贸易，则是同一套逻辑的商业版本。

### 8.8 四维分层表

按《知识笔记写作规则》的受害人群分析框架，把主要群体放进四个维度：

| 群体 | 规模/金额 | 法律地位 | 受偿排序 | 痛苦指数 |
| :--- | :--- | :--- | :--- | :--- |
| 莱茵兰犹太人（1096） | 2,000—12,000 死者 | 帝国"王室仆从"，理论受保护 | 无 | 极高 |
| 人民十字军（1096） | 2 万—4 万人 | 无正式身份，朝圣者 | 无 | 极高 |
| 耶路撒冷穆斯林/犹太人（1099） | 3,000—70,000（争议） | 被征服者 | 无 | 极高 |
| 君士坦丁堡希腊人（1204） | 数万 | 同属基督徒，但被视为"分裂者" | 无 | 极高 |
| 阿尔比派（1209—1229） | 数万 | 异端，法律上无保护 | 无 | 极高 |
| 北方异教徒（12—15 世纪） | 数十万（长期） | 异教徒，征服对象 | 无 | 高 |
| 儿童十字军（1212） | 传说数万 | 无 | 无 | 高 |
| 东方基督徒 | 无法估计 | 被容忍的"异端" | 低 | 中—高 |
| 战俘/奴隶 | 数万至数十万 | 财产 | 无 | 极高 |
| 女性（随军/留守） | 无法估计 | 依附于男性 | 低 | 中—高 |

**受害者的共同点不是"宗教"，而是"没有可执行的索赔权"。** 在一个没有国际法、没有人权话语、没有中立法庭的世界里，暴力一旦被"神圣"授权，受害者就只剩下两种选择：改宗、逃亡，或死。

## 九、记忆与史学：谁在讲述十字军

### 9.1 中世纪的记忆：Gesta Dei per Francos

中世纪的十字军史学，核心框架是"上帝通过法兰克人行事"（Gesta Dei per Francos）。吉贝尔·德·诺让（Guibert of Nogent）用这个标题写十字军史；罗伯特修士把克莱蒙演说写成"上帝所愿"；威廉·提尔（William of Tyre）把耶路撒冷王国写成"神圣历史"的延续。

| 史料 | 作者/立场 | 特点 |
| :--- | :--- | :--- |
| Gesta Francorum | 无名作者，亲博希蒙德 | 最早的十字军叙事之一 |
| Fulcher of Chartres | 鲍德温一世的随军司铎 | 亲身经历，亲耶路撒冷 |
| Robert the Monk | 事后编纂 | "Deus vult" 的来源 |
| William of Tyre | 耶路撒冷王国官方史家 | 12 世纪王国史的标准叙事 |
| Ibn al-Athir | 穆斯林史家 | 晚出，反十字军叙事 |
| Niketas Choniates | 拜占庭史家 | 1204 年的创伤记忆 |

> 📌 **Gesta Dei per Francos（上帝通过法兰克人所行的事）**：吉贝尔·德·诺让的十字军史标题，也是中世纪十字军史学的核心框架：十字军不是"人的战争"，而是"上帝通过法兰克人实施的奇迹"。在本文中的作用：它说明中世纪的记忆不是"历史"，而是"圣史"——事件的因果被替换为神意的安排。

### 9.2 启蒙的记忆：愚昧与贪婪

18 世纪的启蒙史家，把十字军写成"迷信与贪婪的混合物"。伏尔泰在《风俗论》里嘲讽十字军是"一群强盗打着宗教旗号"；吉本在《罗马帝国衰亡史》里把十字军写成"野蛮的回归"。这套叙事的影响力极大，直到今天仍然是大众想象的一部分。

> 📌 **启蒙史学（Enlightenment Historiography）**：18 世纪以理性、进步与世俗化为核心的历史写作；它倾向于把宗教战争解释为"迷信"与"教士权力"的产物。在本文中的作用：它是对中世纪"圣史"的反转——从"上帝通过法兰克人行事"变成"教士欺骗愚昧的民众"。

> 🔗 **横向关联**：本节"启蒙史学把十字军写成迷信"与 [马克斯·韦伯的社会学理论](../社会学研究/马克斯·韦伯的社会学理论.md)（第四节"理性化与祛魅"）形成**对照关系**——韦伯把"祛魅"解释为现代性的核心过程；启蒙史学的十字军叙事，正是"祛魅"在历史写作中的表现：**把神圣叙事还原为利益与欺骗。**

### 9.3 19 世纪：骑士、东方主义与殖民

19 世纪，十字军被浪漫化。沃尔特·司各特的小说《护身符》（1825）把萨拉丁与理查写成"骑士精神"的典范；夏多布里昂的《从巴黎到耶路撒冷》把东方写成"信仰的故乡"；德拉克洛瓦的画把十字军写成"英雄的史诗"。与此同时，法国在 1830 年征服阿尔及利亚，把"十字军"当作殖民的祖先；"文明使命"（mission civilisatrice）成为十字军的世俗版本。

> 📌 **东方主义（Orientalism）**：萨义德（Edward Said）使用的概念，指西方对东方的想象、研究与统治方式；它把东方写成"异质、停滞、感性"的他者，从而为殖民提供合法性。在本文中的作用：它解释了 19 世纪十字军叙事为何把"圣地"写成"等待拯救的东方"——**十字军成为殖民主义的"史前史"。**

> 🔗 **横向关联**：本节"十字军成为殖民的祖先"与 [工业资本主义编年史](../../人类学/工业资本主义编年史：煤、铁、工厂与阶级斗争（1750-1945）.md)（4.1 节"新帝国主义：瓜分非洲"）形成**对照关系**——19 世纪的新帝国主义用"文明使命"包装征服；十字军的"神圣使命"被改写成"文明使命"，但"授权暴力 + 特许权 + 教化"的结构没有变。

### 9.4 20 世纪：从朗西曼到赖利-史密斯

20 世纪的十字军史学，经历了三次转向：

| 学者 | 核心命题 | 影响 |
| :--- | :--- | :--- |
| 朗西曼（Runciman） | 十字军是"一部悲剧史诗" | 文学化叙事，大众影响最大 |
| 赖利-史密斯（Riley-Smith） | 十字军是"武装朝圣" | 把宗教动机放回中心 |
| 蒂尔曼（Tyerman） | 十字军是"教皇的战争" | 强调制度与财政 |
| 阿斯布里奇（Asbridge） | 十字军是"争夺圣地的战争" | 综合叙事，兼顾双方 |
| 希伦布兰德（Hillenbrand） | 从伊斯兰视角看十字军 | 打破欧洲中心 |
| 豪斯利（Housley） | 十字军是"多元的" | 把晚期十字军纳入视野 |

> 📌 **武装朝圣（Armed Pilgrimage）**：赖利-史密斯对十字军的核心定义：十字军不是"战争"，而是"以武装方式进行的朝圣"；誓愿、赦罪、朝圣者的保护，是理解十字军的关键。在本文中的作用：它纠正了"十字军 = 殖民主义"的现代投射，也解释了为什么十字军对参与者的吸引力首先是宗教的。

> 🔗 **横向关联**：本节"十字军史学的多次转向"与 [马丁·路德与宗教改革](马丁·路德与宗教改革：从赎罪券到威斯特伐利亚（1517—1648）.md)（8.1 节"七种叙事"）形成**对照关系**——两篇笔记都说明：**史学史不是"谁对谁错"，而是"每一代人用自己的问题重写过去"。** 宗教改革的史学有英雄、叛徒、阶级、媒介等叙事；十字军的史学有圣史、启蒙、浪漫、殖民、宗教修正、伊斯兰视角等叙事。

### 9.5 阿拉伯与土耳其的记忆：萨拉丁的挪用

在阿拉伯世界，萨拉丁是"反十字军的英雄"，被纳赛尔、复兴党、萨达姆等反复挪用；在土耳其，1453 年征服君士坦丁堡是民族叙事的高潮，圣索菲亚的博物馆/清真寺地位之争是当代政治的缩影；在西方，"十字军"一词被用于"反恐战争""人道主义干预"等世俗运动。

| 使用者 | 用途 | 效果 |
| :--- | :--- | :--- |
| 纳赛尔 | 阿拉伯民族主义 | 把萨拉丁写成"反帝"象征 |
| 复兴党/萨达姆 | 伊拉克/叙利亚政治 | 把自己比作萨拉丁 |
| 土耳其 | 民族认同 | 1453 年成为"征服"神话 |
| 西方政客 | 道德动员 | "crusade against poverty" 等 |
| 极端组织 | 动员 | 把现代冲突写成"十字军复活" |

**萨拉丁被每个时代重新发明一次。** 中世纪的萨拉丁是"仁君"与"圣战者"；19 世纪的萨拉丁是"骑士精神"的典范；20 世纪的萨拉丁是"反帝英雄"；21 世纪的萨拉丁是"抵抗西方"的符号。每一个版本都服务于当下的政治需要，而不是历史本身。

### 9.6 五个史学争议

| 争议 | 主流看法 | 证据边界 |
| :--- | :--- | :--- |
| 1099 年死亡人数 | 数千人（仍有争议） | 编年史修辞 vs 人口基数 |
| "Deus vult" 是否现场口号 | 可能是事后建构 | 罗伯特修士的版本晚出 |
| 十字军是否"殖民主义" | 有殖民特征，但不能等同 | 封建权利 vs 现代殖民 |
| 第四次十字军是意外还是结构 | 结构与意外共同作用 | 债务链 + 威尼斯利益 |
| 十字军是否"延误"了奥斯曼 | 没有；反而削弱了拜占庭 | 1204 年后拜占庭无法恢复 |

**争议本身是史料的一部分。** 每一个数字、每一句口号、每一个"意外"，都经过编年史家的选择与后世的复述；历史学的任务不是"还原唯一真相"，而是"说明为什么不同的人会看到不同的真相"。

## 十、长期账本与收束：十字军留下了什么

### 10.1 五本账与证据强度

| 账本 | 主张 | 证据强度 | 关键限定 |
| :--- | :--- | :--- | :--- |
| 教会财政 | 十字军税 → 赎罪券 → 宗教改革 | 强 | 赎罪券的财政化是长期过程，不是单线因果 |
| 商业金融 | 十字军 → 意大利银行 → 资本主义 | 中 | 意大利商业革命早于十字军 |
| 教皇权威 | 十字军 → 教皇君主制 → 世俗化 | 中 | 十字军也透支了教皇信誉 |
| 反犹主义 | 1096 → 血祭诽谤 → 现代反犹 | 强 | 反犹主义有更早的宗教根源 |
| 中东记忆 | 十字军 → 现代冲突 | 弱 | 修辞影响强，因果链弱 |
| 军事技术 | 城堡、攻城、海军 | 中 | 技术传播是多向的 |

> 📌 **证据强度（Evidence Strength）**：本文用来区分"制度关联"与"因果断言"的尺度：强 = 有直接制度链条与档案；中 = 有合理机制但缺直接证据；弱 = 主要是修辞与记忆的关联。在本文中的作用：它防止把"十字军"写成"一切现代问题的原因"。

**五本账的强度不一样。把弱账写成强账，就是"文明冲突"叙事的来源。** 十字军确实留下了反犹主义、战争财政与地中海商业网络；但它没有"导致"现代中东冲突，也没有"创造"资本主义。**历史的重要性，不等于因果的唯一性。**

### 10.2 归因：四台机器、一个窗口、三次转向

| 阶段 | 主导逻辑 | 结果 |
| :--- | :--- | :--- |
| 1095—1099 | 朝圣 + 封建 + 教皇授权 + 海运 | 第一次十字军成功 |
| 1144—1187 | 穆斯林国家建设 + 圣战 | 萨拉丁收复耶路撒冷 |
| 1201—1204 | 商业债务 + 威尼斯利益 | 君士坦丁堡被洗劫 |
| 1250—1291 | 马穆鲁克常备军 + 伊克塔 | 十字军国家被拔除 |
| 1300—1500 | 十字军模板世俗化 | 伊比利亚、波罗的海、胡斯、反奥斯曼 |

**十字军不是"一件事"，而是四次不同的制度实验：** 1095 年是"朝圣动员"的实验；1144—1187 年是"国家建设"的实验；1204 年是"商业债务"的实验；1291 年是"常备军"的实验。每一次实验都留下了制度遗产，也留下了受害者。

### 10.3 延伸：模板的世俗化

十字军的"模板"没有随 1291 年结束。它被世俗化、殖民化、民族化，进入近代：

| 模板要素 | 世俗版本 | 风险 |
| :--- | :--- | :--- |
| 教皇授权 | 国家主权、国际组织决议 | "授权"可以被滥用 |
| 赦罪 | 意识形态纯洁性、历史使命 | 把对手写成"敌人" |
| 誓愿 | 入伍誓词、入党誓词 | 个人被绑定 |
| 十字军税 | 战争税、国防预算 | 财政负担转嫁 |
| 特许权 | 殖民特许状、公司特许 | 暴力外包 |

> 📌 **特许公司（Chartered Company）**：16—19 世纪由君主或议会授予特许状、拥有贸易垄断与军事权力的公司（如英国东印度公司、荷兰 VOC）；它是"十字军模板"的世俗版本：授权 + 特许 + 武装 + 殖民。在本文中的作用：它说明十字军的组织技术，如何在近代被商业公司继承。

> 🔗 **横向关联**：本节"特许公司的十字军模板"与 [商业革命编年史](../../人类学/商业革命编年史：白银、股份公司与第一次全球化（1500-1750）.md)（2.1 节"VOC：第一家真正的公司"）形成**上下游关系**——该笔记讲 VOC 如何用股份与特许状组织全球贸易；本文讲它的"前世"：十字军的"授权 + 特许 + 武装"三件套，在世俗化之后变成了殖民公司的组织模板。

### 10.4 个体坐标：三条识别

十字军离我们不远，不是因为"文明冲突"，而是因为它的组织技术仍然在运行。对普通人来说，至少有三条识别规则：

| 识别信号 | 追问 | 现实例子 |
| :--- | :--- | :--- |
| 神圣语言 | 谁在授权？授权者能得到什么？ | "文明使命""历史使命""反恐" |
| 债务结构 | 谁垫资？谁承担违约风险？ | 战争预算、主权债务、外包合同 |
| 特许权 | 谁获得了例外？谁被排除？ | 殖民特许、平台垄断、资源租让 |

> 🔗 **横向关联**：本节"三条识别"与 [阿拉伯之春](../国家/中东/阿拉伯之春：从突尼斯小贩自焚到六国秩序崩塌.md)（10.3 节"个体坐标：普通人能做的三件事"）形成**方法上的呼应**——两篇笔记都把"宏大叙事"拆成"制度 + 账本 + 个体位置"；区别在于，十字军的账本是"赦罪—税—船"，阿拉伯之春的账本是"青年—食品—军队"。

### 10.5 一句话收束

**十字军最持久的遗产不是耶路撒冷，而是一套把信仰折算成可支付、可转让、可继承的债权的技术：它先教会欧洲怎样为一场远征收税、借钱、发船、记账，然后才教会欧洲怎样把这一切忘掉，只留下骑士与圣杯的浪漫图像。**
