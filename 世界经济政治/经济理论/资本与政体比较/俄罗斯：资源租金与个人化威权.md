# 俄罗斯：资源租金与个人化威权

> - **核心问题**：为什么"资本的结构性权力"这套在别处屡试不爽的解释，在俄罗斯**基本失效**？为什么国家可以长期忽略资本的意愿、侵犯产权、驱逐寡头，而不承受"资本不投资 → 经济崩溃"的后果？
> - **叙事逻辑**：结构性资本权力的前提条件 → 俄罗斯为什么不符合 → 租金的性质（不依赖资本，只依赖资源 + 管道）→ 从寡头到国家化（2000s 的产权重定义）→ 个人化威权的决策结构 → 为什么这套系统在停滞中稳定、在战争中被重新激活 → 信息结构的独特脆弱性 → 与新加坡/中国的对照 → 收束
> - **立场说明**：本笔记分析的是**国家—资本关系的结构类型**，不是对俄罗斯政治或对外政策的评价。核心论点是可检验的：**资源租金使国家获得了"不需要资本"的能力，从而取消了资本对国家施加结构性压力的通道**。这一机制的通用性也适用于海湾国家、委内瑞拉、以及部分非洲资源国——它们政治制度不同，但国家—资本关系同型。
> - **来源标注**：Rosstat（俄罗斯联邦统计局）、俄罗斯央行（CBR）、俄罗斯联邦财政部、Gaidar Institute 与 HSE 研究文献、Guriev & Sonin 关于俄罗斯政治经济学的综述、Gaddy & Ickes 关于租金与国家的研究、EBRD 转型报告；涉及 2022 年后的部分只作结构性描述，数据以公开国际机构估计为准；综合分析与理论判断为笔记作者原创，2026-09-19。

## 一、一套解释的失效：资本的结构性权力在俄罗斯不成立

### 1.1 回到前提

在 [[美国：多否决点与资本的结构性权力]] 中，"结构性权力"的逻辑是：

```
资本不投资 → 失业上升 → 社会不满 → 政府失去支持
  ↓
政府主动照顾资本的需要（无需游说）
```

**这套逻辑有几个隐含前提**：

| # | 前提 | 内容 |
|---|---|---|
| **1** | **就业依赖私人投资** | 资本是就业的主要创造者 |
| **2** | **税收依赖私人部门的产出** | 国家财政收入来自资本的经济活动 |
| **3** | **资本可以退出** | 有可行的外部选项 |
| **4** | **政府需要公众支持** | 存在某种形式的政治问责 |

### 1.2 俄罗斯逐条不符合

| 前提 | 俄罗斯的情况 | 结果 |
|---|---|---|
| **①就业依赖私人投资** | **部分不成立**：大量就业在国有部门、能源、军工、以及补贴性公共部门 | 资本退出不直接转化为大规模失业 |
| **②税收依赖私人产出** | **不成立**：财政高度依赖**资源出口租金**（石油、天然气及其衍生的增值税与出口税） | 国家收入的首要来源不是资本的生产活动 |
| **③资本可以退出** | **成立但不对称**：资本可以外移，但**不能带走资源** | 国家握有不可移动的资产 |
| **④需要公众支持** | **结构性弱**：无实质选举竞争、媒体受控 | 资本的政治动员无法转化为选举压力 |

> ⭐ **根本区别**：
> - **中国**：国家依赖资本创造就业与税收，但禁止资本组织化 → **高依赖 + 低保障**
> - **俄罗斯**：国家**不主要依赖资本**，收入来自租金，且掌握不可移动的资产 → **低依赖 + 零保障**
>
> 这两者的差别不在于"谁更威权"，而在于**国家对资本的功能需求不同**。**需求决定议价，而不是制度决定议价。**

## 二、租金：一种不同的收入来源

### 2.1 租金的三个性质

| 性质 | 含义 | 政治后果 |
|---|---|---|
| **① 不依赖投资者** | 只要资源在地下、管道在运转，收入就进来 | 国家不需要"讨好资本" |
| **② 可被外部定价** | 收入主要取决于世界价格，不取决于国内制度质量 | 政府努力从"改善营商环境"转向"争夺定价权与渠道" |
| **③ 可集中收取** | 资源出口天然适合集中（管道、港口、出口许可） | 收入极易被中央控制，成为权力集中的物质基础 |

```
租金 → 中央财政 → 转移支付 + 公共部门工资 + 补贴
  ↓
地方政府与民众依赖中央而非本地资本
  ↓
地方无法形成与中央议价的独立经济基础
  ↓
"垂直权力"（вертикаль）有了物质支撑
```

### 2.2 租金与资源诅咒的差别（一个关键区分）

| 维度 | 一般的"资源诅咒" | 俄罗斯的形态 |
|---|---|---|
| **主要机制** | 荷兰病：汇率升值 → 制造业失去竞争力 | **有**，但**不是主导机制** |
| **核心后果** | 产业结构单一 | **国家—社会关系的重构**：国家成为分配者，民众成为受惠者 |
| **制度效果** | 削弱制度质量 | **明确地取消了"资本作为独立政治力量"的地位** |

> 📌 **俄罗斯的资源租金最重要的政治效果不是"让经济单一"，而是"让国家不再需要资本"**。这正是它与 [[中国：高决断力与低纠错力]] 的分岔点：**中国的国家需要资本，所以必须与资本维持一种有张力的共处；俄罗斯的国家不需要资本，所以可以做纯粹的支配。**

## 三、产权重定义：从寡头到国家化

### 3.1 三个阶段

| 阶段 | 时间 | 特征 | 资本地位 |
|---|---|---|---|
| **① 混乱私有化** | 1991-1999 | 休克疗法、私有化券、"贷款换股份" | **寡头获得巨大政治权力**（叶利钦时期的"家族"） |
| **② 国家收权** | 2000-2008 | 尤科斯事件、霍多尔科夫斯基入狱、能源资产重归国有 | **产权被证明是可撤销的** |
| **③ 租金体系固化** | 2008-2021 | 国有能源巨头 + 亲信控制的私营部门 + 大量国有银行 | **资本成为租金体系的附属与代理** |

### 3.2 尤科斯案的理论意义

**这不只是一次企业纠纷，而是产权规则的公开重定义**：

```
信号：任何重要资产的政治安全性 = 其所有者的政治忠诚
  ↓
推论一：资本不再按"投资回报率"做决策，而按"政治安全性"做决策
  ↓
推论二：安全资产（土地、管道、能源）成为最佳配置
  ↓
推论三：长期生产力投资（制造、研发、服务业）失去吸引力
  ↓
结果：经济结构进一步锁定在租金部门
```

> ⭐ **这是最重要的因果链条**：**产权不安全 → 资本不投资长期生产力 → 经济更依赖租金 → 国家更不需要资本 → 产权可以更不安全。**
>
> **这是一个自我强化的闭锁循环**，比单纯"制度质量差"更精确：**是国家的收入结构使它可以不在乎资本的长期行为，而资本的短视又使国家的收入结构更加依赖租金。**

### 3.3 资本的行为模式

| 表现 | 说明 |
|---|---|
| **资本外流** | 长期净外流（私人部门持有大量海外资产） |
| **安全资产偏好** | 伦敦、塞浦路斯、迪拜的房产与账户 |
| **"信得过的人"经济** | 重要行业由政治忠诚者掌握（不是最有能力者） |
| **不投长期项目** | 回报周期超过政治周期的项目几乎不投 |
| **退出优先于发声** | 与中国的资本同构：只能退出（见 [[中国：高决断力与低纠错力]]） |

## 四、个人化威权的决策结构

### 4.1 四种威权的区分

| 类型 | 合法性基础 | 决策方式 | 例子 |
|---|---|---|---|
| **技术官僚威权** | 绩效（增长、民生） | 精英协商、制度化试错 | 新加坡、改革期中国 |
| **党国威权** | 意识形态 + 组织 | 集体领导 + 派系平衡 | 中国（2012 前） |
| **个人化威权** | 领袖 + 秩序 | **个人最终决定，顾问只提供选项** | 俄罗斯、部分中东国家 |
| **帝王式总统制** | 领袖 + 民族叙事 | 个人 + 亲信网络 | 部分拉美、菲律宾 |

> 📌 **俄罗斯属于"个人化威权"**，其决策特征与"党国威权"在机制上根本不同：

| 维度 | 党国威权（中国） | 个人化威权（俄罗斯） |
|---|---|---|
| **信息来源** | 多层官僚体系（虽有失真但存在） | **顾问圈 + 安全部门**（更窄） |
| **纠错机制** | 内部派系压力 + 地方实验 | **几乎完全依赖个人** |
| **政策连续性** | 强（制度化） | **强但取决于个人偏好** |
| **继承风险** | 中（有制度化交接程序） | **极高**（无制度化继承机制） |
| **信息的系统性偏差** | 报喜不报忧 | **报"领导想听的"**——更严重 |

### 4.2 一个关键的结构性特征：**无人说真话**

```
顾问知道真实情况 → 但报告坏消息 = 质疑领袖的判断 = 高风险
  ↓
顾问倾向报告"可接受的现实"
  ↓
领袖越来越依赖小圈子与安全部门的信息
  ↓
安全部门的信息偏好是"威胁"，不是"经济"
  ↓
决策越来越基于安全逻辑而非经济逻辑
```

> ⭐ **这是个人化威权最深的脆弱点**：**它把"提供准确信息"变成了一项高风险行为**。在中国，信息失真来自**考核结构**（说真话扣分）；在俄罗斯，信息失真来自**人身风险**（说真话危险）。**后者更难纠正，因为前者可以通过改变考核指标部分修正，后者只能通过更换领袖修正。**

## 五、为什么这套系统在停滞中稳定

### 5.1 停滞的表现与不表现

| 维度 | 表现 |
|---|---|
| **长期增长率** | 2010s 后**低于全球平均**，2000s 的高增长（**约 7%**）主要来自油价上行 + 后危机恢复 |
| **生产率** | 长期低速，全要素生产率贡献低 |
| **人口** | **持续负增长**（叠加外流），劳动力收缩 |
| **社会秩序** | **稳定**（无大规模抗议的有效空间） |
| **民众生活** | 2000s **明显改善**（油价红利），2014 后**实际收入长期停滞** |
| **政权稳定性** | **高**（在 2022 年前） |

> 📌 **这就是"停滞中的稳定"**：**经济不增长，但政权不受威胁。**
> 原因：**租金足以维持基本分配 + 镇压能力充足 + 无组织化反对的合法空间 + 民族叙事提供替代性满足。**

### 5.2 一个重要的反直觉判断

> ⭐ **俄罗斯证明了：政权稳定性与经济绩效的关联，远低于通常假设。**
>
> **当国家收入不依赖民众的生产活动、也不依赖资本的投资时，"经济差 → 政权不稳"这条链条就断了。** 这与中国的处境形成鲜明对照——**中国的政权合法性高度依赖绩效，所以经济下行直接转化为政治压力；俄罗斯的政权合法性已经转向秩序与民族叙事，经济下行的政治传导要弱得多。**

## 六、战争经济的结构性后果（只作机制描述）

> ⚠️ **本节只分析经济结构的传导机制，不涉及军事战略、不评价战争本身。**

### 6.1 三个结构性变化

| # | 变化 | 机制 |
|---|---|---|
| **① 制裁与技术获取** | 高端技术、金融渠道、部分零部件被限制 → 生产效率与长期增长潜力受损 | 影响在**中长期**显现，短期可由库存与替代供应缓冲 |
| **② 军事凯恩斯主义** | 军工与相关制造业的产出与就业被强力拉动 | **短期提振 GDP**（国防支出计入 GDP），**长期挤出民用投资** |
| **③ 劳动力与人口** | 动员与移民外流叠加已存在的人口负增长 | 劳动力供给进一步收缩，工资上行压力（在部分行业表现为短缺） |

### 6.2 军事凯恩斯主义的性质

```
国防支出 → 需求（订单、工资、就业）→ GDP 上升
  ↓
但产出是"不可消费"的（武器、弹药）
  ↓
下一期没有对应的消费或生产能力形成
  ↓
净效果：把未来的生产能力转化为当下的 GDP 数字
```

> 📌 **这与"基建投资"在性质上不同**：基建至少留下可用的资本存量（尽管可能过剩）。**军工消耗品的当期产出不形成未来产能**，因此在会计上表现为"增长"，在实质上表现为"消耗"。
>
> **这也不是俄罗斯独有的机制**。任何以军事支出拉动总需求的经济体（战时英国、战时美国、冷战期苏联）都走过同一条路：**短期繁荣 + 长期产能折损**。

### 6.3 一个必须保持的不确定性

> ⚠️ **俄罗斯经济的实际表现比多数预测更有韧性**。原因包括：**能源出口的替代买家 + 平行进口 + 财政缓冲 + 强制结汇 + 资本管制 + 低债务起点（政府债务/GDP 相对低）**。**不能假设制裁必然导致经济崩溃**——这一点与本笔记的核心论点一致：**一个不依赖资本的国家，其经济韧性来自不同的来源。**

## 七、三向对照：租金型、绩效型、规则型威权

### 7.1 国家—资本关系的类型学

| 类型 | 国家收入来源 | 对资本的需求 | 资本的政治地位 | 例子 |
|---|---|---|---|---|
| **绩效型威权** | 资本的生产活动（税基） | **高** | 结构性权力高，政治性权力零 | **中国** |
| **租金型威权** | 资源租金 | **低** | **近乎无** | **俄罗斯、海湾国家** |
| **规则型威权** | 资本的生产活动 + 全球资本流入 | **极高** | **受尊重、被制度化保护** | **新加坡** |

> ⭐ **这个类型学是本笔记最有价值的产出**：
>
> - **中国**：需要资本 → 必须与资本共存 → 但不能让资本有政治力量 → **张力最大的组合**
> - **俄罗斯**：不需要资本 → 可以直接支配 → **最简单的组合，代价是经济长期停滞**
> - **新加坡**：极度需要资本 → 必须提供可预期性 → **外国资本与法治承诺（在政治领域之外）**
>
> **三种组合的差别不是"威权程度"，而是"国家对资本的功能依赖度"。**

### 7.2 为什么新加坡是威权国家的"最佳版本"

| 维度 | 俄罗斯 | 中国 | 新加坡 |
|---|---|---|---|
| **产权安全** | **低**（可撤销） | 中（可调整，规则可变） | **高**（规则清晰、不突袭） |
| **资本可预期性** | 低 | 中低 | **极高** |
| **长期投资意愿** | 低 | 中低 | **高**（区域总部密集） |
| **经济结果** | 停滞 | 放缓、转型困难 | 持续增长 |

> 📌 **新加坡证明了一件对理解中国最重要的事**：**威权不必然压制资本——它只会在没有功能性需要时压制资本。** 当一个威权国家**高度依赖资本**时，它会自愿建立**规则的可预期性**。详见 [[新加坡：威权与资本的可预期性]]。

## 八、判断与边界

### 8.1 三个可检验的判断

| # | 判断 | 检验方式 |
|---|---|---|
| **1** | **资源租金使国家可以不依赖资本** | 检查资源国的财政结构中资源收入的占比与资本税基的关系 |
| **2** | **产权不安全与租金依赖互为因果，形成闭锁循环** | 观察资源国是否长期出现"资本外流 + 生产力投资不足 + 租金依赖加深" |
| **3** | **个人化威权把"说真话"变成高风险行为，信息质量尤差** | 观察重大决策是否长期依赖小圈子来源 |

### 8.2 必须声明的边界

> ⚠️ **本笔记不做的事**：
> 1. **不预测俄罗斯政权的稳定性或继承结果**。个人化威权在停滞中稳定，但**继承是其结构性弱点**，这一点无法预测时点。
> 2. **不假设制裁必然导致崩溃**。已观察到的事实与之相反：经济表现出的韧性高于多数初始预测。
> 3. **不把俄罗斯当"中国的未来"**。两者在国家—资本关系上是**不同类型**，机制不可直接移植。

### 8.3 一句话总结

> **俄罗斯是"资本的结构性权力"理论的边界案例：当一个国家的收入不来自资本的生产活动时，资本的所有威胁都失效了——代价是这个国家也失去了一个能自我更新、能提供长期增长的经济基础。**
