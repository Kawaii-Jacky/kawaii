# 新加坡：可预期性作为资本的核心需求

> - **核心问题**：新加坡是一个长期一党执政、媒体受限、无真正竞争性选举的威权国家——但它同时是全球资本最信任的司法辖区之一。**资本不害怕威权，那资本害怕什么？** 如果"威权 = 资本逃离"这个直觉是错的，那么在资本与国家的关系中，真正起决定作用的变量是什么？
> - **叙事逻辑**：新加坡的制度悖论 → 它凭什么留住资本（五个可预期性来源）→ 这套设计的历史条件（李光耀的初始禀赋）→ 国家资本主义的另一面（淡马锡、GIC、组屋）→ 分配结构（为什么没有爆发）→ 与中国的对照（1990-2015 做到了，2018 后放弃了）→ 收束：可预期性是可被制度化，也可被主动放弃的
> - **立场说明**：新加坡不是"模式"，而是**一个关于"资本到底需要什么"的思想实验**。它的价值在于把"威权 vs 民主"这个二分法拆开——**决定资本信心的是"可预期性"，而可预期性是独立于政体形式的变量**。这对理解中国 2018 年后的 FDI 变化至关重要。
> - **来源标注**：新加坡统计局（Singstat）、新加坡金融管理局（MAS）、《经济学人》民主指数与全球治理指标、世界银行营商环境报告、透明国际腐败感知指数、遗产基金会经济自由度指数、淡马锡与 GIC 年报；综合分析为笔记作者原创，2026-09-20。

## 一、制度悖论：威权 + 资本信心

### 1.1 事实清单

| 维度 | 新加坡的实际状况 |
|---|---|
| **政体** | 人民行动党（PAP）自 1959 年起持续执政（**超过 65 年**） |
| **选举** | 有选举，但**集选区制度（GRC）+ 选举局控制 + 反对党受限**，结果高度可预期 |
| **媒体** | 主流媒体受政府控制（SPH 重组、外国媒体法律约束） |
| **言论** | **诽谤诉讼、POFMA（反假信息法）** 等手段约束批评 |
| **结社** | 工会（NTUC）与政府紧密结合；独立工会与抗议受限 |
| **人身自由** | 有内部安全法（ISA）的无审判拘留权 |
| **死刑** | 保留（毒品犯罪） |
| **民主指数** | "部分自由"/"混合政体"级别 |

**而同时**：

| 维度 | 新加坡的排名 |
|---|---|
| **营商环境** | 长期全球前 2-3 |
| **腐败感知指数** | 长期全球前 5 |
| **经济自由度** | 长期全球前 2 |
| **法治指数** | 极高（合同执行、产权保护） |
| **外资流入** | 亚洲人均最高的 FDI 目的地之一 |
| **跨国企业区域总部** | 数千家（亚太区域中心密度最高） |

> **这是一个真实的悖论：一个在政治权利上受限的国家，同时在资本需要的所有维度上都表现优异。**

### 1.2 这个悖论为什么让很多人困惑

**流行的隐含假设**：

> "资本需要民主" / "威权会吓跑资本"

**新加坡证伪了这个假设。**但它不是唯一的反例：

| 反例 | 说明 |
|---|---|
| **新加坡** | 威权 + 极高资本信心 |
| **海湾国家（阿联酋、卡塔尔）** | 绝对君主制 + 资本自由流动 |
| **香港（1997-2019）** | 非民主 + 极高资本信心 |
| **越南** | 一党制 + FDI 快速增长 |

**反过来的反例**：

| 反例 | 说明 |
|---|---|
| **印度** | 民主 + 资本信心相对低（税收追溯、征地困难） |
| **阿根廷** | 民主 + 资本反复逃离 |
| **南非** | 民主 + 资本持续外流 |

> **所以"民主 → 资本信心"这条链是不成立的。**需要换一个变量。

## 二、新加坡凭什么留住资本：五个可预期性来源

### 2.1 来源一：财产权不可侵犯（对政治动机的没收）

**这是最核心的一条**。

| 制度安排 | 内容 |
|---|---|
| **普通法传统** | 继承英国普通法，判例法体系，合同可执行 |
| **司法独立** | 国际商业法庭（SICC）设立，法院在国际商事案件中可信 |
| **无政治性没收** | **从未发生过针对特定企业的政治性国有化或强制出售** |
| **外资可全资** | 大多数行业允许外资 100% 控股（与中国的合资要求形成对比） |
| **资金自由** | **无资本管制**，资金进出自由 |
| **货币** | 新加坡元可自由兑换，MAS 以汇率为货币政策工具 |

> 📌 **资本不怕"政府强"，资本怕"政府可以随时改主意且不用付代价"。**
>
> **新加坡的政府很强，但它**自我约束**——把"不没收"变成了可预期的规则。**

### 2.2 来源二：政策连续（跨数十年的方向不变）

| 政策方向 | 持续时间 |
|---|---|
| **开放贸易与投资** | 1960s 至今 |
| **低税率** | 持续 |
| **英语为商业语言** | 持续 |
| **不搞福利主义（但持房率高）** | 持续 |
| **不搞反对派政治** | 持续 |
| **亲跨国公司** | 持续 |

> **政策的可预期性 = 投资决策的可行前提。**一个需要十年回本的项目，无法在"政策每三年变一次"的环境里成立。
>
> **新加坡的政策连续性超过大多数民主国家** ——因为民主国家的政策会随执政党更替而转向。

### 2.3 来源三：行政效率与无腐败

| 维度 | 表现 |
|---|---|
| **公司注册** | 数小时至一天 |
| **施工许可** | 极快 |
| **跨境贸易** | 全球最快之一 |
| **腐败** | 极低（腐败感知指数长期前 5） |
| **官僚素质** | 高薪养廉，精英招募 |

> **行政成本的可预期性，与法律的可预期性同等重要。**一个企业能容忍高税，但不能容忍"不知道要付多少、给谁、什么时候"。

### 2.4 来源四：要素与市场的开放性

| 维度 | 新加坡 |
|---|---|
| **关税** | 几乎为零 |
| **外资准入** | 极宽 |
| **资本账户** | **完全开放** |
| **人才引进** | 极积极（Employment Pass、Global Investor Programme） |
| **税收** | **低企业所得税（约 17%）**、**无资本利得税**、**无遗产税** |
| **税收协定网络** | 极广 |

### 2.5 来源五：**"拿走"的成本被制度化**（这一点最少被提及，但可能是最关键）

> **新加坡的威权有清晰的边界**：它**压制政治**（反对党、媒体、集会），但**不碰经济产权**。
>
> **这个边界是稳定的、可学习的、可预期的** —— 投资者知道什么会被禁止（政治动员），什么不会被禁止（经营、持有、转出）。

**对照中国 2018 年后的变化**：

| 领域 | 之前的边界 | 之后的变化 |
|---|---|---|
| **经营** | 不碰 | **平台整顿、教培清零、游戏版号** |
| **持有** | 不碰 | 相对安全 |
| **转出** | 部分受限 | **收紧（边控、外汇审查、34 条新规）** |
| **政治表态** | 不碰（企业家被默许沉默） | **被要求表态、被迫"感恩"** |
| **边界本身** | **可预期** | **不可预期（因为边界可以被临时重划）** |

> **这就是"可预期性"的核心含义**：
>
> **不是"限制少"，而是"限制的边界稳定"** ——**投资者可以绕开已知的红线，但无法绕开随时移动的红线。**

## 三、这套设计的历史条件

**新加坡的成功，依赖于一组特定的初始禀赋。这些条件大多不可复制**：

| # | 条件 | 内容 | 可复制性 |
|---|---|---|---|
| **①** | **极小的人口与面积** | 约 570 万人口、约 730 平方公里（约为北京的 1/23） | ❌ 不可复制 |
| **②** | **城市国家** | 无农村、无区域差距、无城乡二元结构 | ❌ 不可复制 |
| **③** | **地理咽喉** | 马六甲海峡，全球最繁忙的航运通道 | ❌ 不可复制 |
| **④** | **李光耀的长期执政** | 1959-1990 执政 31 年，之后以其他身份继续影响 | ❌ 不可复制（也因个人因素） |
| **⑤** | **精英官僚体系** | 从英国殖民时期继承的高效行政传统 + 高薪招募 | ⚠️ 难复制 |
| **⑥** | **外部安全依赖** | 依赖美国的安全伞（同时与中国保持经济联系） | ⚠️ 难复制 |
| **⑦** | **英语与普通法** | 殖民遗产，直接对接国际商业体系 | ⚠️ 难复制 |
| **⑧** | **高储蓄 + 强制公积金（CPF）** | 强制储蓄率极高，为国家投资提供资金 | ✅ 部分可复制 |

**关键判断**：

> **新加坡是一个"城市国家 + 地理咽喉 + 英国遗产 + 强人政治"的组合结果。**
>
> **它的经验对大国（中国、印度、美国）的适用性极低** ——**规模的非线性效应**（见 [[储蓄-出口模式的政治经济学：权力、阶级与转型困境]] 第七节）意味着：
>
> - 570 万人可以靠"吸引全球资本与人才"致富
> - **14 亿人不可能**（因为全球没有那么多的资本和人才可吸引，且内部差距无法通过外部输入解决）

## 四、国家资本主义的另一面

**新加坡不是"自由市场"，它是"国家主导的资本主义"。**这一点常被忽略。

### 4.1 国家资本的两个载体

| 机构 | 性质 | 规模（量级） |
|---|---|---|
| **淡马锡（Temasek）** | 主权投资公司，持有新加坡政联公司（GLC）股权 | 数千亿新元 |
| **GIC（政府投资公司）** | 管理外汇储备 | **数千亿美元级** |

**这两个机构的意义**：

> **新加坡政府不仅"监管"经济，它还是最大的股东。**
>
> **淡马锡持有的企业包括**：新加坡航空、新电信、星展银行、PSA 国际港务、新加坡电力等——**几乎每一个关键行业。**

### 4.2 与中国的相似与差异

| 维度 | 新加坡 | 中国 |
|---|---|---|
| **国家持有企业** | ✅ 广泛（淡马锡、GIC） | ✅ 广泛（央企、地方国企） |
| **国家对企业的政治控制** | ❌ **不干预经营**（淡马锡明确不参与日常经营） | ✅ **党委进企业、党建、政治要求** |
| **目标** | **商业回报**（淡马锡的回报率是硬指标） | **混合**（利润 + 就业 + 政策目标 + 政治控制） |
| **透明度** | 高（淡马锡发布年报、接受市场评估） | 低 |
| **资本自由** | ✅ 完全 | ⚠️ 管制 |
| **外资待遇** | **等同国民** | 差异化 |

> **关键差异：新加坡的国家资本主义是"国家作为股东"，中国的国家资本主义是"国家作为所有者 + 管理者 + 政治领导"。**
>
> **前者保留了资本逻辑（要回报、要效率），后者混入了政治逻辑（要稳定、要控制、要就业）。**
>
> **这就是为什么淡马锡能赚钱，而中国国企的回报率长期低于民企。**

### 4.3 组屋制度（HDB）：一个真实的分配成就

| 制度 | 内容 |
|---|---|
| **建屋发展局（HDB）** | 1960 年成立，大规模建设公共住房 |
| **覆盖率** | **约 80% 的居民住在组屋**，其中约 90% 拥有产权 |
| **资金来源** | 强制公积金（CPF）+ 土地征收法 |
| **土地获取** | **1966 年《土地征收法》，允许政府以低价征地** |

> 📌 **注意最后一条**：**新加坡的高住房自有率，建立在一个允许政府低价征地的法律基础上。**
>
> **这与中国的土地财政有结构上的相似性**（见 [[土地财政的双重依赖：流量与存量的断裂]]），**但结果不同**：
> - 新加坡：征地 → 建组屋 → **低价卖给居民**（国家补贴居民）
> - 中国：征地 → 招拍挂 → **高价卖给开发商 → 高价卖给居民**（居民补贴国家）

**这是同一个工具的两个方向**：

> **新加坡用土地垄断来"补贴居民"，中国用土地垄断来"抽取居民"。**
>
> **差异的根源不在土地制度，而在政治结构** ——**新加坡需要选票（即使是不公平的选举，也要维持基本的民意基础）；中国的政治约束来自上而非下。**

## 五、分配结构：为什么新加坡没有爆发

**新加坡的基尼系数（税前）很高（约 0.45-0.47），但**：

| 机制 | 效果 |
|---|---|
| **组屋** | 80% 人口有住房产权 → 有资产 |
| **CPF（强制公积金）** | 强制储蓄 → 人人有账户 |
| **低税 + 补贴的混合** | 中低收入有直接补贴（Workfare、GST 补助） |
| **外籍劳工的分层** | **不平等的负担被转移给外籍劳工**（他们无投票权、无长期居留权） |
| **精英高薪** | 部长与高级公务员薪资全球最高（"高薪养廉"） |

**关键判断**：

> **新加坡的不平等是真实的，但它的"底层"主要是外籍劳工（约占劳动力的三分之一以上）。**
>
> **本国公民被组屋、CPF、补贴所覆盖，且有投票权（即使有限）** ——**这使不满的规模被限制在"无政治权能"的群体内。**

**对照中国**：

| | 新加坡 | 中国 |
|---|---|---|
| **谁是不平等的承担者** | **外籍劳工**（无投票权） | **农民工**（无市民权） |
| **是否有政治表达** | 都没有 | 都没有 |
| **但有区别** | **外籍劳工可以回国（退出）** | **农民工无法退出（户籍在原籍，但无城市权）** |

> **两者都用"外来者"承担不平等的成本，但新加坡的外来者可以退出，中国的农民工不能。**
>
> **这是一个重要的差异**：新加坡的结构之所以稳定，部分因为它给不满者**留了一个出口**；中国的结构则把不满者**留在原地且无出口**。

## 六、与中国的对照：可预期性是可被主动放弃的

### 6.1 中国曾经（1990-2015）做到了类似的事

| 新加坡的做法 | 中国 1990-2015 的对应 |
|---|---|
| **产权保护** | 物权法（2007）、公司法、合同法的建立 |
| **政策连续** | 加入 WTO（2001）提供对外承诺 |
| **行政效率** | 地方政府的"招商引资"竞争 |
| **外资开放** | FDI 优惠、合资、经济特区 |
| **不碰经营** | 民营企业家被默许积累财富（"让一部分人先富起来"） |
| **政治沉默换经济自由** | 企业家不参政，政府不干预经营 |

**结果**：中国成为全球最大的 FDI 目的地之一，加入 WTO 后出口爆炸式增长。

### 6.2 2018 年后的变化

| 领域 | 变化 |
|---|---|
| **平台经济** | 蚂蚁 IPO 叫停（2020）、反垄断、数据合规 |
| **教培** | 全行业清零（2021） |
| **游戏** | 版号冻结 |
| **房地产** | 三条红线（2020） |
| **资本流动** | 外汇审查、34 条新规、边控 |
| **企业家表态** | 被要求"感恩"、"共同富裕"表态 |
| **政治参与** | 党建进民企、党组织全覆盖 |

**结果**：

| 指标 | 变化 |
|---|---|
| **FDI** | 转为净流出（近年首次出现负值） |
| **民营投资** | 显著下降 |
| **超额储蓄** | 居民与企业存款高企 |
| **企业家移民** | 上升 |
| **境外上市** | 大幅减少（VIE 结构受限，见 [[小红书IPO折戟与期权清零案：VIE架构矛盾、劳动纠纷与上市合规风波深度拆解]]） |

### 6.3 核心判断

> **新加坡证明：威权可以留住资本——前提是自我约束，把"不碰经营"变成稳定的制度规则。**
>
> **中国在 1990-2015 年大致做到了这一点；2018 年后主动放弃了它。**
>
> **放弃的方式不是"加大限制"（限制本身不一定吓跑资本），而是"使边界不可预测"** ——
>
> **一个可以今天允许、明天禁止的环境，比一个从一开始就禁止的行业更难投资。**

**这解释了一个反直觉的现象**：

> **为什么"整顿教培"吓跑的是"做新能源的"？**
>
> **因为教培的整顿传递的信息不是"教培不能做"，而是"任何行业都可能被一夜清零"。**
>
> **这个信息是对全部资本的，不只是对教培的。**

## 七、收束：四个判断

### 7.1 判断一：资本不怕威权，怕不可预期

> **新加坡、海湾国家、1997-2019 的香港、越南都证明了这一点。**
>
> **资本真正需要的**：
> 1. 财产权不可被政治动机侵犯
> 2. 政策的边界稳定（红线不动）
> 3. 合同可执行
> 4. 资金可进出
> 5. 行政成本可预测
>
> **这五项与政体形式无关。**

### 7.2 判断二：可预期性是"自我约束"的产物，不是"自由度"的产物

> **新加坡的政府很强，但它对资本**自我约束** ——**它把"不碰经营"变成了稳定的规则，即使在它可以随时改变的时候。
>
> **自我约束的价值恰恰在于"本可以不这么做"** ——**一个无权侵犯产权的政府保护产权不算承诺；一个有权侵犯却选择不侵犯的政府保护产权，才是可信的承诺。**

### 7.3 判断三：这套设计的可复制性极低（因为规模）

> **570 万人的城市国家 + 马六甲咽喉 + 英国遗产 + 强人政治** ——这是一个独特的历史巧合。
>
> **它的经验对 14 亿人口的大国几乎不适用。**"新加坡模式"在中国语境下常被误用为"证明威权可以成功"，但**它更准确的教训是"小国的成功需要小国的条件"**。

### 7.4 判断四：可预期性可以被主动放弃——这是最危险的信号

> **中国 2018 年后的 FDI 变化，不是因为限制变多了，而是因为规则的边界开始移动。**
>
> **而"边界移动"这件事，无法通过对某个具体行业的放松来修复** ——**它需要的是"承诺不再移动"的制度化机制（独立的司法、可被追责的规则、稳定的立法程序），而这意味着政治改革。**
>
> **这就是为什么"改善营商环境"的政策在实际效果上有限** ——它解决的是具体限制，而问题在"边界的稳定性"。

## 八、对中国的三条直接启示

| # | 启示 |
|---|---|
| **1** | **"威权留不住资本"是错的；"威权 + 可预期"能留住资本** ——中国曾经做到过（1990-2015） |
| **2** | **不可预期性是资本最怕的东西，而它没有政策解药** ——放松某个行业无法重建信心，只有"承诺不再移动边界"才能，而这需要制度性自我约束 |
| **3** | **新加坡的核心教训不是"威权也可以成功"，而是"强政府必须自我约束才能留住资本"** ——这是对中国的直接反讽：它比任何民主国家都更需要证明自己会守规则 |
