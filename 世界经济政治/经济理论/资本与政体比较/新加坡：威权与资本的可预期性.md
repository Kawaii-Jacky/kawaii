# 新加坡：威权与资本的可预期性

> - **核心问题**：一个没有实质政治竞争、没有新闻自由、有强大国有企业、且曾公开驱逐外资媒体的政府，为什么长期是全球资本最偏好的落点之一？资本究竟害怕威权的哪一部分？
> - **叙事逻辑**：一个必须解释的反例 → 资本真正害怕的不是威权而是不可预测 → 新加坡是怎么做到可预测的（五根支柱）→ 国有企业为什么反而增加了可信度 → 组屋制度如何替代了财政转移的政治功能 → 这套模式的三个不可复制条件 → 与中国、俄罗斯、美国的四方对照 → 对中国的直接含义 → 收束
> - **立场说明**：本笔记**不评价新加坡的政治制度是否可取**，只分析**一个国家如何在威权结构下为资本提供高水平的可预期性**。核心论点是可操作的：**资本定价的不是"自由"，是"不确定性"**。这个命题对中国的政策含义极其直接——**在保持现有政治结构不变的条件下，仍有很大的空间降低资本的制度不确定性。**
> - **来源标注**：新加坡统计局（SingStat）、新加坡金融管理局（MAS）、财政部预算文件、GIC 与 Temasek 年度报告、HDB 年度报告、EDB 投资数据、World Bank 治理指标（Rule of Law / Regulatory Quality / Government Effectiveness）、Heritage 与 Fraser 经济自由指数；政治经济学文献为 Lee Kuan Yew、W. G. Huff、Linda Lim、Simon Tay 等；综合分析与理论判断为笔记作者原创，2026-09-19。

## 一、必须解释的反例

### 1.1 三个并列的事实

| 事实 | 内容 |
|---|---|
| **政治** | 人民行动党自 1959 年起持续执政；反对党长期弱小；政治性言论与集会受限制；诽谤诉讼被用于对付批评者 |
| **经济** | 人均 GDP 从 1960s 的极低水平升至极高收入国家行列；长期高增长；产业结构持续升级（制造 → 金融 → 生物医药 → 科技） |
| **资本** | 数千家跨国公司区域总部；全球最重要的金融与资管中心之一；外资长期净流入 |

> 📌 **这三件事同时成立，推翻了两个常见的简单判断**：
> - **"没有民主 → 资本不敢来"**（错误）
> - **"威权 → 资本只能靠强迫"**（错误）
>
> **正确的解释必须同时说明：资本在一个威权国家里为什么感到安全。**

### 1.2 资本的真正恐惧

| 恐惧的对象 | 是否致命 | 例子 |
|---|---|---|
| **税率高** | 不致命 | 北欧高税负但资本充裕 |
| **劳动管制严** | 不致命 | 德国、日本 |
| **国有部门大** | 不致命 | 挪威主权基金、法国国有部门 |
| **不能投票** | 不致命 | 大量资本投向无投票权的市场 |
| **政策不可预测** | **致命** | 突如其来的没收、规则追溯、行业整顿、司法不独立 |

> ⭐ **核心命题**：**资本定价的不是"自由"，是"不确定性"。**
>
> 一个**规则稳定的威权国家**，对资本的价值高于一个**规则不稳定的民主国家**。这不是道德判断，是资本回报率的算术：**不确定性直接进入折现率**。

### 1.3 用一句话说清新加坡与俄罗斯的区别

| | 俄罗斯 | 新加坡 |
|---|---|---|
| **资本的政治权力** | 无 | 无 |
| **产权安全性** | **低**（可撤销） | **高**（规则清晰、不追溯） |
| **政策可预期性** | **低** | **极高** |
| **资本的行为** | 外逃、短视、安全资产 | **长期投资、区域总部、再投资** |
| **结果** | 停滞 | 持续升级 |

> 📌 **两个都是威权，都限制资本的政治权力，结果完全不同。** 关键变量是**可预期性**。

## 二、新加坡怎么做到了可预期：五根支柱

### 2.1 支柱一：规则清晰、不追溯、不突袭

| 做法 | 内容 | 与"突袭式管制"的对比 |
|---|---|---|
| **政策提前咨询** | 重大税制与监管变化通常提前预算公布、并有过渡期 | 对照：追溯性加税、突然行业整顿 |
| **外资规则稳定** | 允许外资在绝大多数行业独资；负面清单明确 | 对照：隐性准入限制、许可随意性 |
| **契约可执行** | 司法体系专业、商业案件可预期、仲裁受国际认可 | 对照：案件结果受政治影响 |
| **税制不追溯** | 优惠政策即使被取消，通常不追溯既有投资 | 对照：政策一变，已有投资的假设被推翻 |
| **官僚专业且可接近** | EDB、MAS 等机构以"服务投资者"为组织文化 | 对照：审批寻租、部门推诿 |

> ⭐ **这一支柱是全部五根中最重要的**。它不要求政治自由，只要求**行政与司法的自我约束**。

### 2.2 支柱二：政策连续性与长期规划能力

| 机制 | 内容 |
|---|---|
| **长任期技术官僚** | 高级公务员体系稳定、专业、与政治任命分离度相对高 |
| **制度化规划** | 五年经济规划、土地长期储备、水资源长期规划（跨数十年） |
| **政策不因选举摆动** | 无政权更替 → 无需为短期民意牺牲长期政策 |
| **明确的产业升级路径** | 从劳动密集 → 技能密集 → 资本密集 → 知识密集，每一阶段有具体工具 |

> 📌 **这与中国和新加坡的共性是"长视野"，与美国的差别也在这里。** 但新加坡把长视野**制度化为可预期的规则**，而不是让长视野变成"方向不可质疑"（见 [[中国：高决断力与低纠错力]]）。

### 2.3 支柱三：宏观稳定作为最高优先

| 工具 | 内容 |
|---|---|
| **汇率作为主要货币政策工具** | MAS 管理新加坡元名义有效汇率区间（不是利率） |
| **强制储蓄（CPF）** | 中央公积金：强制储蓄替代部分福利支出 |
| **财政规则的自我约束** | 宪法要求预算平衡（运营收支），动用储备需总统批准 |
| **不搞大规模赤字** | 无外债、低政府债务、财政长期盈余 |

> ⭐ **这一支柱的政治含义被长期低估**：**财政纪律是威权的信用凭证。** 当政府证明自己不会为了短期政治需要而滥发货币或借债时，**资本相信它对产权的承诺也更可信**。

### 2.4 支柱四：精英吸纳——把最危险的人变成合伙人

```
优秀学生 → 政府奖学金 → 顶级大学 → 回国进入公务员体系 / 政联公司 / GLC
  ↓
最聪明的头脑被吸纳进体制
  ↓
高薪（部长与高级公务员薪酬对标私人部门顶尖水平）
  ↓
反对的成本 > 合作的收益
  ↓
"异议精英"的供给被结构性压制
```

> 📌 **这是新加坡模式中最精妙的一环**：**它不靠镇压消灭反对，而靠吸纳消除反对的动机。** 这也意味着：**新加坡的稳定依赖于"体制内的高回报"这一持续条件**——一旦薪酬竞争力下降或机会收窄，这个机制会减弱。

### 2.5 支柱五：国家资本作为一种"信用锚"

**GIC（政府投资公司）、Temasek（淡马锡）、MAS（金融管理局）** 构成了三根主权资本支柱。

| 机构 | 职能 | 对资本可预期性的作用 |
|---|---|---|
| **GIC** | 管理外汇储备，长期全球资产配置 | 国库有巨大缓冲 → 不需要临时征税或掠夺资本 |
| **Temasek** | 持有并经营国有股权 | 国有资本按商业逻辑运作、公开披露 → **证明国家不会随意干预商业** |
| **MAS** | 央行 + 金融监管 | 独立专业的技术声誉 |

> ⭐ **反直觉但关键**：**新加坡庞大的国有部门不是资本的风险，而是资本的信用锚。**
> 逻辑是：**政府自己的钱也在市场里，而且投的是长期全球资产 → 政府有直接动机维护产权与法治 → 政策承诺因此可信。**
>
> 对照俄罗斯：**国家也持有大量资产，但运作方式是政治性的（忠诚者管理、可撤销产权）→ 国有资产变成了威胁而非承诺。**

## 三、组屋制度：一个被严重低估的政治设计

### 3.1 机制

```
HDB（建屋发展局）大规模建屋
  ↓
政府在土地征用法下以低成本取得土地（早期）
  ↓
组屋以低于市场价出售给公民（99 年租赁权）
  ↓
公民用 CPF（强制储蓄）支付首付与月供
  ↓
多数公民拥有住房 + 资产升值
  ↓
① 财富效应 → 生活满意
② 强制储蓄 → 储蓄率极高 → 支撑投资与金融中心
③ 抵押关系 → 对金融稳定的直接利益
④ 社区结构 → 种族配额、选区划分与住房绑定
```

### 3.2 与中国的直接对照

| 维度 | 新加坡 | 中国 |
|---|---|---|
| **土地制度** | **土地征用法**下国家取得，但**大规模用于公共住房** | 地方垄断供地，**主要用于商业与高价住宅** |
| **住房作用** | **稳定器**（多数人拥有，价格受管理） | **融资工具**（土地出让金是地方财政核心） |
| **财政角色** | 组屋是**支出**（补贴） | 土地是**收入**（出让金） |
| **社会效果** | **去商品化 + 资产化并存** | **过度金融化 + 代际债务转移** |
| **政治效果** | **稳定**（多数人受益） | **风险集中**（见 [[土地财政的政治经济学：攫取、崩溃与代际剥削]]） |

> 📌 **这是本笔记对中国最有价值的一条对照**：
> **同样是"国家掌握土地 + 与住房制度结合"，新加坡把它做成了稳定器，中国把它做成了融资工具。** 差别不在于"是否威权"，而在于**土地收入的用途与住房的定位**。
>
> 一个关键区别：**新加坡政府把土地当作必须被管理的公共资源，中国政府把土地当作了可贴现的财政资产。**

## 四、三个不可复制的条件

> ⚠️ **新加坡模式的可复制性被严重高估。它依赖至少三个难以复制的条件：**

| # | 条件 | 为什么难以复制 |
|---|---|---|
| **① 城邦尺度** | 约数百万人口的城市国家 | **治理可以高度中央化、政策可以快速调整、精英可以被完全吸纳**。大国无法做到——中国的一个省就超过新加坡的人口 |
| **② 战略位置红利** | 马六甲海峡、区域金融与航运中心 | 地理 + 历史窗口（冷战期间美国的安全保护伞、区域不稳定带来的资本流入） |
| **③ 建国时刻的共识** | 从马来西亚分离后的生存危机 | **外部威胁创造了"必须合作"的初始共识**，使动员、纪律、长视野成为可能。后来者没有这个初始条件 |

**还有第四个隐含条件**：

| **④ 人才与人口的可控性** | 通过移民政策精确调控人口结构、技能组合与族群比例 | 大国无法做到 |

> ⭐ **结论**：**新加坡是一个"小样本条件下的最优解"，不能作为大国改革的模板。** 但**它在原理层面的启示是可推广的**：**可预期性可以由政治意志单方面提供，不需要民主化**。

## 五、四方对照

### 5.1 资本可预期性矩阵

| 维度 | 新加坡 | 中国 | 美国 | 俄罗斯 |
|---|---|---|---|---|
| **政治竞争** | 无实质 | 无 | 高 | 无实质 |
| **新闻自由** | 受限 | 受限 | 高 | 受限 |
| **产权安全** | **高** | 中 | 高 | **低** |
| **规则稳定性** | **极高** | 中低 | 高 | 低 |
| **国有部门** | 大但商业化 | 大且政策性 | 小 | 大且政治化 |
| **资本的政治权力** | 无 | 无 | **高** | 无 |
| **资本的实际行为** | **长期投资** | 观望/短期 | 长期 + 政治参与 | 外逃 |
| **长期一致性** | **极高** | 高（但方向可急转） | 低 | 中 |

### 5.2 三种威权国家的资本关系

| | 中国 | 新加坡 | 俄罗斯 |
|---|---|---|---|
| **国家对资本的需求** | 高 | **极高** | 低 |
| **资本的政治权力** | 无 | 无 | 无 |
| **资本得到的回报** | **不确定性** | **可预期性** | **可撤销性** |
| **决定性约束** | 合法性框架不允许承认错误 | 依赖资本 → 必须提供可预期性 | 不依赖资本 |
| **结果** | 增长放缓 + 转型困难 | 持续升级 | 停滞 |

> ⭐ **三方对照给出的最重要判断**：
> **在三个都没有政治自由的国家里，资本待遇的差别不来自"威权强度"，而来自"国家对资本的功能依赖度"。依赖越深，资本得到的可预期性越高。**
>
> **这给中国一个明确的、不涉及政治结构改革的改进方向。**

## 六、对中国的直接含义

### 6.1 新加坡模式中真正可学的三件事

| # | 可学项 | 具体内容 |
|---|---|---|
| **① 规则不突袭** | 政策制定前咨询、设过渡期、不追溯——**不需要民主化即可做到** | 直接降低资本的不确定性折现率 |
| **② 财政纪律作为承诺工具** | 用可核查的财政规则替代口头承诺 | 新加坡的宪法平衡要求是其信用的核心来源 |
| **③ 国有资本的商业化运作** | 把国有资本从"政策工具"部分转为"商业主体"，并**公开披露** | 使国有资产从风险来源变成信用锚 |

### 6.2 不能学、也不应学的三件事

| 不能学 | 原因 |
|---|---|
| **城邦治理尺度** | 人口与国土规模决定治理方式不同 |
| **全面限制政治竞争 + 高可预期性的组合** | 两者的兼容依赖新加坡特有的建国叙事与规模条件 |
| **完全依赖外部市场的经济结构** | 中国体量决定它必须是内需驱动的 |

### 6.3 一条最直接的政策含义

> ⭐ **"预期转弱"在中国官方文件中反复出现，但它常常被当作"信心的心理问题"来处理（座谈、表态、鼓励）。**
>
> **新加坡的经验说明它是制度问题**：资本的不确定性折现率**由规则的可预测性决定，而不由表态决定**。**在现有政治结构不变的条件下，中国完全有能力通过"规则不追溯、政策有过渡期、审批标准化、司法对商业纠纷可预期"来显著改善资本预期。**
>
> **这不是民主化问题，是行政自我约束问题。**

## 七、判断与边界

### 7.1 三个可检验的判断

| # | 判断 | 检验方式 |
|---|---|---|
| **1** | **资本定价的是不确定性，不是自由** | 比较规则稳定的威权国家与规则不稳定的民主国家的资本流入 |
| **2** | **国有资本商业化 + 高透明度 → 从风险源变成信用锚** | 比较 Temasek 与俄罗斯国有能源公司的运作方式与资本反应 |
| **3** | **土地 + 住房制度既可以是稳定器，也可以是融资工具** | 比较 HDB 与地方土地财政的资金流向 |

### 7.2 必须声明的边界

> ⚠️ **本笔记不做的事**：
> 1. **不主张新加坡模式应当被移植**。它的三个条件（城邦尺度、地理红利、建国共识）不可复制。
> 2. **不把"高可预期性"等同于"政治制度正当"**。本笔记只分析机制，不做正当性判断。
> 3. **不忽略新加坡模式的代价**：政治竞争的缺乏、对异见的法律压制、移民与人口政策的社会成本、以及对单一执政党继承机制的高度依赖——这些都是真实的成本，只是**不是本笔记的分析对象**。

### 7.3 一句话总结

> **新加坡的全部启示可以压缩成一句话：资本怕的不是威权，而是不可预测；而不可预测不是威权的必然属性，是行政选择的后果。**
