# 俄罗斯：资源租金、个人化威权与资本的零权力

> - **核心问题**：俄罗斯是唯一一个可以**任意掠夺资本**（尤科斯，2003）而**不承担投资崩溃后果**的主要经济体。为什么它能做到？因为它不需要资本。**同一个行为（没收私人企业）在俄罗斯是可行的，在中国是不可行的，在美国是不可想象的——差别不在政治意愿，在于国家对资本的依赖程度。**
> - **叙事逻辑**：资源租金如何改变国家-资本关系（三个变量的应用）→ 从混乱到国家夺回（1990s-2000s）→ 尤科斯分水岭 → 无纠错的代价（乌克兰战争）→ 与中国的对照（为什么中国不能走这条路）→ 与海湾国家的对照（同样是租金，为什么结果不同）→ 收束
> - **立场说明**：俄罗斯在本课题中不是"另一个威权样本"，而是**结构性权力理论的反证**。它证明：**国家对抗资本的能力，取决于国家能否在没有资本的情况下活下去**。科威特与委内瑞拉同样有石油，政治结果却相反——**这本身就是对"资源决定论"的反驳**。因此俄罗斯的价值在于它**分离出了"资源租金"这个变量**，让其余变量变得可见。
> - **来源标注**：俄罗斯联邦统计局（Rosstat）、俄罗斯中央银行、财政部的财政统计、IMF Article IV 报告、世界银行与 EBRD 转型报告；理论框架借自 Rentier State Theory（Beblawi & Luciani）、Guriev & Treisman《Spin Dictators》、Easter 关于俄罗斯石油政治的研究；综合分析为笔记作者原创，2026-09-20。

## 一、资源租金如何改变国家-资本关系

### 1.1 回到三个决定变量

**在 [[资本与国家的双向选择：结构性权力的三个决定变量]] 中提出的框架**：

| 变量 | 含义 | 高资本权力 | 低资本权力 |
|---|---|---|---|
| **① 资本流动性** | 资本能否"退出" | 可自由汇出、产业可搬迁 | 资产专用性强 |
| **② 国家的融资独立性** | 国家是否**必须**靠资本才能运转 | 依赖资本市场发债 | **有资源租金** |
| **③ 对抗力量的组织度** | 劳动/社会能否抵消资本 | 强工会、竞争性选举 | 工会被禁、结社受限 |

**俄罗斯的取值**：

| 变量 | 俄罗斯 | 后果 |
|---|---|---|
| **① 资本流动性** | ⚠️ 中（能源资产不可移动，但金融资本可外逃） | 部分约束 |
| **② 国家的融资独立性** | **极高（石油天然气租金）** | **资本的结构性权力被消灭** |
| **③ 对抗力量的组织度** | **极低**（工会被控、媒体被控、反对派被清除） | 无制衡 |

> **②是决定性的**：**当国家不依赖资本的投资来维持运转时，"资本罢工"这个武器就失效了。**
>
> **这就是俄罗斯可以掠夺资本的根本原因** ——不是因为它更强横，而是因为**它不需要资本的配合**。

### 1.2 租金国家的政治逻辑（Rentier State Theory）

**Beblawi & Luciani 的经典框架**：

| 特征 | 机制 |
|---|---|
| **租金（rent）而非利润（profit）** | 收入来自资源开采权，而非生产与销售 |
| **国家是租金的分配者** | 国家不需要向国民征税（租金来自外部） |
| **"不纳税 → 不代议"（no taxation without representation 的倒置）** | 国民不纳税，所以不要求政治权利 |
| **分配（allocation）取代生产（production）** | 政治的核心是争夺租金分配权，不是经济效率 |
| **精英是"分配性精英"** | 不创造价值，只分配租金 |

> 📌 **最后一条是关键**：**在租金国家，财富不来自"把蛋糕做大"，而来自"控制蛋糕的分法"。**
>
> **这解释了一个反直觉的现象**：**俄罗斯的寡头不是"资本家"，而是"租金的承包人"。**他们不生产，他们持有开采权和分配权。

### 1.3 一个形式化的对比

| | 生产型国家（中国） | 租金型国家（俄罗斯） |
|---|---|---|
| **国家收入的来源** | 税收（依赖企业利润） | **资源租金（不依赖）** |
| **国家的首要任务** | 让企业愿意投资 | **控制资源开采权** |
| **资本的角色** | **不可缺少的伙伴** | **可替换的承包人** |
| **资本的政治权力** | 高（可以用"不投资"威胁） | **几乎为零** |
| **国家的约束** | **必须维持商业信心** | **不需要** |
| **代价** | 不能任意掠夺资本 | **可以不掠夺，但经济停滞** |

## 二、从混乱到国家夺回（1990s-2000s）

### 2.1 1990 年代的"贷款换股份"（loans-for-shares）

**背景**：苏联解体后，叶利钦政府推行激进私有化（"休克疗法"）。

| 阶段 | 内容 |
|---|---|
| **1992-1994** | 凭证私有化（voucher privatization）：全民发券，但很快被集中收购 |
| **1995-1996** | **"贷款换股份"**：政府缺钱，让银行以贷款换取大型国企股份，贷款还不清则股份归银行 |
| **结果** | **寡头以极低价格获得石油、金属、镍等战略资产** |

**典型交易**：

| 企业 | 行业 | 实际支付（估） | 后来价值 |
|---|---|---|---|
| **尤科斯（Yukos）** | 石油 | **约 3 亿美元** | 数十亿美元级 |
| **诺里尔斯克镍业** | 镍/金属 | 约 1.7 亿美元 | 数十亿美元级 |
| **西伯利亚石油** | 石油 | 约 1 亿美元 | 数十亿美元级 |

> ⚠️ 数字为当时报道与学界估计的量级，不同来源差异较大。

### 2.2 1998 年危机与普京上台

| 时间 | 事件 |
|---|---|
| **1998** | 俄罗斯主权违约、卢布崩溃 |
| **1999** | 普京成为总理，后任代总统 |
| **2000** | 普京当选总统 |
| **2000-2003** | 建立"权力垂直体系"（power vertical），削弱地方、控媒体、压寡头 |
| **2003** | **尤科斯事件** |
| **2003-2008** | 油价从约 25 美元涨至 140 美元 → **财政大幅盈余** |

**2000 年代的关键条件**：

> **普京上台时，油价开始了一段历史性的上涨（2000-2008）。**
>
> **这给了他一个关键资源：不需要寡头的钱，也能填满国库。**
>
> **这就是"夺回"的财政基础。**

## 三、尤科斯：分水岭

### 3.1 事件经过

| 时间 | 事件 |
|---|---|
| **2003 年 7 月** | 尤科斯总裁霍多尔科夫斯基公开资助反对党、暗示参政 |
| **2003 年 10 月** | **霍多尔科夫斯基在新西伯利亚机场被捕** |
| **2004** | 尤科斯主要子公司（尤甘斯克）被**强制拍卖**，被国有石油公司（Rosneft）的关联方低价买下 |
| **2005** | 尤科斯被判欠税，资产被拆解 |
| **2006** | 尤科斯破产 |
| **2003-2013** | 霍多尔科夫斯基服刑 10 年（2013 年特赦后流亡） |

**结果**：

> **俄罗斯最大的私人石油公司被完全国有化，其创始人在机场被捕。**
>
> **这是 21 世纪最清晰的"资本零权力"的演示。**

### 3.2 为什么能做，为什么有效

| 条件 | 作用 |
|---|---|
| **油价上涨** | 国家不需要寡头的税收 |
| **能源资产不可移动** | **资本无法"退出"**（油田搬不走）——这是变量①的反例 |
| **政治控制** | 媒体被控、司法被控、反对派被压 |
| **寡头内部不团结** | 其他寡头没有共同防卫（因为"下一个不是我"） |
| **国际反应有限** | 当时欧美对俄依赖能源，不愿升级对抗 |

> 📌 **注意第 2 条**：**如果尤科斯是一家软件公司，它可以把工程师搬到塞浦路斯。但它是一口油井。**
>
> **这就是"资产专用性"（asset specificity）的意义** ——**资本的结构性权力，取决于它能否离开。**

### 3.3 后果：信心的永久损伤

| 指标 | 2003 年后 |
|---|---|
| **国内私人投资** | 长期低迷（除能源与国有部门外） |
| **资本外逃** | 持续（每年数百亿美元级，危机年份更高） |
| **FDI** | 除能源与资源外，几乎没有 |
| **企业家行为** | 要么依附国家，要么外逃 |
| **经济结构** | **进一步依赖资源（去工业化加速）** |

**关键判断**：

> **俄罗斯用"掠夺资本"换取了"国家控制"，代价是"没有资本愿意投资"。**
>
> **而因为它有石油，所以它可以承担这个代价** ——**它只是变得更"租金化"、更停滞了。**
>
> **这是"资源诅咒"的政治版本**：**资源租金使国家可以不依赖资本，因此国家失去约束，因此资本不投资，因此经济更加依赖资源。**

## 四、无纠错的代价

**这是俄罗斯与中国的关键结构差异，值得单独说清**。

### 4.1 库尔斯克号（2000）

| 时间 | 事件 |
|---|---|
| **2000 年 8 月** | 核潜艇库尔斯克号沉没，118 名船员全部遇难 |
| **关键细节** | **部分船员在沉没后存活数小时至数天**，有敲击声被探测到 |
| **政府反应** | **拖延数日才接受外国救援**，并对外信息不透明 |
| **后果** | 引发强烈公众愤怒，成为普京早期最大的公关危机 |

**意义**：**这是"无纠错机制 + 信息不透明"的教科书案例** ——**因为不愿示弱而拒绝外援，因为信息控制而延误救援。**

### 4.2 乌克兰战争（2022-）

| 层次 | 问题 |
|---|---|
| **情报层** | 对乌克兰抵抗意志与西方反应的严重误判 |
| **决策层** | **决策圈极小**（据说只有极少数人知情），无独立评估 |
| **执行层** | 军队不敢上报真实情况（与库尔斯克号同一个机制） |
| **纠错层** | 无法承认战略错误，只能不断加码 |

**核心机制**：

```
无独立媒体 → 无公开辩论
无竞争选举 → 无政治问责
无独立司法 → 无法律约束
无独立智库 → 无专业评估
无自由学术 → 无批评空间
  ↓
唯一的信息来源是下属汇报
  ↓
下属有强烈动机报喜不报忧
  ↓
决策者在一个失真的世界里决策
  ↓
错误直到不可挽回才被发现
```

> **这与 [[中国：高决断力、低纠错力与急转弯]] 第三节描述的机制完全同构** ——**信息过滤 → 问题积累 → 突然爆发。**
>
> **区别是规模与后果**：中国的错误通常表现为经济与政策的急转弯；俄罗斯的错误表现为一场全面战争。

### 4.3 一个更早的先例：苏联解体

| 层次 | 表现 |
|---|---|
| **经济** | 计划经济效率低下被长期掩盖（统计数据造假） |
| **政治** | 改革（戈尔巴乔夫）在体制无法承受时被迫启动 |
| **结果** | **改革 → 失控 → 解体**（1985-1991，仅 6 年） |

> **苏联的解体不是"被外部打败"，而是"内部信息的全面失真导致决策无法适应现实"。**
>
> **这是"无纠错机制"的最极端后果** ——**不是政策错误，而是体制本身的崩溃。**

## 五、与中国对照：为什么中国不能走这条路

### 5.1 关键差异表

| 维度 | 俄罗斯 | 中国 |
|---|---|---|
| **资源** | **石油、天然气、矿产（世界最大出口国之一）** | **无足够资源（石油进口依赖约 70%）** |
| **资源租金占财政** | **极高** | 低（土地财政是准租金，但有极限） |
| **对资本的依赖** | **低**（卖油就够了） | **高**（需要投资、技术、出口市场） |
| **资本的结构性权力** | **几乎为零** | **高（国家需要它）** |
| **能否任意掠夺资本** | ✅ 能（尤科斯） | ❌ 不能任意（会失去投资），但可"选择性惩罚" |
| **结果** | 可以掠夺，代价是停滞 | 不能掠夺，但可以压制 |
| **人口** | 约 1.4 亿 | 约 14 亿（**10 倍**） |
| **经济结构** | 高度依赖资源 | 制造业 + 出口 + 房地产 |

### 5.2 中国的"选择性惩罚"

**中国不能像俄罗斯那样全面掠夺资本，但它发展出了一种"中间形态"**：

| 形式 | 案例 | 性质 |
|---|---|---|
| **行业性归零** | 教培（2021） | 整个行业消失，但不动产权 |
| **个别性打击** | 蚂蚁 IPO 叫停（2020） | 针对特定企业，不没收资产 |
| **政治性要求** | 党建进民企、共同富裕表态 | 政治服从，不改产权 |
| **人身控制** | 边控（见 34 条新规） | 限制退出，不改产权 |
| **行政性审查** | 数据合规、反垄断、版号 | 增加不确定性，不改产权 |

> **核心区别**：
>
> **俄罗斯动的是"产权"（尤科斯被国有化），中国动的是"预期"（边界不可预测）。**
>
> **两者都降低了资本信心，但机制不同**：
> - **俄罗斯**：资本知道"如果被盯上，就没了" → **要么依附，要么外逃**
> - **中国**：资本知道"边界会移动，但不知道往哪移" → **降低投资、增加不确定性**

### 5.3 一个残酷的对比

| | 俄罗斯 | 中国 |
|---|---|---|
| **能否掠夺资本** | ✅ 能 | ❌ 不能（依赖太深） |
| **掠夺后的代价** | 停滞（但有油可卖） | **会比俄罗斯大得多**（没有油可卖） |
| **所以** | **俄罗斯是中国的"下限情景"，不是"同构情景"** | — |

> **这就是为什么中国在 2018 年后"部分地"走了这条路（平台整顿、民营信心下降），而不是完全走。**
>
> **而结果恰恰是**：**"退出的资本"用不投资惩罚了国家** ——**中国在"对抗资本"上赢了，但赢了对抗、输了投资。**
>
> **（详见 [[中国：高决断力、低纠错力与急转弯]] 第五节。）**

## 六、与海湾国家的对照：同样是租金，为什么结果不同

**这是对"资源决定论"最重要的反驳**：

| | 沙特 / 阿联酋 / 卡塔尔 | 俄罗斯 | 委内瑞拉 |
|---|---|---|---|
| **资源** | 石油/天然气 | 石油/天然气 | 石油 |
| **政体** | 绝对君主制/家族统治 | **个人化威权** | 民粹威权 |
| **资本信心** | **高**（迪拜、阿布扎比是区域金融中心） | **低** | **极低** |
| **产权保护** | **较强**（尤其迪拜自贸区） | 弱 | **极弱（大量国有化）** |
| **经济多元化** | **部分成功**（迪拜、阿布扎比） | 失败 | 失败 |
| **外资态度** | 欢迎 | 受限 | 驱逐 |
| **结果** | 富裕、稳定 | **停滞** | **崩溃（恶性通胀、难民外流）** |

**核心判断**：

> **同样是资源租金，政治结果完全不同 ——**这证明：**
>
> **资源租金给了国家"不依赖资本的自由"，但国家如何使用这个自由，取决于政治选择，而不是资源。**
>
> - **海湾国家**用租金换取"开放 + 可预期 + 多元化" → **资本愿意来（因为边界稳定）**
> - **俄罗斯**用租金换取"控制 + 不透明" → **资本不愿来**
> - **委内瑞拉**用租金换取"全面国有化 + 价格管制" → **资本逃离、经济崩溃**

**这就是 [[新加坡：可预期性作为资本的核心需求]] 的核心命题在资源国家中的再次验证**：

> **资本不怕威权，不怕资源国家，不怕家族统治——资本怕"边界不可预测"。**
>
> **迪拜是最好的证明：一个绝对君主制下的城市，成为了全球资本的避风港，因为它把"不掠夺"变成了稳定的规则。**

**另一个必须提到的反例：挪威**

| | 挪威 |
|---|---|
| **资源** | 石油（北海） |
| **政体** | **成熟的民主制** |
| **租金管理** | **主权财富基金（GPFG，全球最大）**，独立于政治，透明，规则化 |
| **结果** | **极富裕 + 高平等 + 长期稳定** |

> **挪威证明**：**资源租金 + 民主 + 制度化 = 可以避免资源诅咒。**
>
> **三个变量（资源、政体、制度）各自独立**——**资源本身不决定任何结果。**

## 七、收束：五个判断

### 7.1 判断一：国家能否对抗资本，取决于它是否需要资本

> **俄罗斯能掠夺资本，不是因为更强横，而是因为它有石油。**
>
> **"资源租金 → 国家不依赖资本 → 资本的结构性权力归零"** ——这是本笔记最核心的机制。

### 7.2 判断二：尤科斯证明的不是"权力"，而是"资产专用性"

> **如果尤科斯是一家软件公司，霍多尔科夫斯基不会被捕 ——他会带着团队搬去塞浦路斯。**
>
> **但它是油井。油井搬不走。**
>
> **所以"资本的结构性权力"必须与"资本的流动性"一起分析** ——**不可移动的资本没有退出选项，因此没有议价能力。**

### 7.3 判断三：无纠错机制的代价，在俄罗斯表现为"信息崩溃"

> **库尔斯克号（2000）→ 乌克兰战争（2022）** ——**同一个机制，二十二年的跨度。**
>
> **而苏联解体（1991）是它的极端形态。**
>
> **这与 [[中国：高决断力、低纠错力与急转弯]] 第三节的机制完全同构**，只是后果的规模不同。

### 7.4 判断四：资源租金不决定结果，政治选择才决定

> **沙特（资本信心高）、俄罗斯（低）、委内瑞拉（极低）、挪威（极高）** ——**四个资源国家，四种结果。**
>
> **资源只提供"自由"，如何使用这个自由是政治问题。**
>
> **这就是为什么"资源诅咒"这个说法本身是有问题的** ——**它不是资源的诅咒，是"使用租金的方式"的诅咒。**

### 7.5 判断五：俄罗斯是中国的"下限"，不是"同构"

> **如果中国像俄罗斯那样全面掠夺资本，代价会大得多** ——因为它没有石油。
>
> **这就是为什么中国走的是"选择性惩罚"而非"全面国有化"** ——**它不是不想，是不能。**
>
> **而这个"不能"，恰恰是资本结构性权力在中国仍然有效的证据。**
