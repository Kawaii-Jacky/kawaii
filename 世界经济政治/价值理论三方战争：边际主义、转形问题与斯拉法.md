# 价值理论三方战争：边际主义、转形问题与斯拉法

> - **根节点**：主流经济学为什么不接受劳动价值论？凯恩斯主义为什么在这个维度上"缺席"？真正在马克思自己的战场上与他正面交手的对手是谁？皮凯蒂的 r>g 与马克思的利润率下降规律（TRPF），是否共享同一套认识论地基？
> - **叙事逻辑**：边际革命作为公理断裂而非论辩胜负 → 转形问题：动摇劳动价值论内部一致性的技术性危机 → 真正的对手：斯拉法与新李嘉图学派 → 奥基肖定理重访：斯拉法工具打造的马克思内部危机 → r>g 与 TRPF 的认识论地位区分 → 收束
> - **立场说明**：本笔记与 [[世界经济政治/新古典边际主义：分配正义的去政治化与数理合法性建构.md]] 横向互补——那篇笔记聚焦边际主义如何**去政治化**分配问题、以及两剑桥之争如何揭穿其循环论证；本笔记聚焦一个那篇笔记未处理的问题：**在马克思主义阵营内部与外部，究竟是谁、用什么方法论，真正对 TRPF 构成了正面挑战**，以及这场挑战与皮凯蒂 r>g 框架的关系。
> - **来源标注**：笔记作者原创综合分析，援引博特凯维奇、奥基肖、斯拉法、克里曼等经济思想史一手文献与学界综述。

## 一、边际革命：一次公理断裂，而非一次辩论的胜负

[[世界经济政治/新古典边际主义：分配正义的去政治化与数理合法性建构.md|新古典边际主义笔记]]已经指出，边际革命把"价值的源泉"从劳动移向了消费者的主观效用，从而在数理上论证了"不存在剩余价值可供剥削"。这里需要补充一层更根本的**方法论**判断：**这不是一场边际学派"驳倒"了劳动价值论的辩论，而是一次公理系统的整体更换**。

马克思问的是"价值的客观来源是什么"（答案：抽象人类劳动）；边际学派问的是"价格如何在主观偏好与稀缺性的相互作用下决定"（答案：边际效用与边际成本的均衡）。这不是同一个问题的两个答案，而是**两套完全不同的语言游戏**。

> 🔗 **横向关联**：这与 [[世界经济政治/维特根斯坦的理论.md|语言游戏]]的框架直接对应——两套理论体系不是在同一个游戏规则下争论对错，而是在玩不同的游戏，彼此的核心词汇（"价值"）在各自的游戏里指向完全不同的东西。**新古典体系里没有"剥削"这个词能够附着的位置，不是因为这个概念被驳倒了，而是因为新游戏的语法里压根没有能表达它的词槽。** 这解释了为什么"说服"从未真正发生——绝大多数主流经济学家不是被"论证"改变了立场，而是从研究生阶段起就只在边际主义这一套语言游戏里被训练，压根不在马克思的游戏里长大。

这一点也解释了你在上一轮追问里的困惑："凯恩斯主义似乎没有在这方面的解释力"——凯恩斯从未打算回答"价值的客观来源是什么"这个问题，他关心的是短期到中期的有效需求、失业与商业周期，明确拒绝了古典政治经济学那种揭示资本主义"长期运动规律"的理论野心。**凯恩斯主义与 TRPF 不在同一个理论量级上对话，不是输了论战，而是从未参赛。**

## 二、转形问题：动摇劳动价值论内部一致性的技术性危机

即便撇开边际革命的外部冲击，劳动价值论本身也遭遇过一场更致命的**内部**危机——这场危机让即便同情马克思政治立场的经济学家，也开始怀疑这套理论作为形式体系的自洽性。

> 📌 **转形问题（The Transformation Problem）**：马克思在《资本论》第三卷里，尝试把商品按"劳动价值"计算出的数值，转换成市场上实际观察到的、包含平均利润率的"生产价格"。他希望这一转换过程能同时保住两个总量恒等式：**总价格 = 总价值**，且**总利润 = 总剩余价值**。但博特凯维奇（Ladislaus von Bortkiewicz）1906–07 年的经典批判证明：在给定的技术条件下，用统一利润率把劳动价值转换为生产价格时，**这两个恒等式一般不可能同时成立**——你只能保住其中一个，代价是放弃另一个。

这个证明的杀伤力在于：它动摇的不是马克思的政治结论，而是他**证明这套理论内部一致性**的核心步骤本身——如果一个理论声称"总利润=总剩余价值"，但这个等式只在特殊情况下才成立，那么"利润来自对劳动的剥削"这个核心论断的数学基础就出现了裂缝。

这场争论延续了一个多世纪：1980 年代福利（Duncan Foley）与杜梅尼尔提出的"新解释（New Interpretation）"，试图通过重新定义"价值"的核算方式来修补这一漏洞，此后又有克里曼与弗里曼的"时间性单一体系解释（TSSI）"从另一个角度重新捍卫马克思——但争论至今没有平息。**转形问题解释了为什么很多经济学家——即便认同马克思对资本主义的道德批判——也不愿意把劳动价值论当作一套可以拿来做精确计算的形式理论来使用。**

## 三、真正的对手：斯拉法与新李嘉图学派——用马克思自己的方法论反对马克思

这是最容易被忽略、却最关键的一点：**真正在马克思自己的战场（用生产的物理/技术系数、而非主观效用，来客观决定价格与利润率）上与他正面交手的，不是新古典边际主义，而是皮埃罗·斯拉法（Piero Sraffa）开创的"新李嘉图学派（Neo-Ricardian School）"。**

> 📌 **斯拉法体系（Sraffian System）**：斯拉法 1960 年《用商品生产商品》提出：仅凭生产的技术数据（每种商品生产需要投入多少其他商品和劳动），就能同时解出一套价格体系和一个利润率——完全不需要借助劳动价值论，也不需要边际效用。这证明了马克思试图用"劳动"这把尺子解决的问题，可以用一套更一般的线性生产方程组解决，且不会遇到转形问题那样的内部矛盾。

### 1. 斯拉法式的线性生产模型（Sraffa's Linear Production Model）
斯拉法颠覆了新古典经济学“单向生产”（要素 $\rightarrow$ 消费）的逻辑，重回古典经济学“**用商品生产商品**”的循环生产图景。
*   **物理技术矩阵**：假设一个经济体生产 $n$ 种商品，生产每一单位商品 $j$ 需要投入其他商品 $i$ 的数量为 $a_{ij}$（技术系数），以及直接劳动投入 $l_j$。
*   **线性方程组**：设各商品价格为 $p_i$，统一利润率为 $r$，工资率为 $w$（事后支付），可列出生产方程组：
    $$(a_{11} p_1 + a_{21} p_2 + \dots + a_{n1} p_n)(1+r) + l_1 w = p_1$$
    $$(a_{12} p_1 + a_{22} p_2 + \dots + a_{n2} p_n)(1+r) + l_2 w = p_2$$
    $$\dots\dots$$
    $$(a_{1n} p_1 + a_{2n} p_2 + \dots + a_{nn} p_n)(1+r) + l_n w = p_n$$
*   **分配与权力的决定**：在上述方程组中，价格 $p_i$ 共有 $n-1$ 个相对价格，加上 $r$ 和 $w$，共有 $n+1$ 个未知数，但只有 $n$ 个独立方程。这在数学上意味着**系统是未决的**。
    *   **核心结论**：必须外生给定一个分配变量（如通过阶级博弈确定工资率 $w$，或通过金融政策确定利率/利润率 $r$），整个价格体系和另一个分配变量才能被唯一确定。
    *   **工资-利润曲线（Wage-Profit Curve）**：$w$ 与 $r$ 之间存在严格的负相关权衡关系。分配不是由技术性的“要素边际生产力”决定的，而是由**阶级之间的社会议价权力**决定的。

### 2. 斯拉法学派（Sraffian School / 新李嘉图主义）
以皮埃罗·斯拉法、皮埃朗杰洛·加雷尼亚尼（Pierangelo Garegnani）、路易吉·帕西内蒂（Luigi Pasinetti）等人为核心的学派，被称为**新李嘉图学派**：
*   **重塑古典“剩余理论”**：他们主张复兴斯密、李嘉图的古典传统，将经济学核心聚焦于“剩余产品的分配与再生产”，彻底抛弃新古典的边际效用、主观偏好与稀缺性分析。
*   **资本理论的拆弹手**：在“两剑桥之争”中，他们提供了一套数理工具，证明了“技术反弹（Reswitching）”和“资本倒转（Capital Reversing）”的存在，彻底在数理上摧毁了新古典的总量生产函数。

### 3. 后凯恩斯主义（Post-Keynesianism）的理论拼图
后凯恩斯主义是现代西方最主要的异端经济学派之一，直接继承了凯恩斯的《通论》精神以及卡莱茨基（Michal Kalecki）、罗宾逊（Joan Robinson）等人的思想。
*   **三大核心基石**：
    1.  **根本不确定性（Fundamental Uncertainty）**：未来是不可预测的，人类决策面临非遍历性（Non-ergodicity），因此货币和契约成为规避风险的防卫机制。
    2.  **有效需求决定论**：有效需求不仅在短期，而且在**长期**都决定了产出与就业。
    3.  **内生货币理论（Endogenous Money）**：贷款创造存款，货币是由银行信贷根据市场需求“凭空”创造的（内生的），而非由中央银行通过准备金乘数外生控制。
*   **与斯拉法学派的合流与张力**：
    *   **合流（抗击主流的联盟）**：后凯恩斯主义者（如罗宾逊夫人）借用斯拉法的线性模型作为摧毁新古典资本理论的数学武器。斯拉法提供了微观的价格和要素分配模型，后凯恩斯主义则提供了宏观的动态总需求和货币模型。
    *   **张力（时间观的分歧）**：斯拉法学派追求“长周期均衡”（Long-period Positions），假设利润率在各行业间均等化；而原教旨后凯恩斯主义（如保罗·戴维森 Paul Davidson）强调“根本不确定性”和“历史时间”的不可逆性，反对任何形式的长期均衡假设。

斯拉法引发的**两剑桥之争（Cambridge Capital Controversy）**——[[世界经济政治/新古典边际主义：分配正义的去政治化与数理合法性建构.md|新古典边际主义笔记]]第四节已详述其"资本总量必须先知道利息率才能计算，但利息率又要靠资本的边际生产力来解释"的循环论证——需要在此补上一个常被忽略的阵营构成事实：**站在琼·罗宾逊身边、真正提供技术武器揭穿这一循环的，正是斯拉法的线性生产框架，而非马克思本人的劳动价值论**。这场争论意外地同时重振了马克思主义经济学的学术地位、并催生了后凯恩斯主义，三条理论脉络（斯拉法学派、马克思主义、后凯恩斯主义）从此结成了对抗新古典主流的"异端联盟"——但联盟内部，对 TRPF 本身依然分裂。

## 四、奥基肖定理重访：斯拉法工具打造的马克思内部危机

现在可以精确回答"谁是 TRPF 真正的对手"这个问题了：**大内力雄（Nobuo Okishio）对马克思利润率下降规律的挑战，用的正是斯拉法式的线性生产模型，而非新古典的边际效用框架。**

这不是巧合——奥基肖在斯拉法《用商品生产商品》出版的同一年（1960/1961），就写了一篇书评，仔细比较了斯拉法的"基本商品"定义与自己框架的异同。**奥基肖定理的数学证明，其方法论根基直接来自斯拉法体系。**

这一点极为关键，它重新定位了整场论战的性质：

> **奥基肖对马克思的挑战，不是"外部野蛮人用完全不同的语言游戏说你错了"（那是边际主义的角色），而是"用你（马克思）自己看重的、基于客观生产技术而非主观偏好的方法论，得出了和你相反的结论"。** 这正是为什么奥基肖定理比新古典边际主义的批评严重得多——它是一场发生在"客观价值/生产技术决定论"这个共同阵营内部的、更难被当作"意识形态偏见"打发掉的正面遭遇战。

也正因如此，马克思主义阵营对奥基肖的反驳（沙伊克的"湍流竞争"、克里曼与弗里曼的 TSSI）也必须在同一个技术层面作战——不能简单诉诸"边际主义是资产阶级意识形态"这类外部批判，而必须证明奥基肖的斯拉法式证明本身，在估值方法（同时性 vs 时间性）上悄悄嵌入了对马克思不利的假设。这也是为什么这场论战——不同于边际主义与马克思主义之间的公理断裂——**始终停留在同一个技术性话语内部，六十多年都无法达成休战。**

> 🔗 **横向关联**：详见 [[世界经济政治/AI与互联网泡沫：暗光纤先例、地缘分流与生产力_生产关系.md|AI与互联网泡沫笔记]]第七节，对奥基肖定理内容本身、TSSI 反驳的"道德贬值"机制、以及巴苏与马诺拉科斯等人的实证证据状况有完整展开。

## 五、r>g 与 TRPF 的认识论地位区分：一个必须澄清的地方

趁着这次梳理，有必要正式澄清一个容易被混淆的地方：**皮凯蒂的 r>g，方法论上根本不建立在劳动价值论之上**，他明确不是马克思主义经济学家。

- **r>g 是一个可以独立于任何特定价值理论、直接测量的经验事实**——只需要统计资本资产的历史回报率和 GDP 增长率，不需要先接受某一套关于"利润的哲学来源是什么"的理论，就能观察到 r 和 g 谁更高。它的历史真实性（包括 1914–1980 年被压缩这一事实）几乎所有经济学流派（新古典、后凯恩斯、马克思主义）都承认，争议主要在"为什么"和"该怎么办"，而非"是否发生过"。
- **TRPF 则是"理论负载（theory-laden）"的**——它的整个逻辑建立在马克思特定的劳动价值论之上（"只有活劳动创造剩余价值，机器只转移价值不创造新价值"）。如果不接受这套价值理论，这条"规律"甚至不构成一个所有学派都会同意"存在一个待解释现象"的经验命题。更麻烦的是，连接受马克思价值论的马克思主义者内部，奥基肖之后也在数学证明层面分裂了六十年，尚未达成共识。

> **精确的结论**：r>g 是一条被广泛观测确认、只在"如何解释/如何应对"上有争议的经验规律；TRPF 是一条连"是否存在""该如何证明"本身都还在激烈论战的理论假说。**两者用完全不同的认识论地基，恰好指向了同一个方向的担忧（资本相对于劳动/增长的力量在扩大），但它们不是同一套理论的两种表述**——r>g 可以被新古典经济学家接受为"一个需要解释的事实"，TRPF 却连"事实"的地位都还没有稳固获得。

## 六、收束：三方战争的地图

```
                  【价值理论三方战争】
                          │
      ┌───────────────┬───┴───┬───────────────┐
      ▼               ▼       ▼               ▼
  马克思劳动价值论   边际主义（新古典）   斯拉法/新李嘉图学派   皮凯蒂 r>g
  （转形问题动摇     （公理断裂，用     （用客观生产技术，   （价值论无关的
   其内部自洽性）     效用重新定义价值）  同时挑战前两者）     纯会计恒等式）
```

- 马克思与边际主义：**公理断裂**（不同语言游戏，无法直接对话）；
- 马克思与斯拉法：**同一战场的正面遭遇战**（都用客观生产技术方法论，但结论相反——奥基肖定理即产物）；
- 皮凯蒂与前三者：**方法论上的旁观者**——r>g 不需要选边站队于价值理论战争的任何一方，这正是它能被更广泛接受为"事实"的原因，也是它不能被直接等同于 TRPF 的原因。
