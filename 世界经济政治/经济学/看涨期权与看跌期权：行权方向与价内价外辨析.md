# 看涨期权与看跌期权：行权方向与价内价外辨析

> 本笔记根据 [[名词解释写作规则]] 编写，收录并深度解构 4 个期权入门核心词条：**看涨期权、看跌期权、行权价、价内/价外/平值**。
>
> **核心命题**：看涨期权是"按行权价**买入**"的权利，看跌期权是"按行权价**卖出**"的权利——一个想低价买、一个想高价卖，所以判断"划不划算"的方向天然相反。

---

## 看涨期权（Call Option）

**看涨期权（Call Option）**是指==赋予买方在约定期限内按约定行权价买入标的资产的权利、而非义务的期权合约；它站在"低价买"的方向上，因此市价高于行权价时处于价内，市价低于行权价时处于价外==。

> 🔗 **横向关联**：本词条把"Call 赋予买方按行权价**买入**的权利"拆成完整的判断链条，与 [[期货、期权、国债期货、股指期货与现券：结构、定价和风险]] 中"期权买方只有权利、卖方才承担履约义务"的非对称结构形成**上下游关系**——正因为买方没有行权义务，"价内才值得行权"这句话才成立：价外时弃权即可，不利方向被截断为权利金损失。

### 一、 核心要素与运作机制（Mechanism）

1. **权利方向：买入**。持有 Call，就有权按行权价从卖方**买入**标的；想买得便宜，所以行权价越低越好。
2. **行权价 vs 市价的分工**：行权价是合约写死的（固定），市价是变动的（浮动）；判断行不行权，就是拿这两个价格比大小。
3. **价内判据**：市价 > 行权价 → 价内；市价 < 行权价 → 价外；市价 = 行权价 → 平值。
4. **权利可以放弃**：价外时买方没有行权义务，可以弃权；这也是"期权买方最大损失一般为已付权利金"的来源。

### 二、 形象化解构：比喻与具体实例（Metaphor & Example）

* **形象比喻**：一张**"低价购房券"**——券上写死"可按 100 万买这套房"。
  * 房子市价 150 万 → 券值钱（**价内**：按 100 万买入即赚 50 万差价）；
  * 房子市价 80 万 → 券没用（**价外**：没人会拿它按 100 万去买市价 80 万的房）。

* **具体实例**：一份行权价为 2.50 的 Call——
  * 市价 2.80：按 2.50 买入、市价 2.80 卖出，毛赚 0.30 → **价内，值得行权**；
  * 市价 2.30：按 2.50 买就是买贵，弃权 → **价外，行权无利可图**。

### 三、 多维度对比表格（Comparison）

判断一份 Call 值不值，不必先猜大势，只要把"市价与行权价"的三个相对位置逐一列出，结论立刻显现：

| 市价与行权价的关系 | 状态 | 行权结果（简化口径） |
| :--- | :--- | :--- |
| 市价 > 行权价 | ✅ 价内 | 按行权价买入即可赚差价，值得行权 |
| 市价 = 行权价 | 平值 | 行权与不行权无差别（不含权利金成本） |
| 市价 < 行权价 | ❌ 价外 | 行权即买贵，理性选择是弃权 |

**最关键的差异点**：**Call 的划算程度随市价单调上升**——市价越高于行权价（越深价内），这份"低价买"的权利越值钱。

## 💡 记忆锚点与口诀

- **方向拆解**：**Call = 买入权**（按行权价把货"叫"进来）；低买是它的天性。
- **极简公式**：$S > K$ 时 Call 价内（$S$ = 市价，$K$ = 行权价）。
- **记忆口诀**：**Call 低价进货券，市价越高越值钱。**

## 看跌期权（Put Option）

**看跌期权（Put Option）**是指==赋予买方在约定期限内按约定行权价卖出标的资产的权利、而非义务的期权合约；它站在"高价卖"的方向上，因此市价低于行权价时处于价内，市价高于行权价时处于价外==。

> 🔗 **横向关联**：本词条"Put 持有者有权按约定价卖出"与 [[王健林万达商管上市失败案：对赌协议、债务危机与资产清仓深度拆解]] 中的"对赌回购条款"形成**镜像互证关系**——对赌协议中"若上市失败，投资方有权要求按约定价格回购股权"，从投资方视角看近似一份嵌在股权里的看跌期权：触发条件（上市失败）一旦出现，就把股权按约定价"卖回"给融资方；而承担回购义务的融资方，则像收了融资款（约等于权利金）却必须被动履约的期权卖方。

### 一、 核心要素与运作机制（Mechanism）

1. **权利方向：卖出**。持有 Put，就有权按行权价向卖方**卖出**标的；想卖得贵，所以行权价越高越好。
2. **行权价 vs 市价的分工**：与 Call 完全相同——合约锁定的价（固定）对比市场价（浮动）。
3. **价内判据（与 Call 相反）**：市价 < 行权价 → 价内；市价 > 行权价 → 价外；市价 = 行权价 → 平值。
4. **保险属性**：持有现货的同时买入 Put，相当于为现货买了一份"跌价险"——价格暴跌时，按高行权价卖出的权利兜底。

### 二、 形象化解构：比喻与具体实例（Metaphor & Example）

* **形象比喻**：一张**"高价卖房券"**——券上写死"可按 100 万卖这套房"。
  * 房子市价 80 万 → 券值钱（**价内**：按 100 万卖出比市场多赚 20 万）；
  * 房子市价 150 万 → 券没用（**价外**：市场上能卖 150 万，何必按 100 万卖）。

* **具体实例**：一份行权价为 2.50 的 Put——
  * 市价 2.20：按 2.50 卖出、市价 2.20 买回（或直接比价），毛赚 0.30 → **价内，值得行权**；
  * 市价 2.80：按 2.50 卖就是卖亏，弃权 → **价外，行权无利可图**。

### 三、 多维度对比表格（Comparison）

用同样三个相对位置检验 Put 的划算方向——注意它与 Call 的判定逐行镜像相反：

| 市价与行权价的关系 | 状态 | 行权结果（简化口径） |
| :--- | :--- | :--- |
| 市价 < 行权价 | ✅ 价内 | 按行权价卖出即可赚差价，值得行权 |
| 市价 = 行权价 | 平值 | 行权与不行权无差别（不含权利金成本） |
| 市价 > 行权价 | ❌ 价外 | 行权即卖亏，理性选择是弃权 |

**最关键的差异点**：**Put 的划算程度随市价单调下降**——市价越低于行权价（越深价内），这份"高价卖"的权利越值钱。

## 💡 记忆锚点与口诀

- **方向拆解**：**Put = 卖出权**（按行权价把货"放"出去卖）；高卖是它的天性。
- **极简公式**：$S < K$ 时 Put 价内。
- **记忆口诀**：**Put 高价出货券，市价越低越值钱。**

## 行权价（Strike Price / Exercise Price）

**行权价**是指==期权合约中事先约定的、买方行权时买入或卖出标的资产的固定价格；它由合约条款锁定、不随市价波动，是判定价内/价外的基准"锚"==。

> 🔗 **横向关联**：本词条把"合约锁定的价格"单独立目，与 [[经济名词解释3]] 中"期权四大基本类型与非对称结构"表形成**详略互补关系**——那张表从"看涨/看跌 × 买方/卖方"四象限铺开权利与义务的分配，其中反复出现的"按行权价买入/卖出"，所依赖的正是本词条抽出来讲透的这把固定标尺。两者的共同底层逻辑：期权的一切判断，都建立在"行权价（合约定）"与"市价（市场定）"这对价格的分工之上。

### 一、 核心要素与运作机制（Mechanism）

1. **由合约写死**：行权价在签约时就锁定，到期前不随市价变动——它是整份期权里唯一"静止"的价格。
2. **决定权利的价值方向**：Call 希望行权价越低越好（买得便宜），Put 希望行权价越高越好（卖得贵）。
3. **与市价比较 → 价内/价外**：行权价与市价的位置关系，就是价内、平值、价外的判据。
4. **与权利金分工**：判断"行不行权"只看行权价与市价；计算"净赚多少"还要扣掉买期权时支付的权利金。

> 📌 **权利金（Premium）**：买方为获得期权权利而支付给卖方的费用，也是期权合约自身的交易价格（可拆为内在价值 + 时间价值）。它与行权价是两回事：行权价管"按什么价成交"，权利金管"买这张合约花了多少钱"。

### 二、 形象化解构：比喻与具体实例（Metaphor & Example）

* **形象比喻**：行权价是**刻在合同上的"锚"**，市价是**水面的"船"**——船围着锚上下浮动：Call 盼船浮高（市价涨过锚），Put 盼船沉低（市价跌破锚）。

* **具体实例**：回到购房券——券上写死的 100 万是**行权价**（锚）；房子现在能卖多少是**市价**（船）；当初买这张券花的 5 万是**权利金**（票价）。无论房价怎么波动，100 万这个数一直印在券上。

### 三、 多维度对比表格（Comparison）

初学者常把"行权价、市价、权利金"笼统记成"期权的价格"，其实这是三把分工完全不同的尺子——先分清楚，再看价内价外就不会晕：

| 维度 | 行权价（Strike） | 标的市价（Spot） | 权利金（Premium） |
| :--- | :--- | :--- | :--- |
| **是什么** | 合约约定的买卖成交价 | 标的资产当下的市场价 | 期权合约自身的交易价格 |
| **由谁决定** | 合约条款（签约时写死） | 市场供需 | 市场供需 |
| **会不会变** | ❌ 到期前不变 | ✅ 时刻变动 | ✅ 时刻变动 |
| **在判断中的作用** | 判价内价外的基准"锚" | 与锚比较的对象"船" | 算净盈亏要扣的"票价" |
| **购房券类比** | 券上写死的 100 万 | 房子当前的市价 | 买这张券花的钱 |

**最关键的差异点**：**行权价是锚（固定），市价是船（浮动），权利金是票价（期权售价）**——判断"行不行权"看锚与船的位置，计算"净赚多少"则必须再扣掉票价。

## 💡 记忆锚点与口诀

- **三者拆解**：锚（行权价，不动）、船（市价，常动）、票（权利金，另算）。
- **极简公式**：Call 净赚 ≈ $(S - K)$ − 权利金；Put 净赚 ≈ $(K - S)$ − 权利金（持有到期行权口径）。
- **记忆口诀**：**锚不动、船常动、票价另算。**

## 价内、价外与平值（In-the-Money / Out-of-the-Money / At-the-Money, ITM / OTM / ATM）

**价内、价外与平值**是指==衡量期权"行权价与当前市价相对位置"的三种状态：行权对自己有利为价内（ITM）、行权对自己不利为价外（OTM）、两者相等为平值（ATM）；同一组价格关系，对看涨期权与看跌期权的含义正好相反==。

> 🔗 **横向关联**：本词条"同一市价关系对 Call 与 Put 意义相反"与 [[期货市场基础：做多做空、持有成本、移仓换月与套利]] 中"同一价格变动对做多与做空盈亏相反"形成**镜像对照关系**——期货里方向相反表现为**线性盈亏**（多头赚即空头亏），期权里方向相反表现为**价内/价外状态**，且买方还能弃权，把不利方向截断为权利金损失。共同底层逻辑：**头寸方向不同，同一个价格关系天然是"有利"或"不利"。**

### 一、 核心要素与运作机制（Mechanism）

1. **状态由"成对比较"决定**：价内/价外不是标的资产的属性，而是"这份合约的权利在当前市价下顺不顺风"——永远要把市价与行权价放在一起比。
2. **Call 与 Put 判据相反**：Call 价内 ⇔ 市价 > 行权价；Put 价内 ⇔ 市价 < 行权价。原因只有一条：**一个买、一个卖**。
3. **"市场判断"≠"合约状态"（重点纠偏）**："看涨/看跌"是你对市场的预期；"价内/价外"是行权价与市价的相对位置。你觉得会涨，不会让 Call 变成价内；市场真的涨到高于行权价，才会。
4. **两条口径边界**：价内 ≠ 一定净赚钱（净盈亏还要扣权利金）；价外 ≠ 一定归零（未到期时可能仍有时间价值，到期仍价外才归零）。

### 二、 形象化解构：比喻与具体实例（Metaphor & Example）

* **形象比喻**：同一个行权价 100 万，房子里却有两张方向相反的券——
  * 房价涨到 150 万："按 100 万**买**"的券（Call）值钱，而"按 100 万**卖**"的券（Put）没了用武之地；
  * 房价跌到 80 万：反过来——Put 值钱，Call 失灵。

* **具体实例**：行权价同为 2.50 时——
  * 市价 2.80：Call 价内 ✅ / Put 价外 ❌；
  * 市价 2.20：Call 价外 ❌ / Put 价内 ✅；
  * 同一句"市价跌了 0.30"，对两份期权的持权人却是"一个哭、一个笑"。

### 三、 多维度对比表格（Comparison）

把同一组价格关系并排铺给 Call 与 Put，就能一眼看穿"同一件事、两种相反结论"的错觉——这正是初学者最容易绕晕的地方：

| 市价 vs 行权价 | 看涨期权 Call | 看跌期权 Put |
| :--- | :--- | :--- |
| **市价 > 行权价** | ✅ **价内**（可以低价买） | ❌ **价外**（无法高价卖） |
| **市价 = 行权价** | 平值 | 平值 |
| **市价 < 行权价** | ❌ **价外**（买贵了，弃权） | ✅ **价内**（可以高价卖） |
| **希望行权价** | 越低越好 | 越高越好 |
| **喜欢市价怎么走** | 越高越值钱（盼涨） | 越低越值钱（盼跌） |
| **生活比喻** | 低价购房券 | 高价卖房券 |

**最关键的差异点**：**同一个"市价 vs 行权价"关系，对 Call 与 Put 的意义正好相反——因为一个按行权价买入、一个按行权价卖出**。价内价外不是对合约的绝对好评差评，而是"这份权利在当前市价下顺不顺风"的相对判断。

## 💡 记忆锚点与口诀

- **三态拆解**：价内 = 行权有利（ITM）｜平值 = 打平（ATM）｜价外 = 行权不利（OTM）。
- **极简公式**：**市价"大"于行权价 → Call 价内；市价"小"于行权价 → Put 价内**（大 Call 小 Put）。
- **记忆口诀**：**市价越涨，Call 越牛；市价越跌，Put 越牛；行权价是锚，市价是船。**
