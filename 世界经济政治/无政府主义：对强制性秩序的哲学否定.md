# 无政府主义：对强制性秩序的哲学否定

> **核心命题**：无政府主义不是"混乱"（chaos），而是"没有统治者"（no rulers，来自希腊语ἀναρχία）。它的哲学前提是：一切强制性的等级权威（无论是国家、资本还是宗教）都没有合法的道德基础；人类通过自愿协作和互助原则，能够在没有强制性权威的情况下自我组织。

---

## 一、无政府主义的哲学基础

### 1.1 核心命题的层次

```
第一层（否定性）：
  国家 = 合法化的暴力垄断
  → 任何人对另一个人施加未经同意的权力，都是非法的
  → 这包括：国家、资本家（通过财产权支配劳动力）、宗教机构、家长制

第二层（肯定性）：
  人类天然具有自我组织能力
  → 克鲁泡特金《互助：进化的一个因素》(1902)：
    物种合作比竞争更普遍
    合作是进化的动力，不只是竞争
  → 社区、行会、村庄公地在历史上是人类的默认组织形式
  → 国家是强加于这种自然秩序之上的

第三层（策略性）：
  革命方式 = 直接行动（direct action）
  → 不通过选举（选举是向统治体制寻求改变的被动行为）
  → 不通过夺取国家（马克思主义路径——被视为掌权后的腐化源泉）
  → 而是立即在日常生活中体现无政府原则（活出改变）
```

### 1.2 与马克思主义的根本分歧

```
马克思/恩格斯立场（第一国际，1864-1872）：
  ① 先组织无产阶级政党
  ② 夺取国家政权（无产阶级专政）
  ③ 用国家推进生产资料集体化
  ④ 国家"自然消亡"后进入共产主义

巴枯宁的反驳（1872年被马克思逐出第一国际）：
  ① "无产阶级专政" = 一群人统治其他人，和任何其他统治没有区别
  ② "国家消亡"是乌托邦——国家机器一旦被掌握，掌握它的人会用它维护自己
  ③ 所谓"先锋队"会成为新的统治阶级
  
  历史验证：
  → 布尔什维克革命（1917）→ 党国 → 斯大林主义
  → 巴枯宁预言的"科学家和官僚的新贵族"精确实现
  → 这是无政府主义最有力的历史论据

蒲鲁东的先见（1840年）：
  "财产即是盗窃！"（Property is theft!）
  → 第一个公开自称"无政府主义者"的思想家
  → 批评资本主义和国家社会主义
  → 提倡互助主义：没有利息的信贷+工人交换产品
```

## 二、主要流派谱系

### 2.1 五大主要流派

| 流派 | 代表人物 | 时代 | 核心主张 | 经济模式 |
|------|---------|------|---------|---------|
| **互助主义** | 蒲鲁东(Proudhon) | 1840s | 财产即盗窃；工人互助银行 | 小生产者+无利息信贷 |
| **集体主义** | 巴枯宁(Bakunin) | 1860s | 废除私有制；工人集体所有 | 生产者联合所有 |
| **无政府共产** | 克鲁泡特金(Kropotkin) | 1880s | 互助原则；"各尽所能，各取所需" | 自愿共产+礼物经济 |
| **无政府工团** | 索雷尔(Sorel) | 1900s | 工会是革命主体；总罢工策略 | 工会管理生产 |
| **个人主义** | 施蒂纳(Stirner)、塔克(Tucker) | 1840s-1900s | 自我主权；拒绝一切外部权威 | 自由市场（无国家）|

### 2.2 争议流派：无政府资本主义

```
罗斯巴德(Murray Rothbard)、弗里德曼(David Friedman)等人提出：
  废除国家 + 保留资本主义和私有产权
  → 用私有合同和市场机制替代国家

传统无政府主义者的批评：
  "资本主义本身就是一种强制性权力结构"
  → 雇主对雇员的关系 = 非自愿的权力不平等
  → 财产权需要国家（或类似机构）来执行——矛盾
  
这是无政府主义内部最激烈的理论争论之一
```

### 2.3 女性主义无政府主义

```
艾玛·戈德曼(Emma Goldman, 1869-1940)：
  → 无政府主义 + 女权主义的早期结合
  → "如果我不能跳舞，这就不是我的革命"（著名格言）
  → 反对强制性婚姻制度、支持节育权利
  → 被美国驱逐（俄国移民）→ 逃回苏联 → 对布尔什维克失望 → 写《我的幻灭》

当代女性主义无政府主义：
  → 库尔德"民主联邦主义"将女性解放置于核心
  → 生态女性主义：对自然的统治 ≈ 对女性的统治
```

## 三、历史实践：活生生的实验

### 3.1 巴黎公社（1871年，72天）

```
背景：
  普法战争（1870-1871）→ 法国战败 → 凡尔赛政府软弱
  3月18日：巴黎工人夺取国民警卫队大炮，阻止政府撤退
  3月28日：公社成立

无政府/社会主义实践：
  ├── 废除常备军，用国民警卫队（武装市民）代替
  ├── 取消民选官员的高薪（工资不得超过普通工人）
  ├── 工人委员会管理工厂和公共服务
  ├── 政教分离（驱逐宗教从学校）
  ├── 没收空置工厂归工人管理
  └── 焚毁断头台（拒绝革命恐怖）

结局：
  5月21-28日"血腥周"：凡尔赛军队重新占领巴黎
  约20,000名公社社员被屠杀
  马克思《法兰西内战》将其称为无产阶级专政的雏形
  无政府主义者也宣称其为自治社区的先驱
  → 争夺公社遗产的政治至今未结束
```

### 3.2 西班牙加泰罗尼亚（1936-1939年）——最重要的无政府主义实验

```
背景：
  西班牙内战（1936-1939）：共和国 vs 弗朗哥法西斯
  全国无政府主义联合会/伊比利亚无政府主义联合会（CNT/FAI）
  是西班牙最大的劳工组织（成员约120-180万）

实践内容：
  ├── 约150万工人参与集体化工厂和农场
  ├── 巴塞罗那：公共交通/公用事业/工厂由工人委员会运营
  ├── 农村：集体农庄（特别是在阿拉贡/加泰罗尼亚）
  ├── 废除货币（部分地区）→ 以物易物或凭证
  ├── 女性解放（"Mujeres Libres"自由女性组织）
  └── 教育社区化

压制：
  ① 弗朗哥法西斯（外部敌人）
  ② 斯大林支持的西班牙共产党（内部背刺）
     → 苏联援助共和国的条件：共产党控制军队
     → 1937年5月巴塞罗那事件：共产党向无政府主义者开枪
     
乔治·奥威尔《向加泰罗尼亚致敬》：
  → 亲历者记录，如实描述了无政府主义社会的短暂现实
  → "这是我第一次生活在一个工人阶级掌握主导权的地方"
  → 也记录了共产党在内部消灭无政府主义的过程
```

### 3.3 乌克兰马赫诺运动（1918-1921年）

```
领导人：内斯托尔·马赫诺(Nestor Makhno)，文盲农民出身

控制区域：乌克兰南部，约700万人口

实践：
  ├── 废除地主土地，分配给农民
  ├── 建立自愿工农苏维埃（不同于布尔什维克苏维埃）
  ├── 地方自治，无强制集体化
  └── 军队（黑军）：民主化指挥，军官由选举产生

对外：
  先后击败白军（邓尼金）、德国占领军
  与红军多次合作对抗白军

结局：
  1920年：布尔什维克在利用马赫诺击败最后的白军后，立即翻脸
  1921年：红军消灭马赫诺运动，马赫诺流亡巴黎

教训：
  → 与列宁主义者的"临时联盟"是无政府主义者历史上一再重复的致命错误
  → 西班牙无政府主义者犯了同样的错误（与斯大林支持者合作对抗弗朗哥）
```

### 3.4 罗贾瓦/北叙利亚库尔德自治（2012-至今）

```
理论基础：
  阿卜杜拉·厄贾兰(Abdullah Öcalan)，库尔德工人党(PKK)领导人
  监狱中读到美国无政府主义者默里·布克钦的"社会生态学"
  → 将传统社会主义改造为"民主联邦主义"

核心实践：
  ├── 去中心化自治（村庄/社区层面的直接民主）
  ├── 三重共治：联合市长制（男女各一）+ 地方议会 + 坎托自治机构
  ├── 女性解放：所有机构强制50%女性参与
  ├── 生态主义：环境政策纳入治理核心
  └── 多族群共治：库尔德/阿拉伯/亚述基督徒共同参与

军事背景：
  ISIS（伊斯兰国）进攻 → 库尔德YPJ/YPG成为抵抗主力
  → 美国/西方支持（与ISIS的战争）
  → 2019年：特朗普撤军 → 土耳其攻击 → 一部分领土丧失

局限：
  → 处于极端战争压力下，非"纯净"无政府主义
  → 仍有武装力量和强制性机构（战时需要）
  → 女性解放在实践中仍面临传统阻力
```

## 四、无政府主义的内在矛盾

```
理论优势：
  ✓ 对权力腐化有最深刻的预见（巴枯宁对列宁主义的预判）
  ✓ 对日常生活中的压迫最敏感（不只是阶级，还有性别/种族/家庭）
  ✓ 实践中确实产生了非凡的解放能量（加泰罗尼亚的短暂繁荣）

核心困境：
  ① 防御悖论
     外部敌人会用国家力量攻击无政府社区
     → 防御需要某种形式的集中协调
     → 集中协调很快变成国家雏形
     
  ② 规模悖论
     小社区的直接民主有效
     → 大规模工业社会如何协调？
     → 自愿联合体在大规模时面临巨大协调成本
     
  ③ 搭便车问题
     没有强制机制，如何处理不愿意遵守集体决定的成员？
     
  ④ 过渡期的暴力问题
     如何从现有国家过渡到无国家？
     革命暴力本身是否可以在无政府主义框架内被证明合理？
```

```
虽然无政府主义"政权"几乎都以失败告终，
其思想工具深刻影响了20-21世纪的进步政治：

直接影响（已被主流化的无政府主义元素）：
  ├── 非暴力直接行动 → 甘地/马丁路德金运动的理论基础
  ├── 共识决策 → 1970年代女性主义运动，OWS（占领运动，2011）

  ├── 水平化组织 → 开源软件运动、Wikipedia
  ├── 去中心化网络 → 互联网协议设计的哲学源泉之一
  └── 生态无政府主义 → 深生态学/反增长运动

对批判理论的贡献：
  福柯(Foucault)的权力微观分析 → 深受无政府主义影响（他本人否认）

  大卫·格雷伯(David Graeber, 1961-2020) → 当代最重要的无政府主义人类学家
    《债务：最初的5000年》
    《民主项目》
    "我们是99%"口号的创作参与者
```

## 六、理论位置

```
在增量/存量框架中：

无政府主义是对"存量时代"最彻底的诊断，也是最激进的处方：

  诊断（与图尔钦/波兰尼高度重合）：
    → 社会问题的根本原因是权力结构性不平等
    → 无论是资本主义还是国家社会主义，都无法摆脱这一结构

  处方（与现有理论根本不同）：
    → 不是改革国家（社会民主主义）
    → 不是夺取国家（马克思主义）
    → 而是废除强制性权力本身

  现实张力：
    存量时代的社会不满 → 通常走向民粹主义（特朗普/极左）或技术官僚解决方案
    无政府主义提供的路径：重建去中心化的自治社区
    → 这在实践上极难，但在当代"去信任"环境中有新的吸引力
```
