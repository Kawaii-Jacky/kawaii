# ADHD 注意力缺陷多动障碍

> 本笔记总结自《世界ADHD联盟国际共识声明：208条循证结论》（2021年3月），来自27个国家79位研究者联署，涵盖超过2000人的原始研究及5项以上的Meta分析。

---

## 一、定义与本质

ADHD（注意力缺陷多动障碍）是一种**慢性精神发育障碍**，核心特征为：
- 与发育水平不相称的**注意力缺陷**和/或**冲动/多动症状**
- 症状损害生活的许多方面（学业、职业、社交、家庭）
- 起病于童年或青春期，常持续到成年

ADHD 是真实存在的医学障碍，符合 Robins 和 Guze 建立的精神障碍有效性标准，**不是性格问题或教育失当的结果**。

## 二、历史沿革（不是新疾病）

| 年份      | 事件                                 |
| ------- | ---------------------------------- |
| 1775    | 德国医师 Weikard 首次以书面形式描述ADHD特征       |
| 1798    | Alexander Crichton 在英国医学教科书中记录类似疾病 |
| 1845    | Heinrich Hoffmann 在儿童读物中描述ADHD样行为  |
| 1902    | 英国医师 George Still 在科学杂志首次正式撰写描述    |
| 1937    | Charles Bradley 发现苯丙胺类药物可减轻ADHD样症状 |
| 1960s   | 美国FDA批准哌醋甲酯（利他林）用于儿童行为障碍           |
| 1970s至今 | ADHD诊断标准基于研究不断完善                   |

## 三、诊断标准

### 诊断要求（需同时满足）
1. 至少**6个月**内出现发育不良的多动冲动和/或注意力不集中症状
2. 症状出现在**不同环境**（如家庭和学校）
3. 症状导致**生活功能障碍**
4. 一些症状和损害首先发生在**儿童早期至中期**
5. 无其他障碍可更好地解释症状

### 三种临床表现类型
- **注意力不集中为主型**：与学业障碍、低自尊、职业结局差相关
- **多动冲动为主型**：与同伴排斥、攻击性、危险驾驶、意外伤害相关
- **混合型**：兼具以上症状

### 诊断注意事项
- 只能由**有执照的临床医生**诊断，不能仅凭评定量表或神经心理测试
- ADHD不只是儿童疾病，可在**所有年龄段**诊断
- 高智商人群同样可以患ADHD，智商高不能排除诊断
- ADHD常与其他精神疾病**共病**（抑郁、双相、焦虑、自闭症谱系、品行障碍等）

## 四、患病率

| 群体 | 患病率 |
|------|--------|
| 青少年 | **5.9%**（全球普遍，无明显地区差异） |
| 成年人 | **2.5%–2.8%** |
| 老年人（50岁以上） | 约 **0.2%**（临床诊断率） |
| 性别差异 | 男女比例约 **2:1**（青少年） |
| 美国黑人青少年 | 约14%（需加强评估与监测） |

> 过去30年儿童ADHD患病率**未见明显升高**，但诊断率提高（反映政策和临床实践变化）。

## 五、病因

ADHD是**多因素共同作用**的结果，极少由单一遗传或环境因素引起。

### 遗传因素
- **遗传性强**：双胞胎研究证实基因起重要作用
- **多基因遗传**：大量遗传位点，每个效应很小，累积增加风险
- ADHD多基因变异与精神分裂症、抑郁、双相、自闭症、行为障碍等存在遗传重叠
- 罕见情况下：单基因缺陷或染色体异常也可导致

### 环境因素（关联因素）

| 类别    | 具体因素                                            |
| ----- | ----------------------------------------------- |
| 有毒物质  | 重金属铅（风险升高2-4倍）、有机磷农药（风险升高55%）                   |
| 产前暴露  | 孕期吸烟（风险升高50%+）、对乙酰氨基酚（+33%）、丙戊酸钠（+50%）、邻苯二甲酸酯   |
| 妊娠因素  | 早产/低出生体重（风险升高3倍）、母亲高血压（+25%）、母亲肥胖（+60%）、甲状腺功能异常 |
| 感染与应激 | 肠道病毒感染（+25%）、孕期严重精神压力（+100%）                    |
| 社会经济  | 家庭贫困、父母失业、父母受教育程度低、家庭逆境（累积风险）                   |
| 营养缺乏  | 铁蛋白降低、Omega-3 PUFA偏低、母亲维生素D不足（+50%）             |

## 六、大脑研究发现

> ⚠️ 以下差异**不能用于诊断ADHD**，且通常在ADHD患者与其他疾病患者间无显著差别。

### 认知/心理测试发现
- **工作记忆**：中等程度损伤
- **持续注意力**：小到中等程度困难
- **抑制控制**：中等程度受损
- **决策倾向**：偏好立即小奖励而非延迟大奖励（冲动性决策）
- **智商**：轻微低于平均，但无临床意义
- 儿童青少年的认知损伤大于成年人

> [!info]- 📖 名词解释：工作记忆（Working Memory）
> 大脑的**"临时草稿纸"**——在完成一件事的过程中，**暂时存储并同时操作**信息的能力。
> 
> - **容量极小**：正常人约能同时保持 4±1 个信息组块
> - **主动操作**：不只是存储，还要边记边用（如心算多位数、听课时记住要点同时理解新内容）
> - **易受干扰**：一被打断，内容即消失，无法自动恢复
> 
> **ADHD 中的表现**（容量平均减少约 1 个标准差）：
> - 被交代三件事，走到另一个房间只记得一件
> - 看书看到第三段，忘了第一段说什么
> - 脑子里有个想法，一分心就永远消失了
> - 答题时忘了题目要求，写着写着跑题
> 
> → 神经机制详见 [[心理学/ADHD神经递质机制]]

> [!info]- 📖 名词解释：抑制控制 与 执行功能（Executive Function）
> **执行功能**是大脑的**"项目经理"**——一组让你能有目的地、灵活地完成复杂行为的高级认知控制能力集合，不负责具体执行，而是负责**规划、调度、监督、纠偏**。
> 
> 核心三维度（Miyake模型）：
> 
> | 维度 | 说明 | ADHD 典型表现 |
> |------|------|-------------|
> | **抑制控制** | 压制冲动反应、无关思维、外部干扰 | 冲口而出；停不下来；走神无法自止 |
> | **工作记忆更新** | 实时监测并替换脑中维持的信息 | 写到后面忘了前面；丢失任务上下文 |
> | **认知灵活性** | 在不同任务/规则/思维框架间切换 | 计划突然变动时慌乱；固执于旧规则 |
> 
> 广义还包括：任务启动、情绪调节、时间感知、计划与问题解决。
> 
> **工作记忆**是执行功能的核心"原料"；**执行功能**决定如何调用工作记忆——两者高度依赖前额叶皮层的多巴胺与去甲肾上腺素系统。
> 
> → 神经机制详见 [[心理学/ADHD神经递质机制]]

### 神经影像学发现
- **大脑结构**：儿童总皮层表面积轻微减少；基底神经节、杏仁核、海马等皮层下核团体积略小；这些差异在青少年和成人中**未见**
- **大脑功能**：认知控制相关区域（右额下回、基底神经节）激活降低
- **白质**：胼胝体等区域连接存在细微差异
- 所有观察到的差异均**很小**，且**不因药物治疗引起**

## 八、社会心理影响

### 生活质量
- 患者本人及父母均报告生活质量**明显下降**
- 情感、社交、学业功能**严重受损**；随年龄增长进一步下降
- 患儿父母生活质量**中度受损**

### 情绪与社交
- 情绪激动、行为问题的可能性是常人的**6倍**
- 同伴社交障碍（被排斥、友谊建立困难）
- 参与欺凌的可能性是常人的**2.4–2.8倍**

### 意外伤害
- 烧伤风险：儿童+75%（6岁以下+100%）
- 意外身体伤害：+40–50%
- 严重交通事故：+50%
- 脑震荡（3次以上）：+3倍

### 英年早逝与自杀
- 自杀率是常人的**2倍**
- 自杀意念：常人的**3倍以上**
- 自杀完成：常人的**6倍以上**
- 死亡主因：意外事故

### 违法犯罪
- 刑事犯罪可能性：常人的**2倍多**
- 监禁可能性：常人的**3倍多**
- 监狱中ADHD患病率：约**20.5%**

### 学业与职业
- 高中不按时毕业：常人的**2倍**
- 特殊教育需求：常人的**8倍多**
- 就业率减少12%，收入减少34%

### 物质使用障碍
- 尼古丁依赖：常人的**3倍**
- 药物/酒精使用障碍：+50%
- 酒精使用障碍（儿童期）：+2倍

### 其他
- 少女怀孕风险增加
- 赌博、冲动消费风险增加
- 痴呆症风险：常人的**3.4倍**（成年ADHD患者）

## 十、药物治疗

### 主要药物类型

| 类型   | 药物                | 效果                       |
| ---- | ----------------- | ------------------------ |
| 兴奋剂  | 哌醋甲酯（利他林）、苯丙胺类    | **最有效**；青少年首选哌甲酯，成人首选苯丙胺 |
| 非兴奋剂 | 托莫西汀（择思达）、胍法辛、可乐定 | 中等效果；兴奋剂不耐受时使用           |

### 药物治疗的额外益处
药物治疗可**显著降低**以下风险：
- 意外伤害（-10–40%）
- 创伤性脑损伤（-70%）
- 严重交通事故（男性-50%）
- 犯罪率（-30–40%）
- 抑郁（-40%）
- 自杀（-20–70%）
- 物质滥用（-30%）
- 吸烟（-50%）
- 少女怀孕（-30%）

### 副作用（通常较轻，可处理）
- 食欲下降、体重减轻
- 入睡困难、睡眠缩短
- 腹痛
- 轻微心血管影响（少见）
- 身高增长轻微延迟（2cm/1-2年，可逆）
- **不增加**精神病性障碍风险
- **不增加**自杀风险（反而降低）

### 孕期用药注意
- 孕期使用哌甲酯与轻微升高的心脏畸形风险相关（需权衡利弊）

## 十一、非药物治疗

> 非药物治疗对核心ADHD症状的疗效**不及药物**，但可作为药物治疗的辅助。

| 治疗方法 | 效果 |
|---------|------|
| **父母培训**（学龄前） | 父母报告的症状中等改善，但独立评估效果有限 |
| **认知行为治疗（CBT）** | 成人ADHD自我报告中等改善；设盲研究仅小幅改善 |
| **认知训练** | 工作记忆小到中等改善 |
| **神经反馈** | 设盲研究显示注意缺陷小幅改善，多动-冲动无显著效果 |
| **组织技能干预** | 中等程度减轻注意缺陷症状 |
| **Omega-3脂肪酸** | 小到中等程度改善（4项Meta分析结果不一） |
| **锻炼** | 中等改善（调整发表偏倚后效果减弱）；可显著减轻焦虑和抑郁 |
| **冥想疗法** | 证据不充分，方法学质量有限 |
| **社交技能训练** | 未改善教师评估的社交技能或学业 |
| **限制食品添加剂** | 小幅改善 |

## 十二、总结：循证核实的核心观点

> ✅ **ADHD是真实的医学障碍**，两个多世纪以来有详细记录
> ✅ 在**全球范围内普遍存在**，不同文化和地区患病率相似
> ✅ 主要由**遗传与环境因素共同作用**导致，而非单一原因
> ✅ 影响**大脑结构与功能**，但差异细微且无法用于诊断
> ✅ 带来**广泛的身心健康风险**和社会经济负担
> ✅ **药物治疗安全有效**，且能预防许多不良结局
> ✅ 非药物治疗有价值，但通常需**与药物治疗结合**

## 十三、最新研究进展（2024–2026）

> 以下内容来源于近年发表的最新研究，对第五章病因部分有重要补充与深化。

### 🧬 1. 罕见基因变异的重大突破（2025年 *Nature*）

2025年，*Nature* 发表了**史上最大规模ADHD外显子组测序研究**（8,895名ADHD患者 vs 53,780名对照），取得关键发现：

- 识别出**三个高风险罕见基因变异**：**MAP1A、ANO8、ANK2**
  - 携带这三种变异的人，患ADHD风险**升高5.5至15倍**（优势比OR=5.55–15.13）
- **MAP1A**：参与微管组装，对神经元结构完整性至关重要
- **ANK2**：编码锚蛋白，与神经元稳定性密切相关
- **ANO8**：功能仍在研究中，可能与神经元离子调控有关
- 这三个基因的蛋白互作网络，与**细胞骨架组织、突触功能、RNA加工**高度相关
- 风险基因在**GABAergic（抑制性）和多巴胺能神经元**的产前及产后发育阶段均有较高表达
- 携带者通常伴随**智商偏低、教育程度低、社会经济水平差**

> 💡 ADHD的遗传率约为**76–88%**，但已知变异仅能解释约20%的遗传风险——说明仍有大量未知机制。

---

### 🧠 2. 神经递质机制的深化理解

当前研究认为ADHD的神经化学机制远比"多巴胺不足"复杂：

| 神经递质           | 作用             | 在ADHD中的异常                                          |
| -------------- | -------------- | -------------------------------------------------- |
| **多巴胺（DA）**    | 奖励、动机、工作记忆     | 前额叶皮层多巴胺信号**调控失常**（非单纯缺乏）                          |
| **去甲肾上腺素（NE）** | 持续注意、执行功能、冲动控制 | 前额叶NE传递减弱                                          |
| **血清素（5-HT）**  | 情绪调节           | 部分参与情绪症状                                           |
| **组胺（H2R）**    | 2025年新发现       | 黑质网状部（SNr）的PV神经元H2R表达下降→出现ADHD症状；H2R激动剂可改善症状（小鼠模型） |

- 药物作用机制：通过**促进释放或阻止再摄取**来提升突触间隙的DA和NE水平

---

### 🔬 3. 大脑神经影像亚型（2025年）

2025年基于**6,509名青少年**的大规模脑影像研究（半监督深度学习），发现ADHD存在**3种神经生物学亚型**：

| 亚型 | 皮层厚度特征 | 临床表现 | 多巴胺通路 |
|------|------------|---------|-----------|
| **发育不足型** | 皮层厚度偏低 | 认知分数低，社会经济水平差 | 多巴胺/兴奋性通路上调（对兴奋剂反应较好） |
| **发育过度型** | 皮层厚度偏高 | 药物反应最差 | 多巴胺通路异常方向相反 |
| **混合型** | 混合特征 | 最严重：情绪失调明显，注意+多动合并 | 多巴胺通路上调 |

> 💡 这一发现**解释了为什么相同诊断的患者对药物反应差异巨大**，为精准治疗奠定基础。

---

### 🦠 4. 肠道菌群与神经炎症（2024–2025年新兴研究）

**肠-脑轴（Gut-Brain Axis）**正成为ADHD病因研究的新方向：

- **ADHD患者的肠道菌群特征**：
  - 菌群**多样性降低**
  - 短链脂肪酸（参与神经信号的关键代谢物）水平偏低
  - 肠道屏障功能受损，导致全身性**低度炎症**

- **机制路径**：肠道菌群 → 调控多巴胺合成与炎症因子 → 影响大脑前额叶功能

- **影响因素**：抗生素使用、高糖高脂饮食、慢性压力均可恶化菌群失衡，加重ADHD症状

- **干预提示**：增加全谷物、蔬菜、豆类、坚果；减少精制糖、饱和脂肪

> ⚠️ 目前为**相关性研究**，因果关系仍待确认，但证据持续增强。

### 📊 病因层次综合模型（2026年视角）
