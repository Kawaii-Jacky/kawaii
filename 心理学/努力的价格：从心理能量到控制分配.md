# 努力的价格：从心理能量到控制分配

> **根节点**："认知能量"这个词其实是**两个隐喻焊在一起**：一个来自十九世纪的热力学（能量是一种可耗尽的实体），一个来自经济学（注意力是一种可分配的稀缺预算）。前者在 2016 年被大样本复现杀死，后者活了下来并且比以前更有用。本篇的任务是**拆焊**——扔掉热力学那一半，把经济学那一半做成一个真正的模型：**努力不是一个被消耗的量，是一个价格。**
>
> **叙事逻辑**：两个隐喻的焊合与一次死亡 → 为什么经济学那一半活着 → 重构：努力作为控制的价格 → 影子价格定理（含流与断崖的统一解释）→ 三层成本 → 社会设定努力的价格（无费力作为文化资本）→ 意志力的道德经济学（为什么这个概念死不掉）→ 判据 → 局限。
>
> **立场说明**：本篇最硬的判断是一个形式上的：**主观努力感 = 约束的影子价格**。这不是类比，是约束优化里 Lagrange 乘子的定义。它一次给出三个结论：约束松弛时努力感为零（流的解释）、约束紧致时努力感升起、约束被外部设定时努力感可以被改变。
>
> **来源标注**：2026-11-01 至 11-02 的对话重构。

## 一、一次焊合，一次死亡

### 1.1 热力学隐喻：从赫尔姆霍茨到弗洛伊德

"心理能量"不是一个心理学发现，是**十九世纪物理学的文化输出**。

能量守恒定律（1847，赫尔姆霍茨）确立后，它迅速变成一种世界观：**宇宙是一个封闭的能量系统，一切现象都是能量的转换。**而心理学在争取科学资格的年代，最自然的做法就是把"心灵"也写进这套账本。

弗洛伊德的《科学心理学大纲》（1895）就是这个动作的极致：神经元被写成"数量的系统"，心理活动被写成**能量的分配、投注（Besetzung）、移置与耗竭**。而"力比多"本质上是一个**经济量**——他晚年自己用的词就是 *Libidoökonomie*（力比多经济学）。

同一时期，法国的让内（Pierre Janet）提出"心理张力"（tension psychologique）与"心理力量"（force psychologique），也是同一个隐喻：**精神是一种有储量的东西，储量低则功能下降。**

> 📌 **心理能量（psychic energy）**：一个来自十九世纪物理学的隐喻，把心理活动描述为某种可积累、可消耗、可转移的"量"。它在弗洛伊德那里成为元心理学的地基，在整个二十世纪被当作不言自明的前提。

**这个隐喻有一个从未被检验的性质**：它假设**总量守恒**。而这正是它后来的死因——如果总量守恒，那么"用完了"应该是一个可测量的状态；而如果测不出来，这个隐喻就没有内容。

### 1.2 经济学隐喻：从"注意力预算"到"认知吝啬鬼"

第二个隐喻来自经济学，而它比热力学那个**晚得多、也精确得多**。

卡尼曼 1973 年的《注意与努力》把它写成"容量模型"：注意是一个有限的容量，任务竞争这个容量。而 1980 年代，"认知吝啬鬼"（cognitive miser，Fiske & Taylor）把这个隐喻推到社会认知：**人默认用最省力的启发式，只在必要时才投入分析。**

注意这两个隐喻的差别：

| | 热力学隐喻 | 经济学隐喻 |
|---|---|---|
| 核心假设 | **能量守恒** | **资源稀缺 + 可分配** |
| 关键问题 | 还剩多少？ | 该分配给谁？ |
| 失败方式 | 耗尽 | 错配 |
| 能否被证伪 | 能（测不出储量就是错的） | 难（分配问题是恒真的） |

**这个差别决定了它们的命运。**

### 1.3 2016：大样本复现杀死了哪一半

"自我损耗"（ego depletion）是热力学隐喻的实验版本：意志力像肌肉，用多了会耗尽，休息或葡萄糖可以恢复。

2016 年，Hagger 等组织 **23 个实验室、N = 2141 的预注册多实验室复现**：

> **效应量 d ≈ 0.04——基本为零。**原始元分析报告的是 d ≈ 0.62。

在心理学的方法学等级里，大样本预注册多实验室复现是最强的证据形式之一。所以这不是"有争议"，是**这个效应在标准范式下不存在**。

**但要精确地说它杀死了什么**：它杀死的是"**存在一个可耗尽的统一资源**"这个假设。它**没有**杀死"努力有成本、成本可比较、人会在任务间分配"——因为后者不依赖于存在一个储量。

### 1.4 葡萄糖漱口：信号而非燃料

第二个决定性证据更漂亮。

Molden 等（2012）：让被试把葡萄糖水含在嘴里，然后**吐掉**——不吞下去。结果：**表现恢复了。**

如果是燃料，漱口没用（葡萄糖没进血液）。它有效，说明起作用的是**口腔的甜味受体**——也就是**信号**，不是**能量**。

> **这一条几乎单独就否定了热力学隐喻。**因为燃料必须被代谢，而信号只需要被感知。

而它同时**支持**了经济学隐喻：如果努力感是一个**信号**，那么它就是可以被"欺骗"的——而一个可以被信号欺骗的系统，正是**用信号做分配决策**的系统，不是**用储量做限制**的系统。

## 二、为什么经济学那一半还活着

### 2.1 最小努力原则的谱系

"人倾向于用最少力气达成目的"这个命题，比心理学古老得多，而且它在好几个不相干的领域独立出现过：

| 领域 | 表述 | 提出者／年代 |
|---|---|---|
| **物理学** | 最小作用量原理 | Maupertuis, Euler, 18 世纪 |
| **语言学** | 词频与词长成反比（省力原则） | Zipf, 1949 |
| **行为主义** | 在其他条件相同时，选择所需反应较少的路径 | Hull 的"少做功定律"，1943 |
| **认知心理学** | 认知吝啬鬼 | Fiske & Taylor, 1984 |
| **决策论** | 有限理性与满意化 | Simon, 1955 |

> **注意第五行**：西蒙的"满意化"（satisficing）是关键的一步——它把"最优化"替换成"够好就停"，而**这个替换的理由正是搜索成本**。所以"省力"不是懒惰，是**在搜索成本为正的世界里的理性策略**。

### 2.2 分配问题不会因为资源模型错而消失

这是本节的核心论点：

> **"存在一个可耗尽的能量池"这个假设错了，不等于"没有分配问题"。**

一个系统只要有：
- 多个竞争的目标，
- 单一的执行通道（你一次只能做一件事），
- 且切换与维持都有成本，

就**必然**有一个分配问题。而分配问题**不需要**一个储量来成立。

**这就是为什么经济学隐喻活着**：它描述的是**结构**（稀缺 + 选择 + 机会成本），而结构不依赖于本体论的具体形式。

### 2.3 结论：换掉本体论，保留问题

所以正确的做法不是"抛弃努力这个概念"，是：

> **扔掉"它是一种可耗尽的实体"，保留"它是一个需要被分配的东西"。**

而一旦这么做，"努力"就不再是一个**状态**（我还有多少），而是一个**价格**（做这件事要我付多少）。

**这个转换是整篇的枢纽。**

## 三、重构：努力作为控制的价格

### 3.1 控制分配问题（EVC）

Shenhav 等（2013, 2017）提出的"控制的期望价值"（Expected Value of Control, EVC）模型，是这个重构最成熟的版本。

核心命题：**大脑在决定"要不要投入控制"时，算的是一个期望值**：

$$\text{EVC}(a) = \underbrace{P(\text{success} \mid a) \cdot V(\text{outcome})}_{\text{控制的收益}} \;-\; \underbrace{C(a)}_{\text{控制的成本}}$$

投入控制，当且仅当 $\text{EVC} > 0$。

**这个模型的关键贡献在于：它把"努力"从"消耗"变成了"投资决策"。**

而它立刻解释了几件"资源模型"解释不了的事：

| 现象 | 资源模型 | EVC 模型 |
|---|---|---|
| 感兴趣的事不累 | 无法解释（燃料一样在烧） | 收益项高，抵消成本 |
| 给钱能延长时间 | 无法解释 | 提高了 $V$ |
| 无聊的事十分钟就崩 | "意志力弱" | 成本高且收益低，EVC < 0 |
| 快成功时突然不累了 | 无法解释 | $P(\text{success})$ 上升 |

### 3.2 努力的价格函数

把成本项展开，得到一个三层结构：

$$C(a) = \underbrace{c_{\text{met}}}_{\text{代谢}} + \underbrace{c_{\text{opp}}}_{\text{机会}} + \underbrace{c_{\text{soc}}}_{\text{社会}}$$

三层的时间尺度、可塑性、以及"能否被意志改变"完全不同（第五节展开）。

### 3.3 为什么这个重构比"资源"强

三个理由：

**① 它可以解释"分配"，而资源模型只能解释"耗尽"。**

资源模型预测：做完 A 之后做 B 会变差。而实际上，**做完 A 之后做 B 有时会变好**（换环路、换兴趣）——资源模型对此无解，分配模型直接推出。

**② 它允许"价格"被社会设定。**

这是最重要的一条：如果努力是价格，那么**谁定价**就成了一个政治经济学问题（第六节）。而"资源"是一个自然事实，没有定价者，也就没有权力关系。

**③ 它把"疲劳"从故障变成了信息。**

资源模型里，累 = 油快没了 = 系统出问题。分配模型里，累 = **当前活动的边际价值低于替代活动** = 系统在提示重新分配。

> **后者意味着：疲劳是可以被"读懂"的，而不是只能被"忍受"的。**

## 四、影子价格定理

这是本篇最技术、也最有收获的一节。

### 4.1 Lagrange 乘子是什么

在约束优化里，我们要求最大化 $f(x)$，受约束 $g(x) \leq b$。

构造拉格朗日函数：

$$\mathcal{L}(x, \lambda) = f(x) - \lambda\,[g(x) - b]$$

而 $\lambda$（Lagrange 乘子）有一个精确的解释：

> **$\lambda = \dfrac{\partial f^*}{\partial b}$——约束放松一个单位，最优值能提高多少。**

也就是说，**$\lambda$ 是"约束的影子价格"**：它告诉你，这个限制值多少钱。

**而关键的性质是**：

> **当约束不起作用时（$g(x) < b$，松弛），$\lambda = 0$。**

因为约束不卡着你，放松它没有任何好处。

### 4.2 主观努力感 = λ

现在把这个结构套到控制分配上。

设：控制资源是约束 $g$，任务要求是 $b$，而 $\lambda$ 是"多一单位控制能力值多少"。

**本篇的核心断言**：

> **主观努力感就是这个 $\lambda$。**

理由：努力感的功能是**告诉你这件事有多贵**——而"多贵"在约束优化里正是 $\lambda$ 的定义。它不是储量的读数（那会随储量单调变化），它是**约束的边际价值**（那会在约束松弛时归零）。

**这个断言一次给出三个可检验的推论。**

### 4.3 推论一：流（约束松弛 → λ = 0）

**心流为什么感觉不到努力？**

资源模型的答案是"因为注意力集中，没注意到"——这是循环论证。

影子价格的答案是：

> **因为在这个状态下，控制约束不卡着你。**任务的要求没有超过你可调用的控制能力，所以 $\lambda = 0$，**努力感的读数为零**。

而"不卡着"有三种来源，正好对应心流的三个经典条件（Csikszentmihalyi）：

| 心流条件 | 在模型里 |
|---|---|
| 挑战与技能匹配 | 约束恰好不被超过 → λ 接近 0 |
| 目标清晰 | $V(\text{outcome})$ 明确，不需要额外搜索 |
| 即时反馈 | 持续更新 $P(\text{success})$，避免误差累积 |

**而这就解释了那个反直觉的事实**：心流不是"努力到极致"，是**约束恰好松弛**。**它不是意志的胜利，是定价的巧合。**

> 推论（重要）：**心流不能被"努力进入"，只能被"条件匹配"诱发。**试图"努力进入心流"恰恰会提高约束的紧致度——这就是库内"越专注，越不专注"（兴趣驱动篇 2.1）在价格语言里的形式：**意志努力本身在提高 λ。**

### 4.4 推论二：断崖（约束由松转紧）

库内 0-1 篇 6.3 记录："一旦冷却就是断崖，而非缓坡。"

**为什么是断崖？**因为 $\lambda$ 在约束的边界上不是连续变化的。

在松弛区（$g < b$），$\lambda = 0$，努力感恒为零；
一旦 $g$ 触及 $b$，$\lambda$ 从零**跳到一个正值**，而且随 $g$ 超过 $b$ 的幅度快速上升。

> **所以努力感不是"逐渐增加"，是"在某个点突然出现"。**

这精确对应超聚焦的经验：**长时间"不累"，然后突然"完全不行"。**中间没有过渡，因为 $\lambda$ 本身没有过渡——它是分段函数。

而这也解释了为什么"昨天还好好的，今天完全不行"：不是昨天透支了（透支是资源模型的语言），是**约束的位置在夜间移动了**（睡眠不足使 $b$ 下降），于是同样难度的任务今天越过了边界。

### 4.5 推论三：代谢物改变的是约束的位置

Wiehler 等（2022, *Current Biology*）的发现——6.5 小时高强度认知工作后外侧前额叶谷氨酸积累上升，且预测决策转向"低努力、短延迟"——在这个模型里有了精确位置：

> **谷氨酸积累不"消耗"什么，它降低 $b$——即可调用的控制能力上限。**

于是：
- 同样难度的任务，在积累之后**越过边界**，λ 从零变为正；
- 而"低努力、短延迟"的转向，是 **EVC 重算的结果**：高成本任务的 EVC 变负，低成本的仍然为正。

**这个解释比"燃料耗尽"强的地方在于**：它预测了**方向**（转向低成本选项），而不只是"能力下降"。一个燃料耗尽的系统应该**什么都做不好**；而一个约束收紧的系统会**选择性地放弃高成本任务**——这正是实验观察到的。

## 五、三层成本

### 5.1 代谢层

| 性质 | 内容 |
|---|---|
| 机制 | 谷氨酸等代谢物积累 |
| 时间尺度 | 小时（累积），夜间（清除） |
| 可否被意志改变 | **不能** |
| 恢复方式 | **睡眠**（清除），不是补充 |
| 在模型里 | 改变 $b$（控制能力上限） |

**关键性质**：它单调累积，只有睡眠真正清零。咖啡因掩盖信号（阻断腺苷受体），不加速清除。

### 5.2 机会层

| 性质 | 内容 |
|---|---|
| 机制 | 边际价值比较（Kurzban 等 2013） |
| 时间尺度 | 分钟（可变） |
| 可否被意志改变 | **能**（改变价值评估） |
| "恢复"方式 | 换任务、提高报酬、找到意义 |
| 在模型里 | 改变 $c_{\text{opp}}$，即 $V$ 的相对值 |

**这就是"再坚持一下有时有用、有时没用"的原因**：如果疲劳主要来自这一层，改框架真的有用；如果已经到了代谢层，改框架只是**掩盖信号**。

**误判这两层，是所有时间管理建议失败的根本原因。**

### 5.3 社会层

第三层是本文最想引入的，因为主流文献几乎不讨论它。

| 性质 | 内容 |
|---|---|
| 机制 | 努力的社会评价（见第六节） |
| 时间尺度 | 年—代 |
| 可否被意志改变 | **不能**（它是外部设定的） |
| 在模型里 | 改变 $c_{\text{soc}}$，即"做这件事在他人眼中意味着什么" |

这一层的存在意味着：**努力的价格有一部分不由你决定。**而这一部分恰恰是最被心理学忽略的。

## 六、社会设定努力的价格

### 6.1 韦伯：延迟满足的宗教价格

韦伯（1904–05）的论证常常被读成"新教促进了资本主义"，但更精确的读法是：**新教重新设定了努力的价格。**

在加尔文宗的预定论下，得救与否已定，善行无法改变。但救赎焦虑需要一个**迹象**——而系统化的世俗劳动提供了这个迹象。

关键的一步是：

> **劳动的价值不再由它的产出决定，而由它作为"蒙恩证据"的性质决定。**

这在价格语言里意味着：**$c_{\text{opp}}$（机会成本）被宗教性地压低了。**因为劳动不再与"更好的替代活动"竞争——它本身就是目的。

**这就是"越努力越安心"的机制**：不是努力产生回报，是**努力本身在当时被定价为零成本**（甚至负成本，因为不努力会产生焦虑）。

> 这解释了后来那个悖论：**为什么人在回报消失后仍然努力？**因为在信念的原始形态里，努力不换取回报——**努力就是回报的证据。**

### 6.2 布迪厄：无费力作为文化资本

这是本节最锋利的一条，也是主流努力研究完全忽略的一条。

布迪厄（《区分》，1979）的核心观察之一：**在精英场域里，"毫不费力"是一种资本。**

```
体面的努力   ：需要努力才能做到 → 说明你不属于这里
自然的优雅   ：不费力就能做到   → 说明这就是你
```

**为什么"不费力"值钱？**因为它证明了两件事：

1. **你有天赋**（不是靠努力堆出来的）；
2. **你有早期投资**（你在能努力之前就已经被养成了）。

> **所以"展示努力"在精英场域里是负资产**——它暴露了你需要努力，而需要努力本身就意味着你不属于。

**在价格语言里**：$c_{\text{soc}}$（努力的社会成本）在精英场域是**正的高值**——你不仅要付代谢与机会成本，还要付**暴露成本**。

而这条有一个极其重要的推论：

> **在一个"无费力"被奖励的场域里，理性策略不是少努力，是"努力但不让人看见"。**

**这就是"隐藏的努力"（hidden effort）的结构**——而它完美解释了库内[[心理学/本科生欲望分化与文化资本避险]]第二节那个现象：直接追钱被编码为"粗俗"，**"用力过猛"同样被编码为 low-status。**

### 6.3 凡勃伦：有闲作为地位的展示

凡勃伦（《有闲阶级论》，1899）给了这个结构的另一面：**有闲阶级通过"不从事生产性劳动"来展示地位。**

因为在一个生产性劳动被视为低贱的社会里，**能不劳动**本身就是财富的证明。

> **所以"努力的价格"在阶级维度上是分层的**：底层努力是义务，中层努力是美德，上层努力是**需要隐藏的失礼**。

这与 6.2 是同一件事的两个侧面：**努力的社会评价不是单调的，它随场域变化。**

### 6.4 一个推论：展示努力本身就是成本

把 6.1–6.3 合起来：

> **努力有三重价格**：代谢的（身体）、机会的（时间）、社会的（他人怎么看）。
>
> **而第三重价格完全由场域设定，且可以是负的（如韦伯的清教场域）或正的高值（如布迪厄的精英场域）。**

这解释了为什么同一件事在不同环境里"累"的程度完全不同——**不是你的身体变了，是价格被重新定了。**

而它也给出了一个非心理学的干预方向：**换场域**（让 $c_{\text{soc}}$ 变低），可能比任何"提高意志力"的训练都有效。

## 七、意志力的道德经济学

### 7.1 为什么这个概念死不掉

2016 年的复现已经足够有说服力，但"意志力"这个概念在公共话语里几乎没有动摇。为什么？

因为它**不只是一个心理学概念，它是一个法学与道德概念**。

> **"意志力"的功能不是解释行为，是分配责任。**

如果行为由"意志力"决定，那么"意志力不足"就是一个**可归责**的缺陷——它使得惩罚、羞辱、以及"你本可以做到"的指责成为可能。

而如果行为由"约束的位置 + 价格结构"决定，那么归责就变得困难——**因为你不能指责一个人"没有足够的 $b$"。**

### 7.2 尼采：意志是使惩罚成为可能的虚构

这一点尼采说得最透，而它的位置在《论道德的谱系》第二篇。

他的论证（简化）：

1. 惩罚需要一个人"**本来可以不这么做**"；
2. 而"本来可以"需要一个**中立的、能自由选择的意志**；
3. 所以"自由意志"不是被发现的心理事实，是**为了能够归责而被发明出来的虚构**。

> **尼采的原话大意**：所谓"意志的发明"，是为了让"你有罪"这句话能够成立。

这个判断对"意志力"同样适用：

> **"意志力强/弱"这个区分，其社会功能不是描述心理，是提供一个可归责的尺度。**

而一旦这个尺度被建立，它就会**自我强化**：被认为意志力弱的人被赋予更少的机会，而机会更少又"证明"了意志力弱。

### 7.3 与内在监工的接线

这一条直接接到库内[[心理学/情绪失调与人格整合系列/兴趣驱动型神经系统与内在监工：死结结构、病因学与系统全景]]。

那个"内在监工"（内化的规训者，核查"我够不够好"）使用的**正是这套道德经济学**：

```
监工的判据：  努力了吗？→ 没努力 → 你有问题
而真实机制：  约束的位置 + 价格结构 → 不是"努力与否"的选择
```

> **所以监工的整个审判是建立在一个错误的归因上的**：它把一个**结构性事实**（约束紧致、$b$ 低、$c_{\text{soc}}$ 高）读成了一个**道德事实**（我不够努力）。

而这也给出了干预方向，且与库内已有的判断一致——**不是"更努力"，是降低约束的紧致度**：
- 降低代谢负担（睡眠）；
- 提高 $b$（治疗基线、必要时用药）；
- 降低 $c_{\text{soc}}$（换场域，减少被审视）。

> **"再努力一点"是唯一确定无效且有害的应对**——因为它不改变 $\lambda$，只增加对 $\lambda$ 的**道德化解读**。

## 八、判据与阈值

### 8.1 三层判别

| 现象 | 主导层 | 正确的应对 | 错误应对 |
|---|---|---|---|
| 做了几小时后脑子"糊" | 代谢 | **睡一觉** | 喝咖啡 |
| 换个任务就能继续 | 机会 | 承认是借账，晚上要还 | 以为什么都能做 |
| 在某个场合特别累 | 社会 | 换场域／减少被审视 | 归因为自己不行 |
| 感兴趣的事不累 | 机会（$V$ 高，约束松弛） | 仍然要限时（代谢照常） | 无限延长 |
| 快完成时突然有劲 | 机会（$P$ 上升） | 利用窗口 | 误以为是意志力 |

### 8.2 阈值是可测量的

"每天思考足够的问题后会感到疲惫"——这个"足够"就是**约束从松弛转为紧致的那个点**，而它是可测量的。

记录四项：开始时间、开始"糊"的时刻、之前的有效时长、恢复所需睡眠。

| 观察 | 推断 | 应对 |
|---|---|---|
| **阈值稳定** | 生理常数（$b$ 的位置稳定） | 接受它，围绕它安排 |
| **阈值波动大** | 主导层是机会或社会（$V$ 或 $c_{\text{soc}}$ 在变） | 改任务结构／换场域 |
| **阈值持续下降** | $b$ 本身在下降 | **先排除生理原因**（睡眠、甲状腺、贫血、抑郁） |

> 第二行最重要：**如果波动大，你缺的不是休息，是任务与你的价格结构的匹配。**

## 九、努力的感觉不是量，是"我"与阻力之间的关系

在进入社会层之前，必须先补一个更古老的角度，因为它直接支持了第四节的影子价格断言，而它的提出时间比 Lagrange 早六十年。

### 9.1 迈内·德·比朗：努力是"我"反对阻力的意识

Maine de Biran（《习惯对思维能力的影响》，1802；《努力感》，约 1810）提出了一个今天几乎被遗忘、但极其锋利的论点：

> **努力感（effort）不是一种被感知到的"量"，是对"我的意志遇到了阻力"这件事的直接意识。**

他的分析：

```
纯粹的意志（我想抬起手臂）——如果没有阻力，就没有努力感
阻力出现（手臂很重／很累）——努力感才出现
```

> **而努力的强度，恰好等于"意志"与"阻力"之间差距的意识。**

注意这个结构与影子价格的**同构**：

| | 迈内·德·比朗 | Lagrange 乘子 |
|---|---|---|
| 努力感是什么 | 意志与阻力之间的关系 | 约束对目标值的边际影响 |
| 何时为零 | 无阻力时 | 约束松弛时 |
| 何时最大 | 阻力恰好快要压倒意志时 | 约束紧致时 |

**两个人在完全不同的世纪、完全不同的问题上，给出了同一个形式。**而这不是巧合——因为**"阻力相对于能力有多大"就是这两者共同描述的东西**。

### 9.2 这条对本文的修正

迈内·德·比朗的版本比本文更激进，而他有一部分是本文缺的：

> **他强调努力感里包含"我"（the self）的在场。**

也就是说：努力感不只是"这件事难"，它还包含"**是我在抵抗**"这一层。这就是为什么极度疲劳时的体验不是"难"，而是"**我不行了**"——**自我的位置从"抵抗者"滑到了"被抵抗者"**。

而这一点在本文的模型里没有位置（λ 只是一个数，没有"谁"）。这是一个真实的缺口。

**而它接上了库内[[心理学/情绪失调与人格整合系列/兴趣驱动型神经系统与内在监工：死结结构、病因学与系统全景]]的核心**：那个"内在监工"之所以有效，正是因为它**把 λ 的读数归因给了自我**——"不是这件事贵，是你不行"。

### 9.3 詹姆斯的"注意的努力"

詹姆斯（《心理学原理》，1890）有一个相关的观察，而它常被引用错。

他说的不是"注意力有限"，是：

> **注意的努力感，出现在"要抓住一个正在逃走的观念"时。**

也就是说：**努力感的强度 = 对象逃离注意的倾向**。

这与 9.1 完全一致——**努力感测量的不是投入的量，是"对抗的强度"**。而一个稳定的、不逃走的对象，无论你盯多久，都不产生努力感。

> **这解释了心流的另一半**（4.3 只解释了约束松弛）：在心流中，对象**不逃**——它自己在吸引注意。所以努力感为零，不是因为你不投入，是因为**没有对抗**。

## 十、劳动过程中的努力：为什么它必须被"榨取"

前面的层都是"个体如何分配努力"。但努力还有一面是本文完全没碰的：**在现代生产里，努力不是自己用的，是被别人买走的。**

### 10.1 泰勒之后：努力从"技艺"变成"可榨取的量"

布雷弗曼（Harry Braverman,《劳动与垄断资本》，1974）的核心论点，用本文的语言重述：

> **泰勒制的真正发明不是"科学管理"，是把"努力"从一个不可分割的技艺整体，拆成可计量、可定价、可榨取的单元。**

在此之前，一个工匠的努力和他的判断是绑在一起的——你不能只要他的力气，不要他的手艺。泰勒制做的正是这件事：**把判断剥离出去（交给管理层），只留下可计量的动作。**

> **在价格语言里**：泰勒制不是降低了努力的成本，是**让努力第一次成为可以被单独定价的商品**。

而这就产生了一个新问题，而它是整个劳动社会学的中心问题：

> **劳动契约买的是"劳动能力"，不是"劳动"。**——你雇了一个人八小时，但你买到的是他八小时里**实际投入了多少努力**，这一点你无法在合同里写死。

### 10.2 布洛维：努力是一场被"游戏化"的协商

布洛维（Michael Burawoy,《制造同意》，1979）接了这个问题，而他的答案极其精彩：

> **工人不是被动地被榨取，而是主动参与了一场"超额完成"的游戏。**而这场游戏的功能，是**让"投入多少努力"这个问题变得可以忍受**。

他的田野观察：工人在"赶工"（making out）中获得的，不只是计件工资，还有一种**游戏式的满足**——赢了这个配额。

**在本文的模型里**：
- 计件工资改变了 $V$（收益）；
- 但更重要的是，它改变了对**努力本身的解释**——从"被剥削"变成"我在玩一个我能赢的游戏"。

> **这是 §3 那个"最小修复"在劳动现场的应用**：工人面对"我在被剥削"这个高成本认知，最便宜的修复不是罢工（成本极高），是**把它重新解释为一场游戏**。

### 10.3 与本文的连接：努力的价格是被制度设定的

三条合起来，得到一个本文前面没有说透的判断：

> **"努力有多贵"这件事，一部分由你的身体决定，一部分由你的场域决定，而还有一部分——由谁买你的努力决定。**

而最后这一部分有独立的历史：它随**管理技术**变化，不随你的神经变化。

## 十一、职业健康：两条把"努力"接到疾病上的定律

这是本篇最强的经验支持，因为它是**大规模流行病学**，而不是实验室范式。

### 11.1 Karasek：要求—控制模型

Karasek（1979）的发现，而它推翻了"压力来自工作量大"这个直觉：

|  | 低要求 | 高要求 |
|---|---|---|
| **高控制** | 低 strain（闲职） | **主动型**（有挑战但可控，最好） |
| **低控制** | 被动型（无聊） | **高 strain**（最坏） |

> **决定健康后果的不是要求的高低，是"要求"与"控制"的比值。**

而这条**在本文的模型里有精确位置**：

- **要求** = $b$（需要多少控制）
- **控制** = 你可调用的 $g$
- **strain** = 当 $b$ 远超 $g$ 时的 $\lambda$

> **所以 Karasek 的"高 strain"就是本文的"λ 长期为正且很大"。**

而它解释了那个著名的发现：**高管要求高但不病，流水线工人要求不高但病**——因为后者的 $\lambda$ 更高（控制更少）。

### 11.2 Siegrist：努力—回报失衡

Siegrist（1996）的模型更接近本文的 EVC：

> **健康损害不来自努力本身，来自"高努力 + 低回报"的组合。**

而它给出了一个具体的生理通路：**努力—回报失衡 → 持续交感激活 → 皮质醇与炎症指标上升 → 心血管风险上升。**

> **在本文的模型里**：这就是 $\text{EVC} < 0$ 但**无法退出**的状态。系统持续投入控制，而收益项不兑现。

**关键在"无法退出"**：Siegrist 特别强调，失衡之所以致病，是因为人**不能选择不投入**（因为工作、身份、经济依赖）。这正是本文第三节的"成本被外部设定"的临床后果。

### 11.3 一个推论：这是"价格"模型的独立验证

为什么这两条对本文特别重要？

> **如果努力是一个"储量"，那么"努力多少"应该与健康单调相关——越多越伤。**
>
> **而流行病学的发现是：努力本身不致病，"努力与控制的关系"和"努力与回报的关系"才致病。**

**这是对"努力是价格而不是储量"的一次独立、大规模、跨文化的验证。**它不来自心理学实验室，来自职业医学。

而它有一个直接的实践含义：

> **降低努力的量（少干活）不改善健康；改变努力的价格结构（提高控制、恢复回报）才改善。**这与本文第七节的判断完全一致。

## 十二、三种负荷与专长的悖论

### 12.1 Sweller：认知负荷不是一种

斯威勒（John Sweller）的认知负荷理论（1988 起）把"负荷"拆成三种，而本文前面把它们混成了一个：

| 类型 | 来源 | 对学习的作用 |
|---|---|---|
| **内在负荷**（intrinsic） | 材料本身的复杂性 | 不可避免，与元素交互数成正比 |
| **外在负荷**（extraneous） | 呈现方式不佳造成的额外负担 | **纯浪费**，应消除 |
| **相关负荷**（germane） | 用于构建图式的努力 | **有益**，应保留 |

> **这个三分法直接修正了本文的"成本"概念**：不是所有成本都该被降低。

- 降低**外在负荷**（改进呈现、减少干扰）→ 纯收益；
- 降低**内在负荷**（拆分材料）→ 看情况；
- 降低**相关负荷**（让人轻松）→ **有害**，因为它削掉了学习本身。

**这就是本文模型的一个真实边界**：$\lambda$ 为正不总是坏事。**在"相关负荷"的情形下，$\lambda > 0$ 恰恰是学习正在发生的信号。**

（而这也解释了为什么"让学习变得毫不费力"的教育技术经常失败——它把三种负荷一起降了。）

### 12.2 专长的悖论：刻意练习要求"不舒服"

Ericsson 的刻意练习研究（1993 起）给了同一个判断的另一个版本：

> **专长的获得，要求在"刚好超出当前能力"的区间里反复练习。**而这个区间的定义性特征就是——**它让人不舒服**。

在本文的模型里，"刚好超出能力"就是 $b$ 略大于 $g$，即 **$\lambda$ 略大于零但可控**。

```
λ 太小（太容易）→ 无聊，不学习
λ 适中（略超能力）→ 学习区，不舒服但有效
λ 太大（远超能力）→ 崩溃，也不学习
```

**这是一条倒 U 曲线**，而它与库内[[心理学/情绪失调与人格整合系列/兴趣驱动型神经系统与内在监工：死结结构、病因学与系统全景]]2.1 提到的 Arnsten 倒 U（去甲肾上腺素与 PFC 功能）是**同一个形状**——只不过一个描述去甲肾上腺素，一个描述影子价格。

> **两个完全不同的理论，得出了同一条倒 U。**这是本节最有价值的发现：**"最优努力水平"这个概念，在神经化学层和约束优化层同时成立。**

### 12.3 与心流的关系（对 4.3 的修正）

4.3 说"心流 = 约束松弛 = λ 为零"。这一节要求修正：

> **心流是 λ≈0，但学习区是 λ 略大于 0。它们不是同一个状态。**

| 状态 | λ | 体验 | 产物 |
|---|---|---|---|
| 无聊 | ≈0（但 V 也低） | 无趣 | 无 |
| **心流** | ≈0（V 高） | 忘我 | **产出** |
| **学习区** | 略 >0 | 吃力 | **能力增长** |
| 崩溃 | 远 >0 | 痛苦 | 无（或损伤） |

> **所以"舒服"和"成长"是两个不同的点。**心流让你产出，学习区让你变强。而**把两者混为一谈，是现代"自我提升"话语最大的错误**——它承诺"在快乐中成长"，而这两件事在结构上是分开的。

## 十三、契约里的努力：为什么它无法被写进合同

最后一个角度来自信息经济学，而它揭示了一个本文没有明说的事实。

### 13.1 努力是"不可观测变量"

在委托—代理模型里，努力（effort）是典型的**不可观测变量**：

- 委托人能看见**结果**（产量、销售额）；
- 但看不见**努力**（因为你可能运气好，也可能方法巧）。

> **所以合同只能对结果定价，不能对努力定价。**

而这个不可观测性，正是本文所有问题的源头：

> **如果努力可以被直接观测和定价，那么"努力有多贵"就是一个公开的事，不需要你用自己的感受去估计。**

### 13.2 反向：为什么"感受"成了唯一的价格信号

把 13.1 翻过来，得到一个对本文极重要的推论：

> **在外部无法测量努力的地方，感受就是唯一的价格信号。**

这就是为什么：

- **你把疲劳当作"我尽力了"的证据**——因为在没有外部测量的情况下，感受是唯一的读数；
- **你把"不累"当作"我没尽力"的证据**——同一个机制的负面；
- **别人无法验证你累不累**——所以"我很努力"永远是一种**自我陈述**，而不是一个事实。

> **这就解释了"努力"为什么必然带道德色彩**（第七节）：**一个不可观测的变量，只能用道德来治理。**

而这也是为什么"努力"这个概念在管理上如此有用、在心理上如此有害——**它同时是一个治理工具和一个自我评价工具，而两者用的都是同一个不可靠的信号。**

### 13.3 效率工资：一个组织层面的对照

经济学里有一个相关的发现：**企业愿意支付高于市场出清的工资**（效率工资），一个解释是——高工资**提高了偷懒的机会成本**（Shapiro & Stiglitz, 1984）。

**在本文的模型里**：这等于**用工资提高了"不努力"的价格**，从而在不观测努力的情况下间接调节努力。

> **所以整个劳动市场，都在围绕"努力不可观测"这件事做设计。**而这解释了为什么本文的第三层成本（社会层）如此重要：**它是唯一可以被外部操纵的那一层。**

## 十四、努力＝回报：一条等式如何被生产、被相信，以及它真正编码的是什么

前十三节都在讲"努力有多贵"。这一节问一个更靠上游的问题：**"努力会换来回报"这条信念，本身是怎么被造出来、被维持、被教会、以及为什么它塌了会那么痛。**

### 14.1 先把等式写成数学：它不是信念，是一条关于斜率的断言

日常语言说"我相信努力会有回报"，听起来像一个**命题**。但把它放进第三、四节的模型，它立刻变成一个**关于导数的断言**：

$$\frac{\partial V}{\partial \text{effort}} > 0 \quad \text{且稳定}$$

也就是说：**多付一单位努力，回报会增加，而且这个增加是可预期的。**

> **这就是全部内容。**它不是"努力是好的"，不是"我应该努力"，是一个关于**因果斜率**的经验断言。

而一旦这样写，会发现它在心理学里有**三个不同的名字，指的是同一件事**：

| 名字 | 提出者 | 定义 | 它断言了什么 |
|---|---|---|---|
| **偶然性**（contingency） | Seligman | 行为与结果之间的相关程度 | 我的动作能改变结果 |
| **自我效能**（self-efficacy） | Bandura | 对自己能完成特定任务的信念 | 我的动作能达成目标 |
| **控制点**（locus of control） | Rotter | 结果由自己还是外部力量决定的泛化预期 | 结果归因于内还是外 |

> **三个概念来自三个不相干的研究传统（习得性无助、社会学习、人格心理学），而它们描述的是同一个斜率。**

这不是巧合——**因为"世界是否回应我的动作"是一个系统必须回答的问题**，而不同的人在研究不同现象时，都撞上了它。

### 14.2 它真正编码的，既不是努力，也不是回报

这是本节最想说的判断。

**努力**在心理上对应什么？——**是对控制的投放，是成本，是"我在做"这个动作本身。**
**回报**在心理上对应什么？——**是环境给出的反馈，是偶然性的读数。**

而"努力=回报"这条等式，**既不描述努力，也不描述回报，它描述的是两者之间的耦合**。

> **所以它真正编码的是：这个世界是否对我的动作有反应。**

而这正是**能动性（agency）本身的心理基础**。

这就解释了一个否则无法解释的现象：**为什么"努力没有回报"比"我很穷"更摧毁人。**

- 穷是一个**状态**，它可以被希望改变；
- 而努力无效是一个**结构判断**——它说的是"改变这个动作不起作用"。

> **前者拿走的是资源，后者拿走的是"下注这个动作有没有意义"。**

一个穷但相信努力有用的人，会继续尝试；一个不穷但相信努力无用的人，会停下——**而停下的人，会在一年后真的变穷。**

（这与库内[[人类学/自我、羡慕与神圣：可达性动力学、通约与共同体的耗散维护]]1.3 的"可操作性归零"完全一致：**自我贬低的真身不是低自尊，是"行动"这个范畴被取消**。）

### 14.3 三条生产线：它如何被造得"看起来是真的"

这条等式不是被"宣传"出来的，它被**三种机制**同时生产。

**① 局部真实化：把相关性在局部做成真的。**

学校和家庭做的第一件事，不是"告诉"孩子努力有用，是**让它在局部真的有用**：

```
多做题 → 分数上升（在考试这个封闭系统里，这确实成立）
练琴一小时 → 曲子变熟（在技能习得里，这确实成立）
```

> **这是关键**：等式在**技能型、反馈快、规则稳定**的场域里**是真的**。所以孩子不是被骗，是**在真实的局部证据上做了归纳**。

**② 证据筛选：让反例不可见。**

而等式在全局（收入、地位、阶层流动）上是不成立的。两者的接缝靠三件事遮住：

| 机制 | 作用 |
|---|---|
| **幸存者偏差** | 你只看见"努力且成功"的人；"努力且失败"的人沉默了 |
| **归因不对称** | 他人的失败归因于其品格（"他不够努力"），自己的失败归因于环境 |
| **时间的错位** | 局部（考试）的证据在**当下**出现，全局（阶层）的证据在**二十年后**出现，而那时归因框架早已装好 |

**③ 仪式重演：每天表演一次。**

考试、排名、成绩单、家长会、奖学金——这套系统**每天在身体层面重演"努力→分数"的等式**。

> 它的功能不是测量，是**排练**。学生在里面待了十二年，这个等式被重复了上万次，以至于它不再是一个"信念"，而是一个**知觉前提**。

（这就是库内[[人类学/自我、羡慕与神圣：可达性动力学、通约与共同体的耗散维护]]11.3 的"仪式同步"——**仪式不传递信息，它产生"这是真的"的体感**，而体感先于论证。）

### 14.4 人是怎么被教会的：四个发展阶段

**阶段一（婴儿期）：原初的偶然性。**

婴儿最早学到的不是"努力有用"，是更原始的东西：**哭→有人来**。

> **这是偶然性（contingency）的原型经验。**而它有一个残酷的性质：**如果它从未发生，后面所有阶段都会歪。**

Tronick 的"静止脸"实验说明了这一点：当母亲突然停止回应，婴儿会在几十秒内崩溃——**不是因为需求没被满足，是因为"我的信号不再产生效果"。**

**阶段二（学前期）：习得性勤奋。**

Eisenberger 的"习得性勤奋"（learned industriousness）：**当努力反复与奖赏配对，努力本身会变成强化物。**

> 也就是说：**孩子会开始"享受努力"**——而这看起来像美德，实际上是**条件反射**。

这一条很重要，因为它解释了为什么"努力"能脱离回报独立运行（第六节韦伯那一节）：**努力已经被训练成自己的奖赏了。**

**阶段三（学龄期）：学校作为等式的样板间。**

学校是这个等式最完美的展示场，因为它同时具备四个条件：

| 条件 | 学校如何满足 |
|---|---|
| 规则稳定 | 考试大纲、评分标准 |
| 反馈即时 | 分数、排名 |
| 因果清晰 | 多做题→高分，几乎线性 |
| 反例被排除 | 差生被分流，不出现在你的视野里 |

> **所以学校是等式的"无菌室"**——在里面它成立得无比干净。而**无菌室的意义恰恰是：它不告诉你外面的世界长什么样。**

**阶段四（青春期后）：第一次失效，而解释框架已经装好。**

第一次真正的失效通常发生在升学、求职、或第一次恋爱失败。而此刻，前三阶段已经装好了**一个不可证伪的解释框架**（下一节）。

### 14.5 关键证据：棉花糖实验的重读——那不是意志力，是信念

这一条我认为是本篇最有价值的实证修正。

Mischel 的棉花糖实验（1972）长期被读成"延迟满足能力预测成功"。而 **Kidd, Palmeri & Aslin（2013）** 做了一个改动版的实验，结果推翻了那个读法：

> 在实验前，先让孩子的环境变得**不可靠**（承诺给贴纸却没给）。然后再做棉花糖测试。
>
> **结果：环境不可靠组的孩子，等待时间大幅缩短，有些立刻就拿走了。**

**这个发现的含义是**：

> **孩子不是在测意志力，是在测"这个环境值不值得等"。**

而在这个意义上，**"不等待"是完全理性的**——如果你生活在一个承诺经常不兑现的环境里，**立刻拿走是正确策略**。

**这一条把整个问题的性质翻了**：

| 旧读法 | 新读法 |
|---|---|
| 等待 = 自控力强 | 等待 = 相信未来会兑现 |
| 不等待 = 意志薄弱 | 不等待 = 对不可靠环境的**理性适应** |
| 结论：训练意志力 | 结论：**改变环境的可靠性** |

> **所以"穷人家的孩子更短视"这个流行叙事，方向是反的**：不是短视导致穷，是**不可靠的环境教会了短视**——而那个学习是准确的。

（这条与库内[[心理学/情绪失调与人格整合系列/情绪失调与人格整合的共同解]]2.8 的"习得性无助"是同一个机制的两个方向：**偶然性的存在训练出努力，偶然性的缺失训练出放弃。两者都是学习，不是品格。**）

### 14.6 为什么它不可证伪：那条归因规则

等式之所以能在一个明显不成立的世界里存活几十年，靠的是一条**归因规则**：

```
成功 → 归因于努力（内部、可控）
失败 → 归因于努力不足（内部、可控）
```

**这条规则的美妙之处在于：它两边都用同一个变量解释。**所以任何结果都能被它吸收：

| 结果 | 这条规则的读法 |
|---|---|
| 我成功了 | 我努力了 |
| 我失败了 | 我不够努力 |
| 别人成功了 | 他努力了（或他有天赋——但仍属"个人品质"） |
| 别人失败了 | 他不够努力 |

> **它永远不需要修改自己**——这就是不可证伪的定义。

而它与**公正世界信念**（Lerner, 1980）耦合在一起，产生了一个更硬的东西：

> **如果努力不带来回报，那么受苦就是不应得的，而世界就是不公正的。**

而"世界不公正"这个念头在心理上极难承受。所以**等式不只是一个描述，它是一个道德必需**——**人需要它是真的，才能忍受他人的苦难和自己的失败。**

（这解释了库内[[心理学/认知矛盾：从一致性传统到信念修正的经济学]]6.2 的"系统正当化"：**为制度辩护，本质上是在为这条等式辩护**，因为一旦等式倒了，"我在底层"就从"运气"变成"不义"。）

### 14.7 谁需要这条等式为真

四个制度各有各的理由，而**它们的理由并不相同**。

| 制度 | 需要它的原因 | 若等式崩塌会怎样 |
|---|---|---|
| **学校** | 在没有强制手段的情况下动员学生 | 无法解释为什么要学 |
| **企业** | 为工资差异提供正当性（"他挣得多因为他值"） | 分配变成纯粹的权力问题 |
| **国家** | 绩效合法性（"结果好是因为治理好"） | 合法性来源被抽空 |
| **父母** | **CARE 系统要求"我能为孩子的未来做点什么"** | 承认"我保护不了他" |

> **最后一行最痛，也最被忽略。**

因为 CARE 系统的输出是"保护后代"，而"保护"唯一可操作的形式就是"督促他努力"。**所以放弃这条等式，等于承认自己作为照料者的无能**——而这在 CARE 系统里是不可承受的。

**这就是为什么这条等式最难在父母身上被放弃**，也是为什么它通过家庭传递得如此彻底——**它不是被教导的，它是被"爱"传递的。**

### 14.8 它与本文价格模型的关系：等式是对价格信号的误读

现在可以把它接回第四节了。

真正的机制是 EVC：

$$\text{EVC} = P(\text{success} \mid a)\cdot V - C(a)$$

而**$V$ 不只由努力决定**——它还由运气、结构、他人的选择、时机决定。所以"努力"在真实模型里只影响 $P(\text{success})$ 的**一部分**。

**而等式做的，是把"我付了成本 $C$"误读成"所以 $V$ 会兑现"**：

> **它把成本当成了投资。**

这是一个范畴错误——**成本是你付出的，投资回报是环境给的**。而两者之间没有必然联系，只有一个**统计上的、有条件的、可被结构破坏的**联系。

**而这正是它作为意识形态的功能**：它让**成本**（你付的）看起来像**投资**（会还的），从而让**不兑现**看起来像**你的判断失误**，而不是**结构的问题**。

### 14.9 一个反例与一个限定（否则这一节就滑向虚无）

必须给反例，否则"等式是假的"这个判断本身就成了另一种不可证伪的断言。

**等式在什么场域是真的？**

| 条件 | 例子 |
|---|---|
| **技能可积累** | 编程、外科、乐器、运动 |
| **反馈快且清晰** | 有明确的对错标准 |
| **竞争不充分** | 供给不足的领域 |
| **规则稳定** | 没有剧烈的制度变动 |

> **在这些场域里，等式近似成立，而且可以持续几十年。**所以它不是纯粹的谎言。

**而它的危害恰恰来自这个局部真**：

> **一个在局部真实的东西，最有资格被推广到全局。**而推广的那一步，没有任何证据支持。

这也解释了为什么"读书改变命运"在某些年代、某些群体里确实成立——**那是一个等式近似为真的窗口**（库内[[人类学/自我、羡慕与神圣：可达性动力学、通约与共同体的耗散维护]]十四节已经记录了 1945–1973 那个窗口）。而**窗口关闭后，等式还在**——因为它是被当成**永恒真理**学会的，不是被当成**历史条件**学会的。

### 14.10 一个自我批判

这一节有一个明显的风险：**它可能被读成"努力没用，别努力了"。**

这个读法是错的，理由有三条：

1. **等式假 ≠ 努力无用。**努力在局部场域（14.9）真的有效，而且**在能做事的范围内，它是唯一可控的变量**。
2. **本条分析的对象是"等式的普遍性宣称"，不是"努力的价值"。**区别在于：前者是一个关于世界的因果断言，后者是一个关于如何活的选择。
3. **最危险的后果不是"人不努力"，是"人只在能被验证的地方努力"**——而这恰恰意味着**放弃那些反馈慢但重要的东西**（长期学习、关系、创作）。

> **所以这一节的实践含义是**：把"努力=回报"从**公理**降级为**局部规律**——在技能场域用它，在结构场域不用它，并且**知道自己在哪一个场域里**。

## 十五、局限

### 15.1 影子价格断言的限度

"主观努力感 = λ"是本文最核心、也最可能过强的一句。

- **它是类比性的形式化，不是推导出来的**：我没有证明大脑在执行约束优化，只说明这个形式能统一多个现象。
- **λ 在多约束系统里是向量，不是标量**：如果有多个同时起作用的约束（代谢、时间、社会），努力感可能对应其中一个的组合，而本文把它写成了单个数。
- **"约束"是什么，本文没有定义**：$b$ 在神经上对应什么，完全不清楚。

### 15.2 历史援引的限度

- **Zipf、Hull、Simon、Shenhav 不在同一个论题上。**"最小努力"在语言学里是分布规律，在行为主义里是选择律，在决策论里是搜索成本，在神经科学里是控制分配。**把它们并置是找结构相似，不是证明同源。**
- **布迪厄与凡勃伦讲的是阶级再生产，不是认知成本。**把他们引进来做 $c_{\text{soc}}$ 的注脚，是我做的**跨层映射**——它可能有启发性，但也可能把社会学问题心理学化。这一点必须标出：**"努力有社会价格"不等于"社会不平等可以被还原为认知成本"。**
- **尼采的"意志是虚构"是一个谱系学论证，不是一个经验命题。**它不能被实验检验，也不该被当作"意志力不存在"的证据。

### 15.3 三个我认为最可能错的地方

1. **三层成本的划分可能是假的。**"社会层"也许只是"机会层"的一个特例（社会评价改变了 $V$，而不是增加了独立的成本项）。如果是这样，三层应塌成两层。
2. **"断崖"归因于 λ 的分段性，是一个事后拟合。**它解释了现象，但没有预测力——它不能告诉你边界在哪。
3. **"意志力是道德技术"这个判断，我给了很高的置信度，但它可能过头。**更稳妥的说法是：意志力概念**同时**有描述功能与归责功能，而两者在公共话语里被混淆了。

### 15.4 与库内《认知能耗框架》的关系

那篇把"认知能耗有限"当作底层事实，层层推到社会与国家。这个推演作为**社会解释**仍然成立（偏见是有损压缩、存量期纠偏能力下降、宏大叙事是降低理解成本的装置）。

但作为**神经机制**，它需要修正：

> 不是"燃料有限"，是"**约束紧致度 + 价格结构**"。

两者在现象上难以区分（都表现为"用久了会累"），但在干预上完全不同：前者导向"补充"（糖、咖啡、激励），后者导向"改约束与改价格"（睡眠、换任务、换场域）。

### 15.5 n=1

与库内症状的接线（审议默认、断崖、低意义任务崩得快）建立在一位当事人的自述上，用于生成假设，不用于判定。涉及持续下降的疲劳，第一步是排除生理原因。
