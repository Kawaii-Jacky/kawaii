 ATP(三磷酸腺苷)‌：由一分子腺苷和三个磷酸基团组成，结构简式为“A-P~P~P”，其中“~”表示高能磷酸键‌。ATP含有两个高能磷酸键，储存的能量较多‌。

# 大脑皮质解剖学

大脑皮质（Cerebral Cortex）是大脑表面的一层灰质，厚度约2-4mm，包含约140-160亿个神经元。它是人类高级认知功能的物质基础。

## Brodmann 分区系统

Brodmann 分区是由德国神经解剖学家 Korbinian Brodmann 于1909年提出的，基于细胞构筑学（cytoarchitectonics）将大脑皮层分为52个区域。每个区域具有独特的细胞组织结构和功能特征。

# 岛叶（Insula）

### 解剖位置

岛叶位于大脑外侧沟（Sylvian fissure）的深部，被额叶、顶叶和颞叶的岛盖所覆盖。它呈三角形或锥形，是大脑皮层中隐藏最深的区域之一，需要翻开大脑外侧的皮层才能看到。

岛叶可分为：
- **前岛叶**：主要负责情感和内感受处理
- **后岛叶**：主要负责感觉和运动整合

### 核心功能

| 功能类别                   | 具体作用                      |
| ---------------------- | ------------------------- |
| **内感受（Interoception）** | 监测身体内部状态（心跳、呼吸、饥饿、口渴、疼痛）  |
| **自我意识**               | 产生主观感受、身体所有权感             |
| **共情与社会认知**            | 理解他人情绪、同理心                |
| **情绪整合**               | 将身体感觉与情绪体验整合（如焦虑时的"胃部不适"） |
| **味觉处理**               | 初级味觉皮层位于前岛叶               |
| **成瘾与渴望**              | 参与物质渴求和成瘾行为               |

### 临床意义

- 岛叶损伤可能导致**失认症**（无法感知身体内部状态）
- 与**焦虑障碍**、**成瘾**、**进食障碍**密切相关
- 最新研究表明岛叶在ADHD的内感受缺陷中可能起重要作用

# 其他重要结构

## 胼胝体（Corpus Callosum）

### 解剖位置

胼胝体是哺乳动物大脑中最大的**白质带**（由大约 2 亿到 3 亿根神经纤维组成），深藏在大脑内部，位于两个大脑半球纵裂的底部，大脑皮层下方，形状像一个扁平且宽阔的拱形结构。

### 核心功能

- **跨半球的信息桥梁：** 大脑的左右半球各有侧重的功能（例如，通常左脑更偏向语言、逻辑和分析，右脑更偏向空间感觉、图像和直觉）。胼胝体负责将一侧半球接收到的感觉、认知和运动信息实时传递给另一侧，确保大脑作为一个整体协同工作。
- **协调运动与感知：** 当你的左眼（视野左侧）看到一个物体，或者左手触摸到某样东西时，这些信号首先会被传输到右脑。随后，胼胝体将这些信息迅速传导给负责语言的左脑，这样你才能顺利地用语言说出那个物体的名字。

### 临床现象：裂脑症（Split-brain）

在医学史上，为了治疗极其严重且无法用药物控制的癫痫，外科医生有时会采取一种极端的手术方法：切断患者的胼胝体（目的是防止异常的神经放电从一侧大脑蔓延到另一侧）。

手术后，患者的癫痫通常会显著缓解，但在特定的实验中会表现出"裂脑症"。因为左右脑失去了这座桥梁，它们无法再交流信息，仿佛一个人拥有了两个独立运作的系统。例如，在一个典型的测试中，如果给患者的右脑（通过左侧视野）看一个词，患者会说自己什么都没看到（因为主导语言的左脑确实没看到），但他的左手（由右脑控制）却能准确地画出那个词代表的物体。

## 岛盖（Operculum）

岛盖是覆盖岛叶的额叶、顶叶和颞叶部分，形成大脑外侧沟的"盖子"。

大脑分为左右两个半球，通过胼胝体连接。每个半球控制对侧身体的运动和感觉。

# 皮层下结构

## 基底前脑
基底前脑（英语：Basal forebrain）是位于大脑前脑、纹状体前下方的结构，主要包括==腹侧基底核==（包括伏隔核与腹侧苍白球）、==基底核==（Meynert基底核）、布洛卡斜带 、无名质以及内侧隔核等部分。这些结构是==乙酰胆碱==的主要合成部位，其产生的乙酰胆碱广泛分布至全脑。

## 中脑（Midbrain）

从神经解剖学的横截面来看，中脑以贯穿其中的**中脑水管（Cerebral aqueduct）**为主要分界线。由后（背侧）到前（腹侧），中脑主要包括**三个核心部分**：

### 1. 顶盖（Tectum）

位于中脑的最背侧（后方），即中脑水管的后方。

- **核心结构：** 表面隆起形成**四叠体（Corpora quadrigemina）**，由上方的一对上丘（Superior colliculi）和下方的一对下丘（Inferior colliculi）组成。
- **功能：** 这是一个关键的反射中心。上丘主要负责视觉相关的无意识反射（例如余光闪过一个物体时你的眼睛和头部迅速转向它）；下丘则负责听觉通路的传导与反射。

### 2. 被盖（Tegmentum）

位于中脑水管的前方、黑质的后方，占据了中脑内部的主体空间。

- **核心结构：** 构造非常复杂，包含中脑导水管周围灰质（PAG）、网状结构、控制眼球运动的脑神经核团（动眼神经核、滑车神经核），以及高度血管化的**红核（Red nucleus）**。
- **功能：** 参与控制无意识的肌肉运动协调、调节痛觉感知，以及维持大脑的觉醒状态。

#### 腹侧被盖区（VTA）

1. 腹侧被盖区（VTA）位于中脑，是多巴胺（快乐物质）的主要制造工厂之一。核心功能：它负责识别和评估潜在的回报、预测奖赏以及应对压力。当你经历快乐（如美食、恋爱、成瘾行为）或面对压力时，VTA的神经元会被激活。神经通路：VTA发出的多巴胺神经纤维会投射到大脑的多个区域，其中最重要的一条通路就是连接前额叶的中脑-皮层通路。

2. 前额叶（Prefrontal Cortex）前额叶位于大脑的最前方（额头后方），是人类进化中发育最完善、最高级的脑区。**核心功能**：主要负责高级认知和执行功能，包括逻辑推理、计划制定、注意力集中、工作记忆以及情绪的踩刹车（抑制冲动）。**决策机制**：它负责权衡利弊，决定是否要执行某个冲动行为。

3. 前额叶与VTA的协同工作（中脑-皮层通路）这两个区域的联动深刻影响着我们的行为和心理：**奖赏与欲望**：当VTA受到刺激释放多巴胺并传递到前额叶时，你会产生强烈的动机、渴望和愉悦感。这也是为什么热恋或成瘾时，该区域会高度活跃。**冲动与自控**：健康的运转状态下，VTA负责"点燃"热情和欲望，而前额叶则负责理性地"评估与控制"。如果前额叶功能较弱，往往会导致冲动控制障碍、拖延或注意力不集中。

### 3. 大脑脚底（Crus cerebri / Basis pedunculi）

位于中脑的最腹侧（最前方）。

- **核心结构：** 它纯粹是由密集的下行神经纤维（白质束）组成的粗大柱状结构，包含了皮质脊髓束、皮质脑干束等。
- **功能：** 它是大脑皮层向下（向脑干和脊髓）下达随意运动指令的"高速公路主干道"。

> **关键过渡结构：黑质（Substantia nigra）**
> 
> 夹在被盖和大脑脚底之间，因神经元内含有黑色素而呈现暗色。它是大脑多巴胺系统的核心产生地之一，负责运动控制和奖赏机制。**帕金森病（Parkinson's disease）**的根源正是这部分多巴胺神经元的退化和死亡。

## 基底核（Basal Ganglia）

基底核是大脑深部的一组灰质核团，主要参与运动控制、习惯形成、奖励学习和情绪调节。它是端脑皮层下结构的重要组成部分。

### 基底核的组成

基底核包括以下核心结构：

| 结构       | 英文名称                | 功能角色  |
| -------- | ------------------- | ----- |
| **纹状体**  | Striatum            | 主要输入站 |
| **苍白球**  | Globus Pallidus     | 主要输出站 |
| **黑质**   | Substantia Nigra    | 多巴胺调节 |
| **底丘脑核** | Subthalamic Nucleus | 运动调节  |

## 纹状体（Striatum）

### 解剖位置

纹状体是端脑皮质下的一部分，位于上丘脑，是基底核的**主要输入区**。它接收来自大脑皮层、丘脑和黑质的信号。

### 核心结构

纹状体在解剖上包括两个主要部分：

| 结构 | 英文名称 | 位置 | 功能 |
|------|----------|------|------|
| **尾核** | Caudate Nucleus | 侧脑室前角外侧，呈C形弯曲 | 认知功能、目标导向行为、视觉运动整合 |
| **被壳** | Putamen | 外侧，靠近岛叶 | 运动控制、运动学习、习惯形成 |

#### 尾核（Caudate Nucleus）

- **解剖位置**：位于侧脑室前角外侧，呈C形弯曲，头部膨大，尾部细长
- **功能**：
  - 认知控制和注意力调节
  - 目标导向行为
  - 视觉运动整合
  - 空间工作记忆

#### 被壳（Putamen）

- **解剖位置**：位于外侧，靠近岛叶，与苍白球合称为"豆状核"
- **功能**：
  - 运动控制和运动学习
  - 习惯形成和自动化行为
  - 运动序列的学习和执行

### 纹状体的神经递质

| 神经递质 | 来源 | 功能 |
|---------|------|------|
| **多巴胺** | 黑质致密部（SNc） | 调节运动控制、奖励学习、动机 |
| **乙酰胆碱** | 纹状体中间神经元 | 调节多巴胺释放、运动控制 |
| **GABA** | 纹状体投射神经元 | 抑制性神经递质，调节基底核输出 |
| **谷氨酸** | 皮层和丘脑输入 | 兴奋性输入 |

### 纹状体的传入和传出通路

#### 传入通路（输入）

| 来源 | 神经递质 | 功能 |
|------|---------|------|
| **大脑皮层** | 谷氨酸 | 运动指令、认知信息 |
| **丘脑** | 谷氨酸 | 感觉信息、运动反馈 |
| **黑质致密部** | 多巴胺 | 运动调节、奖励信号 |

#### 传出通路（输出）

| 目标 | 神经递质 | 功能 |
|------|---------|------|
| **苍白球内侧** | GABA | 抑制性输出 |
| **苍白球外侧** | GABA | 抑制性输出 |
| **黑质网状部** | GABA | 抑制性输出 |

### 核心功能

| 功能类别 | 具体作用 |
|---------|---------|
| **运动控制** | 调节肌肉张力、协调复杂运动、运动序列执行 |
| **运动学习** | 学习新的运动技能、形成运动习惯 |
| **习惯形成** | 将有意识的行为转化为自动化习惯 |
| **奖励学习** | 通过多巴胺信号学习奖励预测、强化行为 |
| **认知功能** | 注意力调节、工作记忆、目标导向行为 |
| **情绪调节** | 参与情绪处理和动机行为 |

### 临床意义

#### 帕金森病（Parkinson's Disease）

- **病因**：黑质致密部多巴胺神经元退化死亡，导致纹状体多巴胺水平下降
- **症状**：
  - 运动迟缓（Bradykinesia）
  - 肌肉僵直（Rigidity）
  - 静止性震颤（Resting Tremor）
  - 姿势不稳（Postural Instability）
- **治疗**：左旋多巴（L-DOPA）补充多巴胺

#### 亨廷顿病（Huntington's Disease）

- **病因**：纹状体（尤其是尾核和被壳）神经元退化
- **症状**：
  - 舞蹈样运动（Chorea）
  - 认知功能下降
  - 精神症状
- **遗传**：常染色体显性遗传

#### 图雷特综合征（Tourette Syndrome）

- **病因**：纹状体功能异常
- **症状**：
  - 运动抽搐
  - 发声抽搐
  - 强迫行为

#### 肝豆状核变性（Wilson's Disease）

- **病因**：铜代谢异常，铜在纹状体沉积
- **症状**：
  - 运动障碍
  - 精神症状
  - 角膜K-F环

## 黑质（Substantia Nigra）

### 解剖位置

黑质位于中脑被盖和大脑脚底之间，因神经元内含有黑色素而呈现暗色。它是大脑多巴胺系统的核心产生地之一。

### 核心结构

黑质分为两个功能不同的部分：

| 部分        | 英文名称                                   | 细胞特征        | 功能        |
| --------- | -------------------------------------- | ----------- | --------- |
| **黑质致密部** | Substantia Nigra Pars Compacta (SNc)   | 含黑色素的多巴胺神经元 | 运动控制、奖励学习 |
| **黑质网状部** | Substantia Nigra Pars Reticulata (SNr) | GABA能神经元    | 基底核的主要输出站 |

#### 黑质致密部（SNc）

- **细胞特征**：含有黑色素的多巴胺神经元，约占黑质神经元的80%
- **投射目标**：主要投射到纹状体（尾核和被壳）
- **功能**：
  - 运动控制：调节肌肉张力和运动协调
  - 奖励学习：通过多巴胺信号强化奖励相关行为
  - 动机：参与动机和目标导向行为

#### 黑质网状部（SNr）

- **细胞特征**：GABA能神经元，不含黑色素
- **投射目标**：丘脑（腹外侧核和腹前核）
- **功能**：
  - 基底核的主要输出站
  - 调节丘脑活动，进而影响大脑皮层
  - 参与眼动控制

### 多巴胺系统

黑质是大脑多巴胺系统的重要组成部分：

#### 多巴胺通路

| 通路           | 起点    | 终点  | 功能        |
| ------------ | ----- | --- | --------- |
| **黑质-纹状体通路** | 黑质致密部 | 纹状体 | 运动控制、运动学习 |
| **中脑-边缘通路**  | 腹侧被盖区 | 伏隔核 | 奖励、动机、成瘾  |
| **中脑-皮层通路**  | 腹侧被盖区 | 前额叶 | 认知功能、执行功能 |
| **结节-漏斗通路**  | 下丘脑   | 垂体  | 催乳素抑制     |

#### 多巴胺的功能

| 功能 | 作用机制 |
|------|---------|
| **运动控制** | 调节纹状体活动，维持正常肌肉张力和运动协调 |
| **奖励学习** | 通过"奖励预测误差"信号强化奖励相关行为 |
| **动机** | 产生追求奖励的动机和欲望 |
| **认知功能** | 调节前额叶的执行功能、工作记忆 |

### 临床意义

#### 帕金森病（Parkinson's Disease）

- **病理**：黑质致密部多巴胺神经元进行性退化死亡
- **病理标志**：路易小体（Lewy Bodies）在神经元内沉积
- **生化改变**：纹状体多巴胺水平显著下降（通常下降60-80%时出现症状）
- **临床表现**：
  - 运动迟缓
  - 肌肉僵直
  - 静止性震颤（4-6Hz）
  - 姿势不稳
  - 非运动症状：抑郁、便秘、嗅觉丧失、睡眠障碍
- **治疗**：
  - 左旋多巴（L-DOPA）：多巴胺前体，补充多巴胺
  - 多巴胺受体激动剂：直接刺激多巴胺受体
  - MAO-B抑制剂：减少多巴胺降解
  - 深部脑刺激（DBS）：刺激丘脑底核或苍白球内侧

#### 黑质与精神疾病

- **精神分裂症**：多巴胺系统功能亢进（"多巴胺假说"）
- **抑郁症**：多巴胺系统功能低下
- **成瘾**：多巴胺系统被劫持

## 基底核的神经环路

### 直接通路（兴奋性）

```
大脑皮层 → 纹状体（抑制）→ 苍白球内侧/黑质网状部（抑制）→ 丘脑（兴奋）→ 大脑皮层
```

**净效应**：促进运动

### 间接通路（抑制性）

```
大脑皮层 → 纹状体（抑制）→ 苍白球外侧（抑制）→ 底丘脑核（兴奋）→ 苍白球内侧/黑质网状部（抑制）→ 丘脑（兴奋）→ 大脑皮层
```

**净效应**：抑制运动

### 超直接通路

```
大脑皮层 → 底丘脑核（兴奋）→ 苍白球内侧/黑质网状部（抑制）→ 丘脑（兴奋）→ 大脑皮层
```

**净效应**：快速抑制运动

### 多巴胺的调节作用

| 受体 | 位置 | 作用 | 通路影响 |
|------|------|------|---------|
| **D1受体** | 纹状体直接通路神经元 | 兴奋 | 促进运动 |
| **D2受体** | 纹状体间接通路神经元 | 抑制 | 抑制运动 |

**多巴胺的净效应**：促进运动（通过同时激活直接通路和抑制间接通路）

## 苍白球（Globus Pallidus）

### 解剖位置

苍白球位于基底核的中心位置，被纹状体（尾核和被壳）所包围。它与被壳合称为**豆状核（Lentiform Nucleus）**。

苍白球因含有较多的有髓纤维而呈现苍白的颜色，因此得名（拉丁语 *globus pallidus* 意为"苍白的球"）。

### 核心结构

苍白球分为两个功能不同的部分：

| 部分 | 英文名称 | 位置 | 功能角色 |
|------|----------|------|---------|
| **苍白球外侧** | Globus Pallidus Externa (GPe) | 外侧部分 | 间接通路的中继站 |
| **苍白球内侧** | Globus Pallidus Interna (GPi) | 内侧部分 | 基底核的主要输出站 |

#### 苍白球外侧（GPe）

- **解剖位置**：苍白球的外侧部分
- **神经递质**：GABA能神经元
- **传入输入**：
  - 纹状体（通过D2受体神经元）
  - 底丘脑核
- **传出输出**：
  - 底丘脑核
  - 苍白球内侧
- **功能**：
  - 间接通路的中继站
  - 调节基底核的输出
  - 参与运动抑制

#### 苍白球内侧（GPi）

- **解剖位置**：苍白球的内侧部分
- **神经递质**：GABA能神经元
- **传入输入**：
  - 纹状体（通过D1受体神经元）
  - 底丘脑核
  - 苍白球外侧
- **传出输出**：
  - 丘脑（腹外侧核和腹前核）
  - 脚桥核
- **功能**：
  - 基底核的主要输出站
  - 通过抑制丘脑来调节运动
  - 参与运动的启动和执行

### 苍白球的神经递质

| 神经递质 | 来源 | 功能 |
|---------|------|------|
| **GABA** | 苍白球神经元 | 抑制性输出 |
| **谷氨酸** | 底丘脑核输入 | 兴奋性输入 |
| **多巴胺** | 黑质致密部 | 调节苍白球活动 |

### 苍白球的传入和传出通路

#### 传入通路（输入）

| 来源 | 神经递质 | 功能 |
|------|---------|------|
| **纹状体** | GABA | 抑制性输入 |
| **底丘脑核** | 谷氨酸 | 兴奋性输入 |
| **黑质致密部** | 多巴胺 | 调节作用 |

#### 传出通路（输出）

| 目标 | 神经递质 | 功能 |
|------|---------|------|
| **丘脑** | GABA | 抑制丘脑活动 |
| **底丘脑核** | GABA | 调节间接通路 |
| **脚桥核** | GABA | 参与运动控制 |

### 核心功能

| 功能类别 | 具体作用 |
|---------|---------|
| **运动抑制** | 通过抑制丘脑来抑制不必要的运动 |
| **运动调节** | 调节肌肉张力和运动协调 |
| **运动学习** | 参与运动技能的学习和优化 |
| **姿势控制** | 维持正常的姿势和平衡 |

### 苍白球在基底核环路中的作用

#### 直接通路

```
大脑皮层 → 纹状体（抑制GPe）→ GPi（抑制）→ 丘脑（兴奋）→ 大脑皮层
```

**净效应**：促进运动

#### 间接通路

```
大脑皮层 → 纹状体（抑制GPe）→ GPe（抑制）→ 底丘脑核（兴奋）→ GPi（抑制）→ 丘脑（兴奋）→ 大脑皮层
```

**净效应**：抑制运动

#### 超直接通路

```
大脑皮层 → 底丘脑核（兴奋）→ GPi（抑制）→ 丘脑（兴奋）→ 大脑皮层
```

**净效应**：快速抑制运动

### 临床意义

#### 苍白球损伤

| 损伤类型 | 症状 |
|---------|------|
| **苍白球内侧损伤** | 运动减少、肌张力降低 |
| **苍白球外侧损伤** | 运动增多、舞蹈样运动 |
| **双侧苍白球损伤** | 严重运动障碍 |

#### 帕金森病中的苍白球

- **病理改变**：苍白球内侧过度活跃
- **原因**：黑质多巴胺神经元退化，导致间接通路过度激活
- **症状**：运动迟缓、肌肉僵直
- **治疗**：苍白球毁损术（Pallidotomy）或深部脑刺激（DBS）

#### 苍白球深部脑刺激（GPi-DBS）

- **适应症**：药物难治性帕金森病、肌张力障碍
- **原理**：通过电刺激抑制苍白球内侧的过度活动
- **效果**：改善运动迟缓、肌肉僵直、异动症

#### 亨廷顿病中的苍白球

- **病理改变**：苍白球外侧神经元退化
- **症状**：舞蹈样运动、运动控制障碍
- **机制**：间接通路受损，导致运动抑制功能下降

#### 肝豆状核变性中的苍白球

- **病理改变**：铜在苍白球沉积
- **症状**：运动障碍、肌张力异常
- **治疗**：铜螯合剂治疗

- **执行功能**：参与目标导向行为

## 锥体系统与锥体外系

### 运动系统的两大通路

大脑控制运动的系统分为两大通路：

| 系统 | 英文名称 | 主要功能 | 传导路径 |

## 锥体系统（Pyramidal System）

### 概述

锥体系统是大脑控制随意运动的主要通路，也称为**皮质脊髓束（Corticospinal Tract）**。它从大脑皮层发出，经过延髓的锥体（Pyramids），因此得名。

### 解剖路径

锥体系统的传导路径如下：

```
大脑皮层（初级运动皮层BA4、前运动区BA6、感觉皮层BA3,1,2）
    ↓
内囊后肢（Posterior Limb of Internal Capsule）
    ↓
大脑脚（Cerebral Peduncles）
    ↓
脑桥基底（Basis Pontis）
    ↓
延髓锥体（Pyramids of Medulla）
    ↓
锥体交叉（Decussation of Pyramids，约85%纤维交叉）
    ↓
脊髓前角运动神经元
    ↓
骨骼肌
```

### 核心结构

#### 1. 皮质脊髓束（Corticospinal Tract）

| 部分 | 纤维来源 | 终止位置 | 功能 |
|------|---------|---------|------|
| **皮质脊髓侧束** | 交叉后的纤维（85%） | 脊髓前角运动神经元 | 控制对侧肢体的精细运动 |
| **皮质脊髓前束** | 未交叉的纤维（15%） | 脊髓前角运动神经元 | 控制躯干和近端肢体运动 |

#### 2. 皮质脑干束（Corticobulbar Tract）

- **起点**：大脑皮层（主要是运动皮层下部）
- **终点**：脑干运动神经核团
- **功能**：控制面部、咽喉、颈部的随意运动

#### 3. 锥体（Pyramids）

- **位置**：延髓腹侧面，呈锥形隆起
- **结构**：包含皮质脊髓束的下行纤维
- **功能**：皮质脊髓束在此交叉（锥体交叉）

### 核心功能

| 功能类别 | 具体作用 |
|---------|---------|
| **随意运动** | 控制有意识的、自主的运动 |
| **精细运动** | 控制手指、手腕等精细动作 |
| **运动执行** | 将运动计划转化为实际动作 |
| **运动学习** | 参与新的运动技能的学习 |

### 锥体交叉（Decussation of Pyramids）

- **位置**：延髓下端
- **交叉比例**：约85%的皮质脊髓纤维交叉到对侧
- **功能意义**：确保大脑左半球控制右侧身体，右半球控制左侧身体

### 临床意义

#### 上运动神经元损伤（UMN Lesion）

| 症状 | 表现 |
|------|------|
| **痉挛性瘫痪** | 肌张力增高、腱反射亢进 |
| **病理反射** | 巴宾斯基征（Babinski sign）阳性 |
| **肌萎缩** | 无或轻微（废用性） |
| **损伤部位** | 大脑皮层、内囊、脑干、脊髓 |

#### 下运动神经元损伤（LMN Lesion）

| 症状 | 表现 |
|------|------|
| **弛缓性瘫痪** | 肌张力降低、腱反射减弱或消失 |
| **病理反射** | 巴宾斯基征阴性 |
| **肌萎缩** | 明显（神经源性） |
| **损伤部位** | 脊髓前角、神经根、周围神经 |

#### 内囊损伤（Internal Capsule Stroke）

- **病因**：大脑中动脉分支破裂或阻塞
- **症状**：对侧偏瘫（面部、上肢、下肢）
- **特点**：由于内囊纤维集中，小病灶可导致严重瘫痪

## 锥体外系（Extrapyramidal System）

### 概述

锥体外系是指不经过延髓锥体的所有运动系统。它主要负责**不随意运动**、**肌张力调节**、**姿势维持**和**运动协调**。

### 核心组成

锥体外系包括多个脑区和神经核团：

| 结构 | 功能 |
|------|------|
| **基底核** | 运动控制、习惯形成、奖励学习 |
| **红核** | 运动协调、肌张力调节 |
| **黑质** | 多巴胺产生、运动控制 |
| **脑干网状结构** | 肌张力调节、姿势反射 |
| **前庭核** | 平衡觉、姿势调节 |
| **小脑** | 运动协调、平衡、运动学习 |
| **上丘** | 视觉反射、眼动控制 |
| **下丘** | 听觉反射 |

### 传导通路

锥体外系通过**多级神经元**传导，主要通路包括：

#### 1. 红核脊髓束（Rubrospinal Tract）

```
红核 → 交叉 → 脊髓前角运动神经元
```
- **功能**：调节肌张力、辅助运动控制

#### 2. 网状脊髓束（Reticulospinal Tract）

```
脑干网状结构 → 脊髓前角运动神经元
```
- **功能**：调节肌张力、姿势反射、自主运动

#### 3. 前庭脊髓束（Vestibulospinal Tract）

```
前庭核 → 脊髓前角运动神经元
```
- **功能**：平衡调节、姿势维持

#### 4. 顶盖脊髓束（Tectospinal Tract）

```
上丘 → 交叉 → 脊髓前角运动神经元
```
- **功能**：视觉反射、头部转动

### 核心功能

| 功能类别 | 具体作用 |
|---------|---------|
| **肌张力调节** | 维持正常的肌肉张力，防止肌肉过度松弛或紧张 |
| **姿势维持** | 维持身体直立姿势，抵抗重力 |
| **不随意运动** | 控制自动化的、无意识的运动（如行走、跑步） |
| **运动协调** | 协调多个肌群的活动，确保运动平滑 |
| **运动学习** | 通过小脑参与运动技能的学习和优化 |
| **平衡调节** | 通过前庭系统维持身体平衡 |

### 基底核在锥体外系中的作用

基底核是锥体外系的核心组成部分：

- **直接通路**：促进运动
- **间接通路**：抑制运动
- **超直接通路**：快速抑制运动
- **多巴胺调节**：通过黑质-纹状体通路调节运动

### 小脑在锥体外系中的作用

小脑是锥体外系的重要组成部分：

| 功能 | 作用机制 |
|------|---------|
| **运动协调** | 比较运动意图与实际运动，纠正误差 |
| **平衡调节** | 通过前庭小脑维持身体平衡 |
| **运动学习** | 通过长期抑制（LTD）优化运动技能 |
| **运动计划** | 参与运动的时序安排 |

### 临床意义

#### 锥体外系疾病

| 疾病 | 受损结构 | 主要症状 |
|------|---------|---------|
| **帕金森病** | 黑质多巴胺神经元 | 运动迟缓、肌肉僵直、静止性震颤 |
| **亨廷顿病** | 纹状体 | 舞蹈样运动、认知下降 |
| **肌张力障碍** | 基底核 | 异常姿势、不自主肌肉收缩 |
| **图雷特综合征** | 纹状体 | 运动抽搐、发声抽搐 |
| **小脑共济失调** | 小脑 | 运动不协调、平衡障碍 |
| **舞蹈病** | 纹状体 | 不自主的舞蹈样运动 |

#### 锥体外系综合征

| 综合征 | 病因 | 症状 |
|--------|------|------|
| **药物性帕金森综合征** | 抗精神病药物阻断多巴胺受体 | 类似帕金森病的症状 |
| **迟发性运动障碍** | 长期使用抗精神病药物 | 不自主的口舌面部运动 |
| **恶性抗精神病药综合征** | 抗精神病药物严重副作用 | 高热、肌肉僵直、自主神经功能紊乱 |

#### 锥体外系与锥体系统的比较

| 特征 | 锥体系统 | 锥体外系 |
|------|---------|---------|
| **传导路径** | 经过延髓锥体 | 不经过锥体 |
| **神经元级数** | 单级神经元（上运动神经元→下运动神经元） | 多级神经元 |
| **主要功能** | 随意运动 | 不随意运动、肌张力调节 |
| **运动类型** | 精细运动、有意识运动 | 粗大运动、自动化运动 |
| **交叉方式** | 在延髓锥体交叉 | 在不同水平交叉 |
| **损伤表现** | 痉挛性瘫痪 | 运动障碍、肌张力异常 |

## 脑干（Brainstem）概述

脑干是大脑最古老的进化结构之一，连接大脑半球与脊髓，是生命维持的中枢。它由三个部分组成（从上到下）：
1. **中脑（Midbrain）**
2. **脑桥（Pons）**
3. **延髓（Medulla oblongata）**

脑干虽然体积不大（约占脑重量的2.6%），但包含几乎所有脑神经核团，控制着呼吸、心跳、意识等基本生命功能。

---

## 脑桥（Pons）

### 解剖位置

脑桥位于中脑下方、延髓上方，是脑干的中间部分。它的名字来源于拉丁语"pons"（桥梁），因为它像一座桥梁连接着小脑的两个半球。

脑桥的腹侧面（前方）膨大隆起，背侧面（后方）构成第四脑室的上部。

### 核心结构

#### 1. 腹侧面（基底部）

| 结构                     | 功能                 |
| ---------------------- | ------------------ |
| **脑桥基底（Basis Pontis）** | 包含大量横行纤维，连接大脑皮层与小脑 |
| **皮质脊髓束**              | 穿过脑桥，传导随意运动指令      |
| **皮质脑桥束**              | 连接大脑皮层与小脑，参与运动协调   |

#### 2. 背侧面（被盖部）

| 结构                           | 功能                        |
| ---------------------------- | ------------------------- |
| **脑桥被盖（Tegmentum）**          | 包含网状结构、脑神经核团              |
| **脑桥网状结构**                   | 调节睡眠-觉醒周期、呼吸节律            |
| **==蓝斑核（Locus Coeruleus）==** | 去甲肾上腺素的主要来源，调节警觉、注意力和应激反应 |

#### 3. 脑神经核团

脑桥包含以下脑神经核团：

| 脑神经 | 核团 | 功能 |
|--------|------|------|
| **三叉神经（CN V）** | 三叉神经运动核、感觉主核、中脑核 | 面部感觉、咀嚼运动 |
| **外展神经（CN VI）** | 外展神经核 | 眼球外展运动 |
| **面神经（CN VII）** | 面神经核、上泌涎核 | 面部表情、泪腺和唾液腺分泌 |
| **前庭蜗神经（CN VIII）** | 前庭核、蜗神经核 | 平衡觉、听觉 |

### 核心功能

| 功能类别 | 具体作用 |
|---------|---------|
| **运动协调** | 通过脑桥-小脑通路，参与随意运动的协调和平衡 |
| **呼吸调节** | 脑桥呼吸中枢调节呼吸节律（与延髓协同） |
| **睡眠-觉醒** | 蓝斑核调节警觉状态，网状结构参与睡眠-觉醒周期 |
| **面部感觉与运动** | 三叉神经和面神经控制面部感觉和表情 |
| **听觉与平衡** | 前庭蜗神经传导听觉和平衡信息 |

### 临床意义

- **脑桥损伤**：可能导致面部麻痹、眼球运动障碍、呼吸节律紊乱
- **去脑强直**：脑桥严重损伤时出现的姿势异常
- **睡眠障碍**：蓝斑核功能异常与失眠、嗜睡症相关
- **三叉神经痛**：三叉神经受压或损伤导致的剧烈面部疼痛

## 延髓（Medulla Oblongata）

### 解剖位置

延髓是脑干最下端的部分，上接脑桥，下连脊髓。它位于颅骨的枕骨大孔前方，是大脑与脊髓之间的"门户"。

延髓呈圆锥形，长约3cm，重量约7g。虽然体积很小，但它是维持生命的最基本中枢。

### 核心结构

#### 1. 腹侧面

| 结构 | 功能 |
|------|------|
| **锥体（Pyramids）** | 皮质脊髓束在此交叉（锥体交叉），控制对侧肢体运动 |
| **橄榄体（Olive）** | 下橄榄核，连接小脑，参与运动协调和学习 |
| **锥体交叉（Decussation of Pyramids）** | 约85%的皮质脊髓纤维在此交叉到对侧 |

#### 2. 背侧面

| 结构 | 功能 |
|------|------|
| **薄束核（Nucleus Gracilis）** | 传导本体感觉和精细触觉（下肢） |
| **楔束核（Nucleus Cuneatus）** | 传导本体感觉和精细触觉（上肢） |
| **最后区（Area Postrema）** | 呕吐中枢，监测血液中的毒素 |

#### 3. 内部结构

| 结构 | 功能 |
|------|------|
| **延髓网状结构** | 调节呼吸、心跳、血压等基本生命功能 |
| **疑核（Nucleus Ambiguus）** | 控制咽喉肌肉，参与吞咽和发声 |
| **迷走神经背核** | 副交感神经中枢，调节内脏活动 |
| **孤束核（Nucleus Tractus Solitarius）** | 接收内脏感觉信息（味觉、内脏感觉） |

#### 4. 脑神经核团

延髓包含以下脑神经核团：

| 脑神经 | 核团 | 功能 |
|--------|------|------|
| **舌咽神经（CN IX）** | 疑核、下泌涎核、孤束核 | 吞咽、唾液腺分泌、味觉 |
| **迷走神经（CN X）** | 迷走神经背核、疑核、孤束核 | 副交感神经调节、吞咽、发声、内脏感觉 |
| **副神经（CN XI）** | 副神经核 | 头部转动、耸肩 |
| **舌下神经（CN XII）** | 舌下神经核 | 舌头运动 |

### 核心功能

| 功能类别 | 具体作用 |
|---------|---------|
| **呼吸控制** | 延髓呼吸中枢是呼吸的基本节律发生器，调节吸气和呼气 |
| **心血管调节** | 心血管中枢调节心率、血压和血管张力 |
| **反射中枢** | 咳嗽、喷嚏、吞咽、呕吐等保护性反射 |
| **内脏调节** | 通过迷走神经调节消化、呼吸、循环等内脏活动 |
| **运动交叉** | 锥体交叉确保大脑左半球控制右侧身体，反之亦然 |
| **感觉传导** | 传导本体感觉、精细触觉到大脑 |

### 延髓的重要中枢

#### 1. 呼吸中枢

| 中群 | 位置 | 功能 |
|------|------|------|
| **背侧呼吸群（DRG）** | 延髓背侧 | 吸气神经元，发起吸气 |
| **腹侧呼吸群（VRG）** | 延髓腹侧 | 呼气神经元，主动呼气 |
| **Pre-Bötzinger复合体** | 延髓腹外侧 | 呼吸节律发生器 |

#### 2. 心血管中枢

| 中群      | 功能                 |
| ------- | ------------------ |
| **加压区** | 升高血压和心率            |
| **减压区** | 降低血压和心率            |
| **感受区** | 接收来自颈动脉窦和主动脉弓的压力信息 |

#### 3. 呕吐中枢

- **化学感受器触发区（CTZ）**：位于最后区，监测血液中的毒素和药物
- **呕吐中枢**：协调呕吐反射的肌肉运动

### 临床意义

- **延髓损伤**：最危险的脑干损伤，可导致呼吸停止、心跳骤停
- **延髓综合征（Wallenberg综合征）**：小脑后下动脉阻塞导致，表现为眩晕、吞咽困难、对侧痛温觉丧失
- **球麻痹**：延髓脑神经损伤导致的吞咽困难、构音障碍
- **呼吸衰竭**：延髓呼吸中枢损伤可导致呼吸停止

## 脑干的整体功能

### 1. 生命维持中枢

| 功能 | 控制中枢 |
|------|---------|
| **呼吸** | 延髓呼吸中枢（基本节律）、脑桥呼吸调整中枢 |
| **心跳** | 延髓心血管中枢 |
| **血压** | 延髓心血管中枢 |
| **意识** | 脑干网状上行激活系统（ARAS） |

### 2. 反射中枢

| 反射 | 控制中枢 |
|------|---------|
| **咳嗽、喷嚏** | 延髓 |
| **吞咽** | 延髓 |
| **呕吐** | 延髓 |
| **眨眼** | 脑桥 |
| **瞳孔对光反射** | 中脑 |

### 3. 感觉与运动传导通路

脑干是几乎所有感觉和运动通路的必经之路：

- **上行通路**：脊髓→脑干→丘脑→大脑皮层（感觉）
- **下行通路**：大脑皮层→脑干→脊髓（运动）

### 4. 脑神经出脑部位

脑干是12对脑神经中10对的出脑部位：

| 脑神经 | 出脑部位 |
|--------|---------|
| 动眼神经（CN III） | 中脑 |
| 滑车神经（CN IV） | 中脑 |
| 三叉神经（CN V） | 脑桥 |
| 外展神经（CN VI） | 脑桥 |
| 面神经（CN VII） | 脑桥 |
| 前庭蜗神经（CN VIII） | 脑桥 |
| 舌咽神经（CN IX） | 延髓 |
| 迷走神经（CN X） | 延髓 |
| 副神经（CN XI） | 延髓 |
| 舌下神经（CN XII） | 延髓 |

## 脑干的临床综合征

### 中脑综合征

| 综合征 | 受损结构 | 症状 |
|--------|---------|------|
| **Weber综合征** | 大脑脚 | 对侧偏瘫、同侧动眼神经麻痹 |
| **Benedikt综合征** | 被盖 | 同侧动眼神经麻痹、对侧不自主运动 |
| **Claude综合征** | 红核 | 同侧动眼神经麻痹、对侧共济失调 |

### 脑桥综合征

| 综合征 | 受损结构 | 症状 |
|--------|---------|------|
| **Millard-Gubler综合征** | 脑桥基底外侧 | 同侧面瘫、对侧偏瘫 |
| **Foville综合征** | 脑桥被盖 | 同侧面瘫、同侧外展麻痹、对侧偏瘫 |

### 延髓综合征

| 综合征 | 受损结构 | 症状 |
|--------|---------|------|

## 脑干与意识

### 网状上行激活系统（ARAS）

脑干网状结构中的上行激活系统是维持清醒和意识的关键：

- **位置**：脑干被盖部的网状结构
- **功能**：通过丘脑非特异性核团激活大脑皮层
- **临床意义**：ARAS损伤可导致昏迷

### 脑死亡判定

脑干功能的完全丧失是判定脑死亡的重要标准之一：
- 脑干反射消失（瞳孔对光反射、角膜反射等）
- 自主呼吸停止
- 不可逆的昏迷

## 垂体（Pituitary Gland）

脑垂体是人体内分泌系统中最重要的腺体之一，通常被称为内分泌系统的"主腺体"或"总司令"。虽然它的大小仅仅和一颗豌豆差不多（重约 0.5 克），但它却掌控着人体内多种关键激素的分泌，直接调节着你的生长、发育、新陈代谢、压力反应以及生殖系统。

### 解剖位置

垂体位于大脑的底部，下丘脑（Hypothalamus）的正下方。它安稳地坐在颅骨底部一个被称为蝶鞍（Sella turcica）的微小骨质凹陷中，被骨头严密保护着。它通过一根名为"垂体柄"的微小漏斗状结构与下丘脑相连。

### 核心结构与功能

#### 1. 垂体前叶（腺垂体，Anterior Pituitary）

这是垂体的主体部分。它接收来自下丘脑的化学信号，并自主合成、分泌多种极其重要的激素：

- **生长激素 (GH)：** 调节儿童时期的骨骼和肌肉生长，并维持成年人的健康体成分和代谢。
- **促甲状腺激素 (TSH)：** 指挥颈部的甲状腺分泌甲状腺素，调节全身的基础代谢率。
- **促肾上腺皮质激素 (ACTH)：** 刺激肾上腺分泌皮质醇（应对压力的重要荷尔蒙）。
- **促性腺激素 (FSH 和 LH)：** 调节卵巢和睾丸的功能，控制女性的排卵、月经周期，以及男性的精子生成和睾酮分泌。
- **催乳素 (Prolactin)：** 刺激女性产后的乳房发育和乳汁分泌。

#### 2. 垂体后叶（神经垂体，Posterior Pituitary）

与前叶不同，后叶本身**不制造**激素。它本质上是下丘脑神经元的延伸，主要负责**储存和释放**由下丘脑产生的两种重要激素：

- **抗利尿激素 (ADH，也称血管加压素)：** 调节肾脏对水分的重吸收。
- **催产素 (Oxytocin)：** 刺激分娩时的子宫强烈收缩，以及哺乳时的排乳反射。它在心理学上也被称为"拥抱荷尔蒙"，与人类的社会连结、信任感和亲密关系密切相关。

### 临床意义

- **激素分泌过多：** 生长激素分泌过多可能导致儿童患上"巨人症"，或成年人患上"肢端肥大症"。
- **激素分泌不足：** 促甲状腺激素分泌不足会导致继发性甲状腺功能减退，让人感到极度疲倦、畏寒、体重异常增加。

## 下丘脑（Hypothalamus）

下丘脑是大脑中一个体积微小（大约只有杏仁那么大）却极其关键的区域。它是维持人体**内环境稳态（Homeostasis）**的最高控制中心，同时也是连接**神经系统**和**内分泌系统**的最重要桥梁。

### 解剖位置

正如它的名字所示，下丘脑位于**丘脑（Thalamus）的正下方**。向下，它通过一个被称为漏斗柄的结构，与脑垂体直接相连。

### 核心功能：生存与本能

下丘脑掌管着人类生存最基础、最本能的生理需求，常被戏称为控制"四个 F"：**F**eeding（进食）、**F**ighting（战斗）、**F**leeing（逃跑）以及 Mating（繁衍）。

- **体温调节：** 前核/视前核负责**散热**（前热），后核负责**产热**（后寒）。
    
- **摄食调节：** 腹内侧核负责**饱食**（腹内饱），外侧核负责**饥饿**（外侧饿）。
    
- **水盐平衡：** 视上核、室旁核合成 **ADH**（控水）。
    
- **时间昼夜：** 视交叉上核控制**生物钟**（SCN）。

- **体温调节（人体的恒温器）：** 当你觉得冷时，下丘脑会触发肌肉收缩（打寒颤）和血管收缩来保暖；当你觉得热时，它会促使你出汗散热。
- **饥饿与口渴：** 下丘脑内的特定神经元会实时监测血液中的血糖、脂肪酸和水分浓度。它决定了你什么时候感到饥饿或口渴，并在吃饱后向你发送"停止进食"的饱腹信号。
- **生物钟（昼夜节律）：** 下丘脑前端的一个微小结构——**视交叉上核（SCN）**，能直接接收视网膜传来的光照信息。它是人体的"主时钟"，控制着你的睡眠-觉醒周期。
- **情绪与压力反应：** 当面临紧急情况时，下丘脑会迅速激活交感神经系统，并促使肾上腺释放皮质醇和肾上腺素。这就是著名的"战斗或逃跑"（Fight or Flight）压力反应的起点。

### 它是如何控制脑垂体的？

1. **化学微血管通讯（控制垂体前叶）：** 下丘脑分泌多种"释放激素"或"抑制激素"。这些化学信使通过一个特殊的微小血管网直接流向垂体前叶，命令它分泌或停止分泌相应的激素。
2. **直接神经下行（控制垂体后叶）：** 下丘脑自己合成**抗利尿激素**和**催产素**，然后直接顺着神经纤维把它们运送到垂体后叶储存起来，等待合适的时机释放入血。

## 伏隔核（Nucleus Accumbens）

伏隔核是基底前脑的一个重要核团，通常被称为大脑的"奖赏中心"（Reward Center）。

### 它与中脑的紧密联系

中脑里除了黑质，还有一个极其关键的区域叫**腹侧被盖区（VTA）**。VTA 就像是多巴胺的"发射站"，而伏隔核就是最主要的"接收站"。它们之间连成了一条高速公路，被称为**中脑边缘多巴胺通路（Mesolimbic dopamine pathway）**。

### 核心功能

- **处理奖赏与愉悦感：** 当你经历美好的事情时，伏隔核会接收到多巴胺信号，让你产生强烈的愉悦感、满足感和正向反馈。
- **将"渴望"转化为"行动"（动机）：** 伏隔核负责把内在的渴望转化为实际的行动力。
- **预测误差与学习：** 伏隔核会对意料之外的惊喜产生最强烈的反应，帮助大脑学习"什么行为能带来好处"。

### 临床意义：成瘾的"重灾区"

几乎所有容易让人成瘾的物质和行为（如毒品、尼古丁、酒精、赌博、甚至无休止地刷短视频），其核心机制都是**劫持了伏隔核**。

## 脑室系统（Ventricular System）

脑室并不是某种实质性的组织或器官，而是大脑内部一系列**相互连接的、充满液体的空腔**。这些空腔里流淌着**脑脊液（Cerebrospinal Fluid, CSF）**。

### 脑室系统的四大"水库"

1. **侧脑室（Lateral Ventricles，共两个）：** 这是最大的一对脑室，呈巨大的"C"字形，左右大脑半球各有一个。
2. **第三脑室（Third Ventricle）：** 位于大脑中线的一个狭窄的、漏斗状的裂隙，正好夹在左右丘脑和下丘脑的中间。
3. **第四脑室（Fourth Ventricle）：** 位于脑干（脑桥和延髓）的后方，小脑的前方，形状像一个菱形的帐篷。

### 脑脊液与脑室的核心功能

- **物理缓冲与防震（"安全气囊"）：** 脑室和脑外围的脑脊液像水囊一样将大脑包裹起来，吸收冲力。
- **提供浮力与减重：** 人的大脑实际重量大约有 1400 克，但由于浮力作用，大脑的"有效重量"会骤降到只有 **50 克左右**。
- **冲刷废物（大脑的"下水道"）：** 脑脊液在脑室和脑组织间不断循环，将代谢废物"冲洗"掉。

### 临床现象：脑积水（Hydrocephalus）

如果脑室系统的某个管道堵塞了，脑脊液就会在脑室内不断积聚排不出去，导致脑室异常扩大，严重压迫周围脆弱的脑组织。

# 特殊结构

## 视神经（Optic Nerve）

第二脑神经（CN II），即视神经，是中枢神经系统（CNS）的直接延伸，负责将视网膜收集到的光信号传输给大脑进行图像解析。

### 特殊身份

- **无法再生：** 视神经是由中枢神经系统的细胞（少突胶质细胞）包裹的，一旦受损，导致的视力丧失通常是永久且不可逆的。
- **自带脑膜：** 视神经的外面直接包裹着和大脑一样的三层脑膜。

### 视觉通路（The Visual Pathway）

- **起点（视网膜）：** 眼球内部的神经节细胞汇聚成视神经离开眼眶。
- **核心十字路口（视交叉，Optic Chiasm）：** 位于大脑底部（恰好在脑垂体的正上方），来自双眼靠近鼻子那一侧的神经纤维会发生交叉。
- **终点站（视皮层）：** 信号传导至丘脑（外侧膝状体）进行初步过滤，最后投射到枕叶。

### 临床意义

- **压迫视交叉：** 脑垂体肿瘤向上压迫会导致**双颞侧偏盲**。
- **切断视交叉之后：** 会导致**同向性偏盲**。

# 自主神经系统（Autonomic Nervous System, ANS）

> 自主神经系统控制**不随意的内脏功能**：心跳、呼吸节律、消化、腺体分泌、血管张力等。
> 分为两大拮抗分支 + 一个半独立分支：
> - **交感神经系统**（Sympathetic NS）：战斗或逃跑
> - **副交感神经系统**（Parasympathetic NS）：休息与消化
> - **肠神经系统**（Enteric NS）：消化道的"第二大脑"（本页暂不展开）

## 三、迷走神经（Vagus Nerve，CN X）——详解

> 迷走（Vagus）= 拉丁语"流浪者"——这条神经从脑干出发，游走全身，是人体分布最广的脑神经。

### 3.1 基本参数

| 属性         | 内容                                        |
| ---------- | ----------------------------------------- |
| **编号**     | 第十对脑神经（CN X）                              |
| **性质**     | 混合神经（感觉 + 运动 + 副交感）                       |
| **纤维比例**   | **~80% 传入（感觉，自体→脑）/ ~20% 传出（运动+副交感，脑→体）** |
| **出脑部位**   | 延髓橄榄后沟                                    |
| **出颅孔**    | 颈静脉孔                                      |
| **核团（延髓）** | 迷走神经背核、疑核、孤束核                             |

### 3.2 四种纤维成分

```
迷走神经
├── 一般躯体感觉（GSA）
│   → 耳廓皮肤感觉（Arnold耳支）
│
├── 一般内脏感觉（GVA）← 最重要：内感受的主要通路
│   → 胸腔和腹腔脏器的机械、化学、温度感觉
│   → 传入孤束核 → 脑干 → 岛叶（主观感受）
│
├── 特殊内脏感觉（SVA）
│   → 会厌和咽部的味觉 → 孤束核
│
├── 一般内脏运动（GVE）= 副交感传出
│   起于迷走神经背核
│   → 心、肺、食管、胃、小肠、肝、胰、肾、结肠（至脾曲）
│
└── 特殊内脏运动（SVE）
    起于疑核
    → 咽喉部肌肉（吞咽、发声）
```

```
├── 胃支 → 胃
├── 肝支 → 肝、胆囊
├── 腹腔支 → 腹腔神经丛 → 小肠、升结肠、横结肠
```

### 3.4 核团详解（延髓）

| 核团 | 功能 |
|------|------|
| **迷走神经背核**（Dorsal Motor Nucleus） | 副交感传出：控制胸腔、腹腔脏器 |
| **疑核**（Nucleus Ambiguus） | 特殊内脏运动：咽喉肌群（吞咽、发声）+ 心脏副交感（部分） |
| **孤束核**（Nucleus Tractus Solitarius） | 接收 80% 的传入：内脏感觉 + 味觉，上传至岛叶/杏仁核/下丘脑 |

### 3.5 迷走神经的"80% 传入"意义

```
常见误解：迷走神经 = 大脑命令身体的通道
实际情况：迷走神经 = 身体向大脑汇报状态的主干道

身体内部信号（心跳、肠道蠕动、炎症、饥饿）
        ↓ 经迷走神经传入纤维（80%）
孤束核（延髓）
        ↓
脑桥、下丘脑、丘脑
        ↓
岛叶（产生主观的身体感受）
        ↓
前额叶（情绪解读、决策）

→ 这正是"岛叶-内感受-情绪"链条的解剖基础
→ 也是肠-脑轴的主要神经通路
```

### 3.6 临床意义

| 临床场景 | 机制 | 表现 |
|---------|------|------|
| **迷走性晕厥（血管迷走性晕厥）** | 强烈情绪/疼痛激活迷走 → 心率↓ + 血压↓ → 脑灌注不足 | 突然眼前发黑、晕倒 |
| **心率变异性（HRV）** | 迷走张力越高→HRV越高→自主神经健康度越好 | 用于评估压力/恢复状态 |
| **迷走神经刺激（VNS）** | 植入式电刺激左侧颈部迷走神经 | 难治性癫痫、抑郁症的辅助治疗 |
| **经皮耳迷走神经刺激（taVNS）** | 刺激耳廓迷走神经支（无创） | ADHD、抑郁、炎症性疾病研究中 |
| **炎症反射（Cholinergic Anti-inflammatory Pathway）** | 迷走传出→脾脏→ACh抑制炎症因子 | 迷走神经是"天然抗炎通道" |
| **肠-脑轴** | 肠道菌群代谢产物→激活迷走传入→大脑 | 焦虑、抑郁、ADHD的可能机制 |
| **Wallenberg综合征** | 小脑后下动脉阻塞→迷走核损伤 | 吞咽困难、声音嘶哑、同侧Horner征 |

## 四、交感 vs 副交感 vs 迷走：综合记忆图

```
【外部威胁感知】
        ↓
    下丘脑激活
        ↓
┌───────────────────────────────────┐
│          交感系统全面激活           │
│  肾上腺髓质 → 肾上腺素入血         │
│  心率↑ 血压↑ 瞳孔↑ 支气管扩张      │
│  消化↓ 排尿↓ 皮肤苍白              │
└───────────────────────────────────┘
【威胁解除/安全状态】
        ↓
    迷走神经激活（副交感主导）
        ↓
┌───────────────────────────────────┐
│          副交感系统（迷走为主）      │
│  心率↓ 消化↑ 腺体分泌↑ 排尿↑       │
│  身体自我修复、储能                 │
└───────────────────────────────────┘
                  ↑
        迷走传入（80%）同时持续上报
        "身体现在的状态" → 岛叶 → 情绪
```

| 指标 | 交感激活 | 副交感（迷走）激活 |
|------|---------|-----------------|
| 心率 | ↑ | ↓ |
| 心率变异性（HRV） | ↓（模式僵硬） | ↑（模式灵活） |
| 瞳孔 | 散大 | 缩小 |
| 口腔 | 干燥、黏稠唾液 | 大量稀薄唾液 |
| 皮肤 | 苍白、出汗（冷汗） | 温暖、红润 |
| 消化 | 抑制 | 促进 |
| 情绪体验 | 焦虑、警觉、紧张 | 平静、放松、连结感 |
| 呼吸 | 浅快 | 深慢 |
