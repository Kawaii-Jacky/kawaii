# 应激相关障碍：抑郁、焦虑、PTSD、库欣与慢性疼痛综合征

> 这六种障碍在 [[心理学/血清素系统、HPA轴与杏仁核恐惧回路]] 中被归入两种 HPA 轴失调模式。本文逐一深入拆解每种障碍的神经内分泌机制、核心脑区异常、临床表现的生化根源，以及治疗靶点。

---

## 总览：两种HPA轴失调模式

```
                    HPA 轴失调谱系
                         │
        ┌────────────────┴────────────────┐
        ↓                                  ↓
【高皮质醇模式】                        【低皮质醇模式】
负反馈失灵，系统过度激活                  系统耗竭，过度抑制
        │                                  │
  ├── 忧郁型抑郁症                    ├── 慢性PTSD
  ├── 慢性焦虑障碍                    ├── 纤维肌痛
  └── 库欣综合征                      └── 慢性疲劳综合征
                                      （非典型抑郁症也常在此侧）
```

> ⚠️ 两种模式不是非此即彼——同一种疾病在不同阶段可能从高皮质醇转为低皮质醇（如 PTSD 从急性期到慢性期的转变）。

## 一、忧郁型抑郁症（Melancholic Depression）

### 1.1 临床画像

忧郁型抑郁症是抑郁症的**最严重亚型**，核心特征不同于"典型"抑郁：

| 特征 | 忧郁型抑郁 | 非典型抑郁 |
|-----|-----------|-----------|
| **情绪反应性** | 对正面事件**完全无反应**（"什么都不能让我开心"） | 对正面事件仍有反应（但被负面压制） |
| **生物节律** | 早醒（比平时早2小时以上）、晨重暮轻 | 晚重暮轻、嗜睡 |
| **食欲/体重** | 显著下降 | 增加（碳水渴求） |
| **精神运动** | 迟缓（说话慢、动作慢）或激越 | 疲劳感为主 |
| **快感缺失** | 全面性——所有活动丧失愉悦感 | 选择性——某些活动仍能享受 |
| **自杀风险** | 极高 | 中高 |

### 1.2 HPA 轴异常（高皮质醇模式）

忧郁型抑郁症是 HPA 轴过度激活的**原型疾病**：

```
慢性心理应激 / 早期创伤
        ↓
下丘脑 CRH 持续过度分泌
        ↓
垂体 ACTH 持续偏高
        ↓
肾上腺皮质醇持续高位
        ↓
【负反馈失灵】
海马 GR 受体下调 → 无法有效抑制 CRH/ACTH
        ↓
皮质醇长期高水平 → 系统性损害
```

**具体神经内分泌标志**：

| 指标 | 忧郁型抑郁的表现 |
|-----|----------------|
| **24小时皮质醇曲线** | 基线升高；晨峰过高且延迟回落 |
| **地塞米松抑制试验（DST）** | **不能被抑制**（正常人服用地塞米质后皮质醇应下降） |
| **CRH 激发试验** | ACTH 反应钝化（垂体已被高 CRH"耗尽"） |
| **脑脊液 CRH** | 显著升高 |
| **皮质醇觉醒反应（CAR）** | 过度放大 |

### 1.3 脑区损害机制

```
长期高皮质醇
    │
    ├──→ 海马
    │    ├── GR 受体下调 → 负反馈环路断裂
    │    ├── 神经元萎缩（树突回缩、棘突减少）
    │    ├── 神经新生减少（BDNF↓）
    │    └── 体积缩小（MRI可测量，治疗后部分可逆）
    │
    ├──→ 前额叶皮层（PFC）
    │    ├── 背外侧 PFC（DLPFC）功能↓ → 执行功能↓
    │    ├── 膝下前扣带回（sgACC，BA25）过度激活
    │    │   → 这是难治性抑郁的核心靶点
    │    │   → 深部脑刺激（DBS）靶点
    │    └── vmPFC 功能↓ → 情绪调节能力↓
    │
    └──→ 杏仁核
         └── 高皮质醇 → 树突增长 → 过度敏感化
             → 对负面刺激反应↑，对正面刺激反应↓
```

> 💡 **为什么忧郁型患者"什么都感受不到"**：杏仁核被高皮质醇重塑为"负面偏向"——对快乐信号的响应被压制，对威胁/悲伤信号的响应被放大。这不是"想太多"，是神经结构的物理改变。

### 1.4 血清素系统的角色

```
高皮质醇
    ↓
中缝核 5-HT1A 自受体下调
    ↓
5-HT 释放调控失常
    ↓
海马 / PFC 中 5-HT 信号↓
    ↓
├── 情绪调节↓
├── 冲动控制↓
└── 杏仁核抑制↓ → 更多负面偏向
```

### 1.5 现代治疗靶点

| 治疗 | 靶点 | 机制 |
|-----|------|------|
| **SSRIs / SNRIs** | 5-HT系统 | 恢复5-HT调节；长期促进海马BDNF |
| **氯胺酮（Ketamine）** | NMDA受体 → mTOR通路 | **快速抗抑郁**（数小时内）；促进突触新生 |
| **ECT（电休克）** | 全脑 | 促进BDNF↑、神经新生↑、HPA轴重置 |
| **DBS（深部脑刺激）** | sgACC（BA25） | 直接调控抑郁核心节点 |
| **rTMS（经颅磁刺激）** | DLPFC | 增强PFC功能 → 恢复对杏仁核的抑制 |

## 二、慢性焦虑障碍（Chronic Anxiety Disorders）

### 2.1 涵盖范围

慢性焦虑不是单一诊断，而是一组共享核心机制的障碍：

```
慢性焦虑谱系
├── 广泛性焦虑障碍（GAD）——持续的、不可控的过度担忧
├── 社交焦虑障碍（SAD）——对社交评价的恐惧
├── 惊恐障碍（PD）——反复的、不可预测的恐慌发作
├── 特定恐惧症——对特定对象/场景的过度恐惧
└── 混合性焦虑——多种焦虑症状共存
```

### 2.2 HPA 轴异常

慢性焦虑的 HPA 轴模式介于正常和忧郁型抑郁之间：

| 指标        | GAD               | 惊恐障碍           | 社交焦虑      |
| --------- | ----------------- | -------------- | --------- |
| **基线皮质醇** | 轻度升高              | 正常或间歇性升高       | 正常或轻度升高   |
| **应激反应性** | 夸大（对心理应激的皮质醇反应过大） | SAM轴为主（肾上腺素风暴） | 对社交应激反应过大 |
| **DST**   | 通常可被抑制（与忧郁型不同）    | 可被抑制           | 可被抑制      |
| **日节律**   | 可能轻度紊乱            | 通常正常           | 通常正常      |

> ⚠️ 惊恐障碍的核心机制更多在 **SAM 轴**（而非 HPA 轴）：杏仁核中央核 → 蓝斑核 → 肾上腺素风暴 → 心悸、出汗、濒死感。这是 SAM 轴的"误触发"。

### 2.3 核心脑区异常

```
慢性焦虑的神经回路失衡：

杏仁核（过度激活）
    ├── 基础激活水平↑（静息时也高于正常）
    ├── 对模糊刺激倾向于威胁性解读
    └── 恐惧消退学习受损

前额叶皮层（抑制不足）
    ├── vmPFC 功能↓ → 无法有效抑制杏仁核
    ├── DLPFC 功能↓ → 认知重评能力↓
    └── ACC 冲突监控过度 → "反刍"（反复想同一件事）

海马
    ├── 提供情境信息功能受损
    └── 无法帮助区分"安全情境"和"危险情境"
```

### 2.4 GABA 系统的核心角色

```
焦虑障碍中 GABA 的地位：

杏仁核内侧的 GABA 能中间神经元
    ├── 正常：构成杏仁核的"内置刹车系统"
    └── 焦虑：GABA 中间神经元功能↓
        ├── GABA-A 受体密度↓
        ├── GABA 合成酶（GAD67）表达↓
        └── 结果：杏仁核失去内部抑制 → 持续过度激活

苯二氮卓类（如地西泮）的快速抗焦虑机制：
    → 增强 GABA-A 受体功能 → 恢复杏仁核内部抑制
    → 但：仅是"掩盖"症状，不解决根本问题
    → 且有依赖风险
```

### 2.5 与忧郁型抑郁的关键区别

| 维度 | 慢性焦虑 | 忧郁型抑郁 |
|-----|---------|-----------|
| **核心情绪** | 对**未来**的恐惧/担忧 | 对**当下**的空虚/绝望 |
| **杏仁核** | 基础激活↑（一直在"警戒"） | 对负面刺激过度反应（"选择性敏感"） |
| **HPA轴** | 轻度升高或正常 | 显著升高、负反馈失灵 |
| **SAM轴** | 惊恐障碍中显著异常 | 较少直接异常 |
| **GABA** | 核心缺陷 | 次要缺陷 |
| **5-HT** | 5-HT2A过度激活为主 | 5-HT1A功能↓为主 |
| **治疗重点** | GABA增强 + 5-HT调节 | HPA轴重置 + 5-HT恢复 + 神经新生 |

## 三、库欣综合征（Cushing's Syndrome）

### 3.1 什么是库欣综合征？

库欣综合征是**皮质醇长期过高**的内分泌疾病，可由外源性（长期使用糖皮质激素药物）或内源性（垂体ACTH瘤、肾上腺瘤、异位ACTH分泌）引起。

**垂体ACTH瘤 → 库欣病（Cushing's Disease）**是内源性最常见的类型。

### 3.2 身体表现

```
长期高皮质醇的全身效应：

代谢
├── 向心性肥胖（躯干胖、四肢细）
├── 满月脸、水牛背
├── 皮肤紫纹（皮肤变薄、血管可见）
└── 高血糖 / 糖尿病

骨骼
├── 骨质疏松
└── 病理性骨折

免疫
├── 免疫抑制 → 感染易感性↑
└── 伤口愈合缓慢

生殖
├── 月经紊乱 / 闭经
└── 性欲↓

心血管
├── 高血压
└── 心血管事件风险↑
```

### 3.3 神经精神表现（与脑区损害的直接对应）

库欣综合征是研究"高皮质醇如何损害大脑"的**天然实验模型**，因为可以精确测量皮质醇水平：

| 神经精神症状 | 脑区损害机制 | 发生率 |
|------------|-----------|-------|
| **抑郁症** | 海马萎缩 + sgACC过度激活 + 5-HT系统受损 | 50-80% |
| **认知障碍**（记忆↓、注意力↓） | 海马体积缩小（可逆性！治疗后部分恢复） | 30-80% |
| **焦虑** | 杏仁核高皮质醇→树突增长→过度敏感化 | 常见 |
| **情绪不稳/易怒** | 前额叶-杏仁核调控失衡 | 常见 |
| **精神病性症状**（罕见） | 重度皮质醇毒性 | 3-5% |
| **自杀意念** | 多因素叠加 | 显著升高 |

> 💡 **关键发现**：库欣综合征患者的海马体积缩小是**可逆的**——成功治疗（降低皮质醇）后，海马体积可以部分恢复，认知功能也随之改善。这证明了海马的神经可塑性，也间接支持了抑郁症"海马萎缩可逆"的假说。

### 3.4 库欣综合征作为抑郁症的"生物模型"

```
库欣综合征                忧郁型抑郁症
    │                        │
    ↓                        ↓
皮质醇过高（可测量）        皮质醇过高（程度较轻）
    │                        │
    ↓                        ↓
海马萎缩（MRI可量化）      海马萎缩（程度较轻）
    │                        │
    ↓                        ↓
抑郁症状 + 认知障碍        抑郁症状 + 认知障碍

→ 库欣综合征的存在证明：高皮质醇本身足以导致抑郁，
  不需要"心理原因"作为解释
→ 这是抑郁症"内分泌假说"的最强证据
```

### 3.5 治疗与神经恢复

| 治疗 | 靶点 | 神经恢复效果 |
|-----|------|------------|
| **手术切除肿瘤** | 根治皮质醇来源 | 海马体积6-12月内部分恢复；抑郁症状通常改善 |
| **酮康唑/美替拉酮** | 皮质醇合成抑制 | 降低皮质醇→神经保护 |
| **米非司酮** | 糖皮质激素受体拮抗剂 | 阻断皮质醇对脑的效应 |
| **SSRIs** | 5-HT系统 | 对库欣相关抑郁有效（但需同时治疗根本原因） |

## 四、慢性 PTSD（Chronic PTSD）

### 4.1 从急性到慢性：HPA 轴的转变

PTSD 的 HPA 轴异常**不是简单的"过度激活"**，而是更复杂的模式：

```
创伤事件
    │
    ├── 急性期（数天-数周）
    │   ├── HPA轴过度激活：皮质醇↑
    │   ├── SAM轴过度激活：肾上腺素/NE↑↑
    │   ├── 杏仁核过度敏感
    │   └── 可能自然消退（大多数人会恢复）
    │
    └── 慢性期（数月-数年，若未恢复）
        ├── HPA轴转为低反应模式 ← 反直觉！
        │   ├── 基础皮质醇偏低
        │   ├── 对新应激的皮质醇反应减弱
        │   ├── 24小时皮质醇曲线扁平化
        │   └── 机制：GR受体超敏 → 负反馈过度 → 系统被"锁在关闭位"
        │
        ├── SAM轴持续高活性
        │   ├── NE基线偏高
        │   ├── 对创伤线索的NE反应过大
        │   └── 交感神经过度激活 → HRV↓
        │
        └── 杏仁核+海马+PFC 的结构性改变
```

### 4.2 慢性 PTSD 的"三重脑损伤"

```
【杏仁核】——过度警觉的守卫
├── 对创伤相关线索过度激活
├── 对中性线索也倾向于威胁性解读
├── 树突结构增长（高皮质醇/高NE效应）
└── 结果：持续的过度警觉、惊跳反应↑

【海马】——时间标记丧失
├── 体积缩小（皮质醇毒性 + 应激性神经新生↓）
├── 情境记忆功能受损
├── 无法标记"那是过去的事"
└── 结果：创伤记忆像"正在发生"——闪回的神经基础

【vmPFC】——失灵的刹车
├── 功能减弱、体积缩小
├── 对杏仁核的抑制性投射减弱
├── 恐惧消退学习受损
└── 结果：无论怎么理智分析，恐惧就是消不掉
```

### 4.3 为什么慢性 PTSD 皮质醇反而低？

这是 PTSD 研究中最反直觉的发现之一（Rachel Yehuda 等人的开创性工作）：

```
解释模型：GR超敏假说

创伤暴露
    ↓
急性期皮质醇大量释放
    ↓
海马 GR 受体长期暴露于高皮质醇
    ↓
GR 受体代偿性超敏（受体密度↑、敏感性↑）
    ↓
即使正常水平的皮质醇也能触发过强的负反馈
    ↓
CRH / ACTH 被过度抑制
    ↓
基础皮质醇偏低
    ↓
但：对新应激的反应仍然过强（因为杏仁核仍然过度敏感）
    → "系统对外界刺激过度反应，但自我调节能力已被锁死"
```

> 💡 这解释了为什么 PTSD 患者既"过度警觉"（杏仁核过激）又"情感麻木"（HPA轴过度抑制）——两种看似矛盾的症状来自同一系统的不同层面。

### 4.4 NE 与恐惧记忆再巩固

```
创伤记忆被提取（闪回/触发）
        ↓
蓝斑核大量释放 NE
        ↓
杏仁核外侧核（LA）的 β-肾上腺素受体激活
        ↓
恐惧记忆再巩固（记忆被重新加固，而非被修正）
        ↓
记忆变得更顽固

【干预窗口】
在记忆提取后 6 小时内给予普萘洛尔（β受体阻断剂）
        ↓
阻断 NE → β 受体信号
        ↓
恐惧记忆再巩固受阻 → 记忆的情绪强度↓
（记忆内容仍在，但不再引发强烈恐惧）
```

### 4.5 治疗策略

| 治疗 | 靶点 | 层面 |
|-----|------|------|
| **EMDR** | 双侧刺激 + 恐惧记忆再巩固 | 促进海马整合创伤记忆 |
| **PE（延长暴露疗法）** | vmPFC → 杏仁核抑制回路 | 促进恐惧消退学习 |
| **普萘洛尔** | β受体 → 记忆再巩固 | 在记忆提取后削弱情绪强度 |
| **SSRIs** | 5-HT → 杏仁核阈值 | 长期调节 |
| **MDMA辅助心理治疗** | 5-HT/催产素/NE → 杏仁核 + 社会信任 | 2024年FDA突破性疗法认定（已暂缓，但证据强） |
| **酮胺** | NMDA → 突触可塑性 | 快速减轻症状（研究中） |

## 五、纤维肌痛（Fibromyalgia）

### 5.1 什么是纤维肌痛？

纤维肌痛是一种**中枢敏化综合征**（Central Sensitization Syndrome），核心特征是：
- 广泛性慢性疼痛（全身多部位）
- 痛觉过敏（对正常刺激感到疼痛）
- 疲劳、睡眠障碍、认知障碍（"纤维雾"）

> ⚠️ 纤维肌痛不是"心理作用"——它有明确的神经生理基础，涉及**下行痛觉抑制通路的失灵**。

### 5.2 HPA 轴异常（低皮质醇模式）

| 指标 | 纤维肌痛的表现 |
|-----|--------------|
| **基础皮质醇** | 偏低（尤其晨峰减弱） |
| **皮质醇日节律** | 扁平化（正常的晨高夜低曲线消失） |
| **应激皮质醇反应** | 钝化（对急性应激的皮质醇升高幅度↓） |
| **ACTH** | 偏低或正常 |
| **DST** | 过度抑制 |

### 5.3 核心机制：下行痛觉抑制通路失灵

```
正常痛觉调控：

疼痛信号进入脊髓
        ↓
脑干（导水管周围灰质 PAG + 延髓头端腹内侧区 RVM）
        ↓ 释放
5-HT + NE → 下行投射到脊髓背角
        ↓
抑制痛觉信号上传 → "不那么疼"

纤维肌痛中：

下行抑制通路功能↓
├── 5-HT 释放↓ → 脊髓 5-HT1A/1B 受体激活不足
├── NE 释放↓ → 脊髓 α2 受体激活不足
└── 同时：兴奋性神经递质（谷氨酸、P物质）↑
        ↓
痛觉信号未被有效抑制 → 广泛性疼痛
        ↓
长期疼痛 → HPA轴慢性应激 → 系统耗竭 → 皮质醇↓
        ↓
低皮质醇 → 免疫调节异常 → 神经炎症↑ → 更多疼痛
```

### 5.4 与抑郁症/PTSD 的共病机制

纤维肌痛与抑郁症、PTSD 的共病率极高（30-80%），因为它们共享部分神经机制：

```
共享机制：
├── HPA 轴低皮质醇模式
├── 5-HT / NE 下行抑制通路功能↓
├── 睡眠结构破坏（深睡眠↓）
├── 神经炎症（促炎因子↑）
└── 早期创伤 / 慢性应激史
```

> 💡 **SNRIs（度洛西汀、米那普仑）** 之所以是一线药物，是因为它们同时增加 5-HT 和 NE → 直接恢复下行痛觉抑制通路的功能。

### 5.5 治疗

| 治疗 | 靶点 | 机制 |
|-----|------|------|
| **度洛西汀 / 米那普仑** | 5-HT + NE 再摄取抑制 | 恢复下行痛觉抑制通路 |
| **普瑞巴林** | α2δ 钙通道 | 减少脊髓兴奋性神经递质释放 |
| **低剂量纳曲酮（LDN）** | 胶质细胞阿片受体 | 降低神经炎症 |
| **运动** | 全身 | 内啡肽↑、神经炎症↓、HPA轴调节 |
| **CBT** | 认知重评 | 减少灾难化思维 → 疼痛感知↓ |

## 六、慢性疲劳综合征（CFS / ME）

### 6.1 什么是慢性疲劳综合征？

CFS（Chronic Fatigue Syndrome），也称 **ME（Myalgic Encephalomyelitis）**，是一种以**极度疲劳**为核心、持续6个月以上、休息不能缓解的疾病。

**核心诊断标准（Fukuda / ICC）**：
- 劳后不适（Post-Exertional Malaise, PEM）：轻微活动后症状急剧恶化
- 睡眠不能恢复精力
- 认知障碍（注意力、记忆、处理速度↓）
- 直立不耐受（站久后头晕/心率异常）

### 6.2 HPA 轴异常

CFS 的 HPA 轴模式与纤维肌痛高度相似：

| 指标 | CFS 的表现 |
|-----|-----------|
| **基础皮质醇** | 偏低（尤其日间总皮质醇↓） |
| **晨峰皮质醇（CAR）** | 减弱或消失 |
| **ACTH 刺激试验** | 肾上腺反应钝化 |
| **应激皮质醇反应** | 幅度↓、恢复时间延长 |

### 6.3 神经免疫机制

CFS 被认为是一种**神经免疫性疾病**，涉及多系统的交互失衡：

```
触发因素（可能）
├── 病毒感染（EBV、肠道病毒等）
├── 慢性心理应激
└── 免疫系统异常激活
        ↓
┌──────────────────────────────────────┐
│ 神经炎症                              │
│ ├── 小胶质细胞激活 → 促炎细胞因子↑     │
│ │   （IL-1β, IL-6, TNF-α）            │
│ ├── 细胞因子作用于脑 → 疲劳/认知障碍   │
│ │   （"病态行为" Sickness Behavior）   │
│ └── 血脑屏障通透性↑                    │
│                                       │
│ HPA 轴耗竭                            │
│ ├── 皮质醇↓ → 抗炎能力↓               │
│ └── 免疫调控失衡 → 慢性低度炎症持续     │
│                                       │
│ 自主神经功能障碍                        │
│ ├── 交感-副交感失衡                    │
│ ├── HRV↓                             │
│ └── 直立不耐受                         │
│                                       │
│ 线粒体功能障碍（能量代谢↓）             │
│ ├── ATP 产生↓                        │
│ └── 乳酸堆积↑                         │
└──────────────────────────────────────┘
```

### 6.4 与其他障碍的对比

| 维度 | CFS | 纤维肌痛 | 忧郁型抑郁 |
|-----|-----|---------|-----------|
| **核心症状** | 极度疲劳 | 广泛性疼痛 | 情绪空虚 |
| **HPA轴** | 低皮质醇 | 低皮质醇 | 高皮质醇 |
| **炎症** | 神经炎症↑ | 神经炎症↑ | 炎症↑（但机制不同） |
| **活动后恶化** | 显著（PEM是核心特征） | 可有但非核心 | 通常无 |
| **抗抑郁药效果** | 有限（对疲劳帮助小） | SNRIs有效 | SSRIs/SNRIs有效 |
| **运动** | **需极度谨慎**（过度运动加重PEM） | 有益 | 有益 |

> ⚠️ **CFS 与运动的关系**：与纤维肌痛和抑郁不同，CFS 患者的运动处方需要**极其谨慎**——过度活动会触发 PEM（劳后不适），导致数天至数周的症状恶化。这是 CFS 与其他疲劳性疾病的关键鉴别点。

### 6.5 治疗现状

目前 CFS **没有特效治疗**，以症状管理为主：

| 治疗 | 靶点 | 证据水平 |
|-----|------|---------|
| **分级运动疗法（GET）** | 体能 | ⚠️ 争议大——可能触发PEM |
| **CBT** | 认知行为 | 部分帮助，但不能治愈 |
| **低剂量纳曲酮（LDN）** | 神经炎症 | 初步证据阳性，RCT不足 |
| **米哚妥林** | H1受体/肥大细胞 | 研究中 |
| **抗病毒药物** | 病毒触发 | 证据有限 |
| **能量管理（Pacing）** | 活动-休息平衡 | 目前最推荐的自我管理策略 |

## 八、治疗原理的统一视角

```
                    治疗靶点对应图

    5-HT系统不足 ──→ SSRIs / SNRIs
    NE系统不足  ──→ SNRIs（度洛西汀）/ 托莫西汀
    GABA不足    ──→ 苯二氮卓 / 加巴喷丁 / 普瑞巴林

    海马萎缩    ──→ 运动（BDNF↑）/ 抗抑郁药 / 氯胺酮
    vmPFC功能↓  ──→ CBT / rTMS / 正念冥想
```
