# 血清素系统、HPA轴、SAM轴与杏仁核恐惧回路

> 这四个系统是理解情绪障碍（抑郁、焦虑、PTSD、BPD）的核心基础设施。  
> 本笔记结合 [[心理学/高级精神活动的脑区基础.md]] 的脑区框架，深入解析其结构、机制与调控。

---

## 一、血清素系统（Serotonin / 5-HT System）

### 1.1 什么是血清素？

血清素（Serotonin），化学名 **5-羟色胺（5-HT，5-Hydroxytryptamine）**，是一种同时充当**神经递质**和**信号分子**的物质。

> ⚠️ 常见误解：血清素 ≠ "快乐激素"。它更像是大脑的**情绪稳定器**和**社会信号调制器**，而非单纯制造快乐。

**合成路径**：

```
食物中的色氨酸（Tryptophan）
        ↓ 色氨酸羟化酶（TPH）
5-羟基色氨酸（5-HTP）
        ↓ 芳香族氨基酸脱羧酶（AADC）
血清素（5-HT）
        ↓（松果体内）N-乙酰转移酶
褪黑素（Melatonin）← 血清素是褪黑素的前体
```

**关键事实**：人体 **约90-95% 的血清素** 存在于**肠道**（肠嗜铬细胞），大脑中只占 5%。肠道血清素主要调节肠道蠕动，**无法穿越血脑屏障**进入大脑——这正是"肠-脑轴"研究的核心问题之一。

---

### 1.2 中缝核：大脑的血清素"总发射台"

```
中缝核（Raphe Nuclei）——脑干中线处
        │
        ├──→ 前额叶皮层（PFC）
        │         情绪调节、认知控制、社会判断
        │
        ├──→ 杏仁核（Amygdala）
        │         抑制过度恐惧反应
        │
        ├──→ 海马（Hippocampus）
        │         情绪记忆整合、应激调节
        │
        ├──→ 基底神经节（Basal Ganglia）
        │         奖励调节、强迫行为
        │
        ├──→ 下丘脑（Hypothalamus）
        │         食欲、睡眠、性行为
        │
        └──→ 脊髓（Spinal Cord）
                  痛觉调制
```

中缝核分为**背侧中缝核（DRN）**和**中缝正中核（MRN）**：
- **DRN** → 主要投射到前额叶、纹状体、杏仁核（与情绪/认知相关）
- **MRN** → 主要投射到海马、隔区（与记忆/焦虑相关）

---

### 1.3 血清素受体家族（14种，功能各异）

血清素没有单一功能，因为它作用于 **14 种受体亚型**，分布在不同脑区：

| 受体          | 分布               | 功能                       | 药物靶点                  |
| ----------- | ---------------- | ------------------------ | --------------------- |
| **5-HT1A**  | 海马、前额叶、中缝核（自突触）  | 抑制焦虑、促进情绪稳定；自突触时抑制5-HT释放 | 丁螺环酮（抗焦虑）；SSRIs 的部分效应 |
| **5-HT2A**  | 皮层、丘脑、基底神经节      | 过度激活→焦虑/幻觉；适度激活→认知灵活性    | 抗精神病药（阻断）；迷幻药（激动）     |
| **5-HT2C**  | 脉络丛、边缘系统         | 食欲抑制、情绪调节                | 部分抗抑郁药的副作用（体重增加）靶点    |
| **5-HT3**   | 脑干、外周神经（唯一离子通道型） | 恶心反射、痛觉                  | 止吐药（昂丹司琼阻断）           |
| **5-HT4**   | 海马、纹状体           | 记忆、认知增强                  | 研究中                   |
| **5-HT6/7** | 纹状体、丘脑           | 认知、昼夜节律                  | 新型抗抑郁药靶点              |

---

### 1.4 血清素如何影响情绪？

血清素不是直接"制造"情绪，而是通过以下机制**调制情绪系统的敏感性**：

#### 机制一：调控杏仁核的威胁反应阈值

```
正常血清素水平：
中缝核 → 5-HT 投射到杏仁核 → 激活 5-HT1A 受体
        ↓
杏仁核对威胁刺激的激活阈值升高
        ↓
"没那么容易被吓到" → 情绪稳定

血清素不足时：
杏仁核阈值降低 → 对中性刺激也产生威胁反应
        ↓
持续焦虑、过度恐惧、情绪反应过激
```

#### 机制二：调节前额叶-杏仁核的抑制回路

```
血清素 → 增强前额叶皮层（PFC）功能
        ↓
PFC 对杏仁核的"自上而下"抑制增强
        ↓
情绪冲动被理性更好地调控

血清素不足 → PFC 功能受损 → 对杏仁核的抑制减弱
        ↓
情绪冲动无法被压制 → 抑郁/焦虑/冲动性行为
```

#### 机制三：影响社会地位感知与威胁评估

进化生物学研究（Sloman, 1994）：血清素水平与感知到的**社会地位**呈正相关。
- 高血清素 → 感知自身地位稳固 → 更少焦虑、更多探索行为
- 低血清素 → 感知自身处于社会威胁中 → 更多防御/回避行为

这解释了为什么社会羞辱、被排斥事件后，抑郁风险会急剧上升。

#### 机制四：昼夜节律与血清素-褪黑素轴

```
白天光照 → 血清素合成↑（DRN 被光激活）
        ↓
血清素 → 松果体 → 夜间转化为褪黑素
        ↓
睡眠质量↑ → 次日情绪稳定性↑

→ 季节性抑郁（SAD）与冬季日照减少→血清素↓→褪黑素紊乱密切相关
```

---

### 1.5 血清素与各障碍的关系

| 障碍           | 血清素异常模式                                   |
| ------------ | ----------------------------------------- |
| **抑郁症**      | 5-HT 传递整体减弱；突触可用性↓                        |
| **焦虑障碍**     | 杏仁核 5-HT2A 过度激活；5-HT1A 功能↓                |
| **强迫症（OCD）** | 眶额皮层-纹状体 5-HT 回路异常（强迫行为是"刹不住的 5-HT 驱动循环"） |
| **BPD**      | 5-HT 传递减弱 → 冲动性↑、情绪调节↓                    |
| **PTSD**     | 5-HT 系统慢性受损（与 HPA 轴共同作用）                  |
| **进食障碍**     | 5-HT2C 受体异常（与食欲/体像感知相关）                   |

### 1.6 SSRIs 的作用原理（为什么是一线药物）

**SSRIs（选择性血清素再摄取抑制剂）**，如氟西汀、舍曲林、艾司西酞普兰：

```
正常突触的"清理机制"：
突触前神经元 → 释放 5-HT → 作用于突触后受体
        ↓ 之后
5-HT 转运体（SERT）把 5-HT 回收回突触前细胞

SSRIs 的作用：
阻断 SERT → 5-HT 无法被回收
        ↓
突触间隙中 5-HT 浓度↑↑
        ↓
突触后受体持续受到刺激
        ↓
（2-4周后）受体下调适应 + 神经可塑性改变
        ↓
情绪稳定性改善
```

> ⚠️ 关键：SSRIs 不是立即起效的，需要 **2-6周** 才能产生抗抑郁效果，因为真正的改变是**受体敏感性的长期调适**和**海马神经新生**，而非简单的"提高血清素浓度"。

## 二、HPA 轴（下丘脑-垂体-肾上腺轴）

### 2.1 什么是 HPA 轴？

**HPA 轴**（Hypothalamic-Pituitary-Adrenal Axis）是人体最核心的**应激反应系统**，由三个层级的腺体串联构成：

```
大脑感知威胁
        ↓
【下丘脑（Hypothalamus）】
  分泌促肾上腺皮质激素释放激素（CRH）
        ↓
【垂体（Pituitary）】
  CRH 刺激垂体前叶分泌
  促肾上腺皮质激素（ACTH）
        ↓
【肾上腺皮质（Adrenal Cortex）】
  ACTH 刺激肾上腺皮质分泌
  糖皮质激素，主要是皮质醇（Cortisol）
        ↓
皮质醇进入血液，作用于全身
```

> 皮质醇是 HPA 轴的**最终效应分子**，几乎每个细胞都有皮质醇受体。

---

### 2.2 皮质醇的双重角色：急性保护 vs. 慢性损害

#### 急性应激（短期）：适应性保护

```
遭遇威胁（5分钟内）
        ↓
【交感神经系统（SAM轴）先行】
肾上腺髓质释放 肾上腺素 + 去甲肾上腺素
        ↓ 立即效应（秒级）
心跳加速 / 血糖升高 / 肌肉供血增加 / 痛觉暂时关闭

【HPA轴随后跟进】（分钟-小时）
皮质醇释放
        ↓
├── 进一步升高血糖（为肌肉供能）
├── 抑制免疫炎症反应（避免战斗中自我损耗）
├── 增强记忆巩固（记住威胁来源）
└── 暂时关闭"非必要"系统（消化、生殖、生长）
```

**急性皮质醇的总结**：让你活下来，之后关闭。

#### 慢性应激（长期）：系统性损害

```
长期持续压力 → 皮质醇长期高位
        ↓
┌─────────────────────────────────────┐
│ 脑区损害                              │
│ ├── 海马：神经元萎缩 → 记忆力↓、情绪整合↓  │
│ ├── 前额叶：树突收缩 → 执行功能↓          │
│ └── 杏仁核：树突增长 → 威胁感知过度敏感↑   │
│                                       │
│ 全身损害                              │
│ ├── 免疫系统：慢性低度炎症              │
│ ├── 心血管：血压持续偏高                │
│ ├── 代谢：胰岛素抵抗、腹部脂肪堆积       │
│ └── 肠道：肠道屏障受损、菌群失衡         │
└─────────────────────────────────────┘
```

> 💡 慢性压力为什么让人"变笨"、"变怂"：海马萎缩（记忆变差）+ 前额叶受损（判断力↓）+ 杏仁核过激（一点小事就恐惧）——这是神经层面的直接损伤，不是心理软弱。

---

### 2.3 负反馈调节与失调

正常的 HPA 轴有**自我刹车机制**：

```
皮质醇升高
        ↓
皮质醇作用于：
├── 海马上的糖皮质激素受体（GR/MR）
├── 下丘脑和垂体上的受体
        ↓
抑制 CRH 和 ACTH 的进一步分泌
        ↓
皮质醇水平回落（负反馈）
        ↓
系统复位
```

**HPA 轴失调的两种模式**：

| 失调模式           | 皮质醇特征               | 关联障碍                     |
| -------------- | ------------------- | ------------------------ |
| **高皮质醇/负反馈失灵** | 基础皮质醇持续偏高；早晨皮质醇峰值过高 | 抑郁症（尤其忧郁型）、慢性焦虑、库欣综合征    |
| **低皮质醇/过度抑制**  | 基础皮质醇偏低；对应激的皮质醇反应减弱 | PTSD（尤其慢性期）、纤维肌痛、慢性疲劳综合征 |

> 这解释了一个反直觉的事实：**PTSD 患者的皮质醇往往偏低**（不是偏高）——长期的系统过激后，HPA 轴被"耗尽"并过度抑制，系统进入低反应模式。

---

### 2.4 HPA 轴与血清素的交叉调控

这两个系统不是独立的，它们**相互调节**：

```
血清素 ──→ 激活 5-HT1A 受体 ──→ 抑制 HPA 轴过度激活
                                （血清素是 HPA 的刹车之一）

皮质醇 ──→ 长期高水平时 ──→ 下调中缝核 5-HT1A 受体
                                （皮质醇损害血清素系统）
        ↓
形成恶性循环：
慢性压力 → 皮质醇↑ → 5-HT1A↓ → 血清素调节失效
        → 杏仁核阈值↓ → 更多威胁感知 → 更多皮质醇释放 → ···
```

**抑郁症的双轴假说**：
- 传统：血清素不足假说（Monoamine Hypothesis）
- 现代：慢性 HPA 轴激活 + 血清素系统受损 + 神经炎症（三者共同作用）

---

### 2.5 HPA 轴与人格障碍

| 障碍 | HPA 轴特征 |
|-----|-----------|
| **BPD** | 对人际应激刺激的皮质醇反应幅度异常大；早期创伤导致 HPA 轴永久性调定点上移 |
| **CPTSD** | 慢性 PTSD 模式：基础皮质醇偏低、日节律紊乱 |
| **ADHD** | 部分研究显示 HPA 轴调节节律异常（与情绪失调有关） |
| **抑郁症** | 忧郁型：皮质醇持续高；非典型：皮质醇正常或低 |

## 三、SAM 轴（交感-肾上腺髓质轴）

### 3.1 什么是 SAM 轴？

**SAM 轴**（Sympatho-Adrenomedullary Axis）是人体的**快速应激反应系统**，与 HPA 轴（慢速）构成应激反应的"双引擎"。

> 如果 HPA 轴是"分钟-小时"级别的慢速持久战系统，SAM 轴就是"秒级"的闪电战系统。

```
大脑感知威胁
        ↓
【下丘脑（Hypothalamus）】
        ↓
【交感神经系统（Sympathetic Nervous System）】
        ↓
【肾上腺髓质（Adrenal Medulla）】
        ↓ 释放
肾上腺素（Adrenaline / Epinephrine, E）
去甲肾上腺素（Norepinephrine, NE）
        ↓ 立即效应（秒级）
```

---

### 3.2 SAM 轴的完整激活链

```
感知威胁（杏仁核中央核 CeA 触发）
        ↓
下丘脑室旁核（PVN）
        ↓
脊髓中间外侧柱（交感神经节前神经元）
        ↓
        ├────────────────────────────┐
        ↓                            ↓
肾上腺髓质                     交感神经末梢
（释放肾上腺素E入血液）          （释放NE到靶器官）
        ↓                            ↓
┌───────────────────────────────────────────────┐
│ 立即全身效应（秒级）                              │
│                                               │
│ ❤ 心脏：心率↑、心肌收缩力↑、心输出量↑             │
│ 🫁 肺：支气管扩张 → 氧摄入↑                      │
│ 💪 骨骼肌：血流量↑（可达平时的10倍）、糖原分解↑     │
│ 🧠 脑：警觉↑、注意力聚焦、短期记忆增强             │
│ 🩸 血管：皮肤/内脏血管收缩（脸色苍白）             │
│      肌肉/心脏血管扩张                            │
│ 🍬 代谢：血糖↑、脂肪分解↑（供能）                  │
│ 👁 瞳孔：散大（进光量↑，视野↑）                    │
│ ❌ 暂停：消化、排尿、性功能、免疫                   │
└───────────────────────────────────────────────┘
```

> 经典的"战斗或逃跑"（Fight-or-Flight）反应，全部在 SAM 轴的控制下。

---

### 3.3 SAM 轴 vs HPA 轴：两条应激通路的对比

| 维度       | SAM 轴           | HPA 轴                |
| -------- | --------------- | -------------------- |
| **速度**   | 秒级（即时反应）        | 分钟-小时级（延迟反应）         |
| **效应分子** | 肾上腺素 + 去甲肾上腺素   | 皮质醇                  |
| **作用方式** | 通过神经→血液直接释放     | 三级激素级联（CRH→ACTH→皮质醇） |
| **持续时间** | 短（秒-分钟）         | 长（小时-天）              |
| **代谢方向** | 糖原分解（即时供能）      | 糖异生（持续供能）+免疫抑制       |
| **关闭机制** | 交感神经活性下降 → 自然停止 | 需要皮质醇负反馈回路           |
| **进化功能** | 应对眼前威胁          | 应对持续压力、免疫调控、记忆巩固     |

**两者的时间轴关系**：

```
遭遇威胁
│
│  0秒          SAM轴激活：肾上腺素瞬间释放
│  │           心跳↑↑ 血糖↑↑ 肌肉充血↑↑
│  │
│  2-3分钟      HPA轴启动：CRH释放
│  │           ↓
│  5-10分钟     ACTH释放
│  │           ↓
│  15-30分钟    皮质醇释放：进一步升高血糖
│  │           抑制免疫/消化
│  │
│  数小时       皮质醇达峰值 → 负反馈 → 恢复
│
└── 恢复副交感神经主导（"休息与消化"）
```

### 3.4 SAM 轴的调控神经递质

SAM 轴的核心输出是**肾上腺素（E）**和**去甲肾上腺素（NE）**，其合成与调控涉及以下系统：

#### 肾上腺素 / NE 的合成路径

```
酪氨酸（Tyrosine）
    ↓ 酪氨酸羟化酶（TH）← 限速步骤
L-DOPA
    ↓ DOPA脱羧酶
多巴胺（DA）
    ↓ 多巴胺β-羟化酶（DBH）
去甲肾上腺素（NE）
    ↓ 苯乙醇胺N-甲基转移酶（PNMT）← 仅在肾上腺髓质
肾上腺素（E）
```

> ⚠️ 外周的 NE（来自交感神经末梢/肾上腺髓质）**不能穿越血脑屏障**，与大脑中的 NE 是两个独立的池。外周 NE 负责身体反应，中枢 NE（蓝斑核）负责警觉/注意。

#### 受体系统

| 受体 | 分布 | 效应 | 药物靶点 |
|-----|------|------|---------|
| **α1** | 血管平滑肌、瞳孔 | 血管收缩、瞳孔散大 | 去氧肾上腺素（升压） |
| **α2** | 突触前膜（自受体）、脑干 | 负反馈抑制NE释放 | 可乐定、胍法辛（ADHD药） |
| **β1** | 心脏 | 心率↑、心肌收缩力↑ | **普萘洛尔**（阻断）→ 抗焦虑、削弱恐惧记忆 |
| **β2** | 支气管、骨骼肌血管 | 支气管扩张、血管舒张 | 沙丁胺醇（哮喘药） |
| **β3** | 脂肪组织 | 脂肪分解 | 研究中 |

> 💊 **普萘洛尔（Propranolol）**是β受体阻断剂，在焦虑/PTSD中的特殊地位：阻断β1受体 → 心跳不加速 → 身体"战斗信号"减弱 → 杏仁核接收到的反馈性威胁信号减少。更重要的是，在提取恐惧记忆后给药，可以**削弱恐惧记忆的再巩固**——这是PTSD记忆干预的前沿方向。

---

### 3.5 SAM 轴的副交感"刹车"：迷走神经

SAM 轴激活后，需要**副交感神经系统**来关闭它——核心是**迷走神经（Vagus Nerve）**：

```
SAM轴激活（交感主导）
        ↓ 威胁解除
迷走神经激活（副交感主导）
        ↓
┌────────────────────────────────┐
│ 乙酰胆碱（ACh）释放              │
│ ├── 心率↓（迷走神经直接抑制窦房结）│
│ ├── 支气管收缩                   │
│ ├── 消化功能恢复                 │
│ ├── 皮质醇分泌↓                 │
│ └── 炎症因子↓（胆碱能抗炎通路）   │
└────────────────────────────────┘
```

**迷走神经张力（Vagal Tone）**：
- 高迷走张力 → 副交感调节能力强 → 情绪恢复快、应激后能快速"刹车"
- 低迷走张力 → 交感难以关闭 → 持续焦虑、心率变异性（HRV）低、情绪失调

> 这就是为什么**HRV（心率变异性）**被用作情绪调节能力的生物标志物：HRV高 = 迷走张力好 = 情绪弹性强。

---

### 3.6 SAM 轴与各障碍的关系

| 障碍 | SAM 轴特征 |
|-----|-----------|
| **惊恐障碍** | SAM 轴过度敏感 → 微小触发即引发肾上腺素风暴 → 濒死感 |
| **PTSD** | 急性期：SAM 轴过度激活；慢性期：SAM 轴反应钝化（与HPA轴同步耗竭） |
| **BPD** | 对人际应激的 SAM 反应幅度异常大 → 情绪爆发时伴随强烈身体反应 |
| **焦虑障碍** | 基线交感神经活性偏高 → 静息心率↑、HRV↓ |
| **抑郁症** | 交感-副交感平衡偏向交感 → HRV降低是抑郁症的独立预测因子 |
| **ADHD** | 蓝斑核-NE系统紊乱 → SAM轴调节不稳定（部分ADHD表现为交感低反应性） |

## 四、杏仁核与恐惧回路

### 4.1 杏仁核的结构：不是一个点，是一个复合体

杏仁核（Amygdala，拉丁语"杏仁"）不是单一结构，而是由多个核团组成的**复合体**：

```
杏仁核复合体
├── 基底外侧核群（BLA）—— 最重要
│   ├── 外侧核（LA）：恐惧记忆的输入门户
│   ├── 基底核（BA）：情绪-行为整合
│   └── 副基底核
│
├── 中央核（CeA）—— 恐惧的"输出站"
│   ├── 中央内侧核 → 投射到下丘脑（自主神经反应）
│   └── 中央外侧核 → 投射到脑干（行为反应）
│
└── 皮质内侧核群
    └── 嗅觉信号、社会行为（费洛蒙相关）
```

---

### 4.2 恐惧的完整神经回路

Joseph LeDoux 的经典研究揭示了**两条并行的恐惧通路**：

```
威胁刺激（如响声 + 疼痛）
            ↓
        丘脑（Thalamus）
        /            \
【低路 Low Road】    【高路 High Road】
（速度：~12ms）      （速度：~300ms）
        ↓                    ↓
    杏仁核外侧核（LA）    皮层感觉区（精细分析）
        ↓                    ↓
    立即恐惧反应          精确评估 ──→ 杏仁核
    （冻结/逃跑）         （"真的危险吗？"）
```

**低路（Thalamo-Amygdala）**：
- 丘脑 → 直接到杏仁核（绕过皮层）
- 速度极快，12毫秒
- 粗糙但快速的危险检测
- "先射击，后提问"策略
- 这是为什么我们对蛇形物体会**本能地跳开**——皮层还没来得及分析

**高路（Thalamo-Cortical-Amygdala）**：
- 丘脑 → 感觉皮层 → 杏仁核
- 速度较慢（数百毫秒）
- 精细分析："这只是条绳子，不是蛇"
- 可以**修正**低路的初始反应

---

### 4.3 杏仁核的完整输入-输出图谱

**输入（威胁信息的来源）**：

```
视觉皮层 ──────────────────────→ ┐
听觉皮层 ──────────────────────→ │
嗅觉球 ────────────────────────→ │ 杏仁核
海马（情境信息）────────────────→ │ 外侧核
前额叶（自上而下的认知调控）────→ │ （LA）
丘脑（快速预处理信号）──────────→ ┘
```

**输出（恐惧反应的执行）**：

```
杏仁核中央核（CeA）
            │
    ┌───────┼──────────┬──────────────┐
    ↓       ↓          ↓              ↓
下丘脑    脑干       蓝斑核          中缝核
  │      （PAG）     （NE↑）         （5-HT↓）
  ↓        │          ↓              ↓
HPA轴    冻结/       警觉↑         抑制减少→
激活    逃跑/战斗    心跳↑          情绪不稳定
(皮质醇)  反应       血压↑
```

> 这张图解释了恐惧为什么同时有：**身体反应**（心跳、战栗）、**行为反应**（冻结或逃跑）、**荷尔蒙反应**（皮质醇）、**认知反应**（注意力聚焦）——它们都是同一个杏仁核激活的并行输出。

---

### 4.4 调节杏仁核的神经递质与激素

这是核心问题：有哪些物质可以**降低或升高**杏仁核的反应性？

#### 🔴 激活杏仁核（升高恐惧/威胁反应）的物质

| 物质 | 来源 | 机制 |
|-----|------|------|
| **CRH（促肾上腺皮质激素释放激素）** | 下丘脑、杏仁核本身 | 直接激活杏仁核内的 CRH 受体，放大恐惧反应 |
| **去甲肾上腺素（NE）** | 蓝斑核 | 急性应激时 NE↑ → 杏仁核激活↑ → 恐惧记忆增强（"当时太刺激了，所以记得很深"） |
| **谷氨酸（Glutamate）** | 兴奋性突触传递 | 外侧核（LA）的 NMDA 受体介导恐惧记忆的形成（LTP机制） |
| **皮质醇（慢性高水平）** | 肾上腺皮质 | 长期高皮质醇 → 杏仁核树突增长 → 结构性过度激活 |
| **神经肽Y（NPY）对立面** | 应激中 NPY 减少 → 恐惧增加 | 详见下方绿色部分 |

#### 🟢 抑制杏仁核（降低恐惧/产生安全感）的物质

| 物质                                | 来源                | 机制                                                       |
| --------------------------------- | ----------------- | -------------------------------------------------------- |
| **血清素（5-HT）**                     | 中缝核               | 通过 5-HT1A 受体抑制杏仁核过度激活；通过 5-HT2C 调节焦虑阈值                   |
| **GABA（γ-氨基丁酸）**                  | 杏仁核内部中间神经元        | 杏仁核内的 GABA 能中间神经元是**内置的抑制系统**；苯二氮卓类（如地西泮）通过增强 GABA 快速抗焦虑 |
| **催产素（Oxytocin）**                 | 下丘脑（旁室核、视上核）→垂体释放 | 直接抑制杏仁核激活；社交接触/信任感 → 催产素↑ → 恐惧↓（这是"安慰"的神经机制）             |
| **内源性大麻素（Endocannabinoids, eCB）** | 突触后神经元            | 逆行抑制谷氨酸释放 → 减少恐惧记忆的巩固；CB1受体是焦虑调节的重要靶点                    |
| **神经肽Y（NPY）**                     | 多处，尤其杏仁核内         | 强效的抗焦虑/抗应激肽；在PTSD患者中 NPY 水平偏低                            |
| **前额叶皮层（vmPFC/PFC）**              | 自上而下的神经控制         | 前额叶通过直接抑制性投射到杏仁核中央核（"认知重评"的神经基础）                         |
| **多巴胺（DA）**                       | VTA → 杏仁核         | 适度 DA → 奖励信号压过威胁信号；D1 受体调节情绪记忆                           |

---

### 4.5 恐惧消退（Extinction）——不是遗忘，是重写

**恐惧消退**是暴露疗法的神经基础，但它的机制不是删除恐惧记忆，而是**在原有记忆上叠加新的安全记忆**：

```
原始恐惧记忆：
[声音] → [LA中的突触连接增强] → 恐惧反应

消退学习（多次暴露于声音但无危险）：
→ vmPFC 向 LA 发送"这是安全的"信号
→ LA 内形成新的抑制性突触连接
→ 新的安全记忆压制旧的恐惧记忆

但原始恐惧记忆仍然存在！
→ 压力、疲劳、回到原始场景 → 恐惧记忆恢复（复发）
```

**PTSD 的问题**：
- vmPFC 对杏仁核的抑制回路受损
- 消退学习受阻（"无论怎么努力，焦虑就是消不掉"）
- 海马损伤 → 无法提供"那是过去，现在安全"的时间背景

**这也是为什么认知疗法对 PTSD 效果有限**——消退需要的不只是语言层面的理解，还需要 vmPFC 对杏仁核神经回路层面的真实抑制。

---

### 4.6 特殊情况：杏仁核完全损伤的案例

**S.M. 案例**（Urbach-Wiethe 病导致双侧杏仁核钙化）：
- 无法识别恐惧表情（但能识别其他情绪）
- 接近危险物体（毒蛇、蜘蛛）无恐惧感
- 遭遇持刀抢劫时没有恐惧感（只有事后的好奇）
- 但：**吸入高CO₂气体**仍能引发恐慌发作（内感受性恐惧通路是独立的，走内侧下丘脑，不经杏仁核）

这证明了：杏仁核是**外部环境威胁**的恐惧核心，但不是所有恐惧的唯一核心。

## 五、三个系统的整合：情绪失调的完整图景

```
威胁感知
    ↓
杏仁核激活（速度：毫秒级）
    │
    ├──→ 中央核 → 下丘脑 → 两条并行通路：
    │                    ├── SAM轴 → 肾上腺素/NE释放（秒级·闪电战）
    │                    └── HPA轴 → 皮质醇释放（分钟-小时·持久战）
    │
    ├──→ 中缝核（反馈性5-HT释放）→ 尝试抑制过度激活
    │
    └──→ 蓝斑核（NE释放）→ 警觉↑、记忆巩固↑

前额叶皮层（PFC）
    └──→ 自上而下评估："真的危险吗？"
         如果安全：vmPFC 抑制杏仁核
         如果危险：PFC 调用记忆，精细化应对策略

海马
    └──→ 提供情境信息："上次在这个地方发生了什么"

迷走神经（副交感）
    └──→ 威胁解除后激活 → 心率↓、消化恢复、皮质醇↓

【健康状态】：四个系统平衡——快速恐惧响应 + 及时的SAM激活与关闭 + HPA轴适度调节 + 5-HT抑制 + PFC理性评估

【病理状态】：
PTSD: 杏仁核过激 + vmPFC调控失败 + SAM轴慢性耗竭 + HPA轴耗竭 + 海马损伤
BPD:  杏仁核过激 + PFC调控结构性不足 + SAM轴反应幅度异常 + HPA轴慢性高激活
抑郁: 5-HT减弱 + HPA轴负反馈失灵 + HRV↓（迷走张力低）+ 杏仁核阈值降低
焦虑: 杏仁核基础激活↑ + SAM轴基线交感偏高 + GABA抑制不足 + 5-HT调节↓
```

## 六、临床应用：为什么不同障碍用不同药物

| 障碍 | 主要神经靶点 | 一线用药 | 机制 |
|-----|------------|---------|------|
| **抑郁症** | 5-HT + HPA轴 + 海马神经新生 | SSRIs / SNRIs | 增加突触间 5-HT；促进海马 BDNF |
| **焦虑/PTSD** | 杏仁核过激 + GABA不足 | SSRIs（长期）/ 苯二氮卓（短期） | 5-HT调节杏仁核；GABA直接抑制杏仁核 |
| **急性恐惧/惊恐发作** | 杏仁核 + SAM轴（NE/肾上腺素） | 普萘洛尔（β受体阻断）/ 苯二氮卓 | 阻断β1→心率↓→SAM反馈信号↓；增强GABA |
| **慢性应激/PTSD记忆再巩固** | 恐惧记忆回路 | 普萘洛尔（提取后给药）| 阻断NE→削弱恐惧记忆再巩固 |
| **社交焦虑** | 杏仁核对社交刺激的过度激活 | SSRIs / 苯二氮卓 | 5-HT升高杏仁核阈值 |
| **OCD** | 眶额皮层-纹状体5-HT回路 | 高剂量 SSRIs / 氯米帕明 | 5-HT回路正常化 |
| **慢性疼痛/纤维肌痛** | HPA轴低皮质醇 + SAM轴失调 | SNRIs（度洛西汀）| NE↑ → 下行痛觉抑制通路恢复 |
