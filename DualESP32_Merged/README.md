# 已废弃：双 ESP32 合并工程

> 本目录是上一轮误解用户需求时生成的双 ESP32 版本，不适用于当前“一颗 ESP32”的设计，请勿编译或烧录。

本目录把原 IoT 固件和 MPPT 固件整理为一个交付工程，但保留两个独立的 Arduino sketch。降压主控板使用两颗 ESP32，因此必须分别编译和烧录，不能把两个 `setup()`/`loop()` 合并到同一个芯片固件中。

## 工程目录

- `IoT_ESP32/`：原 `loT\loT` 固件，设备 ID `esp32-001`
- `MPPT_ESP32/`：原 `ESP32_MPPT` 固件，设备 ID `mppt-001`

## ESP32 引脚映射

### IoT ESP32

| 功能 | GPIO |
| --- | ---: |
| 雨量模拟输入 | 39 |
| 雨量数字输入 | 19 |
| DHT11 | 26 |
| MOSFET | 2 |
| INA226 I2C | SDA/SCL，总线地址 0x40 |
| UTC NTC 模拟输入 | 34 |
| 加热片正/负控制 | 17 / 16 |
| 摄像头电源 | 5 |
| 电机正转/反转 | 12 / 13 |
| 风扇正/负控制 | 15 / 14 |

### MPPT ESP32

| 功能 | GPIO |
| --- | ---: |
| 回流 MOSFET | 27 |
| 降压 PWM | 33 |
| 降压使能 | 32 |
| 状态 LED | 2 |
| 风扇 | 16 |
| INA226 输入 ALERT | 34 |
| INA226 输出 ALERT | 35 |
| 温度传感器模拟输入 | 39 |
| INA226 I2C | SDA/SCL，地址 0x40 / 0x41 |

两张表中的同号 GPIO 属于不同 ESP32，不构成冲突。原理图需要确认每个网络分别连接到对应的 U33/第二颗 ESP32，而不是把两颗芯片的同名网络短接。

## 通信

两个固件继续使用独立 MQTT 身份和主题：

- `devices/esp32-001/...`
- `devices/mppt-001/...`

本次合并没有改动 MQTT 凭据、业务逻辑或 PCB 文件。烧录前应在本地配置文件中更换已经暴露过的 Wi-Fi/MQTT 凭据。
