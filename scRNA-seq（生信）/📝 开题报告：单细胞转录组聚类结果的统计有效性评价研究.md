## 一、选题背景与意义

### 1.1 研究背景

scRNA-seq 已经成为解析组织异质性、发现新细胞类型/状态的标准工具，Seurat、Scanpy 等框架把"质控 → 归一化 → 特征选择 → 降维 → 距离计算 → 无监督聚类"固化成了一条几乎人人默认照搬的标准流程（参见 [[🧬 scRNA-seq 单细胞测序分析流程 — 完整学习笔记]] 流程总览）。但在逐张图深入追问之后可以发现，这条流程里几乎每一步都建立在**未被充分检验的统计假设**之上：

- **归一化**：管家基因"表达恒定"的假设并不成立（GAPDH 在缺氧/肿瘤下变化、ACTB 在迁移细胞中差异数倍），CPM 又会被少数高表达基因系统性"污染"分母（详见 [[📏 图2：归一化 Normalization]]）；
- **特征选择**：负二项分布拟合出的过离散参数 α，把"细胞间真实生物学差异"和"超出泊松预期的额外技术噪音"**混在一起、无法区分**（详见 [[🔬 图3：特征选择 Feature Selection]]）；
- **降维**：前 10–50 个主成分的选择目前主要依赖碎石图这类"目测经验法则"，缺乏统一、可复现的标准（详见 [[📉 图4+6：降维 & 无监督聚类]]）；
- **聚类**：这是笔记里质疑最尖锐的一点——**层次聚类无论数据里有没有真实的群体结构，永远都会输出一棵树**。热图上的蓝色块究竟是真实的细胞亚型，还是算法"强制把连续分布切割成离散群体"的视觉假象，笔记明确指出"如何验证蓝色块是真实的"是悬而未决的问题（详见 [[🔥 图5：细胞间距离热图 Cell-cell Distances]]）。

这不是笔记作者一个人的困惑。近年来生物信息学界把这个问题正式化为**"过度聚类"（over-clustering）与"双重挖掘"（double dipping）问题**：用同一份数据先聚类、再对聚出来的簇做差异表达检验来"证明"它们是不同细胞类型，本质上是循环论证——即使数据本身没有任何真实结构，聚类算法也必然能切出若干个簇，随后的差异表达检验几乎必然显著，从而制造出假阳性的"新细胞亚型"。这一问题已经在多篇方法学论文中被系统讨论（见下文文献综述）。

### 1.2 研究意义

- **方法学意义**：为 scRNA-seq 下游最关键、也是最容易被滥用的一步——"这是不是一个真实的细胞亚群"——提供可操作、可复现的统计判断依据，而不是依赖经验和图形直觉。
- **实践意义**：随着单细胞图谱类论文数量爆炸式增长，"发现新细胞亚型/新状态"已经成为高频的论文卖点，一旦聚类有效性把关不严，会直接污染下游的 marker 基因发现、细胞类型注释乃至公共数据库（如 CellMarker、Human Cell Atlas）的准确性。建立一套轻量、可推广的有效性检验流程，对课题组和整个领域都有直接的实用价值。
- **个人训练意义**：作为本科生首个独立课题，选择纯计算方向（无需湿实验、无需课题组分配特定数据集）既能充分复用已经打下的统计基础（负二项分布、PCA、聚类的完整数学推导已经在笔记中完成），又给了一个边界清晰、可以在一学年内独立完成的研究范围。

## 二、国内外研究现状

聚类结果的统计有效性问题近五年在 scRNA-seq 方法学界快速升温，代表性工作大致可分三条路线：

**1）"聚类是否存在" —— 事前显著性检验**

- **SigClust**（Liu, Hayes, Nobel & Marron, 2008）最早提出对高维数据的二分聚类做统计显著性检验，但基于高斯假设，不适用于稀疏计数的单细胞数据。
- **scSHC**（Grabski & Irizarry 等，"Significance Analysis for Clustering with Single-Cell RNA-sequencing Data"，2022–2023，[GitHub: igrabski/sc-SHC](https://github.com/igrabski/sc-SHC)）把 SigClust 的思路扩展到负二项/计数模型：对层次聚类树上每一次二分，拟合一个"无差异"的零假设模型、模拟出零分布下的平均轮廓系数，与观测值比较来决定这一次分裂是否显著——这与笔记 [[🔥 图5：细胞间距离热图 Cell-cell Distances]] 里提出的"轮廓系数验证蓝色块真实性"的思路高度一致，可以视为对笔记质疑的一个"标准答案"。
- **CHOIR**（"CHOIR improves significance-based detection of cell types and states from single-cell data"，2024，[PubMed 38328105](https://pubmed.ncbi.nlm.nih.gov/38328105/)）用随机森林分类器 + 置换检验，沿层次聚类树逐节点判断该分支是否代表统计上可区分的细胞群体，并在 100 个模拟数据集和 4 个真实多组学数据集上与 14 种现有聚类方法做了系统 benchmark。
- **Chung (2020)**，"Statistical significance of cluster membership for unsupervised evaluation of cell identities"（*Bioinformatics*）提出 jackstraw 检验：通过重采样构造"零样本"、重新聚类建立经验零分布，进而给出每个细胞真正属于其所在簇的后验概率（PIP），而不只是一个簇级别的 p 值。

**2）"聚类之后能不能再检验" —— 选择性推断（selective inference）**

- **Gao, Bien & Witten**，"Selective Inference for Hierarchical Clustering"（*JASA*, 2022）首次把选择性推断框架系统地引入层次聚类，通过条件化"聚类事件本身"来推导有效的检验统计量和 p 值，直接回应了"用同一份数据先聚类、再检验差异是否是循环论证"这一问题。
- **Neufeld, Gao, Popp, Battle & Witten**，"Inference after latent variable estimation for single-cell RNA sequencing data"（*Biostatistics*, 2022）把这一思路进一步延伸到 scRNA-seq 常见的"先降维/聚类、再做差异表达"的完整流程。
- **ClusterDE**（"a post-clustering differential expression method robust to false-positive inflation caused by double dipping"，*Genome Biology*, 2023，[PMC10418557](https://pmc.ncbi.nlm.nih.gov/articles/PMC10418557/)）用生成对照的"合成零数据集"来估计并校正双重挖掘带来的假阳性膨胀，是目前较新、工程上也比较容易复现的方案。

**3）经典基线方法**

- **Gap Statistic**（Tibshirani, Walther & Hastie, 2001）：将真实数据的类内离散度与均匀分布零假设下的期望离散度做比较，是笔记中提到的"如何验证真实性"的经典工具之一。
- **SC3**（Kiselev et al., 2017, *Nature Methods*）：基于共识矩阵（consensus clustering）的多参数聚类，通过对多次随机化聚类结果取共识来提高稳定性，是笔记学习总结中提到的"现代分析主流实践"里常被对比的方法之一。
- **Splatter**（Zappia, Phipson & Oshlack, 2017, *Genome Biology*）：目前最主流的 scRNA-seq 模拟数据生成工具，可以按需生成已知真实簇数目、簇间分离度、dropout 率的模拟数据集，是做"假阳性率/假阴性率"基准测试不可或缺的基础设施。

**现状小结**：目前的方法学论文几乎都是"提出一个新方法 + 与两三个旧基线比较"的自证模式，缺少一篇**独立第三方、覆盖面更广的横向系统评价**；同时几乎没有工作专门研究**上游预处理选择（归一化方法、HVG 方法、PC 数目）本身会不会系统性地影响下游"有多少个显著簇"这一判断结果**——这正是本课题试图填补的空白，也直接对应笔记里从归一化到聚类逐层追问、层层传递误差的思路。

## 三、研究目标与研究内容

### 3.1 核心科学问题

> 在没有金标准的情况下，如何客观判断 scRNA-seq 数据中被无监督聚类识别出的"细胞亚群"，究竟是真实的生物学结构，还是聚类算法对连续分布/纯噪音"强制离散化"所产生的伪结构？上游预处理参数的选择，是否会系统性地放大或掩盖这种伪结构？

### 3.2 具体研究内容

**内容一：模拟数据基准测试（假阳性/假阴性率评价）**

用 Splatter/scDesign2 生成四类场景的模拟数据：

1. Null 场景：单一细胞群体、无真实亚群（检验各方法的**假阳性率**，即"无中生有"切出簇的倾向）；
2. 已知 K 个真实簇、簇间分离度可调（近 / 远）；
3. 不同噪音水平（dropout 率、测序深度）；
4. **连续轨迹型数据**（无离散边界，模拟分化过程）——专门用来检验各方法是否会像笔记质疑的那样，把连续谱系错误地切成离散块。

候选评价方法：层次聚类 + 轮廓系数 / Gap Statistic / SigClust / jackstraw / scSHC / CHOIR / bootstrap 一致性（pvclust）/ SC3 共识聚类。

评价指标：假阳性率、假阴性率、与真实 K 的一致性（ARI、NMI）、计算耗时。

**内容二：上游预处理选择的敏感性分析**

固定聚类算法与有效性检验方法，分别改变：

- 归一化方法（CPM / DESeq2 中位数法 / Scran 池化 / SCTransform）；
- 特征选择方法（vst / scran trendVar-decomposeVar / deviance-based）；
- PC 数目选择方法（碎石图 / 置换检验 / 固定经验值）。

观察"被判定为显著的簇数目"如何随上游选择变化，回答**预处理流程本身是否会系统性地制造或掩盖细胞亚群**这一问题——这一部分直接呼应笔记 [[📏 图2：归一化 Normalization]] 里"CPM 受高表达基因影响""管家基因不稳定"的质疑，把它们从"课堂疑问"变成"可测量的下游后果"。

**内容三：真实数据验证与细胞周期案例研究**

选用带有金标准细胞类型标签的公开数据集（如经 FACS 分选验证的 PBMC 数据集），检验各方法能否正确恢复已知的细胞类型数目；并专门以**细胞周期**作为案例——细胞周期本身是连续、渐进的过程（见 [[生物学/细胞周期]]），但 Cyclin/CDK 相关基因的周期性表达常常在 PCA/聚类中被误判为独立的"细胞亚群"，是文献中公认的经典混淆因素。用这一案例具体检验：哪些有效性评价方法能够正确识别"这是一个连续过程而非离散亚型"，哪些方法会像层次聚类一样被误导。

## 四、研究方案与技术路线

```
文献调研 + 工具环境搭建（R: Seurat/scran/splatter/SigClust2/pvclust；
                          Python: Scanpy/scikit-learn；scSHC/CHOIR 官方实现）
        ↓
复现笔记中的教学流程作为基线（验证对 QC→归一化→特征选择→PCA→聚类全链条的掌握）
        ↓
模拟数据生成（Splatter：Null / 已知K / 连续轨迹 / 不同噪音水平）
        ↓
候选有效性方法横向 benchmark（假阳性率 / 假阴性率 / ARI / NMI / 耗时）
        ↓
上游预处理敏感性分析（归一化 × 特征选择 × PC数目 → 显著簇数目的变化）
        ↓
真实数据验证 + 细胞周期案例研究
        ↓
结果汇总 → 形成方法选择实践建议（checklist）→ 视情况封装为可复用脚本/小工具
```

- **数据来源**：全部为公开数据（10x Genomics 官方 PBMC 数据集、Zheng et al. 2017 FACS 分选数据、Tabula Muris 等）与模拟数据，不依赖课题组分配的特定数据集，因此技术路线与选题在没有具体研究对象的情况下依然完全可执行。
- **软件平台**：R / Python 开源生态，个人电脑或学校计算集群即可运行，无需湿实验。

## 五、创新点

1. **独立第三方、跨方法的系统横向比较**：现有文献大多是"提出新方法 + 与两三个基线比较"的自证模式，缺少覆盖 SigClust 系、选择性推断系、共识聚类系等多条技术路线的统一评价；
2. **首次把"预处理参数选择"和"聚类有效性判断"作为一个联动系统整体研究**，回答误差是否会从归一化、特征选择一路传递放大到最终的"细胞亚型数量"判断；
3. **用细胞周期这一已知的"连续过程 vs 离散亚型"真实案例，作为检验各统计方法能否正确处理"层次聚类强制离散化"问题的具体试金石**，把笔记中的理论质疑落到一个可复现的具体检验上。

## 六、可行性分析

- **技术可行性**：全流程基于开源工具与公开数据，不涉及湿实验、伦理审批或课题组专属数据，个人计算资源即可完成。
- **知识基础**：笔记体系已经完整覆盖了 QC、归一化（CPM/Scran 理论推导）、特征选择（泊松-Gamma 混合模型的完整数学推导）、PCA（正交性/维度诅咒）、聚类（层次聚类原理与局限）全链条的原理与统计假设，具备直接开展方法学比较研究所需的理论基础。
- **时间可行性**：模拟数据基准测试、敏感性分析、真实数据验证三部分内容彼此独立、可分阶段推进，适合本科生在一学年内分模块完成。

## 九、拓展方向（作为未来工作简要提及）

以下两个方向不作为本课题主体，但与笔记中的知识积累有直接关联，可作为课题的自然延伸或研究生阶段的候选方向：

- **生物学应用方向**：若课题组后续分配具体的疾病/组织/物种数据集，本课题建立的"聚类有效性评价流程"可以直接作为下游细胞亚型发现前的质控步骤，迁移成本很低。
- **交叉创新方向——印记基因的等位基因特异性表达分析**：结合 [[生物学/印记基因与亲代遗传战争]] 中亲代冲突理论的兴趣，未来可利用父母本基因组已知的 F1 杂交模型单细胞数据，检验印记基因在不同脑区/细胞类型中的等位基因偏好表达模式，计算验证 Badcock-Crespi 假说（皮层下 vs 皮层区域父系/母系印记基因表达强度的对立关系）。这一方向需要额外掌握等位基因特异性表达（ASE）分析方法（SNP calling、按等位基因分别计数、beta-binomial 建模），技术门槛更高，更适合作为研究生阶段课题。
