细胞周期是指持续分裂的真核细胞从一次分裂结束到下一次分裂结束的循环过程，主要分为间期与分裂期（M期）。典型的细胞周期耗时约24小时，通过严密的“检查点”机制确保生命遗传物质的精确复制与均分。 
1. 主要阶段划分

细胞周期按进程主要分为以下四个核心阶段：

- 间期（占90%以上时间）

- **G_1 期（生长与准备）**： 细胞大量合成RNA和蛋白质，体积增大，为DNA复制做准备。
- **S期（DNA合成）**： 核心阶段，细胞进行DNA复制，确保遗传物质完整加倍。
- **G_2 期（分裂准备）**： 细胞继续生长，并合成有丝分裂所需的特定蛋白质。 

- 分裂期（M 期）

- 核分裂： 经历前期、中期、后期和末期，复制后的染色体平均分配到两个子细胞中。
- 胞质分裂： 细胞膜内陷或形成细胞板，将细胞一分为二。

2. 关键调控机制

细胞周期的顺利推进依赖于精密的分子调控网络：

- 细胞周期蛋白（Cyclins） 与 细胞周期蛋白依赖性激酶（CDKs）：两者的结合构成了驱动细胞进入下一阶段的引擎。
- 检查点（Checkpoints）： 包括 $\text{G}_1/\text{S}$ 检查点、$\text{G}_2/\text{M}$ 检查点和中-后期检查点。若发现DNA损伤或纺锤体未正确组装，周期将在此暂停修复或触发凋亡。

3. 特殊状态与应用

- G_0 期： 部分细胞（如神经元、成熟心肌细胞）会暂时或永久退出细胞周期，进入休眠期。
- 癌症关联： 癌症的本质就是细胞周期调控失常，导致细胞无休止地分裂和增殖。
- 生物学检测： 临床和科研常利用流式细胞术进行 细胞周期分析 ，通过标记物定量评估细胞的增殖状态。

**Cyclin（细胞周期蛋白）是一类在真核生物细胞周期中起关键调控作用的蛋白质家族**。它们的浓度会随着细胞周期的不同阶段周期性地合成和降解，通过与**细胞周期蛋白依赖性激酶（Cyclin-dependent kinases）** 结合并激活后者，推动细胞顺利通过各个分裂阶段。

  - **Cyclin D**：在生长因子刺激下表达，促使细胞从生长准备期（G₁期）进入 DNA 复制期（S期）。
- **Cyclin E**：在 G₁ 期末期达到高峰，驱动细胞顺利通过 G₁/S 转换点，启动 DNA 复制。
- **Cyclin A**：在 S 期和 G₂ 期表达，主要负责促进 DNA 的合成与复制。
- **Cyclin B**：主导细胞分裂期（M期）的进程，当分裂完成后它会被迅速降解，促使细胞进入下一个周期。

**Checkpoints（细胞周期检查点）**和 **CDKs（细胞周期蛋白依赖性激酶）** 是细胞周期调控系统的核心组件，它们之间是**“刹车”与“发动机”**的关系。

CDK 驱动细胞周期向前推进（发动机），而 Checkpoints 则是质量监控系统（刹车）。当细胞检测到 DNA 损伤或复制错误时，Checkpoints 会通过**抑制 CDK 的活性**来暂停细胞周期，以便进行修复。

核心互动机制

Checkpoints 主要通过三种途径关闭 CDK 的“发动机”功能：

- **激活抑制蛋白 (CKIs)**：当 Checkpoint 检测到 DNA 损伤，会激活 p53 蛋白，进而表达 **p21 蛋白**。p21 是一种 CDK 抑制剂，它直接结合并锁死 CDK4/6 或 CDK2，使细胞停滞在 G₁ 或 S 期。
- **改变磷酸化状态**：Checkpoint 激酶（如 Chk1 和 Chk2）会失活 **Cdc25 磷酸酶**。Cdc25 原本负责移除 CDK 上的抑制性磷酸化标签（使其活化）。Cdc25 被抑制后，CDK（如 CDK1）将保持在被抑制的磷酸化状态，细胞无法进入 M 期。
- **降解 Cyclin**：某些 Checkpoint 信号会加速 Cyclin（CDK 的核心激活剂）的泛素化降解。失去 Cyclin 的 CDK 将彻底失去活性。
- 关键检查点中的具体体现

| 检查点名称 (Checkpoint)               | 监控内容             | 对 CDK 的直接影响                           |
| -------------------------------- | ---------------- | ------------------------------------- |
| **G₁/S 检查点 (Restriction Point)** | 细胞大小、营养、DNA 损伤   | **抑制 CDK4/6 和 CDK2**，阻止细胞启动 DNA 复制。   |
| **S 期检查点**                       | DNA 复制是否完整、是否有损伤 | **减缓 CDK2 活性**，降低 DNA 复制分叉的速度。        |
| **G₂/M 检查点**                     | DNA 是否复制完毕、是否有损伤 | **抑制 CDK1 (Cdc2)**，阻止细胞进入分裂期。         |
| **M 期检查点 (纺锤体组装检查点)**            | 染色体是否正确排列在赤道板    | **间接阻止 CDK1 的降解**，直到所有染色体对齐才允许细胞分裂结束。 |

**Checkpoints（细胞周期检查点）本身不是一种酶，而是一个“信号传导通路”或“质量控制机制”。**

它更像是一套复杂的自动化安检系统。这套系统由**多种不同的蛋白质**共同组成，其中确实包含了一些酶，但也包含了很多非酶蛋白。

Checkpoint 的三类核心组件

为了运行这套安检系统，细胞动用了三类不同功能的蛋白质：

- **传感器（Sensors）——不是酶**：
    - 负责日常巡逻，发现问题。
    - 例如 **MRN 复合体**，它像扫描仪一样直接结合到断裂的 DNA 两端。它们本身没有催化化学反应的酶活性，只负责“报案”。
- **传导器（Transducers）——是酶**：
    - 负责拉响警报，放大信号。
    - 这部分主要是**激酶（Kinases，一种催化磷酸基团转移的酶）**。
    - 例如 **ATM、ATR、Chk1、Chk2** 蛋白。当传感器报案后，这些激酶被激活，通过给下游蛋白“加磷酸基团”来快速传递停工信号。
- **效应器（Effectors）——有些是酶，有些不是**：
    - 负责执行停工命令（去抑制 CDK）。
    - **p53 蛋白**：转录因子（非酶），负责指挥细胞合成刹车片。
    - **p21 蛋白**：CDK 抑制剂（非酶），直接身体力行锁死 CDK。
    - **Cdc25 磷酸酶**：它是一种**酶**，但它的活性在检查点激活时会被**关闭**，从而让 CDK 保持熄火状态。
