## ❓ 课堂问答精炼

### Q1：归一化的原理和依据？

**核心问题：** 不同细胞测序深度不一致，需要消除技术偏差才能公平比较基因表达量。

**CPM公式：**

> CPM = （某基因reads / 该细胞total reads）× 1,000,000

**为什么乘以1,000,000？**

纯粹是单位换算，把0.00005这样的小数变成50这样的整数，方便读取和比较。没有任何生物学意义，只是**换了一个更顺手的单位**。

|平台|常用归一化基准|原因|
|---|---|---|
|bulk RNA-seq|CPM（一1,000,000）|每样本total reads在百万量级|
|10x Genomics|CP10K（一10,000）|单细胞测序深度浅，仈10,000为基准更合适|

---

### Q2：管家基因的科学名称和常见基因？

**正式名称：** 管家基因（Housekeeping Genes, HKGs）/ 内参基因（Reference Genes）

**核心假设：** 在所有细胞类型、所有状态下表达量保持恒定。

常见管家基因：

|基因名|功能|
|---|---|
|GAPDH|糖酵解关键酶|
|ACTB|细胞骨架（β-肌动蛋白）|
|B2M|MHC I类分子组成|
|HPRT1|嘴呤代谢|
|RPL13A|核糖体组成|

---

### Q3：管家基因表达不稳定的证据？

**管家基因并不恒定，这是一个理想化的粗略假设：**

- GAPDH：缺氧、肿瘤、神经元活动增强时表达变化

- ACTB：细胞迁移、肌肉细胞 vs 神经元表达量差异可达数倍

- B2M：免疫激活、炎症环境下显著上调

**本质原因：** “管家” = 细胞基础功能必需，不等于表达量恒定不变。

**现代解决方案：**

|层次|方法|优点|
|---|---|---|
|传统实验|用多个管家基因几何平均|比单个基因更稳定|
|现代scRNA-seq|Scran/SCTransform等统计方法|不依赖任何基因恒定假设|
|高精度定量|ERCC spike-in|浓度完全已知，最准确|

---

### Q4： Scran池化归一化的理论基础？

**核心问题：** 单细胞数据极度稀疏（dropout现象），单个基因的count不可靠，无法直接估计size factor。

**三大理论基础：**

**1. 大数定律**

```jsx
把多个细胞的counts直接相加（池化）
→ 随机波动被平均掉了
→ 稀疏性问题消失
→ 估计更准确
```

**2. 线性缩放假设**

```jsx
观测 counts = 真实表达量 × size factor
Y_ij = s_i × μ_ij
归一化 = 找到s_i后除掉它
```

**3. 非差异表达假设**

```jsx
任意两个细胞间，大多数基因不差异表达
→ size factor之比主要反映测序深度差异
→ 用中位数估计，对少数差异表达基因鲁棒
```

**数学工具：** 超定方程组 + 最小二乘法求解每个细胞的size factor。

### Q5：归一化方法综合比较

|方法|假设|可靠性|问题|
|---|---|---|---|
|CPM（总 reads归一化）|所有细胞 RNA总量相同|⭐⭐|受高表达基因影响|
|DESeq2中位数法|大多数基因不差异表达|⭐⭐⭐⭐|稀疏性数据表现不佳|
|Scran|大数定律+线性缩放+非差异表达|⭐⭐⭐⭐|计算较复杂|
|ERCC spike-in|外源安内RNA浓度已知|⭐⭐⭐⭐⭐|成本高，操作复杂|

**CPM受高表达基因影响的原因：**

一个基因异常高表达→师total reads被拉高→其他基因的CPM被系统性压低→产生虚假的“下调”信号。**分母被少数基因“污染”了**。
