
## 核心定义

分子马达是把**化学能（主要是 ATP 水解）直接转化为机械运动**的蛋白质。

**共同本质**：用持续的能量耗散给随机热运动施加方向，以局部对抗熵增。

---

## 一、总览：三大类 + 旋转马达

| 大类 | 代表 | 轨道/底物 | 运动方式 | 燃料 |
|---|---|---|---|---|
| **线性马达** | 肌球蛋白、驱动蛋白、动力蛋白 | 沿细胞骨架行走 | 平移 | ATP |
| **旋转马达** | ATP合酶、鞭毛马达 | 原地转 | 旋转 | 质子梯度 |
| **核酸马达** | 聚合酶、解旋酶、核糖体 | 沿DNA/RNA爬行 | 平移+加工 | ATP/NTP |

---

## 二、线性马达——沿细胞骨架行走

沿两种轨道运动：**肌动蛋白丝（actin）** 和 **微管（microtubule）**

### 1. 肌球蛋白（Myosin）——走在肌动蛋白上

**应用**：肌肉收缩

**原理："摆臂"模型（swinging lever arm）**

```
① 头部结合 ATP → 从肌动蛋白松开
② ATP 水解（→ADP+Pi）→ 头部"上膛"（蓄势）
③ 头部重新结合肌动蛋白
④ 释放 Pi → 触发"动力冲程（power stroke）"→ 头部摆动，拉动肌动蛋白
⑤ 释放 ADP → 回到起点
```

- 每水解 1 个 ATP → 走一步（约 5–10 nm）
- 肌肉中：无数肌球蛋白集体拉动肌动蛋白丝相对滑动 → 肌节缩短 → 收缩
- 家族庞大：Myosin I~XVIII，有的运货、有的管细胞形状

#### 动力冲程（Power Stroke）详解

动力冲程是马达把储存的化学能转化为定向力的核心步骤。

**肌球蛋白头部结构：**

```
        ┌─────────┐
        │  马达域  │  ← 结合肌动蛋白 + 结合/水解ATP的口袋
        │ (motor) │
        └────┬────┘
             │
        ┌────┴────┐
        │  杠杆臂  │  ← 像刚性"臂"，放大构象变化为位移
        │ (lever) │
        └────┬────┘
             │
         ……连接到肌球蛋白尾部（锚定处）
```

**完整循环四状态：**

```
状态① 空手（无ATP）
  → 头部紧紧抓住肌动蛋白（强结合）
  → 杠杆臂处于"冲程后"位置

         ↓ ATP结合

状态② 结合ATP
  → 对肌动蛋白亲和力急剧下降 → 头部松手
  → 头部自由漂浮

         ↓ ATP水解（→ADP + Pi，Pi暂留在口袋）

状态③ 水解后（ADP+Pi）← "上膛"状态 ⭐
  → 杠杆臂被扳回高能的"冲程前"角度（储存弹性势能）
  → 头部以弱亲和力重新结合肌动蛋白

         ↓ 释放 Pi ← 扣动扳机！

状态④ 动力冲程！⭐⭐
  → Pi离开 → 马达域深处构象重排 → 传导到杠杆臂
  → 杠杆臂从"冲程前"快速摆回"冲程后"（约转动35°）
  → 末端位移约 5–10 nm → 推动肌动蛋白

         ↓ ADP释放 → 回到状态①
```

杠杆臂在头部**离开肌动蛋白后**（状态②）复位到冲程前构象，靠的是：

**ATP结合引起的构象变化**，而不是纯被动的热运动：

- ATP结合马达域 → 核苷酸结合口袋关闭 → 触发马达域内部的构象重排 → **主动把杠杆臂扳回冲程前角度**；
- 这步是**ATP结合能（不是水解能）** 驱动的，发生在水解之前；
- 所以复位不是"等热运动把臂碰回去"，而是**ATP结合的构象变化强制把臂扳回**。

**但热运动也参与**：杠杆臂本身有柔性，复位后在冲程前角度附近**热振动**——并不是严格锁死在某个角度，而是在一个构象"盆地"里抖动。

- 肌动蛋白丝上结合位点**每隔约36 nm重复一次**（螺旋周期）；
- 但肌球蛋白步长只有5–10 nm；
- 头部扩散探索的范围**恰好覆盖下一个位点**——不是随机乱撞，而是几何上被约束在附近。

**能量转化本质：**

```
ATP水解自由能 → 储存在杠杆臂高能构象（状态③）
Pi释放 = 解开保险
杠杆臂从高能弛豫到低能 = 推动肌动蛋白
```

> 类比：ATP水解 = 压缩弹簧；Pi释放 = 松开锁扣；动力冲程 = 弹簧弹开做功

**与新冠S蛋白的共同逻辑：** 高能亚稳态构象 + 触发信号（Pi释放/蛋白酶剪切）→ 弹性能量定向释放。同一套设计哲学：**先把化学能储存在构象里，再精确触发释放**。

**力学参数：**

| 参数     | 数值          |
| ------ | ----------- |
| 产生的力   | 1–5 pN（皮牛顿） |
| 位移（步长） | 5–10 nm     |
| 机械效率   | ~25–50%     |
| 单次冲程时间 | ~毫秒量级       |

**与布朗棘轮的关系：** 动力冲程不是纯粹的"ATP推动"——上膛状态的头部仍靠热运动找到结合位点，构象弛豫也利用热力学过程。**真正的动力冲程 = ATP自由能 + 对热运动的整流**，布朗棘轮是其真实物理基础。

#### 失速力（Stall Force）与光镊实验

**失速力**：分子马达能对抗的最大外力，超过则停转甚至反转。

$$F_{\text{stall}} = \frac{\Delta G_{\text{ATP}}}{d}$$

- $\Delta G_{\text{ATP}}$：ATP水解自由能（细胞内约80–100 pN·nm/分子）
- $d$：步长（驱动蛋白 8 nm）
- 驱动蛋白理论值 ~10 pN，实测 ~7 pN，效率约 **70%**

**各马达失速力对比：**

| 马达            | 失速力            |
| ------------- | -------------- |
| 驱动蛋白（Kinesin） | ~7 pN          |
| 肌球蛋白 II       | ~1–5 pN/头      |
| 动力蛋白（Dynein）  | ~1–7 pN        |
| RNA 聚合酶       | ~20–25 pN      |
| **病毒DNA包装马达** | **~60 pN（最强）** |

---

**光镊实验（Optical Tweezers）：**

聚焦激光束形成势阱，捕捉微米级珠子，通过珠子对马达施加精确可调的反向力。

**两种实验构型（物理等价，相对运动相同）：**

```
构型A：马达固定于底面，轨道通过珠子被拉动
  光镊→珠子→肌动蛋白丝←→肌球蛋白（固定）
  对应场景：肌肉收缩（粗丝固定，拉动细丝）

构型B：轨道固定于底面，马达+珠子被光阱拉住
  光镊→珠子→马达→微管（固定）
  对应场景：囊泡运输（微管固定，马达+货物移动）
```

> 两者等价：马达只感受与轨道的**相对运动**，与谁是静止参考系无关。

**为何构型B更常用：** 微管易稳定吸附于玻璃、单马达隔离干净、力方向明确、珠子位置直接对应马达位置。

**双光镊实验（最高精度）：**

```
光镊1───珠1───肌动蛋白丝───珠2───光镊2
                    │
              肌球蛋白（固定）
```

肌动蛋白悬空绷紧，避免表面摩擦，位移分辨率 **<1 nm**，可直接测单次冲程。

---

**光镊是否影响马达正常运作：**

- 力施加在马达**尾部/货物端**，不直接作用于催化头部；
- 皮牛顿级的力远小于破坏蛋白构象所需（几十至几百 pN）；
- ATP化学能（~50 kJ/mol）远强于力学干扰；
- **真实存在的干扰**：激光微热（<1°C，可控）、几何约束（用长连接臂缓冲）；
- 接近失速力时力确实影响化学动力学——这**不是缺陷，而是被测量的现象本身**。

**接近失速力时热运动可见：**

```
正常工作（F << F_stall）：步进确定，热运动被淹没
接近失速（F ≈ F_stall）：势能景观近乎平坦
  → 热涨落显现 → 前进一步、退后一步……
  → 有偏的随机游走 ← 布朗棘轮的直接实验证据
超过失速力：马达被迫后退（ATP合酶即是被质子动势"强制超失速"而反转合成ATP）
```

### 2. 驱动蛋白（Kinesin）——走在微管上，朝"+"端

**应用**：细胞内运输（从细胞中心运向边缘）

**原理："手过手"行走（hand-over-hand）**

```
两个头部交替前进，像人走路：
① 前头结合微管 + 结合 ATP
② ATP 水解推动后头向前摆，越过前头成为新的前头
③ 交替循环 → 像迈步一样走在微管上
```

- 高度**持续性（processive）**：能连续走上百步不掉落
- 步长约 **8 nm**（正好是微管上一个结合位点的间距）
- **方向性**：朝微管"+"端（细胞外周）——运输线粒体、囊泡、神经递质

### 3. 动力蛋白（Dynein）——走在微管上，朝"−"端

**应用**：逆向运输 + 纤毛/鞭毛摆动

- 方向与驱动蛋白**相反**：朝微管"−"端（细胞中心）
- 神经元中：把废物、信号从轴突末端运回胞体
- 结构最大最复杂，基于 AAA+ 环的构象变化
- **纤毛/鞭毛**：相邻微管间的动力蛋白滑动 → 弯曲摆动 → 推动游动或清扫黏液

**驱动蛋白 vs 动力蛋白——双向运输系统**

```
微管：  (−)中心 ←————————→ (+)外周

驱动蛋白 ───────→ 朝(+)（出口运输）
动力蛋白 ←─────── 朝(−)（回收运输）
```

## 三、旋转马达——原地转圈

### 1. ATP 合酶（ATP synthase）——质子驱动的发电机

**原理**：H⁺ 顺质子动势流过 → 驱动 c 环旋转 → 中央 γ 轴转动 → 挤压催化头合成 ATP

- **可逆**：也能反向水解 ATP 来泵质子
- 接近 **100% 能量效率**，是已知最高效的旋转马达
- 与 Mitchell 质子动势直接相关（梯度→旋转→ATP）

### 2. 细菌鞭毛马达——质子驱动的螺旋桨

- **燃料**：质子动势（不是 ATP！）
- 转速：每秒上千转
- 能**正反转切换**：逆时针→直游，顺时针→翻滚换向（细菌趋化的基础）

## 四、核酸马达——沿 DNA/RNA 移动的加工机器

| 马达                | 功能              | 燃料            |
| ----------------- | --------------- | ------------- |
| **DNA/RNA 聚合酶**   | 沿模板链移动，合成新链     | NTP（本身是底物兼燃料） |
| **解旋酶（helicase）** | 解开 DNA/RNA 双链   | ATP           |
| **核糖体**           | 沿 mRNA 移动，翻译成蛋白 | GTP           |
| **病毒 DNA 包装马达**   | 把病毒 DNA 高压塞进衣壳  | ATP           |

- **病毒 DNA 包装马达**：已知力量最大的分子马达之一
- **核糖体**：本质是沿 mRNA 棘轮式前进的马达，每读一个密码子前进一步

## 五、所有分子马达的共同原理

### 1. 构象循环（conformational cycle）

- 燃料结合/水解 → 蛋白周期性构象变化 → 做功 → 复位
- 化学循环与机械循环**严格耦合**

### 2. 布朗棘轮（Brownian ratchet）——整流机制

> 不是"推"，而是"挡住退路"

- 分子尺度上，热运动（布朗运动）本身是随机的
- 马达利用 ATP 水解的不可逆性，**只允许某个方向的随机涨落被锁定**
- 把随机热运动**净整流为定向运动**

### 3. 方向性来自能量耗散

$$\text{定向运动} \Leftarrow \text{持续消耗 ATP} \Leftarrow \text{维持非平衡态}$$

- 平衡态不可能产生定向运动（违反热力学第二定律）
- 马达持续消耗 ATP、持续耗散能量 → 维持在**非平衡态** → 才能定向

## 六、与细胞能量体系的联系

```
分子马达 = 化学能→机械能的非平衡耗散装置
        │
        ├─ ATP合酶：梯度→旋转→ATP（Mitchell质子动势）
        │
        ├─ 布朗棘轮："被动随机→主动定向"的机制
        │   （与道金斯"主动性是涌现属性"同源）
        │
        └─ 持续耗能维持方向
            （与Na/K泵、生命是耗散结构同一原理）
```

**统一洞察**：从离子泵、ATP合酶到肌球蛋白，生命的所有"主动"机器，本质都是**用持续的能量耗散给随机热运动施加方向**——这是"生命对抗熵增"的分子级实现。
