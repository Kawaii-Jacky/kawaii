# SDS-PAGE聚丙烯酰胺凝胶电泳（SDS-Polyacrylamide Gel Electrophoresis）

> **根节点**：SDS-PAGE 如何消除蛋白质电荷与三维结构差异，仅凭分子量（Molecular Weight）实现高分辨率分离？
> **叙事逻辑**：电荷掩盖与还原变性 → 凝胶交联网络 → 浓缩胶与分离胶等速电泳（Isotachophoresis） → 染色与分子量测定
> **立场说明**：本文根据生物化学与分子生物学实验技术标准整理，详细剖析物理化学原理与实验细节。
> **来源标注**：来源：生物化学实验指南与蛋白质技术规范，2026

## 一、三元变性掩盖机制（物理化学基础）

天然蛋白质在水溶液中具有复杂的三维折叠构象（一、二、三、四级结构），且不同的氨基酸残基使其带有不同的净电荷。如果直接对天然蛋白进行电泳，决定其迁移速率的将是**净电荷、分子体积与三维形状**三者混合作用的结果，无法准确反映蛋白质的真实分子量。

SDS-PAGE 通过“SDS 结合 + 还原剂 + 加热”三元变性处理，彻底消除电荷与构象干扰：

> 📌 **十二烷基硫酸钠（Sodium Dodecyl Sulfate, SDS）**：一种阴离子表面活性剂，其较长的疏水碳链能插入蛋白质疏水核心并使其展开，带负电的硫酸根暴露在外。在本文中，SDS 按约 $1.4\text{ g SDS} : 1.0\text{ g 蛋白质}$ 的固定比例与蛋白质结合，使所有蛋白表面覆盖均匀的负电荷，掩盖原有的内源电荷，使质荷比（$e/m$）恒定为常数。

> 📌 **还原剂（Reducing Agent: DTT / 2-ME）**：二硫苏糖醇（DTT）或 2-岉基乙醇（2-Mercaptoethanol, 2-ME），用于还原切断蛋白质链内及链间的共价二硫键（$-\text{S}-\text{S}-$）。在本文中，它能消除亚基间的共价交联，确保多亚基复合物完全解离为单链多肽。

### 1.1 三元变性的化学作用

二硫苏糖醇（DTT）切断二硫键的化学反应方程式如下：

$$
\text{Protein-S-S-Protein} + 2 \text{ R-SH} \rightleftharpoons 2 \text{ Protein-SH} + \text{R-S-S-R}
$$

- **$\text{Protein-S-S-Protein}$**：含有共价二硫键折叠的天然蛋白质亚基；
- **$\text{R-SH}$**：还原态的 DTT 或 2-ME（提供活性岉基 $-\text{SH}$）；
- **$\text{Protein-SH}$**：被还原解离的单链多肽岉基残基；
- **$\text{R-S-S-R}$**：还原剂自身氧化形成的环状二硫化物（驱动反应向右进行）。

变性后，所有蛋白质分子均转化为表面带均匀负电荷、长度与其分子量成正比的**棒状（Rod-like）阴离子胶束**。

> 🔗 **横向关联**：本节“SDS 掩盖净电荷与构象”与 [[Western Blot 蛋白印迹法]] 中“变性电泳后蛋白转印”形成**上下游关系**——SDS-PAGE 提供的线性化带负电多肽链，是后一步在转移电场中向正极膜（PVDF）定向迁移的基础。

## 二、不连续缓冲体系与骤缩浓缩效应（分辨率核心）

SDS-PAGE 的最高分辨率来源于**不连续缓冲体系（Discontinuous Buffer System）**。该体系由 pH、凝胶浓度及离子组分不同的两层凝胶组成：**积层胶（Stacking Gel）** 与 **分离胶（Resolving / Separating Gel）**。

```
              ┌────────────────────────┐  ← 上样孔（Sample Well）
              │     样品区 (Sample)     │
              ├────────────────────────┤  ← 积层胶 (Stacking Gel, pH 6.8, 4% T)
              │ ⚡ Cl⁻ > 蛋白 > Gly⁻ ⚡  │  ← 离子挤压（等速电泳浓缩为窄带）
            ──┴────────────────────────┴──  ← 胶界线（GEL Interface）
              │                        │
              │   分离胶 (Resolving)   │  ← 分离胶 (Resolving Gel, pH 8.8, 12% T)
              │    (Gly⁻ 超越 蛋白)    │  ← 分子筛效应（按分子量大小按序分离）
              │                        │
              └────────────────────────┘  ← 正极 (+)
```

### 2.1 极性离子夹心与等速电泳（Isotachophoresis）

积层胶缓冲液的 pH 为 6.8，电泳缓冲液（Tris-Glycine）的 pH 为 8.3。在此体系中存在两种关键离子：

> 📌 **氯离子（$\text{Cl}^-$，快离子/前导离子）**：解离度极高，在电场中迁移速率最快。在本文中作为前端领跑电荷。

> 📌 **甘氨酸离子（$\text{Gly}^-$，慢离子/尾随离子）**：甘氨酸的等电点 $\text{pI} = 6.06$。在 pH 6.8 的积层胶中，极少部分解离为带负电的 $\text{NH}_2\text{-CH}_2\text{-COO}^-$，大部分为净电荷为零的兼性离子，因此其有效迁移速率极慢。

#### 浓缩过程机制：
1. 在积层胶（pH 6.8）中：$\text{Cl}^-$ 跑在最前，$\text{Gly}^-$ 滞后在最后。由于高电阻区形成，$\text{Cl}^-$ 与 $\text{Gly}^-$ 之间产生高电场强度区。
2. **蛋白质胶束的有效迁移速率介于 $\text{Cl}^-$ 与 $\text{Gly}^-$ 之间**（即 $\text{v}_{\text{Cl}^-} > \text{v}_{\text{Protein}} > \text{v}_{\text{Gly}^-}$）。
3. 所有蛋白质被高电场强挤压在 $\text{Cl}^-$ 界面与 $\text{Gly}^-$ 界面之间极其狭窄的极薄薄层（< 0.1 mm）中，实现**样品高度浓缩**。

#### 进入分离胶（pH 8.8）后的变化：
1. 分离胶 pH 升至 8.8，甘氨酸发生彻底电离，$\text{Gly}^-$ 负电荷剧增，迁移速率大幅提升，反超蛋白质（$\text{v}_{\text{Gly}^-} > \text{v}_{\text{Protein}}$）。
2. 蛋白质摆脱离子夹心区，在孔径更小的聚丙烯酰胺交联网格中，纯粹依据**分子筛效应（Molecular Sieve Effect）**按分子量大小展开分离。

## 三、凝胶网格筛分与分子量推算（孔径调控）

聚丙烯酰胺凝胶由**丙烯酰胺（Acr）**单体在交联剂**甲叉双丙烯酰胺（Bis）**作用下，由过硫酸铵（APS）和四甲基乙二胺（TEMED）催化聚合而成。

### 3.1 凝胶浓度 (%T) 与孔径匹配

凝胶总单体浓度 $T\%$ 决定了凝胶网格的平均孔径大小：

$$
\%T = \frac{a + b}{V} \times 100\%
$$

- **$a$**：丙烯酰胺单体质量（g）；
- **$b$**：甲叉双丙烯酰胺交联剂质量（g）；
- **$V$**：凝胶混合液总体积（mL）。

例如：配制 $V = 10\text{ mL}$ 的 $12\% T$ 分离胶，需要 $a + b = 1.2\text{ g}$ 的总单体。数值越大，网格孔径越密小。

| 分离胶浓度 (%T) | 最佳分离分子量范围 (kDa) | 典型应用场景 |
| :--- | :--- | :--- |
| **6%** | $60 - 300\text{ kDa}$ | 超大分子量蛋白（如 Myosin, Spectrin） |
| **8%** | $40 - 200\text{ kDa}$ | 高分子量结合蛋白 |
| **10%** | $20 - 120\text{ kDa}$ | 中等分子量蛋白通用分离 |
| **12%** | $14 - 100\text{ kDa}$ | 通用实验（如 $\beta$-actin 42 kDa） |
| **15%** | $10 - 45\text{ kDa}$ | 小分子量细胞因子、组蛋白 |

### 3.2 相对迁移率与分子量标准曲线

在凝胶电泳中，蛋白质的相对迁移率 $R_f$ 与其分子量对数 $\lg(\text{MW})$ 存在严格的反比线性关系：

$$
R_f = \frac{d_{\text{protein}}}{d_{\text{front}}} = -b \cdot \lg(\text{MW}) + K
$$

- **$R_f$ (Relative Mobility)**：蛋白质相对迁移率；
- **$d_{\text{protein}}$**：蛋白质条带自积层胶/分离胶交界处迁移的距离（cm）；
- **$d_{\text{front}}$**：指示剂前沿（如溴酚蓝 Bromophenol Blue）迁移的总距离（cm）；
- **$\text{MW}$**：蛋白质相对分子质量（Da / kDa）；
- **$b, K$**：特定凝胶浓度下的经验常数（斜率与截距）。

#### 数值推算示例：
若指示剂前沿迁移 $d_{\text{front}} = 10\text{ cm}$：
- 标准 Marker 蛋白 A ($100\text{ kDa}$) 迁移 $2.0\text{ cm}$ $\to R_f = 0.20$
- 标准 Marker 蛋白 B ($10\text{ kDa}$) 迁移 $8.0\text{ cm}$ $\to R_f = 0.80$
- 若待测蛋白 X 迁移 $5.0\text{ cm}$ $\to R_f = 0.50$
根据线性插值可极快拟合推算出蛋白 X 的分子量约处于 $31.6\text{ kDa}$ 附近。

## 四、形象化解构：安检排队与森林障碍赛跑

### 4.1 形象比喻：机场安检与丛林马拉松

* **形象比喻**：SDS-PAGE 就像**“安检口极速整队 + 丛林障碍赛跑”**。
  - **变性处理（SDS+DTT+加热）**：所有人（蛋白质）脱去厚外套（三维结构），穿上统一的带负电黄雨衣（SDS 结合），不管原本高矮胖瘦，每公斤体重都贴上相同数量的电荷标签。
  - **积层胶（浓缩）**：安检前所有人排在狭窄过道（$\text{Cl}^-$ 警卫在最前，$\text{Gly}^-$ 警卫在最后拉网），把所有参跑者强行挤压成一条极其整齐的横线。
  - **分离胶（筛分）**：安检门打开（进入 pH 8.8），所有人冲入一片密林（聚丙烯酰胺网格）。身材娇小的（小分子蛋白）轻松穿过树枝缝隙快速冲线；体型庞大的（大分子蛋白）不断被树枝挂住，留在后方。

## 五、多维度电泳分离技术对比

不同电泳技术在蛋白质化学研究中有各自不可替代的作用。

为什么要对比这三种电泳技术？因为研究者常混淆“分子量测定”、“天然复合物活性保留”与“极高分辨率异构体分离”的实验选型。

| 维度 | SDS-PAGE（变性胶） | Native-PAGE（天然胶） | 2D-PAGE（双向电泳） |
| :--- | :--- | :--- | :--- |
| **蛋白质状态** | 完全变性、还原为单链 | 保持天然折叠三维结构 | 第一向变性折叠，第二向 SDS 变性 |
| **分离依据** | 纯粹按**分子量大小** | 综合**净电荷、形状、分子量** | 第一向**等电点 (pI)** + 第二向**分子量** |
| **活性保留** | 否（酶活性丧失） | 是（可做胶内酶活性染色） | 否 |
| **分辨率** | 中等（能分清 1~5 kDa 差异）| 较低（多重因素重叠） | 极高（可分辨数千种总蛋白斑点）|
| **典型用途** | 纯度检测、分子量定性/定量 | 蛋白-蛋白复合物结合研究 | 差异蛋白质组学（Proteomics） |

最关键的差异点在哪里？**SDS-PAGE 通过彻底变性牺牲了蛋白质天然活性，换取了仅按分子量单一维度精确分离的高可预测性。**

## 💡 记忆锚点与口诀

- **变性三宝**：SDS 赋予负电荷，DTT 切断二硫键，煮沸展平三维链。
- **浓缩机制**：积层胶低 pH，氯快甘慢蛋白夹；分离胶高 pH，甘氨超越蛋白飞。
- **分子筛规律**：胶浓孔径小，大蛋白滞后，小蛋白跑前沿。
