# Western Blot 蛋白印迹法（Western Blotting / 免疫印迹法）

> **根节点**：Western Blot 如何在复杂的全细胞裂解液中，将电泳分离的蛋白质转印并利用抗体特异性“钓”出目标蛋白？
> **叙事逻辑**：电泳分离 → 膜转印（Blotting） → 封闭（Blocking） → 免疫杂交（一抗/二抗） → 底物发光显色（ECL）与相对定量
> **立场说明**：本文根据标准分子生物学及免疫学实验规范整理，透彻剖析物理转印、抗体结合机制与显色定量原理。
> **来源标注**：来源：蛋白质技术与免疫学实验手册，2026

## 一、电转印物理机制与固相膜选择（固相化）

在 SDS-PAGE 完成电泳后，目标蛋白质被封印在脆弱且密闭的聚丙烯酰胺凝胶网格内部，高分子的抗体无法穿透凝胶网格与蛋白质结合。因此，必须利用外加垂直电场，将凝胶中的蛋白质转移并牢固结合到高亲和力的**固相印迹膜（Blotting Membrane）**上。

> 📌 **固相转印膜（Blotting Membrane: PVDF / NC）**：用于结合并固定蛋白质的聚合物薄膜。在本文中，PVDF（聚偏二氟乙烯）膜依赖疏水作用结合蛋白质（须先用甲醇激活），具有极高机械强度；NC（硝酸纤维素）膜则依赖静电与氢键结合蛋白，无需甲醇激活但易碎。

> 📌 **转印缓冲液（Transfer Buffer）**：包含 Tris、甘氨酸、甲醇及微量 SDS 的缓冲体系。在本文中，甲醇促进 SDS 从蛋白质表面脱离，暴露蛋白质疏水区域以利于结合膜；而微量 SDS 则维持大分子蛋白的流动性与带电量。

```
              (负电极 -)
       ┌───────────────────────┐
       │     海绵垫 (Sponge)   │
       ├───────────────────────┤
       │     滤纸 (Filter)     │
       ├───────────────────────┤
       │  SDS-PAGE 凝胶 (Gel)  │  ← 蛋白质在此带负电 (-)
       ├───────────────────────┤
       │  转印膜 (PVDF/NC Membrane) │ ← 蛋白质向正极迁移并被膜拦截捕获
       ├───────────────────────┤
       │     滤纸 (Filter)     │
       ├───────────────────────┤
       │     海绵垫 (Sponge)   │
       └───────────────────────┘
              (正电极 +)
```

### 1.1 甲醇与 SDS 在转印中的平衡

转印缓冲液中甲醇浓度一般为 $10\% - 20\%$：
- **甲醇的作用**：脱去包裹在蛋白质表面的 SDS，恢复蛋白质的疏水性，极大地增强蛋白质对 PVDF/NC 膜的结合力；但过高浓度的甲醇会导致大分子蛋白质在凝胶内沉淀。
- **SDS 的作用**：通常加入 $0.025\% - 0.05\%$ 的 SDS。对于大分子量蛋白（$>100\text{ kDa}$），适量 SDS 能防止其在胶内沉淀，维持向正极迁移的动力。

> 🔗 **横向关联**：本节“转印中脱去 SDS”与 [[SDS-PAGE聚丙烯酰胺凝胶电泳]] 中的“SDS 结合赋予负电荷”形成**上下游关系**——SDS-PAGE 阶段利用 SDS 强结合实现纯分子量分离，而 WB 转印阶段则需要部分脱去 SDS 以恢复疏水暴露，使蛋白能牢固固定在膜上。

## 二、免疫封闭与双层抗体特异性识别（特异性捕获）

转印完成后，固相膜上未结合蛋白质的空白区域具有极强的非特异性蛋白吸附能力。如果不加处理直接加抗体，抗体本身也是蛋白质，会涂满整张膜，导致极高背景噪点。

> 📌 **封闭（Blocking）**：使用高浓度的无关蛋白质溶液（如 5% 脱脂奶粉或 3% BSA）浸泡转印膜的过程。在本文中，封闭分子会优先占据膜上所有的空白疏水/静电结合位点，防止后续抗体发生非特异性吸附。

> 📌 **一抗（Primary Antibody）**：特异性识别待测目标蛋白特定抗原表位（Epitope）的免疫球蛋白（IgG）。在本文中扮演“准确定位目标”的角色。

> 📌 **二抗（Secondary Antibody）**：针对一抗宿主物种 IgG 恒定区（Fc 段）的抗体（如山羊抗兔 IgG），且偶联了辣根过氧化物酶（HRP）或荧光染料。在本文中扮演“信号放大与显色中介”的角色。

### 2.1 免疫杂交反应流程

1. **封闭（Blocking）**：$5\%\text{ BSA}$ 或 脱脂奶粉，室温摇床孵育 1 小时。
2. **一抗孵育（Primary Ab）**：特异性结合目标蛋白条带，$4^\circ\text{C}$ 摇床孵育过夜。
3. **洗涤（TBST Wash）**：用含 Tween-20 表面活性剂的缓冲液洗去未结合的一抗（洗 3 次，每次 10 分钟）。
4. **二抗孵育（Secondary Ab-HRP）**：二抗特异性识别一抗 Fc 段，室温孵育 1 小时。
5. **再次洗涤（TBST Wash）**：彻底洗去残留游离二抗。

## 三、ECL 化学发光显色与半定量计算（信号转换）

最常用的检测系统是**增强型化学发光法（Enhanced Chemiluminescence, ECL）**。二抗上偶联的辣根过氧化物酶（HRP）催化底物发生氧化反应并释放光子。

```
              二抗 (Secondary Ab) ─ HRP 酶
                       │
             ┌─────────┴─────────┐
             │ HRP 催化氧化反应  │
             └─────────┬─────────┘
                       ▼
       鲁米诺 (Luminol) + H₂O₂ + 增强剂
                       │
                       ▼
        激发态 3-氨基邻苯二甲酸特异中间体 (3-APA*)
                       │
                       ▼ 释放光子 (hν, λ = 425 nm)
                   光信号输出
```

### 3.1 ECL 化学反应方程式与符号拆解

$$
\text{Luminol} + \text{H}_2\text{O}_2 \xrightarrow{\text{HRP + Enhancer}} 3\text{-APA}^* + \text{N}_2 \uparrow + 2\text{H}_2\text{O} \longrightarrow 3\text{-APA} + h\nu \; (\lambda = 425\text{ nm})
$$

- **$\text{Luminol}$**：5-氨基-2,3-二氢-1,4-酞嗪二酮（鲁米诺，底物发光体）；
- **$\text{H}_2\text{O}_2$**：过氧化氢（电子受体/氧化剂）；
- **$\text{HRP}$**：辣根过氧化物酶（Horseradish Peroxidase），固定于二抗末端；
- **$\text{Enhancer}$**：酚类增强剂（如对-碘代苯酚），可提高光量子产率近百倍；
- **$3\text{-APA}^*$**：处在激发态的 3-氨基邻苯二甲酸二阴离子；
- **$h\nu$**：释放出的蓝光光子，峰值波长约为 $425\text{ nm}$，可被 CCD 成像仪或 X 光胶片捕获。

### 3.2 内参归一化（Loading Control Normalization）定量计算

为了消除不同上样孔之间总蛋白量微小偏差或转印效率差异，必须引入稳定表达的**内参蛋白（Loading Control，如 $\beta$-actin, GAPDH, Tubulin）**进行灰度值归一化。

相对表达量公式：

$$
\text{Relative Expression} = \frac{\text{Intensity}_{\text{Target}} / \text{Intensity}_{\text{Internal Control (Target Group)}}}{\text{Intensity}_{\text{Control}} / \text{Intensity}_{\text{Internal Control (Control Group)}}}
$$

- **$\text{Intensity}_{\text{Target}}$**：实验组目标蛋白条带的积分灰度值；
- **$\text{Intensity}_{\text{Internal Control}}$**：对应上样孔内参蛋白（如 GAPDH）条带的积分灰度值。

#### 数值定量示例：
假定分析某抗肿瘤药物处理前后蛋白 X 的表达变化：
- **对照组**：蛋白 X 灰度值 = $10,000$；内参 GAPDH 灰度值 = $20,000$ $\to$ 比值 $= 0.50$
- **给药组**：蛋白 X 灰度值 = $30,000$；内参 GAPDH 灰度值 = $15,000$ $\to$ 比值 $= 2.00$
则给药组蛋白 X 的相对表达量为 $\frac{2.00}{0.50} = 4.00$，即**药物处理使目标蛋白 X 的表达水平上调了 4 倍**。

## 四、形象化解构：海报复写与雷达导弹比喻

### 4.1 形象比喻：印章复写与雷达引导导弹

* **形象比喻**：Western Blot 就像**“把果冻内部的印章复写到纸上，再用雷达引导导弹精准打中目标”**。
  - **转印（Blotting）**：SDS-PAGE 电泳完的果冻（凝胶）里藏着图案，但伸手摸不到。通过通电印章（电转印），把果冻里的蛋白质图案原封不动复写盖印到一张耐磨的硬纸（PVDF膜）上。
  - **封闭（Blocking）**：纸上没印着图案的空白地方沾满了胶水，为了不让后面的探针乱粘，先泼一层白面粉（奶粉/BSA）把空白胶水全部封死。
  - **一抗识别（Primary Ab）**：放出专一的追踪侦察兵（一抗），在几万种蛋白质图案里，只死死抓住目标图案（抗原表位）。
  - **二抗与显色（Secondary Ab + ECL）**：侦察兵身上携带着反射信号塔，二抗就像带有发光弹头的打击导弹，精准扣在侦察兵尾巴上，一加燃料（ECL底物）就爆发出强烈蓝光（$425\text{ nm}$），被夜视仪（CCD）拍下。

## 五、免疫印迹与相关蛋白质检测技术对比

为什么要对比这三种技术？因为在蛋白质分析中，研究者常常需要根据样品形态（液态/胶态）、分子量定性需求与精确绝对定量需求选择不同的免疫学方法。

| 维度 | Western Blot (WB) | SDS-PAGE 电泳 | 双抗体夹心法 ELISA |
| :--- | :--- | :--- | :--- |
| **检测核心** | 分子量 + **抗体特异性免疫识别** | 仅按**分子量分离染色** | **双抗体夹心特异性捕获** |
| **样品要求** | 变性裂解液（固体/组织/细胞） | 变性裂解液 | 可溶性液体（血清/细胞上清） |
| **分子量信息** | 提供（可通过条带位置核对 MW）| 提供 | **不提供**（无法区分截短体/单体）|
| **定量能力** | 半定量（Relative Quantitative）| 粗略半定量 | **高精度绝对定量**（pg/mL 标曲）|
| **通量** | 较低（每次 10~15 个样品） | 中等 | 高通量（96/384 孔板） |

最关键的差异点在哪里？**Western Blot 结合了 SDS-PAGE 的分子量空间分辨率与抗体的特异性免疫识别，是唯一能明确告知“目标分子量是否正确、是否存在降解片段”的半定量技术。**

## 💡 记忆锚点与口诀

- **实验五步曲**：一跑胶（PAGE），二转膜（Blot），三封闭（Block），四抗体（Ab），五发光（ECL）。
- **转印要领**：胶在负极膜在正，甲醇脱 SDS 促进结合。
- **归一化口诀**：目标灰度除内参，消除上样偏差干扰。
