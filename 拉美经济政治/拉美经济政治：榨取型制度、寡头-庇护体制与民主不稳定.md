> **根节点**：拉美为什么坐拥资源、早早独立、普遍实行民主，却长期陷入极端不平等、政变-民粹循环与「中等收入陷阱」，民主始终无法带来稳定？
> **叙事逻辑**：榨取型制度起源（殖民地基因）→ 阶级结构（寡头 vs 被排斥巨众）→ 制度形态（寡头制+庇护主义+考迪罗）→ 经济模式（资源依赖与民粹循环）→ 社会调查（民主为何失去人心）→ 为何民主不稳定（六大机制）
> **立场说明**：本文为多轮对话延伸的分析型笔记（用户要求用统计数据与社会调查解释核心逻辑，故含整理者分析）。统计数字标注口径与年份；拉美各国差异大，结论为区域共性提炼，个案有例外。

## 一、榨取型制度起源：殖民地基因

拉美问题的根，要追溯到殖民时代植入的**榨取型制度**——它从设计之初就是为了让少数精英从多数人身上抽取财富。

> 📌 **榨取型制度 vs 包容型制度（Extractive vs Inclusive Institutions，Acemoglu & Robinson《国家为什么会失败》）**：包容型制度广泛保护产权、开放机会、分散权力，激励创新（北美、西欧）；榨取型制度只保护精英产权、机会封闭、权力集中，目的是从多数人身上榨取给少数人（拉美、多数殖民地后国家）。本文用它作为拉美一切问题的制度学总根。

**北美 vs 拉美的殖民分野**（同样是欧洲殖民，命运两极）：

| 维度 | 北美（包容型基因） | 拉美（榨取型基因） |
|------|------------------|------------------|
| 殖民模式 | 定居型，小农产权广泛分布 | 种植园/矿场，土地与劳力高度集中 |
| 原住民/劳力 | 相对（被驱逐后）自由劳动力 | 大地产制 + 强制劳役/奴隶 |
| 产权分布 | 广泛（有产者众多） | 集中（少数家族占有） |
| 独立后 | 包容型制度自我强化 | 换了统治者，榨取基因被继承 |

> 📌 **大地产制（Latifundia）**：源于殖民的超大规模私人地产，土地与依附其上的劳动力高度集中在少数家族手中，是半封建食利精英的经济基础。拉美土地基尼普遍超过 0.8，是全球土地最集中的地区。本文用它解释拉美为何缺乏「广泛分布的有产者」这一民主稳定的根基。

> 🔗 **横向关联**：本节「榨取型 vs 包容型」与 [[世界经济政治/《国家为什么会失败》——知识树与批判性总结.md]] 中的制度二分框架形成**互证关系**——本笔记是该框架在拉美的具体演绎；与 [[世界经济政治/美国独立战争的本质：从反税到身份与合法性的重写.md]] 中「北美有产者反抗任意征税」形成**对照关系**——北美的包容型产权催生了稳定宪政，拉美的榨取型集中催生了寡头动荡。

## 二、阶级结构：哑铃型断层

拉美不是「橄榄型」（中产庞大）社会，而是**「哑铃型/沙漏型」**——顶端寡头、底层巨众、中间被掏空。这是它一切政治动荡的社会构造。

```
美国/西欧：  ◇ 橄榄型——中产庞大，两极小，妥协空间大
拉美：       ⧗ 哑铃/沙漏型——顶端寡头 + 底层巨众，中间被掏空
```

| 阶层        | 构成                                   | 性质              |
| --------- | ------------------------------------ | --------------- |
| **顶端寡头**  | 大地主 + 出口买办 + 金融财阀 + 军队高层 + （历史上）教会上层 | 半封建食利 + 依附性买办精英 |
| **缺失的中产** | 薄弱、不稳定，常在危机中被消灭                      | 缺乏民主的「承重墙」      |
| **底层巨众**  | 无地农民/农业雇工 + 原住民 + 城市非正规部门 + 小产业工人    | 被殖民制度排斥的多数      |

> 📌 **食利寡头（Rentier Oligarchy）**：财富不主要来自创新和生产效率，而来自占有土地、垄断资源出口、攫取地租和特许权的精英。这与美国「熊彼特式产业资本家」（创造性破坏、扩大生产）形成本质区别——拉美寡头是「占有存量、收租」，美国资本家是「创造增量」。本文用它解释拉美精英为何缺乏推动包容型增长的动力。

**最致命的结构特征：中产阶级缺失**。健康民主需要庞大中产作为「缓冲带」和「妥协的社会基础」。拉美中产长期薄弱，且每次恶性通胀/危机都会把中产储蓄归零、重新打回底层。**没有中间地带 = 没有妥协的社会基础 = 政治必然走向极化。**

> 🔗 **横向关联**：本节「哑铃型 + 中产缺失」与 [[世界经济政治/美国收入-阶级分布.md]] 中的美国阶级分布形成**对照关系**——美国（尽管不平等也在加剧）仍有相对厚实的中产承重层，拉美则是中产被反复消灭，这正是两者民主一稳一荡的社会结构根源。

## 三、制度形态：民主外壳 + 寡头内核

拉美的制度是一套**三层嵌套**——民主形式、寡头实质、军队兜底。

| 层级 | 形态 | 运作 |
|------|------|------|
| 表面 | 民主（选举/宪法/议会） | 定期选举、政党、形式合法性 |
| 中层 | 寡头制（oligarchy） | 寡头用媒体/资金/庇护网络操纵选举 |
| 底层 | 军队（暴力兜底） | 再分配威胁寡头核心利益时政变 |

> 📌 **庇护主义/恩庇侍从（Clientelism）**：基于「庇护人—侍从」人身依附的政治交换——政治大佬用恩惠（工作、补贴、保护）换取底层的政治忠诚和选票。这是拉美政治运作的「底层操作系统」，导致法律、官僚体系被私人关系网络穿透和俘获，制度永远无法非人格化。

> 📌 **考迪罗主义（Caudillismo）**：拉美特有的「个人化强人」政治传统——权力围绕魅力型领袖（caudillo）而非制度组织运转。从 19 世纪军事强人到 20 世纪庇隆、查韦斯，都是「个人凌驾于制度」。本文用它解释拉美为何反复产生民粹强人、制度难以积累。

**三层结构的关键**：民主是「平时的游戏规则」，但它有一个**军事政变的「熔断器」**——一旦再分配压力突破寡头容忍线，军队就推翻民选政府（智利 1973 阿连德是经典）。这就是为什么拉美民主总被政变打断。

> 🔗 **横向关联**：本节「庇护主义 + 考迪罗」与 [[世界经济政治/南亚经济政治：早熟民主、无就业增长与社会断裂.md]] 中「庇护主义俘获弱国家」形成**互证关系**——拉美（阶级断层）与南亚（身份断层）用不同社会材料生成同一种「制度无法非人格化」的病理。

## 四、经济模式：资源依赖与民粹循环

拉美经济被锁在 **「初级产品出口依附 + 财政民粹循环」** 里，形成周期性危机。

> 📌 **资源诅咒（Resource Curse）/ 依附理论（Dependency Theory）**：资源丰富的国家常因经济命脉系于初级产品出口（铜、石油、咖啡、大豆），受国际价格和跨国资本支配，难以工业升级，且资源租金强化食利精英。依附理论（普雷维什、CEPAL）进一步指出拉美处于「中心-外围」结构的外围，被结构性锁定在低端。本文用它解释拉美财富为何「向上和向外」（精英 + 跨国资本）汇集而非向下扩散。

**拉美的经济政策钟摆**（反复在两个极端间震荡）：

```
进口替代工业化（ISI，1940s–70s）
→ 债务危机 + 恶性通胀（1980s「失去的十年」）
→ 新自由主义/华盛顿共识（1990s 私有化+紧缩）
→ 贫富分化加剧 + 社会反弹
→ 粉红浪潮（2000s 左翼民粹，资源繁荣期撒钱）
→ 商品价格下跌 + 财政崩溃
→ 右翼紧缩反扑 → 下一轮循环
```

> 📌 **财政民粹主义（Fiscal Populism）**：在普选权 + 庞大穷人多数 + 弱制度约束下，政客靠承诺撒钱（福利、涨薪、国有化）赢选举，当选后兑现导致财政崩溃→通胀→危机。阿根廷（庇隆主义遗产 + 200%+ 通胀）和委内瑞拉（查韦斯-马杜罗 + 百万级恶性通胀）是两个极端样本。本文用它解释拉美民主为何沦为「民粹拍卖会」。

**这就是拉美「中等收入陷阱」的政治版本**：经济在中等收入水平反复震荡，每次接近升级就被债务/通胀/政变打回原形，始终无法突破到高收入。

> 🔗 **横向关联**：本节「中等收入陷阱反复震荡」与 [[世界经济政治/东亚经济政治：发展型国家、存量博弈与冷极化.md]] 中「东亚突破中等收入（除中国待定）」形成**对照关系**——东亚靠强国家 + 制造业升级闯关成功，拉美则因寡头俘获 + 财政民粹反复失败，两者印证「能否突破陷阱取决于制度而非资源禀赋」。

## 五、社会调查：民主为何失去人心

拉美的独特之处在于——它有最长的民主历史之一，却有最深的「民主幻灭」。社会调查数据把这种幻灭量化了。

**Latinobarómetro（拉美晴雨表）的核心发现**：

| 指标 | 趋势 | 含义 |
|------|------|------|
| 「民主优于任何其他政体」支持率 | 长期下滑至约 48% | 对民主的信念在松动 |
| 「不在乎民主还是威权，只要解决问题」 | 约半数认同，部分国家更高 | 民主被工具化、失去内在价值 |
| 对政党/议会/法院的信任 | 普遍极低（常低于 20–30%） | 制度合法性流失 |
| 对「强人领导」的接受度 | 在危机国家上升 | 为民粹强人/政变提供土壤 |

> 📌 **民主幻灭（Democratic Disillusionment）**：当民主长期不能兑现实质平等和有效治理，民众虽未必反对民主程序，却对其逐渐冷漠、工具化，转而支持「能办事」的强人。本文用它解释拉美为何在保有选举的同时，反复产生查韦斯、布克莱（萨尔瓦多）等绕过制度制约的民粹强人。

**不平等-不信任-民粹的三角**：

```
极端不平等（基尼 0.5+、顶端 10% 占 55%）
→ 底层认为「制度内民主改变不了我被榨取的命运」
→ 对政党/议会/法院失去信任
→ 转向街头革命 或 支持「为我说话」的民粹强人
→ 民粹上台撒钱 → 财政崩溃 → 幻灭加深 → 循环
```

> 🔗 **横向关联**：本节「民主幻灭」与 [[世界经济政治/东亚经济政治：发展型国家、存量博弈与冷极化.md]] 中「中国高信任威权悖论」形成**镜像关系**——东亚（中国）是「威权下的高满意度调查 + 用脚投票」，拉美是「民主下的低满意度调查 + 拥抱强人」，两者从相反方向揭示：当制度不能兑现实质福祉，无论民主还是威权，民众的「真实信号」都会与「制度叙事」背离。

## 六、为何民主不稳定：六大机制（收束）

把前述结构落到「民主为何无法稳定」这个核心问题，是**六个相互强化的机制**：

| # | 机制 | 逻辑 |
|---|------|------|
| 1 | **零和清算** | 极端不平等下，对穷人民主=合法剥夺寡头，对寡头民主=合法被抢，双方都视民主为你死我活而非轮流执政 |
| 2 | **无中产承重墙** | 缺乏「既怕底层革命又怕寡头专制」的妥协力量，民主在两极间剧烈摆动 |
| 3 | **民粹循环** | 多数决 + 弱约束 → 民主退化为财政民粹拍卖会 → 周期性危机 |
| 4 | **寡头俘获** | 寡头用钱/媒体/网络操纵选举 → 民主失去合法性 → 大众转向革命或强人 |
| 5 | **军队熔断器** | 再分配威胁寡头核心利益时军队政变（智利 1973）→ 民主无法巩固 |
| 6 | **非人格化未完成** | 庇护主义 + 考迪罗让权力始终人格化，民主外壳套在人身依附实质上，制度落不了地 |

**归因**：拉美民主之所以不稳定，根本原因不是「民主本身有问题」，而是**它只是嫁接在榨取型阶级结构上的「形式外壳」**——在极端不平等和阶级断层下，民主的多数决变成零和清算和民粹拍卖，而军队随时作为寡头的熔断器中断它。**稳定民主所需的社会基础——包容性制度、产权的广泛分布、庞大的中产阶级——拉美恰恰都缺。**

**延伸**：这反向印证了贯穿本系列的核心规律——**稳定的民主不是凭空产生的，它需要「广泛分布的有产者阶级」作根基**。美国有（北美定居型小农产权），所以民主稳定；拉美没有（殖民榨取型土地集中），所以民主动荡。**阶级结构决定制度命运。**

**个体坐标**：对拉美普通人而言，民主给了投票权却没给经济安全，于是「民主」与「面包」被反复对立——这解释了为何拉美民众在「珍视投票」与「拥抱强人」之间反复摇摆。要打破循环，真正要改的不是「要不要民主」，而是「能否把榨取型制度改造为包容型制度」——即土地/产权/机会的再分配与法治的非人格化，这远比选举本身更难，也更根本。

> 🔗 **横向关联**：本章「阶级结构决定制度命运」是本系列三篇笔记的共同收束——[[世界经济政治/东亚经济政治：发展型国家、存量博弈与冷极化.md]]（强国家先发展）、[[世界经济政治/南亚经济政治：早熟民主、无就业增长与社会断裂.md]]（弱国家早民主）、本篇（榨取型寡头民主），三者共同证明：决定一国政体命运的不是「选不选举」，而是「发展次序 + 阶级结构 + 国家能力」的组合。
